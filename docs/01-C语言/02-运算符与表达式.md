## 1. 算术运算符

```c
#include <stdio.h>

int main(void) {
    int a = 10, b = 3;

    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);
    printf("a %% b = %d\n", a % b);

    int c = 5;
    printf("c++ = %d\n", c++);
    printf("c = %d\n", c);
    printf("++c = %d\n", ++c);

    return 0;
}
```

### 1. 算术运算符总结

| 运算符 | 名称 | 示例 | 结果 |
|-------|------|------|------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 3` | `1`（整数除法） |
| `%` | 取模 | `5 % 3` | `2` |
| `++` | 自增 | `i++` / `++i` | 加1 |
| `--` | 自减 | `i--` / `--i` | 减1 |

### 2. 自增自减的前缀与后缀区别

| 形式 | 名称 | 执行顺序 |
|------|------|---------|
| `++i` | 前缀自增 | 先自增，再使用值 |
| `i++` | 后缀自增 | 先使用值，再自增 |
| `--i` | 前缀自减 | 先自减，再使用值 |
| `i--` | 后缀自减 | 先使用值，再自减 |

## 2. 关系运算符

| 运算符 | 说明 | 示例 |
|-------|------|------|
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `<` | 小于 | `a < b` |
| `>` | 大于 | `a > b` |
| `<=` | 小于等于 | `a <= b` |
| `>=` | 大于等于 | `a >= b` |

```c
#include <stdio.h>

int main(void) {
    int a = 10, b = 20;

    printf("a == b: %d\n", a == b);
    printf("a != b: %d\n", a != b);
    printf("a < b:  %d\n", a < b);
    printf("a > b:  %d\n", a > b);

    return 0;
}
```

## 3. 逻辑运算符

```c
#include <stdio.h>

int main(void) {
    int a = 1, b = 0;

    printf("a && b = %d\n", a && b);
    printf("a || b = %d\n", a || b);
    printf("!a = %d\n", !a);
    printf("!b = %d\n", !b);

    int x = 0;
    if (x != 0 && 10/x > 1) {
        printf("不会执行\n");
    }

    return 0;
}
```

### 1. 短路求值

```c
#include <stdio.h>

int main(void) {
    int i = 0;

    if (i != 0 && i++ > 0) {
    }
    printf("i = %d\n", i);

    if (i++ > 0 && i != 0) {
    }
    printf("i = %d\n", i);

    return 0;
}
```

## 4. 位运算符

```c
#include <stdio.h>

int main(void) {
    unsigned int a = 0b1100;
    unsigned int b = 0b1010;

    printf("a & b = %u\n", a & b);
    printf("a | b = %u\n", a | b);
    printf("a ^ b = %u\n", a ^ b);
    printf("~a = %u\n", ~a);
    printf("a << 2 = %u\n", a << 2);
    printf("a >> 2 = %u\n", a >> 2);

    return 0;
}
```

### 1. 位运算的实用技巧

```c
#include <stdio.h>

int main(void) {
    unsigned int flags = 0;

    flags |= (1 << 3);
    flags &= ~(1 << 3);
    flags ^= (1 << 3);

    if (flags & (1 << 3)) {
        printf("第3位为1\n");
    }

    int num = 7;
    if (num & 1) {
        printf("奇数\n");
    } else {
        printf("偶数\n");
    }

    int x = 10, y = 20;
    x = x ^ y;
    y = x ^ y;
    x = x ^ y;
    printf("x = %d, y = %d\n", x, y);

    return 0;
}
```

## 5. 赋值运算符

int a = 10;
a += 5;    /* a = a + 5; */

a ^= 0xFF; /* a = a ^ 0xFF; */

## 6. 条件运算符

```c
#include <stdio.h>

int main(void) {
    int a = 10, b = 20;
    int max = (a > b) ? a : b;
    printf("max = %d\n", max);

    return 0;
}
```

## 8. sizeof运算符

```c
#include <stdio.h>

int main(void) {
    printf("sizeof(char) = %zu\n", sizeof(char));
    printf("sizeof(int) = %zu\n", sizeof(int));
    printf("sizeof(float) = %zu\n", sizeof(float));
    printf("sizeof(double) = %zu\n", sizeof(double));

    int arr[10];
    printf("sizeof(arr) = %zu\n", sizeof(arr));
    int size = sizeof(arr) / sizeof(arr[0]);
    printf("数组元素个数: %d\n", size);

    return 0;
}
```

## 9. 运算符优先级表

| 优先级 | 运算符 | 结合性 |
|-------|-------|--------|
| 1 (最高) | `()` `[]` `->` `.` | 从左到右 |
| 2 | `!` `~` `++` `--` `+` `-` `*` `&` `sizeof` | 从右到左 |
| 3 | `*` `/` `%` | 从左到右 |
| 4 | `+` `-` | 从左到右 |
| 5 | `<<` `>>` | 从左到右 |
| 6 | `<` `<=` `>` `>=` | 从左到右 |
| 7 | `==` `!=` | 从左到右 |
| 8 | `&` | 从左到右 |
| 9 | `^` | 从左到右 |
| 10 | `\|` | 从左到右 |
| 11 | `&&` | 从左到右 |
| 12 | `\|\|` | 从左到右 |
| 13 | `?:` | 从右到左 |
| 14 (最低) | `=` `+=` `-=` `*=` `/=` 等 | 从右到左 |
