> 💡 **通俗理解 - 函数就像"食谱步骤"**：
>
> 想象你要做一道复杂的菜，菜谱会这样写：
> - "将食材切好"（一个函数）
> - "放入锅中翻炒"（另一个函数）
> - "装盘上桌"（又一个函数）
>
> 每个步骤都是独立的"操作单元"，可以复用。哪天想做同样的菜，只要按同样的步骤做就行。
>
> **函数的本质就是"给一段代码取个名字，需要时直接调用"**，不用每次都重新写一遍。

> 🔬 **抽象理解 - 函数的本质**：
>
> - **函数调用**：在汇编层面是"跳转+保存返回地址"
> - **栈帧**：每次函数调用在栈上创建一个"工作区"，存放局部变量和参数
> - **递归**：是函数调用自身的特殊形式，每次调用创建新的栈帧
> - **函数指针**：将函数视为"数据"，可以在运行时决定调用哪个函数

## 1. 函数定义和声明

### 1. 函数定义

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

void print_line(void) {
    printf("--------------------\n");
}

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main(void) {
    print_line();
    printf("3 + 5 = %d\n", add(3, 5));
    printf("5! = %d\n", factorial(5));
    print_line();

    return 0;
}
```

### 2. 函数声明（原型）

函数声明告诉编译器函数的名称、返回类型和参数类型，使编译器能正确检查函数调用。

```c
int add(int, int);
int add(int a, int b);
void print_line(void);
```

### 3. return语句

```c
#include <stdio.h>

int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

void early_return(void) {
    printf("第一步\n");
    return;
    printf("第二步\n");
}

int main(void) {
    printf("max(10, 20) = %d\n", max(10, 20));
    early_return();
    return 0;
}
```

## 2. 参数传递

```c
#include <stdio.h>

void swap_value(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

void swap_pointer(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 20;

    printf("Before: x = %d, y = %d\n", x, y);

    swap_value(x, y);
    printf("After swap_value: x = %d, y = %d\n", x, y);

    swap_pointer(&x, &y);
    printf("After swap_pointer: x = %d, y = %d\n", x, y);

    return 0;
}
```

### 1. 值传递 vs 指针传递

| 特性 | 值传递 | 指针传递 |
|------|-------|---------|
| 传递内容 | 变量的副本 | 变量的地址 |
| 修改原变量 | ❌ 不能 | ✅ 可以 |
| 内存开销 | 大（复制整个数据） | 小（只复制地址） |
| 适用场景 | 基本类型、小数据 | 数组、大数据、需要修改原值 |

## 3. 作用域

```c
#include <stdio.h>

int global = 100;

void func(void) {
    int local = 10;
    static int count = 0;

    count++;
    printf("local = %d, count = %d, global = %d\n", local, count, global);
}

int main(void) {
    func();
    func();
    func();

    return 0;
}
```

### 1. 作用域类型总结

| 作用域 | 生命周期 | 可见范围 |
|-------|---------|---------|
| 块作用域 | 块的执行期间 | 定义它的块内 |
| 文件作用域 | 整个程序运行期间 | 定义它的文件内 |
| 全局作用域 | 整个程序运行期间 | 所有文件 |

## 4. 存储类

| 存储类 | 生命周期 | 作用域 | 初始值 |
|-------|---------|-------|-------|
| `auto` | 块 | 块内 | 不确定 |
| `static` | 程序 | 块内/文件 | 0 |
| `extern` | 程序 | 全局 | 0 |
| `register` | 块 | 块内 | 不确定 |

### 1. volatile关键字

`volatile`告诉编译器：该变量可能被程序之外的因素修改，不要对它的访问进行优化。

```c
#include <stdio.h>
#include <signal.h>

volatile sig_atomic_t flag = 0;

void signal_handler(int sig) {
    flag = 1;
}

volatile int counter = 0;

void increment(void) {
    counter++;
}

int main(void) {
    volatile int sensor_value;
    sensor_value = *(volatile int*)0x12345678;

    printf("sensor_value = %d\n", sensor_value);

    return 0;
}
```

#### 1. volatile不保证原子性

`volatile`只保证每次都从内存读取，不保证操作的原子性。在多线程环境下，即使变量是volatile，也可能出现数据竞争。

## 5. 递归函数

```c
#include <stdio.h>

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

int main(void) {
    printf("5! = %d\n", factorial(5));
    printf("fibonacci(10) = %d\n", fibonacci(10));
    printf("gcd(48, 18) = %d\n", gcd(48, 18));

    return 0;
}
```

### 1. 递归 vs 迭代

| 特性 | 递归 | 迭代 |
|------|------|------|
| 代码简洁性 | 更简洁 | 较复杂 |
| 性能 | 函数调用开销大 | 更高 |
| 内存消耗 | 每次调用占用栈空间 | 通常只需少量变量 |
| 适用场景 | 树形结构、分治算法 | 简单重复任务 |

## 6. 可变参数函数

### 1. stdarg.h的四个宏

| 宏 | 说明 |
|---|------|
| `va_list` | 声明变量，用于遍历可变参数列表 |
| `va_start` | 初始化va_list，指定最后一个固定参数 |
| `va_arg` | 获取下一个参数，需要指定参数类型 |
| `va_end` | 清理va_list |

### 2. 自定义可变参数函数

```c
#include <stdio.h>
#include <stdarg.h>

int sum(int count, ...) {
    va_list args;
    va_start(args, count);

    int total = 0;
    for (int i = 0; i < count; i++) {
        total += va_arg(args, int);
    }

    va_end(args);
    return total;
}

int main(void) {
    printf("sum(3, 1,2,3) = %d\n", sum(3, 1, 2, 3));
    printf("sum(5, 1,2,3,4,5) = %d\n", sum(5, 1, 2, 3, 4, 5));
    printf("sum(0) = %d\n", sum(0));

    return 0;
}
```

### 3. printf的可变参数原理

```c
#include <stdio.h>
#include <stdarg.h>

void my_printf(const char* fmt, ...) {
    va_list args;
    va_start(args, fmt);

    while (*fmt) {
        if (*fmt == '%') {
            fmt++;
            switch (*fmt) {
                case 'd': {
                    int val = va_arg(args, int);
                    printf("%d", val);
                    break;
                }
                case 's': {
                    const char* str = va_arg(args, const char*);
                    printf("%s", str);
                    break;
                }
                case '%': {
                    putchar('%');
                    break;
                }
                default:
                    putchar('%');
                    putchar(*fmt);
            }
        } else {
            putchar(*fmt);
        }
        fmt++;
    }

    va_end(args);
}

int main(void) {
    my_printf("姓名: %s, 年龄: %d\n", "张三", 25);
    my_printf("100%%完成\n");

    return 0;
}
```

### 4. 自定义日志函数

```c
#include <stdio.h>
#include <stdarg.h>
#include <time.h>

typedef enum { LOG_INFO, LOG_WARNING, LOG_ERROR } LogLevel;

void log_message(LogLevel level, const char* fmt, ...) {
    const char* level_names[] = {"INFO", "WARNING", "ERROR"};

    time_t now = time(NULL);
    struct tm* t = localtime(&now);
    char time_buf[20];
    strftime(time_buf, sizeof(time_buf), "%Y-%m-%d %H:%M:%S", t);

    printf("[%s] [%s] ", time_buf, level_names[level]);

    va_list args;
    va_start(args, fmt);
    vprintf(fmt, args);
    va_end(args);

    printf("\n");
}

int main(void) {
    log_message(LOG_INFO, "程序启动");
    log_message(LOG_WARNING, "内存使用率: %d%%", 85);
    log_message(LOG_ERROR, "文件 %s 打开失败，错误码: %d", "data.txt", 2);

    return 0;
}
```

## 7. extern关键字

### 1. extern的作用

`extern`关键字用于声明在其他文件中定义的全局变量或函数，告诉编译器"这个变量/函数在别处定义，不要分配空间"。

### 2. extern声明 vs 定义

| 操作 | 是否分配内存 | 能否出现多次 | 示例 |
|------|------------|------------|------|
| 定义 | ✅ 分配内存 | ❌ 只能一次 | `int count = 0;` |
| extern声明 | ❌ 不分配内存 | ✅ 可以多次 | `extern int count;` |

### 3. extern与多文件编程

```c
/* file1.c */
int count = 0;

void increment(void) {
    count++;
}

int get_count(void) {
    return count;
}
```

```c
/* file2.c */
#include <stdio.h>

extern int count;
extern void increment(void);
extern int get_count(void);

int main(void) {
    increment();
    increment();
    printf("count = %d\n", get_count());
    printf("count = %d\n", count);
    return 0;
}
```

### 4. 最佳实践：头文件中放extern声明

```c
/* counter.h */
#ifndef COUNTER_H
#define COUNTER_H

extern int count;
void increment(void);
int get_count(void);

#endif
```

```c
/* counter.c */
#include "counter.h"

int count = 0;

void increment(void) {
    count++;
}

int get_count(void) {
    return count;
}
```

```c
/* main.c */
#include <stdio.h>
#include "counter.h"

int main(void) {
    increment();
    increment();
    printf("count = %d\n", get_count());
    return 0;
}
```

### 5. extern "C"

在C++中调用C语言编写的函数时，需要使用`extern "C"`来告诉C++编译器"请用C的方式查找这个函数名"。

```c
/* c_math.h */
#ifndef C_MATH_H
#define C_MATH_H

#ifdef __cplusplus
extern "C" {
#endif

int add(int a, int b);
int subtract(int a, int b);

#ifdef __cplusplus
}
#endif

#endif
```

## 8. static关键字详解

### 1. static的三种用法

| 用法 | 作用 |
|------|------|
| 静态局部变量 | 生命周期延长到程序结束，只初始化一次 |
| 静态全局变量/函数 | 限制作用域为当前文件（内部链接性） |

### 2. 静态局部变量

```c
#include <stdio.h>

void normal_func(void) {
    int count = 0;
    count++;
    printf("普通变量: count = %d\n", count);
}

void static_func(void) {
    static int count = 0;
    count++;
    printf("静态变量: count = %d\n", count);
}

int main(void) {
    printf("=== 第1次调用 ===\n");
    normal_func();
    static_func();

    printf("=== 第2次调用 ===\n");
    normal_func();
    static_func();

    printf("=== 第3次调用 ===\n");
    normal_func();
    static_func();

    return 0;
}
```

### 3. 静态全局变量/函数

```c
/* file_a.c */
#include <stdio.h>

static int private_count = 0;

static void private_helper(void) {
    printf("这是file_a的私有函数\n");
}

void public_func(void) {
    private_count++;
    private_helper();
    printf("private_count = %d\n", private_count);
}
```

```c
/* file_b.c */
#include <stdio.h>

extern void public_func(void);

int main(void) {
    public_func();
    public_func();
    return 0;
}
```

### 4. static与extern的对比

| 特性 | static全局变量/函数 | extern声明 |
|------|-------------------|-----------|
| 链接性 | 内部（仅本文件可见） | 外部（跨文件可见） |
| 能否被其他文件extern | ❌ 不可以 | ✅ 可以 |
| 命名冲突 | 不会与其他文件同名变量冲突 | 多个文件共享同一个变量 |
| 典型用途 | 模块内部实现细节 | 跨文件共享全局数据 |

## 9. 多文件编程基础

### 1. 为什么需要多文件

| 原因 | 说明 |
|------|------|
| 代码组织 | 将不同功能模块分到不同文件，结构清晰 |
| 编译效率 | 修改一个文件只需重新编译该文件 |
| 团队协作 | 不同开发者负责不同文件，互不干扰 |
| 代码复用 | 通用模块可以被多个项目共享 |

### 2. 头文件与源文件的分离

| 文件类型 | 内容 |
|---------|------|
| `.h` 头文件 | 声明（函数原型、类型定义、extern声明、宏定义） |
| `.c` 源文件 | 定义（函数实现、变量定义） |

### 3. 头文件保护

#### 1. 方式1：#ifndef / #define / #endif

```c
#ifndef MYHEADER_H
#define MYHEADER_H

int my_function(int x);

#endif
```

#### 2. 方式2：#pragma once

```c
#pragma once

int my_function(int x);
```

| 特性 | `#ifndef`方式 | `#pragma once` |
|------|-------------|----------------|
| 可移植性 | ✅ 所有编译器 | ✅ 主流编译器都支持 |
| 代码量 | 较多（3行） | 一行 |
| 推荐场景 | 需要最大兼容性 | 日常开发 |

### 4. 编译多文件项目

```bash
# 一次性编译所有源文件
gcc math_utils.c main.c -o program -lm

# 分步编译
gcc -c math_utils.c -o math_utils.o
gcc -c main.c -o main.o
gcc math_utils.o main.o -o program -lm
```

### 5. 使用Makefile

```makefile
CC = gcc
CFLAGS = -Wall -g
OBJS = math_utils.o main.o

program: $(OBJS)
	$(CC) $(OBJS) -o program $(LDFLAGS)

math_utils.o: math_utils.c math_utils.h
	$(CC) $(CFLAGS) -c math_utils.c -o math_utils.o

main.o: main.c math_utils.h
	$(CC) $(CFLAGS) -c main.c -o main.o

clean:
	rm -f $(OBJS) program
```

## 10. 本章小结

### 1. 核心知识点

| 类别 | 要点 |
|-----|------|
| 函数定义 | 返回类型、函数名、参数列表、函数体 |
| 参数传递 | 值传递和指针传递的区别 |

| 可变参数 | va_list/va_start/va_arg/va_end |
| extern | 跨文件声明、extern "C" |
| static | 静态局部变量、静态全局变量/函数 |
| 多文件编程 | 头文件与源文件分离、头文件保护 |

### 2. 常见陷阱

| 陷阱 | 说明 |
|-----|------|
| 值传递无法修改原值 | 需要修改原值时应使用指针传递 |
| 递归深度过大 | 栈溢出 |
| 可变参数类型错误 | va_arg类型与实际不匹配导致未定义行为 |
| extern带初始化 | `extern int x = 0;`等于定义而非声明 |
| static误用 | 静态局部变量只初始化一次 |
| 头文件缺少保护 | 重复包含导致重复定义错误 |
