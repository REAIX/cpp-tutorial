## 本章导读

在C语言中，字符串是以空字符 `\0` 结尾的字符数组。C语言没有专门的字符串类型，而是通过字符数组和指针来处理字符串。本章将详细介绍字符串的定义、常用函数以及字符串处理技巧。

### 1. 🌟 通俗解释 - 什么是字符串？

> 💡 **生活中的比喻：字符串就像"一串鞭炮"**

想象一下：

- **字符串** 就像一串鞭炮，每个鞭炮就是一个字符
- **字符** 就是每个鞭炮上的"花色"（比如'H', 'e', 'l', 'l', 'o'）
- **空字符 '\0'** 就像鞭炮结尾的"鞭头"，告诉放鞭炮的人"到这里结束"
- **字符数组** 就像挂鞭炮的那根绳子

**为什么需要结束的标记？**

想象你要告诉朋友"这串鞭炮有多长"：

- 方法1：先数一遍有几个鞭炮，然后告诉朋友"有5个"
- 方法2：在最后一个鞭炮后面打个结作为标记，朋友从第一个开始放，一直放到打结处

C语言用的是方法2！在最后一个字符后面放一个特殊的"结束标记" `\0`，这样就知道字符串到哪里结束了。

**内存中的样子：**

```
字符串 "Hello" 在内存中就像这样：

┌─────┬─────┬─────┬─────┬─────┬─────┐
│ 'H' │ 'e' │ 'l' │ 'l' │ 'o' │ '\0'│   ← 就像5个鞭炮 + 1个结尾标记
└─────┴─────┴─────┴─────┴─────┴─────┘
  [0]   [1]   [2]   [3]   [4]   [5]   ← 索引位置
```

### 2. 概念与定义

**字符串（string）**：以空字符 `\0` 结尾的字符序列。`\0` 是ASCII码为0的字符，用作字符串结束标志。

**字符数组（character array）**：存储字符的数组，可以用来存储字符串。

**字符串字面量（string literal）**：用双引号括起来的字符序列，如 `"Hello"`。

## 1. 字符串基础

### 1. 字符串的定义方式

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    /* 方式1：字符数组（可修改） */
    char str1[] = "Hello";           /* 自动计算大小，包含'\0' */
    printf("str1: %s, size: %zu\n", str1, sizeof(str1));  /* size: 6 */
    
    /* 方式2：指定大小的字符数组 */
    char str2[10] = "World";         /* 剩余位置填充'\0' */
    printf("str2: %s, size: %zu\n", str2, sizeof(str2));  /* size: 10 */
    
    /* 方式3：字符指针（指向字符串字面量，不可修改） */
    char *str3 = "Hello";            /* 指向只读内存 */
    printf("str3: %s\n", str3);
    /* str3[0] = 'h';  错误！字符串字面量不可修改 */
    
    /* 方式4：逐个字符初始化 */
    char str4[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
    printf("str4: %s\n", str4);
    
    return 0;
}
```

### 2. 字符串内存布局

```
字符串 "Hello" 在内存中的布局：

地址      索引    字符    ASCII
┌────────┬─────┬──────┬───────┐
│ 0x1000 │ [0] │  H   │  72   │
├────────┼─────┼──────┼───────┤
│ 0x1001 │ [1] │  e   │  101  │
├────────┼─────┼──────┼───────┤
│ 0x1002 │ [2] │  l   │  108  │
├────────┼─────┼──────┼───────┤
│ 0x1003 │ [3] │  l   │  108  │
├────────┼─────┼──────┼───────┤
│ 0x1004 │ [4] │  o   │  111  │
├────────┼─────┼──────┼───────┤
│ 0x1005 │ [5] │  \0  │   0   │ ← 字符串结束标志
└────────┴─────┴──────┴───────┘

关键概念：
- strlen("Hello") = 5  （不含'\0'）
- sizeof("Hello") = 6  （含'\0'）
```

### 3. strlen与sizeof的区别

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char str[] = "Hello";
    
    /* strlen：字符串长度（不含'\0'） */
    printf("strlen(str) = %zu\n", strlen(str));  /* 5 */
    
    /* sizeof：数组大小（含'\0'） */
    printf("sizeof(str) = %zu\n", sizeof(str));  /* 6 */
    
    /* 对于指针 */
    char *ptr = "Hello";
    printf("strlen(ptr) = %zu\n", strlen(ptr));  /* 5 */
    printf("sizeof(ptr) = %zu\n", sizeof(ptr));  /* 8（指针大小） */
    
    return 0;
}
```

| 函数/运算符        | 说明            | 示例结果 |
| ------------- | ------------- | ---- |
| `strlen(str)` | 字符串长度（不含`\0`） | 5    |
| `sizeof(str)` | 数组大小（含`\0`）   | 6    |
| `sizeof(ptr)` | 指针大小          | 4或8  |

## 2. 字符串函数详解

### 1. 字符串长度与复制

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    /* strlen：获取字符串长度 */
    char str[] = "Hello, World!";
    printf("Length: %zu\n", strlen(str));  /* 13 */
    
    /* strcpy：复制字符串（目标必须足够大） */
    char dest[20];
    strcpy(dest, str);
    printf("After strcpy: %s\n", dest);
    
    /* strncpy：安全复制（指定最大长度） */
    char safe_dest[10];
    strncpy(safe_dest, str, sizeof(safe_dest) - 1);
    safe_dest[sizeof(safe_dest) - 1] = '\0';  /* 确保以'\0'结尾 */
    printf("After strncpy: %s\n", safe_dest);  /* "Hell" */
    
    return 0;
}
```

### 2. 字符串连接与比较

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char str1[50] = "Hello";
    char str2[] = " World";
    
    /* strcat：连接字符串 */
    strcat(str1, str2);
    printf("After strcat: %s\n", str1);  /* "Hello World" */
    
    /* strncat：安全连接（指定最大长度） */
    char str3[10] = "Hi";
    strncat(str3, " There!", sizeof(str3) - strlen(str3) - 1);
    printf("After strncat: %s\n", str3);
    
    /* strcmp：比较字符串 */
    char a[] = "apple";
    char b[] = "banana";
    char c[] = "apple";
    
    printf("strcmp(a, b) = %d\n", strcmp(a, b));  /* 负数：a < b */
    printf("strcmp(a, c) = %d\n", strcmp(a, c));  /* 0：相等 */
    printf("strcmp(b, a) = %d\n", strcmp(b, a));  /* 正数：b > a */
    
    /* strncmp：比较前n个字符 */
    printf("strncmp(a, c, 3) = %d\n", strncmp(a, c, 3));  /* 0 */
    
    return 0;
}
```

### 3. 字符串查找

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char str[] = "Hello, World!";
    
    /* strchr：查找字符首次出现的位置 */
    char *ptr = strchr(str, 'o');
    if (ptr) {
        printf("Found 'o' at position: %td\n", ptr - str);  /* 4 */
    }
    
    /* strrchr：查找字符最后一次出现的位置 */
    ptr = strrchr(str, 'o');
    if (ptr) {
        printf("Last 'o' at position: %td\n", ptr - str);  /* 7 */
    }
    
    /* strstr：查找子串 */
    ptr = strstr(str, "World");
    if (ptr) {
        printf("Found \"World\" at position: %td\n", ptr - str);  /* 7 */
    }
    
    /* strpbrk：查找任意匹配字符 */
    ptr = strpbrk(str, "aeiou");
    if (ptr) {
        printf("First vowel: %c at position: %td\n", *ptr, ptr - str);
    }
    
    return 0;
}
```

### 4. 字符串函数速查表

| 函数                   | 功能        | 返回值                  |
| -------------------- | --------- | -------------------- |
| `strlen(s)`          | 字符串长度     | 长度（不含`\0`）           |
| `strcpy(d, s)`       | 复制字符串     | 目标指针                 |
| `strncpy(d, s, n)`   | 复制n个字符    | 目标指针                 |
| `strcat(d, s)`       | 连接字符串     | 目标指针                 |
| `strncat(d, s, n)`   | 连接n个字符    | 目标指针                 |
| `strcmp(s1, s2)`     | 比较字符串     | 0相等，负数s1\<s2，正数s1>s2 |
| `strncmp(s1, s2, n)` | 比较前n个字符   | 同上                   |
| `strchr(s, c)`       | 查找字符首次出现  | 位置指针或NULL            |
| `strrchr(s, c)`      | 查找字符最后出现  | 位置指针或NULL            |
| `strstr(s1, s2)`     | 查找子串      | 位置指针或NULL            |
| `strpbrk(s1, s2)`    | 查找任意匹配字符  | 位置指针或NULL            |
| `strtok(s, delim)`   | 分割字符串     | 分割后的字符串              |
| `strdup(s)`          | 复制字符串到新内存 | 新字符串指针（需free）        |
| `strerror(errnum)`   | 获取错误信息    | 错误描述字符串              |
| `strsignal(signum)`  | 获取信号含义    | 信号描述字符串              |

## 3. 字符串复制函数 strdup

`strdup` 是 C 语言中非常实用的函数，用于将字符串复制到新分配的内存中：

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int main(void) {
    const char *original = "Hello, World!";
    
    /* strdup：复制字符串到新分配的内存 */
    char *copy = strdup(original);
    if (copy == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }
    
    printf("Original: %s\n", original);
    printf("Copy: %s\n", copy);
    
    /* 修改副本不会影响原字符串 */
    copy[0] = 'h';
    printf("After modifying copy:\n");
    printf("  Original: %s\n", original);  /* 仍是 "Hello, World!" */
    printf("  Copy: %s\n", copy);          /* "hello, World!" */
    
    /* 重要：使用完毕后必须释放内存 */
    free(copy);
    
    return 0;
}
```

**`strdup`** **的特点：**

| 特性          | 说明                 |
| ----------- | ------------------ |
| 自动分配内存      | 根据字符串长度自动 `malloc` |
| 自动复制内容      | 包括结尾的 `\0`         |
| 返回新指针       | 与原字符串无关            |
| 需要手动 `free` | 否则造成内存泄漏           |

**与** **`strcpy`** **的区别：**

```c
/* strcpy：需要预先分配内存，复制到已有缓冲区 */
char dest[20];
strcpy(dest, "Hello");  /* 目标缓冲区必须足够大 */

/* strdup：自动分配内存，返回新指针 */
char *copy = strdup("Hello");  /* 自动分配并复制 */
free(copy);  /* 使用完毕要释放 */
```

**使用场景：**

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

/* 函数返回新分配的字符串（调用者需负责释放） */
char *extract_extension(const char *filename) {
    const char *dot = strrchr(filename, '.');
    if (dot == NULL) {
        return strdup("");  /* 无扩展名，返回空字符串 */
    }
    return strdup(dot + 8);  /* 返回扩展名副本 */
}

int main(void) {
    char *ext = extract_extension("document.pdf");
    printf("Extension: %s\n", ext);  /* "pdf" */
    free(ext);
    
    return 0;
}
```

## 4. 错误信息函数

`strerror` 和 `strsignal` 用于获取错误和信号的相关信息，在调试和日志记录中非常实用：

```c
#include <stdio.h>
#include <string.h>
#include <signal.h>
#include <errno.h>

int main(void) {
    /* strerror：根据错误码获取错误描述 */
    printf("ENOENT (file not found): %s\n", strerror(ENOENT));
    printf("ENOMEM (out of memory): %s\n", strerror(ENOMEM));
    printf("EACCES (permission denied): %s\n", strerror(EACCES));
    
    /* 配合 errno 使用 */
    FILE *f = fopen("nonexistent.txt", "r");
    if (f == NULL) {
        printf("Error opening file: %s (errno: %d)\n", strerror(errno), errno);
    }
    
    /* 注意：strerror不是线程安全的，它返回指向内部静态缓冲区的指针。
       在多线程环境中，应使用 strerror_r（POSIX）或 strerror_s（C11 Annex K）。 */
    
    /* strsignal：根据信号码获取信号描述 
    printf("\nSignal descriptions:\n");
    printf("SIGINT (Ctrl+C): %s\n", strsignal(SIGINT));
    printf("SIGSEGV (segmentation fault): %s\n", strsignal(SIGSEGV));
    printf("SIGABRT (abort): %s\n", strsignal(SIGABRT));
    */
    return 0;
}
```

**典型应用场景：**

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

/* 错误处理封装 */
void handle_error(const char *context) {
    fprintf(stderr, "Error in %s: %s\n", context, strerror(errno));
}

/* 文件操作错误处理示例 */
int safe_file_operation(void) {
    FILE *f = fopen("data.txt", "r");
    if (f == NULL) {
        fprintf(stderr, "Failed to open data.txt: %s\n", strerror(errno));
        return -1;
    }
    
    /* 读取文件... */
    
    if (fclose(f) != 0) {
        fprintf(stderr, "Failed to close file: %s\n", strerror(errno));
        return -1;
    }
    
    return 0;
}
```

## 5. 内存操作函数

`memcpy`、`memmove` 和 `memset` 虽然不是字符串专用函数，但与字符串操作密切相关：

```c
memcpy 从前到后硬拷贝，当数据源和目标重叠时，会提前覆盖尚未读取的原始数据，导致后续拷贝出错、产生脏数据。
memmove 会先判断内存是否重叠，若重叠则从后向前拷贝，或创建一份源数据的临时副本，再用副本安全填充目标区域，不会破坏源数据。
```

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char buffer[20];
    
    /* memset：向内存区域填充值（常用于清零或设置标记） */
    memset(buffer, 0, sizeof(buffer));  /* 清零缓冲区 */
    printf("After memset(0): ");
    for (int i = 0; i < 5; i++) printf("%d ", buffer[i]);
    printf("\n");
    
    memset(buffer, 'A', 5);  /* 填充 5 个 'A' */
    printf("After memset('A'): %s\n", buffer);
    
    /* memcpy：复制内存区域（不处理重叠） */
    const char *src = "Hello, World!";
    memcpy(buffer, src, 5);  /* 复制前5个字符 */
    buffer[5] = '\0';
    printf("After memcpy: %s\n", buffer);
    
    /* memmove：安全复制（处理重叠区域） */
    char overlap[] = "ABCDEFGH";       /* memmove(目标，源，复制长度) */
    memmove(overlap + 2, overlap, 4);  /* "ABCD" 移到 "CDEF" 位置 */
    printf("After memmove: %s\n", overlap);  /* "ABABCDGH" */
    
    return 0;
}
```

**三者区别：**

| 函数        | 处理重叠   | 速度 | 适用场景      |
| --------- | ------ | -- | --------- |
| `memcpy`  | 不处理重叠  | 最快 | 确认无重叠时使用  |
| `memmove` | 安全处理重叠 | 稍慢 | 可能存在重叠时使用 |
| `memset`  | N/A    | 快  | 初始化/清零    |

### 1. memcmp 内存比较

`memcmp` 用于比较两个内存区域的内容：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    const char *str1 = "Hello";
    const char *str2 = "Hello";
    const char *str3 = "World";
    const char *str4 = "Hell";

    /* memcmp：比较内存区域 */
    printf("memcmp(str1, str2): %d\n", memcmp(str1, str2, 5));  /* 0 相等 */
    printf("memcmp(str1, str3): %d\n", memcmp(str1, str3, 5));  /* 负数 str1 < str3 */
    printf("memcmp(str1, str4): %d\n", memcmp(str1, str4, 5));  /* 正数 str1 > str4 */

    /* 比较二进制数据 */
    unsigned char data1[] = {0x01, 0x02, 0x03};
    unsigned char data2[] = {0x01, 0x02, 0x00};
    int result = memcmp(data1, data2, 3);
    printf("memcmp(data1, data2): %d\n", result);  /* 正数：data1 > data2 */

    return 0;
}
```

**memcmp vs strcmp：**

| 特性    | `memcmp`     | `strcmp`       |
| ----- | ------------ | -------------- |
| 比较对象  | 任意内存区域       | 字符串（遇 `\0` 停止） |
| 比较长度  | 指定字节数        | 自动直到 `\0`      |
| 二进制安全 | 是            | 否（不能比较 `\0`）   |
| 适用场景  | 结构体、协议数据、二进制 | 字符串比较          |

**实际应用示例：**

```c
#include <stdio.h>
#include <string.h>

/* 比较协议头 */
typedef struct {
    char magic[4];
    int version;
    int payload_len;
} Header;

int validate_header(const Header *hdr) {
    const char expected_magic[] = {'D', 'A', 'T', 'A'};

    /* 比较魔数（前4字节） */
    if (memcmp(hdr->magic, expected_magic, 4) != 0) {
        printf("Invalid magic number\n");
        return 0;
    }

    /* 比较版本号（整数比较） */
    if (hdr->version != 1) {
        printf("Unsupported version: %d\n", hdr->version);
        return 0;
    }

    return 1;
}

/* 检查内存区域是否全为0 */
int is_zeroed(const void *ptr, size_t size) {
    const unsigned char *p = (const unsigned char *)ptr;
    for (size_t i = 0; i < size; i++) {
        if (p[i] != 0) return 0;
    }
    return 1;
}

/* 比较固定长度的字符串（不受 \0 影响）*/
int fixed_length_compare(const char *s1, const char *s2, size_t n) {
    for (size_t i = 0; i < n; i++) {
        if (s1[i] != s2[i]) {
            return 1;  /* 不相等 */
        }
    }
    return 0;  /* 相等 */
}
```

**注意事项：**

```c
/* memcmp 返回值只是比较大小，不是 -1/0/1 */
int result = memcmp(a, b, n);
if (result < 0) {
    /* a < b */
} else if (result > 0) {
    /* a > b */
} else {
    /* a == b */
}

/* 比较时按字节逐个比较，一旦遇到不同的字节就返回结果 */
const char s1[] = "ABz";
const char s2[] = "ABa";
/* 'z' (122) > 'a' (97)，所以 s1 > s2，返回正数 */
```

**什么时候用 memcmp？**

1. 比较固定长度的数据（不考虑 `\0`）
2. 比较结构体
3. 比较协议数据/二进制数据
4. 需要指定比较长度时

**什么时候用 strcmp？**

1. 比较以 `\0` 结尾的字符串
2. 需要自动处理字符串长度时

**什么时候用？**

```c
/* 场景1：清零字符串数组 */
char usernames[100][50];
memset(usernames, 0, sizeof(usernames));

/* 场景2：复制固定长度的数据（如结构体） */
```

```c

#include <ctype.h>
#include <string.h>

/* 验证用户名：只能包含字母和数字 */
int validate_username(const char *username) {
    if (username == NULL || strlen(username) == 0) {
        return 0;
    }

    for (const char *p = username; *p; p++) {
        if (!isalnum((unsigned char)*p)) {
            return 0;  /* 包含非法字符 */
        }
    }
    return 1;  /* 用户名有效 */
}

/* 验证密码：必须包含字母和数字 */
int validate_password(const char *password) {
    int has_letter = 0;
    int has_digit = 0;

    if (password == NULL || strlen(password) < 8) {
        return 0;  /* 密码太短 */
    }

    for (const char *p = password; *p; p++) {
        if (isalpha((unsigned char)*p)) has_letter = 1;
        if (isdigit((unsigned char)*p)) has_digit = 1;
    }

    return has_letter && has_digit;  /* 必须同时包含字母和数字 */
}

/* 统计字符串中的各类字符 */
void count_chars(const char *str) {
    int letters = 0, digits = 0, spaces = 0, others = 0;

    while (*str) {
        unsigned char c = *str;
        if (isalpha(c)) letters++;
        else if (isdigit(c)) digits++;
        else if (isspace(c)) spaces++;
        else others++;
        str++;
    }

    printf("Letters: %d, Digits: %d, Spaces: %d, Others: %d\n",
           letters, digits, spaces, others);
}

    printf("  'password': %s\n", validate_password("password") ? "Valid" : "Invalid");
    printf("  '123456': %s\n", validate_password("123456") ? "Valid" : "Invalid");

    printf("\nCharacter count:\n");
    count_chars("Hello, World! 123");

    return 0;
}
```

```c
char *trim(char *str) {
    char *end;
    
    /* 去除前导空白 */
    while (isspace((unsigned char)*str)) {
        str++;
    }
    
    /* 全是空白的情况 */
    if (*str == '\0') {
        return str;

        end--;
    }
    end[1] = '\0';
    
    return str;
}
```

### 4. const char\* 的正确使用

在函数参数中使用 `const char*` 是 C 语言中的重要规范，表明函数不会修改字符串：

```c
#include <stdio.h>
#include <string.h>

/* 推荐做法：使用 const 表明函数不会修改字符串 */
size_t safe_strlen(const char *s) {
    size_t len = 0;
    while (s && *s) {
        len++;
        s++;
    }
    return len;
}

/* 错误做法：不使用 const，调用者可能担心数据被修改 */
size_t unsafe_strlen(char *s) {
    size_t len = 0;
    while (s && *s) {
        len++;
        s++;
    }
    return len;
}

int main(void) {
    const char *readonly_string = "This should not be modified";
    char modifiable_string[] = "This can be modified";

    /* const char* 参数可以接受两种字符串 */
    printf("Length of readonly string: %zu\n", safe_strlen(readonly_string));
    printf("Length of modifiable string: %zu\n", safe_strlen(modifiable_string));

    /* 但 char* 参数不能接受 const 字符串（可能修改危险） */
    /* unsafe_strlen(readonly_string); */  /* 编译警告 */

    return 0;
}
```

**为什么 const char* 很重要？**

| 作用     | 说明             |
| ------ | -------------- |
| 代码清晰   | 调用者知道函数不会修改数据  |
| 编译器检查  | 意外修改会收到编译警告    |
| 接口安全   | 防止意外修改只读数据     |
| API 规范 | POSIX 和标准库函数常用 |

**实际应用示例：**

## 8. 字符串安全操作

### 1. 危险函数与安全替代

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char dest[10];
    char src[] = "This is a very long string";
    
    /* 危险：strcpy不检查目标大小 */
    /* strcpy(dest, src);  可能缓冲区溢出！ */
    
    /* 安全：使用strncpy并手动添加'\0' */
    strncpy(dest, src, sizeof(dest) - 1);
    dest[sizeof(dest) - 1] = '\0';
    printf("Safe copy: %s\n", dest);
    
    /* 危险：gets不检查缓冲区大小（已弃用） */
    /* char buf[10]; */
    /* gets(buf);  极度危险！ */
    
    /* 安全：使用fgets */
    char buf[10];
    printf("Enter a string: ");
    if (fgets(buf, sizeof(buf), stdin) != NULL) {
        /* 去除换行符 */
        size_t len = strlen(buf);
        if (len > 0 && buf[len - 1] == '\n') {
            buf[len - 1] = '\0';
        }
        printf("You entered: %s\n", buf);
    }
    
    return 0;
}
```

### 2. 安全函数对照表

| 危险函数          | 风险    | 安全替代                     |
| ------------- | ----- | ------------------------ |
| `strcpy`      | 缓冲区溢出 | `strncpy` + 手动加`\0`      |
| `strcat`      | 缓冲区溢出 | `strncat`                |
| `sprintf`     | 缓冲区溢出 | `snprintf`               |
| `gets`        | 无长度检查 | `fgets`                  |
| `scanf("%s")` | 无长度检查 | `scanf("%9s")` 或 `fgets` |

### 3. snprintf 安全的格式化字符串

`snprintf` 是 `sprintf` 的安全版本，可以防止缓冲区溢出：

```c
#include <stdio.h>

int main(void) {
    char buffer[20];
    const char *name = "Alice";
    int age = 30;
    
    /* snprintf：安全的格式化输出 */
    /* 格式：snprintf(目标缓冲区, 缓冲区大小, 格式字符串, 参数...) */
    snprintf(buffer, sizeof(buffer), "Name: %s, Age: %d", name, age);
    printf("Result: %s\n", buffer);  /* "Name: Alice, Age: 30" */
    
    /* 测试缓冲区溢出保护 */
    snprintf(buffer, sizeof(buffer), "Very long string: %s", "This is too long!");
    printf("Overflow test: %s\n", buffer);
    /* 只会写入 "Very long string: This is t" (截断到缓冲区大小) */
    
    /* 获取实际需要的长度（不写入缓冲区） */
    int needed = snprintf(NULL, 0, "Name: %s, Age: %d", name, age);
    printf("Needed buffer size: %d bytes\n", needed + 1);  /* +1 for '\0' */
    
    /* 动态分配正确大小的缓冲区 */
    char *dynamic_buffer = malloc(needed + 1);
    if (dynamic_buffer) {
        snprintf(dynamic_buffer, needed + 1, "Name: %s, Age: %d", name, age);
        printf("Dynamic: %s\n", dynamic_buffer);
        free(dynamic_buffer);
    }
    
    return 0;
}
```

**snprintf 的返回值：**

| 返回值 | 含义                 |
| --- | ------------------ |
| 正数  | 实际需要的字符数（不包括 `\0`） |
| 负数  | 格式化错误              |

```c
/* 安全的字符串复制 */
char *safe_strcpy(char *dest, size_t dest_size, const char *src) {
    if (dest == NULL || src == NULL || dest_size == 0) {
        return dest;
    }
    
    size_t src_len = strlen(src);
    size_t copy_len = (src_len < dest_size - 1) ? src_len : dest_size - 1;
    
    memcpy(dest, src, copy_len);
    dest[copy_len] = '\0';
    
    return dest;
}

char *safe_strcat(char *dest, size_t dest_size, const char *src) {
    if (dest == NULL || src == NULL || dest_size == 0) {
        return dest;
    }
    
    size_t dest_len = strlen(dest);
    size_t src_len = strlen(src);
    size_t available = dest_size - dest_len - 1;
    
    if (available > 0) {
        size_t copy_len = (src_len < available) ? src_len : available;
        memcpy(dest + dest_len, src, copy_len);
        dest[dest_len + copy_len] = '\0';
    }
    
    return dest;
}
```

## 6. 宽字符与多字节字符

### 1. 字符编码基础

计算机中的字符需要用数字编码来表示。不同的编码方案覆盖的字符范围和存储方式各不相同：

**ASCII（American Standard Code for Information Interchange）**

- 7位编码，共128个字符（0~127）
- 包含英文字母、数字、标点符号和控制字符
- 无法表示中文、日文、韩文等非拉丁文字

**Latin-1 / ISO-8859-1**

- 8位编码，共256个字符（0~255）
- 向下兼容ASCII，扩展了西欧语言字符
- 仍然无法表示中文等CJK字符

**Unicode**

- 统一编码标准，目标是覆盖世界上所有文字系统
- 目前已收录超过14万个字符
- Unicode只是"码位"（code point）的集合，具体存储需要编码方案

**UTF-8 / UTF-16 / UTF-32 编码方案对比：**

| 编码方案 | 字节长度 | 特点             | 适用场景        |
| ---- | ---- | -------------- | ----------- |
| UTF-8  | 1~4字节变长 | 兼容ASCII、节省空间、无字节序问题 | 网络传输、文件存储、Linux |
| UTF-16 | 2或4字节变长 | Windows内部使用、有字节序问题 | Windows API、Java |
| UTF-32 | 固定4字节 | 随机访问方便、占用空间大 | 内部处理、索引查找   |

```
以汉字"中"为例：
  Unicode码位：U+4E2D
  UTF-8编码：  0xE4 0xB8 0xAD（3字节）
  UTF-16编码： 0x4E2D（2字节）
  UTF-32编码： 0x00004E2D（4字节）

以字母"A"为例：
  Unicode码位：U+0041
  UTF-8编码：  0x41（1字节，与ASCII相同）
  UTF-16编码： 0x0041（2字节）
  UTF-32编码： 0x00000041（4字节）
```

### 2. 宽字符 wchar_t

`wchar_t` 是C标准库定义的"宽字符类型"，用于表示扩展字符集中的字符：

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void) {
    /* wchar_t 的定义：扩展字符集的整数类型 */
    /* 在Windows上通常占2字节(UTF-16)，Linux上通常占4字节(UTF-32) */
    printf("sizeof(wchar_t) = %zu\n", sizeof(wchar_t));

    /* 宽字符字面量：用 L 前缀 */
    wchar_t wc = L'中';
    wchar_t ws[] = L"你好世界";

    /* 宽字符的打印需要使用 wprintf */
    setlocale(LC_ALL, "");
    wprintf(L"宽字符: %lc\n", wc);
    wprintf(L"宽字符串: %ls\n", ws);

    return 0;
}
```

**宽字符I/O函数：**

| 窄字符函数      | 宽字符函数       | 功能     |
| ----------- | ----------- | ------ |
| `printf`    | `wprintf`   | 格式化输出  |
| `scanf`     | `wscanf`    | 格式化输入  |
| `fgets`     | `fgetws`    | 读取一行   |
| `fputs`     | `fputws`    | 输出字符串  |
| `puts`      | `fputws`    | 输出字符串  |
| `getchar`   | `getwchar`  | 读取一个字符 |
| `putchar`   | `putwchar`  | 输出一个字符 |

> ⚠️ **注意**：不要在同一个流上混用窄字符函数和宽字符函数，否则会导致未定义行为。

**宽字符操作函数（`<wchar.h>`）：**

| 窄字符函数        | 宽字符函数       | 功能    |
| ------------ | ----------- | ----- |
| `strlen`     | `wcslen`    | 字符串长度 |
| `strcpy`     | `wcscpy`    | 复制字符串 |
| `strncpy`    | `wcsncpy`   | 复制n个字符 |
| `strcat`     | `wcscat`    | 连接字符串 |
| `strncat`    | `wcsncat`   | 连接n个字符 |
| `strcmp`     | `wcscmp`    | 比较字符串 |
| `strncmp`    | `wcsncmp`   | 比较前n个字符 |
| `strchr`     | `wcschr`    | 查找字符  |
| `strrchr`    | `wcsrchr`   | 反向查找字符 |
| `strstr`     | `wcsstr`    | 查找子串  |
| `strtok`     | `wcstok`    | 分割字符串 |

**代码示例：用 wchar_t 处理中文**

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void) {
    /* 必须设置区域，否则宽字符输出可能乱码 */
    setlocale(LC_ALL, "");

    wchar_t name[] = L"张三";
    wchar_t greeting[50] = L"你好，";

    /* 宽字符串长度（字符数，不是字节数） */
    wprintf(L"名字长度: %zu 个字符\n", wcslen(name));

    /* 宽字符串连接 */
    wcscat(greeting, name);
    wcscat(greeting, L"！欢迎学习C语言。");
    wprintf(L"%ls\n", greeting);

    /* 宽字符串查找 */
    wchar_t *pos = wcschr(greeting, L'，');
    if (pos) {
        wprintf(L"找到逗号，位置: %ld\n", pos - greeting);
    }

    /* 宽字符串比较 */
    wchar_t a[] = L"苹果";
    wchar_t b[] = L"香蕉";
    int cmp = wcscmp(a, b);
    wprintf(L"比较结果: %d (%ls %s %ls)\n",
            cmp, a, cmp < 0 ? L"小于" : (cmp > 0 ? L"大于" : L"等于"), b);

    return 0;
}
```

### 3. setlocale 本地化

`setlocale` 用于设置程序的"区域"，影响字符编码、数字格式、货币符号等行为：

```c
#include <locale.h>

/* setlocale(分类, 区域字符串) */
/* 区域字符串：
   NULL     - 查询当前设置，不修改
   ""       - 使用系统默认区域
   "C"      - 最小化C语言默认区域（默认值）
   "zh_CN"  - 中文（简体）区域
   "en_US"  - 英文（美国）区域
*/
```

**区域分类：**

| 分类          | 影响范围           | 说明         |
| ----------- | -------------- | ---------- |
| `LC_ALL`    | 所有分类           | 一次性设置全部    |
| `LC_CTYPE`  | 字符分类和转换        | 影响宽字符/多字节转换 |
| `LC_NUMERIC` | 数字格式           | 小数点、千位分隔符  |
| `LC_TIME`   | 时间格式           | 日期和时间的显示格式 |
| `LC_COLLATE` | 字符串比较排序        | 影响strcoll  |
| `LC_MONETARY` | 货币格式           | 货币符号和格式    |

**代码示例：设置中文环境**

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void) {
    /* 默认"C"区域下，宽字符输出可能不正常 */
    wprintf(L"默认区域: %s\n", setlocale(LC_ALL, NULL));

    /* 设置为系统默认区域（中文系统即为中文环境） */
    char *loc = setlocale(LC_ALL, "");
    if (loc == NULL) {
        printf("设置区域失败！\n");
        return 1;
    }
    wprintf(L"当前区域: %s\n", loc);

    /* 现在可以正常输出中文 */
    wprintf(L"你好，世界！\n");

    /* 也可以只设置字符类型区域 */
    setlocale(LC_CTYPE, "zh_CN.UTF-8");

    /* LC_NUMERIC 影响数字格式 */
    setlocale(LC_NUMERIC, "");
    printf("数字格式: %.2f\n", 1234567.89);

    return 0;
}
```

> 💡 **关键提示**：在处理宽字符之前，必须先调用 `setlocale(LC_ALL, "")` 设置区域，否则宽字符的输入输出和编码转换可能无法正常工作。

### 4. 多字节字符与编码转换

C标准库提供了多字节字符（如UTF-8）与宽字符（`wchar_t`）之间的转换函数：

**单字符转换函数：**

| 函数          | 功能              | 备注   |
| ----------- | --------------- | ---- |
| `mblen`     | 获取多字节字符的字节数      | 简单版本 |
| `mbtowc`    | 多字节字符 → 宽字符      | 简单版本 |
| `wctomb`    | 宽字符 → 多字节字符      | 简单版本 |
| `mbrtowc`   | 多字节字符 → 宽字符      | 可重入版本 |
| `wcrtomb`   | 宽字符 → 多字节字符      | 可重入版本 |

**字符串转换函数：**

| 函数          | 功能              | 备注       |
| ----------- | --------------- | -------- |
| `mbstowcs`  | 多字节字符串 → 宽字符串    | 简单版本     |
| `wcstombs`  | 宽字符串 → 多字节字符串    | 简单版本     |
| `mbsrtowcs` | 多字节字符串 → 宽字符串    | 可重入版本    |
| `wcsrtombs` | 宽字符串 → 多字节字符串    | 可重入版本    |

**代码示例：UTF-8 字符串的字符遍历**

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <wchar.h>
#include <locale.h>

int main(void) {
    setlocale(LC_ALL, "");

    /* UTF-8编码的中文字符串 */
    const char *utf8_str = "你好ABC世界";

    /* 方法1：使用 mblen 逐字符遍历 */
    printf("方法1：使用 mblen 遍历\n");
    const char *p = utf8_str;
    int char_count = 0;
    while (*p != '\0') {
        int len = mblen(p, MB_CUR_MAX);
        if (len <= 0) {
            printf("编码错误！\n");
            break;
        }
        printf("  字符%d: %d字节 -> ", char_count, len);
        for (int i = 0; i < len; i++) {
            printf("%02X ", (unsigned char)p[i]);
        }
        printf("\n");
        p += len;
        char_count++;
    }
    printf("总字符数: %d，总字节数: %zu\n\n", char_count, strlen(utf8_str));

    /* 方法2：使用 mbtowc 转换为宽字符 */
    printf("方法2：使用 mbtowc 转换为宽字符\n");
    p = utf8_str;
    wchar_t wc;
    while (*p != '\0') {
        int len = mbtowc(&wc, p, MB_CUR_MAX);
        if (len <= 0) break;
        wprintf(L"  宽字符: %lc (Unicode: U+%04X, %d字节)\n", wc, (unsigned)wc, len);
        p += len;
    }

    /* 方法3：使用 mbstowcs 整串转换 */
    printf("\n方法3：使用 mbstowcs 整串转换\n");
    size_t wcs_len = mbstowcs(NULL, utf8_str, 0);
    wchar_t *wcs = (wchar_t *)malloc((wcs_len + 1) * sizeof(wchar_t));
    if (wcs) {
        mbstowcs(wcs, utf8_str, wcs_len + 1);
        wprintf(L"宽字符串: %ls\n", wcs);
        wprintf(L"宽字符串长度: %zu 个字符\n", wcslen(wcs));
        free(wcs);
    }

    return 0;
}
```

**可重入版本 mbrtowc / wcrtomb：**

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>
#include <string.h>

int main(void) {
    setlocale(LC_ALL, "");

    /* mbrtowc：可重入版本的多字节→宽字符转换 */
    const char *mb_str = "你好";
    const char *ptr = mb_str;
    size_t remaining = strlen(mb_str);
    mbstate_t state = {0};
    wchar_t wc;

    printf("使用 mbrtowc 逐字符转换：\n");
    while (remaining > 0) {
        size_t result = mbrtowc(&wc, ptr, remaining, &state);
        if (result == (size_t)-1 || result == (size_t)-2) {
            printf("编码错误！\n");
            break;
        }
        wprintf(L"  字符: %lc (U+%04X)\n", wc, (unsigned)wc);
        ptr += result;
        remaining -= result;
    }

    /* wcrtomb：可重入版本的宽字符→多字节转换 */
    printf("\n使用 wcrtomb 逐字符转换：\n");
    mbstate_t state2 = {0};
    char buffer[MB_CUR_MAX + 1];
    wchar_t wcs[] = {L'你', L'好', L'!', L'\0'};

    for (int i = 0; wcs[i] != L'\0'; i++) {
        size_t len = wcrtomb(buffer, wcs[i], &state2);
        if (len == (size_t)-1) {
            printf("转换错误！\n");
            continue;
        }
        buffer[len] = '\0';
        printf("  宽字符 %lc -> UTF-8: ", wcs[i]);
        for (size_t j = 0; j < len; j++) {
            printf("%02X ", (unsigned char)buffer[j]);
        }
        printf("(%zu字节)\n", len);
    }

    return 0;
}
```

> 💡 **简单版本 vs 可重入版本**：简单版本（`mbtowc`等）使用内部静态状态，不是线程安全的；可重入版本（`mbrtowc`等）通过 `mbstate_t` 参数传递状态，是线程安全的，推荐在多线程环境中使用。

### 5. UTF-8 实战技巧

**UTF-8 编码规则：**

UTF-8 是一种变长编码，根据 Unicode 码位范围使用1~4个字节：

| Unicode范围          | UTF-8字节序列                     | 字节数 | 说明    |
| ----------------- | ------------------------------ | --- | ----- |
| U+0000 ~ U+007F  | `0xxxxxxx`                     | 1   | 兼容ASCII |
| U+0080 ~ U+07FF  | `110xxxxx 10xxxxxx`            | 2   | 拉丁扩展等 |
| U+0800 ~ U+FFFF  | `1110xxxx 10xxxxxx 10xxxxxx`   | 3   | CJK汉字 |
| U+10000 ~ U+10FFFF | `11110xxx 10xxxxxx 10xxxxxx 10xxxxxx` | 4   | emoji等 |

**判断 UTF-8 字符的字节数：**

```c
#include <stdio.h>

/* 根据首字节判断UTF-8字符占用的字节数 */
int utf8_char_len(unsigned char first_byte) {
    if (first_byte < 0x80) {
        return 1;  /* 0xxxxxxx：ASCII字符 */
    } else if ((first_byte & 0xE0) == 0xC0) {
        return 2;  /* 110xxxxx：2字节字符 */
    } else if ((first_byte & 0xF0) == 0xE0) {
        return 3;  /* 1110xxxx：3字节字符（中文在此范围） */
    } else if ((first_byte & 0xF8) == 0xF0) {
        return 4;  /* 11110xxx：4字节字符（emoji等） */
    }
    return -1;     /* 非法的UTF-8首字节 */
}

int main(void) {
    const char *test = "A中🎉";
    printf("字符首字节分析：\n");
    for (int i = 0; test[i] != '\0'; ) {
        int len = utf8_char_len((unsigned char)test[i]);
        if (len < 1) {
            printf("  位置%d: 非法UTF-8字节\n", i);
            i++;
            continue;
        }
        printf("  位置%d: 首字节0x%02X, 占%d字节\n", i, (unsigned char)test[i], len);
        i += len;
    }
    return 0;
}
```

**UTF-8 字符串的字符数计算：**

```c
#include <stdio.h>
#include <string.h>

/* 计算UTF-8字符串的字符数（不是字节数） */
size_t utf8_strlen(const char *str) {
    size_t count = 0;
    while (*str != '\0') {
        unsigned char c = (unsigned char)*str;
        if (c < 0x80) {
            str += 1;  /* ASCII：1字节 */
        } else if ((c & 0xE0) == 0xC0) {
            str += 2;  /* 2字节字符 */
        } else if ((c & 0xF0) == 0xE0) {
            str += 3;  /* 3字节字符 */
        } else if ((c & 0xF8) == 0xF0) {
            str += 4;  /* 4字节字符 */
        } else {
            str += 1;  /* 非法字节，跳过 */
        }
        count++;
    }
    return count;
}

int main(void) {
    const char *str = "你好Hello世界🎉";
    printf("字符串: %s\n", str);
    printf("字节数: %zu (strlen)\n", strlen(str));
    printf("字符数: %zu (utf8_strlen)\n", utf8_strlen(str));
    return 0;
}
```

**UTF-8 字符串截取（按字符而非字节）：**

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

/* 获取UTF-8字符串中第n个字符的起始位置 */
const char *utf8_char_at(const char *str, size_t index) {
    size_t count = 0;
    while (*str != '\0' && count < index) {
        unsigned char c = (unsigned char)*str;
        if (c < 0x80) {
            str += 1;
        } else if ((c & 0xE0) == 0xC0) {
            str += 2;
        } else if ((c & 0xF0) == 0xE0) {
            str += 3;
        } else if ((c & 0xF8) == 0xF0) {
            str += 4;
        } else {
            str += 1;
        }
        count++;
    }
    return str;
}

/* 按字符数截取UTF-8字符串（左闭右开区间） */
char *utf8_substr(const char *str, size_t start, size_t char_count) {
    const char *begin = utf8_char_at(str, start);
    const char *end = utf8_char_at(begin, char_count);
    size_t byte_len = end - begin;

    char *result = (char *)malloc(byte_len + 1);
    if (result == NULL) return NULL;

    memcpy(result, begin, byte_len);
    result[byte_len] = '\0';
    return result;
}

int main(void) {
    const char *str = "你好Hello世界🎉";

    /* 截取前3个字符 */
    char *sub1 = utf8_substr(str, 0, 3);
    printf("前3个字符: %s\n", sub1);
    free(sub1);

    /* 截取第4~6个字符 */
    char *sub2 = utf8_substr(str, 3, 3);
    printf("第4~6个字符: %s\n", sub2);
    free(sub2);

    /* 截取最后3个字符 */
    size_t total = 0;
    const char *p = str;
    while (*p) {
        unsigned char c = (unsigned char)*p;
        if (c < 0x80) p += 1;
        else if ((c & 0xE0) == 0xC0) p += 2;
        else if ((c & 0xF0) == 0xE0) p += 3;
        else if ((c & 0xF8) == 0xF0) p += 4;
        else p += 1;
        total++;
    }
    char *sub3 = utf8_substr(str, total - 3, 3);
    printf("最后3个字符: %s\n", sub3);
    free(sub3);

    return 0;
}
```

> ⚠️ **重要提醒**：上述 UTF-8 处理代码假设输入是合法的 UTF-8 编码。在生产环境中，应增加对后续字节（必须为 `10xxxxxx`）的校验，以防止畸形编码导致的安全问题。
