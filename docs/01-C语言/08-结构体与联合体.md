## 本章导读

结构体和联合体是C语言中用于组织复杂数据的复合类型。结构体可以将多个不同类型的变量组合成一个整体，而联合体则允许多个变量共享同一块内存。本章将详细介绍这两种数据类型的定义、使用方法以及实际应用场景。

### 1. 🌟 通俗解释 - 什么是结构体？

> 💡 **生活中的比喻：结构体就像"简历"**

想象一下你要记录一个人的信息：

- 姓名：张三
- 年龄：25岁
- 身高：175cm
- 工作：程序员

在编程中，这些信息类型不同（字符串、数字、小数），怎么放在一起？

**结构体就是来解决这个问题的！** 就像一份"简历"，把不同类型的信息整合在一起：

```
struct Person {           // 就像"简历"这个表格
    char name[50];        // 姓名栏（最多50个字符）
    int age;              // 年龄栏（整数）
    float height;         // 身高栏（小数）
};                        // 这就是"简历模板"

struct Person p1;         // 创建一份具体简历
strcpy(p1.name, "张三");  // 填写姓名
p1.age = 25;             // 填写年龄
p1.height = 175.5;       // 填写身高
```

**那联合体又是什么？**

> 💡 **联合体就像"多功能房"**

想象一个房间：

- 白天它是"办公室"
- 晚上它是"卧室"
- 你只能同时用它做一件事，不能同时是办公室和卧室

联合体就是这样：多个变量"共享"同一块内存，一次只能存一个值。

***

### 2. 概念与定义

**结构体（structure）**：将多个不同类型的变量组合成一个自定义数据类型，每个成员占用独立的内存空间。

**联合体（union）**：多个成员共享同一块内存空间，同一时刻只能存储一个成员的值。

**枚举（enumeration）**：定义一组命名的整数常量，提高代码可读性。

## 1. 结构体基础

### 1. typedef 最佳实践

typedef 可以简化结构体的使用，但有几种风格需要注意：

```c
#include <stdio.h>
#include <string.h>

/* 风格1：先定义 struct，再单独 typedef（推荐用于自引用结构体） */
struct Person1 {
    char name[50];
    int age;
};
typedef struct Person1 Person1;

/* 风格2：匿名 struct 直接 typedef（最简洁，推荐） */
typedef struct {
    char name[50];
    int age;
} Person2;

/* 风格3：自引用结构体必须用风格1 */
typedef struct Node {
    int data;
    struct Node *next;  /* 注意：这里必须写完整的 struct Node */
} Node;

/* 常见错误：自引用用匿名 struct */
typedef struct {          /* 错误！无法在内部引用自己 */
    int data;
    ??? *next;           /* 不知道类型名怎么写 */
} BadNode;
```

**三种风格对比：**

| 风格  | 写法                          | 优点    | 缺点    |
| --- | --------------------------- | ----- | ----- |
| 风格1 | 先 `struct X`，再 `typedef`    | 自引用可用 | 稍繁琐   |
| 风格2 | 匿名 `struct` + `typedef`     | 简洁    | 不能自引用 |
| 风格3 | 同时定义 `struct X` 和 `typedef` | 清晰    | 稍繁琐   |

**什么时候用哪种？**

```c
/* 简单结构体：用风格2 */
typedef struct {
    int x;
    int y;
} Point;

/* 链表/树节点：用风格1 */
typedef struct ListNode {
    int data;
    struct ListNode *next;
} ListNode;

/* 需要前向声明时：用风格3 */
typedef struct ComplexType ComplexType;
struct ComplexType {
    int x;
    ComplexType *ref;  /* 可以引用自己 */
};
```

### 2. 结构体的定义

```c
#include <stdio.h>
#include <string.h>

/* 方式1：先定义结构体类型，再声明变量 */
struct Person {
    char name[50];
    int age;
    float height;
};

/* 方式2：使用typedef简化类型名 */
typedef struct {
    int x;
    int y;
} Point;

/* 方式3：定义类型的同时声明变量 */
struct {
    int id;
    char title[100];
} article1, article0;

int main(void) {
    /* 使用struct定义的结构体 */
    struct Person p1;
    strcpy(p1.name, "Alice");
    p1.age = 25;
    p1.height = 1.75f;
    
    /* 初始化列表 */
    struct Person p0 = {"Bob", 30, 1.80f};
    
    /* 指定成员初始化（C99） */
    struct Person p2 = {
        .name = "Charlie",
        .age = 35
        /* height自动初始化为0 */
    };
    
    /* 使用typedef定义的结构体 */
    Point p3 = {10, 20};
    
    printf("Name: %s, Age: %d, Height: %.1f\n", p1.name, p1.age, p1.height);
    printf("Name: %s, Age: %d, Height: %.1f\n", p0.name, p0.age, p0.height);
    printf("Point: (%d, %d)\n", p3.x, p3.y);
    
    return 0;
}
```

### 3. 结构体内存布局

```C
struct Person {
    char name[50];    /* 50字节 */
    int age;          /* 4字节 */
    float height;     /* 4字节 */
};

内存布局（假设无对齐填充）：
┌────────────────────────────────────────────────────┐
│ name[0] ... name[49] │ age │ height │
│      50 bytes        │ 4B  │  4B    │
└────────────────────────────────────────────────────┘
总大小: 50 + 4 + 4 = 58 字节

实际大小（考虑内存对齐）：
┌────────────────────────────────────────────────────────┐
│ name[0] ... name[49] │ padding │ age │ height │
│      50 bytes        │  2字节   │ 4B  │  4B    │
└────────────────────────────────────────────────────────┘
sizeof(struct Person) 可能是 60 或 56 字节
```

### 4. 指定初始化器进阶用法

C99 的指定初始化器除了基本用法外，还有一些高级技巧：

```c
#include <stdio.h>

typedef struct {
    int x;
    int y;
    int z;
} Point;

int main(void) {
    /* 基本指定初始化 */
    Point p1 = {.x = 10, .z = 20};  /* y 自动初始化为 0 */
    printf("p1: x=%d, y=%d, z=%d\n", p1.x, p1.y, p1.z);

    /* 数组风格索引（C99） */
    int arr[10] = {[0] = 1, [5] = 5, [1] = 1};
    printf("arr[0]=%d, arr[5]=%d, arr[1]=%d\n", arr[0], arr[5], arr[1]);
    /* 其他元素自动初始化为 0 */

    /* 范围初始化（GNU扩展语法，非标准C99） */
    int brr[100] = {[0 ... 1] = 1, [10 ... 13] = 0};
    printf("brr[0]=%d, brr[5]=%d, brr[50]=%d\n", brr[0], brr[5], brr[50]);
    /* 范围初始化：索引 0-1 是 1，10-13 是 0，其余是 0 */

    /* 嵌套结构体指定初始化 */
    typedef struct {
        Point start;
        Point end;
    } Line;

    Line line = {
        .start = {.x = 0, .y = 0},
        .end = {.x = 100, .y = 50}
    };
    printf("Line: (%d,%d) -> (%d,%d)\n",
           line.start.x, line.start.y, line.end.x, line.end.y);

    /* 部分初始化，其余自动为 0 */
    Point p0 = {.x = 5};  /* y=0, z=0 */
    printf("p0: x=%d, y=%d, z=%d\n", p0.x, p0.y, p0.z);

    return 0;
}
```

**指定初始化器的优点：**

| 特性      | 说明                                     |
| ------- | -------------------------------------- |
| 初始化顺序无关 | `.x = 1, .y = 0` 和 `.y = 0, .x = 1` 等价 |
| 可跳过某些成员 | 未指定的成员自动初始化为 0                         |
| 可读性好    | 明确指定每个成员的初始值                           |
| 可维护性好   | 添加新成员时不易引入 bug                         |

**与数组结合的技巧：**

```c
#include <stdio.h>

/* 初始化结构体数组 */
typedef struct {
    const char *name;
    int score;
} Player;

Player players[] = {
    [0] = {.name = "Alice", .score = 100},
    [1] = {.name = "Bob", .score = 200},  /* 跳过 2-3 */
    /* 数组中间可以有空洞，未初始化的元素为 {NULL, 0} */
};

int main(void) {
    printf("players[0]: %s, %d\n", players[0].name, players[0].score);
    printf("players[1]: %s, %d\n", players[1].name, players[1].score);
    printf("Array size: %zu\n", sizeof(players) / sizeof(players[0]));
    return 0;
}
```

**注意事项：**

**1. 指定初始化器 和 普通初始化器 不能混用（除末尾）**

```c
/* ❌ 错误：普通 + 指定 + 普通 → 编译失败 */
Player players[] = {
    {"Alice", 100},      /* 普通初始化 */
    [1] = {"Bob", 200},  /* 指定初始化（中间插入） */
    {"Charlie", 10}      /* 又普通 → 报错 */
};

/* ✅ 正确1：全部用指定初始化 */
Player players1[] = {
    [0] = {.name = "Alice", .score = 100},
    [1] = {.name = "Bob", .score = 200},
};

/* ✅ 正确2：普通初始化只能放在最后 */
Player players0[] = {
    [0] = {.name = "Alice", .score = 100},
    [1] = {.name = "Bob", .score = 200},
    {"Charlie", 10}  /* 放最后 → 合法 */
};
```

### 5. 数组范围初始化 `[0 ... 11]` 必须加空格（GNU 扩展）

```c
/* ❌ 错误：没空格 → 语法错误 */
int arr1[10] = {[0...3] = 1};  /* 错误！语法解析失败 */

/* ✅ 正确：... 左右必须加空格 */
int arr0[10] = {[0 ... 3] = 1};  /* 正确：批量初始化 0~3 */
```

### 6. 指定的索引 不能超过数组大小

```c
/* ❌ 错误：索引越界 */
int arr[3];        /* 数组大小=3，索引只能是 0、1、2 */
arr[5] = 100;      /* 错误！5 ≥ 3，越界 */

/* ✅ 正确：索引 ≤ 数组长度-1 */
int arr0[6];       /* 大小=6，索引 0~5 */
arr0[5] = 100;    /* 合法 */
```

### 7. 自引用结构体（链表）不能直接用指定初始化器

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;

/* ❌ 错误：直接自引用初始化（编译失败） */
Node n = {
    .data = 10,
    .next = &n  /* 错误：编译期无法确定地址 */
};

/* ✅ 正确：分步赋值（先定义、后赋值） */
Node n;
n.data = 10;
n.next = &n;   /* 正确：运行时取地址 */
```

### 5 总结

1. **不能混用初始化**：普通与指定只能二选一，或普通放最后。
2. **范围初始化必须空格**：`[0 ... 3]` 是 GNU 扩展，无空格报错。
3. **索引不能越界**：指定索引必须 < 数组大小。
4. **自引用结构体**：不能直接用 `.next = &n` 初始化，必须分步赋值。

### 9. 结构体赋值与比较

结构体的赋值和比较与普通变量不同，需要特别注意：

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[50];
    int age;
    float score;
} Student;

/* 结构体可以直接赋值（浅拷贝） */
void test_assignment(void) {
    Student s1 = {"Alice", 20, 85.5f};
    Student s0;

    /* 赋值：复制所有成员 */
    s0 = s1;
    printf("After assignment: s0.name = %s\n", s0.name);

    /* 修改 s1 不会影响 s0（因为是值拷贝） */
    s1.age = 30;
    printf("s1.age = %d, s0.age = %d\n", s1.age, s0.age);
}

/* 结构体不能用 == 比较，需要用 memcmp */
void test_comparison(void) {
    Student s1 = {"Alice", 20, 85.5f};
    Student s0 = {"Alice", 20, 85.5f};

    /* 错误：不能使用 == 比较结构体 */
    /* if (s1 == s0) { ... } */  /* 编译错误！ */

    /* 正确方式：使用 memcmp */
    if (memcmp(&s1, &s0, sizeof(Student)) == 0) {
        printf("s1 and s0 are equal\n");
    } else {
        printf("s1 and s0 are different\n");
    }
}

/* memcmp 比较的陷阱：内存对齐填充可能导致误判 */
void test_comparison_pitfall(void) {
    typedef struct {
        char a;      /* 1字节 */
        int b;       /* 4字节 */
    } Example;

    Example e1 = {.a = 1, .b = 0};
    Example e0 = {.a = 1, .b = 0};

    /* e1 和 e0 的有效数据相同，但内存布局可能不同：
     * e1: [1][padding][0][0][0][0][0]
     * e0: [1][padding][0][0][0][0][0]
     * 如果 padding 区域有随机数据，memcmp 可能失败
     */

    /* 正确做法：逐个成员比较 */
    if (e1.a == e0.a && e1.b == e0.b) {
        printf("e1 and e0 are equal\n");
    }
}

int main(void) {
    test_assignment();
    test_comparison();
    test_comparison_pitfall();

    return 0;
}
```

**赋值 vs 比较：**

| 操作   | 方法                                   | 说明          |
| ---- | ------------------------------------ | ----------- |
| 赋值   | `s0 = s1`                            | 直接赋值，复制所有成员 |
| 比较   | `memcmp(&s1, &s0, sizeof(...)) == 0` | 内存比较        |
| 安全比较 | 逐个成员比较                               | 避免对齐填充导致的问题 |

**什么时候不能用 memcmp 比较结构体？**

`memcmp` 是**逐字节二进制逐位比对**，只看内存原始比特，不关心业务语义、成员类型、内存布局。以下四种场景**绝对不能用**：

### 10. 结构体包含浮点数

**核心原因**：浮点存在 **NaN、正负0、精度误差**：

- `NaN != NaN`，但二进制比特可能相同/不同，逻辑相等≠内存相等；
- `+0.0` 与 `-0.0` 数值相等，但二进制位不同，`memcmp` 判不等。

```c
#include <stdio.h>
#include <math.h>
#include <string.h>

typedef struct {
    double val;
} S;

int main(void) {
    S a = {.val = NAN};
    S b = {.val = NAN};
    /* 逻辑上都为非法NaN，但memcmp结果不可控，业务判断完全错误 */
    printf("memcmp result: %d\n", memcmp(&a, &b, sizeof(S)));  /* 结果不可预测 */

    S c = {.val = 0.0};
    S d = {.val = -0.0};
    /* 数值相等(+0.0 == -0.0)，但二进制位不同 */
    printf("0.0 == -0.0: %d, memcmp: %d\n", c.val == d.val, memcmp(&c, &d, sizeof(S)));

    return 0;
}
```

### 11. 结构体包含指针成员

**核心原因**：`memcmp` 比较**指针地址值**，不是指针指向的**堆/栈内存内容**。

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    int *ptr;
} S;

int main(void) {
    int x = 10, y = 10;
    S a = {.ptr = &x};
    S b = {.ptr = &y};
    /* 指向内容都是10，业务相等；但地址不同，memcmp 判定不相等 */
    printf("memcmp result: %d\n", memcmp(&a, &b, sizeof(S)));  /* 不相等！ */

    /* 正确做法：解引用比较内容 */
    printf("content equal: %d\n", *(a.ptr) == *(b.ptr));  /* 相等 */
    return 0;
}
```

### 12. 结构体存在内存对齐填充（最常见坑）

**核心原因**：编译器为 CPU 对齐，会在成员之间/末尾**插入填充字节（padding）**，填充字节是**随机脏数据**。

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char c;   /* 1字节 */
    /* 编译器自动填充 3 字节对齐空洞（随机垃圾值） */
    int num;  /* 4字节 */
} S;

int main(void) {
    S s1 = {.c = 'A', .num = 42};
    S s0 = {.c = 'A', .num = 42};
    /* 所有成员值完全相同，但填充字节残留脏数据，memcmp 大概率不相等 */
    printf("memcmp result: %d\n", memcmp(&s1, &s0, sizeof(S)));

    /* 正确做法：逐个成员比较 */
    printf("member equal: %d\n", s1.c == s0.c && s1.num == s0.num);
    return 0;
}
```

### 13. 结构体内含定长 `char[]` 字符串、无 `\0` 终止

**核心原因**：业务只关心有效字符；但 `memcmp` 会**比对数组全部字节**。

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char buf[10];
} S;

int main(void) {
    S a = {.buf = "hello"};
    S b = {.buf = "hello"};
    /* 仅前5字节有效，后面5字节无'\0'、是随机脏值 */
    printf("memcmp result: %d\n", memcmp(&a, &b, sizeof(S)));

    /* 正确做法：用 strcmp 比较字符串 */
    printf("strcmp result: %d\n", strcmp(a.buf, b.buf));  /* 相等 */
    return 0;
}
```

### 14. 正确做法

不要直接 `memcmp` 整个结构体，**逐成员手动比较**：

- 整数：直接 `==`
- 浮点：用误差范围比较 `fabs(a-b) < 1e-6`
- 指针：解引用比较指向内容
- 定长数组：只比较有效长度

### 15. 唯一安全能用 memcmp 的结构体

**无填充、无指针、无浮点、无变长字符数组**的纯整数聚合体。

### 16. 安全的结构体比较函数

```c
#include <stdio.h>
#include <string.h>
#include <math.h>

typedef struct {
    char name[50];
    int age;
    double score;
} Person;

/* 安全的结构体比较函数 */
int compare_person(const Person *p1, const Person *p0) {
    /* 整数直接比较 */
    if (p1->age != p0->age) {
        return p1->age - p0->age;
    }
    /* 浮点用误差范围 */
    if (fabs(p1->score - p0->score) > 1e-6) {
        return p1->score > p0->score ? 1 : -1;
    }
    /* 字符串用 strcmp */
    return strcmp(p1->name, p0->name);
}

int main(void) {
    Person p1 = {"Alice", 30, 85.5};
    Person p0 = {"Alice", 30, 85.5};
    Person p2 = {"Bob", 25, 90.0};

    printf("p1 vs p0: %d\n", compare_person(&p1, &p0));  /* 0 相等 */
    printf("p1 vs p2: %d\n", compare_person(&p1, &p2)); /* 正数 */

    return 0;
}
```

### 17. 极简背诵版

### 3. 结构体与文件 I/O

结构体可以方便地序列化到文件和从文件读取：

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[50];
    int age;
    float score;
} Student;

/* 写入结构体到文件 */
void write_student(const char *filename, const Student *s) {
    FILE *f = fopen(filename, "wb");
    if (f == NULL) {
        printf("Failed to open file for writing: %s\n", filename);
        return;

    size_t written = fwrite(s, sizeof(Student), 1, f);

        printf("Failed to write student data\n");

void read_student(const char *filename, Student *s) {
    FILE *f = fopen(filename, "rb");
    if (f == NULL) {
        printf("Failed to open file for reading: %s\n", filename);
        return;
    }

    /* fread：从文件读取结构体 */
    size_t read = fread(s, sizeof(Student), 1, f);
    if (read != 1) {
        printf("Failed to read student data\n");
    }

    fclose(f);
}

int main(void) {
    Student s1 = {"Alice", 20, 85.5f};

    /* 写入文件 */
    write_student("student.dat", &s1);

    /* 从文件读取 */
    Student s0;
```

**批量写入/读取结构体数组：**

```c
#include <stdio.h>

typedef struct {
    int id;
    char name[50];
    float score;
} Record;

/* 写入多个结构体 */
void write_records(const char *filename, Record *records, int count) {
    FILE *f = fopen(filename, "wb");
    if (f == NULL) {
        return;
    }

    /* 写入记录数量 */
    fwrite(&count, sizeof(int), 1, f);

    /* 批量写入所有记录 */
    fwrite(records, sizeof(Record), count, f);

    fclose(f);
}

/* 读取多个结构体 */
int read_records(const char *filename, Record **records) {
    FILE *f = fopen(filename, "rb");
    if (f == NULL) {
        return -1;
    }

    /* 读取记录数量 */
    int count;
    fread(&count, sizeof(int), 1, f);

    /* 分配内存并读取记录 */
    *records = malloc(sizeof(Record) * count);
    fread(*records, sizeof(Record), count, f);

    fclose(f);
    return count;
}

int main(void) {
    Record records[] = {
        {1, "Alice", 85.5f},
        {2, "Bob", 90.0f},
        {3, "Charlie", 78.5f}
    };

    /* 写入文件 */
    write_records("records.dat", records, 3);

    /* 读取文件 */
    Record *loaded;
    int count = read_records("records.dat", &loaded);

    printf("Loaded %d records:\n", count);
    for (int i = 0; i < count; i++) {
        printf("  %d: %s - %.1f\n",
               loaded[i].id, loaded[i].name, loaded[i].score);
    }

    free(loaded);
    return 0;
}
```

**二进制文件 vs 文本文件：**

| 特性   | 二进制文件    | 文本文件     |
| ---- | -------- | -------- |
| 读写速度 | 快        | 慢        |
| 文件大小 | 小（无格式开销） | 大（文本转换）  |
| 可读性  | 不可直接查看   | 可直接查看    |
| 跨平台  | 需要考虑字节序  | 自动转换     |
| 适用场景 | 结构体、大量数据 | 字符串、简单数据 |

**注意事项：**

1. 写入和读取时使用 `"wb"` 和 `"rb"` 模式（二进制）
2. 结构体内存对齐可能导致文件格式在不同平台不兼容
3. 跨平台交换数据时应使用紧凑结构体（`#pragma pack`）
4. 网络传输时需考虑字节序（大端/小端）

```c
#include <stdio.h>
```

```c
/* 链表节点 */
typedef struct Node {
    int data;
    struct Node *next;    /* 指向自身类型的指针 */
} Node;

/* 创建新节点 */
Node* create_node(int data) {
    Node *node = (Node*)malloc(sizeof(Node));
    if (node != NULL) {
        node->data = data;
        node->next = NULL;
    }
    return node;
}

/* 打印链表 */
void print_list(Node *head) {
    Node *current = head;
    while (current != NULL) {
        printf("%d -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

/* 释放链表 */
void free_list(Node *head) {
    Node *current = head;
    while (current != NULL) {
        Node *next = current->next;
        free(current);
        current = next;
    }
}

int main(void) {
    /* 创建链表: 1 -> 2 -> 3 -> NULL */
    Node *head = create_node(1);
    head->next = create_node(2);
    head->next->next = create_node(3);

    print_list(head);
    free_list(head);

    return 0;
}
```

### 3. 柔性数组成员

柔性数组成员（Flexible Array Member，FAM）是 C99 引入的重要特性，允许结构体的最后一个成员是一个未知大小的数组。

**标准写法：**

```c
struct Buffer {
    int size;
    char data[];   /* 柔性数组，无长度，必须放最后 */
};
```

**为什么需要柔性数组？**

| 传统方式                  | 柔性数组方式           |
| --------------------- | ---------------- |
| `char data[1]` + 超量分配 | 直接 `char data[]` |
| 访问需要偏移计算              | 访问如同普通数组成员       |
| 内存布局不直观               | 更清晰直观            |

### 4. 优点1：内存连续，只有一次 malloc

```c
/* 指针版本：需要两次内存分配 */
struct BufPtr {
    int size;
    char *data;  /* 单独指针需要单独分配 */
};
/* 使用：
struct BufPtr *p = malloc(sizeof(struct BufPtr));  // 第一次
p->data = malloc(100);  // 第二次
free(p->data);  // 需要两次释放
free(p);
*/

/* 柔性数组：一次 malloc 直接申请 */
struct Buffer {
    int size;
    char data[];
};
/* 使用：
struct Buffer *p = malloc(sizeof(struct Buffer) + 100);
free(p);  // 只需一次释放
*/
```

**指针版缺点：**

- 需要 **两次内存分配**
- 内存碎片化、两块内存不连续

**柔性数组优点：**

- 一次 malloc 直接申请「结构体头 + 后面变长数组」
- 整块内存连续，干净高效

### 5. 优点2：内存释放简单，只需要一次 free

- 指针版：必须先 `free(ptr->data)`，再 `free(ptr)`，漏释放 → 内存泄漏
- 柔性数组：**直接 free 整个结构体指针就行**，无需单独释放数组，极简不易漏

### 6. 优点3：节省内存、无额外指针开销

```C
柔性结构体大小：仅 sizeof(int) 字节（char[] 不占结构体大小）
指针结构体大小：sizeof(int) + sizeof(char*) 字节（指针要占 4/8 字节）
```

### 7. 优点4：缓存友好、CPU 读取更快

- 内存**连续排布**
- CPU 缓存命中率高
- 遍历数据时寻址更快
- 网络协议、内核、数据包、自定义协议头大量使用

### 8. 优点5：序列化/网络收发极其方便

整块连续内存，直接：

- 二进制发包 `send()`
- 本地写入文件 `write()`
- 不需要逐个拷贝、不需要处理二级指针

### 9. 缺点 & 限制

1. 必须是结构体**最后一个成员**
2. C99 专属，标准 C++ 不支持
3. 不能定义数组大小 `char[0]` 是编译器扩展，标准只允许 `char[]`

### 10. 实际应用场景

```c

    printf("Type: %d, Length: %d, Content: %s\n",

int main(void) {
```

## 5. 联合体

### 1. 联合体基础

```c
#include <stdio.h>

/* 联合体：所有成员共享同一块内存 */
union Data {
    int i;
    float f;
    char str[20];
};

int main(void) {
    union Data data;
    
    printf("Size of union: %zu\n", sizeof(data));  /* 20字节（最大成员） */
    
    /* 存储整数 */
    data.i = 10;
    printf("data.i = %d\n", data.i);
    
    /* 存储浮点数（覆盖之前的值） */
    data.f = 3.14f;
    printf("data.f = %f\n", data.f);
    printf("data.i = %d (now garbage)\n", data.i);  /* 值已被覆盖 */
    
    /* 存储字符串 */
    strcpy(data.str, "Hello");
    printf("data.str = %s\n", data.str);
    
    return 0;
}
```

### 2. 联合体内存布局

```
union Data {

├────────┤        │                     │

sizeof(union Data) = 20（最大成员大小）
```

### 4. 匿名结构体与联合体

**匿名联合体（Anonymous Union）** 是 C11 和 C++11 均支持的标准特性；**匿名结构体（Anonymous Struct）** 是 C11 标准特性，C++ 中需要编译器扩展支持。它们在组织数据和优化内存布局方面非常有用。

#### 1. 匿名结构体

**作用：**
- 在联合体中组织相关字段，提高代码可读性
- 嵌入结构体中，避免创建单独的类型名称，减少命名空间污染
- 成员可直接通过外层变量访问，无需中间层级

```c
#include <stdio.h>

typedef struct {
    struct {  // 匿名结构体
        float x;
        float y;
    };
    float z;
} Point3D;

void example_anonymous_struct() {
    Point3D p;
    p.x = 1.0f;  // 直接访问，无需 p.coord.x
    p.y = 0.0f;
    p.z = 2.0f;
    printf("Point: (%.1f, %.1f, %.1f)\n", p.x, p.y, p.z);
}
```

#### 2. 匿名联合体

**作用：**
- 内存共享：所有成员共享同一块内存空间，节省内存
- 类型转换：允许同一数据以不同类型访问
- 在结构体中共享内存，优化内存布局

```c
#include <stdio.h>

typedef struct {
    int type;
    union {  // 匿名联合体
        int i;
        float f;
        char str[20];
    };
} Variant;

void example_anonymous_union() {
    Variant v;
    
    v.type = 0;
    v.i = 42;
    printf("Int value: %d\n", v.i);
    
    v.type = 1;
    v.f = 3.14f;
    printf("Float value: %.2f\n", v.f);
}
```

#### 3. 组合使用示例

```c
#include <stdio.h>

typedef union {
    struct {  // 匿名结构体
        uint16_t lo;
        uint16_t hi;
    };
    uint32_t value;  // 与匿名结构体共享内存
} Word32;

void example_combined() {
    Word32 w;
    w.value = 0x12345678;
    printf("Value: 0x%08X\n", w.value);
    printf("Low: 0x%04X, High: 0x%04X\n", w.lo, w.hi);
}
```

#### 4. 注意事项

| 注意事项 | 说明 |
|---------|------|
| **内存重叠风险** | 匿名联合体的成员共享内存，修改一个成员会影响其他成员 |
| **类型安全** | 需要确保访问的成员与当前存储的类型匹配，建议配合类型标记使用 |
| **编译器兼容性** | 匿名联合体：C11 和 C++11 均支持；匿名结构体：C11 支持，C++ 需编译器扩展 |
| **初始化限制** | 匿名联合体不能有用户定义的构造函数或析构函数 |
| **无独立地址** | 匿名结构体/联合体本身没有独立名称，不能单独定义变量 |

#### 5. 典型应用场景

| 场景 | 说明 |
|-----|------|
| **硬件寄存器映射** | 将寄存器位域分组，方便访问不同位段 |
| **变体类型** | 存储不同类型的值，配合类型标记使用 |
| **内存优化** | 共享内存空间，减少内存占用 |
| **协议解析** | 不同协议格式的复用，同一数据的多种解读方式 |

```c
enum Permission {
    PERM_READ    = 1 << 0,  /* 1 */
    PERM_WRITE   = 1 << 1,  /* 2 */
    PERM_EXECUTE = 1 << 2,  /* 4 */
    PERM_DELETE  = 1 << 3   /* 8 */
};

int main(void) {
    enum Weekday today = WEDNESDAY;
    printf("Today is day %d\n", today);  /* 3 */
    
    /* 枚举可以比较 */
    if (today == WEDNESDAY) {
        printf("It's Wednesday!\n");
    }
    
    /* 位标志组合 */
    int my_permissions = PERM_READ | PERM_WRITE;
    
    if (my_permissions & PERM_READ) {
        printf("Has read permission\n");
    }
    if (my_permissions & PERM_EXECUTE) {
        printf("Has execute permission\n");
    } else {
        printf("No execute permission\n");
    }
    
    return 0;
}
```

### 2. 枚举与字符串转换

```c
#include <stdio.h>

enum Color { RED, GREEN, BLUE };

/* 枚举值转字符串 */
const char* color_to_string(enum Color c) {
    static const char* names[] = {"Red", "Green", "Blue"};
    return names[c];
}

/* 字符串转枚举值 */
enum Color string_to_color(const char* str) {
    if (strcmp(str, "Red") == 0) return RED;
    if (strcmp(str, "Green") == 0) return GREEN;
    if (strcmp(str, "Blue") == 0) return BLUE;
    return -1;  /* 无效值 */
}

int main(void) {
    enum Color c = GREEN;
    printf("Color: %s\n", color_to_string(c));
    
    return 0;
}
```

## 7. 位域

### 1. 位域基础

```c
#include <stdio.h>

/* 位域：精确控制成员占用的位数 */
struct Flags {
    unsigned int is_read    : 1;  /* 1位 */
    unsigned int is_write   : 1;  /* 1位 */
    unsigned int is_execute : 1;  /* 1位 */
    unsigned int priority   : 2;  /* 2位（0-3） */
    unsigned int reserved   : 0;  /* 0位保留 */
};

int main(void) {
    struct Flags f = {0};
    
    f.is_read = 1;
    f.is_write = 1;
    f.priority = 5;
    
    printf("Size of Flags: %zu bytes\n", sizeof(f));
    printf("Read: %u, Write: %u, Execute: %u\n", 
           f.is_read, f.is_write, f.is_execute);
    printf("Priority: %u\n", f.priority);
    
    return 0;
}
```

**位域 sizeof 计算规则**

**位域的 sizeof 到底怎么算？**

**核心规则：**

1. **位域必须装进「基类型」的盒子里**
   - 你写 `unsigned int` → 盒子 = **4 字节（32位）**
   - 你写 `unsigned char` → 盒子 = **1 字节（8位）**
2. **装不下就新开一个盒子**
   最终大小 = **用了多少个盒子 × 盒子大小**

**直观例子：**

```c
// 例1：全部装进 1 个盒子
struct Test1 {
    unsigned int a : 0;   // 用 0 位
    unsigned int b : 2;   // 用 2 位
    unsigned int c : 1;   // 用 1 位
};                        // 总共 3 位 << 32 位 → 只用 1 个盒子
// sizeof = 4 字节

// 例2：装不下，开第二个盒子
struct Test2 {
    unsigned int a : 20;  // 用 20 位
    unsigned int b : 20;  // 再用 20 位 → 装不下！
};                        // 第一个盒子剩 12 位，不够放第二个 20 位 → 新开盒子
// sizeof = 4 + 4 = 8 字节

// 例3：换成 char 盒子（1字节）
struct Test3 {
    unsigned char a : 3;
    unsigned char b : 4;
};                        // 总共 7 位 ≤ 8 位 → 1 个 char 盒子
// sizeof = 1 字节
```

**最关键的一句话：**

> **sizeof(位域结构体) = 用了多少个「基类型存储单元」× 基类型大小**

- `unsigned int` → 单元 = 4 字节
- `unsigned char` → 单元 = 1 字节
- `unsigned short` → 单元 = 2 字节

**不是把位加起来除以8！不是把位加起来除以8！不是把位加起来除以8！**

**口诀：**

> 看基类型，定盒子大小
> 往里装位，装不下就新开盒子
> 最终大小 = 盒子数 × 盒子大小

**补充1：不同基类型的位域，强制切新单元**

```c
struct S {
    unsigned char a : 3;   // 1字节单元
    unsigned int  b : 3;   // 类型变了，直接新开 4字节单元
};
// sizeof = 1 + 4 = 5 字节（不会挤在一起！）
```

**补充2：位域整体还要遵循结构体内存对齐**

就算位域打包完只占 5bit，如果结构体整体对齐是 4 字节，依然会填充对齐，`sizeof` 向上取整。

**极简最终背诵版：**

1. 同类型位域共用一个基类型存储单元，装不下就新建；
2. 单元大小由**位域基类型**决定，`sizeof` 按单元个数计算；
3. `unsigned` 只控正负与数值范围，不改变内存布局；
4. 不同基类型位域不混装，结构体整体还要对齐填充。

**位域使用规则:**

**C 语言中，位域（bit-field）只能定义在** **`struct`** **/** **`union`** **内部，不能单独定义普通位域变量、不能放数组、不能当独立类型。**

***

## 1. 合法写法（仅结构体/联合体内部）

```c
// 结构体位域 ✅
struct Info {
    unsigned int flag1 : 1;
    unsigned int flag0 : 2;
    unsigned int type  : 3;
};

// 联合体位域 ✅
union Data {
    unsigned int val;
    struct {
        unsigned int low : 1;
        unsigned int high: 1;
    };
};
```

***

## 2. 非法写法（全部报错）

```c
// 单独定义位域变量：非法
unsigned int a : 1;

// 位域数组：非法
struct Test {
    unsigned int arr[3] : 2;
};

// 函数参数/返回值用位域：非法
void func(unsigned int : 2);
```

***

## 3. 关键规则补充

1. 位域**没有独立地址**，不能用 `&` 取地址
2. 不能定义位域数组
3. 只能依附结构体/联合体成员存在
4. 位域存储单元由编译器决定，**跨平台布局不统一**

***

## 4. 极简背诵

- 位域**天生是结构体成员专属语法**
- 只能在 `struct` / `union` 里写 `变量 : 位数`
- 不能全局/局部单独定义、不能数组、不能取地址

### 1. 位域应用：网络协议头

```c
#include <stdio.h>
#include <stdint.h>

/* IP协议头（简化版） */
struct IPHeader {
    uint8_t version : 4;      /* 版本号 */
    uint8_t ihl : 4;          /* 头部长度 */
    uint8_t tos;              /* 服务类型 */
    uint16_t total_length;    /* 总长度 */
    uint16_t identification;  /* 标识 */
    uint16_t flags : 3;       /* 标志 */
    uint16_t fragment : 13;   /* 片偏移 */
    uint8_t ttl;              /* 生存时间 */
    uint8_t protocol;         /* 协议 */
    uint16_t checksum;        /* 校验和 */
};

int main(void) {
    struct IPHeader header = {0};

    header.version = 4;
    header.ihl = 5;
    header.ttl = 64;

    printf("IP Version: %u\n", header.version);
    printf("Header Length: %u * 4 = %u bytes\n", header.ihl, header.ihl * 4);

    return 0;
}
```

### 2. 结构体内存对齐控制

默认情况下，编译器会对结构体进行内存对齐以提高访问效率。但在处理网络协议、文件格式或跨平台数据时，可能需要控制对齐方式：

```c
#include <stdio.h>

/* 默认对齐：编译器自动填充对齐 */
struct DefaultLayout {
    char a;     /* 1字节 */
    int b;       /* 4字节，从偏移4开始 */
    char c;      /* 1字节，但整个结构体按4字节对齐 */
};
/* sizeof(struct DefaultLayout) = 12 */

#ifdef _MSC_VER
// MSVC specific
#pragma pack(push, 1)  /* 1字节对齐，不填充 */
struct PackedLayout {
    char a;     /* 1字节 */
    int b;      /* 4字节 */
    char c;     /* 1字节 */
};
#pragma pack(pop)  /* 恢复默认对齐 */
#endif

#if defined(__GNUC__) || defined(__clang__)
// GCC extension
struct __attribute__((packed)) PackedLayout {
    char a;     /* 1字节 */
    int b;      /* 4字节，无填充 */
    char c;     /* 1字节 */
};
#endif

int main(void) {
    printf("Default layout size: %zu\n", sizeof(struct DefaultLayout));

#if defined(__GNUC__) || defined(__clang__)
    printf("Packed layout size: %zu\n", sizeof(struct PackedLayout));
#endif

    return 0;
}
```

**为什么需要控制对齐？**

| 应用场景  | 原因              |
| ----- | --------------- |
| 网络协议  | 协议头必须精确匹配固定字节序  |
| 文件格式  | 二进制文件有固定格式要求    |
| 跨平台通信 | 不同平台对齐方式可能不同    |
| 节省内存  | 嵌入式系统需要精确控制内存使用 |

**字节对齐示例：**

```c
#include <stdio.h>

#if defined(__GNUC__) || defined(__clang__)
// GCC extension
struct __attribute__((packed)) IPv4Header {
    uint8_t  version_ihl;     /* 1字节 */
    uint8_t  tos;             /* 1字节 */
    uint16_t total_length;    /* 2字节 */
    uint16_t identification;  /* 2字节 */
    uint16_t flags_fragment;  /* 2字节 */
    uint8_t  ttl;             /* 1字节 */
    uint8_t  protocol;        /* 1字节 */
    uint16_t checksum;        /* 2字节 */
    uint32_t src_addr;        /* 4字节 */
    uint32_t dst_addr;        /* 4字节 */
};
#endif

int main(void) {
#if defined(__GNUC__) || defined(__clang__)
    printf("IPv4 header size: %zu (should be 20)\n", sizeof(struct IPv4Header));
#endif
    return 0;
}
```

**MSVC 方式（Windows）：**

```c
/* MSVC 使用 #pragma pack */
#pragma pack(push, 1)  /* 保存当前对齐状态，设置1字节对齐 */

struct NetworkPacket {
    uint16_t magic;       /* 2字节 */
    uint8_t  version;     /* 1字节 */
    uint8_t  type;        /* 1字节 */
    uint32_t length;      /* 4字节 */
    char     payload[];   /* 柔性数组 */
};

#pragma pack(pop)  /* 恢复之前的对齐状态 */

/* 使用 */
struct NetworkPacket *pkt = malloc(sizeof(struct NetworkPacket) + 256);
pkt->magic = 0xABCD;
pkt->version = 1;
pkt->type = 5;
pkt->length = 256;
/* payload 可以安全使用 256 字节 */
```

**通用跨平台宏定义：**

```c
#include <stdio.h>

/* 跨平台紧凑结构体定义 */
#if defined(_MSC_VER)
    #define PACK_BEGIN
    #define PACK_END
    #define PACK(struct_type) \
        __pragma(pack(push, 1)) \
        struct_type \
        __pragma(pack(pop))
#elif defined(__GNUC__) || defined(__clang__)
    #define PACK_BEGIN
    #define PACK_END __attribute__((packed))
    #define PACK(struct_type) struct struct_type
#endif

PACK_BEGIN
typedef struct {
    uint8_t  id;
    uint32_t value;
    uint16_t flags;
} PACK_END Packet;

int main(void) {
    printf("Packet size: %zu (expected 7)\n", sizeof(Packet));
    return 0;
}
```

**对齐注意事项：**

1. `#pragma pack` 是 MSVC 特有，GCC/Clang 使用 `__attribute__((packed))`
2. 紧凑结构体可能降低访问效率，但能精确控制大小
3. 网络编程和文件 I/O 时经常需要紧凑结构体
4. 跨平台通信时，应确保两端使用相同的对齐方式

## 8. 本章小结

### 1. 核心知识点

| 类型  | 特点     | 内存占用          |
| --- | ------ | ------------- |
| 结构体 | 成员独立存储 | 所有成员大小之和（含对齐） |
| 联合体 | 成员共享内存 | 最大成员的大小       |
| 枚举  | 命名整数常量 | 通常为int大小      |
| 位域  | 精确控制位数 | 按需分配          |

### 2. 常见陷阱

| 陷阱     | 说明            | 解决方案             |
| ------ | ------------- | ---------------- |
| 内存对齐   | 结构体大小可能大于成员之和 | 使用`sizeof`获取实际大小 |
| 联合体覆盖  | 写入一个成员会覆盖其他成员 | 使用类型标记区分         |
| 位域可移植性 | 位域布局依赖编译器     | 避免依赖具体布局         |
