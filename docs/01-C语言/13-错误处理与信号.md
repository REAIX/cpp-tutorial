## 1. errno错误码

### 1. 概念与定义

**errno**：C标准库定义的全局变量，函数出错时设置为非零值，成功时不保证清零。

### 2. 常见错误码

| 错误码 | 值 | 含义 |
|--------|---|------|
| `EINVAL` | 22 | 无效参数 |
| `ENOENT` | 2 | 文件不存在 |
| `ENOMEM` | 12 | 内存不足 |
| `EACCES` | 13 | 权限不足 |
| `EEXIST` | 17 | 文件已存在 |
| `ESRCH` | 3 | 进程不存在 |

### 3. 使用模式

```c
#include <errno.h>
#include <stdio.h>
#include <string.h>

int main() {
    FILE* f = fopen("nonexistent.txt", "r");
    if (!f) {
        printf("打开失败，errno=%d: %s\n", errno, strerror(errno));
        return 1;
    }
    fclose(f);
    return 0;
}
```

### 4. 注意事项

1. **使用前先清零**：`errno = 0;` 再调用函数
2. **函数成功不保证清零**：必须先检查返回值再检查errno
3. **多线程安全**：C11起errno是线程局部存储

## 2. perror与strerror

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

void demo_error_functions(void) {
    errno = ENOENT;
    perror("my_function");  // 输出: my_function: No such file or directory

    printf("strerror: %s\n", strerror(EACCES));  // Permission denied
}
```

| 函数 | 用途 | 输出位置 |
|------|------|---------|
| `perror(msg)` | 打印 msg: errno描述 | stderr |
| `strerror(err)` | 返回错误码描述字符串 | 返回值 |

## 3. 自定义错误处理

### 1. 错误码枚举

```c
typedef enum {
    ERR_OK = 0,
    ERR_INVALID_PARAM,
    ERR_OUT_OF_MEMORY,
    ERR_FILE_NOT_FOUND,
    ERR_IO_ERROR,
    ERR_TIMEOUT,
} ErrorCode;

const char* error_message(ErrorCode code) {
    static const char* messages[] = {
        "Success",
        "Invalid parameter",
        "Out of memory",
        "File not found",
        "I/O error",
        "Timeout",
    };
    if (code >= 0 && code < sizeof(messages) / sizeof(messages[0])) {
        return messages[code];
    }
    return "Unknown error";
}

// 使用宏简化错误检查
#define CHECK_NULL(ptr) do { \
    if (!(ptr)) { \
        fprintf(stderr, "%s:%d: NULL pointer: %s\n", \
                __FILE__, __LINE__, #ptr); \
        return ERR_INVALID_PARAM; \
    } \
} while(0)

#define CHECK_ALLOC(ptr) do { \
    if (!(ptr)) { \
        fprintf(stderr, "%s:%d: Allocation failed\n", \
                __FILE__, __LINE__); \
        return ERR_OUT_OF_MEMORY; \
    } \
} while(0)
```

## 4. 信号基础

### 1. 概念与定义

**信号（Signal）**：操作系统向进程发送的异步通知，用于通知进程发生了某个事件。

### 2. 常见信号

| 信号 | 值 | 来源 | 默认行为 |
|------|---|------|---------|
| `SIGINT` | 2 | Ctrl+C | 终止 |
| `SIGTERM` | 15 | kill命令 | 终止 |
| `SIGKILL` | 9 | 强制杀死 | 终止（不可捕获） |
| `SIGSEGV` | 11 | 段错误 | 终止+core |
| `SIGABRT` | 6 | abort() | 终止+core |
| `SIGFPE` | 8 | 除零 | 终止+core |
| `SIGPIPE` | 13 | 管道断裂 | 终止 |
| `SIGUSR1` | 10 | 用户自定义 | 终止 |
| `SIGUSR2` | 12 | 用户自定义 | 终止 |
| `SIGCHLD` | 17 | 子进程状态变化 | 忽略 |

## 5. signal函数

```c
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>

volatile sig_atomic_t running = 1;

void handle_sigint(int sig) {
    printf("\n收到信号 %d，正在清理...\n", sig);
    running = 0;
}

int main() {
    signal(SIGINT, handle_sigint);

    printf("按 Ctrl+C 停止...\n");
    while (running) {
        // 主循环
    }
    printf("程序正常退出\n");
    return 0;
}
```

### 1. signal的局限

1. 信号处理函数中只能安全调用异步信号安全函数
2. 不确定信号处理函数在哪个线程执行
3. 某些信号不可捕获（SIGKILL、SIGSTOP）
4. 信号可能被丢失（不可靠信号）

## 6. sigaction

```c
#include <signal.h>
#include <stdio.h>
#include <string.h>

void handler(int sig, siginfo_t* info, void* context) {
    printf("信号: %d\n", sig);
    printf("发送进程PID: %d\n", info->si_pid);
    printf("发送进程UID: %d\n", info->si_uid);
}

int main() {
    struct sigaction sa;
    memset(&sa, 0, sizeof(sa));
    sa.sa_sigaction = handler;
    sa.sa_flags = SA_SIGINFO;

    sigaction(SIGINT, &sa, NULL);
    sigaction(SIGUSR1, &sa, NULL);

    printf("PID=%d, 等待信号...\n", getpid());
    while (1) pause();
    return 0;
}
```

### 1. sigaction vs signal

| 特性 | signal | sigaction |
|------|--------|-----------|
| 可移植性 | C标准 | POSIX |
| 获取发送者信息 | 不支持 | si_pid/si_uid |
| 信号处理期间屏蔽 | 不确定 | sa_mask |
| 一次性处理 | 部分系统是 | 可控（SA_RESETHAND） |
| 推荐度 | 简单场景 | 生产代码 |

## 7. 常见信号处理场景

### 1. 优雅退出

```c
volatile sig_atomic_t g_running = 1;

void cleanup_handler(int sig) {
    g_running = 0;
}

int main() {
    struct sigaction sa;
    sa.sa_handler = cleanup_handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;
    sigaction(SIGINT, &sa, NULL);
    sigaction(SIGTERM, &sa, NULL);

    while (g_running) {
        // 主循环
    }

    // 清理资源
    printf("清理完成，退出\n");
    return 0;
}
```

### 2. 忽略SIGPIPE

```c
// 网络编程中防止写入已关闭的socket导致进程退出
signal(SIGPIPE, SIG_IGN);
// 或
struct sigaction sa;
sa.sa_handler = SIG_IGN;
sigemptyset(&sa.sa_mask);
sigaction(SIGPIPE, &sa, NULL);
```
