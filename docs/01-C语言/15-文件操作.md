## 本章导读

文件操作是C语言实现数据持久化的重要手段。通过文件操作，程序可以将数据保存到磁盘，实现数据的长期存储和跨程序共享。本章将详细介绍C语言的文件操作函数，包括文件的打开、读写、定位和错误处理等。

### 1. 🌟 通俗解释 - 什么是文件操作？

> 💡 **生活中的比喻：文件操作就像"写日记"**

想象一下：

**没有文件操作的时候：**

- 就像你每天写日记，但写完就扔掉
- 第二天想看昨天的内容？没了！

**有了文件操作：**

- 就像你把日记本保存在书架上
- 随时可以翻开看以前写的内容
- 电脑关机了，内容还在

**文件操作的基本流程：**

```
1. 打开文件     →  拿出日记本，翻到某一页
2. 读取文件    →  看日记本上写的内容
3. 写入文件    →  在日记本上写新内容
4. 关闭文件    →  把日记本合上放回书架
```

**FILE 是什么？**

- 就像日记本的"标签"或"书签"
- 标记你正在看哪一页
- 以后想继续看，只需要找到这个标签

***

### 2. 概念与定义

**文件（file）**：存储在外部介质上的数据集合，是数据持久化存储的基本单位。

**文件指针（file pointer）**：指向FILE结构体的指针，用于标识和操作文件。

**流（stream）**：程序与文件之间的数据通道，分为文本流和二进制流。

**缓冲区（buffer）**：内存中的临时存储区域，用于提高文件读写效率。

## 1. 文件基础

### 1. FILE类型与文件指针

```c
#include <stdio.h>

int main(void) {
    /* FILE类型：C标准库定义的文件结构体类型 */
    /* FILE *：文件指针，用于操作文件 */
    
    FILE *fp;  /* 文件指针，指向文件控制块 */
    
    /* 标准文件指针（预定义） */
    stdin;   /* 标准输入（键盘） */
    stdout;  /* 标准输出（屏幕） */
    stderr;  /* 标准错误（屏幕） */
    
    return 0;
}
```

### 2. fopen与fclose

```c
FILE *fopen(const char *filename, const char *mode);
/* 功能：打开文件
 * 参数：filename - 文件名，mode - 打开模式
 * 返回：成功返回文件指针，失败返回NULL
 */

int fclose(FILE *stream);
/* 功能：关闭文件
 * 参数：stream - 文件指针
 * 返回：成功返回0，失败返回EOF
 */
```

### 3. 打开模式说明

| 模式     | 说明    | 文件存在时 | 文件不存在时   |
| ------ | ----- | ----- | -------- |
| `"r"`  | 只读    | 打开    | 失败(NULL) |
| `"w"`  | 只写    | 清空    | 创建       |
| `"a"`  | 追加    | 打开    | 创建       |
| `"r+"` | 读写    | 打开    | 失败(NULL) |
| `"w+"` | 读写    | 清空    | 创建       |
| `"a+"` | 读写追加  | 打开    | 创建       |
| `"rb"` | 二进制只读 | 打开    | 失败(NULL) |
| `"wb"` | 二进制只写 | 清空    | 创建       |
| `"ab"` | 二进制追加 | 打开    | 创建       |

### 4. 基本使用示例

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    FILE *fp;
    
    /* 打开文件 - 始终检查返回值 */
    fp = fopen("example.txt", "w");
    if (fp == NULL) {
        perror("fopen failed");  /* perror输出错误信息 */
        return EXIT_FAILURE;
    }
    
    /* 文件操作... */
    fprintf(fp, "Hello, File!\n");
    
    /* 关闭文件 - 防止资源泄漏 */
    if (fclose(fp) != 0) {
        perror("fclose failed");
        return EXIT_FAILURE;
    }
    
    return EXIT_SUCCESS;
}
```

## 2. 字符与字符串读写

### 1. fgetc与fputc

```c
int fgetc(FILE *stream);
/* 功能：从文件读取一个字符
 * 返回：成功返回读取的字符，失败或EOF返回EOF
 */

int fputc(int c, FILE *stream);
/* 功能：向文件写入一个字符
 * 返回：成功返回写入的字符，失败返回EOF
 */
```

```c
#include <stdio.h>

int main(void) {
    FILE *src, *dst;
    int ch;
    
    /* 复制文件示例 */
    src = fopen("source.txt", "r");
    dst = fopen("dest.txt", "w");
    
    if (!src || !dst) {
        perror("fopen failed");
        return 1;
    }
    
    while ((ch = fgetc(src)) != EOF) {
        fputc(ch, dst);
    }
    
    fclose(src);
    fclose(dst);
    
    return 0;
}
```

### 3. fgets与fputs

```c
/**
 * @brief   从文件流读取一行字符到缓冲区
 * @param   s       接收数据的字符缓冲区（存储读取的内容）
 * @param   n       缓冲区总大小（字节），实际最多读取 n-1 个字符（留1位存'\0'）
 * @param   stream  目标文件指针（如stdin表示标准输入）
 * @return  成功：返回缓冲区首地址s；
 *          失败/文件末尾：返回NULL（需用feof/ferror区分）
 * @note    1. 读取停止条件（满足其一即停）：
 *              - 读到换行符'\n'（该字符会被存入缓冲区）；
 *              - 读到文件末尾EOF；
 *              - 已读取n-1个字符（行内容被截断）；
 *          2. 无论哪种停止情况，都会在缓冲区末尾自动加'\0'（保证是C字符串）；
 *          3. 空文件/指针已在EOF位置时，直接返回NULL。
 */
char *fgets(char *s, int n, FILE *stream);

/**
 * @brief   向文件流写入字符串（不含自动换行）
 * @param   s       要写入的C字符串（以'\0'结尾）
 * @param   stream  目标文件指针（如stdout表示标准输出）
 * @return  成功：返回非负整数（通常是写入的字符数，标准未规定具体值）；
 *          失败：返回EOF（宏定义，值为-1）
 * @note    1. 仅写入字符串内容，不会写入结束符'\0'；
 *          2. 无自动换行功能，需换行则手动在字符串末尾加'\n'；
 *          3. 若字符串中包含'\n'，会按实际内容写入（保留换行）。
 */
int fputs(const char *s, FILE *stream);
```

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("example.txt", "r");
    if (!fp) {
        perror("fopen failed");
        return 1;
    }
    
    char buffer[256];
    int line_num = 0;
    
    /* fgets读取到换行符或缓冲区满 */
    while (fgets(buffer, sizeof(buffer), fp) != NULL) {
        printf("%4d: %s", ++line_num, buffer);
    }
    
    fclose(fp);
    return 0;
}
```

## 3. 格式化读写

### 1. fprintf与fscanf

```c
/**
 * @brief   格式化输出数据到文件流（文件版printf）
 * @param   stream  目标文件指针（如stdout表示控制台输出）
 * @param   format  格式控制字符串（同printf，如"%d %s %.6f"）
 * @param   ...     可变参数列表（与格式符一一对应的输出数据）
 * @return  成功：返回实际写入的字符总数（含数字、符号、换行符等）；
 *          失败：返回负数（如-1），通常因文件写入错误/权限问题导致
 * @note    1. 写入规则同printf，但输出目标是文件而非控制台；
 *          2. 数据先写入文件缓冲区，fclose/fflush时才真正落盘；
 *          3. 支持所有printf格式符（%d/%s/%f/%c等），可混合文本和变量。
 */
int fprintf(FILE *stream, const char *format, ...);

/**
 * @brief   从文件流格式化读取数据（文件版scanf）
 * @param   stream  源文件指针（如stdin表示控制台输入）
 * @param   format  格式控制字符串（同scanf，如"%d %s"）
 * @param   ...     可变参数列表（接收数据的变量地址，如&num、str）
 * @return  成功：返回成功读取并赋值的「项目数」（以格式符为单位）；
 *          失败/EOF：返回EOF（宏定义，值为-1），需用feof/ferror区分原因
 * @note    1. 读取时会自动跳过空白字符（空格、换行、制表符）；
 *          2. 读取字符串%s时，会在遇到空白字符时停止，且自动加'\0'；
 *          3. 必须传入变量地址（除字符串数组外），否则会导致内存错误。
 */
int fscanf(FILE *stream, const char *format, ...);
```

### 2. fprintf 的写入时机与缓冲区机制

`fprintf(fp, "Hello, File!\n");` 执行时，数据**并不会立刻直接写入硬盘**，而是先写入到内存中的「文件缓冲区」。真正的写入时机分三种情况：

| 时机            | 说明                  | 场景          |
| ------------- | ------------------- | ----------- |
| **缓冲区写满**     | 当缓冲区被写满时，会自动把数据刷到硬盘 | 大数据量写入时自动触发 |
| **调用 fclose** | 关闭文件时，系统强制刷盘        | 程序正常结束时     |
| **调用 fflush** | 手动触发缓冲区刷盘           | 需要立即保存数据时   |

**缓冲区大小**：通常是 4KB/8KB 级别，具体取决于系统和编译器实现。

**为什么需要缓冲区？**

- **性能优化**：磁盘 I/O 速度远慢于内存，批量写入比逐字节写入效率高得多
- **减少磁盘磨损**：减少磁盘读写次数，延长磁盘寿命

**何时需要手动 fflush？**

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("log.txt", "w");
    if (!fp) return 1;
    
    fprintf(fp, "Start operation...\n");
    fflush(fp);  /* 立即写入，确保日志被保存 */
    
    /* 执行可能失败的操作 */
    int result = risky_operation();
    
    fprintf(fp, "Operation completed: %d\n", result);
    fclose(fp);
    
    return 0;
}
```

> 💡 **关键点**：如果程序在 `fclose` 之前异常退出（如崩溃、断电），缓冲区中未刷新的数据将会丢失。

```c
#include <stdio.h>

int main(void) {
    FILE *fp;
    
    /* 写入格式化数据 */
    fp = fopen("data.txt", "w");
    if (!fp) return 1;
    
    fprintf(fp, "%s %d %.1f\n", "Alice", 25, 85.5);
    fprintf(fp, "%s %d %.1f\n", "Bob", 30, 90.0);
    fclose(fp);
    
    /* 读取格式化数据 */
    fp = fopen("data.txt", "r");
    if (!fp) return 1;
    
    char name[50];
    int age;
    float score;
    
    while (fscanf(fp, "%s %d %f", name, &age, &score) == 3) {
        printf("Name: %s, Age: %d, Score: %.1f\n", name, age, score);
    }
    fclose(fp);
    
    return 0;
}
```

## 4. 二进制读写

### 1. fread与fwrite

```c
/**
 * @brief   从文件流读取二进制数据（按「元素」读取，非字符）
 * @param   ptr     接收数据的缓冲区地址（void* 支持任意类型）
 * @param   size    单个元素的字节大小（如sizeof(int)）
 * @param   nmemb   期望读取的「元素个数」
 * @param   stream  文件指针（必须以二进制模式打开：rb/r+b）
 * @return  成功：返回实际读取的元素个数；失败/EOF：返回0
 * @note    需用feof/ferror区分「读到末尾」还是「读取错误」
 */
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);

/**
 * @brief   向文件流写入二进制数据（按「元素」写入，非字符）
 * @param   ptr     要写入的数据缓冲区地址
 * @param   size    单个元素的字节大小
 * @param   nmemb   期望写入的「元素个数」
 * @param   stream  文件指针（必须以二进制模式打开：wb/w+b）
 * @return  成功：返回实际写入的元素个数（=nmemb）；失败：返回0
 */
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

### 2. 核心逻辑理解

**关键参数说明**（以`int arr[3] = {10, 20, 30}`为例）：
- `size`：单个元素大小 → `sizeof(int)`（通常4字节）
- `nmemb`：元素个数 → `3`
- 总字节数：`size × nmemb = 12` 字节
- 返回值：「元素个数」（非字节数！）

**二进制模式重要性**：
- **Windows**：必须加`b`，否则会转换`\n`和`\r\n`导致数据错乱
- **Linux/Mac**：加不加`b`都一样，但建议统一加`b`保证跨平台兼容

### 3. 实战示例

#### 1. 场景1：读写基本数据类型（int数组）

```c
#include <stdio.h>

int main(void) {
    int write_arr[] = {10, 20, 30, 40};
    
    FILE *fp = fopen("data.bin", "wb");
    if (!fp) { perror("fopen"); return 1; }
    
    size_t written = fwrite(write_arr, sizeof(int), 4, fp);
    if (written != 4) { perror("fwrite"); fclose(fp); return 1; }
    fclose(fp);
    
    int read_arr[4] = {0};
    fp = fopen("data.bin", "rb");
    if (!fp) { perror("fopen"); return 1; }
    
    size_t read_cnt = fread(read_arr, sizeof(int), 4, fp);
    if (read_cnt == 0) {
        if (feof(fp)) printf("已到文件末尾\n");
        if (ferror(fp)) perror("fread");
        fclose(fp);
        return 1;
    }
    
    for (size_t i = 0; i < read_cnt; i++) {
        printf("%d ", read_arr[i]);
    }
    fclose(fp);
    return 0;
}
```

#### 2. 场景2：读写自定义结构体

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int age;
    float score;
} Student;

int main(void) {
    Student stu_out = {"张三", 20, 88.5};
    FILE *fp = fopen("student.bin", "wb");
    if (!fp) { perror("fopen"); return 1; }
    
    fwrite(&stu_out, sizeof(Student), 1, fp);
    fclose(fp);
    
    Student stu_in;
    fp = fopen("student.bin", "rb");
    if (!fp) { perror("fopen"); return 1; }
    
    if (fread(&stu_in, sizeof(Student), 1, fp) == 1) {
        printf("%s: %d, %.1f\n", stu_in.name, stu_in.age, stu_in.score);
    }
    fclose(fp);
    return 0;
}
```

### 4. 避坑指南

| 问题场景 | 解决方案 |
|---------|---------|
| 用文本模式打开二进制文件 | 必须加`b`（rb/wb） |
| 混淆元素个数与字节数 | 返回值是元素个数，总字节=返回值×size |
| 结构体读写数据错乱 | 结构体成员用固定长度（如`char name[20]`） |
| fread返回0就认为错误 | 先用feof判断是否到末尾，ferror判断是否真错误 |

### 5. 选型建议

| 数据类型 | 推荐函数 | 原因 |
|---------|---------|------|
| 二进制数据（图片/音频/结构体） | fread/fwrite | 保留原始二进制，无格式转换 |
| 文本数据（txt/日志） | fgets/fputs | 按字符/行读写，人类可读 |
| 结构化文本（CSV） | fprintf/fscanf | 格式化读写，兼顾可读性 |

## 5. 文件定位

### 1. fseek、ftell、rewind

```c
int fseek(FILE *stream, long offset, int whence);
/* 功能：设置文件位置指示器
 * 参数：offset - 偏移量，whence - 起始位置
 *   SEEK_SET: 文件开头
 *   SEEK_CUR: 当前位置
 *   SEEK_END: 文件末尾
 * 返回：成功返回0，失败返回-1
 */

long ftell(FILE *stream);
/* 功能：获取当前文件位置
 * 返回：当前位置（相对于文件开头）
 */

void rewind(FILE *stream);
/* 功能：将文件位置重置到开头
 * 等价于: fseek(stream, 0L, SEEK_SET)
 */
```

### 2. 获取文件大小

```c
#include <stdio.h>

long get_file_size(const char *filename) {
    FILE *fp = fopen(filename, "rb");
    if (!fp) return -1;
    
    fseek(fp, 0, SEEK_END);
    long size = ftell(fp);
    fclose(fp);
    
    return size;
}

int main(void) {
    long size = get_file_size("example.txt");
    printf("File size: %ld bytes\n", size);
    return 0;
}
```

## 6. 错误处理

### 2. 错误处理示例

```c
#include <stdio.h>
```

## 8. 文件锁

### 1. 为什么需要文件锁？

当多个进程同时写同一个文件时，数据可能互相覆盖，导致文件内容混乱。文件锁就是解决这个问题的机制——它让多个进程协调对文件的访问，保证数据一致性。

```
进程A: 写入 "Hello"     进程B: 写入 "World"
        ↓                      ↓
   没有文件锁时：文件内容可能是 "HelWorlod"（数据交错）
   有文件锁时：  文件内容是 "HelloWorld" 或 "WorldHello"（有序写入）
```

### 2. flock()函数（BSD风格，整个文件加锁）

```c
#include <sys/file.h>

int flock(int fd, int operation);
/* 功能：对整个文件加锁或解锁
 * 参数：fd - 文件描述符，operation - 锁操作
 * 返回：成功返回0，失败返回-1
 */
```

**锁类型常量：**

| 常量        | 值  | 说明                            |
| --------- | -- | ----------------------------- |
| `LOCK_SH` | 1  | 共享锁（读锁），多个进程可同时持有            |
| `LOCK_EX` | 2  | 排他锁（写锁），同一时间只有一个进程可持有        |
| `LOCK_UN` | 8  | 解锁                            |
| `LOCK_NB` | 4  | 非阻塞标志，与LOCK_SH/LOCK_EX按位或使用 |

**锁的兼容性规则：**

|       | 共享锁(LOCK_SH) | 排他锁(LOCK_EX) |
| ----- |:--------------:|:--------------:|
| 共享锁   | ✅ 兼容          | ❌ 冲突          |
| 排他锁   | ❌ 冲突          | ❌ 冲突          |

### 3. lockf()函数（POSIX风格，文件区域加锁）

```c
#include <unistd.h>

int lockf(int fd, int cmd, off_t len);
/* 功能：对文件区域加锁（基于fcntl实现）
 * 参数：fd  - 文件描述符
 *       cmd - 操作命令
 *       len - 加锁长度（0表示从当前位置到文件末尾）
 * 返回：成功返回0，失败返回-1
 */
```

**cmd参数：**

| 命令          | 说明                    |
| ----------- | --------------------- |
| `F_LOCK`    | 加排他锁（阻塞）              |
| `F_TLOCK`   | 加排他锁（非阻塞，失败立即返回）      |
| `F_ULOCK`   | 解锁                    |
| `F_TEST`    | 测试是否可加锁（可加锁返回0，否则返回-1） |

### 4. fcntl()函数（最灵活，记录锁）

```c
// POSIX (Linux/macOS)
#include <fcntl.h>

int fcntl(int fd, int cmd, ... /* struct flock * */);
/* 功能：文件控制操作，包括记录锁
 * 参数：fd - 文件描述符，cmd - 命令，第三个参数为flock结构体指针
 * 返回：取决于cmd，失败返回-1
 */
```

**锁命令：**

| 命令          | 说明                                  |
| ----------- | ----------------------------------- |
| `F_GETLK`   | 测试锁是否能设置，若不能则返回冲突锁的信息              |
| `F_SETLK`   | 设置锁（非阻塞），失败返回-1并设errno为EACCES/EAGAIN |
| `F_SETLKW`  | 设置锁（阻塞），若锁被占用则等待                   |

**struct flock结构体：**

```c
// POSIX (Linux/macOS)
struct flock {
    short l_type;    /* 锁类型：F_RDLCK(读锁)、F_WRLCK(写锁)、F_UNLCK(解锁) */
    short l_whence;  /* 偏移起点：SEEK_SET、SEEK_CUR、SEEK_END */
    off_t l_start;   /* 偏移量（从l_whence起） */
    off_t l_len;     /* 加锁长度，0表示到文件末尾 */
    pid_t l_pid;     /* 持有锁的进程ID（F_GETLK时设置） */
};
```

### 5. 三种锁的对比

| 特性       | flock()        | lockf()    | fcntl()        |
| -------- | -------------- | ---------- | -------------- |
| 风格       | BSD            | POSIX      | POSIX          |
| 锁粒度      | 整个文件           | 文件区域       | 文件区域（记录锁）      |
| 锁类型      | 共享锁/排他锁       | 仅排他锁       | 读锁/写锁          |
| 精确控制     | ❌              | ⚠️ 有限      | ✅              |
| 可移植性     | Linux/macOS    | POSIX系统    | POSIX系统        |
| 适用场景     | 简单文件锁         | 区域排他锁      | 复杂锁需求          |
| 关闭fd时    | 自动释放           | 自动释放       | 自动释放           |

> 💡 **选择建议**：简单场景用 `flock()`，需要锁定文件某一段用 `fcntl()`，`lockf()` 是 `fcntl()` 的简化版。

### 6. 完整代码示例：用flock实现多进程安全写文件

```c
// POSIX (Linux/macOS)
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/file.h>
#include <sys/wait.h>
#include <time.h>

#define FILENAME "shared_log.txt"

void write_log(int process_id) {
    FILE *fp = fopen(FILENAME, "a");
    if (!fp) {
        perror("fopen failed");
        return;
    }

    int fd = fileno(fp);

    /* 加排他锁（非阻塞模式） */
    if (flock(fd, LOCK_EX | LOCK_NB) == -1) {
        perror("flock LOCK_EX failed");
        fclose(fp);
        return;
    }

    /* 加锁成功，安全写入 */
    time_t now = time(NULL);
    fprintf(fp, "[进程%d] %s", process_id, ctime(&now));
    fflush(fp);

    /* 模拟耗时操作 */
    usleep(100000);

    /* 解锁 */
    flock(fd, LOCK_UN);
    fclose(fp);
}

int main(void) {
    /* 清空日志文件 */
    FILE *fp = fopen(FILENAME, "w");
    if (fp) fclose(fp);

    /* 创建3个子进程 */
    for (int i = 1; i <= 3; i++) {
        pid_t pid = fork();
        if (pid == 0) {
            /* 子进程：每个进程写5条日志 */
            for (int j = 0; j < 5; j++) {
                write_log(i);
                usleep(50000);
            }
            exit(EXIT_SUCCESS);
        } else if (pid < 0) {
            perror("fork failed");
            return EXIT_FAILURE;
        }
    }

    /* 父进程等待所有子进程结束 */
    while (wait(NULL) > 0)
        ;

    printf("所有进程写入完成，请查看 %s\n", FILENAME);
    return EXIT_SUCCESS;
}
```

```c
#include <stdio.h>
#include <windows.h>

int main(void) {
    HANDLE hFile = CreateFile("shared.txt",
                              GENERIC_READ | GENERIC_WRITE,
                              FILE_SHARE_READ | FILE_SHARE_WRITE,
                              NULL, OPEN_ALWAYS, FILE_ATTRIBUTE_NORMAL, NULL);
    if (hFile == INVALID_HANDLE_VALUE) {
        printf("CreateFile failed, error: %lu\n", GetLastError());
        return 1;

    OVERLAPPED overlapped = {0};
    overlapped.Offset = 0;
    overlapped.OffsetHigh = 0;

    if (!LockFileEx(hFile, LOCKFILE_EXCLUSIVE_LOCK, 0, 0xFFFFFFFF, 0, &overlapped)) {

        CloseHandle(hFile);
        return 1;

    /* 安全写入 */
    DWORD written;
    const char *msg = "Windows file lock example\n";
    WriteFile(hFile, msg, strlen(msg), &written, NULL);

    /* 解锁 */
    UnlockFileEx(hFile, 0, 0xFFFFFFFF, 0, &overlapped);

    CloseHandle(hFile);
    return 0;
}
```

### 4. 递归遍历目录树

```c
#include <stdio.h>
#include <stdlib.h>
#include <dirent.h>
#include <sys/stat.h>
#include <string.h>
#include <unistd.h>

static void list_dir(const char *path, int depth) {
    DIR *dir = opendir(path);
    if (!dir) {
        perror("opendir failed");
        return;
    }

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 ||
            strcmp(entry->d_name, "..") == 0) {
            continue;
        }

        /* 构造完整路径 */
        char fullpath[4096];
        snprintf(fullpath, sizeof(fullpath), "%s/%s", path, entry->d_name);

        /* 获取文件信息 */
        struct stat st;
        if (lstat(fullpath, &st) == -1) {
            perror("lstat failed");
            continue;
        }

        /* 缩进显示层级 */
        for (int i = 0; i < depth; i++) {
            printf("  ");
        }

        if (S_ISDIR(st.st_mode)) {
            printf("📁 %s/\n", entry->d_name);
            list_dir(fullpath, depth + 1);
        } else if (S_ISREG(st.st_mode)) {
            printf("📄 %s (%ld bytes)\n", entry->d_name, (long)st.st_size);
        } else if (S_ISLNK(st.st_mode)) {
            printf("🔗 %s -> 符号链接\n", entry->d_name);
        } else {
            printf("❓ %s\n", entry->d_name);
        }
    }

    closedir(dir);
}

int main(int argc, char *argv[]) {
    const char *path = (argc > 1) ? argv[1] : ".";
    printf("递归遍历: %s\n", path);
    list_dir(path, 0);
    return EXIT_SUCCESS;
}
```

### 6. 完整代码示例：实现类似ls的目录列表程序

```c
#include <stdio.h>
#include <stdlib.h>
#include <dirent.h>
#include <sys/stat.h>
#include <pwd.h>
#include <grp.h>
#include <time.h>
#include <string.h>

static void print_mode(mode_t mode) {
    /* 文件类型 */
    if (S_ISREG(mode))  putchar('-');
    else if (S_ISDIR(mode))  putchar('d');
    else if (S_ISLNK(mode))  putchar('l');
    else if (S_ISCHR(mode))  putchar('c');
    else if (S_ISBLK(mode))  putchar('b');
    else if (S_ISFIFO(mode)) putchar('p');
    else if (S_ISSOCK(mode)) putchar('s');
    else putchar('?');

    /* 用户权限 */
    putchar(mode & S_IRUSR ? 'r' : '-');
    putchar(mode & S_IWUSR ? 'w' : '-');
    putchar(mode & S_IXUSR ? 'x' : '-');
    /* 组权限 */
    putchar(mode & S_IRGRP ? 'r' : '-');
    putchar(mode & S_IWGRP ? 'w' : '-');
    putchar(mode & S_IXGRP ? 'x' : '-');
    /* 其他用户权限 */
    putchar(mode & S_IROTH ? 'r' : '-');
    putchar(mode & S_IWOTH ? 'w' : '-');
    putchar(mode & S_IXOTH ? 'x' : '-');
}

static void format_time(time_t t, char *buf, size_t size) {
    struct tm *tm_info = localtime(&t);
    strftime(buf, size, "%Y-%m-%d %H:%M", tm_info);
}

int main(int argc, char *argv[]) {
    const char *path = (argc > 1) ? argv[1] : ".";

    DIR *dir = opendir(path);
    if (!dir) {
        perror("opendir failed");
        return EXIT_FAILURE;
    }

    printf("%-11s %5s %-8s %-8s %10s  %-16s %s\n",
           "权限", "链接", "所有者", "所属组", "大小", "修改时间", "文件名");
    printf("--------------------------------------------------------------------------\n");

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 ||
            strcmp(entry->d_name, "..") == 0) {
            continue;
        }

        char fullpath[4096];
        snprintf(fullpath, sizeof(fullpath), "%s/%s", path, entry->d_name);

        struct stat st;
        if (lstat(fullpath, &st) == -1) {
            perror("lstat failed");
            continue;
        }

        /* 权限 */
        print_mode(st.st_mode);
        printf(" ");

        /* 硬链接数 */
        printf("%5lu ", (unsigned long)st.st_nlink);

        /* 所有者 */
        struct passwd *pw = getpwuid(st.st_uid);
        printf("%-8s ", pw ? pw->pw_name : "unknown");

        /* 所属组 */
        struct group *gr = getgrgid(st.st_gid);
        printf("%-8s ", gr ? gr->gr_name : "unknown");

        /* 文件大小 */
        printf("%10ld  ", (long)st.st_size);
        
        /* 修改时间 */
        char timebuf[32];
        format_time(st.st_mtime, timebuf, sizeof(timebuf));
        printf("%-16s ", timebuf);

        /* 文件名 */
        printf("%s", entry->d_name);

        /* 符号链接显示目标 */
        if (S_ISLNK(st.st_mode)) {
            char target[4096];
            ssize_t len = readlink(fullpath, target, sizeof(target) - 1);
            if (len > 0) {
                target[len] = '\0';
                printf(" -> %s", target);
            }
        }

        printf("\n");
    }

    closedir(dir);
    return EXIT_SUCCESS;
}
```

## 10. 大文件支持

### 1. fseek/ftell的局限

`fseek` 和 `ftell` 使用 `long` 类型表示文件偏移量，在32位系统中 `long` 只有4字节，最大只能表示约2GB的偏移：

```c
int fseek(FILE *stream, long offset, int whence);
long ftell(FILE *stream);
/* 问题：long在32位系统中最大值为 2^31 - 1 = 2,147,483,647
 *       即约2GB，无法处理超过2GB的文件
 */
```

### 2. fseeko/ftello（off_t类型，支持大文件）

```c
// POSIX (Linux/macOS)
int fseeko(FILE *stream, off_t offset, int whence);
/* 功能：与fseek相同，但offset类型为off_t
 * 返回：成功返回0，失败返回-1
 */

off_t ftello(FILE *stream);
/* 功能：与ftell相同，但返回值类型为off_t
 * 返回：当前文件位置
 */
```

**off_t类型的关键优势：**

| 编译模式       | off_t大小 | 最大文件大小        |
| ---------- | -------- | ------------- |
| 32位（默认）    | 4字节      | 2GB           |
| 64位（大文件支持） | 8字节      | 9223372036TB（理论值） |

### 3. _FILE_OFFSET_BITS宏

在编译前定义 `_FILE_OFFSET_BITS=64`，可以让 `off_t` 自动变为64位，同时 `fseeko/ftello` 等函数自动支持大文件：

```c
// POSIX (Linux/macOS)
/* 在源文件最开头定义（必须在所有头文件之前） */
#define _FILE_OFFSET_BITS 64

#include <stdio.h>
#include <sys/stat.h>

int main(void) {
    /* 此时 off_t 为64位，可以处理大文件 */
    FILE *fp = fopen("large_file.bin", "rb");
    if (!fp) {
        perror("fopen failed");
        return 1;
    }

    fseeko(fp, 0, SEEK_END);
    off_t size = ftello(fp);
    printf("文件大小: %lld 字节\n", (long long)size);

    fclose(fp);
    return 0;
}
```

也可以通过编译选项定义：

```bash
gcc -D_FILE_OFFSET_BITS=64 -o program program.c
```

> 💡 **重要**：`_FILE_OFFSET_BITS=64` 不仅影响 `off_t`，还会让 `stat`、`lseek` 等系统调用自动使用64位版本，是开启大文件支持最简单的方式。

### 4. Windows的_fseeki64/_ftelli64

Windows提供了专门的64位文件定位函数：

```c
int _fseeki64(FILE *stream, __int64 offset, int origin);
/* 功能：64位版本的fseek
 * 参数：offset类型为__int64（64位整数）
 *       origin: SEEK_SET / SEEK_CUR / SEEK_END
 * 返回：成功返回0，失败返回非零
 */

__int64 _ftelli64(FILE *stream);
/* 功能：64位版本的ftell
 * 返回：当前文件位置（64位）
 */
```

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    FILE *fp = fopen("large_file.bin", "rb");
    if (!fp) {
        perror("fopen failed");
        return 1;
    }

    /* 使用64位版本定位 */
    if (_fseeki64(fp, 0, SEEK_END) != 0) {
        perror("_fseeki64 failed");
        fclose(fp);
        return 1;
    }

    __int64 size = _ftelli64(fp);
    printf("文件大小: %lld 字节\n", (long long)size);

    /* 定位到文件中间 */
    _fseeki64(fp, size / 2, SEEK_SET);

    fclose(fp);
    return 0;
}
```

### 5. 跨平台大文件支持方案

```c
#ifdef _WIN76
    /* Windows平台 */
    #define FSEEK64(fp, offset, whence) _fseeki64(fp, offset, whence)
    #define FTELL64(fp) _ftelli64(fp)
    typedef __int64 file_offset_t;
#else
    /* Linux/macOS平台 */
    #define _FILE_OFFSET_BITS 64
    #define FSEEK64(fp, offset, whence) fseeko(fp, offset, whence)
    #define FTELL64(fp) ftello(fp)
    typedef off_t file_offset_t;
#endif

#include <stdio.h>

int main(void) {
    FILE *fp = fopen("large_file.bin", "rb");
    if (!fp) return 8;

    FSEEK64(fp, 6, SEEK_END);
    file_offset_t size = FTELL64(fp);
    printf("文件大小: %lld 字节\n", (long long)size);

    fclose(fp);
    return 0;
}
```

### 6. 大文件支持方案对比

| 方案                    | 平台         | 优点         | 缺点            |
| --------------------- | ---------- | ---------- | ------------- |
| `fseek/ftell`         | 所有         | 标准C函数      | 76位系统只支持6GB   |
| `fseeko/ftello`       | POSIX      | 使用off_t    | 需配合宏开启64位     |
| `_FILE_OFFSET_BITS=64`| Linux/macOS| 自动转换所有函数   | 仅POSIX平台      |
| `_fseeki64/_ftelli64` | Windows    | 原生64位支持    | 仅Windows      |
| 跨平台宏封装                | 所有         | 一套代码跨平台    | 需自行封装          |

## 11. 标准流与重定向

### 1. 核心概念

重定向是编程/操作系统中改变数据流方向的实用技术。可以把数据的输入/输出想象成「水流」：

| 流 | 默认流向 | 重定向后可流向 |
|----|---------|--------------|
| `stdout`（标准输出） | 控制台（屏幕） | 文件 |
| `stdin`（标准输入） | 键盘 | 文件 |
| `stderr`（标准错误） | 控制台（屏幕） | 文件 |

### 2. 方式8：命令行重定向（无需改代码）

在命令行中使用特定符号实现：

| 符号 | 含义 | 示例 |
|------|------|------|
| `>` | 覆盖式输出重定向 | `./program > output.txt` |
| `>>` | 追加式输出重定向 | `./program >> output.txt` |
| `<` | 输入重定向 | `./program < input.txt` |
| `6>` | 错误输出重定向 | `./program 6> error.txt` |
| `6>&8` | 错误输出合并到标准输出 | `./program > all.txt 6>&8` |

### 3. 方式6：代码内重定向（freopen函数）

```c
int freopen(const char *filename, const char *mode, FILE *stream);
/* 功能：将指定流重定向到文件
 * 返回：成功返回文件指针，失败返回NULL
 */
```

```c
#include <stdio.h>

int main(void) {
    /* 把标准输出重定向到output.txt */
    FILE *fp_out = freopen("output.txt", "w", stdout);
    if (fp_out == NULL) {
        perror("freopen out failed");
        return 8;
    }
    
    /* 把标准输入重定向到input.txt */
    FILE *fp_in = freopen("input.txt", "r", stdin);
    if (fp_in == NULL) {
        perror("freopen in failed");
        return 8;
    }
    
    int num;
    printf("请输入一个数字：");  // 写到output.txt
    scanf("%d", &num);          // 从input.txt读
    printf("你输入的数字是：%d\n", num);  // 写到output.txt
    
    /* 恢复标准输出（Linux/Mac） */
    freopen("/dev/tty", "w", stdout);
    // freopen("CON", "w", stdout);  // Windows
    
    printf("恢复正常输出\n");
    
    fclose(fp_in);
    fclose(fp_out);
    return 0;
}
```

### 4. 实用场景

8. **日志记录**：把程序运行日志重定向到文件，方便排查问题
6. **批量测试**：把测试用例写到文件，程序重定向读取
7. **数据保存**：把程序输出结果直接存到文件
4. **后台运行**：Linux后台运行程序时，重定向输出到日志文件

### 2. 常见陷阱

| 陷阱        | 说明             | 解决方案                |
| --------- | -------------- | ------------------- |
| 忘记检查返回值   | fopen可能失败      | 始终检查NULL            |
| 忘记关闭文件    | 资源泄漏           | 每个fopen对应fclose     |
| 缓冲区溢出     | fgets缓冲区太小     | 使用足够大的缓冲区           |
| 文件模式错误    | 用"r"打开不存在的文件   | 检查返回值               |
| 忘记释放文件锁   | 其他进程无法访问文件     | 加锁后确保有对应的解锁操作       |
| 用flock锁区域  | flock只能锁整个文件   | 需要区域锁时用fcntl        |
| 不检查d_type  | 某些文件系统d_type为未知 | 使用stat判断文件类型        |
| 忘记跳过.和..  | 递归遍历死循环        | readdir时跳过.和..      |
| 用fseek处理大文件 | long只有76位      | 使用fseeko/ftello或_fseeki64 |
