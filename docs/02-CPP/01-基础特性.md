> （先让它工作，再让它正确，最后让它快。）

>
> （C++的强大源于其基础特性的精心设计，打好基础才能写出高质量的代码。）

> 💡 **通俗理解 - C++的基础特性就像"工具箱升级"**：
>
> 相比C语言，C++给你的工具箱里加了很多新工具：
> - **引用**：像是给变量起了个"外号"，叫哪个名字都能找到同一个人
> - **auto**：像是"智能标签"，自动告诉你盒子里装的是什么类型
> - **范围for**：像是"自动传送带"，一个一个把东西送到你面前
> - **nullptr**：像是"专门的空信封"，不会和数字0混淆

> 🔬 **抽象理解 - 基础特性设计哲学**：
>
> - **类型安全**：C++的每个新特性都在增强类型安全（如enum class、nullptr）
> - **零开销原则**：如果你不用某个特性，就不需要为其付出性能代价
> - **显式优于隐式**：C++倾向于让程序员明确表达意图（如explicit关键字）

## 1. 输入输出流

### 1. 标准流对象

| 对象 | 用途 | 对应C |
| ----------- | --------- | -------- |
| `std::cin` | 标准输入 | `stdin` |
| `std::cout` | 标准输出 | `stdout` |
| `std::cerr` | 标准错误(无缓冲) | `stderr` |
| `std::clog` | 标准错误(有缓冲) | `stderr` |

### 2. 基本使用

```cpp
#include <iostream>
#include <string>

int main() {
    int age;
    std::string name;

    // 输入
    std::cout << "Enter your name: ";
    std::cin >> name;

    std::cout << "Enter your age: ";
    std::cin >> age;

    // 输出
    std::cout << "Name: " << name << ", Age: " << age << std::endl;

    return 0;
}
```

### 3. 格式化输出

```cpp
#include <iostream>
#include <iomanip>

int main() {
    double pi = 3.14159265358979;

    // 设置精度
    std::cout << std::setprecision(4) << pi << std::endl;  // 3.142

    // 设置宽度
    std::cout << std::setw(10) << 42 << std::endl;  // "        42"

    // 左对齐
    std::cout << std::left << std::setw(10) << 42 << std::endl;  // "42        "

    // 填充字符
    std::cout << std::setfill('0') << std::setw(5) << 42 << std::endl;  // "00042"

    // 十六进制
    std::cout << std::hex << 255 << std::endl;  // "ff"

    return 0;
}
```

### 4. 读取整行

```cpp
#include <iostream>
#include <string>

int main() {
    std::string line;

    std::cout << "Enter a line: ";
    std::getline(std::cin, line);  // 读取整行，包括空格

    std::cout << "You entered: " << line << std::endl;

    return 0;
}
```

## 2. 引用

### 1. 基本概念

引用是变量的别名，必须在定义时初始化，且不能改变引用目标。

```cpp
int x = 10;
int& ref = x;  // ref 是 x 的引用

ref = 20;      // x 也变成 20
```

### 2. 引用 vs 指针

| 特性 | 引用 | 指针 |
| ---- | -------- | ----------- |
| 初始化 | 必须初始化 | 可以不初始化 |
| 空值 | 不能为空 | 可以为 nullptr |
| 重新绑定 | 不能 | 可以 |
| 语法 | 更简洁 | 需要 \* 和 & |
| 用途 | 函数参数、返回值 | 动态内存、数据结构 |

### 3. 引用作为函数参数

```cpp
// 1. 避免拷贝（高效）
void process(const std::string& str) {
    std::cout << str << std::endl;
}

// 2. 修改实参
void increment(int& n) {
    n++;
}

// 3. 输出参数
void getMinMax(int a, int b, int& min, int& max) {
    if (a < b) {
        min = a;
        max = b;
    } else {
        min = b;
        max = a;
    }
}
```

### 4. 引用作为返回值

```cpp
#include <vector>

std::vector<int> data = {1, 2, 3, 4, 5};

// 返回引用，可以修改
int& at(size_t index) {
    return data[index];
}

// 使用
at(0) = 100;  // data[0] = 100
```

### 5. 常量引用

```cpp
void print(const std::string& s) {
    // s 不能被修改
    std::cout << s << std::endl;
}

// 常量引用可以绑定临时对象
const std::string& ref = std::string("hello");
```

## 3. auto类型推导

### 1. 基本用法

```cpp
auto x = 10;           // int
auto y = 3.14;         // double
auto s = "hello";      // const char*
auto str = std::string("hello");  // std::string

// 用于复杂类型
std::map<std::string, std::vector<int>> data;
auto it = data.begin();  // 自动推导迭代器类型
```

### 2. auto与引用

```cpp
int x = 10;
auto a = x;      // int (拷贝)
auto& b = x;     // int& (引用)
const auto& c = x;  // const int& (常量引用)
```

### 3. auto与指针

```cpp
int x = 10;
int* p = &x;

auto a = p;      // int*
auto* b = p;     // int*
auto& c = p;     // int*&
```

### 4. 最佳实践

```cpp
// 1. 用于迭代器
std::vector<int> vec = {1, 2, 3};
for (auto it = vec.begin(); it != vec.end(); ++it) {
    std::cout << *it << std::endl;
}

// 2. 用于范围for
for (const auto& item : vec) {
    std::cout << item << std::endl;
}

// 3. 用于lambda
auto lambda = [](int x) { return x * 2; };
```

## 4. 范围for循环

### 1. 基本语法

```cpp
std::vector<int> numbers = {1, 2, 3, 4, 5};

// 只读访问
for (int n : numbers) {
    std::cout << n << " ";
}

// 引用访问（可修改）
for (int& n : numbers) {
    n *= 2;
}

// 常量引用（避免拷贝）
for (const int& n : numbers) {
    std::cout << n << " ";
}

// 使用auto
for (const auto& n : numbers) {
    std::cout << n << " ";
}
```

### 2. 支持的类型

```cpp
// 1. 数组
int arr[] = {1, 2, 3};
for (int n : arr) { }

// 2. STL容器
std::vector<int> vec;
std::list<int> lst;
std::map<int, int> mp;

for (const auto& p : mp) {
    std::cout << p.first << ": " << p.second << std::endl;
}

// 3. 初始化列表
for (int n : {1, 2, 3, 4, 5}) { }

// 4. 字符串
std::string str = "hello";
for (char c : str) { }
```

## 6. 统一初始化（Uniform Initialization）

### 1. C++11之前的初始化问题

> 💡 **通俗理解 - C++11之前的初始化就像"各管各的方言"**
>
> 每种类型都有自己的初始化"方言"：基本类型用 `=`，对象用 `()`，数组用 `{}`……统一初始化就像推广"普通话"，一种语法搞定所有类型。

**1. 不同类型初始化语法不一致**

```cpp
int x = 10;              // 基本类型：用 =
std::string s("hello");  // 对象：用 ()
int arr[] = {1, 2, 3};   // 数组：用 {}
```

**2. 最令人烦恼的解析（Most Vexing Parse）**

```cpp
class Widget {
public:
    Widget() {}
    Widget(int x) {}
};

// 你以为声明了一个Widget对象，实际上编译器认为这是一个函数声明！
Widget w();  // ⚠️ 这是一个返回Widget的无参函数声明，不是对象！

Widget w2(10);  // 这不是MVP问题，带参数的构造调用不会被误解析
```

### 2. 统一初始化语法

C++11引入花括号 `{}` 作为统一的初始化语法：

```cpp
// 基本类型
int x{10};
double d{3.14};
char c{'A'};

// 对象
std::string s{"hello"};
std::vector<int> v{1, 2, 3, 4, 5};

// 数组
int arr[]{1, 2, 3};

// 结构体
struct Point { int x, y; };
Point p{10, 20};

// 动态内存
int* pi = new int{42};

// 成员初始化
class Config {
    int width{800};
    int height{600};
};
```

### 3. 统一初始化的优势

**1. 防止窄化转换（narrowing conversion）**

```cpp
int x{10};       // ✅
// int y{3.14};  // ❌ 编译错误：double到int是窄化转换

double d{3.14};
// int z{d};     // ❌ 编译错误：窄化转换

// 对比传统初始化（不会报错，静默丢失数据）
int a = 3.14;    // ⚠️ 编译通过，a = 3，丢失了0.14
int b(3.14);     // ⚠️ 编译通过，b = 3，丢失了0.14
```

**2. 避免最令人烦恼的解析**

```cpp
class Widget {
public:
    Widget() {}
    Widget(int x) {}
};

Widget w1();     // ⚠️ 被解析为函数声明
Widget w2{};     // ✅ 明确是对象初始化
Widget w3{10};   // ✅ 带参数的初始化
```

**3. 语法统一**

```cpp
// 所有类型都用 {} 初始化，风格一致
int n{0};
double d{1.0};
std::string s{"hello"};
std::vector<int> v{1, 2, 3};
Point p{1, 2};
```

### 4. 统一初始化的注意事项

**1. auto与花括号**

```cpp
auto x = {1};     // x 的类型是 std::initializer_list<int>，不是 int！
auto y = {1, 2};  // y 的类型是 std::initializer_list<int>
auto z{1};        // C++17起：z 的类型是 int（C++11中是 initializer_list<int>）

// 建议：初始化基本类型时直接指定类型，不要用 auto + {}
int a{1};         // ✅ 明确
// auto b = {1};  // ❌ 意外的 initializer_list
```

**2. 构造函数重载与 initializer_list 的优先级**

```cpp
#include <vector>
#include <iostream>

class MyContainer {
public:
    MyContainer(int size) {
        std::cout << "调用 MyContainer(int)" << std::endl;
    }
    MyContainer(std::initializer_list<int> init) {
        std::cout << "调用 MyContainer(initializer_list)" << std::endl;
    }
};

int main() {
    MyContainer a(10);    // 调用 MyContainer(int)
    MyContainer b{10};    // 调用 MyContainer(initializer_list)！花括号优先匹配 initializer_list
    MyContainer c(10, 5); // 调用 MyContainer(int, int)（如果有的话）
    MyContainer d{10, 5}; // 调用 MyContainer(initializer_list)
    return 0;
}
```

> ⚠️ **当类同时有普通构造函数和 `initializer_list` 构造函数时，花括号初始化会优先匹配 `initializer_list` 版本，这可能导致意外行为。**

```cpp
// 经典陷阱：vector 的两种构造方式
std::vector<int> v1(5, 10);   // 5个元素，每个值为10 → {10, 10, 10, 10, 10}
std::vector<int> v2{5, 10};   // 2个元素：5和10   → {5, 10}
```

> 📌 **规则：优先使用花括号初始化以获得类型安全，但要注意 `auto` 和 `initializer_list` 的陷阱**

## 7. nullptr与NULL的区别

### 1. NULL的问题

> 💡 **通俗理解 - NULL就像一个"模糊的地址"**
>
> 想象你要寄一个包裹到"空地址"。在C语言中，NULL就像写了一个"0号"——既可能是门牌号0，也可能表示"没有地址"。这种模糊性在C++中会引发麻烦。

在C语言中，`NULL` 通常定义为 `((void*)0)` 或 `0`：

```cpp
// C语言中的典型定义
#define NULL ((void*)0)  // 或 #define NULL 0
```

但在C++中，`NULL` 被定义为整数字面量 `0`，因为C++不允许 `void*` 隐式转换为其他指针类型：

```cpp
// C++中的典型定义
#define NULL 0  // 整数字面量，不是指针
```

这会导致函数重载时的二义性问题：

```cpp
#include <iostream>

void f(int value) {
    std::cout << "调用 f(int)" << std::endl;
}

void f(char* ptr) {
    std::cout << "调用 f(char*)" << std::endl;
}

int main() {
    f(0);       // 调用 f(int) ✅
    f(NULL);    // 也调用 f(int)！❌ 本意是调用指针版本
    return 0;
}
```

> ⚠️ 因为 `NULL` 在C++中就是 `0`，所以 `f(NULL)` 匹配的是 `f(int)` 而非 `f(char*)`，这违背了使用空指针的初衷。

### 2. nullptr的优势

> 💡 **nullptr就像一个"明确的空信封"**——它明确表示"没有地址"，不会和数字0混淆。

`nullptr` 是C++11引入的空指针常量，类型为 `std::nullptr_t`：

- 可以隐式转换为任何指针类型
- 不会转换为整数
- 解决了函数重载时的二义性问题

```cpp
#include <iostream>

void f(int value) {
    std::cout << "调用 f(int)" << std::endl;
}

void f(char* ptr) {
    std::cout << "调用 f(char*)" << std::endl;
}

int main() {
    f(0);          // 调用 f(int)
    f(nullptr);    // 调用 f(char*) ✅ 正确匹配指针版本
    return 0;
}
```

`nullptr` 的类型特性：

```cpp
#include <cstddef>

int* p1 = nullptr;          // 可以赋值给任何指针类型
char* p2 = nullptr;         // ✅
double* p3 = nullptr;       // ✅

// int n = nullptr;         // ❌ 编译错误：不能转换为整数

// nullptr 的类型
auto np = nullptr;          // np 的类型是 std::nullptr_t
std::nullptr_t null_val;    // 显式声明 nullptr_t 类型
```

### 3. 对比表格

| 特性 | NULL | nullptr |
|------|------|---------|
| 类型 | `int` 或 `void*` | `std::nullptr_t` |
| 函数重载 | 可能匹配int版本 | 正确匹配指针版本 |
| 类型安全 | 否 | 是 |
| 隐式转int | 可能 | 不可以 |
| 隐式转指针 | 视定义而定 | 可以（任意指针类型） |
| 推荐使用 | C语言 | C++11及以上 |

### 4. 最佳实践

```cpp
// ❌ 旧风格
int* p = NULL;
if (p != NULL) { }

// ✅ 新风格
int* p = nullptr;
if (p != nullptr) { }

// ✅ 更简洁的写法
if (p) { }        // 等价于 p != nullptr
if (!p) { }       // 等价于 p == nullptr
```

> 📌 **规则：C++代码中统一使用 `nullptr` 替代 `NULL` 和 `0`**

## 8. enum class与enum的区别

### 1. 传统enum的问题

> 💡 **通俗理解 - 传统enum就像"公共广播"**
>
> 传统enum的值就像用大喇叭喊出来的名字——所有人都能听到，而且容易和别人喊的名字撞上。`enum class` 则像"对讲机频道"——只有在同一个频道里才能听到。

**1. 作用域污染：枚举值泄漏到外层作用域**

```cpp
enum Color { RED, GREEN, BLUE };
enum TrafficLight { RED, YELLOW, GREEN };  // ❌ 编译错误：RED和GREEN重复定义

// 枚举值直接暴露在外层作用域
int x = RED;  // 不需要 Color:: 前缀就能访问
```

**2. 隐式转换为int：类型不安全**

```cpp
enum Color { RED, GREEN, BLUE };
enum Fruit { APPLE, BANANA, ORANGE };

Color c = RED;
int n = c;         // ✅ 隐式转换为int，但丢失了类型信息

if (c == APPLE) { }  // ✅ 可以编译！但比较不同枚举类型毫无意义
```

**3. 不同枚举类型的值可以比较**

```cpp
enum Direction { UP, DOWN };
enum Status { OK, ERROR };

Direction d = UP;
Status s = OK;

if (d == s) { }  // ✅ 可以编译，但逻辑上不合理
```

### 2. enum class的优势

```cpp
// 作用域限定：必须通过 EnumType::Value 访问
enum class Color { RED, GREEN, BLUE };
enum class TrafficLight { RED, YELLOW, GREEN };  // ✅ 不会冲突

Color c = Color::RED;          // 必须使用 Color:: 前缀
// int n = c;                  // ❌ 不能隐式转换为int
// if (c == TrafficLight::RED) // ❌ 不能比较不同枚举类型

// 可以指定底层类型
enum class Flags : unsigned int {
    READ    = 1u << 0,
    WRITE   = 1u << 1,
    EXECUTE = 1u << 2
};

// 需要整数时，必须显式转换
int value = static_cast<int>(Color::RED);  // ✅ 显式转换
```

### 3. 对比表格

| 特性 | `enum` | `enum class` |
|------|--------|-------------|
| 作用域 | 外层作用域 | 枚举作用域内 |
| 隐式转int | 可以 | 不可以 |
| 类型安全 | 否 | 是 |
| 不同枚举可比较 | 可以 | 不可以 |
| 指定底层类型 | C++11起支持 | C++11支持 |
| 前向声明 | 有限制 | 可以 |

### 4. 何时使用

```cpp
// ✅ 新代码优先使用 enum class
enum class LogLevel { DEBUG, INFO, WARNING, ERROR };
LogLevel level = LogLevel::INFO;

// ✅ 需要隐式转int时（如位运算flags），可用传统enum
enum Permission : unsigned int {
    PERM_READ    = 1u << 0,
    PERM_WRITE   = 1u << 1,
    PERM_EXECUTE = 1u << 2
};
unsigned int perms = PERM_READ | PERM_WRITE;  // 方便位运算

// ✅ enum class 也可以做位运算，但需要重载运算符
enum class Flags : unsigned int {
    A = 1u << 0,
    B = 1u << 1
};
// 需要重载 operator| 等才能直接位运算
```

> 📌 **规则：新代码优先使用 `enum class`，只有在需要方便位运算等特殊场景时才考虑传统 `enum`**

## 9. 本章小结

### 1. 核心概念回顾

| 概念 | 说明 | 示例 |
| --- | --- | --- |
| **I/O流** | 类型安全的输入输出 | `std::cin`、`std::cout` |
| **引用** | 变量别名，避免拷贝 | `int& ref = x;` |
| **auto** | 自动类型推导 | `auto x = 10;` |
| **范围for** | 简化容器遍历 | `for (auto& x : vec)` |
| **统一初始化** | 花括号初始化，防止窄化 | `int x{10};` |
| **nullptr** | 类型安全的空指针 | `int* p = nullptr;` |
| **enum class** | 强类型枚举 | `enum class Color { RED };` |

### 2. 关键语法要点

1. **引用必须初始化**：`int& ref = x;`，不能为空，不能重新绑定
2. **auto推导规则**：`auto` 会忽略引用和顶层const
3. **范围for**：优先使用 `const auto&` 避免拷贝
4. **统一初始化**：优先使用花括号初始化，注意 `initializer_list` 陷阱
5. **nullptr**：C++代码中统一使用 `nullptr` 替代 `NULL` 和 `0`
6. **enum class**：新代码优先使用 `enum class`
