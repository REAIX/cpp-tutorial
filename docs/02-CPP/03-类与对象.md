> 💡 **通俗理解 - 什么是面向对象？**

想象一下你要建一个"动物园"：

**面向过程（像C语言）的做法：**

- 先画一个大场地
- 然后在里面一个一个放置动物
- 每种动物都要单独照顾：喂食、清洁、医疗...

**面向对象（像C++）的做法：**

- 先定义"动物"这个概念（类）
- 然后创建具体的动物（对象），比如"老虎"是动物的一个实例
- 动物有什么共同特征？比如都有名字、年龄、都需要吃饭
- 每种动物特有的行为，比如老虎会吼叫，猴子会爬树

**所以面向对象就是：先抽象出"概念"，再创建具体的"实例"**

> 🔬 **抽象理解 - 面向对象的本质**：
>
> - **抽象**：是从具体事物中提取"共同特征"，忽略细节的过程
> - **类**：是一种"模板/蓝图"，定义了对象的"属性"和"行为"
> - **对象**：是类的"实例"，是具体存在的个体
> - **封装**：是把数据和操作数据的代码"打包"在一起，对外隐藏内部细节
> - **继承**：是"复用"和"扩展"，子类继承父类的特性
> - **多态**：是"同一接口，不同实现"，用父类引用指向子类对象

## 1. 从struct到class

### 1. 概念与定义

**类（class）**：C++中用于封装数据和函数的机制。类可以将数据和函数封装在一起，提高代码复用性，减少代码冗余。

**对象（object）**：类的实例。对象可以访问类的成员变量和成员函数。例如`Point p(1, 2);`创建了一个`Point`类的对象`p`。

**封装（encapsulation）**：将数据和函数封装在一起，隐藏实现细节，只对外提供接口。封装可以提高代码安全性，减少代码耦合。

### 2. C语言的struct

```c
// C语言：数据与函数分离
struct Point {
    int x;
    int y;
};

void point_init(struct Point* p, int x, int y) {
    p->x = x;
    p->y = y;
}

void point_print(const struct Point* p) {
    printf("(%d, %d)\n", p->x, p->y);
}
```

### 3. C++的class

```cpp
// C++：数据与函数封装
class Point {
public:
    int x, y;
    
    Point(int x, int y) : x(x), y(y) {}
    
    // const 放在成员函数后面，表示：这个函数不会修改对象里的任何成员变量。
    void print() const {
        std::cout << "(" << x << ", " << y << ")" << std::endl;
    }
};

// 使用
Point p(1, 2);
p.print();
```

### 4. struct vs class

| 特性     | struct | class   |
| ------ | ------ | ------- |
| 默认访问权限 | public | private |
| 默认继承权限 | public | private |
| 用途     | 数据聚合   | 面向对象    |

> 💡 **经验法则**：小的纯数据结构用`struct`，需要封装和行为的用`class`。

## 2. 构造函数与析构函数

### 1. 构造函数

构造函数是特殊的成员函数，用于初始化对象。

#### 1. 基本构造函数

```cpp
class Student {
public:
    std::string name;
    int age;
    
    // 默认构造函数
    Student() : name(""), age(0) {}
    
    // 带参数构造函数
    Student(const std::string& n, int a) : name(n), age(a) {}
    
    // 拷贝构造函数
    Student(const Student& other) : name(other.name), age(other.age) {}
    
    // 移动构造函数
    Student(Student&& other) noexcept 
        : name(std::move(other.name)), age(other.age) {
        other.age = 0;
    }
};
```

#### 2. 构造函数重载

```cpp
class Rectangle {
private:
    double width, height;

public:
    // 默认构造函数
    Rectangle() : width(0), height(0) {}
    
    // 带参数构造函数
    Rectangle(double w, double h) : width(w), height(h) {}
    
    // 正方形构造函数
    explicit Rectangle(double side) : width(side), height(side) {}
    
    double getArea() const {
        return width * height;
    }
};

// 使用
Rectangle r1;                // 面积为0
Rectangle r2(4, 5);          // 面积为20
Rectangle r3(3);             // 面积为9（正方形）
Rectangle r4 = Rectangle(2); // 显式构造
```

#### 3. 构造函数委托

在`初始化列表`中调用`已有的构造函数`来完成初始化，属于C++11新特性，用于减少重复初始化代码。

```cpp
class Rectangle {
public:
    int width, height;
    
    Rectangle(int w, int h) : width(w), height(h) {}
    
    // 委托构造
    Rectangle(int size) : Rectangle(size, size) {}
    
    // 默认构造委托
    Rectangle() : Rectangle(1, 1) {}
};
```

**委托构造的规则**：

1. **只能在初始化列表里委托**，不能在构造函数函数体内调用另一个构造
2. **不能循环委托**：A委托B、B又委托A，编译报错
3. 委托构造一旦调用了另一个构造，**就不能再写其他成员初始化列表**

**默认构造委托**：

无参的默认构造函数，委托本类的有参构造函数来完成初始化。

```cpp
class Student {
    std::string name;
    int age;
public:
    Student(std::string n, int a) : name(n), age(a) {}  // 有参构造
    Student() : Student("", 0) {}  // 默认构造委托给有参构造
};
```

#### 4. explicit关键字

`explicit`关键字用于防止类的构造函数进行**隐式类型转换**。

```cpp
class Test1 {
public:
    Test1(int n) { num = n; }  // 普通构造函数
private:
    int num;
};

class Test2 {
public:
    explicit Test2(int n) { num = n; }  // explicit构造函数
private:
    int num;
};

int main() {
    Test1 t1 = 12;  // 隐式调用构造函数，成功
    Test2 t2 = 12;  // 编译错误！不能隐式调用
    Test2 t3(12);   // 显式调用，成功
    return 0;
}
```

#### 5. 默认拷贝构造与浅拷贝

如果你不手动写拷贝构造函数，C++编译器会**自动生成一个默认的拷贝构造函数**，它只会做一件事：**成员级拷贝（memberwise copy）**——对每个成员分别调用其拷贝构造函数，而非逐字节复制。

**浅拷贝的问题**：只拷贝变量本身，不拷贝变量指向的堆内存。

```cpp
class Person {
public:
    char* buf;
    Person() { buf = new char[100]; }
    ~Person() { delete[] buf; }
};

Person p1;
Person p2 = p1;  // 默认浅拷贝：p2.buf = p1.buf，指向同一块内存
// 析构时会重复释放导致崩溃！
```

#### 6. 禁用拷贝构造函数

如果类不应被拷贝，可以使用 `= delete` 显式禁用拷贝构造和拷贝赋值：

```cpp
class NonCopyable {
public:
    // 禁用拷贝构造
    NonCopyable(const NonCopyable&) = delete;
    
    // 禁用拷贝赋值
    NonCopyable& operator=(const NonCopyable&) = delete;
    
    // 默认构造
    NonCopyable() = default;
};
```

**常见使用场景**：

```cpp
class FileHandler {
private:
    FILE* file;
public:
    FileHandler(const std::string& filename) {
        file = fopen(filename.c_str(), "r");
    }
    ~FileHandler() { if (file) fclose(file); }
    
    // 禁用拷贝，防止double free
    FileHandler(const FileHandler&) = delete;
    FileHandler& operator=(const FileHandler&) = delete;
};
```

### 2. 析构函数

析构函数用于在对象销毁时释放资源。每个类只能有一个析构函数，不能重载。

#### 1. 基本用法

```cpp
class Resource {
private:
    int* data;
    
public:
    Resource(size_t size) : data(new int[size]) {}
    
    ~Resource() {
        delete[] data;  // 自动释放资源
    }
};
```

#### 2. 析构函数示例：文件处理

```cpp
class FileHandler {
private:
    FILE* file;

public:
    FileHandler(const std::string& filename, const std::string& mode) {
        file = fopen(filename.c_str(), mode.c_str());
        if (!file) {
            throw std::runtime_error("Failed to open file");
        }
    }

    ~FileHandler() {
        if (file) {
            fclose(file);
        }
    }

    void write(const std::string& content) {
        if (file) {
            fputs(content.c_str(), file);
        }
    }
};
```

## 3. 类初始化详解

### 1. 成员初始化列表

```cpp
class Example {
private:
    const int value;      // const成员
    int& ref;             // 引用成员
    std::string name;     // 对象成员
    
public:
    // 必须使用初始化列表
    Example(int v, int& r, const std::string& n) 
        : value(v), ref(r), name(n) {}
};
```

### 2. 初始化顺序

```cpp
class Order {
private:
    int a;  // 先初始化
    int b;  // 后初始化
    
public:
    // 初始化顺序由声明顺序决定，不是初始化列表顺序！
    Order() : b(2), a(1) {}  // 实际：a先初始化为1，b后初始化为2
};
```

### 3. C++11类内初始化

```cpp
class Config {
public:
    int width = 800;              // 类内初始化
    int height = 600;             // 类内初始化
    std::string title = "Window"; // 类内初始化
    
    // 可以覆盖类内初始化
    Config(int w, int h) : width(w), height(h) {}
};
```

### 4. 初始化列表的使用场景

| 场景 | 必须使用初始化列表 | 说明 |
| --- | --- | --- |
| const成员 | ✅ | 必须在初始化列表中初始化 |
| 引用成员 | ✅ | 引用必须在定义时绑定 |
| 基类 | ✅（可选委托） | 调用基类构造函数 |
| 无默认构造的成员 | ✅ | 必须在初始化列表中传参 |
| 普通成员 | ❌（推荐使用） | 初始化列表效率更高 |

## 4. 访问控制

### 1. 访问修饰符

```cpp
class AccessDemo {
public:
    int publicVar;        // 任何地方可访问
    
protected:
    int protectedVar;     // 类内及派生类可访问
    
private:
    int privateVar;       // 仅类内可访问
    
public:
    void setPrivate(int v) {
        privateVar = v;   // 类内访问私有成员
    }
};
```

### 2. 访问权限表

| 访问权限      | 类内 | 派生类 | 外部 |
| --------- | -- | --- | -- |
| public    | ✓  | ✓   | ✓  |
| protected | ✓  | ✓   | ✗  |
| private   | ✓  | ✗   | ✗  |

### 3. 封装性的最佳实践

```cpp
class BankAccount {
private:
    double balance;  // 私有数据，外部不能直接访问

public:
    // 通过公有接口访问
    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    
    double getBalance() const {
        return balance;
    }
};
```

## 5. this指针

`this` 是一个指向当前对象自身的指针，在所有非静态成员函数中可用。

### 1. 基本用法

```cpp
class Person {
private:
    std::string name;
    
public:
    Person(const std::string& name) {
        // 使用this区分参数和成员变量
        this->name = name;
    }
    
    Person& setName(const std::string& name) {
        this->name = name;
        return *this;  // 返回当前对象的引用，支持链式调用
    }
    
    void print() const {
        std::cout << "Name: " << this->name << std::endl;
        // 在const成员函数中，this 的类型是 const Person*
    }
};

// 链式调用
Person p("Alice");
p.setName("Bob").setName("Charlie");
```

### 2. this指针的要点

| 特性 | 说明 |
| --- | --- |
| 类型 | 在非const成员函数中为 `T* const`，在const成员函数中为 `const T* const` |
| 可用性 | 所有**非静态**成员函数中可用 |
| 静态成员函数 | 没有 `this` 指针 |
| 主要用途 | 区分参数与成员、返回对象引用实现链式调用 |

## 6. const成员函数

const成员函数承诺**不修改对象的任何非静态成员变量**。

### 1. 基本语法

```cpp
class Counter {
private:
    int count = 0;
    
public:
    void increment() {
        count++;  // 非const函数可以修改成员
    }
    
    int getCount() const {
        // count++;  // ❌ 编译错误！const成员函数不能修改成员
        return count;
    }
};
```

### 2. const对象只能调用const成员函数

```cpp
const Counter c;     // const对象
c.getCount();        // ✅ const对象只能调用const成员函数
// c.increment();    // ❌ 编译错误！const对象不能调用非const成员函数
```

### 3. const成员函数重载

```cpp
class Container {
public:
    int& operator[](size_t index) {
        return data[index];
    }
    
    const int& operator[](size_t index) const {
        return data[index];
    }
    
private:
    int data[100];
};

void process(const Container& constRef, Container& ref) {
    constRef[0] = 10;  // ❌ 调用const版本，返回const引用，不能修改
    ref[0] = 10;       // ✅ 调用非const版本，可以修改
}
```

> 📌 **规则**：只要函数不修改对象状态，就应声明为 `const`

## 7. static成员

static成员属于类本身，而非某个对象实例。

### 1. 静态成员变量

```cpp
class BankAccount {
private:
    static int totalAccounts;  // 声明：属于类，所有对象共享
    std::string owner;
    
public:
    BankAccount(const std::string& owner) : owner(owner) {
        totalAccounts++;
    }
    
    static int getTotalAccounts() {
        return totalAccounts;
    }
};

// 定义和初始化（必须在类外进行）
int BankAccount::totalAccounts = 0;

// 使用
BankAccount a1("Alice"), a2("Bob");
std::cout << BankAccount::getTotalAccounts();  // 输出：2
```

### 2. 静态成员函数

| 特性 | 说明 |
| --- | --- |
| 没有this指针 | 静态成员函数不依赖具体对象 |
| 只能访问静态成员 | 不能访问非静态成员变量或非静态成员函数 |
| 调用方式 | 通过 `类名::` 或对象调用（推荐通过类名） |

```cpp
class MathUtils {
public:
    static double pi() { return 3.1415926535; }
    static double square(double x) { return x * x; }
};

// 通过类名调用
double area = MathUtils::pi() * MathUtils::square(5.0);
```

### 3. 静态成员的常见用途

1. **全局计数器**：统计类的实例数量
2. **共享配置**：所有对象共享相同的配置值
3. **工厂方法**：创建对象实例的静态方法
4. **工具函数**：与类相关但不需要访问实例数据的函数

## 8. 本章小结

### 1. 核心概念回顾

| 概念 | 说明 | 示例 |
| --- | --- | --- |
| **类** | 数据和函数的封装体 | `class Point { ... };` |
| **对象** | 类的实例 | `Point p(1, 2);` |
| **构造函数** | 初始化对象 | `Point(int x, int y) : x(x), y(y) {}` |
| **析构函数** | 释放资源 | `~Resource() { delete[] data; }` |
| **初始化列表** | 高效初始化成员 | `: value(v), ref(r)` |
| **封装** | 隐藏内部实现 | private成员 + public接口 |
| **this指针** | 指向当前对象的指针 | `this->name = name;` |
| **const成员函数** | 不修改对象的函数 | `void print() const;` |
| **static成员** | 属于类的成员 | `static int count;` |

### 2. 关键语法要点

1. **初始化列表**：const和引用成员必须在初始化列表中初始化
2. **初始化顺序**：按成员声明顺序，而非初始化列表顺序
3. **explicit**：防止隐式类型转换，单参数构造推荐使用
4. **const成员函数**：不修改对象状态的函数都应加const
5. **static成员**：在类外定义和初始化
