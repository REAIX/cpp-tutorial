# 继承与多态

> 面向对象编程的继承、多态、虚函数、抽象类、RTTI等

***

> **Inheritance is a generalization-specialization relationship.** — Bjarne Stroustrup
> （继承是一种泛化-特化的关系。）

> **The secret to building large apps is never build large apps. Break your applications into small pieces. Then, assemble those testable, bite-sized pieces into your big application.** — Justin Meyer
> （构建大型应用的秘诀是永远不要构建大型应用。将应用分解成小块，然后将这些可测试的小块组装成大型应用。）

***

> **🎯 青，取之于蓝，而青于蓝。**
>
> （继承不是简单地复制，而是在原有基础上改进和超越。）

> 💡 **通俗理解 - 继承就像"家族基因"**：
>
> - 孩子继承父母的基因（成员变量和方法），但又有自己的特点（新增成员）
> - 孩子可以"改进"父母的特征（方法重写/override）
> - 一家人可以做相似的事情，但各有特色（多态）
> - 爷爷、爸爸、你——可以形成一条"继承链"，每一代都继承上一代的特征

> 🔬 **抽象理解 - OOP三大特性的本质**：
>
> - **封装**：将数据（成员变量）和操作（成员函数）捆绑在一起，通过访问权限控制外部可见性
> - **继承**：建立类之间的"is-a"关系，派生类拥有基类的所有成员（除了构造/析构/赋值运算符）
> - **多态**：通过虚函数表（vtable）实现"同一接口，多种实现"，编译器在运行时根据实际对象类型调用对应的函数

## 1. 继承基础

### 1. 继承的基本语法

```cpp
class Base {
public:
    void publicMethod() {}
protected:
    int protectedData;
private:
    int privateData;
};

class Derived : public Base {
public:
    void derivedMethod() {
        publicMethod();    // ✅ 可以访问public成员
        protectedData = 1; // ✅ 可以访问protected成员
        // privateData = 1;  // ❌ 不能访问private成员
    }
};

int main() {
    Derived d;
    d.publicMethod();     // ✅ 可以访问public成员
    // d.protectedData = 1; // ❌ 不能访问protected成员
    return 0;
}
```

### 2. 构造函数与析构函数

```cpp
#include <iostream>

class Base {
public:
    Base() { std::cout << "Base constructor\n"; }
    ~Base() { std::cout << "Base destructor\n"; }
};

class Derived : public Base {
public:
    Derived() { std::cout << "Derived constructor\n"; }
    ~Derived() { std::cout << "Derived destructor\n"; }
};

int main() {
    Derived d;
    /*
     * 输出顺序：
     * Base constructor
     * Derived constructor
     * Derived destructor
     * Base destructor
     */
    return 0;
}
```

### 3. 派生类的构造函数

```cpp
class Base {
public:
    Base(int x) : data(x) {}
    Base(const Base& other) : data(other.data) {}
private:
    int data;
};

class Derived : public Base {
public:
    // 调用基类构造函数
    Derived(int x, int y) : Base(x), extraData(y) {}

    // 拷贝构造函数
    Derived(const Derived& other)
        : Base(other),          // 调用基类拷贝构造
          extraData(other.extraData) {}
private:
    int extraData;
};
```

## 2. 继承方式

### 1. 三种继承方式

| 继承方式 | 基类public → 派生类 | 基类protected → 派生类 | 基类private → 派生类 |
|---------|--------------------|----------------------|--------------------|
| public继承 | public | protected | 不可访问 |
| protected继承 | protected | protected | 不可访问 |
| private继承 | private | private | 不可访问 |

```cpp
class Base {
public:
    int pub;
protected:
    int prot;
private:
    int priv;
};

class PubDerived : public Base {
    // pub → public
    // prot → protected
    // priv → 不可访问
};

class ProtDerived : protected Base {
    // pub → protected
    // prot → protected
    // priv → 不可访问
};

class PrivDerived : private Base {
    // pub → private
    // prot → private
    // priv → 不可访问
};
```

### 2. public继承的含义

public继承表示"is-a"关系。即派生类是一种基类。

```cpp
class Animal { /* ... */ };
class Dog : public Animal { /* ... */ };

// Dog "is-a" Animal
void feed(Animal& a) { /* ... */ }

int main() {
    Dog dog;
    feed(dog);  // ✅ Dog 是 Animal，可以传给需要Animal的函数
    return 0;
}
```

### 3. 组合优先于继承

> 💡 **通俗理解 - "has-a" vs "is-a"**

当你设计类之间的关系时，先问自己：是"是一种"还是"有一个"？

- 汽车"是一种"交通工具 → 用继承
- 汽车"有一个"发动机 → 用组合

```cpp
// ✅ 组合：Car has-a Engine
class Engine {
public:
    void start() { /* ... */ }
};

class Car {
private:
    Engine engine;  // Car 包含 Engine
public:
    void start() {
        engine.start();
    }
};
```

## 3. 多态与虚函数

### 1. 虚函数

```cpp
#include <iostream>

class Animal {
public:
    virtual void speak() {  // virtual 关键字
        std::cout << "Animal speaks" << std::endl;
    }
    virtual ~Animal() {}    // 虚析构函数
};

class Dog : public Animal {
public:
    void speak() override {  // override 关键字（C++11）
        std::cout << "Woof!" << std::endl;
    }
};

class Cat : public Animal {
public:
    void speak() override {
        std::cout << "Meow!" << std::endl;
    }
};

void makeSpeak(Animal& animal) {
    animal.speak();  // 多态：根据实际对象类型调用
}

int main() {
    Dog dog;
    Cat cat;

    makeSpeak(dog);  // Woof!
    makeSpeak(cat);  // Meow!

    return 0;
}
```

### 2. 虚函数表（vtable）

> 💡 **通俗理解 - vtable就像"函数索引表"**
>
> 每个有虚函数的类都有一张"函数索引表"（vtable），记录了每个虚函数的实际地址。对象中有一个隐藏的指针（vptr）指向这张表。调用虚函数时，实际是通过这个指针查表找到真正的函数地址。

| 概念 | 存储位置 | 说明 |
|------|---------|------|
| vtable | 静态存储区（类特有） | 每个有虚函数的类一张表 |
| vptr | 对象内部（4/8字节） | 每个对象一个指针，指向vtable |
| 虚函数调用 | 运行时 | 通过vptr查vtable找到函数地址 |

### 3. override和final

```cpp
class Base {
public:
    virtual void func() {}
    virtual void process(int x) {}
};

class Derived : public Base {
public:
    // override：显式标记重写，编译器会检查是否正确重写了基类虚函数
    void func() override {
        // ...
    }

    // ❌ 编译错误：基类没有 process(double) 这个虚函数
    // void process(double x) override;

    // ✅ 正确：重写基类的 process(int)
    void process(int x) override {
        // ...
    }
};

class FinalClass final : public Base {
    // final 类不能被继承
};

// ❌ 编译错误：不能继承 final 类
// class Derived2 : public FinalClass { };
```

### 4. 纯虚函数与虚析构函数

```cpp
class AbstractBase {
public:
    virtual void pureVirtual() = 0;  // 纯虚函数
    virtual ~AbstractBase() {}       // 虚析构函数
};
```

### 5. 虚析构函数的重要性

```cpp
#include <iostream>

class Base {
public:
    Base() { std::cout << "Base()\n"; }
    ~Base() { std::cout << "~Base()\n"; }  // 非虚析构
};

class Derived : public Base {
public:
    Derived() { data = new int[100]; }
    ~Derived() {                     // 非虚析构
        delete[] data;
        std::cout << "~Derived()\n";
    }
private:
    int* data;
};

int main() {
    Base* p = new Derived();
    delete p;  // ❌ 只会调用 Base 的析构函数！
    // Derived 的析构函数不会调用，data 内存泄漏！

    return 0;
}
```

```cpp
// ✅ 正确做法：基类析构函数声明为虚函数
class Base {
public:
    virtual ~Base() = default;  // 虚析构函数
};

class Derived : public Base {
    // ...
};
```

### 6. 虚函数注意事项

```cpp
class Base {
public:
    virtual void func() { std::cout << "Base\n"; }
};

class Derived : public Base {
public:
    void func() override { std::cout << "Derived\n"; }
};

int main() {
    // 情况1：通过引用/指针调用 → 多态
    Derived d;
    Base& ref = d;
    Base* ptr = &d;
    ref.func();   // Derived ✅ 多态
    ptr->func();  // Derived ✅ 多态

    // 情况2：通过对象调用 → 静态绑定
    Base b = d;   // 对象切片！d 的 Derived 部分被切掉了
    b.func();     // Base ❌ 调用了基类版本

    // 情况3：构造函数和析构函数中调用虚函数
    // 不会发生多态，因为对象类型在构造/析构过程中会变化

    // 情况4：静态函数不能是虚函数
    // static virtual void staticFunc();  // ❌ 编译错误

    return 0;
}
```

## 4. 抽象类

### 1. 纯虚函数

```cpp
class Shape {
public:
    virtual double area() const = 0;     // 纯虚函数
    virtual double perimeter() const = 0; // 纯虚函数
    virtual ~Shape() = default;
};
```

### 2. 抽象类

```cpp
// 抽象类：包含纯虚函数的类
// 不能实例化，只能作为基类
class Shape {
public:
    virtual double area() const = 0;
    virtual void draw() const = 0;
    virtual ~Shape() = default;
};

// ❌ 编译错误：不能实例化抽象类
// Shape s;

// 具体类：实现了所有纯虚函数
class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() const override {
        return 3.14159 * radius * radius;
    }
    void draw() const override {
        std::cout << "Drawing circle\n";
    }
};

class Rectangle : public Shape {
private:
    double width, height;
public:
    Rectangle(double w, double h) : width(w), height(h) {}
    double area() const override {
        return width * height;
    }
    void draw() const override {
        std::cout << "Drawing rectangle\n";
    }
};
```

### 3. 抽象类的用途

```cpp
#include <memory>  // 智能指针所需头文件
// 通过基类指针/引用操作所有派生类对象
void printArea(const Shape& shape) {
    std::cout << "Area: " << shape.area() << std::endl;
}

int main() {
    Circle circle(5.0);
    Rectangle rect(4.0, 6.0);

    printArea(circle);   // Area: 78.5397
    printArea(rect);     // Area: 24

    // 可以创建基类指针数组
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Circle>(3.0));
    shapes.push_back(std::make_unique<Rectangle>(4.0, 5.0));

    for (const auto& shape : shapes) {
        shape->draw();
        std::cout << "Area: " << shape->area() << std::endl;
    }

    return 0;
}
```

### 4. 接口类

```cpp
// C++中的"接口"：只有纯虚函数的抽象类
class Drawable {
public:
    virtual void draw() const = 0;
    virtual ~Drawable() = default;
};

class Serializable {
public:
    virtual void serialize(std::ostream& os) const = 0;
    virtual void deserialize(std::istream& is) = 0;
    virtual ~Serializable() = default;
};

// 一个类可以实现多个"接口"
class MyClass : public Drawable, public Serializable {
public:
    void draw() const override {
        std::cout << "Drawing MyClass\n";
    }
    void serialize(std::ostream& os) const override {
        os << "MyClass data";
    }
    void deserialize(std::istream& is) override {
        // 读取数据
    }
};
```

## 5. RTTI

### 1. typeid运算符

```cpp
#include <iostream>
#include <typeinfo>

class Base { virtual void func() {} };
class Derived : public Base {};

int main() {
    Base* basePtr = new Derived();

    // typeid 返回 type_info 对象
    const std::type_info& type = typeid(*basePtr);
    std::cout << type.name() << std::endl;  // 实现定义的类型名

    // 类型比较
    if (typeid(*basePtr) == typeid(Derived)) {
        std::cout << "It's a Derived object\n";
    }

    delete basePtr;
    return 0;
}
```

### 2. dynamic_cast

```cpp
#include <iostream>

class Base { virtual void func() {} };
class Derived : public Base {
public:
    void derivedMethod() {
        std::cout << "Derived method\n";
    }
};
class AnotherClass : public Base {};

int main() {
    Base* basePtr = new Derived();

    // 向下转型（downcasting）
    if (Derived* derivedPtr = dynamic_cast<Derived*>(basePtr)) {
        derivedPtr->derivedMethod();  // ✅ 转型成功
    } else {
        std::cout << "Cast failed\n";
    }

    // 转型失败返回 nullptr
    Base* another = new AnotherClass();
    if (Derived* dp = dynamic_cast<Derived*>(another)) {
        dp->derivedMethod();  // ❌ 不会执行
    } else {
        std::cout << "Cast to Derived failed\n";
    }

    // dynamic_cast 引用版本：失败抛出异常
    Base& ref = *another;
    try {
        Derived& dref = dynamic_cast<Derived&>(ref);
        dref.derivedMethod();
    } catch (const std::bad_cast& e) {
        std::cout << "Bad cast: " << e.what() << std::endl;
    }

    // static_cast：不进行运行时检查，更快但不安全
    Derived* unsafePtr = static_cast<Derived*>(basePtr);  // ✅ 编译通过
    // 但类型错误时不会检测到，可能导致未定义行为

    delete another;
    delete basePtr;
    return 0;
}
```

### 3. RTTI开销

| 操作 | 开销 | 说明 |
|------|------|------|
| typeid | 小 | 读取vtable中的类型信息 |
| dynamic_cast | 较大 | 遍历继承体系，运行时检查 |
| static_cast | 无 | 编译时转换，无运行时开销 |

## 6. 多重继承

### 1. 多重继承语法

```cpp
class Base1 {
public:
    void func1() {}
};

class Base2 {
public:
    void func2() {}
};

class Derived : public Base1, public Base2 {
    // 继承 Base1 和 Base2 的所有成员
};
```

### 2. 钻石继承问题

```cpp
// 钻石继承（菱形继承）
class GrandParent {
public:
    int data;
};

class Parent1 : public GrandParent {};
class Parent2 : public GrandParent {};

class Child : public Parent1, public Parent2 {
    // Child 中有两份 GrandParent 的 data
    // 访问 data 时会产生二义性
};

int main() {
    Child c;
    // c.data = 42;      // ❌ 二义性：访问哪个 data？
    c.Parent1::data = 42; // ✅ 指定路径
    c.Parent2::data = 24; // ✅ 另一份 data
    return 0;
}
```

### 3. 虚继承解决钻石问题

```cpp
class GrandParent {
public:
    int data;
};

class Parent1 : virtual public GrandParent {};
class Parent2 : virtual public GrandParent {};

class Child : public Parent1, public Parent2 {
    // 虚继承后，Child 中只有一份 GrandParent 的 data
};

int main() {
    Child c;
    c.data = 42;  // ✅ 没有二义性
    return 0;
}
```

### 4. 多重继承的适用场景

```cpp
// ✅ mixin 模式：通过多重继承组合功能
class Printable {
public:
    virtual void print() const = 0;
    virtual ~Printable() = default;
};

class Serializable {
public:
    virtual void serialize(std::ostream& os) const = 0;
    virtual ~Serializable() = default;
};

class Loggable {
public:
    virtual void log() const = 0;
    virtual ~Loggable() = default;
};

// 组合多个功能
class Document : public Printable, public Serializable, public Loggable {
    void print() const override { /* 打印实现 */ }
    void serialize(std::ostream& os) const override { /* 序列化 */ }
    void log() const override { /* 日志实现 */ }
};
```

## 7. 继承设计原则

### 1. 常见错误

```cpp
// ❌ 错误1：将非虚函数声明为虚函数
class Container {
public:
    virtual void add(int value);  // 不需要虚函数
};

// ❌ 错误2：继承不是为复用而设计的类
class Database {
public:
    void connect();
    void query();
};

class MyDatabase : public Database {  // ❌ 应该用组合
    // ...
};

// ❌ 错误3：继承层次过深
class A {};
class B : public A {};
class C : public B {};
class D : public C {};  // 4层继承，难以维护
```

### 2. 设计原则

| 原则 | 说明 |
|------|------|
| LSP（里氏替换） | 派生类必须能替换基类 |
| OCP（开闭原则） | 对扩展开放，对修改关闭 |
| 优先组合 | 组合优于继承 |
| 接口隔离 | 小而专的接口优于大而全的接口 |

### 3. 何时使用继承

| 使用场景 | 说明 | 示例 |
|---------|------|------|
| is-a关系 | 派生类是基类的一种 | Dog is-a Animal |
| 需要多态 | 通过基类接口操作派生类 | Shape → Circle/Rectangle |
| 代码复用 | 共享接口和实现 | 框架类继承 |
| 模板方法 | 固定算法骨架，子类实现细节 | 钩子函数 |

### 4. 何时避免继承

| 避免场景 | 替代方案 |
|---------|---------|
| 仅为复用代码 | 组合 |
| has-a关系 | 组合 |
| 不满足LSP | 重新设计 |
| 继承层次过深 | 扁平化设计 |

## 8. 本章小结

### 1. 核心知识点

| 概念 | 说明 | 关键点 |
|------|------|-------|
| 继承 | 派生类继承基类成员 | 三种继承方式，构造/析构顺序 |
| 多态 | 同一接口多种实现 | 虚函数、vtable、动态绑定 |
| 抽象类 | 包含纯虚函数的类 | 不能实例化，定义接口 |
| RTTI | 运行时类型识别 | typeid、dynamic_cast |
| 多重继承 | 一个类继承多个基类 | 钻石问题、虚继承 |

### 2. 最佳实践

1. 基类析构函数声明为 virtual
2. 重写虚函数使用 override 关键字
3. 优先使用组合而非继承
4. 避免过深的继承层次
5. 使用抽象类定义接口
6. 谨慎使用多重继承
