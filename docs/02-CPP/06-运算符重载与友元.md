# 运算符重载与友元

> C++运算符重载机制与友元访问控制

---

> **The goal of operator overloading is to make user-defined types behave like built-in types.** — Bjarne Stroustrup
> （运算符重载的目标是让用户自定义类型像内置类型一样工作。）

> **运算符重载是语法糖，不是魔法——它只是函数调用的另一种写法。**
> （Operator overloading is syntactic sugar, not magic—it's just another way to write a function call.）

---

> **🎯 让代码像自然语言一样流畅。**
>
> （学会运算符重载，让你的类像内置类型一样好用。）

---

> 💡 **通俗理解 - 什么是运算符重载？**
>
> 运算符重载就是让自定义类型也能用 `+`、`-`、`==`、`<<` 等运算符，就像内置类型一样自然。
> 比如 `Complex(1,2) + Complex(3,4)` 能直接做复数加法，而不必写 `c1.add(c2)`。
>
> 本质：运算符重载是**编译期多态**的一种——同一个运算符对不同类型有不同行为。

## 1. 运算符重载

### 1. 可重载与不可重载运算符

#### 1. 可重载的运算符

| 分类 | 运算符 |
| --- | --- |
| 算术 | `+` `-` `*` `/` `%` `^` `&` `\|` `~` `!` |
| 比较 | `==` `!=` `<` `>` `<=` `>=` `<=>`(C++20) |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` `^=` `&=` `\|=` |
| 移位 | `<<` `>>` `>>=` `<<=` |
| 自增自减 | `++` `--` |
| 成员访问 | `->` `->*` `[]` `()` |
| 其他 | `,` `new` `delete` `new[]` `delete[]` |

#### 2. 不可重载的运算符

| 运算符 | 含义 | 原因 |
| --- | --- | --- |
| `.` | 成员访问 | 保证语义唯一性 |
| `.*` | 成员指针访问 | 保证语义唯一性 |
| `::` | 作用域解析 | 语言核心机制 |
| `?:` | 三目条件 | 语义无法自定义 |
| `sizeof` | 大小计算 | 编译期内置 |
| `typeid` | 类型信息 | 编译期内置 |
| `alignof` | 对齐要求 | 编译期内置 |

> ⚠️ **重要限制**：
> - 不能改变运算符的**操作数个数**（`+`始终是二元）
> - 不能改变运算符的**优先级和结合性**
> - 不能发明新的运算符（如 `**`）
> - 不能重载内置类型的运算符（`int + int` 不可改变）

### 2. 运算符重载的三种形式

#### 1. 成员函数

左操作数是 `*this`，参数比运算符操作数少一个。

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    Complex operator+(const Complex& rhs) const {
        return Complex(real + rhs.real, imag + rhs.imag);
    }
};

Complex a(1, 2), b(3, 4);
Complex c = a + b;
```

#### 2. 友元函数

左右操作数都是参数，支持左操作数的隐式类型转换。

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    friend Complex operator+(const Complex& lhs, const Complex& rhs) {
        return Complex(lhs.real + rhs.real, lhs.imag + rhs.imag);
    }
};

Complex a(1, 2);
Complex c = a + 3.0;  // 成员函数：3.0不能在左侧
Complex d = 3.0 + a;  // 友元函数：3.0隐式转换为Complex，可以在左侧
```

#### 3. 普通函数

与友元函数类似，但只能通过公有接口访问成员。

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
};

Complex operator+(const Complex& lhs, const Complex& rhs) {
    return Complex(lhs.real + rhs.real, lhs.imag + rhs.imag);
}
```

#### 4. 选择原则

| 运算符 | 推荐形式 | 原因 |
| --- | --- | --- |
| `=` `()` `[]` `->` | **必须**成员函数 | 语言规定 |
| `+=` `-=` `*=` 等 | 成员函数 | 修改左操作数 |
| `+` `-` `*` `/` | 非成员函数（友元） | 支持左操作数类型转换 |
| `==` `<` `!=` 等 | 非成员函数（友元） | 对称性，支持双向转换 |
| `<<` `>>` | 非成员函数（友元） | 左操作数是流，不是本类 |
| `++` `--` | 成员函数 | 修改自身 |
| 类型转换 | 成员函数 | 语言规定 |

### 3. 常用运算符重载详解

#### 1. 算术运算符（+, -, *, /）

以复数 `Complex` 类为例，算术运算符建议用**非成员友元函数**实现，以支持左操作数类型转换。

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    friend Complex operator+(const Complex& a, const Complex& b) {
        return Complex(a.real + b.real, a.imag + b.imag);
    }

    friend Complex operator-(const Complex& a, const Complex& b) {
        return Complex(a.real - b.real, a.imag - b.imag);
    }

    friend Complex operator*(const Complex& a, const Complex& b) {
        return Complex(a.real * b.real - a.imag * b.imag,
                       a.real * b.imag + a.imag * b.real);
    }

    friend Complex operator/(const Complex& a, const Complex& b) {
        double denom = b.real * b.real + b.imag * b.imag;
        return Complex((a.real * b.real + a.imag * b.imag) / denom,
                       (a.imag * b.real - a.real * b.imag) / denom);
    }

    // 一元负号
    Complex operator-() const {
        return Complex(-real, -imag);
    }

    // 一元正号（通常很少重载，但可以用于一致性）
    Complex operator+() const {
        return *this;
    }
};

Complex a(1, 2), b(3, 4);
Complex c = a + b;      // (4, 6)
Complex d = 2.0 * a;    // 左操作数2.0隐式转换，(2, 4)
Complex e = a * 3.0;    // 右操作数3.0隐式转换，(3, 6)
```

> 💡 **复合赋值运算符**（`+=`、`-=`等）建议用**成员函数**，因为它们修改 `*this`：

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    Complex& operator+=(const Complex& rhs) {
        real += rhs.real;
        imag += rhs.imag;
        return *this;
    }

    Complex& operator-=(const Complex& rhs) {
        real -= rhs.real;
        imag -= rhs.imag;
        return *this;
    }
};

// 用复合赋值实现算术运算符（推荐模式）
Complex operator+(Complex a, const Complex& b) {
    a += b;   // 复用 operator+=
    return a; // 返回副本（a是值传递的副本）
}
```

#### 2. 比较运算符（==, !=, <, >, <=, >=）

**传统写法**：需要逐一实现六个运算符。

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    friend bool operator==(const Complex& a, const Complex& b) {
        return a.real == b.real && a.imag == b.imag;
    }

    friend bool operator!=(const Complex& a, const Complex& b) {
        return !(a == b);  // 复用 operator==
    }

    // 按模长比较
    friend bool operator<(const Complex& a, const Complex& b) {
        return (a.real * a.real + a.imag * a.imag) <
               (b.real * b.real + b.imag * b.imag);
    }

    friend bool operator>(const Complex& a, const Complex& b) {
        return b < a;  // 复用 operator<
    }

    friend bool operator<=(const Complex& a, const Complex& b) {
        return !(b < a);
    }

    friend bool operator>=(const Complex& a, const Complex& b) {
        return !(a < b);
    }
};
```

**C++20 三向比较运算符**（`<=>`，太空船运算符）：一个运算符自动生成全部六个比较运算符。

```cpp
#include <compare>

class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // 三向比较：自动生成 ==, !=, <, >, <=, >=
    friend std::partial_ordering operator<=>(const Complex& a, const Complex& b) {
        double mod_a = a.real * a.real + a.imag * a.imag;
        double mod_b = b.real * b.real + b.imag * b.imag;
        return mod_a <=> mod_b;  // 浮点数用 partial_ordering
    }

    // C++20中 == 和 != 不再需要单独声明友元，<=>会自动生成
    // 但如果需要精确比较（而非按模长），可以单独定义 operator==
    friend bool operator==(const Complex& a, const Complex& b) {
        return a.real == b.real && a.imag == b.imag;
    }
};
```

**三向比较的返回类型**：

| 返回类型 | 含义 | 适用场景 |
| --- | --- | --- |
| `strong_ordering` | 全序，等价即相等 | 整数、字符串 |
| `weak_ordering` | 全序，等价未必相等 | 大小写不敏感比较 |
| `partial_ordering` | 偏序，可能有不可比 | 浮点数（NaN） |

```cpp
// 最简单的用法：使用 = default
class Value {
public:
    int v;
    auto operator<=>(const Value&) const = default;  // 自动按成员逐个比较
};
```

#### 3. 赋值运算符（operator=）

赋值运算符**必须**用成员函数实现，分为拷贝赋值和移动赋值。

```cpp
class Buffer {
private:
    int* data;
    size_t size;

public:
    Buffer(size_t s = 0) : data(s ? new int[s]() : nullptr), size(s) {}
    ~Buffer() { delete[] data; }

    // 拷贝赋值
    Buffer& operator=(const Buffer& other) {
        if (this != &other) {              // 自赋值检查
            int* newData = other.size ? new int[other.size]() : nullptr;
            std::copy(other.data, other.data + other.size, newData);
            delete[] data;                 // 释放旧资源
            data = newData;
            size = other.size;
        }
        return *this;                      // 返回 *this 支持链式赋值
    }

    // 移动赋值
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data;                 // 释放旧资源
            data = other.data;             // 窃取资源
            size = other.size;
            other.data = nullptr;          // 置空源对象
            other.size = 0;
        }
        return *this;
    }
};

Buffer a(10), b(20);
a = b;                    // 拷贝赋值
a = Buffer(30);           // 移动赋值（临时对象是右值）
a = a;                    // 自赋值安全
```

> ⚠️ **拷贝赋值的自赋值检查至关重要**，否则 `a = a` 会先释放自己的数据，再拷贝已释放的数据。

#### 4. 下标运算符（operator[]）

下标运算符**必须**用成员函数实现，通常提供两个版本：**只读版本**（const）和**读写版本**（非const）。

```cpp
class IntArray {
private:
    int* data;
    size_t len;

public:
    IntArray(size_t n) : data(new int[n]()), len(n) {}
    ~IntArray() { delete[] data; }

    // 读写版本：返回引用，可以 arr[i] = value
    int& operator[](size_t index) {
        return data[index];
    }

    // 只读版本：const对象调用，不能修改
    const int& operator[](size_t index) const {
        return data[index];
    }

    size_t size() const { return len; }
};

IntArray arr(5);
arr[2] = 42;                // 调用非const版本

const IntArray& carr = arr;
int val = carr[2];           // 调用const版本
// carr[2] = 10;             // 编译错误！const版本返回const引用
```

> 💡 **C++23 `operator[]` 支持多参数**：
> ```cpp
> // C++23之前：只能单参数，多下标用 operator()
> // C++23：operator[] 可以接受多个参数
> double& operator[](size_t row, size_t col);  // C++23合法
> ```

#### 5. 函数调用运算符（operator()）

函数调用运算符**必须**用成员函数实现。重载了 `operator()` 的类对象称为**仿函数（functor）**，可以像函数一样被调用。

```cpp
// 仿函数：带状态的"函数"
class Multiplier {
private:
    int factor;
public:
    Multiplier(int f) : factor(f) {}
    int operator()(int x) const {
        return x * factor;
    }
};

Multiplier triple(3);
int result = triple(10);   // 调用 operator()，结果为30

// 仿函数的优势：可以保存状态
class Counter {
private:
    int count = 0;
public:
    int operator()() {
        return ++count;
    }
};

Counter cnt;
cnt();  // 返回1
cnt();  // 返回2
cnt();  // 返回3

// 多参数版本
class Adder {
public:
    int operator()(int a, int b) const {
        return a + b;
    }
};

Adder add;
int sum = add(3, 5);  // 结果为8
```

> 💡 **Lambda的底层就是仿函数**：
> ```cpp
> // Lambda表达式
> auto lambda = [factor](int x) { return x * factor; };
>
> // 编译器生成的仿函数（大致等价）
> class __Lambda {
>     int factor;
> public:
>     __Lambda(int f) : factor(f) {}
>     int operator()(int x) const { return x * factor; }
> };
> ```

#### 6. 类型转换运算符

类型转换运算符**必须**用成员函数实现，将本类对象隐式转换为目标类型。

```cpp
class Fraction {
private:
    int numerator;
    int denominator;
public:
    Fraction(int n, int d = 1) : numerator(n), denominator(d) {}

    // 隐式转换为double
    operator double() const {
        return static_cast<double>(numerator) / denominator;
    }

    // 隐式转换为bool（如用于条件判断）
    operator bool() const {
        return numerator != 0;
    }
};

Fraction f(3, 4);
double d = f;          // 隐式转换：0.75
if (f) { /* ... */ }   // 隐式转换为bool
```

**问题**：隐式转换可能导致意外行为。C++11 引入 `explicit` 修饰转换运算符。

```cpp
class SafeBool {
private:
    int value;
public:
    SafeBool(int v) : value(v) {}

    // explicit：禁止隐式转换，只允许显式转换
    explicit operator bool() const {
        return value != 0;
    }
};

SafeBool sb(1);
if (sb) { /* ... */ }     // OK：if条件允许显式bool转换
int n = sb;                // 编译错误！禁止隐式转换
int m = static_cast<bool>(sb);  // OK：显式转换
```

> ⚠️ **最佳实践**：类型转换运算符应尽量使用 `explicit`，避免隐式转换带来的歧义和意外。

#### 7. 自增/自减运算符（++, --）

前置和后置通过**参数区分**：后置版本接受一个 `int` 哑元参数（不被使用）。

```cpp
class Counter {
private:
    int value;
public:
    Counter(int v = 0) : value(v) {}

    // 前置 ++x：返回修改后的引用
    Counter& operator++() {
        ++value;
        return *this;
    }

    // 后置 x++：返回修改前的副本，int是哑元参数用于区分
    Counter operator++(int) {
        Counter temp = *this;  // 保存旧值
        ++value;               // 修改
        return temp;           // 返回旧值
    }

    // 前置 --x
    Counter& operator--() {
        --value;
        return *this;
    }

    // 后置 x--
    Counter operator--(int) {
        Counter temp = *this;
        --value;
        return temp;
    }

    int get() const { return value; }
};

Counter c(5);
Counter c1 = ++c;  // c变为6，c1为6（前置返回引用）
Counter c2 = c++;  // c变为7，c2为6（后置返回旧值副本）
```

> 💡 **前置 vs 后置**：
> - 前置返回引用，效率更高（无拷贝）
> - 后置返回副本，需要额外拷贝
> - 对于迭代器等复杂类型，**优先使用前置 `++i`**

#### 8. 流插入/提取运算符（<<, >>）

流运算符**必须**用非成员函数实现，因为左操作数是 `std::ostream`/`std::istream`，不是本类。

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // 流插入：std::ostream& operator<<(std::ostream&, const Complex&)
    friend std::ostream& operator<<(std::ostream& os, const Complex& c) {
        os << c.real;
        if (c.imag >= 0) os << " + " << c.imag << "i";
        else os << " - " << -c.imag << "i";
        return os;  // 返回流的引用，支持链式调用
    }

    // 流提取：std::istream& operator>>(std::istream&, Complex&)
    friend std::istream& operator>>(std::istream& is, Complex& c) {
        is >> c.real >> c.imag;
        return is;
    }
};

Complex c(3, -4);
std::cout << c << std::endl;          // 输出：3 - 4i
std::cout << c << " " << c;           // 链式调用

Complex input;
std::cin >> input;                     // 输入两个数
```

> 💡 **为什么返回流的引用？** 为了支持 `std::cout << a << b << c;` 这种链式调用。

#### 9. 箭头运算符（operator->）

箭头运算符**必须**用成员函数实现，是智能指针的底层机制。`operator->` 返回一个指针，编译器会自动对该指针再次应用 `->`。

```cpp
template<typename T>
class SmartPtr {
private:
    T* ptr;
public:
    SmartPtr(T* p = nullptr) : ptr(p) {}
    ~SmartPtr() { delete ptr; }

    // 箭头运算符：返回指针，编译器自动解引用
    T* operator->() const {
        return ptr;
    }

    // 解引用运算符
    T& operator*() const {
        return *ptr;
    }

    // bool转换：判断是否为空
    explicit operator bool() const {
        return ptr != nullptr;
    }
};

class Person {
public:
    std::string name;
    int age;
    void greet() { std::cout << "Hi, I'm " << name << std::endl; }
};

SmartPtr<Person> sp(new Person{"Alice", 25});
sp->name = "Bob";       // sp.operator->() 返回 Person*，然后 ->name
sp->greet();            // sp.operator->() 返回 Person*，然后 ->greet()
(*sp).age = 30;         // sp.operator*() 返回 Person&

if (sp) { /* ... */ }   // explicit operator bool()
```

> 💡 **`operator->` 的重载规则**：如果返回类型本身也重载了 `operator->`，编译器会**递归调用**直到返回原始指针。这是实现代理模式和智能指针链的关键机制。

### 4. 运算符重载的设计原则

#### 1. 原则一：保持语义一致性

重载后的运算符应该与内置类型的语义一致，让用户能直觉地理解。

```cpp
// 好的设计：+ 做加法
Complex operator+(const Complex& a, const Complex& b);

// 糟糕的设计：+ 做减法（违反直觉）
Complex operator+(const Complex& a, const Complex& b) {
    return Complex(a.real - b.real, a.imag - b.imag);  // 不要这样做！
}
```

#### 2. 原则二：尊重操作数个数和优先级

不能改变运算符的固有属性：

```cpp
// 不能把二元运算符变成一元的
Complex operator+();  // 编译错误：operator+ 必须有一个参数（成员函数）或两个参数（友元）

// 不能改变优先级
// a + b * c 永远先算 *，不管你怎么重载
```

#### 3. 原则三：对称运算符用非成员函数

对于 `+`、`==`、`<` 等对称运算符，使用非成员函数确保左右操作数都能隐式转换：

```cpp
class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // 成员函数方式：3.0 + a 会失败
    // Complex operator+(const Complex& rhs) const;

    // 友元函数方式：3.0 + a 和 a + 3.0 都可以
    friend Complex operator+(const Complex& a, const Complex& b);
};

Complex a(1, 2);
Complex r1 = a + 3.0;   // OK：3.0隐式转换为Complex(3, 0)
Complex r2 = 3.0 + a;   // 友元函数OK，成员函数编译错误
```

#### 4. 原则四：赋值/下标/箭头/调用用成员函数

这些运算符与对象自身紧密相关，且语言规定必须为成员函数：

| 运算符 | 必须成员函数的原因 |
| --- | --- |
| `=` | 修改左操作数，语言规定必须成员 |
| `()` | 函数调用语义，语言规定必须成员 |
| `[]` | 下标访问语义，语言规定必须成员 |
| `->` | 成员访问语义，语言规定必须成员 |

#### 5. 原则五：不要滥用运算符重载

如果运算符的语义不够直观，使用普通函数更清晰：

```cpp
// 合理的重载：矩阵乘法用 * 很自然
Matrix operator*(const Matrix& a, const Matrix& b);

// 不合理的重载：用 % 做字符串拼接？太牵强了
// string operator%(const string& a, const string& b);  // 不要这样做
// 用普通函数更好：
string concatenate(const string& a, const string& b);
```

### 5. 完整的Complex类示例

以下是一个包含所有常用运算符重载的完整可编译代码：

```cpp
#include <iostream>
#include <cmath>
#include <compare>

class Complex {
private:
    double real;
    double imag;

public:
    // 构造函数
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // ========== 算术运算符 ==========
    friend Complex operator+(Complex a, const Complex& b) {
        a += b;
        return a;
    }

    friend Complex operator-(Complex a, const Complex& b) {
        a -= b;
        return a;
    }

    friend Complex operator*(Complex a, const Complex& b) {
        a *= b;
        return a;
    }

    friend Complex operator/(Complex a, const Complex& b) {
        a /= b;
        return a;
    }

    // 一元正号
    Complex operator+() const { return *this; }

    // 一元负号
    Complex operator-() const { return Complex(-real, -imag); }

    // ========== 复合赋值运算符 ==========
    Complex& operator+=(const Complex& rhs) {
        real += rhs.real;
        imag += rhs.imag;
        return *this;
    }

    Complex& operator-=(const Complex& rhs) {
        real -= rhs.real;
        imag -= rhs.imag;
        return *this;
    }

    Complex& operator*=(const Complex& rhs) {
        double r = real * rhs.real - imag * rhs.imag;
        double i = real * rhs.imag + imag * rhs.real;
        real = r;
        imag = i;
        return *this;
    }

    Complex& operator/=(const Complex& rhs) {
        double denom = rhs.real * rhs.real + rhs.imag * rhs.imag;
        double r = (real * rhs.real + imag * rhs.imag) / denom;
        double i = (imag * rhs.real - real * rhs.imag) / denom;
        real = r;
        imag = i;
        return *this;
    }

    // ========== 比较运算符 ==========
    // 精确相等比较
    friend bool operator==(const Complex& a, const Complex& b) {
        return a.real == b.real && a.imag == b.imag;
    }

    friend bool operator!=(const Complex& a, const Complex& b) {
        return !(a == b);
    }

    // C++20三向比较（按模长排序）
    friend std::partial_ordering operator<=>(const Complex& a, const Complex& b) {
        return a.modulusSq() <=> b.modulusSq();
    }

    // ========== 下标运算符 ==========
    double& operator[](int index) {
        return index == 0 ? real : imag;
    }

    const double& operator[](int index) const {
        return index == 0 ? real : imag;
    }

    // ========== 自增/自减运算符 ==========
    Complex& operator++() {
        ++real;
        return *this;
    }

    Complex operator++(int) {
        Complex temp = *this;
        ++real;
        return temp;
    }

    Complex& operator--() {
        --real;
        return *this;
    }

    Complex operator--(int) {
        Complex temp = *this;
        --real;
        return temp;
    }

    // ========== 流运算符 ==========
    friend std::ostream& operator<<(std::ostream& os, const Complex& c) {
        os << c.real;
        if (c.imag >= 0) os << " + " << c.imag << "i";
        else os << " - " << -c.imag << "i";
        return os;
    }

    friend std::istream& operator>>(std::istream& is, Complex& c) {
        is >> c.real >> c.imag;
        return is;
    }

    // ========== 类型转换 ==========
    explicit operator double() const {
        return modulus();
    }

    explicit operator bool() const {
        return real != 0 || imag != 0;
    }

    // ========== 工具函数 ==========
    double modulus() const {
        return std::sqrt(real * real + imag * imag);
    }

    double modulusSq() const {
        return real * real + imag * imag;
    }

    Complex conjugate() const {
        return Complex(real, -imag);
    }
};

int main() {
    Complex a(3, 4), b(1, -2);

    // 算术运算
    std::cout << "a + b = " << a + b << std::endl;     // 4 + 2i
    std::cout << "a - b = " << a - b << std::endl;     // 2 + 6i
    std::cout << "a * b = " << a * b << std::endl;     // 11 - 2i
    std::cout << "a / b = " << a / b << std::endl;     // -0.5 + 2i
    std::cout << "-a = " << -a << std::endl;           // -3 - 4i

    // 复合赋值
    Complex c = a;
    c += b;
    std::cout << "a += b -> " << c << std::endl;       // 4 + 2i

    // 比较
    std::cout << std::boolalpha;
    std::cout << "a == b: " << (a == b) << std::endl;  // false
    Complex d(3, 4);
    std::cout << "a == d: " << (a == d) << std::endl;  // true

    // 下标
    std::cout << "a[0] = " << a[0] << std::endl;       // 3 (real)
    std::cout << "a[1] = " << a[1] << std::endl;       // 4 (imag)

    // 自增
    Complex e(1, 2);
    std::cout << "++e = " << ++e << std::endl;         // 2 + 2i
    std::cout << "e++ = " << e++ << std::endl;         // 2 + 2i（返回旧值）
    std::cout << "e = " << e << std::endl;             // 3 + 2i

    // 流输入
    Complex input;
    std::cout << "输入复数（实部 虚部）: ";
    // std::cin >> input;
    // std::cout << "你输入了: " << input << std::endl;

    // 类型转换
    std::cout << "a的模 = " << static_cast<double>(a) << std::endl;  // 5
    if (a) { std::cout << "a不为零" << std::endl; }

    // 左操作数类型转换
    Complex f = 2.0 + a;   // 2.0隐式转换为Complex(2, 0)
    std::cout << "2.0 + a = " << f << std::endl;       // 5 + 4i

    return 0;
}
```

### 6. 运算符重载速查表

| 运算符 | 形式 | 返回类型 | 示例 |
| --- | --- | --- | --- |
| `+` `-` `*` `/` | 非成员友元 | 新对象（值） | `Complex operator+(const Complex&, const Complex&)` |
| `+=` `-=` `*=` `/=` | 成员函数 | `*this`引用 | `Complex& operator+=(const Complex&)` |
| `==` `!=` `<` `>` | 非成员友元 | `bool` | `bool operator==(const Complex&, const Complex&)` |
| `<=>` | 非成员友元 | 排序类型 | `auto operator<=>(const T&, const T&)` |
| `=` | 成员函数 | `*this`引用 | `T& operator=(const T&)` |
| `[]` | 成员函数 | 元素引用 | `int& operator[](size_t)` |
| `()` | 成员函数 | 任意 | `int operator()(int)` |
| `++` `--`（前置） | 成员函数 | `*this`引用 | `T& operator++()` |
| `++` `--`（后置） | 成员函数 | 旧值副本 | `T operator++(int)` |
| `<<` `>>` | 非成员友元 | 流引用 | `ostream& operator<<(ostream&, const T&)` |
| `->` | 成员函数 | 指针 | `T* operator->()` |
| `*`（解引用） | 成员函数 | 引用 | `T& operator*()` |
| 类型转换 | 成员函数 | 目标类型 | `explicit operator bool()` |
| `-` `+`（一元） | 成员函数 | 新对象 | `Complex operator-() const` |

## 2. 移动语义详解

### 1. 左值与右值

```cpp
int x = 10;           // x是左值，10是右值
int& ref = x;         // 左值引用
int&& rref = 10;      // 右值引用

std::string s1 = "hello";
std::string s2 = std::move(s1);  // s1被移动后处于"有效但未指定（valid but unspecified）"的状态，不保证一定为空
```

### 2. std::move

```cpp
std::string str = "hello";
std::string moved = std::move(str);  // str被移动
// str现在是未定义状态
```

### 3. 完美转发

```cpp
template<typename T, typename Arg>
auto make(Arg&& arg) {
    return T(std::forward<Arg>(arg));
}
```

## 3. 友元详解

### 1. 友元函数

```cpp
class Point {
private:
    int x, y;
    
public:
    Point(int x, int y) : x(x), y(y) {}
    
    // 友元函数可以访问私有成员
    friend Point operator+(const Point& a, const Point& b) {
        return Point(a.x + b.x, a.y + b.y);
    }
    
    friend std::ostream& operator<<(std::ostream& os, const Point& p) {
        return os << "(" << p.x << ", " << p.y << ")";
    }
};
```

### 2. 友元类

```cpp
class A {
private:
    int secret;
    friend class B;  // B是A的友元类
};

class B {
public:
    void accessA(A& a) {
        a.secret = 10;  // 可以访问A的私有成员
    }
};
```

## 5. 问题解答

### 1. Q: 为什么要使用构造函数初始化列表？

A: 构造函数初始化列表可以直接初始化成员变量，避免先默认构造再赋值，提高效率。例如：

```cpp
class MyClass {
private:
    std::string name;
public:
    MyClass(const std::string& n) : name(n) {} // 直接初始化
    // MyClass(const std::string& n) { name = n; } // 先默认构造再赋值
};
```

### 2. Q: 为什么要将基类析构函数声明为虚函数？

A: 如果基类析构函数不是虚函数，当通过基类指针删除派生类对象时，只会调用基类析构函数，不会调用派生类析构函数，导致资源泄漏。

### 3. Q: 什么是 RAII 原则？

A: RAII（Resource Acquisition Is Initialization）是 C++ 中管理资源的核心原则，通过构造函数获取资源，析构函数释放资源，确保资源自动管理。

### 4. Q: 什么是 Rule of Three/Five？

A: Rule of Three 指如果类需要自定义析构函数、拷贝构造函数或拷贝赋值运算符，通常需要同时定义这三个。Rule of Five 是 C++11 引入移动语义后的扩展，增加了移动构造函数和移动赋值运算符。

### 5. Q: 什么时候使用友元？

A: 友元可以用于运算符重载（如 `<<`、`>>`）、访问私有成员进行测试等，但应谨慎使用，避免破坏封装性。

### 6. Q: 组合与继承的区别是什么？

A: 组合是 "has-a" 关系，继承是 "is-a" 关系。组合更灵活，继承更适合代码复用和多态。
