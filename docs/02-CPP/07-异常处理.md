想象你在做菜：

- 正常情况：按步骤做，最后端上美味的菜
- 但可能出问题：盐放多了、锅烧糊了、菜刀切到手了...

**传统做法（像C语言）：**

- 每一步都要检查"有没有问题？"
- 如果有问题，就返回"错误码"
- 代码里充满了 `if (error) return -1;`

**异常处理（像C++）：**

- 就像有个"紧急出口"
- 正常做菜，不用担心每一步
- 如果出了问题，按一下"紧急按钮"
- 有人会来帮你处理这个"紧急情况"

```
try {
    // 正常做菜的步骤
    做菜();
} catch (盐放多了) {
    // 加水稀释
} catch (锅烧糊了) {
    // 换个锅重新做
} catch (...) {
    // 未知问题，打电话找人帮忙
}
```

> 🔬 **抽象理解 - 错误处理范式的演进**：
>
> - **错误码**：是"返回值"方式，通过返回值表示成功或失败
> - **异常**：是"控制流"方式，通过throw抛出异常，catch捕获处理
> - **异常的价值**：是"分离错误处理逻辑"，让正常流程和错误处理分开
> - **栈展开**：异常抛出时，编译器会自动展开调用栈，寻找匹配的catch
> - **RAII与异常**：通过RAII（智能指针、析构函数）确保资源在异常时也能正确释放
> - **异常安全**：是"保证程序在异常情况下不会产生资源泄漏或数据损坏"

## 1. 异常处理基础

### 1. 概念与定义

**异常（exception）**：程序运行时发生的错误或意外情况。异常会打断正常的程序执行流程，需要使用异常处理机制来处理。

**异常处理（exception handling）**：C++中用于处理异常的机制。异常处理可以优雅地处理错误，提高程序健壮性。

**try块（try block）**：监控可能抛出异常的代码块。try块中的代码如果抛出异常，会被catch块捕获。例如`try { /* ... */ } catch (...) { /* ... */ }`。

**catch块（catch block）**：捕获并处理异常的代码块。catch块可以捕获特定类型的异常，也可以捕获所有类型的异常。例如`catch (const std::runtime_error& e) { /* ... */ }`。

**throw语句（throw statement）**：抛出异常的语句。throw语句可以抛出任何类型的异常，包括内置类型、自定义类型、标准异常类等。例如`throw std::runtime_error("Division by zero!");`。

**标准异常类（standard exception class）**：C++标准库中提供的异常类。标准异常类可以用于抛出常见的异常，例如`std::runtime_error`、`std::logic_error`、`std::invalid_argument`等。

**自定义异常类（custom exception class）**：用户自定义的异常类。自定义异常类可以用于抛出特定的异常，例如`class MyException : public std::exception { /* ... */ };`。

**异常安全（exception safety）**：程序在抛出异常时，不会出现资源泄漏、数据损坏等问题。异常安全可以分为基本异常安全、强异常安全、不抛异常安全。

**noexcept说明符（noexcept specifier）**：C++11引入的新特性，用于指定函数是否抛出异常。例如`void func() noexcept { /* ... */ }`表示函数`func`不会抛出异常。

### 2. 什么是异常

异常是程序运行时发生的错误或意外情况，它会打断正常的程序执行流程。C++提供了异常处理机制来优雅地处理这些错误。

### 4. 基本语法

```cpp
#include <iostream>
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0) {
        // 抛出异常：除数为0
        throw std::runtime_error("Division by zero!");
    }
    return a / b;
}

int main() {
    try {
        // try块：监控可能抛出异常的代码
        double result = divide(2.0, 0.0);
        std::cout << "Result: " << result << std::endl;
    }
    catch (const std::runtime_error& e) {
        // catch块：捕获并处理异常
        std::cerr << "Error: " << e.what() << std::endl;
    }
    catch (...) {
        // 捕获所有其他类型的异常
        std::cerr << "Unknown error occurred" << std::endl;
    }
    
    return 0;
}
```

### 5. 多个catch块

```cpp
#include <iostream>
#include <stdexcept>
#include <string>

void processValue(int value) {
    if (value < 0) {
        throw std::invalid_argument("Value cannot be negative");
    }
    if (value > 100) {
        throw std::out_of_range("Value exceeds maximum limit");
    }
    if (value == 0) {
        throw 42;  // 可以抛出任意类型
    }
}

int main() {
    try {
        processValue(-5);
    }
    // catch块必须按从具体到一般的顺序排列
    catch (const std::invalid_argument& e) {
        std::cerr << "Invalid argument: " << e.what() << std::endl;
    }
    catch (const std::out_of_range& e) {
        std::cerr << "Out of range: " << e.what() << std::endl;
    }
    catch (const std::exception& e) {
        // 捕获所有标准异常
        std::cerr << "Standard exception: " << e.what() << std::endl;
    }
    catch (int errorCode) {
        // 捕获整数类型的异常
        std::cerr << "Error code: " << errorCode << std::endl;
    }
    catch (...) {
        // 捕获所有其他异常（必须放在最后）
        std::cerr << "Unknown exception" << std::endl;
    }
    
    return 0;
}
```

### 6. 异常的传播

```cpp
#include <iostream>
#include <stdexcept>

// 第三层函数：抛出异常
void level3() {
    std::cout << "Level 3: Throwing exception..." << std::endl;
    throw std::runtime_error("Error in level 3");
}

// 第二层函数：不处理异常，向上传播
void level2() {
    std::cout << "Level 2: Calling level3..." << std::endl;
    level3();  // 异常会传播到调用者
    std::cout << "Level 2: This won't be executed" << std::endl;
}

// 第一层函数：捕获异常
void level1() {
    std::cout << "Level 1: Calling level2..." << std::endl;
    try {
        level2();
    }
    catch (const std::runtime_error& e) {
        std::cout << "Level 1: Caught exception: " << e.what() << std::endl;
    }
}

int main() {
    level1();
    std::cout << "Program continues..." << std::endl;
    return 0;
}

/*
输出：
Level 1: Calling level2...
Level 2: Calling level3...
Level 3: Throwing exception...
Level 1: Caught exception: Error in level 3
Program continues...
*/
```

### 3. 使用标准异常示例

```cpp
#include <iostream>
#include <stdexcept>
#include <vector>
#include <string>

class StudentManager {
private:
    std::vector<std::string> students;
    
public:
    void addStudent(const std::string& name) {
        // 检查参数有效性
        if (name.empty()) {
            throw std::invalid_argument("Student name cannot be empty");
        }
        
        // 检查容器大小
        if (students.size() >= 100) {
            throw std::length_error("Maximum number of students reached");
        }
        
        students.push_back(name);
    }
    
    std::string getStudent(size_t index) {
        // 检查索引范围
        if (index >= students.size()) {
            throw std::out_of_range("Student index out of range");
        }
        return students[index];
    }
    
    double calculateAverage() {
        if (students.empty()) {
            throw std::logic_error("No students to calculate average");
        }
        // ... 计算逻辑
        return 0.0;
    }
};

int main() {
    StudentManager manager;
    
    try {
        manager.addStudent("");  // 抛出 invalid_argument
    }
    catch (const std::invalid_argument& e) {
        std::cerr << "Invalid argument: " << e.what() << std::endl;
    }
    
    try {
        manager.getStudent(5);  // 抛出 out_of_range
    }
    catch (const std::out_of_range& e) {
        std::cerr << "Out of range: " << e.what() << std::endl;
    }
    
    try {
        manager.calculateAverage();  // 抛出 logic_error
    }
    catch (const std::logic_error& e) {
        std::cerr << "Logic error: " << e.what() << std::endl;
    }
    
    return 0;
}
```

## 3. 自定义异常类

### 1. 基本自定义异常

```cpp
#include <iostream>
#include <exception>
#include <string>

// 自定义异常类：继承自 std::exception
class FileException : public std::exception {
private:
    std::string message;
    
public:
    // 构造函数：接收错误消息
    explicit FileException(const std::string& msg) 
        : message(msg) {}
    
    // 重写 what() 方法：返回错误描述
    const char* what() const noexcept override {
        return message.c_str();
    }
};

// 更具体的异常类
class FileNotFoundException : public FileException {
public:
    explicit FileNotFoundException(const std::string& filename)
        : FileException("File not found: " + filename) {}
};

class FilePermissionException : public FileException {
public:
    explicit FilePermissionException(const std::string& filename)
        : FileException("Permission denied: " + filename) {}
};

// 使用示例
void openFile(const std::string& filename) {
    if (filename.empty()) {
        throw FileException("Filename cannot be empty");
    }
    if (filename == "secret.txt") {
        throw FilePermissionException(filename);
    }
    if (filename == "missing.txt") {
        throw FileNotFoundException(filename);
    }
    
    std::cout << "File opened: " << filename << std::endl;
}

int main() {
    try {
        openFile("secret.txt");
    }
    catch (const FileNotFoundException& e) {
        std::cerr << "File not found: " << e.what() << std::endl;
    }
    catch (const FilePermissionException& e) {
        std::cerr << "Permission error: " << e.what() << std::endl;
    }
    catch (const FileException& e) {
        std::cerr << "File error: " << e.what() << std::endl;
    }
    
    return 0;
}
```

### 2. 带错误码的异常类

```cpp
#include <iostream>
#include <exception>
#include <string>
#include <map>

// 带错误码的异常类
class DatabaseException : public std::exception {
private:
    int errorCode;
    std::string message;
    
public:
    // 错误码枚举
    enum ErrorCode {
        CONNECTION_FAILED = 1001,
        QUERY_ERROR = 1002,
        DUPLICATE_ENTRY = 1003,
        TIMEOUT = 1004
    };
    
    DatabaseException(ErrorCode code, const std::string& msg)
        : errorCode(code), message(msg) {}
    
    const char* what() const noexcept override {
        return message.c_str();
    }
    
    int getErrorCode() const {
        return errorCode;
    }
    
    // 获取错误描述
    std::string getErrorDescription() const {
        static const std::map<int, std::string> errorDescriptions = {
            {CONNECTION_FAILED, "Failed to connect to database"},
            {QUERY_ERROR, "Query execution failed"},
            {DUPLICATE_ENTRY, "Duplicate entry found"},
            {TIMEOUT, "Operation timed out"}
        };
        
        auto it = errorDescriptions.find(errorCode);
        if (it != errorDescriptions.end()) {
            return it->second;
        }
        return "Unknown error";
    }
};

// 使用示例
void connectDatabase(const std::string& host) {
    if (host.empty()) {
        throw DatabaseException(
            DatabaseException::CONNECTION_FAILED,
            "Database host is empty"
        );
    }
    
    if (host == "timeout.server") {
        throw DatabaseException(
            DatabaseException::TIMEOUT,
            "Connection timeout after 30 seconds"
        );
    }
    
    std::cout << "Connected to database: " << host << std::endl;
}

int main() {
    try {
        connectDatabase("timeout.server");
    }
    catch (const DatabaseException& e) {
        std::cerr << "Database Error [" << e.getErrorCode() << "]: "
                  << e.what() << std::endl;
        std::cerr << "Description: " << e.getErrorDescription() << std::endl;
    }
    
    return 0;
}
```

## 4. 异常安全

### 1. 异常安全级别

```
┌─────────────────────────────────────────────────────────┐
│                  异常安全保证级别                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 无异常安全（No guarantee）                          │
│     - 异常发生时，程序状态未定义                         │
│     - 最差的情况                                        │
│                                                         │
│  2. 基本保证（Basic guarantee）                         │
│     - 异常发生时，不会泄漏资源                           │
│     - 对象仍处于有效状态（但可能改变）                   │
│     - 最低要求                                          │
│                                                         │
│  3. 强保证（Strong guarantee）                          │
│     - 异常发生时，程序状态回滚到操作前                   │
│     - 要么成功，要么无影响（事务语义）                   │
│     - 推荐                                              │
│                                                         │
│  4. 不抛出保证（Nothrow guarantee）                     │
│     - 函数保证不抛出异常                                 │
│     - 最高级别保证                                      │
│     - 析构函数、移动操作应满足此保证                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2. 基本保证示例

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>

class Container {
private:
    std::vector<int> data;
    
public:
    // 基本保证：即使抛出异常，对象仍处于有效状态
    void addValue(int value) {
        if (value < 0) {
            throw std::invalid_argument("Value cannot be negative");
        }
        
        // vector::push_back 提供强保证
        // 如果失败，vector 状态不变
        data.push_back(value);
    }
    
    size_t size() const {
        return data.size();
    }
    
    void print() const {
        std::cout << "Container: ";
        for (int val : data) {
            std::cout << val << " ";
        }
        std::cout << std::endl;
    }
};

int main() {
    Container cont;
    
    try {
        cont.addValue(10);
        cont.addValue(20);
        cont.addValue(-5);  // 抛出异常
    }
    catch (const std::invalid_argument& e) {
        std::cerr << "Error: " << e.what() << std::endl;
        // 对象仍处于有效状态
        std::cout << "Container size: " << cont.size() << std::endl;
        cont.print();
    }
    
    return 0;
}
```

### 3. 强保证示例（copy-and-swap）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <stdexcept>

class StringList {
private:
    std::vector<std::string> strings;
    
public:
    // 强保证：使用 copy-and-swap 惯用法
    void sortAll() {
        // 1. 创建副本
        std::vector<std::string> temp = strings;
        
        // 2. 在副本上操作（可能抛出异常）
        std::sort(temp.begin(), temp.end());
        
        // 3. 如果成功，交换（不会抛出异常）
        strings.swap(temp);
        
        // 如果步骤2失败，原数据不变
    }
    
    // 强保证：添加多个元素
    void addMultiple(const std::vector<std::string>& newStrings) {
        // 创建临时对象
        std::vector<std::string> temp = strings;
        
        // 在临时对象上添加元素
        for (const auto& str : newStrings) {
            if (str.empty()) {
                throw std::invalid_argument("Empty string not allowed");
            }
            temp.push_back(str);  // 可能抛出 bad_alloc
        }
        
        // 全部成功后，交换
        strings.swap(temp);
    }
    
    void print() const {
        std::cout << "Strings: ";
        for (const auto& str : strings) {
            std::cout << "[" << str << "] ";
        }
        std::cout << std::endl;
    }
    
    void add(const std::string& str) {
        strings.push_back(str);
    }
};

int main() {
    StringList list;
    list.add("banana");
    list.add("apple");
    list.add("cherry");
    
    std::cout << "Before sort: ";
    list.print();
    
    list.sortAll();
    
    std::cout << "After sort: ";
    list.print();
    
    // 测试强保证
    try {
        std::vector<std::string> newItems = {"date", "", "elderberry"};
        list.addMultiple(newItems);  // 会抛出异常
    }
    catch (const std::invalid_argument& e) {
        std::cerr << "Error: " << e.what() << std::endl;
        std::cout << "List unchanged: ";
        list.print();  // 列表保持原状态
    }
    
    return 0;
}
```

### 4. RAII与异常安全

```cpp
#include <iostream>
#include <fstream>
#include <stdexcept>
#include <memory>

// RAII 类：自动管理资源
class FileGuard {
private:
    std::ofstream file;
    
public:
    explicit FileGuard(const std::string& filename) {
        file.open(filename);
        if (!file.is_open()) {
            throw std::runtime_error("Cannot open file: " + filename);
        }
    }
    
    ~FileGuard() {
        if (file.is_open()) {
            file.close();
            std::cout << "File closed automatically" << std::endl;
        }
    }
    
    void write(const std::string& content) {
        if (!file) {
            throw std::runtime_error("File stream error");
        }
        file << content << std::endl;
    }
    
    // 禁止拷贝
    FileGuard(const FileGuard&) = delete;
    FileGuard& operator=(const FileGuard&) = delete;
};

// 使用 RAII 确保异常安全
void processFile(const std::string& filename) {
    // RAII：无论是否抛出异常，文件都会被正确关闭
    FileGuard guard(filename);
    
    guard.write("Line 1");
    guard.write("Line 2");
    
    // 模拟异常
    if (filename == "error.txt") {
        throw std::runtime_error("Processing error");
    }
    
    guard.write("Line 3");
}

int main() {
    try {
        processFile("output.txt");
        std::cout << "File processed successfully" << std::endl;
    }
    catch (const std::exception& e) {
        std::cerr << "Exception: " << e.what() << std::endl;
    }
    
    return 0;
}
```

## 5. noexcept说明符

### 1. noexcept基础

```cpp
#include <iostream>
#include <vector>
#include <utility>

// noexcept 函数：承诺不抛出异常
int safeAdd(int a, int b) noexcept {
    return a + b;
}

// 条件 noexcept：根据条件决定是否不抛出异常
template<typename T>
void safeSwap(T& a, T& b) noexcept(noexcept(std::swap(a, b))) {
    std::swap(a, b);
}

// noexcept(false)：明确表示可能抛出异常
void riskyOperation() noexcept(false) {
    throw std::runtime_error("Something went wrong");
}

// 检查函数是否 noexcept
void testNoexcept() {
    std::cout << "safeAdd is noexcept: " 
              << noexcept(safeAdd(1, 2)) << std::endl;
    
    std::vector<int> v1, v2;
    std::cout << "vector swap is noexcept: "
              << noexcept(std::swap(v1, v2)) << std::endl;
}

int main() {
    testNoexcept();
    
    try {
        safeAdd(1, 2);
        riskyOperation();
    }
    catch (const std::exception& e) {
        std::cerr << "Caught: " << e.what() << std::endl;
    }
    
    return 0;
}
```

### 2. noexcept 的双重身份：运算符 vs 说明符 ⭐

**核心答案：单词长得一模一样，但身份完全不一样**

就像同一个字，一个是动词、一个是名词，拼写一样，语法角色完全不同。

> **两个** **`noexcept`** **是同一个关键字，但是两种不同语法用法**

#### 1. 外层 `noexcept(...)` ：异常说明符（函数修饰符）

- **语法角色**：函数修饰符
- **作用**：给函数贴标签，承诺是否不抛异常
- **要求**：括号里必须是编译期布尔常量（`true/false`），不能写函数调用代码;  没有括号则表示不会抛出异常，

```cpp
// 外层 noexcept：修饰函数
void safeSwap(...) noexcept( 布尔值 )
```

#### 2. 内层 `noexcept(表达式)` ：一元运算符（编译期判断运算符）

- **语法角色**：一元运算符（就像 `sizeof()` 一样）
- **作用**：编译期判断表达式会不会抛异常
- **返回值**：`true` / `false`

```cpp
// 内层 noexcept：运算符 → 算出 true/false
constexpr bool result = noexcept(std::swap(a, b));
```

#### 3. 嵌套结构解析

```cpp
noexcept( noexcept(std::swap(a, b)) )
```

拆解：

1. **内层** **`noexcept(代码)`**：运算符 → 算出一个 `true/false`
2. **外层** **`noexcept(布尔值)`**：函数修饰符 → 用这个布尔值，给函数定异常属性

#### 4. 类比理解

把 `noexcept` 类比成 `sizeof`：

```cpp
// 同一个单词，两种语法身份，嵌套使用
int arr[ sizeof( sizeof(int) ) ];

// sizeof 也一样：
// - 里面 sizeof(int)：取类型大小，返回 size_t
// - 外面 sizeof(...)：再套一层求值
```

`noexcept` 也是同一个道理：

- **一个当修饰符、一个当运算符**
- 单词拼写完全一样，语法角色完全不同

#### 5. 为什么不能简写？

```cpp
// ❌ 想直接放代码 —— 不行！
noexcept(std::swap(a,b))

// ✅ 必须这样写：
noexcept(noexcept(std::swap(a,b)))
```

原因：**外层只认布尔常量，不认执行代码**。必须先用内层 `noexcept` 运算符，把代码转成 `true/false`，再给外层用。

#### 6. 实际应用示例

```cpp
#include <iostream>
#include <vector>
#include <utility>
#include <string>

template<typename T>
void mySwap(T& a, T& b) noexcept(noexcept(std::swap(a, b))) {
    // 外层 noexcept：函数修饰符，决定 mySwap 是否 noexcept
    // 内层 noexcept：运算符，检查 std::swap(a,b) 是否抛异常
    
    std::swap(a, b);
}

class MayThrow {
public:
    MayThrow() = default;
    MayThrow(MayThrow&&) { /* 可能抛出异常 */ }
};

class NoThrow {
public:
    NoThrow() = default;
    NoThrow(NoThrow&&) noexcept {}  // 承诺不抛异常
};

int main() {
    std::cout << "std::string swap is noexcept: "
              << noexcept(std::swap(std::string{}, std::string{}))
              << std::endl;  // 输出: 1 (true) — C++17起 std::string 的 swap 保证为 noexcept
    
    std::cout << "MayThrow swap is noexcept: "
              << noexcept(std::swap(MayThrow{}, MayThrow{}))
              << std::endl;  // 输出: 0 (false)
    
    std::cout << "NoThrow swap is noexcept: "
              << noexcept(std::swap(NoThrow{}, NoThrow{}))
              << std::endl;  // 输出: 1 (true)
    
    return 0;
}
```

#### 7. 一句话总结

| 身份     | 位置                           | 角色     | 输入       | 输出           |
| ------ | ---------------------------- | ------ | -------- | ------------ |
| **外层** | `void f() noexcept(**...**)` | 函数修饰符  | 布尔值      | 给函数定属性       |
| **内层** | `noexcept(**表达式**)`          | 编译期运算符 | 表达式/函数调用 | `true/false` |

**必须写成：`noexcept(noexcept(表达式))`**

### 3. noexcept与析构函数

```cpp
#include <iostream>
#include <stdexcept>

class Resource {
private:
    int* data;
    
public:
    Resource() : data(new int(42)) {
        std::cout << "Resource acquired" << std::endl;
    }
    
    // 析构函数默认是 noexcept
    // 如果析构函数可能抛出异常，必须明确声明
    ~Resource() noexcept {
        delete data;
        std::cout << "Resource released" << std::endl;
        
        // 不要在析构函数中抛出异常！
        // throw std::runtime_error("Error in destructor");  // 危险！
    }
    
    // 移动构造函数应该是 noexcept
    Resource(Resource&& other) noexcept 
        : data(other.data) {
        other.data = nullptr;
        std::cout << "Resource moved" << std::endl;
    }
    
    // 移动赋值运算符应该是 noexcept
    Resource& operator=(Resource&& other) noexcept {
        if (this != &other) {
            delete data;
            data = other.data;
            other.data = nullptr;
        }
        return *this;
    }
    
    // 禁止拷贝
    Resource(const Resource&) = delete;
    Resource& operator=(const Resource&) = delete;
};

int main() {
    Resource r1;
    Resource r2 = std::move(r1);  // 使用移动构造
    
    return 0;
}
```

### 4. noexcept与标准库

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

class Widget {
private:
    int id;
    
public:
    explicit Widget(int i) : id(i) {}
    
    // noexcept 移动构造函数
    Widget(Widget&& other) noexcept : id(other.id) {
        other.id = 0;
        std::cout << "Widget moved: " << id << std::endl;
    }
    
    // 非 noexcept 拷贝构造函数
    Widget(const Widget& other) : id(other.id) {
        std::cout << "Widget copied: " << id << std::endl;
    }
    
    Widget& operator=(Widget&& other) noexcept {
        id = other.id;
        other.id = 0;
        return *this;
    }
    
    int getId() const { return id; }
};

int main() {
    std::vector<Widget> widgets;
    
    // 添加元素
    widgets.emplace_back(1);
    widgets.emplace_back(2);
    widgets.emplace_back(3);
    
    std::cout << "\nResizing vector..." << std::endl;
    
    // vector 扩容时： (STL的vector默认逻辑)
    // - 如果移动构造函数是 noexcept，使用移动
    // - 否则使用拷贝（更安全但更慢）
    widgets.reserve(100);
    
    return 0;
}
```

## 6. 异常与错误码对比

### 1. 对比表

| 特性       | 异常              | 错误码            |
| -------- | --------------- | -------------- |
| **可读性**  | 高（正常流程与错误处理分离）  | 低（错误处理与正常流程混合） |
| **强制性**  | 强（必须处理，否则程序终止）  | 弱（容易被忽略）       |
| **性能**   | 无异常时高效，抛出异常有开销  | 每次都要检查，有一定开销   |
| **信息量**  | 丰富（可携带类型、消息、堆栈） | 有限（通常只是整数）     |
| **传播**   | 自动向上传播          | 需要手动传播         |
| **适用场景** | 异常情况、错误恢复       | 性能关键、预期错误      |

### 2. 错误码示例

```cpp
#include <iostream>
#include <string>

// 使用错误码的传统方式
enum class FileError {
    None = 0,
    FileNotFound,
    PermissionDenied,
    IOError
};

FileError readFile(const std::string& filename, std::string& content) {
    if (filename.empty()) {
        return FileError::FileNotFound;
    }
    
    if (filename == "secret.txt") {
        return FileError::PermissionDenied;
    }
    
    // 模拟读取文件
    content = "File content here";
    return FileError::None;
}

int main() {
    std::string content;
    
    // 错误码方式：必须检查返回值
    FileError error = readFile("test.txt", content);
    
    if (error == FileError::None) {
        std::cout << "Content: " << content << std::endl;
    }
    else if (error == FileError::FileNotFound) {
        std::cerr << "Error: File not found" << std::endl;
    }
    else if (error == FileError::PermissionDenied) {
        std::cerr << "Error: Permission denied" << std::endl;
    }
    else {
        std::cerr << "Error: Unknown error" << std::endl;
    }
    
    return 0;
}
```

```cpp
#include <iostream>
#include <system_error>

// 使用 std::error_code 进行性能关键路径的错误处理
std::error_code readFileFast(const std::string& filename, std::string& content) {
    std::ifstream file(filename);
    if (!file) {
        return std::make_error_code(std::errc::no_such_file_or_directory);

        throw std::system_error(error, "Failed to read file: " + filename);

    std::cout << "File content: " << content << std::endl;
}

int main() {
    try {
        processFile("nonexistent.txt");

    catch (const std::system_error& e) {
        std::cerr << "System error: " << e.what() << std::endl;
        std::cerr << "Error code: " << e.code() << std::endl;
    }
    
    return 0;
```

## 7. 最佳实践

### 1. ✅ 应该做的

```cpp
#include <iostream>
#include <stdexcept>
#include <memory>
#include <vector>

// ✅ 1. 使用 RAII 管理资源
class Buffer {
private:
    std::unique_ptr<int[]> data;
    size_t size;
    
public:
    explicit Buffer(size_t s) : data(std::make_unique<int[]>(s)), size(s) {}
    
    int& operator[](size_t index) {
        if (index >= size) {
            throw std::out_of_range("Buffer index out of range");
        }
        return data[index];
    }
};

// ✅ 2. 抛出有意义的异常类型
void processAge(int age) {
    if (age < 0) {
        throw std::invalid_argument("Age cannot be negative");
    }
    if (age > 150) {
        throw std::out_of_range("Age exceeds reasonable limit");
    }
    // 正常处理
}

// ✅ 3. 使用 const 引用捕获异常
void example1() {
    try {
        processAge(-5);
    }
    catch (const std::invalid_argument& e) {  // const 引用
        std::cerr << "Error: " << e.what() << std::endl;
    }
}

// ✅ 4. 析构函数和移动操作标记为 noexcept
class SafeClass {
public:
    ~SafeClass() noexcept = default;
    
    SafeClass(SafeClass&& other) noexcept = default;
    SafeClass& operator=(SafeClass&& other) noexcept = default;
};

// ✅ 5. 提供强异常安全保证
class Container {
private:
    std::vector<int> data;
    
public:
    void replaceAll(const std::vector<int>& newData) {
        std::vector<int> temp = newData;  // 先创建副本
        data.swap(temp);                   // 再交换（不会抛出异常）
    }
};

// ✅ 6. 在适当的层级捕获异常
void lowLevelFunction() {
    throw std::runtime_error("Low level error");
}

void midLevelFunction() {
    try {
        lowLevelFunction();
    }
    catch (const std::runtime_error& e) {
        // 添加上下文信息后重新抛出
        throw std::runtime_error(
            std::string("Mid level: ") + e.what()
        );
    }
}

void highLevelFunction() {
    try {
        midLevelFunction();
    }
    catch (const std::runtime_error& e) {
        std::cerr << "High level caught: " << e.what() << std::endl;
    }
}
```

### 2. ❌ 不应该做的

```cpp
#include <iostream>
#include <stdexcept>
#include <cstring>

// ❌ 1. 不要用异常替代正常的控制流
int factorial(int n) {
    if (n < 0) {
        throw std::invalid_argument("Negative input");  // 正确
    }
    
    // ❌ 错误：用异常来结束递归
    // if (n == 0) throw 1;
    
    // ✅ 正确：用正常返回值
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

// ❌ 2. 不要在析构函数中抛出异常
class BadClass {
public:
    ~BadClass() {
        // ❌ 危险！析构函数不应抛出异常
        // throw std::runtime_error("Error in destructor");
        
        // ✅ 正确：记录日志或忽略错误
        try {
            // cleanup code
        }
        catch (...) {
            // 吞掉异常或记录日志
        }
    }
};

// ❌ 3. 不要捕获所有异常然后忽略
void badPractice1() {
    try {
        // some code
    }
    catch (...) {
        // ❌ 吞掉所有异常，隐藏了问题
    }
}

// ✅ 正确：至少记录日志
void goodPractice1() {
    try {
        // some code
    }
    catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << std::endl;
        // 可以选择重新抛出
        throw;
    }
}

// ❌ 4. 不要抛出原始指针或基本类型
void badPractice2() {
    // ❌ 不要这样
    throw "Error message";
    throw 42;
    throw new std::runtime_error("Error");  // 内存泄漏！这里抛出的是指针!
}

// ✅ 正确：抛出异常对象
void goodPractice2() {
    throw std::runtime_error("Error message");
}

// ❌ 5. 不要在性能关键路径使用异常
// 对于频繁发生的预期错误，使用错误码
class PerformanceCritical {
public:
    // ❌ 如果这个函数每秒调用百万次，不要用异常
    int divide(int a, int b) {
        if (b == 0) {
            throw std::runtime_error("Division by zero");
        }
        return a / b;
    }
    
    // ✅ 使用错误码或 optional
    std::pair<int, bool> divideFast(int a, int b) {
        if (b == 0) {
            return {0, false};
        }
        return {a / b, true};
    }
};

// ❌ 6. 不要在构造函数中抛出异常后继续使用对象
class Resource {
public:
    Resource() {
        // 如果构造函数抛出异常，对象不会创建
        throw std::runtime_error("Construction failed");
    }
};

void example() {
    Resource* ptr = nullptr;
    try {
        ptr = new Resource();  // 抛出异常，ptr 保持 nullptr
    }
    catch (...) {
        // ❌ ptr 未初始化，不要使用
        // delete ptr;  // 错误！
    }
}
```

### 3. 异常处理检查清单

```C++
□ 资源管理
  ✓ 使用 RAII 类管理资源
  ✓ 智能指针代替原始指针
  ✓ 析构函数标记为 noexcept

□ 异常类型
  ✓ 使用标准异常类型或自定义异常类
  ✓ 异常消息清晰、有意义
  ✓ 包含足够的上下文信息

□ 异常安全
  ✓ 提供至少基本保证
  ✓ 关键操作提供强保证
  ✓ 使用 copy-and-swap 惯用法

□ 性能考虑
  ✓ 不在性能关键路径使用异常
  ✓ 异常仅用于真正的异常情况
  ✓ 移动操作标记为 noexcept

□ 代码质量
  ✓ const 引用捕获异常
  ✓ 不吞掉异常
  ✓ 在适当的层级处理异常
```
