想象你要寄信：
- **没有模板**：每次写信都要重新写格式：亲爱的xxx你好...
- **有模板**：直接填内容就行，格式已经固定好

**模板就是"格式固定，内容可换"的工具！**

比如：
- 模板：`<html><body><h1>标题</h1><p>内容</p></body></html>`
- 填入具体内容后就变成了一封具体的HTML邮件

**C++模板的作用：**

```cpp
// 这是一个"加法模板"
template<typename T>
T add(T a, T b) {
    return a + b;
}

// 用来生成具体的"加法函数"
add(1, 2);      // 生成 int add(int, int)
add(1.5, 2.5);  // 生成 double add(double, double)
add(std::string("hello"), std::string("world")); // 生成 string add(string, string)
```

**就像"印钞机"**：模板是"印钞机"，可以印出各种面值的钞票（不同类型的函数）

> 🔬 **抽象理解 - 模板的编译时多态**：

> - **模板实例化**：是"编译时生成代码"的过程，在编译期根据参数类型生成具体代码
> - **编译时多态**：vs运行时多态，模板的多态在编译期决定，效率更高
> - **元编程**：模板是一种"编译时编程"，可以在编译期做计算和类型推导
> - **模板的本质**：是"代码生成的规则"，告诉编译器如何根据类型生成代码

## 1. 模板基础概念

### 1. 概念与定义

**模板（template）**：C++泛型编程的核心机制，允许编写与类型无关的代码。模板可以分为函数模板和类模板。

**泛型编程（generic programming）**：与类型无关的编程方式。泛型编程可以提高代码复用性，减少代码冗余。

**函数模板（function template）**：定义与类型无关的函数。函数模板可以用于不同类型的参数。例如`template<typename T> T add(T a, T b) { return a + b; }`。

**类模板（class template）**：定义与类型无关的类。类模板可以用于不同类型的成员变量和成员函数。例如`template<typename T> class Vector { /* ... */ };`。

**模板参数（template parameter）**：模板的参数，可以是类型参数、非类型参数、模板模板参数等。例如`template<typename T, int N> class Array { /* ... */ };`。

**模板实例化（template instantiation）**：将模板参数替换为具体类型或值，生成具体的函数或类。模板实例化可以分为隐式实例化和显式实例化。

**隐式实例化（implicit instantiation）**：编译器自动根据模板参数推导生成具体的函数或类。例如`add(1, 2)`会实例化`add<int>`。

**显式实例化（explicit instantiation）**：手动指定模板参数，生成具体的函数或类。例如`add<double>(1.5, 2.5)`会实例化`add<double>`。

**模板特化（template specialization）**：为特定类型或值提供特殊的模板实现。模板特化可以分为全特化和偏特化。

### 2. 什么是模板？

模板是C++泛型编程的核心机制，允许编写与类型无关的代码。

```cpp
// 不使用模板：需要为每种类型写一个函数
int max_int(int a, int b) { return a > b ? a : b; }
double max_double(double a, double b) { return a > b ? a : b; }
std::string max_string(const std::string& a, const std::string& b) { 
    return a > b ? a : b; 
}

// 使用模板：一份代码适用于所有类型
template<typename T>
T maximum(T a, T b) {
    return a > b ? a : b;
}

// 使用
maximum(1, 2);           // int
maximum(1.5, 2.5);       // double
maximum(std::string("a"), std::string("b"));  // string
```

### 3. 模板实例化

```cpp
template<typename T>
T add(T a, T b) {
    return a + b;
}

// 隐式实例化
int result1 = add(1, 2);        // 实例化 add<int>

// 显式实例化
double result2 = add<double>(1.5, 2.5);

// 显式实例化定义
template int add<int>(int, int);
```

## 2. 函数模板

### 1. 基本语法

```cpp
template<typename T>
T func(T param) {
    // 函数体
}

// 或使用 class 关键字（等价）
template<class T>
T func(T param) {
    // 函数体
}
```

### 2. 多模板参数

```cpp
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

// C++14 简化
template<typename T, typename U>
auto add(T a, U b) {
    return a + b;
}

// 使用
auto result = add(1, 2.5);  // double
```

### 3. 模板参数推导

```cpp
template<typename T>
void print(T value) {
    std::cout << value << std::endl;
}

print(42);        // T = int
print(3.14);      // T = double
print("hello");   // T = const char*

// 引用推导
template<typename T>
void func(T& param) {}

int x = 10;
func(x);  // T = int, param = int&

// 万能引用
template<typename T>
void forward(T&& param) {}

forward(10);  // T = int, param = int&&
forward(x);   // T = int&, param = int&
```

### 4. 函数模板重载

```cpp
// 模板版本
template<typename T>
T maximum(T a, T b) {
    return a > b ? a : b;
}

// 指针特化
template<typename T>
T* maximum(T* a, T* b) {
    return *a > *b ? a : b;
}

// 非模板重载
const char* maximum(const char* a, const char* b) {
    return std::strcmp(a, b) > 0 ? a : b;
}
```

## 3. 类模板

### 1. 基本语法

```cpp
template<typename T>
class Container {
private:
    T value;
    
public:
    Container(T v) : value(v) {}
    
    T get() const { return value; }
    void set(T v) { value = v; }
};

// 使用
Container<int> c1(10);
Container<std::string> c2("hello");
```

### 2. 成员函数模板

```cpp
template<typename T>
class Converter {
public:
    template<typename U>
    U convert() const {
        return static_cast<U>(value);
    }
    
private:
    T value;
};

// 使用
Converter<double> c(3.14);
int i = c.convert<int>();
```

### 3. 类模板特化

```cpp
// 主模板
template<typename T>
class TypeInfo {
public:
    static void print() {
        std::cout << "Unknown type" << std::endl;
    }
};

// 完全特化
template<>
class TypeInfo<int> {
public:
    static void print() {
        std::cout << "int type" << std::endl;
    }
};

// 使用
TypeInfo<double>::print();  // Unknown type
TypeInfo<int>::print();     // int type
```

## 4. 模板参数详解

### 1. 类型参数

```cpp
template<typename T>
class MyClass {};

// 使用
MyClass<int> m;
MyClass<std::string> m2;
```

### 2. 非类型参数

```cpp
template<typename T, size_t Size>
class Array {
private:
    T data[Size];
    
public:
    size_t size() const { return Size; }
    T& operator[](size_t i) { return data[i]; }
    const T& operator[](size_t i) const { return data[i]; }
};

// 使用
Array<int, 10> arr;
arr[0] = 1;
```

### 3. 模板模板参数

```cpp
template<typename T, template<typename> class Container>
class Stack {
private:
    Container<T> data;
    
public:
    void push(const T& value) { data.push_back(value); }
    void pop() { data.pop_back(); }
    T top() const { return data.back(); }
};

// 使用
Stack<int, std::vector> s;
s.push(1);
```

### 4. 默认模板参数

```cpp
template<typename T = int, size_t Size = 10>
class Buffer {
private:
    T data[Size];
};

// 使用
Buffer<> b1;           // Buffer<int, 10>
Buffer<double> b2;     // Buffer<double, 10>
Buffer<double, 20> b3; // Buffer<double, 20>
```

### 5. 可变参数模板

```cpp
// 参数包
template<typename... Args>
void print(Args... args) {
    (std::cout << ... << args) << std::endl;  // C++17 折叠表达式
}

// 使用
print(1, 2, 3, 4, 5);
print("hello", " ", "world");

// 递归展开
template<typename T>
void print(T value) {
    std::cout << value << std::endl;
}

template<typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first << ", ";
    print(rest...);
}
```

## 5. 本章小结

### 1. 核心概念回顾

| 概念 | 说明 | 示例 |
|-----|------|------|
| **函数模板** | 泛型函数 | `template<typename T> T func(T)` |
| **类模板** | 泛型类 | `template<typename T> class C` |
| **特化** | 特定类型定制 | `template<> class C<int>` |
| **参数包** | 可变参数 | `template<typename... Args>` |

### 2. 关键语法要点

1. **模板定义**：`template<typename T>`
2. **实例化**：显式或隐式
3. **特化**：为特定类型提供定制实现
4. **参数推导**：编译器自动推导类型
5. **可变参数**：使用参数包 `...`

### 3. 最佳实践

1. 模板定义放在头文件中
2. 使用 `typename` 而非 `class`
3. 合理使用特化优化特定类型
4. 使用 `constexpr if` 简化条件编译
5. 避免过度复杂的模板设计
