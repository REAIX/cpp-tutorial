> 💡 **通俗理解 - 模板进阶学什么？**

回想一下第7章的"模板"比喻：模板就像"印钞机"。

**进阶就是学"特殊印钞技术"：**

1. **模板特化** - 就像"专门印某种钱"
   - 普通模板：什么货币都能印
   - 特化模板：专门印"美元"，或者专门印"硬币"

2. **可变参数模板** - 就像"不限数量的参数"
   - 普通函数：只能接收固定数量的参数
   - 可变参数：想传多少传多少 `printf("%d %s %f", a, b, c, d, e...)`

3. **模板元编程** - 就像"在编译时就算账"
   - 普通的计算：程序运行时才算
   - 模板元编程：编译时就算好结果，运行直接用

> 🔬 **抽象理解 - 模板元编程的本质**：
> - **模板特化**：是"针对特定类型的特殊处理"，为特定类型提供不同的实现
> - **可变参数模板**：是"参数个数可变的模板"，通过参数包展开实现
> - **SFINAE**：是"替换失败非错误"原则，编译器在模板推导失败时尝试其他重载
> - **模板元编程**：是"编译时计算"，在编译期执行计算任务，减少运行时开销
> - **类型推导**：是"编译期类型计算"，通过模板推导出具体类型
> - **constexpr**：是"编译时常量"，标记可以在编译期求值的函数或变量

## 1. 模板特化与偏特化

### 1. 概念与定义

**模板特化（template specialization）**：为特定类型或值提供特殊的模板实现。模板特化可以分为全特化和偏特化。

**全特化（full specialization）**：为所有模板参数提供特殊的模板实现。例如`template<> class TypeInfo<int> { /* ... */ };`。

**偏特化（partial specialization）**：为部分模板参数提供特殊的模板实现。例如`template<typename T> class TypeInfo<T*> { /* ... */ };`。

**可变参数模板（variadic template）**：C++11引入的新特性，用于支持可变数量的模板参数。例如`template<typename... Args> void func(Args... args) { /* ... */ }`。

**参数包（parameter pack）**：可变参数模板中的参数集合。例如`Args... args`表示参数包。

**参数包展开（parameter pack expansion）**：将参数包展开为单个参数。例如`func(args...)`表示将参数包`args`展开为单个参数。

**SFINAE（Substitution Failure Is Not An Error）**：C++中的一个规则，用于在模板实例化失败时不产生错误。SFINAE可以用于类型萃取、重载解析等。

**类型萃取（type traits）**：C++中用于获取类型信息的机制。类型萃取可以用于判断类型是否为整数、是否为指针、是否为类等。例如`std::is_integral<T>::value`用于判断类型`T`是否为整数。

**模板元编程（template metaprogramming）**：C++中用于在编译期执行代码的机制。模板元编程可以用于计算编译期常量、生成代码等。例如`template<int N> struct Factorial { static const int value = N * Factorial<N-1>::value; };`。

### 2. 完全特化

```cpp
#include <iostream>
#include <cstring>

// 通用模板（主模板）
template<typename T>
class TypeInfo {
public:
    static void print() {
        std::cout << "Unknown type, size = " << sizeof(T) << "\n";
    }
};

// 完全特化：int
template<>
class TypeInfo<int> {
public:
    static void print() {
        std::cout << "int type, size = 4\n";
    }
};

// 偏特化：指针
template<typename T>
class TypeInfo<T*> {
public:
    static void print() {
        std::cout << "Pointer to ";
        TypeInfo<T>::print();
    }
};
```

### 3. 偏特化

```cpp
// 主模板
template<typename T, typename U>
class Pair {
public:
    void print() {
        std::cout << "Generic pair\n";
    }
};

// 偏特化：两个相同类型
template<typename T>
class Pair<T, T> {
public:
    void print() {
        std::cout << "Same type pair\n";
    }
};

// 偏特化：第二个是指针
template<typename T, typename U>
class Pair<T, U*> {
public:
    void print() {
        std::cout << "Second is pointer\n";
    }
};

// 使用
Pair<int, double> p1;  // Generic pair
Pair<int, int> p2;     // Same type pair
Pair<int, double*> p3; // Second is pointer
```

## 2. 可变参数模板

### 1. 参数包展开

```cpp
// 基本语法
template<typename... Args>
void func(Args... args) {
    // sizeof...(Args) 获取参数数量
    std::cout << "Number of args: " << sizeof...(Args) << "\n";
    std::cout << "Number of args: " << sizeof...(args) << "\n";
}

// C++17 折叠表达式
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // 右折叠
}

template<typename... Args>
auto sum_left(Args... args) {
    return (... + args);  // 左折叠
}

// 使用
sum(1, 2, 3, 4, 5);  // 15
```

### 2. 递归展开

```cpp
// 递归终止条件
void print() {}

// 递归展开
template<typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first;
    if constexpr (sizeof...(rest) > 0) {
        std::cout << ", ";
        print(rest...);
    }
}

// 使用
print(1, 2.5, "hello", 'c');
// 输出：1, 2.5, hello, c
```

### 3. 完美转发

```cpp
template<typename... Args>
void forward_to_func(Args&&... args) {
    func(std::forward<Args>(args)...);
}
```

#ifndef HEADER_H

```cpp
// header.h
template<typename T>
T add(T a, T b);

// source.cpp

template int add<int>(int, int);

```

## 4. SFINAE与类型萃取

### 1. SFINAE原则

SFINAE：Substitution Failure Is Not An Error（替换失败不是错误）

```cpp
#include <type_traits>

// 使用 enable_if
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
only_for_integers(T value) {
    return value * 2;
}

// C++17 简化
template<typename T>
std::enable_if_t<std::is_integral_v<T>, T>
only_for_integers_v2(T value) {
    return value * 2;
}

// C++20 Concepts（推荐）
template<std::integral T>
T only_for_integers_concept(T value) {
    return value * 2;
}
```

### 2. 类型萃取

```cpp
#include <type_traits>

// 判断类型
std::is_integral<int>::value;        // true
std::is_pointer<int*>::value;        // true
std::is_array<int[]>::value;         // true
std::is_class<std::string>::value;   // true

// C++17 简化
std::is_integral_v<int>;             // true
std::is_pointer_v<int*>;             // true

// 类型关系
std::is_same<int, int32_t>::value;   // true
std::is_base_of<Base, Derived>::value;

// 类型修改
std::remove_pointer<int*>::type;     // int
std::add_pointer<int>::type;         // int*
std::remove_const<const int>::type;  // int
```

### 3. 自定义类型萃取

```cpp
template<typename T>
struct is_pointer {
    static constexpr bool value = false;
};

template<typename T>
struct is_pointer<T*> {
    static constexpr bool value = true;
};

// 使用
is_pointer<int>::value;   // false
is_pointer<int*>::value;  // true
```

## 5. 模板元编程基础

### 1. 编译期计算

```cpp
// 阶乘
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

// 使用
Factorial<5>::value;  // 120，编译期计算
```

### 2. 编译期条件

```cpp
template<bool Condition, typename Then, typename Else>
struct If;

template<typename Then, typename Else>
struct If<true, Then, Else> {
    using type = Then;
};

template<typename Then, typename Else>
struct If<false, Then, Else> {
    using type = Else;
};

// 使用
If<true, int, double>::type;   // int
If<false, int, double>::type;  // double
```

### 3. constexpr if（C++17）

```cpp
template<typename T>
auto get_value(T t) {
    if constexpr (std::is_pointer_v<T>) {
        return *t;
    } else {
        return t;
    }
}
```

## 6. 本章小结

### 1. 核心概念回顾

| 概念 | 说明 | 示例 |
|-----|------|------|
| **特化** | 特定类型定制 | `template<> class C<int>` |
| **偏特化** | 部分参数定制 | `template<T> class C<T, T>` |
| **参数包** | 可变参数 | `typename... Args` |
| **SFINAE** | 替换失败非错误 | `enable_if` |
| **类型萃取** | 编译期类型信息 | `is_integral<T>` |

### 2. 关键语法要点

1. **特化**：完全特化和偏特化
2. **参数包**：`sizeof...`、折叠表达式
3. **SFINAE**：`enable_if`、`void_t`
4. **类型萃取**：`<type_traits>` 头文件
5. **constexpr if**：编译期分支

### 3. 最佳实践

1. 优先使用 C++20 Concepts 替代 SFINAE
2. 使用 `constexpr if` 简化模板代码
3. 合理使用特化优化性能
4. 避免过度复杂的模板元编程
5. 使用 `static_assert` 进行编译期检查
