## 1. 文件流基础

### 1. 概念与定义

**文件流（file stream）**：C++中用于文件读写的机制。文件流可以分为输入文件流、输出文件流、输入输出文件流等。例如`std::ifstream`用于读取文件，`std::ofstream`用于写入文件，`std::fstream`用于读写文件。

**输入文件流（input file stream）**：C++中用于读取文件的机制。例如`std::ifstream file("data.txt");`用于读取文件`data.txt`。

**输出文件流（output file stream）**：C++中用于写入文件的机制。例如`std::ofstream file("data.txt");`用于写入文件`data.txt`。

**输入输出文件流（input/output file stream）**：C++中用于读写文件的机制。例如`std::fstream file("data.txt", std::ios::in | std::ios::out);`用于读写文件`data.txt`。

**打开模式（open mode）**：C++中用于指定文件打开方式的机制。打开模式可以分为读模式、写模式、追加模式、截断模式、二进制模式等。例如`std::ios::in`表示读模式，`std::ios::out`表示写模式，`std::ios::app`表示追加模式，`std::ios::trunc`表示截断模式，`std::ios::binary`表示二进制模式。

**文件系统库（filesystem library）**：C++17引入的新特性，用于支持文件系统操作。文件系统库可以用于创建目录、删除目录、复制文件、移动文件等。例如`std::filesystem::create_directory("dir");`用于创建目录`dir`。

**二进制文件（binary file）**：C++中用于存储二进制数据的文件。二进制文件可以存储图像、音频、视频等数据。例如`std::ofstream file("data.bin", std::ios::binary);`用于写入二进制文件`data.bin`。

### 2. 文件流类型

```cpp
#include <iostream>
#include <fstream>
#include <string>

// std::ifstream：输入文件流（读取）
// std::ofstream：输出文件流（写入）
// std::fstream：输入输出文件流（读写）

int main() {
    // 写入文件
    std::ofstream outFile("output.txt");
    outFile << "Hello, File!" << std::endl;
    outFile.close();
    
    // 读取文件
    std::ifstream inFile("output.txt");
    std::string line;
    while (std::getline(inFile, line)) {
        std::cout << line << std::endl;
    }
    inFile.close();
    
    return 0;
}
```

### 3. 打开模式

| 模式 | 说明 |
|-----|------|
| `std::ios::in` | 读模式 |
| `std::ios::out` | 写模式 |
| `std::ios::app` | 追加模式 |
| `std::ios::ate` | 打开后定位到末尾 |
| `std::ios::trunc` | 截断文件 |
| `std::ios::binary` | 二进制模式 |

```cpp
// 组合模式
std::ofstream file("log.txt", std::ios::app);  // 追加
std::fstream file2("data.txt", std::ios::in | std::ios::out);  // 读写
```

### 4. 检查文件状态

```cpp
#include <fstream>

void check_file() {
    std::ifstream file("data.txt");
    
    if (!file.is_open()) {
        std::cerr << "Failed to open file\n";
        return;
    }
    
    if (file.good()) {
        std::cout << "File is good\n";
    }
    
    if (file.eof()) {
        std::cout << "End of file\n";
    }
    
    if (file.fail()) {
        std::cout << "I/O operation failed\n";
    }
    
    if (file.bad()) {
        std::cout << "Critical error\n";
    }
}
```

## 2. 文件读写操作

### 1. 文本文件读写

```cpp
#include <fstream>
#include <string>
#include <vector>

// 读取整个文件
std::string read_file(const std::string& filename) {
    std::ifstream file(filename);
    return std::string(std::istreambuf_iterator<char>(file),
                       std::istreambuf_iterator<char>());
}

// 逐行读取
void read_lines(const std::string& filename) {
    std::ifstream file(filename);
    std::string line;
    while (std::getline(file, line)) {
        std::cout << line << "\n";
    }
}

// 写入文件
void write_file(const std::string& filename, const std::string& content) {
    std::ofstream file(filename);
    file << content;
}
```

### 2. 格式化读写

```cpp
#include <fstream>
#include <iomanip>

void formatted_write() {
    std::ofstream file("data.txt");
    
    // 设置格式
    file << std::setw(10) << std::setfill('0') << 42 << "\n";
    file << std::fixed << std::setprecision(2) << 3.14159 << "\n";
    file << std::hex << 255 << "\n";
}

void formatted_read() {
    std::ifstream file("data.txt");
    
    int num;
    double pi;
    
    file >> num >> pi;
}
```

## 3. 文件系统库

### 1. 基本操作（C++17）

```cpp
#include <filesystem>
#include <iostream>

namespace fs = std::filesystem;

int main() {
    // 路径操作
    fs::path p = "/home/user/documents/file.txt";
    
    std::cout << "Parent: " << p.parent_path() << "\n";
    std::cout << "Filename: " << p.filename() << "\n";
    std::cout << "Extension: " << p.extension() << "\n";
    std::cout << "Stem: " << p.stem() << "\n";
    
    // 文件信息
    if (fs::exists(p)) {
        std::cout << "Size: " << fs::file_size(p) << " bytes\n";
        std::cout << "Last modified: " 
                  << fs::last_write_time(p).time_since_epoch().count() << "\n";
    }
    
    // 创建目录
    fs::create_directory("new_dir");
    fs::create_directories("path/to/dir");
    
    // 复制文件
    fs::copy("source.txt", "dest.txt");
    fs::copy("source.txt", "dest.txt", fs::copy_options::overwrite_existing);
    
    // 移动/重命名
    fs::rename("old.txt", "new.txt");
    
    // 删除
    fs::remove("file.txt");
    fs::remove_all("directory");
    
    return 0;
}
```

### 2. 遍历目录

```cpp
#include <filesystem>
#include <iostream>

namespace fs = std::filesystem;

void list_directory(const std::string& path) {
    for (const auto& entry : fs::directory_iterator(path)) {
        std::cout << entry.path() << "\n";
        
        if (entry.is_directory()) {
            std::cout << "  [DIR]\n";
        } else if (entry.is_regular_file()) {
            std::cout << "  [FILE] " << entry.file_size() << " bytes\n";
        }
    }
}

void recursive_list(const std::string& path) {
    for (const auto& entry : fs::recursive_directory_iterator(path)) {
        std::cout << entry.path() << "\n";
    }
}
```

## 4. 二进制文件

### 1. 二进制读写

```cpp
#include <fstream>
#include <vector>

struct Record {
    int id;
    char name[50];
    double value;
};

void write_binary() {
    std::ofstream file("data.bin", std::ios::binary);
    
    Record r = {1, "Test", 3.14};
    file.write(reinterpret_cast<const char*>(&r), sizeof(r));
    
    // 写入数组
    std::vector<int> data = {1, 2, 3, 4, 5};
    file.write(reinterpret_cast<const char*>(data.data()), 
               data.size() * sizeof(int));
}

void read_binary() {
    std::ifstream file("data.bin", std::ios::binary);
    
    Record r;
    file.read(reinterpret_cast<char*>(&r), sizeof(r));
    
    // 读取数组
    std::vector<int> data(5);
    file.read(reinterpret_cast<char*>(data.data()), 
              data.size() * sizeof(int));
}
```

### 2. 文件定位

```cpp
#include <fstream>

void file_seek() {
    std::fstream file("data.bin", std::ios::in | std::ios::out | std::ios::binary);
    
    // 定位到文件开头
    file.seekg(0, std::ios::beg);
    
    // 定位到文件末尾
    file.seekg(0, std::ios::end);
    std::streampos size = file.tellg();  // 获取文件大小
    
    // 定位到指定位置
    file.seekg(100);  // 从开头偏移100字节
    
    // 写入定位
    file.seekp(0, std::ios::beg);
}
```

## 5. 注意事项与最佳实践

### 1. 常见陷阱

```cpp
// 1. 忘记关闭文件
void bad() {
    std::ofstream file("output.txt");
    file << "data";
    // 忘记 close()
}  // 析构时会自动关闭，但最好显式关闭

// 2. 路径问题
// Windows: "C:\\Users\\name\\file.txt" 或 R"(C:\Users\name\file.txt)"
// Linux: "/home/user/file.txt"

// 3. 编码问题
// 文本文件可能有不同编码，注意处理

// 4. 大文件处理
void process_large_file() {
    std::ifstream file("large.txt");
    std::string line;
    while (std::getline(file, line)) {
        // 逐行处理，避免一次性读取
    }
}
```

### 2. 最佳实践

```cpp
// 1. 使用 RAII
void good() {
    std::ofstream file("output.txt");
    file << "data";
    // 自动关闭
}

// 2. 检查文件是否成功打开
void safe_open() {
    std::ifstream file("data.txt");
    if (!file) {
        throw std::runtime_error("Cannot open file");
    }
}

// 3. 使用 filesystem 处理路径
#include <filesystem>
fs::path p = fs::current_path() / "data" / "file.txt";

// 4. 异常处理
void with_exception() {
    std::ifstream file;
    file.exceptions(std::ifstream::failbit | std::ifstream::badbit);
    
    try {
        file.open("data.txt");
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << "\n";
    }
}
```
