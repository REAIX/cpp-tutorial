## 2. 自动类型推导

> 📖 **详细内容请参考：[12-类型推导](12-类型推导.md)**

C++11 引入了 `auto` 和 `decltype` 两个关键字，让编译器自动推导变量类型，大幅简化代码：

```cpp
// auto 基本用法
auto i = 42;              // int
auto d = 3.14;            // double
auto it = data.begin();   // 自动推导迭代器类型（最常用场景）

// decltype 获取表达式类型
decltype(x) a = x;        // 与 x 同类型
decltype((x)) c = x;      // int&（双层括号返回引用）
```

**auto 使用要点**：
- 忽略顶层 const，保留底层 const
- 引用必须显式指定 `auto&`
- 初始化列表推导为 `std::initializer_list`
- 与范围 for 循环配合使用最常见

> 💡 更多 auto 高级用法、decltype 详细规则、`decltype(auto)` 等，详见 [12-类型推导](12-类型推导.md)。

## 3. 右值引用与移动语义

> 📖 **详细内容请参考：[09-移动语义与完美转发](09-移动语义与完美转发.md)**

C++11 引入右值引用（`T&&`）和移动语义，避免不必要的深拷贝，显著提升性能：

```cpp
// 移动语义：转移资源而非复制
std::string s1 = "hello";
std::string s2 = std::move(s1);  // s1 的内容转移给 s2，s1 变为空

// 移动构造 vs 拷贝构造
MyClass(MyClass&& other) noexcept;  // 移动构造：转移资源
MyClass(const MyClass& other);      // 拷贝构造：复制资源
```

**核心概念**：
- **左值 vs 右值**：左值有名字可取地址，右值是临时对象
- **std::move**：将左值转换为右值引用，表示"可以移动"
- **移动构造/赋值**：转移资源所有权，原对象变为有效但未指定状态
- **完美转发**：`std::forward<T>` 保持参数的值类别

> 💡 更多右值引用、移动语义、完美转发的深入内容，详见 [09-移动语义与完美转发](09-移动语义与完美转发.md)。

## 4. 智能指针

> 📖 **详细内容请参考：[08-智能指针与内存管理](08-智能指针与内存管理.md)**

C++11 引入三种智能指针，通过 RAII 自动管理内存生命周期：

```cpp
#include <memory>

// unique_ptr：独占所有权，不可复制
std::unique_ptr<int> p1 = std::make_unique<int>(42);

// shared_ptr：共享所有权，引用计数
std::shared_ptr<int> p2 = std::make_shared<int>(42);

// weak_ptr：弱引用，不增加引用计数
std::weak_ptr<int> wp = p2;
```

**选择指南**：
| 场景 | 推荐智能指针 |
|------|------------|
| 独占所有权 | `unique_ptr` |
| 共享所有权 | `shared_ptr` |
| 打破循环引用 | `weak_ptr` |
| 动态数组 | `unique_ptr<T[]>` |

> 💡 更多智能指针的用法、自定义删除器、性能分析等，详见 [08-智能指针与内存管理](08-智能指针与内存管理.md)。

## 5. Lambda表达式

> 📖 **详细内容请参考：[13-Lambda与函数对象](13-Lambda与函数对象.md)**

C++11 引入 Lambda 表达式，可以在代码中直接定义匿名函数：

```cpp
// 基本语法：[捕获列表](参数列表) -> 返回类型 { 函数体 }
auto add = [](int a, int b) { return a + b; };

// 捕获外部变量
int x = 10;
auto capture = [x]() { return x; };        // 值捕获
auto ref_capture = [&x]() { x++; };        // 引用捕获
auto all_value = [=]() { return x; };      // 全部值捕获
auto all_ref = [&]() { x++; };             // 全部引用捕获

// 配合 STL 算法使用
std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });
```

**捕获方式总结**：
| 捕获方式 | 说明 |
|---------|------|
| `[]` | 不捕获 |
| `[=]` | 全部值捕获 |
| `[&]` | 全部引用捕获 |
| `[x, &y]` | x值捕获，y引用捕获 |
| `[this]` | 捕获 this 指针 |

> 💡 更多 Lambda 高级用法、泛型 Lambda、std::function 等，详见 [13-Lambda与函数对象](13-Lambda与函数对象.md)。

## 6. 范围for循环

### 1. 基本用法

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <array>

int main() {
    // 数组
    int arr[] = {1, 2, 3, 4, 5};
    for (int x : arr) {
        std::cout << x << " ";
    }
    std::cout << "\n";
    
    // vector
    std::vector<int> vec = {10, 20, 30};
    for (int x : vec) {
        std::cout << x << " ";
    }
    std::cout << "\n";
    
    // 引用修改
    for (int& x : vec) {
        x *= 2;  // 修改原元素
    }
    
    // const引用（只读）
    for (const int& x : vec) {
        std::cout << x << " ";
    }
    std::cout << "\n";
    
    // map
    std::map<std::string, int> scores = {
        {"Alice", 95},
        {"Bob", 87}
    };
    for (const auto& pair : scores) {
        std::cout << pair.first << ": " << pair.second << "\n";
    }
    
    // 使用auto
    for (auto x : vec) {
        std::cout << x << " ";
    }
    std::cout << "\n";
    
    return 0;
}
```

## 7. 初始化列表与统一初始化

### 1. 统一初始化语法

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>

class Point {
public:
    int x, y;
    
    // 聚合类：可以使用花括号初始化
};

class Rectangle {
    int width, height;
public:
    Rectangle(int w, int h) : width(w), height(h) {}
    int area() const { return width * height; }
};

int main() {
    // 统一初始化：使用花括号 {}
    
    // 基本类型
    int a{10};
    double b{3.14};
    std::string s{"hello"};
    
    // 数组
    int arr[]{1, 2, 3, 4, 5};
    
    // 容器
    std::vector<int> vec{1, 2, 3, 4, 5};
    std::map<std::string, int> map{{"a", 1}, {"b", 2}};
    
    // 自定义类型
    Point p{10, 20};
    Rectangle rect{5, 10};
    
    // 防止窄化转换
    int x = 3.14;     // 警告但允许
    // int y{3.14};   // 错误：不允许窄化
    
    // 初始化列表
    auto initList = {1, 2, 3};  // std::initializer_list<int>
    
    return 0;
}
```

### 2. initializer_list

```cpp
#include <iostream>
#include <initializer_list>
#include <vector>

class MyVector {
    std::vector<int> data;
public:
    // 接受初始化列表的构造函数
    MyVector(std::initializer_list<int> list) 
        : data(list) {
        std::cout << "初始化列表构造\n";
    }
    
    void push_back(std::initializer_list<int> list) {
        for (int x : list) {
            data.push_back(x);
        }
    }
    
    void print() const {
        for (int x : data) {
            std::cout << x << " ";
        }
        std::cout << "\n";
    }
};

int main() {
    MyVector v{1, 2, 3, 4, 5};
    v.print();
    
    v.push_back({6, 7, 8});
    v.print();
    
    return 0;
}
```

## 8. nullptr与强类型枚举

### 1. nullptr

```cpp
#include <iostream>
#include <cstddef>

void func(int* p) {
    std::cout << "指针版本\n";
}

void func(int n) {
    std::cout << "整数版本\n";
}

int main() {
    // NULL的问题
    // NULL通常定义为0或((void*)0)
    // func(NULL);  // 可能调用整数版本！
    
    // nullptr：类型安全的空指针
    func(nullptr);  // 一定调用指针版本
    
    int* p1 = nullptr;
    int* p2 = NULL;
    int* p3 = 0;
    
    // nullptr可以隐式转换为任意指针类型
    char* cp = nullptr;
    double* dp = nullptr;
    
    // 不能转换为整数
    // int n = nullptr;  // 错误
    
    // 检查空指针
    if (p1 == nullptr) {
        std::cout << "p1是空指针\n";
    }
    
    return 0;
}
```

### 2. 强类型枚举

```cpp
#include <iostream>

// 旧式枚举（C风格）
enum OldColor {
    Red,
    Green,
    Blue
};

// 强类型枚举（C++11）
enum class NewColor {
    Red,
    Green,
    Blue
};

// 指定底层类型
enum class SmallColor : uint8_t {
    Red = 1,
    Green = 2,
    Blue = 3
};

int main() {
    // 旧式枚举的问题
    OldColor oc = Red;  // 污染命名空间
    int n = Red;        // 可以隐式转换为整数
    
    // 强类型枚举
    NewColor nc = NewColor::Red;  // 需要作用域
    // int m = NewColor::Red;     // 错误：不能隐式转换
    int m = static_cast<int>(NewColor::Red);  // 需要显式转换
    
    // 指定类型
    SmallColor sc = SmallColor::Green;
    std::cout << "size: " << sizeof(sc) << "\n";  // 1 byte
    
    // switch中使用
    switch (nc) {
        case NewColor::Red:
            std::cout << "红色\n";
            break;
        case NewColor::Green:
            std::cout << "绿色\n";
            break;
        case NewColor::Blue:
            std::cout << "蓝色\n";
            break;
    }
    
    return 0;
}
```

## 9. constexpr与静态断言

### 1. constexpr

```cpp
#include <iostream>
#include <array>

// constexpr：编译期常量表达式

// 编译期常量
constexpr int MAX_SIZE = 100;
constexpr double PI = 3.14159265358979;

// constexpr函数
constexpr int square(int x) {
    return x * x;
}

constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

// C++14：允许更复杂的constexpr函数
constexpr int fibonacci(int n) {
    if (n <= 1) return n;
    
    int a = 0, b = 1;
    for (int i = 2; i <= n; ++i) {
        int temp = a + b;
        a = b;
        b = temp;
    }
    return b;
}

int main() {
    // 编译期计算
    constexpr int sq = square(5);      // 编译期计算
    int arr[square(3)];                // 数组大小
    std::array<int, square(4)> arr2;   // 标准库容器大小
    
    // 运行时也可以使用
    int x = 5;
    int result = square(x);  // 运行期计算
    
    // 编译期验证
    static_assert(square(5) == 25, "square(5) should be 25");
    static_assert(factorial(5) == 120, "factorial(5) should be 120");
    
    std::cout << "5! = " << factorial(5) << "\n";
    std::cout << "fib(10) = " << fibonacci(10) << "\n";
    
    return 0;
}
```

### 2. static_assert

```cpp
#include <iostream>
#include <type_traits>

// 静态断言：编译期检查

// 模板中使用
template<typename T>
void process(T value) {
    static_assert(std::is_integral<T>::value, 
                  "T必须是整数类型");
    // ...
}

int main() {
    // 基本用法
    static_assert(sizeof(int) == 4, "int必须是4字节");
    static_assert(sizeof(void*) == 8, "必须是64位系统");
    
    // 类型检查
    static_assert(std::is_integral<int>::value, "int是整数类型");
    static_assert(std::is_pointer<int*>::value, "int*是指针类型");
    
    // 数组大小检查
    int arr[10];
    static_assert(sizeof(arr) / sizeof(arr[0]) == 10, 
                  "数组大小必须是10");
    
    return 0;
}
```
