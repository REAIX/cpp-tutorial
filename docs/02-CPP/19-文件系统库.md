## 1. 文件系统库概述

### 1. 概念与定义

**filesystem库**：C++17引入的新特性，用于支持跨平台的文件系统操作。filesystem库可以用于创建目录、删除目录、复制文件、移动文件等。例如`std::filesystem::create_directory("dir");`用于创建目录`dir`。

**路径（path）**：C++中用于表示文件或目录路径的机制。路径可以分为绝对路径、相对路径、根路径等。例如`std::filesystem::path p("/usr/local/bin");`表示绝对路径`/usr/local/bin`。

**绝对路径（absolute path）**：C++中用于表示文件或目录的完整路径。绝对路径可以从根目录开始。例如`/usr/local/bin`是绝对路径。

**相对路径（relative path）**：C++中用于表示文件或目录的相对路径。相对路径可以从当前目录开始。例如`../data.txt`是相对路径。

**目录条目（directory entry）**：C++中用于表示目录条目的机制。目录条目可以表示文件或目录。例如`std::filesystem::directory_entry entry("file.txt");`表示文件`file.txt`的目录条目。

**目录迭代器（directory iterator）**：C++中用于遍历目录的机制。目录迭代器可以遍历目录中的文件和子目录。例如`std::filesystem::directory_iterator it("dir");`用于遍历目录`dir`。

**递归目录迭代器（recursive directory iterator）**：C++中用于递归遍历目录的机制。递归目录迭代器可以遍历目录中的文件和子目录，包括子目录中的文件和子目录。例如`std::filesystem::recursive_directory_iterator it("dir");`用于递归遍历目录`dir`。

**文件状态（file status）**：C++中用于表示文件状态的机制。文件状态可以表示文件的类型、权限、大小等。例如`std::filesystem::file_status status = std::filesystem::status("file.txt");`用于获取文件`file.txt`的状态。

### 2. 什么是filesystem库

C++17引入的`<filesystem>`库提供了跨平台的文件系统操作能力，类似于Python的`os.path`和`shutil`模块。

## 2. path路径操作

### 1. 创建与基本操作

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    // 创建路径对象
    fs::path p1("/usr/local/bin");
    fs::path p2("C:\\Program Files\\MyApp");  // Windows风格
    fs::path p3 = "data/config.txt";          // 从字符串构造
    
    // 输出路径
    std::cout << "p1: " << p1 << "\n";
    std::cout << "p2: " << p2 << "\n";
    
    // 路径拼接
    fs::path p4 = p1 / "subdir" / "file.txt";  // 使用 / 运算符
    std::cout << "p4: " << p4 << "\n";
    
    // append 和 concat
    fs::path p5;
    p5 /= "home";
    p5 /= "user";
    p5 += ".txt";  // 直接追加字符串
    std::cout << "p5: " << p5 << "\n";
    
    return 0;
}
```

### 2. 路径分解

```cpp
#include <iostream>

    std::cout << "  根目录: " << p.root_directory() << "\n";
    std::cout << "  根路径: " << p.root_path() << "\n";
    std::cout << "  相对路径: " << p.relative_path() << "\n";
    std::cout << "  父路径: " << p.parent_path() << "\n";
    std::cout << "  文件名: " << p.filename() << "\n";
    std::cout << "  主干名: " << p.stem() << "\n";
    std::cout << "  扩展名: " << p.extension() << "\n";
    std::cout << "\n";
}

int main() {
    // Linux路径
    printPathInfo("/home/user/docs/report.txt");
    
    // Windows路径
    printPathInfo("C:\\Users\\Admin\\Documents\\data.csv");
    
    // 相对路径
    printPathInfo("../config/settings.json");
    
    return 0;
}
```

### 4. 路径比较与迭代

```cpp
#include <iostream>

    std::cout << "\n路径组件:\n";
    for (const auto& part : p) {
        std::cout << "  " << part << "\n";
    }
    
    return 0;
}
```

## 3. 目录操作

### 1. 创建与删除目录

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::path dir = "test_dir";
    
    // 创建目录
    fs::create_directory(dir);  // 创建单层目录
    std::cout << "目录已创建: " << dir << "\n";
    
    // 创建多层目录
    fs::create_directories(dir / "sub1" / "sub2" / "sub3");
    std::cout << "多层目录已创建\n";
    
    // 检查目录是否存在
    if (fs::exists(dir)) {
        std::cout << "目录存在\n";
    }
    
    // 判断是否为目录
    if (fs::is_directory(dir)) {
        std::cout << "是目录\n";
    }
    
    // 删除空目录
    fs::remove(dir / "sub1" / "sub2" / "sub3");
    
    // 递归删除目录及其内容
    fs::remove_all(dir);
    std::cout << "目录已删除\n";
    
    return 0;
}
```

### 2. 遍历目录

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::path dir = ".";
    
    // 方法1：directory_iterator（非递归）
    std::cout << "当前目录内容:\n";
    for (const auto& entry : fs::directory_iterator(dir)) {
        std::cout << "  " << entry.path().filename();
        if (entry.is_directory()) {
            std::cout << "/";
        }
        std::cout << "\n";
    }
    
    // 方法2：recursive_directory_iterator（递归）
    std::cout << "\n递归遍历:\n";
    for (const auto& entry : fs::recursive_directory_iterator(dir)) {
        std::cout << "  " << entry.path() << "\n";
    }
    
    return 0;
}
```

### 3. 目录遍历选项

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::path dir = ".";
    
    // 使用目录选项
    auto options = fs::directory_options::skip_permission_denied |
                   fs::directory_options::follow_directory_symlink;
    
    std::cout << "遍历目录（跳过无权限）:\n";
    for (const auto& entry : fs::directory_iterator(dir, options)) {
        std::cout << "  " << entry.path().filename() << "\n";
    }
    
    // 过滤特定类型
    std::cout << "\n只显示文件:\n";
    for (const auto& entry : fs::directory_iterator(dir)) {
        if (entry.is_regular_file()) {
            std::cout << "  " << entry.path().filename() << "\n";
        }
    }
    
    std::cout << "\n只显示目录:\n";
    for (const auto& entry : fs::directory_iterator(dir)) {
        if (entry.is_directory()) {
            std::cout << "  " << entry.path().filename() << "/\n";
        }
    }
    
    return 0;
}
```

## 4. 文件操作

### 1. 复制、移动、删除

```cpp
#include <iostream>
#include <filesystem>
#include <fstream>

namespace fs = std::filesystem;

int main() {
    // 创建测试文件
    std::ofstream("file1.txt") << "Hello, World!";
    
    // 复制文件
    fs::copy_file("file1.txt", "file2.txt");
    std::cout << "文件已复制\n";
    
    // 复制选项
    fs::copy_file("file1.txt", "file2.txt", 
                  fs::copy_options::overwrite_existing);
    
    // 复制目录
    fs::create_directory("dir1");
    fs::copy("file1.txt", "dir1/file1.txt");
    
    // 移动/重命名文件
    fs::rename("file2.txt", "renamed.txt");
    std::cout << "文件已重命名\n";
    
    // 删除文件
    fs::remove("file1.txt");
    fs::remove("renamed.txt");
    fs::remove_all("dir1");
    
    std::cout << "文件已删除\n";
    
    return 0;
}
```

### 2. 创建符号链接

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    // 创建测试文件
    std::ofstream("original.txt") << "Original content";
    
    // 创建符号链接
    fs::create_symlink("original.txt", "link_to_original");
    std::cout << "符号链接已创建\n";
    
    // 创建硬链接（仅文件）
    fs::create_hard_link("original.txt", "hardlink_to_original");
    std::cout << "硬链接已创建\n";
    
    // 检查是否为符号链接
    if (fs::is_symlink("link_to_original")) {
        std::cout << "是符号链接\n";
        // 读取链接目标
        std::cout << "目标: " << fs::read_symlink("link_to_original") << "\n";
    }
    
    // 清理
    fs::remove("original.txt");
    fs::remove("link_to_original");
    fs::remove("hardlink_to_original");
    
    return 0;
}
```

## 5. 文件属性

### 1. 获取文件信息

```cpp
#include <iostream>
#include <filesystem>
#include <chrono>

namespace fs = std::filesystem;

int main() {
    fs::path p = "example.txt";
    
    // 创建测试文件
    std::ofstream(p) << "Test content";
    
    // 文件大小
    std::cout << "文件大小: " << fs::file_size(p) << " bytes\n";
    
    // 最后修改时间
    auto ftime = fs::last_write_time(p);
    auto sctp = std::chrono::time_point_cast<std::chrono::system_clock::duration>(
        ftime - fs::file_time_type::clock::now() + std::chrono::system_clock::now()
    );
    std::time_t cftime = std::chrono::system_clock::to_time_t(sctp);
    std::cout << "最后修改时间: " << std::ctime(&cftime);
    
    // 文件状态
    fs::file_status status = fs::status(p);
    
    // 文件类型
    std::cout << "文件类型: ";
    switch (status.type()) {
        case fs::file_type::regular:    std::cout << "普通文件\n"; break;
        case fs::file_type::directory:  std::cout << "目录\n"; break;
        case fs::file_type::symlink:    std::cout << "符号链接\n"; break;
        case fs::file_type::block:      std::cout << "块设备\n"; break;
        case fs::file_type::character:  std::cout << "字符设备\n"; break;
        case fs::file_type::fifo:       std::cout << "管道\n"; break;
        case fs::file_type::socket:     std::cout << "套接字\n"; break;
        case fs::file_type::unknown:    std::cout << "未知\n"; break;
        case fs::file_type::not_found:  std::cout << "不存在\n"; break;
    }
    
    // 文件权限
    fs::perms pperms = status.permissions();
    std::cout << "权限: " << std::oct << static_cast<unsigned>(pperms) << "\n";
    
    // 硬链接数
    std::cout << "硬链接数: " << fs::hard_link_count(p) << "\n";
    
    // 空间信息
    fs::space_info space = fs::space(".");
    std::cout << "\n磁盘空间:\n";
    std::cout << "  总空间: " << space.capacity / (1024*1024*1024) << " GB\n";
    std::cout << "  可用空间: " << space.available / (1024*1024*1024) << " GB\n";
    std::cout << "  已用空间: " << (space.capacity - space.free) / (1024*1024*1024) << " GB\n";
    
    // 清理
    fs::remove(p);
    
    return 0;
}
```

### 2. 文件权限操作

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::path p = "test_file.txt";
    std::ofstream(p) << "test";
    
    // 获取权限
    fs::perms pperms = fs::status(p).permissions();
    
    // 权限常量
    std::cout << "权限检查:\n";
    std::cout << "  所有者读: " << static_cast<bool>(pperms & fs::perms::owner_read) << "\n";
    std::cout << "  所有者写: " << static_cast<bool>(pperms & fs::perms::owner_write) << "\n";
    std::cout << "  所有者执行: " << static_cast<bool>(pperms & fs::perms::owner_exec) << "\n";
    
    // 修改权限
    fs::permissions(p, 
                    fs::perms::owner_read | fs::perms::owner_write,
                    fs::perm_options::replace);
    std::cout << "\n权限已修改为只读写\n";
    
    // 添加权限
    fs::permissions(p, fs::perms::owner_all, fs::perm_options::add);
    
    // 移除权限
    fs::permissions(p, fs::perms::group_write, fs::perm_options::remove);
    
    fs::remove(p);
    return 0;
}
```

## 6. 实用示例

### 1. 文件搜索工具

```cpp
#include <iostream>
#include <filesystem>
#include <string>
#include <regex>

namespace fs = std::filesystem;

// 搜索匹配模式的文件
void searchFiles(const fs::path& dir, const std::string& pattern) {
    std::regex re(pattern);
    
    for (const auto& entry : fs::recursive_directory_iterator(dir)) {
        if (entry.is_regular_file()) {
            std::string filename = entry.path().filename().string();
            if (std::regex_search(filename, re)) {
                std::cout << entry.path() << "\n";
            }
        }
    }
}

int main() {
    std::cout << "搜索所有.cpp文件:\n";
    searchFiles(".", "\\.cpp$");
    
    std::cout << "\n搜索所有test开头的文件:\n";
    searchFiles(".", "^test");
    
    return 0;
}
```

### 2. 目录大小统计

```cpp
#include <iostream>
#include <filesystem>
#include <unordered_map>

namespace fs = std::filesystem;

// 计算目录大小
std::uintmax_t calculateDirectorySize(const fs::path& dir) {
    std::uintmax_t size = 0;
    
    for (const auto& entry : fs::recursive_directory_iterator(dir)) {
        if (entry.is_regular_file()) {
            size += entry.file_size();
        }
    }
    
    return size;
}

// 按扩展名统计
void analyzeByExtension(const fs::path& dir) {
    std::unordered_map<std::string, std::uintmax_t> extSizes;
    std::unordered_map<std::string, int> extCounts;
    
    for (const auto& entry : fs::recursive_directory_iterator(dir)) {
        if (entry.is_regular_file()) {
            std::string ext = entry.path().extension().string();
            if (ext.empty()) ext = "(no extension)";
            
            extSizes[ext] += entry.file_size();
            extCounts[ext]++;
        }
    }
    
    std::cout << "\n扩展名统计:\n";
    for (const auto& [ext, size] : extSizes) {
        std::cout << ext << ": " << extCounts[ext] << " 个文件, "
                  << size / 1024.0 << " KB\n";
    }
}

int main() {
    fs::path dir = ".";
    
    std::cout << "目录大小: " 
              << calculateDirectorySize(dir) / (1024.0 * 1024.0) 
              << " MB\n";
    
    analyzeByExtension(dir);
    
    return 0;
}
```

### 3. 目录同步工具

```cpp
#include <iostream>
#include <filesystem>
#include <fstream>

namespace fs = std::filesystem;

// 同步两个目录
void syncDirectories(const fs::path& src, const fs::path& dst) {
    // 确保目标目录存在
    fs::create_directories(dst);
    
    // 遍历源目录
    for (const auto& entry : fs::directory_iterator(src)) {
        fs::path srcPath = entry.path();
        fs::path dstPath = dst / entry.path().filename();
        
        if (entry.is_directory()) {
            // 递归同步子目录
            syncDirectories(srcPath, dstPath);
        }
        else if (entry.is_regular_file()) {
            // 检查是否需要复制
            bool needCopy = !fs::exists(dstPath);
            
            if (!needCopy) {
                // 比较修改时间
                auto srcTime = fs::last_write_time(srcPath);
                auto dstTime = fs::last_write_time(dstPath);
                needCopy = srcTime > dstTime;
            }
            
            if (needCopy) {
                fs::copy_file(srcPath, dstPath, 
                              fs::copy_options::overwrite_existing);
                std::cout << "已复制: " << srcPath << " -> " << dstPath << "\n";
            }
        }
    }
}

int main() {
    fs::path srcDir = "source";
    fs::path dstDir = "backup";
    
    // 创建测试目录
    fs::create_directories(srcDir);
    std::ofstream(srcDir / "file1.txt") << "Content 1";
    std::ofstream(srcDir / "file2.txt") << "Content 2";
    
    // 同步
    syncDirectories(srcDir, dstDir);
    
    // 清理
    fs::remove_all(srcDir);
    fs::remove_all(dstDir);
    
    return 0;
}
```

### 4. 路径规范化

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    // 相对路径转换
    fs::path relative = "../data/./config/../files/test.txt";
    fs::path absolute = fs::absolute(relative);
    fs::path canonical = fs::canonical(relative);
    
    std::cout << "原始路径: " << relative << "\n";
    std::cout << "绝对路径: " << absolute << "\n";
    std::cout << "规范路径: " << canonical << "\n";
    
    // 相对路径计算
    fs::path p1 = "/home/user/docs/report.txt";
    fs::path p2 = "/home/user/projects/main.cpp";
    fs::path rel = fs::relative(p1, p2);
    
    std::cout << "\n从 " << p2 << " 到 " << p1 << "\n";
    std::cout << "相对路径: " << rel << "\n";
    
    // 路径规范化（移除 . 和 ..）
    fs::path messy = "/a/b/../c/./d/../e";
    fs::path clean = messy.lexically_normal();
    std::cout << "\n规范化: " << messy << " -> " << clean << "\n";
    
    return 0;
}
```

## 总结

### 5. 常用操作速查

| 操作 | 函数 |
|------|------|
| 检查存在 | `fs::exists(path)` |
| 判断是文件 | `fs::is_regular_file(path)` |
| 判断是目录 | `fs::is_directory(path)` |
| 创建目录 | `fs::create_directory(path)` |
| 创建多层目录 | `fs::create_directories(path)` |
| 删除文件/空目录 | `fs::remove(path)` |
| 递归删除 | `fs::remove_all(path)` |
| 复制文件 | `fs::copy_file(src, dst)` |
| 移动/重命名 | `fs::rename(old, new)` |
| 获取文件大小 | `fs::file_size(path)` |
| 获取修改时间 | `fs::last_write_time(path)` |
| 遍历目录 | `fs::directory_iterator(path)` |
| 递归遍历 | `fs::recursive_directory_iterator(path)` |

### 6. 最佳实践

```
□ 使用 fs::path 代替字符串处理路径
□ 创建目录前检查是否存在
□ 使用 create_directories 创建多层目录
□ 遍历目录时处理异常
□ 大文件操作时检查空间
□ 使用相对路径时注意当前工作目录
```
