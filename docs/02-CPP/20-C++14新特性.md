# C++14新特性

> C++14标准增量改进与实用特性

---

> **C++14 is a relatively small extension of C++11, but it fills important gaps and makes the language more complete.** — Bjarne Stroustrup
> （C++14是对C++11的较小扩展，但它填补了重要的空白，使语言更完整。）

> **C++14不是革命，而是进化——让C++11的好东西更好用。**
> （C++14 is not a revolution, but an evolution—making C++11's good things even better.）

---

> **🎯 小步快跑，持续改进。**
>
> （C++14虽小，但每个改进都直击痛点。）

---

> 💡 **通俗理解 - C++14是什么？**
>
> 如果C++11是一次大装修，那C++14就是装修后的"补漏"：
> - C++11引入了auto，但函数返回类型还得手写？C++14让auto也能推导返回类型了
> - C++11有了Lambda，但模板参数还得写？C++14让Lambda也支持泛型了
> - C++11有了unique_ptr，但创建还得写new？C++14有了make_unique
>
> **C++14 = C++11的"补丁包"**，让现代C++更顺手。

## 1. C++14增强特性

### 1. 返回类型推导

```cpp
#include <iostream>
#include <vector>

// C++11：需要尾置返回类型
auto add11(int a, int b) -> int {
    return a + b;
}

// C++14：自动推导返回类型
auto add14(int a, int b) {
    return a + b;  // 自动推导为int
}

// 递归函数也可以
auto factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

// 返回类型可能不同时，需要统一
template<typename T, typename U>
auto add(T t, U u) {
    return t + u;  // 自动推导
}

int main() {
    std::cout << add14(3, 4) << "\n";
    std::cout << add(1, 2.5) << "\n";  // double
    
    return 0;
}
```

### 2. 泛型Lambda

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    // C++11：需要显式指定参数类型
    auto add11 = [](int a, int b) { return a + b; };
    
    // C++14：泛型lambda（使用auto）
    auto add14 = [](auto a, auto b) { return a + b; };
    
    std::cout << add14(1, 2) << "\n";       // int
    std::cout << add14(1.5, 2.5) << "\n";   // double
    std::cout << add14(1, 2.5) << "\n";     // double
    
    // 在算法中使用
    std::vector<int> v1 = {3, 1, 4, 1, 5};
    std::vector<double> v2 = {3.5, 1.5, 4.5};
    
    // 同一个lambda可用于不同类型
    auto printer = [](const auto& val) {
        std::cout << val << " ";
    };
    
    std::for_each(v1.begin(), v1.end(), printer);
    std::cout << "\n";
    std::for_each(v2.begin(), v2.end(), printer);
    std::cout << "\n";
    
    return 0;
}
```

### 3. Lambda初始化捕获

```cpp
#include <iostream>
#include <memory>

int main() {
    // C++14：初始化捕获（Init Capture / Generalized Lambda Capture）
    // 将变量移动到lambda中
    auto pData = std::make_unique<int>(42);
    
    auto func = [ptr = std::move(pData)] {
        std::cout << "数据: " << *ptr << "\n";
    };
    // pData 已被移动，不再有效
    func();
    
    // 捕获表达式结果
    auto lambda = [result = 1 + 2 + 3] {
        return result;
    };
    std::cout << "捕获计算结果: " << lambda() << "\n";
    
    // 实现移动捕获的函数对象
    std::string str = "hello world";
    auto move_capture = [s = std::move(str)] {
        std::cout << s << "\n";
    };
    // 此时str为空
    move_capture();
    
    // 按引用捕获表达式
    int x = 10;
    auto ref_capture = [&ref = x] {
        ref = 20;
    };
    ref_capture();
    std::cout << "x = " << x << "\n";  // 20
    
    return 0;
}
```

### 4. make_unique

```cpp
#include <iostream>
#include <memory>

class Widget {
public:
    Widget(int id, std::string name) 
        : id_(id), name_(std::move(name)) {
        std::cout << "Widget created: " << name_ << "\n";
    }
    ~Widget() {
        std::cout << "Widget destroyed: " << name_ << "\n";
    }
private:
    int id_;
    std::string name_;
};

int main() {
    // C++11：make_shared存在，但make_unique不存在
    // auto p1 = std::make_unique<Widget>(1, "w1");  // C++11不支持
    
    // C++14：make_unique
    auto p1 = std::make_unique<Widget>(1, "Widget1");
    auto p2 = std::make_unique<Widget>(2, "Widget2");
    
    // 数组版本
    auto arr = std::make_unique<int[]>(10);
    for (int i = 0; i < 10; ++i) {
        arr[i] = i * i;
    }
    
    return 0;
}
```

### 5. constexpr增强（C++14放宽的条件）

```cpp
#include <iostream>
#include <array>

// C++11的constexpr函数限制很多：只能包含一个return语句
constexpr int factorial11(int n) {
    return n <= 1 ? 1 : n * factorial11(n - 1);
}

// C++14的constexpr函数可以包含：
// - 局部变量
// - 循环
// - 分支语句
// - 多个return语句
constexpr int factorial14(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

// constexpr可以修改局部变量
constexpr int fibonacci(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; ++i) {
        int temp = a + b;
        a = b;
        b = temp;
    }
    return b;
}

// constexpr支持switch语句
constexpr const char* to_string(int n) {
    switch (n) {
        case 0: return "zero";
        case 1: return "one";
        default: return "unknown";
    }
}

// constexpr对象
constexpr auto fact5 = factorial14(5);    // 编译期计算
constexpr auto fib10 = fibonacci(10);     // 55
constexpr auto str = to_string(1);        // "one"

// constexpr数组
constexpr auto make_squares() {
    std::array<int, 5> squares = {};
    for (int i = 0; i < 5; ++i) {
        squares[i] = i * i;
    }
    return squares;
}

constexpr auto squares = make_squares();

static_assert(fact5 == 120, "factorial14(5) should be 120");
static_assert(fib10 == 55, "fibonacci(10) should be 55");

int main() {
    std::cout << "factorial14(5) = " << fact5 << "\n";
    std::cout << "fibonacci(10) = " << fib10 << "\n";
    std::cout << "to_string(1) = " << str << "\n";
    std::cout << "squares[3] = " << squares[3] << "\n";  // 9
    
    constexpr int runtime_val = 6;
    constexpr auto fact6 = factorial14(runtime_val);
    std::cout << "factorial14(6) = " << fact6 << "\n";  // 720
    
    return 0;
}
```

| C++11 constexpr | C++14 constexpr |
|---|---|
| 只能包含一个return语句 | 可包含局部变量、循环、分支 |
| 不能修改局部变量 | 可以修改局部变量 |
| 不能有if/switch | 可以有if/switch |
| 不能有for/while | 可以有for/while |
| 递归有限制 | 递归更灵活 |

### 7. [[deprecated]]属性

```cpp
#include <iostream>

// 标记函数已弃用

void old_function() {
    std::cout << "This function is deprecated\n";

    std::cout << "Legacy API\n";

    void do_something() {}

    Value1,
```

### 8. std::exchange

```cpp
#include <iostream>
#include <utility>
#include <vector>
#include <memory>

// std::exchange 用新值替换旧值，并返回旧值

void exchange_demo() {
    int a = 10;
    int b = 20;
    
    // 交换并返回旧值
    int old = std::exchange(a, b);
    std::cout << "a = " << a << ", b = " << b << ", old = " << old << "\n";
    // a = 20, b = 20, old = 10
    
    // 实现移动赋值
    std::string s1 = "hello";
    std::string s2 = "world";
    s1 = std::exchange(s2, std::string());  // s1 = "world", s2变为空
    std::cout << "s1 = " << s1 << ", s2 = '" << s2 << "'\n";
}

// std::exchange 的典型应用

// 1. 实现移动构造函数
class MyBuffer {
public:
    MyBuffer(size_t size) : data_(new char[size]), size_(size) {}
    
    // 移动构造函数
    MyBuffer(MyBuffer&& other) noexcept
        : data_(std::exchange(other.data_, nullptr))
        , size_(std::exchange(other.size_, 0)) {}
    
    // 移动赋值运算符
    MyBuffer& operator=(MyBuffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = std::exchange(other.data_, nullptr);
            size_ = std::exchange(other.size_, 0);
        }
        return *this;
    }
    
    ~MyBuffer() { delete[] data_; }
    
private:
    char* data_;
    size_t size_;
};

// 2. 实现自增ID生成器
class IDGenerator {
public:
    int next() {
        return current_++;  // 传统方式
    }
    
    int next_exchange() {
        return std::exchange(current_, current_ + 1);
    }
private:
    int current_ = 0;
};

// 3. 线程安全的标志位操作（配合原子操作）
#include <atomic>
void atomic_exchange_demo() {
    std::atomic<bool> flag{false};
    
    // 获取旧值并设置新值
    bool old = flag.exchange(true);
    
    // 如果flag为false，设置为true并返回true
    bool expected = false;
    bool success = flag.compare_exchange_strong(expected, true);
}

int main() {
    exchange_demo();
    
    // 4. 在容器中转移unique_ptr
    std::vector<std::unique_ptr<int>> vec;
    auto ptr = std::make_unique<int>(42);
    
    // 将ptr移动到vector中，ptr变为空
    vec.push_back(std::exchange(ptr, nullptr));
    std::cout << "ptr is null: " << (ptr == nullptr) << "\n";
    
    return 0;
}
```

### 9. std::quoted

```cpp
#include <iostream>
#include <iomanip>
#include <sstream>
#include <string>

// std::quoted 用于处理带引号和转义的字符串

void quoted_demo() {
    // 1. 输出带引号的字符串
    std::string s1 = "hello \"world\"";
    std::cout << "普通输出: " << s1 << "\n";
    std::cout << "quoted输出: " << std::quoted(s1) << "\n";
    // 输出: "hello \"world\""
    
    // 2. 使用自定义分隔符和转义符
    std::cout << "自定义引号: " << std::quoted(s1, '\'') << "\n";
    // 输出: 'hello "world"'
    
    // 3. 从带引号的字符串中解析
    std::string input = R"("hello \"world\"")";
    std::istringstream iss(input);
    std::string parsed;
    
    iss >> std::quoted(parsed);
    std::cout << "解析结果: " << parsed << "\n";
    // 输出: hello "world"
    
    // 4. CSV格式处理
    std::vector<std::string> fields = {
        "simple",
        "contains spaces",
        "contains \"quotes\"",
        "contains, commas"
    };
    
    std::cout << "\nCSV输出:\n";
    for (size_t i = 0; i < fields.size(); ++i) {
        if (i > 0) std::cout << ", ";
        std::cout << std::quoted(fields[i]);
    }
    std::cout << "\n";
    
    // 5. 读写配置文件
    auto write_config = [](const std::string& key, const std::string& value) {
        std::cout << std::quoted(key) << " = " << std::quoted(value) << "\n";
    };
    
    auto read_config = [](const std::string& line) -> std::pair<std::string, std::string> {
        std::istringstream iss(line);
        std::string key, eq, value;
        iss >> std::quoted(key) >> eq >> std::quoted(value);
        return {key, value};
    };
    
    write_config("name", "John \"Johnny\" Doe");
    write_config("path", "C:\\Program Files\\My App");
    
    std::string config_line = R"("user name" = "Alice \"Bob\" Smith")";
    auto [key, val] = read_config(config_line);
    std::cout << "key = " << key << ", value = " << val << "\n";
}

int main() {
    quoted_demo();
    return 0;
}
```

### 10. 聚合体成员初始化（Aggregate Member Initialization）

```cpp
#include <iostream>
#include <string>
#include <vector>

// C++11：聚合体不能有用户定义的默认初始化
struct Point {
    int x;
    int y;
    // int z = 0;  // C++11：如果有了默认初始化，就不再是聚合体
};

// C++14：允许聚合体中有默认成员初始化
struct Point14 {
    int x = 0;
    int y = 0;
    int z = 0;
};

// 实际应用：配置结构体
struct AppConfig {
    std::string app_name = "MyApp";
    int port = 8080;
    bool enable_logging = true;
    int max_connections = 100;
    std::string log_path = "./logs";
};

// 继承中的聚合体
struct Base14 {
    int base_val = 10;
};

struct Derived14 : Base14 {
    int derived_val = 20;
};

// 模板聚合体
template<typename T>
struct Vec3 {
    T x = T{};
    T y = T{};
    T z = T{};
};

void aggregate_demo() {
    // C++14聚合初始化
    Point14 p1{1, 2, 3};       // 完全初始化
    Point14 p2{1, 2};          // z使用默认值0
    Point14 p3{};              // 全部使用默认值
    
    std::cout << "p1: " << p1.x << ", " << p1.y << ", " << p1.z << "\n";
    std::cout << "p2: " << p2.x << ", " << p2.y << ", " << p2.z << "\n";
    std::cout << "p3: " << p3.x << ", " << p3.y << ", " << p3.z << "\n";
    
    // 配置结构体的部分初始化
    AppConfig config1{};                          // 全部默认
    AppConfig config2{"MyServer", 3000};          // 自定义名称和端口
    AppConfig config3{"MyServer", 3000, false};   // 禁用日志
    
    std::cout << "config2: " << config2.app_name 
              << " on port " << config2.port << "\n";
    
    // 基类聚合体的聚合初始化
    Derived14 d{};
    std::cout << "derived base_val: " << d.base_val 
              << ", derived_val: " << d.derived_val << "\n";
    
    // 模板聚合体
    Vec3<int> vi{1, 2, 3};
    Vec3<double> vd{1.5, 2.5};
    std::cout << "vi: " << vi.x << ", " << vi.y << ", " << vi.z << "\n";
    std::cout << "vd: " << vd.x << ", " << vd.y << ", " << vd.z << "\n";
}

int main() {
    aggregate_demo();
    return 0;
}
```

### 11. 变量模板（Variable Templates）

```cpp
#include <iostream>
#include <cmath>
#include <limits>

// C++14：变量模板
template<typename T>
constexpr T pi_v = T(3.14159265358979323846);

// 类型特化
template<>
constexpr float pi_v<float> = float(3.14159265358979323846);

template<>
constexpr double pi_v<double> = double(3.14159265358979323846);

// 应用：数学常量
template<typename T>
constexpr T e_v = T(2.718281828459045);

// 单位转换系数
template<typename T>
constexpr T degrees_to_radians = pi_v<T> / T(180);

template<typename T>
constexpr T radians_to_degrees = T(180) / pi_v<T>;

// 类型萃取辅助
template<typename T>
constexpr bool is_floating_point_v = std::is_floating_point<T>::value;

template<typename T>
constexpr bool is_integral_v = std::is_integral<T>::value;

// 编译期计算
template<size_t N>
constexpr size_t factorial_v = N * factorial_v<N - 1>;

template<>
constexpr size_t factorial_v<0> = 1;

// 编译期斐波那契
template<size_t N>
constexpr size_t fibonacci_v = fibonacci_v<N - 1> + fibonacci_v<N - 2>;

template<>
constexpr size_t fibonacci_v<0> = 0;

template<>
constexpr size_t fibonacci_v<1> = 1;

// 使用变量模板
void variable_template_demo() {
    double radius = 5.0;
    double area = pi_v<double> * radius * radius;
    std::cout << "面积: " << area << "\n";
    
    float angle_deg = 45.0f;
    float angle_rad = angle_deg * degrees_to_radians<float>;
    std::cout << "45度 = " << angle_rad << " 弧度\n";
    
    // 编译期常量
    constexpr auto fact5 = factorial_v<5>;
    constexpr auto fib10 = fibonacci_v<10>;
    
    std::cout << "5! = " << fact5 << "\n";     // 120
    std::cout << "fib(10) = " << fib10 << "\n"; // 55
    
    static_assert(fact5 == 120, "");
    static_assert(fib10 == 55, "");
}

int main() {
    variable_template_demo();
    return 0;
}
```

### 12. C++14相对于C++11的改进总结

| 特性 | C++11 | C++14 |
|------|-------|-------|
| **函数返回类型推导** | 不支持（需尾置返回） | 支持auto推导 |
| **泛型Lambda** | 不支持 | 支持auto参数 |
| **Lambda初始化捕获** | 不支持 | 支持捕获表达式 |
| **constexpr** | 单语句、无副作用 | 多语句、循环、分支、变量修改 |
| **make_unique** | 不存在 | 标准库提供 |
| **二进制字面量** | 不支持 | 0b前缀 |
| **数字分隔符** | 不支持 | '分隔 |
| **[[deprecated]]** | 不支持 | 标准属性 |
| **std::exchange** | 不存在 | 标准库提供 |
| **std::quoted** | 不存在 | 标准库提供 |
| **聚合体成员初始化** | 破坏聚合体 | 允许默认初始化 |
| **变量模板** | 不支持 | 支持 |
| **constexpr成员函数** | 隐式const | 不要求const |

### 15. C++14设计哲学

C++14的核心设计理念是"完善C++11"，而非引入革命性的新特性。它修复了C++11中的许多不便之处，使得日常编程更加顺畅：

- **减少样板代码**：返回类型推导、泛型Lambda、变量模板
- **增强编译期计算**：constexpr增强使得更多计算可在编译期完成
- **完善标准库**：make_unique填补了C++11的疏忽、std::exchange和std::quoted填补了实用工具的空白
- **提升可读性**：二进制字面量、数字分隔符、[[deprecated]]

## 2. 问题解答

### 1. Q: 为什么要使用C++11/14新特性？
A: C++11/14新特性可以提高代码可读性、可维护性、可扩展性和可测试性，减少错误和bug，提高开发效率。例如，`auto`可以自动推导类型，减少代码冗长；`智能指针`可以自动管理内存，避免内存泄漏；`Lambda`可以简化代码，提高可读性。

### 2. Q: 如何选择C++版本？
A: 应该根据项目的需求和团队的习惯选择C++版本。如果项目需要使用现代C++特性，应该选择C++11或更高版本；如果项目需要兼容旧代码，应该选择C++98/03。

### 3. Q: 如何迁移到C++11/14？
A: 迁移到C++11/14的步骤：
1. 升级编译器到支持C++11/14的版本
2. 逐步替换旧代码为新特性
3. 测试代码，确保正确性
4. 优化代码，提高性能

### 4. Q: C++14相比C++11最重要的改进是什么？
A: C++14最重要的改进是：泛型Lambda使得编写通用代码更加简单；constexpr增强让编译期计算更加实用；make_unique弥补了C++11智能指针体系的缺口；返回类型推导简化了模板代码的编写。

### 5. Q: 什么是右值引用？
A: 右值引用是C++11引入的新特性，用于支持移动语义。右值引用可以绑定到临时对象，避免拷贝，提高性能。例如，`std::move`可以将左值转换为右值引用，用于移动构造和移动赋值。

### 6. Q: 什么是智能指针？
A: 智能指针是C++11引入的新特性，用于自动管理内存。智能指针可以自动释放内存，避免内存泄漏。常见的智能指针有`std::unique_ptr`、`std::shared_ptr`和`std::weak_ptr`。

### 7. Q: 什么是Lambda表达式？
A: Lambda表达式是C++11引入的新特性，用于创建匿名函数。Lambda表达式可以简化代码，提高可读性。Lambda表达式可以捕获变量，用于函数式编程。

### 8. Q: 什么是范围for循环？
A: 范围for循环是C++11引入的新特性，用于简化遍历容器。范围for循环可以自动遍历容器的所有元素，避免手动管理迭代器。例如，`for (auto& x : vec)`可以遍历`vec`的所有元素。
