> 💡 **通俗理解 - 什么是线程？**

想象你在玩游戏：
- **单线程**：你一个人既要操作角色，又要播放音乐，还要更新画面 → 忙不过来
- **多线程**：有三个"你"同时工作，一个操作角色，一个播放音乐，一个更新画面 → 流畅！

**线程就是程序里的"做事单元"！**

- **进程**：就像一个"工厂"（程序运行的实例）
- **线程**：就像工厂里的"工人"（实际执行任务的单元）
- 一个工厂可以有多个工人，一个进程可以有多个线程

> 🔬 **抽象理解 - 线程与进程**：
> - **进程**：拥有独立内存空间的程序实例，资源分配的基本单位
> - **线程**：进程内的执行单元，调度的基本单位，共享进程资源
> - **并发**：多个线程交替执行（单核CPU快速切换）
> - **并行**：多个线程同时执行（多核CPU真正同时运行）
> - **std::thread**：C++11引入的线程库，用于创建和管理线程
> - **join()**：等待线程执行完毕，主线程阻塞
> - **detach()**：分离线程，让其在后台独立运行
> - **线程安全**：多线程访问共享资源时不会出现问题

## 1. 线程概念

### 1. 进程与线程

**进程**：程序运行的实例，拥有独立的内存空间。每个进程都有自己的代码段、数据段、堆、栈等。

**线程**：进程内的执行单元，共享进程的资源。一个进程可以包含多个线程，这些线程共享进程的内存空间、文件描述符等资源。

```
进程（工厂）
├── 线程1（工人A）- 洗菜
├── 线程2（工人B）- 切菜
├── 线程3（工人C）- 炒菜
└── 共享资源（厨房、食材、工具）
```

### 2. 并发与并行

**并发**：多个任务交替执行，单核CPU通过快速切换实现"看起来同时运行"。

**并行**：多个任务真正同时执行，需要多核CPU支持。

```
并发（单核）：
时间轴 →
任务A: ████    ████
任务B:    ████    ████

并行（多核）：
CPU1: ████████████
CPU2: ████████████
```

## 2. 创建线程

### 1. 基本语法

```cpp
#include <thread>

// 创建线程
std::thread t(函数名, 参数1, 参数2, ...);
```

### 2. 方式1：函数指针

```cpp
#include <iostream>
#include <thread>

void printHello() {
    std::cout << "Hello from thread!" << std::endl;
}

int main() {
    std::thread t(printHello);  // 创建线程执行printHello
    t.join();  // 等待线程结束
    return 0;
}
```

### 3. 方式2：Lambda表达式

```cpp
std::thread t([]() {
    std::cout << "Hello from Lambda!" << std::endl;
});
t.join();
```

### 4. 方式3：函数对象（仿函数）

```cpp
class Task {
public:
    void operator()() const {
        std::cout << "Hello from functor!" << std::endl;
    }
};

Task task;
std::thread t(task);
t.join();
```

### 5. 方式4：成员函数

```cpp
class Worker {
public:
    void work() {
        std::cout << "Working..." << std::endl;
    }
};

Worker worker;
std::thread t(&Worker::work, &worker);  // 成员函数指针 + 对象指针
t.join();
```

### 6. 传递参数

```cpp
void printMessage(const std::string& msg, int count) {
    for (int i = 0; i < count; ++i) {
        std::cout << msg << std::endl;
    }
}

std::thread t(printMessage, "Hello", 5);  // 参数传递
t.join();
```

> ⚠️ **重要**：`std::thread` 默认**按值拷贝**所有参数，即使函数参数是引用类型。如果需要真正按引用传递，必须使用 `std::ref()` 或 `std::cref()`：
>
> ```cpp
> void increment(int& n) { n++; }
>
> int x = 10;
> // std::thread t(increment, x);      // ❌ 编译错误！std::thread会拷贝x，无法绑定到引用
> std::thread t(increment, std::ref(x)); // ✅ 使用std::ref传递引用
> t.join();
> // 此时 x == 11
> ```
>
> 同理，传递指针时也是安全的，因为指针本身被拷贝，指向的对象不变。

## 3. 线程管理

### 1. join() - 等待线程

```cpp
std::thread t([]() {
    std::this_thread::sleep_for(std::chrono::seconds(2));
    std::cout << "Thread finished!" << std::endl;
});

std::cout << "Waiting for thread..." << std::endl;
t.join();  // 阻塞，等待线程执行完毕
std::cout << "Main thread continues!" << std::endl;
```

### 2. detach() - 分离线程

```cpp
std::thread t([]() {
    std::this_thread::sleep_for(std::chrono::seconds(2));
    std::cout << "Detached thread finished!" << std::endl;
});

t.detach();  // 分离线程，不等待
std::cout << "Main thread continues!" << std::endl;
// 注意：分离后不能再join
```

### 3. RAII管理线程

```cpp
class ThreadGuard {
    std::thread& t;
public:
    explicit ThreadGuard(std::thread& t_) : t(t_) {}
    ~ThreadGuard() {
        if (t.joinable()) {
            t.join();  // 析构时自动join
        }
    }
    ThreadGuard(const ThreadGuard&) = delete;
    ThreadGuard& operator=(const ThreadGuard&) = delete;
};

{
    std::thread t([]() { /* ... */ });
    ThreadGuard guard(t);
    // 离开作用域时自动join
}
```

## 4. 线程属性

### 1. 获取线程ID

```cpp
std::thread t([]() {
    std::cout << "Thread ID: " << std::this_thread::get_id() << std::endl;
});

std::cout << "Thread ID: " << t.get_id() << std::endl;
t.join();
```

### 2. 获取硬件并发数

```cpp
unsigned int cores = std::thread::hardware_concurrency();
std::cout << "Hardware concurrency: " << cores << std::endl;
```

### 3. 检查joinable状态

```cpp
std::thread t([]() { /* ... */ });
std::cout << "Joinable: " << (t.joinable() ? "Yes" : "No") << std::endl;
t.join();
std::cout << "Joinable after join: " << (t.joinable() ? "Yes" : "No") << std::endl;
```

### 4. 线程休眠

```cpp
#include <chrono>
#include <thread>

std::this_thread::sleep_for(std::chrono::milliseconds(100));  // 休眠100毫秒
std::this_thread::sleep_for(std::chrono::seconds(2));         // 休眠2秒
```

### 5. 让出CPU

```cpp
std::this_thread::yield();  // 让出CPU，让其他线程执行
```

## 5. 注意事项

### 1. 必须join或detach

```cpp
// 错误示例
{
    std::thread t([]() { /* ... */ });
    // 离开作用域，t被销毁但没有join或detach
    // 程序终止！
}

// 正确示例
{
    std::thread t([]() { /* ... */ });
    t.join();  // 或 t.detach();
}
```

### 2. 不能重复join

```cpp
std::thread t([]() { /* ... */ });
t.join();
// t.join();  // 错误！不能重复join
```

### 3. detach后不能再join

```cpp
std::thread t([]() { /* ... */ });
t.detach();
// t.join();  // 错误！已分离
```

### 4. 避免引用临时变量

```cpp
// 错误示例
{
    int x = 10;
    std::thread t([&x]() {  // 引用局部变量
        std::cout << x << std::endl;  // 危险！x可能已销毁
    });
    t.detach();
}  // x在这里被销毁

// 正确示例：传值
int x = 10;
std::thread t([x]() {
    std::cout << x << std::endl;
});
t.detach();
```

## 总结

| 操作 | 说明 |
|-----|------|
| `std::thread t(func, args...)` | 创建线程 |
| `t.join()` | 等待线程结束 |
| `t.detach()` | 分离线程 |
| `t.joinable()` | 检查是否可join |
| `t.get_id()` | 获取线程ID |
| `std::this_thread::get_id()` | 获取当前线程ID |
| `std::this_thread::sleep_for(duration)` | 线程休眠 |
| `std::thread::hardware_concurrency()` | 获取硬件并发数 |
