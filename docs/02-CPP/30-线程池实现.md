> 💡 **通俗理解 - 什么是线程池？**

想象餐厅请服务员：
- **没有线程池**：来一个客人请一个服务员 → 忙不过来
- **有线程池**：固定请10个服务员 → 永远够用

**线程池就是"预雇好的服务员团队"！**

- 预先创建好一批线程
- 有任务来了，分给空闲的线程
- 做完任务后，线程回到池里等待新任务
- 不用每次都重新"雇人"（创建线程）

> 🔬 **抽象理解 - 资源池化思想**：
> - **线程池**：是"预分配资源"的思想，避免频繁创建和销毁线程的开销
> - **任务队列**：是"生产者-消费者模式"，任务提交和执行解耦
> - **工作线程**：是"消费者"，从队列取任务执行
> - **线程数确定**：需要根据任务类型（CPU密集vs I/O密集）和硬件配置来确定
> - **拒绝策略**：当任务队列满时的处理方式（拒绝、阻塞、丢弃等）
> - **线程池的本质**：是"资源管理"和"任务调度"的组合，提高系统吞吐量和响应速度

## 1. 线程池概述

### 1. 概念与定义

**线程池（thread pool）**：一种多线程处理模式，预先创建一定数量的线程，将任务放入队列，由空闲线程自动获取执行。线程池可以减少线程创建销毁开销，控制并发数量，提高响应速度。

**任务队列（task queue）**：存储待执行任务的队列。任务队列可以是FIFO队列、优先级队列等。

**工作线程（worker thread）**：线程池中的线程，用于执行任务。工作线程可以是固定数量的，也可以是动态调整的。

**任务（task）**：线程池执行的单元。任务可以是函数指针、Lambda表达式、函数对象等。

**线程池大小（pool size）**：线程池中工作线程的数量。线程池大小可以是固定的，也可以是动态调整的。

**任务调度（task scheduling）**：线程池选择任务执行的方式。任务调度可以是FIFO、优先级、负载均衡等。

**线程池关闭（shutdown）**：线程池停止接受新任务，等待所有任务执行完成，然后关闭工作线程。

**线程池终止（terminate）**：线程池立即停止所有任务，关闭工作线程。

## 2. 基础线程池实现

### 1. 最简单的线程池

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <queue>
#include <functional>
#include <mutex>
#include <condition_variable>

class SimpleThreadPool {
private:
    std::vector<std::thread> workers;           // 工作线程
    std::queue<std::function<void()>> tasks;    // 任务队列
    std::mutex queueMutex;                      // 队列互斥锁
    std::condition_variable condition;          // 条件变量
    bool stop = false;                          // 停止标志
    
public:
    // 构造函数：创建指定数量的工作线程
    SimpleThreadPool(size_t numThreads) {
        for (size_t i = 0; i < numThreads; ++i) {
            workers.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    
                    // 获取任务
                    {
                        std::unique_lock<std::mutex> lock(queueMutex);
                        
                        // 等待任务或停止信号
                        condition.wait(lock, [this] {
                            return stop || !tasks.empty();
                        });
                        
                        // 如果停止且无任务，退出
                        if (stop && tasks.empty()) {
                            return;
                        }
                        
                        // 取出任务
                        task = std::move(tasks.front());
                        tasks.pop();
                    }
                    
                    // 执行任务（不在锁内）
                    task();
                }
            });
        }
    }
    
    // 添加任务
    template<typename F>
    void enqueue(F&& task) {
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            tasks.emplace(std::forward<F>(task));
        }
        condition.notify_one();  // 通知一个等待的线程
    }
    
    // 析构函数：等待所有线程完成
    ~SimpleThreadPool() {
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            stop = true;
        }
        condition.notify_all();  // 通知所有线程
        
        for (auto& worker : workers) {
            worker.join();
        }
    }
};

int main() {
    SimpleThreadPool pool(4);
    
    // 添加任务
    for (int i = 0; i < 10; ++i) {
        pool.enqueue([i] {
            std::cout << "Task " << i << " executed by thread " 
                      << std::this_thread::get_id() << "\n";
        });
    }
    
    // 等待任务完成（通过析构函数）
    return 0;
}
```

## 3. 任务队列设计

### 1. 支持返回值的任务

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <queue>
#include <functional>
#include <mutex>
#include <condition_variable>
#include <future>
#include <memory>

class ThreadPool {
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    mutable std::mutex queueMutex;
    std::condition_variable condition;
    bool stop = false;
    
public:
    ThreadPool(size_t numThreads) {
        for (size_t i = 0; i < numThreads; ++i) {
            workers.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    
                    {
                        std::unique_lock<std::mutex> lock(queueMutex);
                        condition.wait(lock, [this] {
                            return stop || !tasks.empty();
                        });
                        
                        if (stop && tasks.empty()) {
                            return;
                        }
                        
                        task = std::move(tasks.front());
                        tasks.pop();
                    }
                    
                    task();
                }
            });
        }
    }
    
    // 支持返回值的任务提交
    template<typename F, typename... Args>
    auto enqueue(F&& f, Args&&... args) 
        -> std::future<typename std::invoke_result<F, Args...>::type> 
    {
        using ReturnType = typename std::invoke_result<F, Args...>::type;
        
        // 创建packaged_task
        // 注意：std::bind 会拷贝参数，无法处理 move-only 类型（如 std::unique_ptr）。
        // 如需支持 move-only 类型，可改用 lambda + std::make_tuple + std::apply 的方式。
        auto task = std::make_shared<std::packaged_task<ReturnType()>>(
            std::bind(std::forward<F>(f), std::forward<Args>(args)...)
        );
        
        std::future<ReturnType> result = task->get_future();
        
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            
            if (stop) {
                throw std::runtime_error("ThreadPool已停止");
            }
            
            tasks.emplace([task]() { (*task)(); });
        }
        
        condition.notify_one();
        return result;
    }
    
    ~ThreadPool() {
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            stop = true;
        }
        condition.notify_all();
        
        for (auto& worker : workers) {
            worker.join();
        }
    }
};

int main() {
    ThreadPool pool(4);
    
    // 提交有返回值的任务
    auto future1 = pool.enqueue([](int a, int b) { return a + b; }, 2, 3);
    auto future2 = pool.enqueue([]() { return 42; });
    auto future3 = pool.enqueue([](const std::string& s) { 
        return s + " world"; 
    }, "hello");
    
    std::cout << "Result 1: " << future1.get() << "\n";
    std::cout << "Result 2: " << future2.get() << "\n";
    std::cout << "Result 3: " << future3.get() << "\n";
    
    return 0;
}
```

## 4. 完整线程池实现

### 1. 功能完善的线程池

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <queue>
#include <functional>
#include <mutex>
#include <condition_variable>
#include <future>
#include <memory>
#include <atomic>

class ThreadPool {
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    mutable std::mutex queueMutex;
    std::condition_variable condition;
    std::atomic<bool> stop{false};
    std::atomic<int> activeTasks{0};
    std::condition_variable finished;
    
public:
    explicit ThreadPool(size_t numThreads = std::thread::hardware_concurrency()) {
        for (size_t i = 0; i < numThreads; ++i) {
            workers.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    
                    {
                        std::unique_lock<std::mutex> lock(queueMutex);
                        
                        condition.wait(lock, [this] {
                            return stop || !tasks.empty();
                        });
                        
                        if (stop && tasks.empty()) {
                            return;
                        }
                        
                        task = std::move(tasks.front());
                        tasks.pop();
                        ++activeTasks;
                    }
                    
                    task();
                    
                    {
                        std::lock_guard<std::mutex> lock(queueMutex);
                        --activeTasks;
                    }
                    finished.notify_all();
                }
            });
        }
    }
    
    // 提交任务
    template<typename F, typename... Args>
    auto submit(F&& f, Args&&... args) 
        -> std::future<typename std::invoke_result<F, Args...>::type> 
    {
        using ReturnType = typename std::invoke_result<F, Args...>::type;
        
        // 注意：std::bind 会拷贝参数，无法处理 move-only 类型（如 std::unique_ptr）。
        // 如需支持 move-only 类型，可改用 lambda + std::make_tuple + std::apply 的方式。
        auto task = std::make_shared<std::packaged_task<ReturnType()>>(
            std::bind(std::forward<F>(f), std::forward<Args>(args)...)
        );
        
        std::future<ReturnType> result = task->get_future();
        
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            
            if (stop) {
                throw std::runtime_error("ThreadPool已停止");
            }
            
            tasks.emplace([task]() { (*task)(); });
        }
        
        condition.notify_one();
        return result;
    }
    
    // 等待所有任务完成
    void waitAll() {
        std::unique_lock<std::mutex> lock(queueMutex);
        finished.wait(lock, [this] {
            return tasks.empty() && activeTasks == 0;
        });
    }
    
    // 获取待处理任务数
    size_t pendingTasks() const {
        std::lock_guard<std::mutex> lock(queueMutex);
        return tasks.size();
    }
    
    // 获取线程数
    size_t threadCount() const {
        return workers.size();
    }
    
    ~ThreadPool() {
        stop = true;
        condition.notify_all();
        
        for (auto& worker : workers) {
            if (worker.joinable()) {
                worker.join();
            }
        }
    }
    
    // 禁止拷贝
    ThreadPool(const ThreadPool&) = delete;
    ThreadPool& operator=(const ThreadPool&) = delete;
};

int main() {
    ThreadPool pool(4);
    
    std::cout << "线程数: " << pool.threadCount() << "\n";
    
    // 批量提交任务
    std::vector<std::future<int>> results;
    for (int i = 0; i < 10; ++i) {
        results.push_back(pool.submit([i] {
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
            return i * i;
        }));
    }
    
    // 等待所有任务完成
    pool.waitAll();
    
    // 获取结果
    std::cout << "结果:\n";
    for (auto& r : results) {
        std::cout << r.get() << " ";
    }
    std::cout << "\n";
    
    return 0;
}
```

## 5. 高级特性

### 1. 优先级任务队列

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <queue>
#include <functional>
#include <mutex>
#include <condition_variable>
#include <future>

class PriorityThreadPool {
private:
    struct Task {
        int priority;
        std::function<void()> func;
        
        // 优先级高的先执行
        bool operator<(const Task& other) const {
            return priority < other.priority;
        }
    };
    
    std::vector<std::thread> workers;
    std::priority_queue<Task> tasks;
    std::mutex queueMutex;
    std::condition_variable condition;
    bool stop = false;
    
public:
    PriorityThreadPool(size_t numThreads) {
        for (size_t i = 0; i < numThreads; ++i) {
            workers.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    
                    {
                        std::unique_lock<std::mutex> lock(queueMutex);
                        condition.wait(lock, [this] {
                            return stop || !tasks.empty();
                        });
                        
                        if (stop && tasks.empty()) {
                            return;
                        }
                        
                        task = std::move(tasks.top().func);
                        tasks.pop();
                    }
                    
                    task();
                }
            });
        }
    }
    
    // 提交带优先级的任务
    template<typename F, typename... Args>
    auto submit(int priority, F&& f, Args&&... args) 
        -> std::future<typename std::invoke_result<F, Args...>::type> 
    {
        using ReturnType = typename std::invoke_result<F, Args...>::type;
        
        // 注意：std::bind 会拷贝参数，无法处理 move-only 类型（如 std::unique_ptr）。
        // 如需支持 move-only 类型，可改用 lambda + std::make_tuple + std::apply 的方式。
        auto task = std::make_shared<std::packaged_task<ReturnType()>>(
            std::bind(std::forward<F>(f), std::forward<Args>(args)...)
        );
        
        std::future<ReturnType> result = task->get_future();
        
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            tasks.push({priority, [task]() { (*task)(); }});
        }
        
        condition.notify_one();
        return result;
    }
    
    ~PriorityThreadPool() {
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            stop = true;
        }
        condition.notify_all();
        
        for (auto& worker : workers) {
            worker.join();
        }
    }
};

int main() {
    PriorityThreadPool pool(2);
    
    // 提交不同优先级的任务
    pool.submit(1, [] { std::cout << "低优先级任务\n"; });
    pool.submit(10, [] { std::cout << "高优先级任务\n"; });
    pool.submit(5, [] { std::cout << "中优先级任务\n"; });
    
    return 0;
}
```

### 2. 可扩展线程池

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <queue>
#include <functional>
#include <mutex>
#include <condition_variable>
#include <future>
#include <atomic>

class ScalableThreadPool {
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    std::mutex queueMutex;
    std::condition_variable condition;
    std::atomic<bool> stop{false};
    std::atomic<size_t> idleThreads{0};
    std::atomic<size_t> threadCount{0};
    size_t minThreads;
    size_t maxThreads;
    
    void workerThread() {
        while (true) {
            std::function<void()> task;
            
            {
                std::unique_lock<std::mutex> lock(queueMutex);
                
                ++idleThreads;
                
                // 等待任务或超时
                bool gotTask = condition.wait_for(
                    lock, 
                    std::chrono::seconds(10),
                    [this] { return stop || !tasks.empty(); }
                );
                
                --idleThreads;
                
                if (stop && tasks.empty()) {
                    return;
                }
                
                if (!gotTask) {
                    // 超时且线程数超过最小值，退出
                    if (threadCount > minThreads) {
                        --threadCount;
                        return;
                    }
                    continue;
                }
                
                task = std::move(tasks.front());
                tasks.pop();
            }
            
            task();
        }
    }
    
    void tryAddThread() {
        std::lock_guard<std::mutex> lock(queueMutex);
        
        if (idleThreads == 0 && threadCount < maxThreads) {
            workers.emplace_back(&ScalableThreadPool::workerThread, this);
            ++threadCount;
        }
    }
    
public:
    ScalableThreadPool(size_t minT, size_t maxT) 
        : minThreads(minT), maxThreads(maxT) 
    {
        for (size_t i = 0; i < minThreads; ++i) {
            workers.emplace_back(&ScalableThreadPool::workerThread, this);
        }
        threadCount = minThreads;
    }
    
    template<typename F, typename... Args>
    auto submit(F&& f, Args&&... args) 
        -> std::future<typename std::invoke_result<F, Args...>::type> 
    {
        using ReturnType = typename std::invoke_result<F, Args...>::type;
        
        // 注意：std::bind 会拷贝参数，无法处理 move-only 类型（如 std::unique_ptr）。
        // 如需支持 move-only 类型，可改用 lambda + std::make_tuple + std::apply 的方式。
        auto task = std::make_shared<std::packaged_task<ReturnType()>>(
            std::bind(std::forward<F>(f), std::forward<Args>(args)...)
        );
        
        std::future<ReturnType> result = task->get_future();
        
        {
            std::unique_lock<std::mutex> lock(queueMutex);
            tasks.emplace([task]() { (*task)(); });
        }
        
        condition.notify_one();
        tryAddThread();
        
        return result;
    }
    
    ~ScalableThreadPool() {
        stop = true;
        condition.notify_all();
        
        std::vector<std::thread> workers_to_join;
        {
            std::lock_guard<std::mutex> lock(queueMutex);
            workers_to_join = std::move(workers);
        }
        for (auto& worker : workers_to_join) {
            if (worker.joinable()) {
                worker.join();
            }
        }
    }
};

int main() {
    ScalableThreadPool pool(2, 8);  // 最少2个，最多8个线程
    
    std::cout << "初始线程数: 2\n";
    
    // 提交大量任务
    for (int i = 0; i < 20; ++i) {
        pool.submit([i] {
            std::this_thread::sleep_for(std::chrono::milliseconds(500));
            std::cout << "Task " << i << " done\n";
        });
    }
    
    return 0;
}
```

## 6. 实际应用示例

### 1. 并行数据处理

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include "ThreadPool.h"  // 假设已定义

// 并行处理数据
template<typename T, typename F>
void parallelProcess(ThreadPool& pool, 
                     std::vector<T>& data, 
                     F&& processor,
                     size_t batchSize = 100) 
{
    std::vector<std::future<void>> futures;
    
    for (size_t i = 0; i < data.size(); i += batchSize) {
        size_t end = std::min(i + batchSize, data.size());
        
        futures.push_back(pool.submit([&data, &processor, i, end] {
            for (size_t j = i; j < end; ++j) {
                processor(data[j]);
            }
        }));
    }
    
    // 等待所有任务完成
    for (auto& f : futures) {
        f.get();
    }
}

int main() {
    ThreadPool pool(4);
    
    // 准备数据
    std::vector<int> data(1000);
    for (int i = 0; i < 1000; ++i) {
        data[i] = i;
    }
    
    // 并行处理：计算平方
    parallelProcess(pool, data, [](int& x) {
        x = x * x;
    });
    
    std::cout << "前10个结果: ";
    for (int i = 0; i < 10; ++i) {
        std::cout << data[i] << " ";
    }
    std::cout << "\n";
    
    return 0;
}
```

### 2. 异步Web请求模拟

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <chrono>
#include <random>
#include "ThreadPool.h"

// 模拟HTTP请求
std::string httpRequest(const std::string& url) {
    // 模拟网络延迟
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(100, 500);
    std::this_thread::sleep_for(std::chrono::milliseconds(dis(gen)));
    
    return "Response from " + url;
}

int main() {
    ThreadPool pool(8);
    
    std::vector<std::string> urls = {
        "http://api.example.com/users",
        "http://api.example.com/products",
        "http://api.example.com/orders",
        "http://api.example.com/settings"
    };
    
    std::cout << "开始异步请求...\n";
    
    auto start = std::chrono::steady_clock::now();
    
    // 并行发送请求
    std::vector<std::future<std::string>> responses;
    for (const auto& url : urls) {
        responses.push_back(pool.submit(httpRequest, url));
    }
    
    // 收集响应
    for (size_t i = 0; i < responses.size(); ++i) {
        std::cout << responses[i].get() << "\n";
    }
    
    auto end = std::chrono::steady_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);
    
    std::cout << "总耗时: " << duration.count() << " ms\n";
    
    return 0;
}
```

## 总结

### 3. 线程池核心组件

| 组件 | 说明 |
|------|------|
| **工作线程** | 执行任务的实际线程 |
| **任务队列** | 存储待执行的任务 |
| **互斥锁** | 保护任务队列 |
| **条件变量** | 线程间通信 |
| **停止标志** | 控制线程退出 |

### 4. 最佳实践

```
□ 线程数设置为 CPU核心数 或 CPU核心数+1
□ 任务执行时间不宜过短（考虑调度开销）
□ 使用 future 获取任务返回值
□ 注意异常处理，避免任务崩溃
□ 合理设置任务队列大小
□ 支持优雅关闭
```
