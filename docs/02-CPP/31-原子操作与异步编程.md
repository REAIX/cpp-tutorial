> 💡 **通俗理解 - 原子操作是什么？**

**原子操作 = 不可分割的操作**

想象数钱：
- **普通操作**：一张一张数，可能数错
- **原子操作**：就像点钞机，"嗖"一下完成，不可分割

**原子操作就是"一口气做完，不会被打断"！**

**异步编程 = 不用等待**

- **同步**：叫外卖，等送到才能吃饭
- **异步**：叫外卖，同时可以看电视，外卖到了再吃

> 🔬 **抽象理解 - 无锁编程与异步模型**：
> - **原子操作**：是不可再分的操作，CPU保证其执行期间不会被中断
> - **无锁编程**：是通过原子操作实现"不加锁"的并发，是最高效的并发方式
> - **内存顺序**：指定原子操作的内存可见性顺序（relaxed、acquire、release等）
> - **异步编程**：是"非阻塞"编程，任务启动后不等待结果，通过回调或future获取结果
> - **future/promise**：是"承诺"机制，异步任务返回future用于获取结果
> - **async**：是高级异步接口，自动管理线程池

## 1. 原子操作基础

### 1. 概念与定义

**原子操作（atomic operation）**：C++11引入的新特性，用于实现无锁编程。原子操作可以确保多个线程访问共享资源时，不会出现竞态条件。

**无锁编程（lock-free programming）**：不使用互斥量的编程方式。无锁编程可以避免死锁、活锁、饥饿等问题，提高性能。

**内存序（memory order）**：C++11引入的新特性，用于控制原子操作的内存可见性。内存序可以确保原子操作的执行顺序符合预期。

**std::atomic**：C++11引入的模板类，用于实现原子操作。`std::atomic`可以支持基本类型和自定义类型的原子操作。

**CAS（Compare-And-Swap）**：比较交换操作，是无锁编程的基础。CAS操作可以确保多个线程访问共享资源时，不会出现竞态条件。

**自旋锁（spin lock）**：基于原子操作的锁实现。自旋锁在获取锁失败时，会循环等待，直到获取锁。

### 2. atomic 基本使用

```cpp
#include <iostream>
#include <thread>
#include <atomic>
#include <vector>

// 原子变量：无锁操作，线程安全
std::atomic<int> counter(0);
std::atomic<bool> ready(false);
std::atomic<int*> ptr(nullptr);

void increment() {
    for (int i = 0; i < 1000; ++i) {
        counter++;  // 原子递增
    }
}

int main() {
    std::vector<std::thread> threads;
    
    for (int i = 0; i < 10; ++i) {
        threads.emplace_back(increment);
    }
    
    for (auto& t : threads) {
        t.join();
    }
    
    std::cout << "Counter: " << counter << "\n";  // 10000
    
    return 0;
}
```

### 3. 原子操作

```cpp
#include <atomic>

std::atomic<int> value(0);

// 基本操作
value.store(10);           // 存储
int v = value.load();      // 加载
int old = value.exchange(20);  // 交换并返回旧值

// 比较交换（CAS）
int expected = 20;
bool success = value.compare_exchange_strong(expected, 30);
// 如果 value == expected，则 value = 30，返回 true
// 否则 expected = value，返回 false

// 算术操作
value.fetch_add(5);        // 原子加，返回旧值
value.fetch_sub(3);        // 原子减
value.fetch_and(0xFF);     // 原子与
value.fetch_or(0x0F);      // 原子或
value.fetch_xor(0x55);     // 原子异或
```

### 4. 自旋锁实现

```cpp
#include <atomic>

class SpinLock {
private:
    std::atomic_flag flag = ATOMIC_FLAG_INIT;  // 注意：ATOMIC_FLAG_INIT 是C风格宏。C++20起 atomic_flag 默认构造已初始化为清除状态，可直接写 std::atomic_flag flag{}; 或 std::atomic_flag flag;
    
public:
    void lock() {
        while (flag.test_and_set(std::memory_order_acquire)) {
            // 自旋等待
        }
    }
    
    void unlock() {
        flag.clear(std::memory_order_release);
    }
};
```

## 2. 内存序

### 1. 内存序选项

| 选项 | 说明 |
|-----|------|
| `memory_order_relaxed` | 无顺序保证 |
| `memory_order_acquire` | 获取语义（读操作） |
| `memory_order_release` | 释放语义（写操作） |
| `memory_order_acq_rel` | 获取+释放 |
| `memory_order_seq_cst` | 顺序一致性（默认） |

### 2. 使用示例

```cpp
#include <atomic>
#include <iostream>
#include <thread>

std::atomic<bool> ready(false);
int data = 0;

void producer() {
    data = 42;
    ready.store(true, std::memory_order_release);  // 释放
}

void consumer() {
    while (!ready.load(std::memory_order_acquire)) {  // 获取
        std::this_thread::yield();
    }
    // 保证能看到 data = 42
    std::cout << data << "\n";
}
```

### 3. relaxed示例

```cpp
#include <atomic>
#include <thread>
#include <vector>

std::atomic<int> counter(0);

void relaxed_increment() {
    for (int i = 0; i < 1000; ++i) {
        counter.fetch_add(1, std::memory_order_relaxed);
        // 只保证原子性，不保证顺序
    }
}
```

## 3. 异步编程

### 1. future和promise

```cpp
#include <future>
#include <iostream>

void async_task() {
    // promise：生产者
    std::promise<int> promise;
    
    // future：消费者
    std::future<int> future = promise.get_future();
    
    // 在另一个线程设置值
    std::thread producer([&promise]() {
        std::this_thread::sleep_for(std::chrono::seconds(1));
        promise.set_value(42);
    });
    
    // 等待结果
    int result = future.get();
    std::cout << "Result: " << result << "\n";
    
    producer.join();
}
```

### 2. std::async

```cpp
#include <future>
#include <iostream>

int compute() {
    std::this_thread::sleep_for(std::chrono::seconds(1));
    return 42;
}

int main() {
    // 异步启动
    std::future<int> fut = std::async(std::launch::async, compute);
    
    // 做其他事情
    
    // 获取结果（阻塞）
    int result = fut.get();
    std::cout << "Result: " << result << "\n";
    
    return 0;
}
```

### 3. std::packaged_task

```cpp
#include <future>
#include <iostream>

int main() {
    std::packaged_task<int()> task([]() {
        return 42;
    });
    
    std::future<int> fut = task.get_future();
    
    // 在线程中执行
    std::thread t(std::move(task));
    
    int result = fut.get();
    std::cout << "Result: " << result << "\n";
    
    t.join();
    
    return 0;
}
```

### 4. shared_future

```cpp
#include <future>
#include <vector>
#include <thread>

int main() {
    std::promise<int> promise;
    std::shared_future<int> sf = promise.get_future().share();
    
    // 多个线程可以共享同一个 future
    std::vector<std::thread> threads;
    for (int i = 0; i < 5; ++i) {
        threads.emplace_back([sf]() {
            int result = sf.get();  // 可以多次调用
            std::cout << "Thread got: " << result << "\n";
        });
    }
    
    promise.set_value(42);
    
    for (auto& t : threads) {
        t.join();
    }
    
    return 0;
}
```

## 4. 注意事项与最佳实践

### 1. 常见陷阱

```cpp
// 1. future只能get一次
std::future<int> fut = std::async([]() { return 42; });
int r1 = fut.get();  // OK
// int r2 = fut.get();  // 错误！

// 2. 异常处理
std::future<int> fut = std::async([]() -> int {
    throw std::runtime_error("Error!");
    return 0;
});

try {
    fut.get();  // 异常会在这里抛出
} catch (const std::exception& e) {
    std::cout << e.what() << "\n";
}

// 3. 避免死锁
std::future<int> fut = std::async([]() {
    // 如果是 deferred 策略，get() 会在这里执行
    return 42;
});
// 注意：仅 std::async 返回的 std::future（采用 std::launch::async 策略时）
// 在析构时会阻塞等待任务完成。来自 std::promise 或 std::packaged_task 的
// std::future 析构时不会阻塞。
```

### 2. 最佳实践

```cpp
// 1. 使用 shared_future 共享结果
std::shared_future<int> sf = std::async([]() { return 42; }).share();

// 2. 检查 future 状态
std::future<int> fut = std::async([]() { return 42; });
if (fut.wait_for(std::chrono::seconds(0)) == std::future_status::ready) {
    int result = fut.get();
}

// 3. 使用 atomic 替代锁（简单场景）
std::atomic<int> counter(0);
counter++;  // 比 mutex 更高效

// 4. 选择合适的内存序
// 默认 seq_cst 最安全
// 性能关键路径可考虑 acquire/release
```

## 5. 本章小结

### 1. 核心概念回顾

| 概念 | 说明 | 示例 |
|-----|------|------|
| **atomic** | 原子变量 | `std::atomic<int>` |
| **memory_order** | 内存序 | `memory_order_acquire` |
| **future** | 异步结果 | `std::future<int>` |
| **promise** | 异步承诺 | `std::promise<int>` |
| **async** | 异步执行 | `std::async(func)` |
| **packaged_task** | 可打包任务 | `std::packaged_task` |

### 2. 关键语法要点

1. **原子操作**：无锁、线程安全
2. **内存序**：控制可见性和顺序
3. **future/promise**：线程间传递结果
4. **async**：简化异步任务
5. **shared_future**：共享异步结果

### 3. 最佳实践

1. 简单计数用 atomic
2. 默认使用 seq_cst 内存序
3. 使用 async 简化异步编程
4. 注意 future 只能 get 一次
5. 使用 shared_future 共享结果
