## 1. Socket基础

> ⚠️ **平台说明**：本章代码示例使用 POSIX Socket API（Linux/macOS），Windows 平台需使用 Winsock2（`winsock2.h` + `ws2_32.lib`），参见 19.2 节末尾的 Windows 版本。

### 1. 概念与定义

**Socket**：C++中用于网络通信的机制。Socket可以分为TCP Socket和UDP Socket。例如`int sockfd = socket(AF_INET, SOCK_STREAM, 0);`用于创建TCP Socket。

**TCP（Transmission Control Protocol）**：传输控制协议，是一种面向连接的、可靠的、基于字节流的传输层通信协议。TCP可以保证数据的可靠传输，例如HTTP、HTTPS、FTP等协议都使用TCP。

**UDP（User Datagram Protocol）**：用户数据报协议，是一种无连接的、不可靠的、基于数据报的传输层通信协议。UDP可以提高数据传输的效率，例如DNS、DHCP、SNMP等协议都使用UDP。

**IP（Internet Protocol）**：互联网协议，是一种无连接的、不可靠的、基于数据报的网络层通信协议。IP可以保证数据的路由，例如IPv4和IPv6。

**端口号（port number）**：C++中用于标识网络应用程序的机制。端口号可以分为知名端口号（0-1023）、注册端口号（1024-49151）、动态端口号（49152-65535）。例如HTTP协议使用端口号80，HTTPS协议使用端口号443。

**IP地址（IP address）**：C++中用于标识网络主机的机制。IP地址可以分为IPv4地址和IPv6地址。例如IPv4地址`192.168.1.1`，IPv6地址`2001:0db8:85a3:0000:0000:8a2e:0370:7334`。

**面向连接（connection-oriented）**：C++中用于网络通信的机制。面向连接的通信需要建立连接、传输数据、关闭连接。例如TCP是面向连接的通信协议。

**无连接（connectionless）**：C++中用于网络通信的机制。无连接的通信不需要建立连接，直接传输数据。例如UDP是无连接的通信协议。

### 5. IP地址详解

> 🎯 **IP地址是网络世界的门牌号**

**生活中的比喻：**

想象你要寄信：
- **现实**：写收信人地址（北京市朝阳区XX路XX号）
- **网络**：写目标主机的IP地址（192.168.1.100）
- **端口号**：就像收信人的房间号（8080端口）

**为什么需要IP地址？**
- 在同一网络中找到目标计算机
- 数据包需要知道从哪里来到哪里去
- 没有IP地址就无法进行网络通信

#### 1. IPv4地址

- **格式**：32位地址，通常用点分十进制表示（如192.168.1.1）
- **范围**：0.0.0.0 到 255.255.255.255
- **分类**：
  - A类：1.0.0.0 - 126.255.255.255（大型网络）
  - B类：128.0.0.0 - 191.255.255.255（中型网络）
  - C类：192.0.0.0 - 223.255.255.255（小型网络）
  - D类：224.0.0.0 - 239.255.255.255（组播）
  - E类：240.0.0.0 - 255.255.255.255（保留）

- **特殊IP地址**：
  - 127.0.0.1：本地回环地址（localhost）
  - 0.0.0.0：表示"任何地址"
  - 255.255.255.255：广播地址

#### 2. IPv6地址

- **格式**：128位地址，用冒号十六进制表示
- **示例**：2001:0db8:85a3:0000:0000:8a2e:0370:7334
- **简化规则**：
  - 前导零可以省略
  - 连续的零可以用`::`表示（只能用一次）

#### 3. 私有IP地址

| 类别 | 范围 | 用途 |
|------|------|------|
| 10.0.0.0 - 10.255.255.255 | 10.0.0.0/8 | 大型网络 |
| 172.16.0.0 - 172.31.255.255 | 172.16.0.0/12 | 中型网络 |
| 192.168.0.0 - 192.168.255.255 | 192.168.0.0/16 | 小型网络 |

#### 4. 子网掩码

- **作用**：区分网络地址和主机地址
- **示例**：255.255.255.0 表示前24位是网络号，后8位是主机号
- **CIDR表示法**：192.168.1.0/24 等同于 192.168.1.0 + 255.255.255.0

#### 5. C++中操作IP地址

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <cstring>

int main() {
    // 1. 点分十进制字符串转网络字节序
    const char* ip_str = "192.168.1.100";
    struct in_addr addr;
    inet_pton(AF_INET, ip_str, &addr);
    std::cout << "IP地址(网络字节序): " << addr.s_addr << "\n";

    // 2. 网络字节序转点分十进制字符串
    char buf[INET_ADDRSTRLEN];
    inet_ntop(AF_INET, &addr, buf, INET_ADDRSTRLEN);
    std::cout << "IP地址(字符串): " << buf << "\n";

    // 3. IPv6 地址转换
    const char* ip6_str = "2001:db8::1";
    struct in6_addr addr6;
    inet_pton(AF_INET6, ip6_str, &addr6);

    char buf6[INET6_ADDRSTRLEN];
    inet_ntop(AF_INET6, &addr6, buf6, INET6_ADDRSTRLEN);
    std::cout << "IPv6地址: " << buf6 << "\n";

    // 4. 设置sockaddr_in结构体
    struct sockaddr_in server_addr;
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;           // IPv4
    server_addr.sin_port = htons(8080);         // 端口号（网络字节序）
    server_addr.sin_addr.s_addr = addr.s_addr;  // IP地址（网络字节序）

    return 0;
}
```

#### 6. 主机名解析

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <netdb.h>

int main() {
    // 通过主机名获取IP地址
    const char* hostname = "www.baidu.com";
    // 注意：gethostbyname() 已被 POSIX 标记为过时（obsolete），不支持 IPv6 且不是线程安全的。
    // 现代代码应使用 getaddrinfo() 替代。
    struct hostent* he = gethostbyname(hostname);

    if (he != nullptr) {
        std::cout << "主机名: " << he->h_name << "\n";
        std::cout << "IP地址: ";

        // 可能有多个IP地址
        for (int i = 0; he->h_addr_list[i] != nullptr; i++) {
            struct in_addr** addr_list = (struct in_addr**)he->h_addr_list;
            char ip[INET_ADDRSTRLEN];
            inet_ntop(AF_INET, addr_list[i], ip, INET_ADDRSTRLEN);
            std::cout << ip;
            if (he->h_addr_list[i + 1] != nullptr) {
                std::cout << ", ";
            }
        }
        std::cout << "\n";
    }

    return 0;
}
```

#### 7. 常见网络命令

```cpp
// 在代码中获取本地IP地址
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <net/if.h>
#include <ifaddrs.h>

std::string get_local_ip() {
    std::string local_ip = "127.0.0.1";

    struct ifaddrs* ifaddr = nullptr;
    if (getifaddrs(&ifaddr) == 0) {
        for (struct ifaddrs* ptr = ifaddr; ptr != nullptr; ptr = ptr->ifa_next) {
            if (ptr->ifa_addr == nullptr) continue;
            if (ptr->ifa_addr->sa_family == AF_INET) {
                struct sockaddr_in* addr = (struct sockaddr_in*)ptr->ifa_addr;
                char ip[INET_ADDRSTRLEN];
                inet_ntop(AF_INET, &addr->sin_addr, ip, INET_ADDRSTRLEN);

                // 排除回环地址
                if (strcmp(ip, "127.0.0.1") != 0) {
                    local_ip = ip;
                    break;
                }
            }
        }
    }
    freeifaddrs(ifaddr);
    return local_ip;
}
```

## 2. TCP编程

### 1. TCP服务端

```cpp
#include <iostream>
#include <cstring>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <arpa/inet.h>

const int PORT = 8080;
const int BUFFER_SIZE = 1024;

int main() {
    int server_fd, client_fd;
    struct sockaddr_in address;
    int opt = 1;
    socklen_t addrlen = sizeof(address);
    char buffer[BUFFER_SIZE] = {0};
    
    // 创建socket
    server_fd = socket(AF_INET, SOCK_STREAM, 0);
    
    // 设置选项
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    
    // 绑定地址
    address.sin_family = AF_INET;
    address.sin_addr.s_addr = INADDR_ANY;
    address.sin_port = htons(PORT);
    
    bind(server_fd, (struct sockaddr*)&address, sizeof(address));
    
    // 监听
    listen(server_fd, 3);
    
    std::cout << "Server listening on port " << PORT << std::endl;
    
    // 接受连接
    client_fd = accept(server_fd, (struct sockaddr*)&address, &addrlen);
    
    // 接收数据
    int valread = read(client_fd, buffer, BUFFER_SIZE);
    std::cout << "Received: " << buffer << std::endl;
    
    // 发送响应
    const char* response = "Hello from server";
    send(client_fd, response, strlen(response), 0);
    
    // 关闭
    close(client_fd);
    close(server_fd);
    
    return 0;
}
```

### 2. TCP客户端

```cpp
#include <iostream>
#include <cstring>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <arpa/inet.h>

const int PORT = 8080;
const char* SERVER_IP = "127.0.0.1";
const int BUFFER_SIZE = 1024;

int main() {
    int sock = socket(AF_INET, SOCK_STREAM, 0);
    
    struct sockaddr_in serv_addr;
    serv_addr.sin_family = AF_INET;
    serv_addr.sin_port = htons(PORT);
    inet_pton(AF_INET, SERVER_IP, &serv_addr.sin_addr);
    
    // 连接服务器
    if (connect(sock, (struct sockaddr*)&serv_addr, sizeof(serv_addr)) < 0) {
        std::cerr << "Connection failed" << std::endl;
        return -1;
    }
    
    // 发送数据
    const char* message = "Hello from client";
    send(sock, message, strlen(message), 0);
    
    // 接收响应
    char buffer[BUFFER_SIZE] = {0};
    int valread = read(sock, buffer, BUFFER_SIZE);
    std::cout << "Server response: " << buffer << std::endl;
    
    close(sock);
    
    return 0;
}
```

## 3. UDP编程

### 1. UDP服务端

```cpp
#include <iostream>
#include <cstring>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>

const int PORT = 8080;
const int BUFFER_SIZE = 1024;

int main() {
    int sockfd = socket(AF_INET, SOCK_DGRAM, 0);
    
    struct sockaddr_in servaddr, cliaddr;
    servaddr.sin_family = AF_INET;
    servaddr.sin_addr.s_addr = INADDR_ANY;
    servaddr.sin_port = htons(PORT);
    
    bind(sockfd, (const struct sockaddr*)&servaddr, sizeof(servaddr));
    
    std::cout << "UDP Server listening on port " << PORT << std::endl;
    
    char buffer[BUFFER_SIZE];
    socklen_t len = sizeof(cliaddr);
    
    while (true) {
        int n = recvfrom(sockfd, buffer, BUFFER_SIZE, 0,
                         (struct sockaddr*)&cliaddr, &len);
        if (n <= 0) continue;
        buffer[n] = '\0';
        
        std::cout << "Received: " << buffer << std::endl;
        
        // 发送响应
        const char* response = "ACK";
        sendto(sockfd, response, strlen(response), 0,
               (const struct sockaddr*)&cliaddr, len);
    }
    
    close(sockfd);
    return 0;
}
```

## 5. I/O多路复用

### 1. 什么是I/O多路复用

> 💡 **通俗理解 - I/O多路复用**
>
> 想象一个前台接待员：
> - **没有多路复用**：一个接待员同一时间只能等一个客人，其他客人排队
> - **多线程**：雇很多接待员，每人等一个客人（开销大）
> - **I/O多路复用**：一个接待员同时关注多个客人，谁有事就处理谁

**I/O多路复用**是一种让单个线程同时监控多个文件描述符（Socket）的机制。当某个文件描述符就绪（可读/可写/异常）时，内核通知应用程序进行处理，从而避免为每个连接创建独立线程的开销。

```
┌─────────────────────────────────────────────────────┐
│              I/O多路复用工作模型                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│   客户端1 ──┐                                       │
│   客户端2 ──┤     ┌──────────────┐                  │
│   客户端3 ──┼────►│  epoll_wait  │──► 事件循环      │
│   客户端4 ──┤     │  (一个线程)   │    处理就绪fd    │
│   客户端5 ──┘     └──────────────┘                  │
│                                                     │
│   一个线程监控多个连接，谁有数据就处理谁              │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 2. select/poll/epoll对比

| 特性 | select | poll | epoll |
|------|--------|------|-------|
| **最大连接数** | 1024（FD_SETSIZE） | 无限制 | 无限制 |
| **数据结构** | 位图（fd_set） | 数组（pollfd[]） | 红黑树 + 就绪链表 |
| **内核拷贝** | 每次全量拷贝 | 每次全量拷贝 | 只拷贝变化的部分 |
| **就绪检测** | 遍历所有fd | 遍历所有fd | 只返回就绪fd |
| **时间复杂度** | O(n) | O(n) | O(1) |
| **触发模式** | 水平触发（LT） | 水平触发（LT） | LT + ET |
| **适用场景** | 少量连接，跨平台 | 少量连接，跨平台 | 大量连接，Linux |

> 🔬 **深入理解**：select和poll每次调用都需要将所有fd从用户态拷贝到内核态，返回后还需遍历所有fd判断哪些就绪。epoll通过epoll_ctl注册fd，内核维护红黑树，就绪事件通过回调加入链表，epoll_wait只返回就绪的fd，因此性能与连接数无关。

### 3. select详解

#### 1. fd_set与操作宏

```cpp
// fd_set是一个位图，每一位对应一个文件描述符
fd_set readfds;

// 操作宏
FD_ZERO(&readfds);        // 清空集合
FD_SET(fd, &readfds);     // 将fd加入集合
FD_CLR(fd, &readfds);     // 将fd从集合移除
FD_ISSET(fd, &readfds);   // 检查fd是否在集合中（是否就绪）
```

#### 2. select函数原型

```cpp
#include <sys/select.h>

int select(int nfds, fd_set* readfds, fd_set* writefds,
           fd_set* exceptfds, struct timeval* timeout);

// nfds:      监控的最大fd + 1
// readfds:   监控可读的fd集合
// writefds:  监控可写的fd集合
// exceptfds: 监控异常的fd集合
// timeout:   超时时间（NULL表示永远等待）
// 返回值:    就绪的fd总数，0表示超时，-1表示出错
```

#### 3. 超时设置

```cpp
struct timeval timeout;

// 永远等待
select(nfds, &readfds, NULL, NULL, NULL);

// 等待5秒
timeout.tv_sec = 5;
timeout.tv_usec = 0;
select(nfds, &readfds, NULL, NULL, &timeout);

// 非阻塞（立即返回）
timeout.tv_sec = 0;
timeout.tv_usec = 0;
select(nfds, &readfds, NULL, NULL, &timeout);
```

#### 4. select服务器示例

```cpp
#include <iostream>
#include <cstring>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <sys/select.h>
#include <vector>

int main() {
    int server_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_fd < 0) {
        perror("socket");
        return 1;
    }

    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(8080);

    if (bind(server_fd, (struct sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind");
        close(server_fd);
        return 1;
    }

    if (listen(server_fd, 5) < 0) {
        perror("listen");
        close(server_fd);
        return 1;
    }

    std::cout << "select服务器启动，监听8080端口..." << std::endl;

    std::vector<int> client_fds;
    int max_fd = server_fd;

    while (true) {
        fd_set readfds;
        FD_ZERO(&readfds);
        FD_SET(server_fd, &readfds);

        for (int fd : client_fds) {
            FD_SET(fd, &readfds);
            if (fd > max_fd) max_fd = fd;
        }

        struct timeval timeout;
        timeout.tv_sec = 5;
        timeout.tv_usec = 0;

        int ready = select(max_fd + 1, &readfds, NULL, NULL, &timeout);
        if (ready < 0) {
            perror("select");
            break;
        }
        if (ready == 0) continue;

        if (FD_ISSET(server_fd, &readfds)) {
            struct sockaddr_in client_addr;
            socklen_t client_len = sizeof(client_addr);
            int client_fd = accept(server_fd, (struct sockaddr*)&client_addr, &client_len);
            if (client_fd >= 0) {
                std::cout << "新连接: fd=" << client_fd << std::endl;
                client_fds.push_back(client_fd);
                if (client_fd > max_fd) max_fd = client_fd;
            }
        }

        for (auto it = client_fds.begin(); it != client_fds.end(); ) {
            if (FD_ISSET(*it, &readfds)) {
                char buf[1024] = {0};
                int n = recv(*it, buf, sizeof(buf) - 1, 0);
                if (n <= 0) {
                    std::cout << "连接关闭: fd=" << *it << std::endl;
                    close(*it);
                    it = client_fds.erase(it);
                    continue;
                }
                buf[n] = '\0';
                std::cout << "收到数据(fd=" << *it << "): " << buf << std::endl;
                send(*it, buf, n, 0);
            }
            ++it;
        }
    }

    for (int fd : client_fds) close(fd);
    close(server_fd);
    return 0;
}
```

### 4. epoll详解

#### 1. epoll三大核心API

```cpp
#include <sys/epoll.h>

// 1. 创建epoll实例
int epfd = epoll_create1(0);
// 参数: 0（或EPOLL_CLOEXEC）
// 返回: epoll文件描述符

// 2. 注册/修改/删除监控的fd
int epoll_ctl(int epfd, int op, int fd, struct epoll_event* event);
// op: EPOLL_CTL_ADD（添加）、EPOLL_CTL_MOD（修改）、EPOLL_CTL_DEL（删除）

// 3. 等待事件
int epoll_wait(int epfd, struct epoll_event* events, int maxevents, int timeout);
// events:    事件数组（输出参数）
// maxevents: 最多返回的事件数
// timeout:   超时毫秒数（-1表示永远等待）
// 返回:      就绪的事件数
```

#### 2. epoll_event结构体

```cpp
struct epoll_event {
    uint32_t events;   // 事件类型
    epoll_data_t data; // 用户数据
};

// 常用事件类型
EPOLLIN     // 可读
EPOLLOUT    // 可写
EPOLLERR    // 错误
EPOLLHUP    // 挂断
EPOLLET     // 边缘触发模式
EPOLLONESHOT // 一次性事件

// 用户数据
typedef union epoll_data {
    void* ptr;
    int fd;
    uint32_t u32;
    uint64_t u64;
} epoll_data_t;
```

#### 3. ET（边缘触发）vs LT（水平触发）

| 特性 | 水平触发（LT） | 边缘触发（ET） |
|------|---------------|---------------|
| **触发条件** | 缓冲区有数据就一直通知 | 缓冲区从无数据变为有数据时通知一次 |
| **读取方式** | 可以部分读取 | 必须一次性读完（循环读至EAGAIN） |
| **编程难度** | 简单 | 较高 |
| **效率** | 较低（可能多次唤醒） | 较高（减少系统调用次数） |
| **默认模式** | epoll默认 | 需设置EPOLLET |

```
┌──────────────────────────────────────────────────────┐
│           LT vs ET 触发时机对比                       │
├──────────────────────────────────────────────────────┤
│                                                      │
│  数据到达:  ████████████████                          │
│                                                      │
│  LT通知:   ▼     ▼     ▼     ▼                      │
│            第1次  第2次  第3次  第4次                  │
│            （每次没读完都继续通知）                     │
│                                                      │
│  ET通知:   ▼                                          │
│            仅1次                                      │
│            （只在数据到达时通知一次）                   │
│                                                      │
└──────────────────────────────────────────────────────┘
```

#### 4. ET模式读取示例

```cpp
// ET模式必须循环读取，直到EAGAIN
void handle_read_et(int fd) {
    while (true) {
        char buf[1024];
        int n = recv(fd, buf, sizeof(buf), 0);
        if (n > 0) {
            // 处理数据
            send(fd, buf, n, 0);
        } else if (n == 0) {
            // 连接关闭
            close(fd);
            break;
        } else {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                // 数据已读完，正常退出循环
                break;
            }
            // 其他错误
            close(fd);
            break;
        }
    }
}
```

### 5. C++ epoll服务器完整示例

```cpp
#include <iostream>
#include <cstring>
#include <vector>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <sys/epoll.h>
#include <fcntl.h>
#include <errno.h>

constexpr int MAX_EVENTS = 64;
constexpr int BUFFER_SIZE = 1024;
constexpr int PORT = 8080;

int set_nonblocking(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags == -1) return -1;
    return fcntl(fd, F_SETFL, flags | O_NONBLOCK);
}

int main() {
    int server_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_fd < 0) {
        perror("socket");
        return 1;
    }

    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    set_nonblocking(server_fd);

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(PORT);

    if (bind(server_fd, (struct sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind");
        close(server_fd);
        return 1;
    }

    if (listen(server_fd, SOMAXCONN) < 0) {
        perror("listen");
        close(server_fd);
        return 1;
    }

    int epfd = epoll_create1(0);
    if (epfd < 0) {
        perror("epoll_create1");
        close(server_fd);
        return 1;
    }

    struct epoll_event ev;
    ev.events = EPOLLIN;
    ev.data.fd = server_fd;
    if (epoll_ctl(epfd, EPOLL_CTL_ADD, server_fd, &ev) < 0) {
        perror("epoll_ctl");
        close(epfd);
        close(server_fd);
        return 1;
    }

    std::cout << "epoll服务器启动，监听" << PORT << "端口..." << std::endl;

    std::vector<struct epoll_event> events(MAX_EVENTS);

    while (true) {
        int nfds = epoll_wait(epfd, events.data(), MAX_EVENTS, -1);
        if (nfds < 0) {
            if (errno == EINTR) continue;
            perror("epoll_wait");
            break;
        }

        for (int i = 0; i < nfds; ++i) {
            if (events[i].data.fd == server_fd) {
                struct sockaddr_in client_addr;
                socklen_t client_len = sizeof(client_addr);
                int client_fd = accept(server_fd, (struct sockaddr*)&client_addr, &client_len);
                if (client_fd < 0) {
                    if (errno != EAGAIN && errno != EWOULDBLOCK) {
                        perror("accept");
                    }
                    continue;
                }

                set_nonblocking(client_fd);

                char ip[INET_ADDRSTRLEN];
                inet_ntop(AF_INET, &client_addr.sin_addr, ip, sizeof(ip));
                std::cout << "新连接: " << ip << ":" << ntohs(client_addr.sin_port)
                          << " (fd=" << client_fd << ")" << std::endl;

                struct epoll_event client_ev;
                client_ev.events = EPOLLIN | EPOLLET;
                client_ev.data.fd = client_fd;
                epoll_ctl(epfd, EPOLL_CTL_ADD, client_fd, &client_ev);
            } else {
                int fd = events[i].data.fd;
                if (events[i].events & (EPOLLERR | EPOLLHUP)) {
                    std::cout << "连接异常: fd=" << fd << std::endl;
                    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                    close(fd);
                    continue;
                }

                if (events[i].events & EPOLLIN) {
                    char buf[BUFFER_SIZE];
                    bool closed = false;
                    while (true) {
                        int n = recv(fd, buf, sizeof(buf), 0);
                        if (n > 0) {
                            send(fd, buf, n, 0);
                        } else if (n == 0) {
                            std::cout << "连接关闭: fd=" << fd << std::endl;
                            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                            close(fd);
                            closed = true;
                            break;
                        } else {
                            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                                break;
                            }
                            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                            close(fd);
                            closed = true;
                            break;
                        }
                    }
                }
            }
        }
    }

    close(epfd);
    close(server_fd);
    return 0;
}
```

### 6. 用epoll实现简单的echo服务器

> 🎯 **echo服务器**：收到客户端发送的数据后，原样返回。这是网络编程中最经典的练习项目。

```cpp
#include <iostream>
#include <cstring>
#include <string>
#include <vector>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <sys/epoll.h>
#include <fcntl.h>
#include <errno.h>

constexpr int MAX_EVENTS = 128;
constexpr int BUF_SIZE = 4096;
constexpr int PORT = 9999;

int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    return fcntl(fd, F_SETFL, flags | O_NONBLOCK);
}

int main() {
    int listen_fd = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
    if (listen_fd < 0) { perror("socket"); return 1; }

    int on = 1;
    setsockopt(listen_fd, SOL_SOCKET, SO_REUSEADDR, &on, sizeof(on));

    struct sockaddr_in saddr;
    memset(&saddr, 0, sizeof(saddr));
    saddr.sin_family = AF_INET;
    saddr.sin_addr.s_addr = INADDR_ANY;
    saddr.sin_port = htons(PORT);

    if (bind(listen_fd, (struct sockaddr*)&saddr, sizeof(saddr)) < 0) {
        perror("bind"); close(listen_fd); return 1;
    }
    if (listen(listen_fd, SOMAXCONN) < 0) {
        perror("listen"); close(listen_fd); return 1;
    }

    int epfd = epoll_create1(EPOLL_CLOEXEC);

    struct epoll_event ev;
    ev.events = EPOLLIN;
    ev.data.fd = listen_fd;
    epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);

    std::cout << "Echo服务器启动，端口 " << PORT << std::endl;

    std::vector<struct epoll_event> events(MAX_EVENTS);

    while (true) {
        int n = epoll_wait(epfd, events.data(), MAX_EVENTS, -1);
        if (n < 0) {
            if (errno == EINTR) continue;
            perror("epoll_wait"); break;
        }

        for (int i = 0; i < n; ++i) {
            int fd = events[i].data.fd;

            if (fd == listen_fd) {
                while (true) {
                    struct sockaddr_in caddr;
                    socklen_t clen = sizeof(caddr);
                    int cfd = accept(listen_fd, (struct sockaddr*)&caddr, &clen);
                    if (cfd < 0) {
                        if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                        perror("accept"); break;
                    }
                    set_nonblock(cfd);
                    struct epoll_event cev;
                    cev.events = EPOLLIN | EPOLLET;
                    cev.data.fd = cfd;
                    epoll_ctl(epfd, EPOLL_CTL_ADD, cfd, &cev);
                    std::cout << "客户端连接: fd=" << cfd << std::endl;
                }
            } else {
                if (events[i].events & (EPOLLERR | EPOLLHUP)) {
                    std::cout << "客户端断开: fd=" << fd << std::endl;
                    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
                    close(fd);
                    continue;
                }

                while (true) {
                    char buf[BUF_SIZE];
                    int len = recv(fd, buf, sizeof(buf), 0);
                    if (len > 0) {
                        std::string msg(buf, len);
                        std::cout << "[fd=" << fd << "] " << msg;
                        send(fd, buf, len, 0);
                    } else if (len == 0) {
                        std::cout << "客户端关闭: fd=" << fd << std::endl;
                        epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
                        close(fd);
                        break;
                    } else {
                        if (errno != EAGAIN && errno != EWOULDBLOCK) {
                            perror("recv");
                            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
                            close(fd);
                        }
                        break;
                    }
                }
            }
        }
    }

    close(epfd);
    close(listen_fd);
    return 0;
}
```

> ⚠️ **注意事项**：
> 1. ET模式必须将fd设为非阻塞，且必须循环读取直到`EAGAIN`
> 2. `accept`也需循环调用，因为ET模式下可能多个连接同时到达
> 3. `epoll_ctl`的`EPOLL_CTL_DEL`操作，若fd已关闭则无需再调用（内核自动清理）
> 4. 实际生产环境中，建议将连接管理封装为类，使用RAII管理资源

## 6. 本章小结

### 1. 核心概念回顾

| 概念 | 说明 | 示例 |
|-----|------|------|
| **socket** | 套接字 | `socket(AF_INET, SOCK_STREAM, 0)` |
| **bind** | 绑定地址 | `bind(sockfd, addr, len)` |
| **listen** | 监听连接 | `listen(sockfd, backlog)` |
| **accept** | 接受连接 | `accept(sockfd, addr, len)` |
| **connect** | 连接服务器 | `connect(sockfd, addr, len)` |
| **send/recv** | TCP收发 | `send(sockfd, buf, len, 0)` |
| **sendto/recvfrom** | UDP收发 | `sendto(sockfd, buf, len, 0, addr, addrlen)` |
| **select** | I/O多路复用（跨平台） | `select(maxfd+1, &readfds, NULL, NULL, &timeout)` |
| **epoll** | I/O多路复用（Linux高性能） | `epoll_create1/epoll_ctl/epoll_wait` |
| **EPOLLET** | 边缘触发模式 | `ev.events = EPOLLIN \| EPOLLET` |

### 2. 关键语法要点

1. **TCP**：面向连接，可靠传输
2. **UDP**：无连接，快速传输
3. **地址转换**：`inet_pton`, `inet_ntop`
4. **端口转换**：`htons`, `ntohs`
5. **错误处理**：检查返回值
6. **I/O多路复用**：select跨平台，epoll高性能
7. **epoll ET模式**：必须非阻塞 + 循环读取至EAGAIN

### 3. 最佳实践

1. 使用 SO_REUSEADDR 避免端口占用
2. 设置合理的超时时间
3. 使用 RAII 管理 socket 资源
4. 处理部分发送/接收
5. 实现心跳机制保持连接
