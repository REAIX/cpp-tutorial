> 💡 **通俗理解 - 什么是序列化和日志？**

**序列化 = 打包行李**

想象你要搬家：
- **序列化**：把家具、衣服等物品打包成箱子，方便运输
- **反序列化**：到了新家，把箱子里的东西拿出来恢复原样

**程序中的序列化：**
```
内存中的对象 → 序列化 → JSON/二进制数据 → 保存到文件或网络传输
JSON/二进制数据 → 反序列化 → 内存中的对象
```

**日志 = 黑匣子记录器**

想象飞机的黑匣子：
- 记录飞行过程中的所有重要事件
- 出问题时可以通过日志排查原因
- 平时可以监控系统运行状态

> 🔬 **抽象理解 - 序列化与日志的价值**：
>
> - **序列化**：将内存中的数据结构转换为可存储或传输的格式（JSON、XML、二进制）
> - **应用场景**：保存配置、网络通信、数据持久化、API交互
> - **日志**：记录程序运行时的关键信息，用于调试、监控、审计
> - **spdlog**：高性能C++日志库，支持多线程、多种输出目标、日志级别控制

## 1. JSON序列化

### 1. nlohmann/json

```cpp
#include <nlohmann/json.hpp>
using json = nlohmann::json;

// 创建JSON
json j = {
    {"name", "Alice"},
    {"age", 25},
    {"scores", {95, 87, 92}},
    {"address", {
        {"city", "Beijing"},
        {"zip", "100000"}
    }}
};

// 序列化为字符串
std::string s = j.dump(4);  // 4空格缩进
std::cout << s << "\n";

// 从字符串解析
json j2 = json::parse(R"({"name":"Bob","age":30})");

// 访问元素
std::string name = j["name"];
int age = j["age"];
auto& scores = j["scores"];
for (int s : scores) std::cout << s << " ";

// 安全访问
if (j.contains("email")) {
    std::string email = j["email"];
}

// 修改
j["age"] = 26;
j["email"] = "alice@example.com";

// 自定义类型序列化
struct Person {
    std::string name;
    int age;
};

void to_json(json& j, const Person& p) {
    j = json{{"name", p.name}, {"age", p.age}};
}

void from_json(const json& j, Person& p) {
    j.at("name").get_to(p.name);
    j.at("age").get_to(p.age);
}

Person p{"Charlie", 28};
json j3 = p;  // 自动序列化
Person p2 = j3.get<Person>();  // 自动反序列化
```

## 2. 二进制序列化

### 1. 简单二进制序列化

```cpp
#include <fstream>
#include <cstring>

struct Header {
    uint32_t magic;
    uint32_t version;
    uint32_t data_size;
};

void write_binary(const std::string& path, const std::vector<int>& data) {
    std::ofstream ofs(path, std::ios::binary);

    Header hdr{0x4D415448, 1, static_cast<uint32_t>(data.size())};
    ofs.write(reinterpret_cast<const char*>(&hdr), sizeof(hdr));
    ofs.write(reinterpret_cast<const char*>(data.data()),
              data.size() * sizeof(int));
}

std::vector<int> read_binary(const std::string& path) {
    std::ifstream ifs(path, std::ios::binary);

    Header hdr;
    ifs.read(reinterpret_cast<char*>(&hdr), sizeof(hdr));

    std::vector<int> data(hdr.data_size);
    ifs.read(reinterpret_cast<char*>(data.data()),
             data.size() * sizeof(int));
    return data;
}
```

### 3. Protocol Buffers实战

#### 1. .proto文件定义

```protobuf
// person.proto
syntax = "proto3";

package tutorial;

// 人物消息类型
message Person {
    string name = 1;          // 姓名
    int32 age = 2;            // 年龄
    repeated string emails = 3; // 邮箱列表（可重复字段）

    // 嵌套消息：地址
    message Address {
        string city = 1;      // 城市
        string street = 2;    // 街道
        int32 zip_code = 3;   // 邮编
    }

    Address address = 4;      // 地址信息
}

// 通讯录消息类型
message AddressBook {
    repeated Person people = 1; // 人员列表
}
```

#### 2. protoc编译命令

```bash
# 生成C++头文件和源文件
protoc --cpp_out=./person.proto

# 指定输出目录
protoc --cpp_out=./generated person.proto

# 同时生成多语言代码
protoc --cpp_out=./cpp --python_out=./py --java_out=./java person.proto
```

编译后会生成两个文件：
- `person.pb.h` — 消息类的头文件
- `person.pb.cc` — 消息类的实现文件

#### 3. C++序列化代码

```cpp
#include "person.pb.h"
#include <fstream>
#include <iostream>

void serialize_person() {
    // 验证头文件版本与运行时库版本一致
    GOOGLE_PROTOBUF_VERIFY_VERSION;

    // 创建Person消息
    tutorial::Person person;
    person.set_name("张三");
    person.set_age(28);

    // 添加repeated字段
    person.add_emails("zhangsan@example.com");
    person.add_emails("zhangsan@work.com");

    // 设置嵌套消息
    auto* addr = person.mutable_address();
    addr->set_city("北京");
    addr->set_street("中关村大街1号");
    addr->set_zip_code(100080);

    // 方式一：序列化为二进制字符串
    std::string binary_data;
    person.SerializeToString(&binary_data);
    std::cout << "二进制大小: " << binary_data.size() << " 字节" << std::endl;

    // 方式二：序列化为JSON字符串
    std::string json_data;
    google::protobuf::util::MessageToJsonString(person, &json_data);
    std::cout << "JSON大小: " << json_data.size() << " 字节" << std::endl;

    // 方式三：直接写入文件
    std::ofstream ofs("person.bin", std::ios::binary);
    person.SerializeToOstream(&ofs);
    ofs.close();

    // 释放protobuf库内部资源（程序退出前调用一次）
    google::protobuf::ShutdownProtobufLibrary();
}
```

#### 4. C++反序列化代码

```cpp
#include "person.pb.h"
#include <fstream>
#include <iostream>

void deserialize_person() {
    GOOGLE_PROTOBUF_VERIFY_VERSION;

    // 方式一：从二进制字符串解析
    std::string binary_data = /* 从网络或缓存获取 */;
    tutorial::Person person;
    if (!person.ParseFromString(binary_data)) {
        std::cerr << "解析失败" << std::endl;
        return;
    }

    // 方式二：从文件读取
    std::ifstream ifs("person.bin", std::ios::binary);
    tutorial::Person person2;
    if (!person2.ParseFromIstream(&ifs)) {
        std::cerr << "文件解析失败" << std::endl;
        return;
    }

    // 方式三：从JSON字符串解析
    tutorial::Person person3;
    std::string json_data = R"({"name":"李四","age":30})";
    google::protobuf::util::JsonStringToMessage(json_data, &person3);

    // 访问字段
    std::cout << "姓名: " << person.name() << std::endl;
    std::cout << "年龄: " << person.age() << std::endl;

    // 遍历repeated字段
    for (int i = 0; i < person.emails_size(); ++i) {
        std::cout << "邮箱" << i << ": " << person.emails(i) << std::endl;
    }

    // 访问嵌套消息
    if (person.has_address()) {
        const auto& addr = person.address();
        std::cout << "城市: " << addr.city() << std::endl;
        std::cout << "街道: " << addr.street() << std::endl;
    }

    google::protobuf::ShutdownProtobufLibrary();
}
```

#### 6. 二进制 vs JSON格式序列化

```cpp
#include "person.pb.h"
#include <iostream>
#include <google/protobuf/util/json_util.h>

void compare_formats() {
    tutorial::Person person;
    person.set_name("张三");
    person.set_age(28);
    person.add_emails("zhangsan@example.com");

    // 二进制序列化
    std::string binary;
    person.SerializeToString(&binary);
    std::cout << "二进制大小: " << binary.size() << " 字节" << std::endl;

    // JSON序列化
    std::string json;
    google::protobuf::util::MessageToJsonString(person, &json);
    std::cout << "JSON大小: " << json.size() << " 字节" << std::endl;
    std::cout << "JSON内容:\n" << json << std::endl;

    // 格式对比
    // ┌──────────┬────────────┬──────────┬──────────┐
    // │ 格式     │ 大小       │ 可读性   │ 解析速度 │
    // ├──────────┼────────────┼──────────┼──────────┤
    // │ 二进制   │ 小（约30B） │ 不可读   │ 快       │
    // │ JSON     │ 大（约80B） │ 可读     │ 慢       │
    // └──────────┴────────────┴──────────┴──────────┘

    // 二进制反序列化
    tutorial::Person p1;
    p1.ParseFromString(binary);

    // JSON反序列化
    tutorial::Person p2;
    google::protobuf::util::JsonStringToMessage(json, &p2);
}
```

### 4. FlatBuffers实战

#### 1. .fbs schema定义

```flatbuffers
// monster.fbs
namespace MyGame;

// 武器表
table Weapon {
    name: string;
    damage: short;
}

// 怪物表
table Monster {
    name: string;
    hp: short = 100;
    mana: short = 50;
    pos: Vec3;              // 使用内联结构体
    weapons: [Weapon];      // 武器数组
    equipped: Weapon;       // 装备的武器（引用另一个表）
    path: [Vec3];           // 路径点数组
}

// 内联结构体（不使用偏移量，直接嵌入父对象）
struct Vec3 {
    x: float;
    y: float;
    z: float;
}

root_type Monster;
```

#### 2. flatc编译命令

```bash
# 生成C++头文件
flatc --cpp monster.fbs

# 指定输出目录
flatc --cpp -o ./generated monster.fbs

# 同时生成多语言代码
flatc --cpp --python --java monster.fbs

# 从JSON生成二进制FlatBuffer文件
flatc -b monster.fbs monster_data.json

# 从FlatBuffer二进制文件导出为JSON
flatc --json monster.fbs -- monster_data.bin
```

编译后生成 `monster_generated.h`。

#### 3. C++构建FlatBuffer（Builder模式）

```cpp
#include "monster_generated.h"
#include <fstream>
#include <iostream>

using namespace MyGame;

void build_monster() {
    // 创建Builder，初始缓冲区1024字节
    flatbuffers::FlatBufferBuilder builder(1024);

    // 创建字符串（必须先于包含它的表创建）
    auto name = builder.CreateString("哥布林");

    // 创建武器数组
    std::vector<flatbuffers::Offset<Weapon>> weapons_vec;
    auto weapon1_name = builder.CreateString("铁剑");
    auto weapon1 = CreateWeapon(builder, weapon1_name, 15);
    weapons_vec.push_back(weapon1);

    auto weapon2_name = builder.CreateString("木盾");
    auto weapon2 = CreateWeapon(builder, weapon2_name, 5);
    weapons_vec.push_back(weapon2);

    auto weapons = builder.CreateVector(weapons_vec);

    // 创建路径点数组
    std::vector<Vec3> path_vec;
    path_vec.push_back(Vec3(1.0f, 2.0f, 3.0f));
    path_vec.push_back(Vec3(4.0f, 5.0f, 6.0f));
    auto path = builder.CreateVectorOfStructs(path_vec);

    // 创建Monster（字段按非标量→标量顺序）
    auto monster = CreateMonster(
        builder,
        name,           // name: string
        150,            // hp: short
        80,             // mana: short
        &Vec3(0.0f, 1.0f, 2.0f), // pos: Vec3（内联结构体传指针）
        weapons,        // weapons: [Weapon]
        weapon1,        // equipped: Weapon
        path            // path: [Vec3]
    );

    // 完成构建
    builder.Finish(monster);

    // 获取序列化数据
    uint8_t* buf = builder.GetBufferPointer();
    int size = builder.GetSize();
    std::cout << "FlatBuffer大小: " << size << " 字节" << std::endl;

    // 保存到文件
    std::ofstream ofs("monster.bin", std::ios::binary);
    ofs.write(reinterpret_cast<const char*>(buf), size);
    ofs.close();
}
```

#### 4. C++读取FlatBuffer（零拷贝直接访问）

```cpp
#include "monster_generated.h"
#include <fstream>
#include <iostream>

using namespace MyGame;

void read_monster() {
    // 读取文件到缓冲区
    std::ifstream ifs("monster.bin", std::ios::binary | std::ios::ate);
    auto size = ifs.tellg();
    ifs.seekg(0, std::ios::beg);
    std::vector<uint8_t> buffer(size);
    ifs.read(reinterpret_cast<char*>(buffer.data()), size);
    ifs.close();

    // 获取Monster根对象（无需解析，零拷贝直接访问）
    auto monster = GetMonster(buffer.data());

    // 直接访问字段（无反序列化开销）
    std::cout << "名字: " << monster->name()->c_str() << std::endl;
    std::cout << "生命值: " << monster->hp() << std::endl;
    std::cout << "魔法值: " << monster->mana() << std::endl;

    // 访问内联结构体
    auto pos = monster->pos();
    if (pos) {
        std::cout << "位置: (" << pos->x() << ", "
                  << pos->y() << ", " << pos->z() << ")" << std::endl;
    }

    // 访问武器数组
    auto weapons = monster->weapons();
    if (weapons) {
        for (size_t i = 0; i < weapons->size(); ++i) {
            auto weapon = weapons->Get(i);
            std::cout << "武器" << i << ": " << weapon->name()->c_str()
                      << ", 伤害: " << weapon->damage() << std::endl;
        }
    }

    // 访问装备的武器
    auto equipped = monster->equipped();
    if (equipped) {
        std::cout << "装备: " << equipped->name()->c_str() << std::endl;
    }
}
```

#### 5. 与protobuf的核心区别（零拷贝 vs 解析）

```
┌─────────────────────────────────────────────────────────────┐
│                    Protobuf 读取流程                         │
│                                                             │
│  二进制数据 ──→ ParseFromString() ──→ 新的C++对象           │
│                （需要解析+内存分配）                         │
│                                                             │
│  读取1000个字段 = 解析1000个字段 + 分配1000份内存            │
├─────────────────────────────────────────────────────────────┤
│                   FlatBuffers 读取流程                       │
│                                                             │
│  二进制数据 ──→ GetMonster() ──→ 直接访问（指针偏移）       │
│                （无需解析，无需内存分配）                    │
│                                                             │
│  读取1个字段 = 只读取1个字段（跳过其他字段）                 │
└─────────────────────────────────────────────────────────────┘
```

```cpp
// protobuf：必须完整解析才能访问任何字段
tutorial::Person person;
person.ParseFromString(binary_data);  // 解析全部字段
std::string name = person.name();     // 访问已解析的数据

// FlatBuffers：无需解析，直接按偏移量访问
auto monster = GetMonster(buffer.data);  // 仅获取根指针
std::string name = monster->name()->c_str();  // 按需访问，跳过其他字段
```

| 对比维度 | Protobuf | FlatBuffers |
|---------|----------|-------------|
| 读取方式 | 先解析全部，再访问 | 零拷贝，按需直接访问 |
| 内存分配 | 解析时分配新对象 | 不分配，直接读原缓冲区 |
| 读取速度 | 慢（需要解析） | 快（直接偏移访问） |
| 构建速度 | 快（顺序写入） | 较慢（需要处理偏移量） |
| 数据大小 | 较小（紧凑编码） | 较大（包含偏移表） |
| 修改数据 | 可直接修改字段 | 不可原地修改，需重建 |
| 适用场景 | 通用通信、存储 | 游戏、实时系统、嵌入式 |

### 5. 三种方案对比实战

#### 1. 同一数据结构用三种方式实现

```cpp
// ===== 原始数据 =====
struct PersonData {
    std::string name;
    int32_t age;
    std::vector<std::string> emails;
    std::string city;
};
```

```cpp
// ===== 方式一：JSON（nlohmann/json）=====
#include <nlohmann/json.hpp>
using json = nlohmann::json;

void json_example(const PersonData& data) {
    // 序列化
    json j;
    j["name"] = data.name;
    j["age"] = data.age;
    j["emails"] = data.emails;
    j["city"] = data.city;
    std::string output = j.dump();

    // 反序列化
    json j2 = json::parse(output);
    PersonData result;
    result.name = j2["name"];
    result.age = j2["age"];
    result.emails = j2["emails"].get<std::vector<std::string>>();
    result.city = j2["city"];
}
```

```protobuf
// ===== 方式二：Protobuf =====
// person.proto
syntax = "proto3";
message Person {
    string name = 1;
    int32 age = 2;
    repeated string emails = 3;
    string city = 4;
}
```

```cpp
// protobuf C++代码
void protobuf_example(const PersonData& data) {
    // 序列化
    tutorial::Person person;
    person.set_name(data.name);
    person.set_age(data.age);
    for (const auto& email : data.emails) {
        person.add_emails(email);
    }
    person.set_city(data.city);

    person.SerializeToString(&output);

    // 反序列化
    tutorial::Person person2;
    person2.ParseFromString(output);
    PersonData result;
    result.name = person2.name();
    result.age = person2.age();

        result.emails.push_back(email);

```


```cpp
// FlatBuffers C++代码
void flatbuffers_example(const PersonData& data) {
    // 序列化
    flatbuffers::FlatBufferBuilder builder(256);
    auto name = builder.CreateString(data.name);
    auto emails = builder.CreateVectorOfStrings(data.emails);
    auto city = builder.CreateString(data.city);
    auto person = CreatePerson(builder, name, data.age, emails, city);
    builder.Finish(person);
    std::string output(
        reinterpret_cast<const char*>(builder.GetBufferPointer()),
        builder.GetSize()
    );

    // 反序列化（零拷贝）
    auto person2 = GetPerson(output.data());
    PersonData result;
    result.name = person2->name()->c_str();
    result.age = person2->age();
    for (size_t i = 0; i < person2->emails()->size(); ++i) {
        result.emails.push_back(person2->emails()->Get(i)->c_str());
    }
    result.city = person2->city()->c_str();
}
```

```cpp
        auto start = std::chrono::high_resolution_clock::now();         \

        auto end = std::chrono::high_resolution_clock::now();           \
        auto ms = std::chrono::duration_cast<std::chrono::microseconds>\
            (end - start).count();                                      \
        std::cout << label << ": " << ms << " μs ("                    \
                  << ms / (count) << " μs/次)" << std::endl;           \
    } while (0)

void benchmark_comparison() {
    const int N = 10000;
    PersonData data{"张三", 28, {"a@b.com", "c@d.com"}, "北京"};

    });

    // FlatBuffers性能
    BENCH("FlatBuffers构建", N, {
        flatbuffers::FlatBufferBuilder b(256);
```

#### 3. 选择建议

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| 配置文件 | JSON | 人类可读，方便手动编辑 |
| Web API | JSON | 前端原生支持，调试方便 |
| 微服务间通信 | Protobuf | 高效、跨语言、schema演进 |
| 数据持久化 | Protobuf | 体积小、解析快、向后兼容 |
| 游戏网络协议 | FlatBuffers | 零拷贝读取，延迟极低 |
| 实时系统/嵌入式 | FlatBuffers | 无内存分配，确定性延迟 |
| C++项目内部 | cereal | 头文件库，集成简单 |
| 跨语言通信 | Protobuf | 语言支持最广泛 |
| 只读场景（大量数据） | FlatBuffers | 按需访问，跳过无关字段 |
| 需要修改序列化数据 | Protobuf | 支持原地修改字段 |

## 3. spdlog日志库

### 1. 基本使用

```cpp
#include <spdlog/spdlog.h>
#include <spdlog/sinks/basic_file_sink.h>
#include <spdlog/sinks/rotating_file_sink.h>

int main() {
    // 控制台日志
    spdlog::info("Welcome to spdlog!");
    spdlog::warn("This is a warning");
    spdlog::error("Error occurred: {}", "file not found");
    spdlog::critical("Critical error!");

    // 格式化
    spdlog::info("Position: ({}, {})", 10, 20);
    spdlog::info("Float: {:.2f}", 3.14159);

    // 文件日志
    auto file_logger = spdlog::basic_logger_mt("file_logger", "logs/app.log");
    file_logger->info("Written to file");

    // 滚动文件日志
    auto rotating_logger = spdlog::rotating_logger_mt(
        "rotating_logger", "logs/app.log",
        1024 * 1024 * 5,  // 5MB
        3                   // 保留3个文件
    );

    // 设置日志级别
    spdlog::set_level(spdlog::level::debug);
    spdlog::debug("Debug message now visible");

    // 设置格式
    spdlog::set_pattern("[%Y-%m-%d %H:%M:%S.%e] [%^%l%$] [thread %t] %v");

    return 0;
}
```

### 2. 日志级别

| 级别 | 宏 | 说明 |
|------|---|------|
| trace | `SPDLOG_TRACE` | 最详细 |
| debug | `spdlog::debug` | 调试信息 |
| info | `spdlog::info` | 一般信息 |
| warn | `spdlog::warn` | 警告 |
| error | `spdlog::error` | 错误 |
| critical | `spdlog::critical` | 严重错误 |
| off | - | 关闭日志 |

## 4. 日志最佳实践

### 1. 分级记录

```cpp
#ifdef NDEBUG
    spdlog::set_level(spdlog::level::info);
#else
    spdlog::set_level(spdlog::level::debug);
#endif
```

### 2. 结构化日志

```cpp
spdlog::info("user_login user_id={} ip={} success={}", user_id, ip, true);
```

### 3. 避免敏感信息

```cpp
// 错误：记录密码
spdlog::info("login user={} pass={}", username, password);

// 正确：脱敏
spdlog::info("login user={} pass=****", username);
```

### 4. 异步日志

```cpp
#include <spdlog/async.h>

auto async_logger = spdlog::basic_logger_mt<spdlog::async_factory>(
    "async_logger", "logs/async.log");
```
