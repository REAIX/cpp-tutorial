# 什么是比特与字节？
> 📖 相关章节：[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 一个生活比喻

想象你面前有一排灯泡，每个灯泡只有两种状态：**亮**或**灭**。一个灯泡就是一个**比特（bit）**。

- 亮 = 1
- 灭 = 0

一个比特能表示的信息太少了（只有两种状态）。但如果把 8 个灯泡排成一排，它们组合起来就能表示 256 种不同的状态——这就是一个**字节（Byte）**。

```
一个比特：  [💡]           → 0 或 1（2 种状态）

一个字节：  [💡💡💡💡💡💡💡💡]  → 00000000 到 11111111（256 种状态）
```

## 二进制——计算机的母语

人类习惯用十进制（0-9），因为人有十根手指。计算机只用二进制（0-1），因为计算机的基本元件（晶体管）只有两种状态：通电和断电。

### 十进制 vs 二进制

| 十进制 | 二进制 | 含义 |
|--------|--------|------|
| 0 | 0000 | 0 |
| 1 | 0001 | 1 |
| 2 | 0010 | 2 |
| 3 | 0011 | 2+1 |
| 5 | 0101 | 4+1 |
| 8 | 1000 | 8 |
| 10 | 1010 | 8+2 |
| 15 | 1111 | 8+4+2+1 |
| 255 | 11111111 | 128+64+32+16+8+4+2+1 |

### 二进制如何表示数字？

每一位的权重是 2 的幂次方：

```
位置：   7    6    5    4    3    2    1    0
权重：  128   64   32   16    8    4    2    1
数值：   1    0    1    1    0    0    1    0

= 128 + 0 + 32 + 16 + 0 + 0 + 2 + 0 = 178
```

## 存储单位

计算机用不同的单位来衡量数据大小：

| 单位 | 缩写 | 大小 | 比喻 |
|------|------|------|------|
| 比特 | bit | 1 个 0 或 1 | 一个灯泡 |
| 字节 | Byte (B) | 8 bits | 一排 8 个灯泡 |
| 千字节 | KB | 1024 Bytes | 一小段文字 |
| 兆字节 | MB | 1024 KB | 一首 MP3 歌曲 |
| 吉字节 | GB | 1024 MB | 一部电影 |
| 太字节 | TB | 1024 GB | 一个大硬盘 |

> ⚠️ **注意**：1 KB = 1024 B，不是 1000 B！因为计算机用二进制，2^10 = 1024。但硬盘厂商常用 1000 来计算，所以买的 500GB 硬盘实际只有约 465GB。

### 换算关系

```
1 Byte = 8 bits
1 KB = 1024 Bytes
1 MB = 1024 KB = 1,048,576 Bytes
1 GB = 1024 MB = 1,073,741,824 Bytes
1 TB = 1024 GB
```

## 为什么程序员要懂二进制？

| 原因 | 说明 |
|------|------|
| 理解数据存储 | 知道 `int` 为什么有范围限制 |
| 位运算 | C++ 中的 `&`、`|`、`<<` 等操作 |
| 调试 | 看懂内存中的十六进制数据 |
| 网络编程 | IP 地址、子网掩码都是二进制 |
| 性能优化 | 位操作比算术运算更快 |

### int 的范围为什么是 -21 亿到 +21 亿？

```cpp
int a = 2147483647;   // int 的最大值
```

因为 `int` 在大多数系统上占 **4 个字节 = 32 个比特**：

```
32 个比特能表示的不同状态数 = 2^32 = 4,294,967,296
一半给正数，一半给负数：
-2,147,483,648 到 +2,147,483,647
```

## 十六进制——程序员的速记法

二进制太长了（`11111111`），十进制又不直观（`255` 看不出二进制结构），所以程序员常用**十六进制**：

| 十进制 | 二进制 | 十六进制 |
|--------|--------|---------|
| 10 | 00001010 | 0A |
| 15 | 00001111 | 0F |
| 16 | 00010000 | 10 |
| 255 | 11111111 | FF |
| 256 | 000100000000 | 100 |

十六进制用 `0-9` 和 `A-F` 表示，`A=10, B=11, ..., F=15`。

在 C++ 中，十六进制以 `0x` 开头：

```cpp
int a = 255;      // 十进制
int b = 0xFF;     // 十六进制，等于 255
int c = 0b11111111; // 二进制（C++14 支持），也等于 255
```

### 为什么用十六进制？

**4 个二进制位 = 1 个十六进制位**，转换非常方便：

```
二进制：  1111 1010 0101 1100
十六进制：  F    A    5    C
```

每 4 位一组，直接对应一个十六进制数字，一目了然！

## 数字在内存中的存储

### 整数的存储

一个 `int` 占 4 字节（32 位），存储数字 42：

```
00000000 00000000 00000000 00101010
```

### 字符的存储

字符在计算机中用数字编码存储，最常用的是 ASCII 编码：

| 字符 | ASCII 码 | 二进制 |
|------|---------|--------|
| 'A' | 65 | 01000001 |
| 'B' | 66 | 01000010 |
| 'a' | 97 | 01100001 |
| '0' | 48 | 00110000 |
| ' ' | 32 | 00100000 |

```cpp
char c = 'A';     // 内存中存储的是 65（01000001）
int n = c;        // n = 65
cout << (char)66; // 输出 'B'
```

### 中文呢？

中文有数万个字符，ASCII（1 字节）不够用，所以用 **UTF-8** 编码（通常 3 个字节存一个中文字）：

```
'你' → UTF-8 编码 → E4 BD A0（3 个字节）
```

## 常见疑问

**Q：bit 和 Byte 的大小写重要吗？**
A：非常重要！`b` = bit（比特），`B` = Byte（字节）。网速 100Mbps 是 100 兆比特/秒，下载速度约 12.5MB/s（100÷8）。

**Q：为什么是 8 个比特组成一个字节？**
A：历史原因。早期计算机用 6 位或 7 位，但 8 位刚好能表示所有 ASCII 字符（0-127），还能留一位做校验，所以 8 位成了标准。

**Q：我需要学会心算二进制吗？**
A：不需要！理解原理就行，具体转换交给计算器。Windows 自带的计算器切换到"程序员模式"就能进行进制转换。

**Q：负数在二进制中怎么表示？**
A：用"补码"表示。简单理解就是最高位作为符号位：0 正 1 负。具体细节在后续教程中会详细讲解。
