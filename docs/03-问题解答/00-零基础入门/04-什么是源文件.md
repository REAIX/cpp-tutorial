# 什么是源文件？
> 📖 相关章节：[编译与链接](../../01-C语言/17-编译与链接.md)、[预处理器](../../01-C语言/10-预处理器.md)

## 一个生活比喻

想象你是一位作曲家。你写在五线谱上的音符，就是"源文件"——它是你创作的原始记录。但乐手们无法直接看着五线谱就发出声音，他们需要先读懂乐谱，然后用乐器演奏出来。

**源文件就是你写给计算机的"乐谱"。** 它是你用编程语言写下的纯文本，需要经过编译器的"演奏"才能变成计算机能执行的程序。

## 源文件长什么样？

源文件就是**普通的文本文件**，你可以用记事本打开它。里面的内容就是你写的代码：

```cpp
// 这是一个 C++ 源文件的内容
#include <iostream>
using namespace std;

int main() {
    cout << "你好，世界！" << endl;
    return 0;
}
```

没错，源文件里就是这样的纯文字，没有任何格式、图片或特殊符号。

## 常见的源文件扩展名

不同的编程语言使用不同的文件扩展名，就像不同类型的文档有不同的后缀一样：

| 扩展名 | 语言 | 说明 |
|--------|------|------|
| `.c` | C 语言 | C 语言的源文件 |
| `.cpp` | C++ | C++ 的源文件（最常见） |
| `.h` | C/C++ | 头文件（声明函数、类等） |
| `.hpp` | C++ | C++ 头文件（有时用） |
| `.py` | Python | Python 源文件 |
| `.java` | Java | Java 源文件 |
| `.js` | JavaScript | JavaScript 源文件 |

> 🔑 **关键理解**：`.cpp` 是 C++ 源文件，`.h` 是头文件。这两个是你学 C++ 时最常打交道的扩展名。

## 源文件 vs 头文件

C/C++ 项目中，代码通常分为两类文件：

| 类型 | 扩展名 | 作用 | 比喻 |
|------|--------|------|------|
| 源文件 | `.c` `.cpp` | 包含具体的实现代码 | 菜谱中的详细做法 |
| 头文件 | `.h` `.hpp` | 包含声明和接口 | 菜谱中的目录/菜单 |

```
头文件 (.h)           源文件 (.cpp)
┌──────────────┐     ┌──────────────────┐
│ 声明：        │     │ 实现：            │
│ 做番茄炒蛋()  │ ──→ │ 做番茄炒蛋() {    │
│ 做红烧肉()    │     │   打蛋...         │
│              │     │   切番茄...        │
│              │     │   翻炒...          │
│              │     │ }                 │
└──────────────┘     └──────────────────┘
```

头文件告诉别人"我能做什么"，源文件具体实现"怎么做"。

## 为什么代码放在文本文件里？

你可能会想：为什么不用 Word 这样的富文本编辑器来写代码呢？

1. **编译器只认纯文本**：编译器不需要字体、颜色、大小等格式信息
2. **版本控制更容易**：纯文本可以方便地比较差异
3. **工具兼容性好**：任何文本编辑器都能打开
4. **文件体积小**：纯文本比 Word 文档小得多

> ⚠️ **重要提醒**：写代码一定要用**纯文本编辑器**或 IDE，千万不要用 Word！Word 会添加隐藏的格式字符，导致编译器无法识别。

## 从源文件到可执行文件

源文件本身不能直接运行，需要经过编译过程：

```
源文件 (.cpp)          头文件 (.h)
    │                     │
    └──────┬──────────────┘
           ↓
     预处理（替换 #include 等）
           ↓
     编译（翻译成汇编代码）
           ↓
     汇编（翻译成机器码 → .o/.obj）
           ↓
     链接（合并多个 .o 文件）
           ↓
     可执行文件 (.exe)
```

就像：菜谱（源文件）→ 厨师研究菜谱（编译）→ 做好的菜（可执行文件）

## 文件编码

源文件是文本文件，而文本文件需要**编码**来决定字符如何存储：

| 编码 | 说明 | 推荐 |
|------|------|------|
| UTF-8 | 国际通用，支持中文 | ✅ 强烈推荐 |
| GBK | 中文 Windows 默认编码 | ⚠️ 可能出问题 |
| ASCII | 只支持英文 | ❌ 不支持中文 |

> 💡 **小贴士**：如果你的代码里有中文注释或中文字符串，一定要把源文件保存为 **UTF-8 编码**，否则可能出现乱码。大多数现代编辑器默认就是 UTF-8。

## 常见疑问

**Q：一个项目只有一个源文件吗？**
A：小项目可以只有一个，大项目可能有成百上千个。就像一本菜谱可以只有一道菜，也可以有几百道菜。

**Q：头文件必须要有吗？**
A：简单程序可以不要。但正规项目都会用头文件来组织代码，让结构更清晰。

**Q：我可以用记事本写代码吗？**
A：技术上可以，但记事本没有语法高亮、自动补全等功能，非常不方便。建议用 VS Code 或其他代码编辑器。
