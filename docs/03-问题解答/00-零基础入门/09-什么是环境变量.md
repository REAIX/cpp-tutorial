# 什么是环境变量？
> 📖 相关章节：[编程入门](../../01-C语言/导学/00-编程入门.md)、[C语言概述](../../01-C语言/00-C语言概述.md)、[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 一个生活比喻

想象你住在一个小镇上，镇上有很多商店。你每次去面包店都要说"去中央大街 42 号的面包店"，太麻烦了。于是你在心里记住了"面包店 = 中央大街 42 号"，以后只需要说"去面包店"就行了。

**环境变量就是计算机的"心理地图"。** 它存储了一些常用的路径和配置信息，让系统和程序能快速找到需要的东西。

## 环境变量是什么？

环境变量是**操作系统提供的一组键值对**，所有运行的程序都能读取：

```
变量名 = 变量值

PATH = C:\Windows\System32;C:\Program Files\Git\bin
HOME = C:\Users\zhangsan
LANG = zh_CN.UTF-8
```

就像一个公共公告栏，上面写着各种信息，所有人都能看。

## 最重要的环境变量：PATH

`PATH` 是最关键的环境变量，没有之一。它告诉系统：**当你在命令行输入一个命令时，去哪些文件夹找对应的程序。**

### 没有 PATH 会怎样？

```
你输入：g++
系统：g++ 是什么？我在哪能找到它？
你：它在 C:\MinGW\bin\g++.exe
系统：好的，让我去那里找……找到了！
```

每次都要输入完整路径，太痛苦了！

### 有了 PATH 之后

```
你输入：g++
系统：让我查查 PATH……
      C:\Windows\System32 → 没有
      C:\MinGW\bin → 找到了！执行它！
```

系统会自动在 PATH 列出的所有目录中搜索，找到就执行。

### PATH 的工作流程

```
输入命令：g++
     ↓
检查当前目录 → 没找到
     ↓
检查 PATH 中的第一个目录 → 没找到
     ↓
检查 PATH 中的第二个目录 → 找到了！执行！
     ↓
如果所有目录都没找到 → 报错"不是内部或外部命令"
```

## 常见的环境变量

| 变量名 | 作用 | 示例值 |
|--------|------|--------|
| `PATH` | 可执行程序的搜索路径 | `C:\Windows\System32;C:\MinGW\bin` |
| `HOME` | 用户主目录 | `C:\Users\zhangsan` |
| `TEMP` | 临时文件目录 | `C:\Users\zhangsan\AppData\Local\Temp` |
| `LANG` | 系统语言 | `zh_CN.UTF-8` |
| `INCLUDE` | C/C++ 头文件搜索路径 | `C:\MinGW\include` |
| `LIB` | C/C++ 库文件搜索路径 | `C:\MinGW\lib` |

## 如何查看环境变量

### Windows

```powershell
# 查看所有环境变量
Get-ChildItem Env:

# 查看 PATH
$env:PATH

# 查看某个变量
$env:JAVA_HOME
```

### Linux / macOS

```bash
# 查看所有环境变量
env

# 查看某个变量
echo $PATH
```

## 如何设置环境变量

### Windows（图形界面）

1. 右键"此电脑" → 属性 → 高级系统设置
2. 点击"环境变量"按钮
3. 在"用户变量"或"系统变量"中新建或编辑

### Windows（命令行）

```powershell
# 临时设置（关闭终端后失效）
$env:MY_VAR = "hello"

# 永久设置（用户级别）
[Environment]::SetEnvironmentVariable("MY_VAR", "hello", "User")

# 永久设置（系统级别，需要管理员权限）
[Environment]::SetEnvironmentVariable("MY_VAR", "hello", "Machine")
```

### Linux / macOS

```bash
# 临时设置
export MY_VAR="hello"

# 永久设置（写入 ~/.bashrc 或 ~/.zshrc）
echo 'export MY_VAR="hello"' >> ~/.bashrc
source ~/.bashrc
```

## 如何把编译器加入 PATH

这是初学者最常遇到的问题——安装了编译器但命令行找不到。

### Windows 添加 MinGW 到 PATH

1. 找到 MinGW 的 `bin` 目录，例如 `C:\MinGW\bin`
2. 打开环境变量设置
3. 编辑 `PATH` 变量
4. 添加 `C:\MinGW\bin`
5. **重新打开**命令行窗口（重要！）

```
PATH 修改前：
C:\Windows\System32;C:\Program Files\Git\cmd

PATH 修改后：
C:\Windows\System32;C:\Program Files\Git\cmd;C:\MinGW\bin
                                        新增的部分 ↑
```

## 常见坑与解决方法

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| "g++ 不是内部或外部命令" | g++ 所在目录不在 PATH 中 | 把 MinGW\bin 加入 PATH |
| 修改 PATH 后仍然找不到命令 | 没有重新打开终端 | 关闭并重新打开终端 |
| PATH 被意外清空 | 编辑时不小心删除了 | 提前备份 PATH 的值 |
| 多个版本冲突 | PATH 中有多个同名程序 | 调整顺序，把想要的版本放前面 |

> ⚠️ **重要提醒**：修改 PATH 时，是**追加**新路径，不要删除已有的路径！否则可能导致系统出问题。

## 常见疑问

**Q：用户变量和系统变量有什么区别？**
A：用户变量只对当前用户生效，系统变量对所有用户生效。一般修改用户变量就够了。

**Q：PATH 中的顺序重要吗？**
A：重要！系统按顺序搜索，找到第一个匹配的就停止。如果 PATH 中有多个同名程序，排在前面的优先。

**Q：修改环境变量需要重启电脑吗？**
A：不需要，但需要**重新打开**终端或 IDE，因为已经打开的程序使用的是启动时的环境变量。
