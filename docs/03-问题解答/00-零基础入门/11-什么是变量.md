# 什么是变量？
> 📖 相关章节：[编程入门](../../01-C语言/导学/00-编程入门.md)、[C语言概述](../../01-C语言/00-C语言概述.md)、[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 用生活比喻理解变量

想象你有一排**贴着标签的盒子**，每个盒子上写着名字，里面可以放一样东西。比如：

- 一个盒子贴着"年龄"，里面放着数字 `25`
- 一个盒子贴着"名字"，里面放着文字 `"小明"`
- 一个盒子贴着"是否会员"，里面放着 `是` 或 `否`

这些"贴了标签的盒子"就是**变量**。`变量`（`variable`）就是程序中用来**存储数据**的容器，它有一个名字，里面可以放一个值，而且这个值可以**变化**——所以叫"变"量。

```
┌──────────┐  ┌──────────┐  ┌──────────┐
│  年龄     │  │  名字     │  │ 是否会员  │
│   25     │  │  "小明"   │  │   true   │
└──────────┘  └──────────┘  └──────────┘
   变量1          变量2          变量3
```

## 为什么需要变量？

如果没有变量，程序就像一个**没有记忆**的人——算完就忘，无法保存任何中间结果。

| 没有变量 | 有变量 |
|---------|--------|
| 算完 `3 + 5`，结果 `8` 就消失了 | 把 `8` 存到 `sum` 里，随时可用 |
| 每次用到同一个值都要重新写 | 写一次，反复使用 |
| 无法记录用户输入 | 把输入存起来，慢慢处理 |

## 声明和定义变量

**声明**（`declaration`）是告诉编译器"我要用一个变量，叫这个名字"；**定义**（`definition`）是真正创建这个变量并分配内存。在 C++ 中，声明和定义通常合二为一：

```cpp
// 声明并定义一个整型变量
int age = 25;           // 年龄

// 声明并定义一个字符串变量
std::string name = "小明";  // 名字

// 也可以先声明，再赋值
double price;           // 声明：告诉编译器 price 是一个双精度浮点数
price = 9.99;           // 赋值：给 price 放入值
```

> 💡 **比喻**：声明就像在仓库里登记了一个储物柜，定义则是真正拿到了那个柜子并开始使用它。

## 变量的命名规则

给变量起名字就像给孩子取名，但必须遵守规则：

| 规则 | 说明 | 正确示例 | 错误示例 |
|------|------|---------|---------|
| 只能用字母、数字、下划线 | 不能有特殊符号 | `my_age` | `my-age` |
| 不能以数字开头 | 数字开头会混淆 | `score1` | `1score` |
| 不能用关键字 | `int`、`return` 等是保留词 | `myInt` | `int` |
| 区分大小写 | `Age` 和 `age` 是不同变量 | — | — |
| 见名知意 | 名字要有意义 | `studentCount` | `x` |

**命名风格推荐**：

```cpp
int student_age;     // 下划线风格（snake_case）——C 语言传统
int studentAge;      // 驼峰风格（camelCase）——C++ 常用
int StudentAge;      // Pascal 风格——通常用于类名
```

## 变量的基本类型

不同类型的"盒子"装不同的东西——你不能在一个装苹果的盒子里放水：

```cpp
int    count = 10;         // 整数：装没有小数点的数
double price = 3.14;       // 浮点数：装有小数点的数
char   grade = 'A';        // 字符：装单个字符
bool   isPassed = true;    // 布尔：装"真"或"假"
std::string name = "小明";  // 字符串：装一串文字
```

> 💡 **比喻**：变量类型就像盒子的**形状**——圆盒子装球，方盒子装书。你不会把水倒进纸盒里，同样，你也不应该把文字塞进整数变量里。

## 变量的值可以变化

变量之所以叫"变"量，是因为它的值可以随时改变：

```cpp
int score = 0;       // 初始分数是 0
score = 80;          // 考试得了 80 分，更新
score = score + 10;  // 加分题又得了 10 分，变成 90
```

这个过程就像你把盒子里的东西拿出来，换一个新东西放进去。注意 `score = score + 10` 不是数学等式，而是"把 `score` 当前的值加上 `10`，再放回 `score`"。

## 变量的作用域（Scope）

**作用域**（`scope`）就是变量"活着"的范围——就像你的工牌只在公司内有效，出了公司门就没人认了。

```cpp
#include <iostream>

int globalVar = 100;   // 全局变量：整个程序都能看到

int main() {
    int localVar = 50; // 局部变量：只在 main 函数内有效

    {
        int blockVar = 30; // 块变量：只在这个大括号内有效
        std::cout << blockVar << std::endl;  // ✅ 可以用
    }
    // std::cout << blockVar << std::endl;   // ❌ 出了作用域，不存在了

    return 0;
}
```

```
┌─────────────── 全局作用域 ───────────────┐
│  globalVar = 100                         │
│  ┌──────── main 作用域 ────────┐         │
│  │  localVar = 50              │         │
│  │  ┌── 块作用域 ──┐          │         │
│  │  │ blockVar=30  │          │         │
│  │  └──────────────┘          │         │
│  └────────────────────────────┘         │
└──────────────────────────────────────────┘
```

## 常量——特殊的"变量"

如果变量的值不应该被改变，就用 `const` 把它"锁"起来：

```cpp
const double PI = 3.14159265;  // 圆周率，不能修改
const int MAX_STUDENTS = 50;   // 最大学生数，不能修改

// PI = 3.14;  // ❌ 编译错误！常量不能被修改
```

> 💡 **比喻**：常量就像博物馆的展品——你可以看，但不能碰。

## 小结

| 概念 | 一句话理解 |
|------|-----------|
| 变量 | 贴了标签的盒子，用来存数据 |
| 声明 | 告诉编译器"我要用这个盒子" |
| 定义 | 真正创建这个盒子 |
| 类型 | 盒子的形状，决定能装什么 |
| 作用域 | 盒子有效的范围 |
| 常量 | 锁上的盒子，只能看不能改 |

记住：**变量是编程最基础的概念**，几乎每一行代码都在和变量打交道。理解了变量，你就迈出了编程的第一步！
