# 什么是数据类型？
> 📖 相关章节：[编程入门](../../00-导学/00-编程入门.md)、[C语言概述](../../01-C语言/00-C语言概述.md)、[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 用生活比喻理解数据类型

想象你去超市买东西，收银台会自动区分：

- **苹果**按斤称重（小数）
- **鸡蛋**按个计数（整数）
- **标签**上写的是文字（字符串）
- **是否打折**只有"是"或"否"（布尔）

你不会问"这个鸡蛋 3.14 个"——因为鸡蛋只能按整数算。同样，在编程中，**数据类型**（`data type`）告诉计算机：这个数据是什么"品种"，应该怎么处理它。

> 💡 **比喻**：数据类型就像超市里不同种类的商品——每种商品有自己的计量方式和存储要求，不能混着来。

## 为什么数字和文字不同？

在计算机眼中，一切都是 `0` 和 `1`。但同样是 `0` 和 `1`，不同类型解读方式完全不同：

```
数字 65 的二进制：01000001
字符 'A' 的二进制：01000001  ← 完全一样！
```

同样的二进制，如果当作数字就是 `65`，当作字符就是 `'A'`。**数据类型就是告诉计算机"用哪种方式解读这些 0 和 1"**。

```cpp
int number = 65;      // 当作数字：65
char letter = 'A';    // 当作字符：A（底层也是 65）
// 同样的数据，类型不同，含义不同！
```

## 整数类型

整数就是**没有小数点**的数，就像你数人数、数苹果，不可能有"半个人"。

| 类型 | 占用空间 | 范围（大约） | 比喻 |
|------|---------|-------------|------|
| `short` | 2 字节 | -3.2万 ~ 3.2万 | 小号盒子 |
| `int` | 4 字节 | -21亿 ~ 21亿 | 中号盒子 |
| `long` | 4/8 字节 | 更大 | 大号盒子 |
| `long long` | 8 字节 | 非常非常大 | 超大号盒子 |

```cpp
short studentCount = 45;       // 一个班的学生数，short 足够
int worldPopulation = 7900000000; // 世界人口，需要 int
long long starCount = 1000000000000; // 星星数量，需要 long long
```

> 💡 **比喻**：选整数类型就像选盒子大小——装一颗珍珠用小盒子，装一头大象用大盒子。用太大的盒子浪费空间，用太小的盒子装不下。

### 有符号 vs 无符号

```cpp
int temperature = -5;          // 有符号：可以是负数（零下温度）
unsigned int age = 25;         // 无符号：只能是正数（年龄不可能是负的）
```

| 修饰符 | 含义 | 示例场景 |
|--------|------|---------|
| `signed`（默认） | 可以是负数 | 温度、利润、海拔 |
| `unsigned` | 只能是非负数 | 年龄、数量、长度 |

## 浮点类型

浮点数就是**有小数点**的数，像身高、价格、圆周率：

| 类型 | 占用空间 | 精度（有效数字） | 比喻 |
|------|---------|-----------------|------|
| `float` | 4 字节 | 约 6-7 位 | 普通秤 |
| `double` | 8 字节 | 约 15-16 位 | 精密天平 |

```cpp
float height = 1.75f;          // 身高，float 精度够用
double pi = 3.141592653589793; // 圆周率，需要 double 的精度
```

> ⚠️ **注意**：浮点数有精度问题！`0.1 + 0.2` 在计算机中不等于 `0.3`，而是约等于 `0.30000000000000004`。这是因为十进制小数在二进制中可能无法精确表示，就像 `1/3` 在十进制中是无限循环小数一样。

## 字符类型

`char` 用来存储**单个字符**，如字母、数字符号、标点：

```cpp
char grade = 'A';       // 用单引号包围单个字符
char digit = '7';       // 字符 '7'，不是数字 7！
char symbol = '$';      // 特殊符号
```

> 💡 **比喻**：`char` 就像一个只能放一张卡片的卡槽——一次只能放一个字符。

字符和数字的关系：

```
字符    ASCII 码
'A'  →  65
'B'  →  66
'a'  →  97
'0'  →  48
' '  →  32（空格）
```

## 布尔类型

`bool` 只有两个值：`true`（真）和 `false`（假），就像电灯开关只有"开"和"关"：

```cpp
bool isStudent = true;      // 是学生
bool hasLicense = false;    // 没有驾照
bool isEmpty = (0 == 0);    // true
```

> 💡 **比喻**：布尔值就像判断题的答案——只有"对"和"错"，没有"可能"。

## 类型大小一览表

在大多数 64 位系统上：

| 类型 | 大小（字节） | 能存什么 |
|------|------------|---------|
| `bool` | 1 | 真或假 |
| `char` | 1 | 单个字符 |
| `short` | 2 | 小范围整数 |
| `int` | 4 | 常用整数 |
| `long` | 4/8 | 大范围整数 |
| `long long` | 8 | 超大整数 |
| `float` | 4 | 6-7 位精度小数 |
| `double` | 8 | 15-16 位精度小数 |

你可以用 `sizeof` 查看你系统上的实际大小：

```cpp
#include <iostream>
int main() {
    std::cout << "int 大小: " << sizeof(int) << " 字节" << std::endl;
    std::cout << "double 大小: " << sizeof(double) << " 字节" << std::endl;
    return 0;
}
```

## 为什么类型很重要？

### 1. 防止错误

```cpp
int age = "二十五";   // ❌ 编译错误！不能把文字放进整数变量
int age = 25;         // ✅ 正确
```

类型检查就像**安检**——不让错误的东西通过，在问题发生之前就拦住它。

### 2. 节省内存

如果所有变量都用最大的类型，就像用卡车送一封信——太浪费了。选择合适的类型可以节省内存。

### 3. 决定操作方式

```cpp
int a = 5, b = 3;
std::cout << a / b << std::endl;    // 输出 1（整数除法，截断小数）

double x = 5.0, y = 3.0;
std::cout << x / y << std::endl;    // 输出 1.66667（浮点除法）
```

同样的除法，整数和浮点数的结果完全不同！

### 4. 类型转换

有时候需要在不同类型之间转换：

```cpp
int score = 85;
double average = score;          // 隐式转换：小盒子→大盒子，安全

double pi = 3.14159;
int approx = pi;                 // 隐式转换：大盒子→小盒子，丢失小数部分
// approx 变成 3，小数被截断

int total = 17;
double result = (double)total / 5;  // 显式转换：告诉编译器"我知道我在做什么"
// result = 3.4
```

## 小结

| 概念 | 一句话理解 |
|------|-----------|
| 数据类型 | 数据的"品种"，决定怎么存储和操作 |
| 整数类型 | 没有小数点的数，有大小之分 |
| 浮点类型 | 有小数点的数，有精度之分 |
| 字符类型 | 单个字符，底层是数字 |
| 布尔类型 | 只有真和假 |
| 类型转换 | 不同类型之间的"翻译" |

记住：**选对数据类型就像选对工具**——用锤子钉钉子，用螺丝刀拧螺丝，用对类型才能写出正确的程序！
