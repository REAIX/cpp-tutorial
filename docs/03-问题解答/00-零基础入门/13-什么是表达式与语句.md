# 什么是表达式与语句？
> 📖 相关章节：[编程入门](../../01-C语言/导学/00-编程入门.md)、[C语言概述](../../01-C语言/00-C语言概述.md)、[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 用生活比喻理解

想象你在餐厅点餐：

- **表达式**就像"3 个汉堡 + 2 杯可乐"——它能**算出一个结果**（总价 85 元）
- **语句**就像"请给我 3 个汉堡和 2 杯可乐"——它是一条**完整的指令**，让服务员去执行

表达式**产生一个值**，语句**完成一个动作**。

> 💡 **比喻**：表达式是"算式"，语句是"命令"。表达式回答"等于多少"，语句回答"做什么"。

## 表达式（Expression）

**表达式**（`expression`）是由变量、常量和运算符组成的式子，它**一定会产生一个值**：

```cpp
3 + 5           // 算术表达式，值为 8
x * 2           // 变量参与的表达式
a > b           // 比较表达式，值为 true 或 false
score + bonus   // 两个变量相加
```

### 表达式的种类

| 类型 | 示例 | 结果 |
|------|------|------|
| 算术表达式 | `3 + 5` | `8` |
| 关系表达式 | `10 > 5` | `true` |
| 逻辑表达式 | `true && false` | `false` |
| 赋值表达式 | `x = 10` | `10`（赋值也有值！） |
| 函数调用 | `abs(-5)` | `5` |

### 表达式可以嵌套

就像数学中 `(3 + 5) * 2` 一样，表达式可以套表达式：

```cpp
int a = 3;
int b = 5;
int result = (a + b) * 2;   // (3+5)*2 = 16
//        └───┘   │
//       表达式1   表达式2
//  └──────────────┘
//       整体也是表达式
```

## 运算符（Operator）

运算符是表达式中的"动词"，它们对数据进行操作：

### 算术运算符

```cpp
int a = 10, b = 3;
a + b    // 13  加法
a - b    // 7   减法
a * b    // 30  乘法
a / b    // 3   除法（整数除法，截断小数）
a % b    // 1   取余（10 除以 3 余 1）
```

> 💡 **比喻**：算术运算符就像计算器上的按钮——每个按钮执行一种计算。

### 比较运算符

```cpp
5 > 3      // true   大于
5 < 3      // false  小于
5 >= 5     // true   大于等于
5 <= 3     // false  小于等于
5 == 5     // true   等于（注意：两个等号！）
5 != 3     // true   不等于
```

> ⚠️ **新手常见错误**：`=` 是赋值，`==` 才是判断相等！

### 逻辑运算符

```cpp
true && false   // false  逻辑与（AND）：两个都真才是真
true || false   // true   逻辑或（OR）：有一个真就是真
!true           // false  逻辑非（NOT）：取反
```

| 运算符 | 含义 | 比喻 |
|--------|------|------|
| `&&` | 与 | "既会唱歌**又会**跳舞"——两个条件都满足 |
| `||` | 或 | "喝茶**或**咖啡"——满足一个就行 |
| `!` | 非 | "**不是**学生"——取反 |

### 运算符优先级

就像数学中"先乘除后加减"，编程也有优先级：

```cpp
int result = 2 + 3 * 4;    // 结果是 14，不是 20！
// 先算 3*4=12，再算 2+12=14

int result2 = (2 + 3) * 4; // 结果是 20，括号优先
```

**简单记忆**：不确定优先级时，**加括号**就对了！

## 语句（Statement）

**语句**（`statement`）是程序执行的**最小独立单元**，每条语句告诉计算机"做一件事"。C++ 中，语句以**分号** `;` 结尾：

```cpp
int x = 10;                // 声明语句
x = x + 5;                 // 赋值语句
std::cout << x << std::endl;  // 输出语句
return 0;                  // 返回语句
```

> 💡 **比喻**：语句就像一句话——"请把门关上。"分号就像句号，告诉计算机"这句话说完了"。

### 常见的语句类型

| 语句类型 | 示例 | 说明 |
|---------|------|------|
| 表达式语句 | `x = 5;` | 表达式加分号 |
| 声明语句 | `int y = 10;` | 声明变量 |
| 条件语句 | `if (x > 0) {...}` | 根据条件执行 |
| 循环语句 | `for (int i=0; i<5; i++) {...}` | 重复执行 |
| 返回语句 | `return 0;` | 从函数返回 |
| 空语句 | `;` | 什么都不做（偶尔有用） |

## 表达式 vs 语句

| 特点 | 表达式 | 语句 |
|------|--------|------|
| 产生值 | ✅ 一定产生值 | ❌ 不一定 |
| 可以单独存在 | ❌ 需要加分号才成语句 | ✅ 可以单独存在 |
| 可以嵌套 | ✅ 可以 | ❌ 不行 |
| 类比 | 算式 | 命令 |

```cpp
3 + 5          // 表达式：值为 8，但不能单独写在这里
3 + 5;         // 语句：计算 3+5 然后丢弃结果（合法但无意义）
int x = 3 + 5; // 语句：计算 3+5 并存入 x（有意义）
```

## 代码块（Block）

用大括号 `{}` 包围的多条语句组成一个**代码块**（`block`），也叫**复合语句**：

```cpp
{
    int temp = 100;     // 语句1
    temp = temp + 1;    // 语句2
    std::cout << temp;  // 语句3
}
// temp 在这里就"消失"了（超出作用域）
```

> 💡 **比喻**：代码块就像一个"工作间"——进去干活，出来后工作间里的临时工具就收走了。

代码块常与条件语句、循环语句一起使用：

```cpp
if (score >= 60) {
    std::cout << "及格了！" << std::endl;    // 代码块开始
    std::cout << "继续加油！" << std::endl;   // 代码块结束
}
```

## 计算机如何一步步执行代码

计算机从上到下、一条一条地执行语句：

```cpp
int a = 10;              // ① 创建变量 a，值为 10
int b = 20;              // ② 创建变量 b，值为 20
int sum = a + b;         // ③ 计算 a+b，结果 30 存入 sum
std::cout << sum;        // ④ 输出 30
```

执行流程：

```
① a = 10
   ↓
② b = 20
   ↓
③ sum = 10 + 20 = 30
   ↓
④ 输出 30
```

就像你按照菜谱做菜——**一步一步来，不能跳步**。

## 小结

| 概念 | 一句话理解 |
|------|-----------|
| 表达式 | 能算出一个值的式子 |
| 语句 | 让计算机做一件事的完整指令 |
| 运算符 | 表达式中的"动词" |
| 分号 | 语句的"句号" |
| 代码块 | 大括号包围的一组语句 |
| 执行顺序 | 从上到下，逐条执行 |

记住：**表达式算值，语句做事**——理解了这两个概念，你就能读懂程序在"算什么"和"做什么"了！
