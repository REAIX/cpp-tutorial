# 什么是流程控制？
> 📖 相关章节：[编程入门](../../00-导学/00-编程入门.md)、[C语言概述](../../01-C语言/00-C语言概述.md)、[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 用生活比喻理解流程控制

想象你开车出门：

- **顺序执行**：沿路一直往前开
- **分支**：到岔路口，看路标决定走哪条路
- **循环**：绕操场跑步，一圈又一圈地重复

**流程控制**（`flow control`）就是决定程序**按什么顺序执行**的机制。没有流程控制，程序只能从上到下死板地执行；有了流程控制，程序就能**判断、选择、重复**。

```
顺序：  ──→ ──→ ──→ ──→
分支：  ──→ ◇ ──→ 左边
                └──→ 右边
循环：  ──→ ○ ←──┐
            └────┘  重复
```

## 顺序执行

程序默认的执行方式——**从上到下，逐行执行**，就像读书从第一行读到最后一行：

```cpp
int main() {
    std::cout << "第一步：起床" << std::endl;
    std::cout << "第二步：刷牙" << std::endl;
    std::cout << "第三步：吃早餐" << std::endl;
    return 0;
}
```

这是最简单的流程，不需要任何控制语句。

## 分支——做选择

### if / else

就像出门前看天气：**如果**下雨就带伞，**否则**就不带。

```cpp
int score = 85;

if (score >= 60) {
    std::cout << "及格了！" << std::endl;
} else {
    std::cout << "没及格，继续努力" << std::endl;
}
```

流程图：

```
       ┌─── score >= 60? ───┐
       │                     │
      是                    否
       │                     │
       ▼                     ▼
  "及格了！"          "没及格，继续努力"
```

### 多条件分支：if / else if / else

```cpp
int score = 85;

if (score >= 90) {
    std::cout << "优秀" << std::endl;
} else if (score >= 80) {
    std::cout << "良好" << std::endl;    // ← 执行这行
} else if (score >= 60) {
    std::cout << "及格" << std::endl;
} else {
    std::cout << "不及格" << std::endl;
}
```

> 💡 **比喻**：多条件分支就像自动售货机选饮料——投币后，按不同按钮得到不同饮料。

### switch 语句

当判断条件是**一个变量的多个固定值**时，`switch` 更清晰：

```cpp
int day = 3;

switch (day) {
    case 1: std::cout << "星期一" << std::endl; break;
    case 2: std::cout << "星期二" << std::endl; break;
    case 3: std::cout << "星期三" << std::endl; break;  // ← 执行这行
    case 4: std::cout << "星期四" << std::endl; break;
    case 5: std::cout << "星期五" << std::endl; break;
    default: std::cout << "周末" << std::endl; break;
}
```

> ⚠️ **注意**：每个 `case` 后面必须加 `break`，否则会"穿透"到下一个 `case` 继续执行！

| if/else | switch |
|---------|--------|
| 判断范围（`x > 0`） | 判断固定值（`x == 1`） |
| 灵活，任何条件都行 | 只能判断整数/字符/枚举 |
| 条件多时嵌套深 | 条件多时更清晰 |

## 循环——重复做

### for 循环

当你**知道要重复多少次**时，用 `for`：

```cpp
// 打印 1 到 5
for (int i = 1; i <= 5; i++) {
//   初始化↑   条件↑    更新↑
    std::cout << i << " ";
}
// 输出：1 2 3 4 5
```

> 💡 **比喻**：`for` 循环就像跑 5 圈操场——你提前知道要跑几圈，每跑完一圈计数器加 1。

`for` 循环的执行流程：

```
① 初始化 (int i = 1)
   ↓
② 判断条件 (i <= 5?) ──否──→ 退出循环
   │是
   ↓
③ 执行循环体
   ↓
④ 更新 (i++)
   ↓
   返回 ②
```

### while 循环

当你**不知道要重复多少次**时，用 `while`：

```cpp
// 猜数字游戏
int secret = 42;
int guess = 0;

while (guess != secret) {     // 只要猜错就继续
    std::cout << "请输入猜测: ";
    std::cin >> guess;
}
std::cout << "猜对了！" << std::endl;
```

> 💡 **比喻**：`while` 循环就像等公交——你不知道要等多久，但只要车没来就一直等。

### do-while 循环

先执行一次，再判断是否继续——**至少执行一次**：

```cpp
int number;
do {
    std::cout << "请输入正数: ";
    std::cin >> number;
} while (number <= 0);   // 如果输入的不是正数，再来一次
```

> 💡 **比喻**：`do-while` 就像试吃——先吃一口，不好吃就不吃了，但至少尝了一次。

### 三种循环对比

| 循环类型 | 何时用 | 至少执行几次 |
|---------|--------|------------|
| `for` | 知道循环次数 | 可能 0 次 |
| `while` | 不知道次数，先判断 | 可能 0 次 |
| `do-while` | 不知道次数，先执行 | 至少 1 次 |

## break 和 continue

### break——跳出循环

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;    // 遇到 5 就跳出循环
    }
    std::cout << i << " ";
}
// 输出：1 2 3 4
```

> 💡 **比喻**：`break` 就像跑步时突然受伤——立刻停下来，不跑了。

### continue——跳过本次

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;   // 跳过 3，继续下一次循环
    }
    std::cout << i << " ";
}
// 输出：1 2 4 5
```

> 💡 **比喻**：`continue` 就像跑步时遇到水坑——跳过这一步，继续跑。

| 关键字 | 作用 | 比喻 |
|--------|------|------|
| `break` | 跳出整个循环 | 受伤退赛 |
| `continue` | 跳过本次，继续下一轮 | 跳过水坑 |

## 为什么需要流程控制？

没有流程控制的程序就像一条**没有岔路口、没有回头路的单行道**——只能直走，不能选择，不能重复。

| 没有流程控制 | 有流程控制 |
|-------------|-----------|
| 只能顺序执行 | 可以选择、可以重复 |
| 代码冗长重复 | 用循环精简代码 |
| 无法根据条件做不同的事 | 灵活应对各种情况 |
| 程序很"笨" | 程序有"判断力" |

## 综合示例

```cpp
#include <iostream>
int main() {
    int total = 0;

    for (int i = 1; i <= 100; i++) {    // 循环：1 到 100
        if (i % 2 == 0) {               // 分支：判断是否偶数
            total += i;                  // 累加偶数
        }
    }

    std::cout << "1到100的偶数之和: " << total << std::endl;
    // 输出：1到100的偶数之和: 2550
    return 0;
}
```

## 小结

| 概念 | 一句话理解 |
|------|-----------|
| 顺序执行 | 从上到下，逐行执行 |
| 分支（if/else） | 到岔路口，选一条路走 |
| 分支（switch） | 按按钮选饮料 |
| 循环（for） | 跑固定圈数 |
| 循环（while） | 等公交，车不来就一直等 |
| 循环（do-while） | 先试吃再决定 |
| break | 受伤退赛，跳出循环 |
| continue | 跳过水坑，继续跑 |

记住：**流程控制让程序从"死板"变"灵活"**——能判断、能选择、能重复，这才是真正的程序！
