# 什么是函数？
> 📖 相关章节：[函数](../../01-C语言/04-函数.md)

## 用生活比喻理解函数

想象你在厨房做菜。你有一本**菜谱**，上面写着：

> **"番茄炒蛋"**
> 材料：鸡蛋 3 个、番茄 2 个
> 步骤：1. 打蛋 2. 切番茄 3. 炒蛋 4. 加番茄翻炒
> 出品：一盘番茄炒蛋

每次你想吃番茄炒蛋，不需要重新想步骤，只要**按菜谱做**就行。**函数**（`function`）就是程序中的"菜谱"——把一组操作打包起来，需要时直接调用。

```
调用函数就像"点菜"：
  你：来一份番茄炒蛋！
  厨房（函数）：按菜谱做 → 端出一盘菜
```

> 💡 **比喻**：函数就像一台**自动售货机**——你投入硬币（输入），按下按钮（调用函数），机器吐出饮料（输出）。你不需要知道机器内部怎么运作，只要知道怎么用就行。

## 函数的基本结构

```cpp
返回类型 函数名(参数列表) {
    // 函数体：具体要做的事
    return 返回值;
}
```

用菜谱来对应：

| 编程概念 | 菜谱比喻 | 说明 |
|---------|---------|------|
| 返回类型 | 出品类型（菜/汤/甜品） | 函数产出什么类型的结果 |
| 函数名 | 菜名 | 用来识别和调用函数 |
| 参数列表 | 所需食材 | 函数需要什么原材料 |
| 函数体 | 烹饪步骤 | 函数具体做什么 |
| 返回值 | 做好的菜 | 函数产出的结果 |

## 一个简单的函数

```cpp
#include <iostream>

// 定义一个函数：打招呼
void sayHello() {
    std::cout << "你好，欢迎学习编程！" << std::endl;
}

int main() {
    sayHello();   // 调用函数：让函数执行一次
    sayHello();   // 再调用一次
    return 0;
}
```

输出：
```
你好，欢迎学习编程！
你好，欢迎学习编程！
```

你看，写一次函数，可以**反复使用**——这就是函数的核心价值。

## 参数和参数——给函数"送食材"

**参数**（`parameter`）是函数定义时声明的"食材清单"，**实参**（`argument`）是调用时真正传入的"食材"。

```cpp
// 参数：a 和 b 是"形参"（占位符）
int add(int a, int b) {
    return a + b;   // 返回 a 加 b 的结果
}

int main() {
    // 实参：3 和 5 是"实参"（真正的值）
    int result = add(3, 5);   // result = 8
    std::cout << result << std::endl;
    return 0;
}
```

> 💡 **比喻**：形参就像菜谱上写的"鸡蛋 N 个"——N 是个占位符；实参就像你真正拿了 3 个鸡蛋——3 是具体的值。

### 多个参数

```cpp
// 打印个人信息
void introduce(std::string name, int age, std::string city) {
    std::cout << "我叫" << name
              << "，今年" << age << "岁"
              << "，来自" << city << std::endl;
}

int main() {
    introduce("小明", 20, "北京");   // 我叫小明，今年20岁，来自北京
    introduce("小红", 22, "上海");   // 我叫小红，今年22岁，来自上海
    return 0;
}
```

## 返回值——函数的"出品"

函数可以有返回值，也可以没有：

```cpp
// 有返回值的函数
double circleArea(double radius) {
    return 3.14159 * radius * radius;   // 返回圆的面积
}

// 没有返回值的函数（用 void 表示）
void printLine() {
    std::cout << "─────────────" << std::endl;
    // 没有 return 语句
}

int main() {
    double area = circleArea(5.0);   // 接收返回值
    std::cout << "面积: " << area << std::endl;
    printLine();                      // 不需要接收返回值
    return 0;
}
```

| 返回类型 | 含义 | 什么时候用 |
|---------|------|-----------|
| `int`、`double` 等 | 返回一个值 | 需要计算结果时 |
| `void` | 不返回任何东西 | 只需要执行操作时 |

## 声明 vs 定义

**声明**（`declaration`）是告诉编译器"有这个函数存在"；**定义**（`definition`）是写出函数的完整实现：

```cpp
// 声明（也叫"原型"）：只写签名，不写函数体
int add(int a, int b);

int main() {
    int result = add(3, 5);   // 编译器知道 add 存在，所以不报错
    return 0;
}

// 定义：完整的函数实现
int add(int a, int b) {
    return a + b;
}
```

> 💡 **比喻**：声明就像菜单上的菜名——告诉你"有这道菜"；定义就像后厨的菜谱——告诉你"怎么做这道菜"。

## 为什么函数如此重要？

### 1. 复用——写一次，用无数次

```cpp
// 不用函数：重复代码
std::cout << "张三的分数: " << 90 << std::endl;
std::cout << "李四的分数: " << 85 << std::endl;
std::cout << "王五的分数: " << 92 << std::endl;

// 用函数：简洁优雅
void printScore(std::string name, int score) {
    std::cout << name << "的分数: " << score << std::endl;
}
printScore("张三", 90);
printScore("李四", 85);
printScore("王五", 92);
```

### 2. 抽象——不需要知道细节

你用手机打电话时，不需要知道信号怎么传输——只要按号码就行。函数也一样，调用者不需要知道内部实现：

```cpp
// 调用者只需要知道：传入半径，得到面积
double area = circleArea(5.0);
// 不需要关心面积公式怎么算的
```

### 3. 组织——把大问题拆成小问题

```
做一顿饭
├── 煮饭()
├── 炒菜()
│   ├── 洗菜()
│   ├── 切菜()
│   └── 翻炒()
└── 煮汤()
```

每个小函数负责一件小事，组合起来完成大事。

## 函数调用的执行流程

```cpp
int main() {              // ① 程序从 main 开始
    int x = add(3, 5);    // ② 调用 add，跳到 add 函数
    printResult(x);       // ⑤ add 返回后继续，调用 printResult
    return 0;             // ⑦ printResult 返回后继续，程序结束
}

int add(int a, int b) {   // ③ 进入 add 函数
    return a + b;         // ④ 计算并返回 8
}

void printResult(int r) { // ⑥ 进入 printResult 函数
    std::cout << r << std::endl;
}
```

```
main() ──调用──→ add(3,5) ──返回8──→ main() ──调用──→ printResult(8) ──返回──→ main()
```

## 小结

| 概念 | 一句话理解 |
|------|-----------|
| 函数 | 程序中的"菜谱"，打包一组操作 |
| 参数 | 函数需要的"食材" |
| 返回值 | 函数的"出品" |
| 声明 | 告诉编译器"有这个函数" |
| 定义 | 写出函数的完整实现 |
| 复用 | 写一次，用无数次 |
| 抽象 | 用的人不需要知道怎么做 |
| 组织 | 大问题拆成小问题 |

记住：**函数是编程最重要的组织工具**——好的程序员不是写很多代码，而是写很多好的函数！
