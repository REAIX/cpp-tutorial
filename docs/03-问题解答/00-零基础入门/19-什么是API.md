# 什么是 API？
> 📖 相关章节：[编程入门](../../00-导学/00-编程入门.md)、[C语言概述](../../01-C语言/00-C语言概述.md)、[数据类型与变量](../../01-C语言/01-数据类型与变量.md)

## 用生活比喻理解 API

想象你去餐厅吃饭：

- **菜单**上列着所有菜品和价格
- 你**不需要**知道厨房怎么炒菜、食材从哪进货
- 你只需要**看菜单点菜**，服务员就会把菜端上来

**API**（`Application Programming Interface`，应用程序编程接口）就是程序世界的"菜单"——它告诉你**可以用什么功能**，但**不需要知道内部怎么实现**。

> 💡 **比喻**：API 就像**自动售货机的按钮面板**——你只需要知道按哪个按钮出什么饮料，不需要知道里面的机械结构怎么运作。

```
你（调用者）          API（接口）           内部实现
   │                    │                     │
   │  "我要一杯可乐"     │                     │
   │ ─────────────────→ │                     │
   │                    │  启动制冷、出货...    │
   │                    │ ──────────────────→ │
   │                    │                     │
   │    可乐出来了       │                     │
   │ ←───────────────── │                     │
```

## 为什么需要 API？

### 没有 API 的世界

```cpp
// 想在屏幕上显示文字，没有 API 的话：
// 1. 找到显卡驱动
// 2. 设置显示模式
// 3. 把文字转成像素点
// 4. 把像素点写入显存
// 5. 刷新屏幕
// ... 几百行代码才能显示一个字！
```

### 有 API 的世界

```cpp
#include <iostream>
std::cout << "Hello" << std::endl;  // 一行搞定！
// iostream 的 API 帮你处理了所有底层细节
```

API 的核心价值：**隐藏复杂性，提供简单接口**。

> 💡 **比喻**：API 就像**电源插座**——你只需要把插头插进去就能用电，不需要知道发电厂怎么发电、电线怎么铺设。

## API 作为"合同"

API 是调用者和实现者之间的**合同**（`contract`）：

| 合同条款 | 说明 |
|---------|------|
| 功能描述 | 这个 API 做什么 |
| 输入参数 | 需要提供什么 |
| 输出结果 | 会返回什么 |
| 约束条件 | 有什么限制 |
| 错误处理 | 出错了怎么办 |

```cpp
// C++ 标准库的 sqrt 函数就是一个 API
// 合同内容：
//   功能：计算平方根
//   输入：一个非负浮点数
//   输出：输入值的平方根
//   约束：输入不能为负数
//   错误：输入负数返回 NaN

double result = sqrt(25.0);  // result = 5.0
```

只要双方都遵守合同，调用者不需要关心内部实现，实现者可以自由修改内部代码——这就是**解耦**。

## 不同层次的 API

### 1. 标准库 API

C++ 标准库提供的接口，所有 C++ 程序都能用：

```cpp
#include <vector>
#include <algorithm>

std::vector<int> nums = {3, 1, 4, 1, 5};
std::sort(nums.begin(), nums.end());  // 标准库 API：排序
int count = nums.size();               // 标准库 API：获取大小
```

| API | 功能 |
|-----|------|
| `std::cout << x` | 输出数据 |
| `std::cin >> x` | 输入数据 |
| `std::sort()` | 排序 |
| `std::vector` | 动态数组 |
| `std::string` | 字符串操作 |

### 2. 操作系统 API（系统调用）

操作系统提供的接口，让程序能使用硬件和系统功能：

```cpp
// Windows API 示例
#include <windows.h>
MessageBox(NULL, "你好！", "提示", MB_OK);  // 弹出对话框

// POSIX API 示例（Linux/macOS）
#include <unistd.h>
getpid();   // 获取当前进程 ID
```

| 操作系统 | API 名称 | 用途 |
|---------|---------|------|
| Windows | Win32 API | 窗口、文件、进程等 |
| Linux | POSIX API | 系统调用接口 |
| macOS | Cocoa API | 图形界面和系统功能 |

### 3. 第三方 API

其他公司或组织提供的接口：

| API | 提供者 | 用途 |
|-----|--------|------|
| `OpenCV API` | 开源社区 | 图像处理 |
| `Qt API` | Qt 公司 | 图形界面开发 |
| `Boost API` | 开源社区 | 通用 C++ 工具 |
| `微信支付 API` | 腾讯 | 在线支付 |
| `百度地图 API` | 百度 | 地图服务 |

### API 层次图

```
┌────────────────────────────────┐
│        你的应用程序             │
├────────────────────────────────┤
│  第三方 API │  第三方 API       │  ← 第三方库接口
├─────────────┴──────────────────┤
│        标准库 API               │  ← C++ 标准库接口
├────────────────────────────────┤
│        操作系统 API             │  ← 系统调用接口
├────────────────────────────────┤
│           硬件                  │  ← 最底层
└────────────────────────────────┘
```

## 如何阅读 API 文档

API 文档是使用 API 的**说明书**，学会读文档是程序员的核心技能：

### 文档通常包含

```
函数名：std::sort
功能：对范围内的元素进行排序
头文件：<algorithm>
语法：
  void sort(Iterator first, Iterator last);
  void sort(Iterator first, Iterator last, Compare comp);
参数：
  first - 起始迭代器
  last  - 结束迭代器
  comp  - 比较函数（可选）
返回值：无
复杂度：O(N·log(N))
示例：...
```

### 阅读步骤

1. **看功能描述**——这个 API 做什么？
2. **看参数**——需要传什么？
3. **看返回值**——返回什么？
4. **看示例**——怎么用？
5. **看注意事项**——有什么坑？

> 💡 **比喻**：读 API 文档就像看电器说明书——先看"功能介绍"，再看"操作步骤"，最后看"注意事项"。

## API vs SDK vs 协议

这三个概念经常被混淆：

| 概念 | 全称 | 是什么 | 比喻 |
|------|------|--------|------|
| API | Application Programming Interface | 编程接口 | 餐厅菜单 |
| SDK | Software Development Kit | 开发工具包 | 厨房全套工具（含菜单、食材、厨具） |
| Protocol | Communication Protocol | 通信规则 | 点餐的规矩（先点菜后上菜） |

### 关系

```
SDK（开发工具包）
├── API（接口/菜单）
├── 文档（说明书）
├── 示例代码（菜谱）
├── 工具（开发辅助工具）
└── 库文件（实现代码）
```

**举例**：

- **微信支付 API**：定义了如何调用支付功能的接口
- **微信支付 SDK**：包含了 API、文档、示例代码、开发工具的完整包
- **HTTP 协议**：定义了客户端和服务器之间如何通信的规则

> 💡 **比喻**：API 是菜单，SDK 是整个厨房（含菜单、食材、厨具、说明书），协议是顾客和厨房之间的沟通规则。

## 实际使用 API 的例子

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>

int main() {
    std::vector<int> scores = {85, 92, 78, 90, 88};

    // 使用标准库 API
    std::sort(scores.begin(), scores.end());   // 排序 API
    int size = scores.size();                   // 获取大小 API
    double avg = 0;
    for (int s : scores) avg += s;
    avg = avg / size;
    double variance = avg * 0.1;               // 简化计算
    double sd = sqrt(variance);                 // 数学 API

    std::cout << "人数: " << size << std::endl;   // 输出 API
    std::cout << "标准差: " << sd << std::endl;

    return 0;
}
```

每一行都在调用某个 API——**编程就是组合各种 API 来完成任务**。

## 小结

| 概念 | 一句话理解 |
|------|-----------|
| API | 程序的"菜单"，告诉你能用什么功能 |
| API 是合同 | 调用者和实现者之间的约定 |
| 标准库 API | C++ 自带的接口 |
| 操作系统 API | 操作系统提供的接口 |
| 第三方 API | 外部库/服务提供的接口 |
| API 文档 | 使用 API 的说明书 |
| SDK | 包含 API + 工具 + 文档的完整包 |
| 协议 | 通信的规则 |

记住：**你不需要从零开始造一切**——API 就是别人给你准备好的工具，学会使用 API，你就拥有了无限可能！
