# 什么是声明和定义
> 📖 相关章节：[运算符与表达式](../../01-C语言/02-运算符与表达式.md)、[控制结构](../../01-C语言/03-控制结构.md)、[函数](../../01-C语言/04-函数.md)、[基础特性](../../02-CPP/01-基础特性.md)、[命名空间](../../02-CPP/02-命名空间与编码规范.md)

> **Declaration tells the compiler "something exists", definition tells it "what it is".** — 声明告诉编译器"它存在"，定义告诉它"它是什么"。

***

### 1. 核心要义

**声明**（Declaration）= 告诉编译器某个名字的存在及其类型，但不分配内存。**定义**（Definition）= 声明 + 分配内存/提供实现，是"真正创建"这个实体的地方。

***

### 2. 生活类比

把程序比作**学校管理**：

- **声明** → 在花名册上登记"有个叫张三的学生"（大家知道有这个人，但还没见到他）
- **定义** → 张三真正来学校报到、坐在教室里（这个人真实存在了）

一个学生可以登记在很多花名册上（多次声明），但只能坐在一个座位上（只能定义一次）。

### 3. 声明 vs 定义 对比

| 特性 | 声明（Declaration） | 定义（Definition） |
|------|:---:|:---:|
| 是否分配内存 | 否 | 是 |
| 是否提供实现 | 否 | 是 |
| 能否重复 | 可以 | 不可以（ODR规则） |
| 用途 | 让编译器知道名字和类型 | 真正创建实体 |

### 4. 变量的声明与定义

```cpp
extern int g_count;       // 声明：告诉编译器 g_count 存在，不分配内存
int g_count = 0;          // 定义：分配内存并初始化

int main() {
    extern int g_count;   // 声明：引用别处定义的变量
    int x = 10;           // 定义：同时是声明（局部变量）
}
```

**关键规则**：`extern` 关键字使变量成为"纯声明"（不分配内存）。没有 `extern` 的全局变量既是声明又是定义。

### 5. 函数的声明与定义

```cpp
// 声明（函数原型/前向声明）
int add(int a, int b);

// 定义（提供函数体）
int add(int a, int b) {
    return a + b;
}
```

函数声明通常放在头文件中，定义放在源文件中：

```cpp
// ===== math_utils.h（头文件：声明） =====
#pragma once
int add(int a, int b);
int multiply(int a, int b);

// ===== math_utils.cpp（源文件：定义） =====
#include "math_utils.h"
int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }
```

### 6. 类的声明与定义

```cpp
class Dog;  // 前向声明：告诉编译器 Dog 是一个类

class Cat {
    Dog* friend_;  // 指针：前向声明足够
    // Dog& ref_;  // 引用：需要完整定义
    // Dog pet_;   // 成员对象：需要完整定义（编译器需要知道大小）
};

// 类的定义
class Dog {
    std::string name_;
public:
    void bark();
};
```

| 使用方式 | 是否需要完整定义 |
|----------|:---:|
| 指针 `Dog*` | 不需要，前向声明即可 |
| 引用 `Dog&` | 不需要声明，但使用时需要定义 |
| 成员对象 `Dog` | 需要 |
| 调用成员函数 | 需要 |
| `sizeof(Dog)` | 需要 |

### 7. 前向声明的作用

前向声明（Forward Declaration）可以减少头文件包含，加快编译速度：

```cpp
// ===== engine.h =====
#pragma once
class Car;  // 前向声明，避免 #include "car.h"

class Engine {
    Car* car_;  // 只用指针，前向声明足够
public:
    void start();
};
```

**前向声明的局限**：

```cpp
class Foo;  // 前向声明

void func(Foo f);    // 合法：参数声明
void func(Foo* p);   // 合法：指针参数
Foo* create();       // 合法：返回指针

// Foo f;            // 错误：不知道大小，无法定义对象
// f.method();       // 错误：不知道有哪些成员
// sizeof(Foo);      // 错误：不完整类型
```

### 8. 单定义规则（ODR）

**One Definition Rule**：在整个程序中，每个实体只能被定义一次。

| 实体 | ODR要求 | 违反后果 |
|------|---------|----------|
| 全局变量 | 只能定义一次 | 链接错误（multiple definition） |
| 普通函数 | 只能定义一次 | 链接错误 |
| 内联函数 | 可以多次定义，但必须完全相同 | 未定义行为 |
| 类定义 | 每个翻译单元只能定义一次 | 编译错误 |
| 模板 | 可以多次实例化，但定义必须相同 | 未定义行为 |

```cpp
// ===== file1.cpp =====
int g_value = 42;  // 定义

// ===== file2.cpp =====
int g_value = 99;  // 错误！重复定义，链接时报 multiple definition
```

**正确做法**：

```cpp
// ===== header.h =====
#pragma once
extern int g_value;  // 声明

// ===== source.cpp =====
#include "header.h"
int g_value = 42;    // 唯一定义

// ===== other.cpp =====
#include "header.h"
// 可以使用 g_value，因为头文件中有声明
```

### 9. C 语言中的声明与定义

C 语言的规则与 C++ 基本相同，但有些细节差异：

```c
// C 中函数声明可以省略参数（不推荐）
void foo();      // C：接受任意参数；C++：不接受参数
void foo(void);  // C 和 C++：明确不接受参数

// C 中 tentative definition（暂定定义）
int g_val;       // C：暂定定义，如果没有其他定义则成为定义
                 // C++：这就是定义
```

### 10. 常见错误

```cpp
// 错误1：头文件中定义变量
// ===== bad.h =====
int g_count = 0;  // 每个包含此头文件的 .cpp 都会生成一个定义 → 链接错误

// 正确做法：
// ===== good.h =====
extern int g_count;  // 声明

// ===== good.cpp =====
int g_count = 0;     // 唯一定义

// 错误2：忘记定义
extern int g_data;   // 只有声明
int main() {
    return g_data;   // 链接错误：undefined reference
}

// 错误3：头文件中定义非内联函数
// ===== bad.h =====
void func() { /* ... */ }  // 多个翻译单元包含 → 重复定义
```

### 11. 极简总结

**声明 = 告诉编译器名字和类型（不分配内存）；定义 = 声明 + 分配内存/提供实现；extern 使变量成为纯声明；前向声明减少头文件依赖；ODR 规则要求每个实体只定义一次；头文件放声明，源文件放定义**
