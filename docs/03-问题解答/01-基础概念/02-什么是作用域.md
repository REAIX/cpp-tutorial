# 什么是作用域
> 📖 相关章节：[函数](../../01-C语言/04-函数.md)、[基础特性](../../02-CPP/01-基础特性.md)

> **Scope determines where a name is visible. Think of it as "who can see whom".** — 作用域决定名字在哪里可见，就像"谁能看到谁"。

***

### 1. 本质洞察

**作用域**（Scope）= 程序中某个名字（变量、函数、类型等）可以被访问的区域。出了作用域，名字就"不存在"了。

***

### 2. 生活类比

把作用域比作**公司组织架构**：

- **全局作用域** → 公司公告栏，所有人都能看到
- **命名空间作用域** → 部门公告，只有本部门的人能看到
- **局部作用域** → 你工位上的便签，只有你自己能看到
- **类作用域** → 团队共享文档，只有团队成员能访问

你在自己的工位上写了个便签"任务=写代码"，隔壁工位的同事看不到。但公司公告栏上的"放假通知"，所有人都能看到。如果同事也在自己工位上写了个"任务=测试"，两个"任务"互不冲突——这就是**作用域隔离**。

### 3. C/C++ 中的作用域分类

| 作用域类型 | 关键字/语法 | 可见范围 |
|-----------|-----------|---------|
| 全局作用域 | 无（最外层） | 整个翻译单元 |
| 命名空间作用域 | `namespace` | 命名空间内 |
| 类作用域 | `class/struct` | 类内部 |
| 局部作用域 | `{}` 块 | 当前块及内层块 |
| 枚举作用域 | `enum class` | 枚举内部（C++11） |

### 4. 块作用域（局部作用域）

```cpp
#include <iostream>

void example() {
    int x = 10;          // x 的作用域开始
    {
        int y = 20;      // y 的作用域开始
        std::cout << x << " " << y << std::endl;  // 可以访问 x 和 y
    }                    // y 的作用域结束
    // std::cout << y;   // 错误！y 已经不可见
    std::cout << x;      // x 仍然可见
}                        // x 的作用域结束
```

**for 循环中的块作用域**：

```cpp
for (int i = 0; i < 10; ++i) {
    // i 只在 for 循环内可见
}
// std::cout << i;  // 错误！i 已不可见

// C++17: if/switch 的初始化语句
if (int* p = get_ptr(); p != nullptr) {
    // p 只在 if 块内可见
}
// p 不可见
```

### 5. 全局作用域

```cpp
#include <iostream>

int g_count = 0;  // 全局作用域：整个文件可见

void increment() {
    ++g_count;    // 函数内可以访问全局变量
}

int main() {
    increment();
    std::cout << g_count << std::endl;  // 1
}
```

**全局变量的风险**：任何函数都能修改它，难以追踪谁改了它。应尽量减少全局变量的使用。

### 6. 命名空间作用域

```cpp
#include <iostream>
#include <vector>

namespace Physics {
    double gravity = 9.8;  // Physics 命名空间作用域
    double calculate() { return gravity * 2.0; }
}

namespace Graphics {
    double gravity = 0.0;  // 不同命名空间，同名不冲突
    void render() { /* ... */ }
}

int main() {
    std::cout << Physics::gravity << std::endl;   // 9.8
    std::cout << Graphics::gravity << std::endl;  // 0.0
}
```

### 7. 类作用域

```cpp
class Player {
    int health_;          // 类作用域：成员变量
    static int count_;    // 类作用域：静态成员

public:
    int get_health() const { return health_; }  // 可以访问类成员
};

int Player::count_ = 0;  // 静态成员需要在类外定义

void func() {
    // health_ 不可见，需要通过对象访问
    Player p;
    // p.health_;  // 错误：private 成员
}
```

### 8. 作用域与名字隐藏（Shadowing）

当内层作用域定义了与外层同名的变量时，内层变量会**隐藏**外层变量：

```cpp
#include <iostream>

int x = 100;  // 全局 x

void shadow_example() {
    int x = 10;       // 局部 x 隐藏了全局 x
    std::cout << x << std::endl;  // 输出 10

    {
        int x = 5;    // 内层 x 隐藏了外层 x
        std::cout << x << std::endl;  // 输出 5
    }

    std::cout << x << std::endl;  // 输出 10（内层 x 已销毁）
}
```

**如何访问被隐藏的全局变量**：

```cpp
int value = 42;

void func() {
    int value = 0;
    std::cout << value << std::endl;     // 0（局部）
    std::cout << ::value << std::endl;   // 42（全局，使用作用域解析运算符）
}
```

**Shadowing 的风险**：

| 情况 | 风险 | 建议 |
|------|------|------|
| 局部变量隐藏全局变量 | 容易误用 | 编译器加警告 `-Wshadow` |
| 内层块隐藏外层变量 | 逻辑混乱 | 避免同名 |
| 函数参数隐藏成员变量 | 可能写错 | 成员变量用 `this->` 或加后缀 `_` |

```cpp
class Bad {
    int size;
public:
    void resize(int size) {  // 参数隐藏了成员变量
        size = size;         // 赋值给自己！成员变量没变
    }
};

class Good {
    int size_;
public:
    void resize(int size) {
        size_ = size;  // 清晰：成员 = 参数
    }
};
```

### 9. 枚举作用域

```cpp
// C 风格枚举：污染外层作用域
enum Color { RED, GREEN, BLUE };
int RED = 1;  // 错误！与枚举值 RED 冲突

// C++11 限定作用域枚举：不会污染
enum class Direction { UP, DOWN, LEFT, RIGHT };
int UP = 1;  // 合法，不冲突

Direction d = Direction::UP;  // 必须加枚举名前缀
// Direction d = UP;          // 错误！
```

### 10. 作用域与生命周期的关系

作用域决定**可见性**（编译期概念），生命周期决定**存在性**（运行期概念），两者不同：

```cpp
#include <iostream>

int* dangling() {
    int local = 42;   // 作用域：函数内；生命周期：函数执行期间
    return &local;    // 函数结束，local 被销毁，返回悬空指针
}

void static_example() {
    static int count = 0;  // 作用域：函数内；生命周期：整个程序
    ++count;
    std::cout << count << std::endl;
}
```

| 变量类型 | 作用域 | 生命周期 |
|---------|--------|---------|
| 普通局部变量 | 块作用域 | 块执行期间 |
| static 局部变量 | 块作用域 | 整个程序运行期间 |
| 全局变量 | 全局作用域 | 整个程序运行期间 |
| 类成员变量 | 类作用域 | 对象存活期间 |
| 堆上变量（new） | 指针的作用域 | delete 之前 |

### 11. 极简总结

**作用域 = 名字的可见范围 → 块/全局/命名空间/类/枚举 → 内层同名变量隐藏外层 → 用 `::` 访问被隐藏的全局名 → 作用域≠生命周期 → 避免不必要的 shadowing**
