# 函数指针类型别名简化写法
> 📖 相关章节：[运算符与表达式](../../01-C语言/02-运算符与表达式.md)、[控制结构](../../01-C语言/03-控制结构.md)、[函数](../../01-C语言/04-函数.md)、[基础特性](../../02-CPP/01-基础特性.md)、[命名空间](../../02-CPP/02-命名空间与编码规范.md)

### 1. 核心要义

函数指针的原始声明极其复杂（如 `void (*signal(int, void(*)(int)))(int)`），用 `typedef` 或 `using` 定义类型别名后可以大幅简化。C++11 的 `using` 比 `typedef` 更清晰，C++11 的 `std::function` 是现代替代方案。

***

### 2. 函数指针的复杂声明

函数指针是 C/C++ 中最令人困惑的语法之一：

```c
// 基本函数指针
void (*fp)(int);              // 指向 void(int) 函数的指针

// 函数指针数组
void (*fps[10])(int);         // 10个函数指针的数组

// 返回函数指针的函数
void (*signal(int, void(*)(int)))(int);  // signal 函数，返回函数指针

// 指向返回函数指针的函数的指针
void (*(*fp2)(int, void(*)(int)))(int);  // 指向 signal 的函数指针
```

**阅读技巧**：从标识符开始，先向右读，再向左读，遇到括号转向。

```
void (*signal(int, void(*)(int)))(int)
         ↑↑↑↑↑↑
         signal 是一个函数
                ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑
                参数：int 和 void(*)(int)
     ↑↑
     返回值是指针
                            ↑↑↑↑
                            指向 void(int) 函数

→ signal 是一个函数，接受 (int, void(*)(int))，返回 void(*)(int)
```

### 3. 三种等价写法

假设已定义：

```c
typedef void (*handler_t)(int);
```

| 版本 | 写法 | 特点 |
|------|------|------|
| 版本1 | `void (*signal(int, void(*)(int)))(int);` | 最原始，完整展开 |
| 版本2 | `void (*signal(int, handler_t))(int);` | 半简化，参数用别名 |
| 版本3 | `handler_t signal(int, handler_t);` | 最简洁，标准写法 |

**三者完全等价！**

### 4. 替换过程

版本1：

```c
void (*signal(int, void(*)(int)))(int);
//                 ↑↑↑↑↑↑↑↑↑↑↑
//                 这部分就是 handler_t
```

将 `void(*)(int)` 替换为 `handler_t` → 版本2：

```c
void (*signal(int, handler_t))(int);
```

版本2的返回类型部分：

```c
void (*signal(...))(int);
```

这个返回类型就是 `void (*)(int)`，而 `handler_t` 恰好定义为这个类型。

因此可以直接用 `handler_t` 替换整个返回类型 → 版本3：

```c
handler_t signal(int, handler_t);
```

### 5. typedef 简化

```c
// 基本函数指针类型
typedef void (*handler_t)(int);
handler_t fp = some_function;  // 简洁

// 函数指针数组
typedef void (*func_t)(int);
func_t handlers[10];  // 10个函数指针

// 返回函数指针的函数
typedef int (*operation_t)(int, int);
operation_t get_op(char c);  // 返回函数指针的函数

// 完整示例
#include <stdio.h>

typedef void (*handler_t)(int);

void default_handler(int sig) {
    printf("Signal %d received\n", sig);
}

handler_t signal_install(int sig, handler_t new_handler) {
    // 安装信号处理器，返回旧的处理器
    handler_t old = default_handler;
    // ... 安装逻辑 ...
    return old;
}

int main() {
    handler_t old = signal_install(2, default_handler);
    old(2);  // 调用旧处理器
}
```

### 6. using 简化（C++11 推荐）

`using` 是 `typedef` 的现代替代，语法更直观：

```cpp
// typedef 写法（从右向左读）
typedef void (*handler_t)(int);         // handler_t 是 void(*)(int)
typedef int (*op_t)(int, int);          // op_t 是 int(*)(int,int)
typedef void (*callback_t)(const char*);// callback_t 是 void(*)(const char*)

// using 写法（从左向右读，更直观）
using handler_t = void (*)(int);        // handler_t = void(*)(int)
using op_t = int (*)(int, int);         // op_t = int(*)(int,int)
using callback_t = void (*)(const char*); // callback_t = void(*)(const char*)

// using 的优势：可以用于模板别名
template <typename T>
using comparator_t = bool (*)(const T&, const T&);  // OK

// typedef 无法直接做模板别名
// template <typename T>
// typedef bool (*comparator_t)(const T&, const T&);  // 编译错误！
```

#### 1. typedef vs using 对比

| 对比项 | typedef | using |
|--------|---------|-------|
| 语法 | `typedef int (*FP)(int);` | `using FP = int (*)(int);` |
| 可读性 | 差（从右向左） | 好（从左向右） |
| 模板别名 | 不支持 | 支持 |
| C 兼容 | 是 | 否（C++11） |
| 推荐度 | 旧代码 | 新代码 |

### 7. 函数指针数组

```cpp
#include <iostream>
#include <string>

// 定义函数指针类型
using menu_handler = void (*)();

// 菜单项
void new_file()  { std::cout << "New File" << std::endl; }
void open_file() { std::cout << "Open File" << std::endl; }
void save_file() { std::cout << "Save File" << std::endl; }
void quit()      { std::cout << "Quit" << std::endl; }

// 函数指针数组
int main() {
    // 方式1：直接声明
    void (*menu1[])(void) = {new_file, open_file, save_file, quit};

    // 方式2：用类型别名（推荐）
    menu_handler menu2[] = {new_file, open_file, save_file, quit};

    std::string names[] = {"New", "Open", "Save", "Quit"};

    for (int i = 0; i < 4; ++i) {
        std::cout << i << ": " << names[i] << std::endl;
    }

    int choice;
    std::cin >> choice;
    if (choice >= 0 && choice < 4) {
        menu2[choice]();  // 通过函数指针调用
    }
}
```

### 8. 函数指针作为参数

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 回调函数类型
using compare_func = bool (*)(int, int);
using callback = void (*)(int);

// 函数指针作为参数
void sort_with_comparator(std::vector<int>& v, compare_func cmp) {
    std::sort(v.begin(), v.end(), cmp);
}

// 使用
bool ascending(int a, int b) { return a < b; }
bool descending(int a, int b) { return a > b; }

void print(const std::vector<int>& v) {
    for (int x : v) std::cout << x << " ";
    std::cout << std::endl;
}

int main() {
    std::vector<int> data = {5, 2, 8, 1, 9};

    sort_with_comparator(data, ascending);
    print(data);  // 1 2 5 8 9

    sort_with_comparator(data, descending);
    print(data);  // 9 8 5 2 1
}
```

### 9. 函数指针作为返回值

```cpp
#include <iostream>
#include <string>

// 定义函数指针类型
using math_op = int (*)(int, int);

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

// 返回函数指针的函数
math_op get_operation(const std::string& name) {
    if (name == "add") return add;
    if (name == "sub") return sub;
    if (name == "mul") return mul;
    return nullptr;
}

// 不用类型别名的写法（对比）
int (*get_op_raw(const std::string& name))(int, int) {
    if (name == "add") return add;
    if (name == "sub") return sub;
    return nullptr;
}

int main() {
    math_op op = get_operation("add");
    if (op) {
        std::cout << op(3, 4) << std::endl;  // 7
    }

    op = get_operation("mul");
    if (op) {
        std::cout << op(3, 4) << std::endl;  // 12
    }
}
```

### 10. std::function 替代（C++11 推荐）

`std::function` 是函数指针的现代替代，更灵活、更安全：

```cpp
#include <iostream>
#include <functional>
#include <string>
#include <map>

// std::function 可以包装：
// 1. 普通函数
// 2. Lambda
// 3. 函数对象（仿函数）
// 4. 成员函数（配合 std::bind）
// 5. 函数指针

// 对比函数指针
using fp_type = int (*)(int, int);          // 只能包装普通函数
using func_type = std::function<int(int, int)>;  // 可以包装任何可调用对象

int add(int a, int b) { return a + b; }

int main() {
    // 都能包装普通函数
    fp_type fp = add;
    func_type fn = add;

    // std::function 还能包装 Lambda
    func_type fn2 = [](int a, int b) { return a * b; };
    // fp_type fp2 = [](int a, int b) { return a * b; };  // 编译错误！

    // std::function 还能包装捕获变量的 Lambda
    int factor = 10;
    func_type fn3 = [factor](int a, int b) { return (a + b) * factor; };
    // fp_type 无法包装有捕获的 Lambda

    // std::function 作为容器元素
    std::map<std::string, func_type> ops;
    ops["+"] = add;
    ops["-"] = [](int a, int b) { return a - b; };
    ops["*"] = [](int a, int b) { return a * b; };

    std::cout << ops["+"](3, 4) << std::endl;  // 7
    std::cout << ops["*"](3, 4) << std::endl;  // 12
}
```

#### 1. 函数指针 vs std::function 对比

| 对比项 | 函数指针 | std::function |
|--------|----------|---------------|
| 普通函数 | 支持 | 支持 |
| Lambda（无捕获） | 支持 | 支持 |
| Lambda（有捕获） | 不支持 | 支持 |
| 函数对象 | 不支持 | 支持 |
| 成员函数 | 需要特殊处理 | 配合 bind/membr_fn |
| 空状态 | nullptr | 可检查（operator bool） |
| 性能 | 零开销 | 有小开销（可能堆分配） |
| 类型安全 | 弱 | 强 |
| 推荐度 | C/性能关键 | C++11+ |

### 11. 成员函数指针

成员函数指针与普通函数指针完全不同，语法更复杂：

```cpp
#include <iostream>
#include <functional>

class Widget {
public:
    void on_click() { std::cout << "Widget clicked" << std::endl; }
    void on_hover() { std::cout << "Widget hovered" << std::endl; }
    int get_value() const { return 42; }
};

int main() {
    // 成员函数指针声明
    void (Widget::*action)() = &Widget::on_click;  // 必须加 &

    Widget w;
    (w.*action)();  // 调用：对象.*成员函数指针
    // 输出: Widget clicked

    action = &Widget::on_hover;
    (w.*action)();  // 输出: Widget hovered

    // const 成员函数指针
    int (Widget::*getter)() const = &Widget::get_value;
    std::cout << (w.*getter)() << std::endl;  // 42

    // 用 using 简化
    using widget_action = void (Widget::*)();
    widget_action act = &Widget::on_click;
    (w.*act)();

    // 用 std::function + std::bind 绑定成员函数
    auto fn = std::bind(&Widget::on_click, &w);
    fn();  // 输出: Widget clicked

    // 用 Lambda 更简洁（推荐）
    auto fn2 = [&w]() { w.on_click(); };
    fn2();  // 输出: Widget clicked
}
```

#### 1. 成员函数指针 vs 普通函数指针

| 对比项 | 普通函数指针 | 成员函数指针 |
|--------|-------------|-------------|
| 声明 | `void (*fp)(int)` | `void (Cls::*fp)(int)` |
| 赋值 | `fp = func;` | `fp = &Cls::func;`（必须加 &） |
| 调用 | `fp(42);` | `(obj.*fp)(42);` 或 `(ptr->*fp)(42);` |
| 大小 | 通常8字节 | 可能更大（虚函数相关） |
| 转换 | 不可互转 | 不可互转 |

### 12. 完整示例：事件系统

```cpp
#include <iostream>
#include <string>
#include <map>
#include <functional>
#include <vector>

// ===== C 风格：函数指针实现 =====

typedef void (*event_handler_t)(const char* event, int data);

void on_click(const char* event, int data) {
    std::cout << "Click at position " << data << std::endl;
}

void on_keypress(const char* event, int data) {
    std::cout << "Key code: " << data << std::endl;
}

class CEventSystem {
    std::map<std::string, event_handler_t> handlers_;
public:
    void register_handler(const std::string& event, event_handler_t handler) {
        handlers_[event] = handler;
    }
    void emit(const std::string& event, int data) {
        auto it = handlers_.find(event);
        if (it != handlers_.end()) {
            it->second(event.c_str(), data);
        }
    }
};

// ===== C++ 风格：std::function 实现 =====

class EventSystem {
    std::map<std::string, std::vector<std::function<void(int)>>> handlers_;
public:
    // 注册事件处理器（支持 Lambda、函数指针、函数对象）
    void on(const std::string& event, std::function<void(int)> handler) {
        handlers_[event].push_back(std::move(handler));
    }

    // 触发事件
    void emit(const std::string& event, int data) {
        auto it = handlers_.find(event);
        if (it != handlers_.end()) {
            for (auto& handler : it->second) {
                handler(data);
            }
        }
    }
};

int main() {
    // C 风格
    CEventSystem csys;
    csys.register_handler("click", on_click);
    csys.register_handler("keypress", on_keypress);
    csys.emit("click", 100);
    csys.emit("keypress", 65);

    std::cout << "---" << std::endl;

    // C++ 风格（更灵活）
    EventSystem sys;
    std::string user = "Alice";

    // Lambda（有捕获）
    sys.on("click", [&user](int pos) {
        std::cout << user << " clicked at " << pos << std::endl;
    });

    // Lambda（无捕获，等价于函数指针）
    sys.on("keypress", [](int key) {
        std::cout << "Key: " << key << std::endl;
    });

    // 函数对象
    struct Logger {
        void operator()(int val) {
            std::cout << "[LOG] value=" << val << std::endl;
        }
    };
    sys.on("update", Logger());

    sys.emit("click", 200);
    sys.emit("keypress", 88);
    sys.emit("update", 42);
}
```

### 13. 极简总结

**函数指针声明复杂 → typedef/using 简化 → C++11 用 using（推荐）→ C++11 用 std::function（更灵活）**

| 方案 | 语法 | 适用场景 |
|------|------|----------|
| 原始声明 | `void (*fp)(int)` | 不推荐 |
| typedef | `typedef void (*fp_t)(int);` | C 语言 |
| using | `using fp_t = void (*)(int);` | C++11（推荐） |
| std::function | `std::function<void(int)>` | C++11（最灵活） |

| 你的需求 | 推荐方案 |
|----------|----------|
| C 语言项目 | typedef + 函数指针 |
| C++11+ 简单回调 | using + 函数指针 |
| C++11+ 需要捕获状态 | std::function + Lambda |
| 成员函数回调 | Lambda 捕获 this |
| 性能关键路径 | 函数指针（零开销） |
