## 1. C语言标准演进时间线

```
C89 → C99 → C11 → C18 → C23
 │      │      │      │      │
 │      │      │      │      └─ 2023：bool/nullptr/constexpr/typeof/BitInt/#embed
 │      │      │      └──────── 2018：C11小修版，无新特性
 │      │      └───────────────── 2011：_Generic/_Atomic/_Thread_local/threads.h
 │      └──────────────────────── 1999：变长数组/ designated initializer/inline/bool
 └─────────────────────────────── 1989：第一个C语言国际标准（ANSI C）
```

| 标准 | 年份 | 正式名称 | 重要性 | 核心变化 |
|------|------|----------|--------|----------|
| C89 | 1989 | ISO/IEC 9899:1990 | ★★★★★ | 第一个国际标准，奠定C语言基础 |
| C99 | 1999 | ISO/IEC 9899:1999 | ★★★★☆ | 变长数组、`//`注释、`inline`、`_Bool`、`snprintf` |
| C11 | 2011 | ISO/IEC 9899:2011 | ★★★★☆ | 多线程、原子操作、泛型选择、对齐支持 |
| C18 | 2018 | ISO/IEC 9899:2018 | ★★☆☆☆ | C11缺陷修复，无新语言特性 |
| C23 | 2023 | ISO/IEC 9899:2024 | ★★★★★ | bool/nullptr/constexpr/typeof/BitInt/#embed/属性 |

## 2. C11核心新特性

### 1. _Generic 泛型选择

`_Generic`让C语言实现类似C++函数重载的效果，根据类型选择不同表达式。

```c
#include <stdio.h>

#define type_name(x) _Generic((x), \
    char: "char",                   \
    int: "int",                     \
    float: "float",                 \
    double: "double",               \
    default: "unknown"              \
)

#define print_value(x) _Generic((x), \
    int:   print_int,                \
    float: print_float,              \
    double: print_double,            \
    default: print_unknown           \
)(x)

void print_int(int v)    { printf("int: %d\n", v); }
void print_float(float v) { printf("float: %f\n", v); }
void print_double(double v) { printf("double: %lf\n", v); }
void print_unknown()     { printf("unknown type\n"); }

int main(void) {
    printf("%s\n", type_name(42));       /* int */
    printf("%s\n", type_name(3.14));     /* double */
    printf("%s\n", type_name('a'));      /* char */

    print_value(42);
    print_value(3.14f);
    return 0;
}
```

### 2. _Atomic 原子操作

```c
#include <stdio.h>
#include <stdatomic.h>
#include <threads.h>

atomic_int counter = 0;

int increment(void *arg) {
    for (int i = 0; i < 100000; i++) {
        atomic_fetch_add(&counter, 1);
    }
    return 0;
}

int main(void) {
    thrd_t t1, t2;
    thrd_create(&t1, increment, NULL);
    thrd_create(&t2, increment, NULL);
    thrd_join(t1, NULL);
    thrd_join(t2, NULL);
    printf("counter = %d\n", atomic_load(&counter)); /* 200000 */
    return 0;
}
```

### 3. _Thread_local 线程局部存储

```c
#include <stdio.h>
#include <threads.h>

_Thread_local int tls_var = 0;

int thread_func(void *arg) {
    int id = *(int *)arg;
    tls_var = id * 100;
    printf("线程%d: tls_var = %d\n", id, tls_var);
    return 0;
}

int main(void) {
    thrd_t t1, t2;
    int id1 = 1, id2 = 2;
    thrd_create(&t1, thread_func, &id1);
    thrd_create(&t2, thread_func, &id2);
    thrd_join(t1, NULL);
    thrd_join(t2, NULL);
    printf("主线程: tls_var = %d\n", tls_var); /* 0，每个线程独立 */
    return 0;
}
```

### 4. aligned_alloc 对齐分配

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    /* 分配256字节对齐的1024字节内存 */
    void *ptr = aligned_alloc(256, 1024);
    if (ptr == NULL) {
        perror("aligned_alloc失败");
        return 1;
    }
    printf("分配地址: %p\n", ptr);
    printf("是否256对齐: %s\n",
           ((size_t)ptr % 256 == 0) ? "是" : "否");
    free(ptr);
    return 0;
}
```

### 7. 边界检查函数（Annex K）

```c
#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
#include <string.h>

int main(void) {
    char dest[10];
    char src[] = "hello";

    /* 安全版本：指定目标缓冲区大小 */
    errno_t err = strcpy_s(dest, sizeof(dest), src);
    if (err != 0) {
        printf("拷贝失败，错误码: %d\n", err);
        return 1;
    }
    printf("结果: %s\n", dest);

```

### 8. 多线程支持（threads.h）

```c
#include <stdio.h>
#include <threads.h>
#include <stdatomic.h>

#define THREAD_COUNT 4
#define INCREMENT 100000

atomic_int shared_counter = 0;
mtx_t print_mutex;

int worker(void *arg) {
    int id = *(int *)arg;
    for (int i = 0; i < INCREMENT; i++) {
        atomic_fetch_add(&shared_counter, 1);
    }
    mtx_lock(&print_mutex);
    printf("线程%d完成\n", id);
    mtx_unlock(&print_mutex);
    return 0;
}

int main(void) {
    thrd_t threads[THREAD_COUNT];
    int ids[THREAD_COUNT];

    mtx_init(&print_mutex, mtx_plain);

    for (int i = 0; i < THREAD_COUNT; i++) {
        ids[i] = i + 1;
        thrd_create(&threads[i], worker, &ids[i]);
    }

    for (int i = 0; i < THREAD_COUNT; i++) {
        thrd_join(threads[i], NULL);
    }

    mtx_destroy(&print_mutex);
    printf("最终结果: %d (期望: %d)\n",
           atomic_load(&shared_counter),
           THREAD_COUNT * INCREMENT);
    return 0;
}
```

**threads.h核心API一览**：

| 类别 | 函数/类型 | 说明 |
|------|-----------|------|
| 线程 | `thrd_create` / `thrd_join` / `thrd_detach` | 创建/等待/分离线程 |
| 互斥 | `mtx_init` / `mtx_lock` / `mtx_unlock` / `mtx_destroy` | 互斥锁操作 |
| 条件变量 | `cnd_init` / `cnd_wait` / `cnd_signal` / `cnd_broadcast` | 条件变量操作 |
| 一次性 | `call_once` | 只执行一次的初始化 |
| 线程局部 | `tss_create` / `tss_set` / `tss_get` | 线程特定存储 |

## 3. C18修正

C18（ISO/IEC 9899:2018）是C11的技术勘误版，**没有引入任何新语言特性**。

| 项目 | 说明 |
|------|------|
| 正式名称 | ISO/IEC 9899:2018 |
| 别名 | C17（标准在2017年定稿，2018年发布） |
| 性质 | C11的小修版（Technical Corrigendum） |
| 新增特性 | **无** |
| 修复内容 | 缺陷报告（DR）修复、措辞澄清、示例修正 |
| 编译选项 | `-std=c17` 或 `-std=c18`（等价于 `-std=c11` 加上缺陷修复） |

**典型修复示例**：

```c
/* C11中的一个歧义：结构体赋值时是否支持临时生存期 */
/* C18澄清：复合字面量在函数调用中有明确的生存期 */

struct point { int x; int y; };

void take_point(struct point p);

int main(void) {
    /* C18明确了这种用法：复合字面量的生存期到包含它的块结束 */
    take_point((struct point){1, 2});
    return 0;
}
```

> **总结**：如果你的编译器支持C18，就用C18而不是C11——同样的功能，更少的bug。

## 4. C23核心新特性

### 1. bool/true/false 成为关键字

```c
#include <stdio.h>

/* C23之前：需要包含 <stdbool.h> */
/* C23：bool/true/false 直接可用，无需头文件 */

int main(void) {
    bool flag = true;
    if (flag) {
        printf("flag为真\n");
    }
    flag = false;
    printf("sizeof(bool) = %zu\n", sizeof(bool)); /* 1 */
    return 0;
}
```

| 版本 | 使用方式 | 说明 |
|------|----------|------|
| C99/C11 | `#include <stdbool.h>` → `bool`/`true`/`false` | 宏定义 |
| C23 | 直接使用 `bool`/`true`/`false` | 真正的关键字 |

### 2. nullptr 空指针常量

```c
#include <stdio.h>

void func_int(int *p)  { printf("int指针: %p\n", (void *)p); }
void func_long(long n) { printf("long值: %ld\n", n); }

int main(void) {
    int *p = nullptr;  /* C23：类型安全的空指针 */

    /* NULL的问题：在C中NULL可能定义为0，导致歧义 */
    func_int(NULL);    /* 可能匹配 func_long，取决于实现 */
    func_int(nullptr); /* C23：明确是空指针，不会误匹配 */

    if (p == nullptr) {
        printf("p是空指针\n");
    }
    return 0;
}
```

| 空指针表示 | 类型 | 问题 |
|------------|------|------|
| `0` | int | 整数和指针歧义 |
| `NULL` | 实现定义 | 可能是 `0` 或 `((void*)0)`，重载时歧义 |
| `nullptr` | nullptr_t | C23新增，类型安全，无歧义 |

### 3. typeof 类型推导

```c
#include <stdio.h>

#define SWAP(a, b) do {    \
    typeof(a) _tmp = (a);  \
    (a) = (b);             \
    (b) = _tmp;            \
} while (0)

int main(void) {
    int x = 10, y = 20;
    double d1 = 1.5, d2 = 2.5;

    SWAP(x, y);
    printf("x=%d, y=%d\n", x, y);       /* x=20, y=10 */

    SWAP(d1, d2);
    printf("d1=%.1f, d2=%.1f\n", d1, d2); /* d1=2.5, d2=1.5 */

    /* typeof声明同类型变量 */
    typeof(x) z = 42;
    printf("z=%d\n", z);                /* z=42 */

    /* typeof与const组合 */
    const typeof(x) cx = 100;
    printf("cx=%d\n", cx);
    return 0;
}
```

### 4. constexpr 常量表达式

```c
#include <stdio.h>

constexpr int MAX_SIZE = 1024;
constexpr double PI = 3.14159265358979;
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

int main(void) {
    int arr[MAX_SIZE];           /* constexpr可用于数组大小 */
    printf("PI = %.14f\n", PI);
    printf("5! = %d\n", factorial(5));

    /* constexpr变量是真正的编译期常量 */
    /* const变量不一定能用于数组大小，constexpr可以 */
    constexpr int size = 10;
    int buffer[size];
    return 0;
}
```

| 修饰符 | 编译期求值 | 可用于数组大小 | 可取地址 |
|--------|-----------|---------------|---------|
| `const` | 不保证 | 不一定（VLA除外） | 是 |
| `constexpr` | 保证 | 是 | 否（类似字面量） |

### 5. 改进的枚举

```c
#include <stdio.h>

/* C23：指定枚举底层类型 */
enum color : unsigned char {
    RED = 0,
    GREEN = 1,
    BLUE = 2
};

/* C23：枚举前向声明 */
enum status : int;

enum status : int {
    STATUS_OK = 0,
    STATUS_ERROR = 1,
    STATUS_PENDING = 2
};

int main(void) {
    enum color c = GREEN;
    printf("sizeof(enum color) = %zu\n", sizeof(c)); /* 1，unsigned char */

    /* C23：枚举值可以用枚举类型而不是int */
    enum status s = STATUS_OK;
    printf("status = %d\n", s);
    return 0;
}
```

### 6. 位精确类型（BitInt）

```c
#include <stdio.h>

/* 精确指定位宽的整数类型 */
_BitInt(7)  small_val = 50;    /* 恰好7位，范围 -64~63 */
_BitInt(24) medium_val = 1000; /* 恰好24位 */
unsigned _BitInt(8) byte_val = 200; /* 无符号8位 */

int main(void) {
    printf("7位整数: %d\n", (int)small_val);
    printf("24位整数: %d\n", (int)medium_val);
    printf("8位无符号: %u\n", (unsigned)byte_val);

    printf("sizeof(_BitInt(7)) = %zu\n", sizeof(_BitInt(7)));
    printf("sizeof(_BitInt(24)) = %zu\n", sizeof(_BitInt(24)));
    return 0;
}
```

| 类型 | 位宽 | 范围 |
|------|------|------|
| `_BitInt(7)` | 7 | -64 ~ 63 |
| `_BitInt(8)` | 8 | -128 ~ 127 |
| `unsigned _BitInt(8)` | 8 | 0 ~ 255 |
| `_BitInt(128)` | 128 | 超大整数（需编译器支持） |

### 7. #embed 预处理指令

```c
#include <stdio.h>

/* C23之前：嵌入文件需要工具转换或运行时读取 */
/* C23：#embed直接在编译期嵌入二进制文件 */

/* 嵌入一个文件的全部内容 */
const unsigned char icon[] = {
#embed "icon.png"
};

/* 限制嵌入大小 */
const unsigned char header[] = {
#embed "data.bin" limit(64)
};

/* 带后缀（文件为空时使用默认值） */
const unsigned char data[] = {
#embed "optional.bin" suffix(, 0xFF)
};

int main(void) {
    printf("图标大小: %zu字节\n", sizeof(icon));
    printf("前4字节: %02x %02x %02x %02x\n",
           icon[0], icon[1], icon[2], icon[3]);
    return 0;
}
```

### 8. 改进的可变参数

```c
#include <stdio.h>

/* C23：可变参数不再需要至少一个命名参数 */
/* C23之前：void func(int last, ...) —— 必须有至少一个命名参数 */
/* C23：void func(...) —— 可以没有命名参数 */

/* C23新增 va_copy 更明确的语义 */

#include <stdarg.h>

int sum(int count, ...) {
    va_list ap;
    va_start(ap, count);
    int total = 0;
    for (int i = 0; i < count; i++) {
        total += va_arg(ap, int);
    }
    va_end(ap);
    return total;
}

int main(void) {
    printf("1+2+3 = %d\n", sum(3, 1, 2, 3));
    return 0;
}
```

### 9. 属性语法 [[...]]

```c
#include <stdio.h>

/* C23：标准化的属性语法，类似C++11的[[...]] */

/* 标记函数已废弃 */
[[deprecated("请使用new_func代替")]]
void old_func(void) {
    printf("旧函数\n");
}

/* 标记函数可能未使用返回值 */
[[nodiscard]]
int important_value(void) {
    return 42;
}

/* 标记函数不返回 */
[[noreturn]]
void fatal_error(const char *msg) {
    fprintf(stderr, "致命错误: %s\n", msg);
    exit(1);
}

/* 标记参数未使用 */
void callback([[maybe_unused]] int signal) {
    /* 不处理该信号 */
}

int main(void) {
    old_func();           /* 编译器可能发出废弃警告 */
    important_value();    /* 编译器警告：忽略nodiscard返回值 */
    return 0;
}
```

| 属性 | 作用 | C++等价 |
|------|------|---------|
| `[[deprecated]]` | 标记已废弃 | C++14 `[[deprecated]]` |
| `[[nodiscard]]` | 不应忽略返回值 | C++17 `[[nodiscard]]` |
| `[[maybe_unused]]` | 抑制未使用警告 | C++17 `[[maybe_unused]]` |
| `[[noreturn]]` | 函数不返回 | C++11 `[[noreturn]]` |
| `[[fallthrough]]` | switch穿透是有意的 | C++17 `[[fallthrough]]` |
| `[[unsequenced]]` | 函数无副作用 | C23独有 |
| `[[reproducible]]` | 函数可重现 | C23独有 |

## 5. C11/C23与C++的对比

### 1. C11/C23中C++也有的特性

| 特性 | C版本 | C++版本 | 差异说明 |
|------|-------|---------|----------|
| `static_assert` | C11 `_Static_assert` | C++11 `static_assert` | C23统一为`static_assert` |
| `thread_local` | C11 `_Thread_local` | C++11 `thread_local` | C23统一为`thread_local` |
| `alignas/alignof` | C11 `_Alignas/_Alignof` | C++11 `alignas/alignof` | C23统一为`alignas/alignof` |
| `nullptr` | C23 | C++11 | 语义一致 |
| `constexpr` | C23 | C++11 | C23版更简单，不支持复杂表达式 |
| `typeof` | C23 | C++11(GNU扩展`decltype`) | `typeof`保留类型限定符，`decltype`更复杂 |
| `[[deprecated]]` | C23 | C++14 | 语法一致 |
| `[[nodiscard]]` | C23 | C++17 | 语法一致 |
| `[[maybe_unused]]` | C23 | C++17 | 语法一致 |
| `[[noreturn]]` | C23 | C++11 | 语法一致 |
| `bool/true/false` | C23关键字 | C++原生 | C99起通过`<stdbool.h>`提供宏 |
| 枚举底层类型 | C23 | C++11 | 语法一致 `enum E : type` |

### 2. C11/C23中C独有的特性

| 特性 | C版本 | 说明 | C++为什么没有 |
|------|-------|------|--------------|
| `_Generic` | C11 | 编译期类型选择 | C++有函数重载和模板 |
| `_Atomic` | C11 | 内建原子类型修饰符 | C++有`std::atomic`类模板 |
| `threads.h` | C11 | C标准线程库 | C++有`<thread>/<mutex>` |
| `_BitInt(N)` | C23 | 位精确整数 | C++无等价物（提案中） |
| `#embed` | C23 | 编译期嵌入文件 | C++无等价物（提案中） |
| `[[unsequenced]]` | C23 | 纯函数标记 | C++无等价物 |
| `[[reproducible]]` | C23 | 可重现函数标记 | C++无等价物 |
| `restrict` | C99 | 指针别名优化 | C++不支持（仅GNU扩展） |
| VLA | C99 | 变长数组 | C++不支持（C11变为可选） |
| 指定初始化器 | C99/C20 | `struct S s = {.x=1}` | C++20才部分支持 |

### 3. 关键字命名差异

C11使用`_Xxx`形式（带下划线大写前缀），通过头文件提供无下划线版本：

```
C11关键字              头文件提供的宏/别名
─────────────────     ──────────────────────
_Static_assert   →    static_assert     (<assert.h>)
_Thread_local    →    thread_local      (<threads.h>)
_Alignas         →    alignas           (<stdalign.h>)
_Alignof         →    alignof           (<stdalign.h>)
_Atomic          →    atomic_*类型      (<stdatomic.h>)

C23直接使用无下划线版本：
static_assert / thread_local / alignas / alignof 直接可用
```

## 6. 编译器支持情况

### 2. Clang支持

## 7. 迁移建议

### 1. 从C99迁移到C11

```
迁移步骤：
  1. 更新编译选项：-std=c99 → -std=c11
  2. 逐步替换线程库：pthread → threads.h
  3. 引入原子操作：手动锁 → _Atomic
  4. 利用_Generic简化类型分发代码
  5. 用_Static_assert增加编译期检查
```

| 迁移项 | C99做法 | C11做法 | 注意事项 |
|--------|---------|---------|----------|
| 布尔类型 | `#include <stdbool.h>` | 仍需包含（C23才内置） | 无需改动 |
| 线程 | `pthread_create` | `thrd_create` | API不同，需重写 |
| 互斥 | `pthread_mutex_t` | `mtx_t` | 更简洁 |
| 原子操作 | `__sync_fetch_and_add`（GCC扩展） | `atomic_fetch_add` | 标准化替代 |
| 断言 | 运行时`assert()` | 增加`_Static_assert` | 编译期检查 |
| 对齐 | `__attribute__((aligned))` | `_Alignas`/`aligned_alloc` | 标准化替代 |

### 2. 从C11迁移到C23

```
迁移步骤：
  1. 更新编译选项：-std=c11 → -std=c23
  2. 移除 <stdbool.h>（bool/true/false已是关键字）
  3. 用nullptr替代NULL
  4. 用constexpr替代部分const
  5. 用typeof简化宏定义
  6. 用[[...]]属性替代编译器扩展
  7. 考虑用_BitInt替代手写位域
```

| 迁移项 | C11做法 | C23做法 | 注意事项 |
|--------|---------|---------|----------|
| 空指针 | `NULL` | `nullptr` | 类型更安全 |
| 常量 | `const int SIZE = 10;` | `constexpr int SIZE = 10;` | 真正编译期常量 |
| 类型推导 | GCC扩展`__typeof__` | `typeof` | 标准化 |
| 废弃标记 | `__attribute__((deprecated))` | `[[deprecated]]` | 标准化 |
| 未使用标记 | `__attribute__((unused))` | `[[maybe_unused]]` | 标准化 |
| 枚举类型 | `enum { ... }` | `enum E : type { ... }` | 可控大小 |
| 嵌入文件 | `xxd`工具转换 | `#embed` | 编译期直接嵌入 |

### 3. 迁移常见陷阱

```c
/* 陷阱1：VLA在C11变为可选特性 */
void func(int n) {
    int arr[n];           /* C99保证支持，C11可选 */
    /* 迁移建议：改用malloc或固定大小数组 */
}

/* 陷阱2：_Generic的类型匹配是精确匹配 */
#define print(x) _Generic((x), \
    int: print_int,            \
    long: print_long           \
)(x)
/* print(42L) 匹配 long，但 print(42) 只匹配 int */
/* 不会自动进行类型提升匹配 */

/* 陷阱3：threads.h与pthread不能混用 */
/* threads.h的mtx_t和pthread_mutex_t是不同类型 */
/* 不要在同一个程序中混用两套线程API */

/* 陷阱4：constexpr在C23中比C++受限 */
constexpr int size = 10;       /* OK */
constexpr int arr[size];       /* OK */
/* constexpr int fib(int n) { ... } */ /* C23的constexpr函数限制更多 */
```
