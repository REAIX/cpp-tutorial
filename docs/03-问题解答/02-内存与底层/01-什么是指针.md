# 什么是指针
> 📖 相关章节：[指针](../../01-C语言/06-指针.md)

> **A pointer is a variable that stores a memory address. It's the most powerful—and dangerous—feature of C/C++.** — 指针是存储内存地址的变量，是 C/C++ 最强大也最危险的特性。

***

### 1. 要点直击

**指针**（Pointer）= 一个变量，它的值是另一个变量的**内存地址**。通过指针，你可以间接地访问和修改那块内存中的数据。

***

### 2. 生活类比

把内存比作**一排储物柜**：

- **变量** → 柜子里放的东西（比如一本书）
- **地址** → 柜子的编号（比如 3 号柜）
- **指针** → 一张写着"3 号柜"的纸条

你拿着纸条（指针），找到 3 号柜（地址），就能拿到里面的书（数据）。纸条本身也占一个柜子（指针变量本身也占内存）。

### 3. 指针的基本操作

```cpp
#include <iostream>

int main() {
    int value = 42;       // 普通变量：值为 42
    int* ptr = &value;    // 指针：存储 value 的地址

    std::cout << "value 的值: " << value << std::endl;      // 42
    std::cout << "value 的地址: " << &value << std::endl;   // 0x7ffd...
    std::cout << "ptr 的值（地址）: " << ptr << std::endl;   // 0x7ffd...（同上）
    std::cout << "ptr 指向的值: " << *ptr << std::endl;     // 42（解引用）

    *ptr = 100;           // 通过指针修改值
    std::cout << "修改后 value: " << value << std::endl;    // 100
}
```

**两个核心运算符**：

| 运算符 | 名称 | 作用 |
|--------|------|------|
| `&` | 取地址运算符 | 获取变量的内存地址 |
| `*` | 解引用运算符 | 访问指针指向地址中的值 |

### 4. 指针的类型

指针的类型决定了**如何解读它指向的内存**：

```cpp
#include <iostream>

int main() {
    int num = 65;        // 内存中存储: 0x41 0x00 0x00 0x00（小端序）
    int* pi = &num;      // int 指针：读 4 字节 → 65
    char* pc = (char*)&num;  // char 指针：读 1 字节 → 'A'（65 的 ASCII）

    std::cout << *pi << std::endl;  // 65
    std::cout << *pc << std::endl;  // A
}
```

| 指针类型 | 大小（64位系统） | 解读方式 |
|---------|:---:|---------|
| `int*` | 8 字节 | 指向一个 `int`（4字节） |
| `char*` | 8 字节 | 指向一个 `char`（1字节） |
| `double*` | 8 字节 | 指向一个 `double`（8字节） |
| `int**` | 8 字节 | 指向一个 `int*`（指针的指针） |

**注意**：所有指针变量本身的大小相同（64位系统为8字节），因为它们存的都是地址。类型不同影响的是**解引用时读取多少字节**。

### 5. 空指针

```cpp
#include <iostream>

int main() {
    int* p1 = nullptr;    // C++11 推荐
    int* p2 = NULL;       // C 风格（不推荐在 C++ 中使用）
    int* p3 = 0;          // 也可以，但不推荐

    if (p1 == nullptr) {
        std::cout << "p1 是空指针" << std::endl;
    }

    // *p1;  // 未定义行为！解引用空指针会崩溃
}
```

### 6. 指针的指针

```cpp
#include <iostream>

int main() {
    int value = 42;
    int* p = &value;       // 一级指针：指向 value
    int** pp = &p;         // 二级指针：指向 p

    std::cout << **pp << std::endl;  // 42（两次解引用）

    // 实际用途：函数中修改指针本身
    // void alloc(int** pp) { *pp = new int(42); }
}
```

### 7. 指针算术

指针加减整数 = 按指向类型的大小移动：

```cpp
#include <iostream>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int* p = arr;          // 指向 arr[0]

    std::cout << *p << std::endl;       // 10
    std::cout << *(p + 1) << std::endl; // 20（移动 1 个 int，即 4 字节）
    std::cout << *(p + 2) << std::endl; // 30

    p++;                    // p 现在指向 arr[1]
    std::cout << *p << std::endl;       // 20

    // 指针差值
    int* q = arr + 4;
    std::cout << q - p << std::endl;    // 3（相差 3 个 int）
}
```

| 运算 | 含义 | 移动字节数 |
|------|------|-----------|
| `p + 1` | 向后移动 1 个元素 | `1 * sizeof(*p)` |
| `p - 1` | 向前移动 1 个元素 | `1 * sizeof(*p)` |
| `p++` | 移动到下一个元素 | `sizeof(*p)` |
| `q - p` | 两个指针间的元素个数 | 结果为整数 |

### 8. 指针与数组

数组名在大多数情况下会退化为指向首元素的指针：

```cpp
#include <iostream>

void print_array(int* arr, int size) {
    for (int i = 0; i < size; ++i) {
        std::cout << arr[i] << " ";  // 等价于 *(arr + i)
    }
    std::cout << std::endl;
}

int main() {
    int arr[] = {1, 2, 3, 4, 5};
    int* p = arr;  // arr 退化为 &arr[0]

    // 以下等价
    std::cout << arr[2] << std::endl;  // 3
    std::cout << p[2] << std::endl;    // 3
    std::cout << *(arr + 2) << std::endl;  // 3
    std::cout << *(p + 2) << std::endl;    // 3

    print_array(arr, 5);
}
```

**例外**：`sizeof(arr)` 得到整个数组大小，而非指针大小。

### 9. 常见错误

```cpp
// 错误1：未初始化的指针（野指针）
int* p;          // 未初始化，指向随机地址
// *p = 42;      // 未定义行为！

// 正确：初始化为 nullptr
int* p2 = nullptr;

// 错误2：悬空指针
int* create() {
    int local = 42;
    return &local;  // 返回局部变量地址 → 悬空指针
}

// 错误3：内存泄漏
void leak() {
    int* p = new int(42);
    // 忘记 delete → 内存泄漏
}

// 错误4：重复释放
void double_free() {
    int* p = new int(42);
    delete p;
    // delete p;  // 未定义行为！重复释放
}
```

| 错误类型 | 原因 | 后果 | 预防 |
|---------|------|------|------|
| 野指针 | 未初始化 | 随机崩溃 | 初始化为 `nullptr` |
| 悬空指针 | 指向已释放的内存 | 未定义行为 | 用智能指针 |
| 内存泄漏 | 忘记 `delete` | 内存持续占用 | 用智能指针 |
| 重复释放 | `delete` 两次 | 未定义行为 | `delete` 后置 `nullptr` |
| 越界访问 | 指针算术超出范围 | 未定义行为 | 严格检查边界 |

### 10. 现代 C++ 的指针使用建议

```cpp
#include <iostream>
#include <memory>
#include <vector>

int main() {
    // 不推荐：裸指针 + new/delete
    // int* p = new int(42);
    // delete p;

    // 推荐1：栈分配
    int value = 42;

    // 推荐2：智能指针
    auto up = std::make_unique<int>(42);
    auto sp = std::make_shared<int>(42);

    // 推荐3：容器
    std::vector<int> data = {1, 2, 3};

    // 裸指针的合理用途：不拥有资源的观察指针
    int* obs = &value;  // 只观察，不负责释放
}
```

### 11. 极简总结

**指针 = 存储内存地址的变量 → & 取地址，* 解引用 → 类型决定解读方式 → 空指针用 nullptr → 指针算术按类型大小移动 → 野指针/悬空指针/内存泄漏是三大陷阱 → 现代 C++ 优先用智能指针和容器**
