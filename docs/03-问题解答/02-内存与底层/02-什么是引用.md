# 什么是引用
> 📖 相关章节：[指针](../../01-C语言/06-指针.md)、[结构体与联合体](../../01-C语言/08-结构体与联合体.md)、[内存管理](../../01-C语言/09-内存管理.md)、[智能指针](../../02-CPP/08-智能指针与内存管理.md)、[内存模型](../../02-CPP/32-内存模型.md)

> **A reference is an alias, not a copy. It's another name for an existing object.** — 引用是别名，不是副本，是已有对象的另一个名字。

***

### 1. 本质速解

**引用**（Reference）= 已有变量的**别名**（另一个名字）。对引用的操作就是对原变量的操作，它们共享同一块内存。

***

### 2. 生活类比

把变量比作**人**：

- **变量** → 一个人叫"张三"
- **引用** → 同一个人还有个小名叫"小三"
- **指针** → 一张写着"张三住在 3 号楼"的纸条

叫"张三"或"小三"都是同一个人。但纸条只是记录了地址，纸条本身不是人。

| 特性 | 引用 | 指针 |
|------|------|------|
| 本质 | 别名（同一个人） | 地址（纸条） |
| 必须初始化 | 是 | 否 |
| 能否重新绑定 | 否 | 是 |
| 是否可能为空 | 否 | 是 |
| 语法 | 直接使用 | 需要 `*` 和 `->` |

### 3. 引用的基本用法

```cpp
#include <iostream>

int main() {
    int value = 42;
    int& ref = value;   // ref 是 value 的引用（别名）

    std::cout << value << std::endl;  // 42
    std::cout << ref << std::endl;    // 42（同一个值）

    ref = 100;          // 通过引用修改
    std::cout << value << std::endl;  // 100（原变量也被修改）

    std::cout << &value << std::endl;  // 地址相同
    std::cout << &ref << std::endl;    // 地址相同
}
```

### 4. 引用的三大规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 必须初始化 | 定义时必须绑定到对象 | `int& r;` 错误 |
| 不可重新绑定 | 一旦绑定就不能改 | `r = other;` 是赋值，不是重新绑定 |
| 不能为空 | 必须绑定到有效对象 | 没有"空引用"的概念 |

```cpp
int a = 10, b = 20;
int& ref = a;    // 绑定到 a
ref = b;         // 这不是重新绑定！这是把 b 的值赋给 a
// 现在 a = 20, b = 20, ref 仍然引用 a

// 证明 ref 仍然引用 a
ref = 99;
std::cout << a << std::endl;  // 99（ref 还是指向 a）
```

### 5. 引用 vs 指针

```cpp
#include <iostream>

void by_pointer(int* p) {
    if (p) *p = 100;  // 需要判空
}

void by_reference(int& r) {
    r = 100;  // 不需要判空，引用一定有效
}

int main() {
    int x = 42;

    by_pointer(&x);    // 需要取地址
    by_reference(x);   // 直接传，更自然

    // 指针可以重新指向
    int y = 50;
    int* p = &x;
    p = &y;            // p 现在指向 y

    // 引用不能重新绑定
    int& r = x;
    // r = y;  // 这是赋值！x 变成 50，r 仍然引用 x
}
```

| 操作 | 指针 | 引用 |
|------|------|------|
| 定义 | `int* p = &x;` | `int& r = x;` |
| 访问值 | `*p` | `r` |
| 访问地址 | `p` | `&r`（等于 `&x`） |
| 重新指向 | `p = &y;` | 不支持 |
| 判空 | `if (p != nullptr)` | 不需要 |
| 做数组元素 | 可以 | 不可以 |

### 6. const 引用

`const` 引用是最常用的引用形式，既能避免拷贝，又保证不被修改：

```cpp
#include <iostream>
#include <string>

// 好习惯：函数参数用 const 引用传递大对象
void print(const std::string& str) {
    std::cout << str << std::endl;
    // str[0] = 'X';  // 错误！const 引用不能修改
}

int main() {
    std::string name = "Hello";
    print(name);           // 传左值
    print("World");        // 传右值（const 引用可以绑定右值）

    // const 引用延长临时对象的生命周期
    const int& ref = 42;   // 合法：const 引用绑定到临时 int
    std::cout << ref << std::endl;  // 42

    // int& bad = 42;     // 错误！非 const 引用不能绑定右值
}
```

**const 引用的特殊能力**：

| 能力 | 非 const 引用 | const 引用 |
|------|:---:|:---:|
| 绑定左值 | ✅ | ✅ |
| 绑定右值 | ❌ | ✅ |
| 修改原值 | ✅ | ❌ |
| 延长临时对象生命周期 | ❌ | ✅ |

### 7. 引用作为函数参数

```cpp
#include <iostream>
#include <string>

// 值传递：拷贝整个对象，开销大
void by_value(std::string s) {
    std::cout << s << std::endl;
}

// 引用传递：不拷贝，直接操作原对象
void by_reference(std::string& s) {
    s += " modified";  // 修改原对象
}

// const 引用传递：不拷贝，不修改（最佳实践）
void by_const_ref(const std::string& s) {
    std::cout << s << std::endl;
    // s += "x";  // 错误：不能修改
}

int main() {
    std::string str = "Hello";

    by_value(str);        // 拷贝 str
    by_reference(str);    // 不拷贝，str 被修改
    by_const_ref(str);    // 不拷贝，不修改
}
```

**参数传递选择指南**：

| 参数类型 | 推荐方式 | 原因 |
|---------|---------|------|
| 基本类型（int, double 等） | 值传递 | 拷贝开销小 |
| 大对象（string, vector 等） | const 引用 | 避免拷贝 |
| 需要修改原对象 | 非const 引用 | 直接修改 |
| 可能不存在 | 指针 + nullptr | 引用不能为空 |

### 8. 引用作为返回值

```cpp
#include <iostream>
#include <vector>

// 危险：返回局部变量的引用
int& bad_func() {
    int local = 42;
    return local;  // 悬空引用！local 已销毁
}

// 安全：返回参数引用
int& max_ref(int& a, int& b) {
    return (a > b) ? a : b;
}

// 安全：返回成员引用
class Array {
    int data_[10];
public:
    int& operator[](int i) { return data_[i]; }
};

int main() {
    int x = 10, y = 20;
    max_ref(x, y) = 100;  // y 被修改为 100

    Array arr;
    arr[0] = 42;  // 通过引用返回修改元素
}
```

### 9. 引用折叠（Reference Collapsing）

在模板和类型推导中，引用的引用会"折叠"：

```cpp
#include <iostream>
#include <utility>

template<typename T>
void func(T&& arg) {  // 转发引用
    // T 的类型取决于传入参数：
    // 传入左值 → T = int&  → T&& = int& && = int&
    // 传入右值 → T = int   → T&& = int&&
}

int main() {
    int x = 42;
    func(x);          // x 是左值，T = int&
    func(42);         // 42 是右值，T = int
}
```

| 外层引用 | 内层引用 | 折叠结果 |
|---------|---------|---------|
| `T& &` | 左值引用的左值引用 | `T&` |
| `T& &&` | 左值引用的右值引用 | `T&` |
| `T&& &` | 右值引用的左值引用 | `T&` |
| `T&& &&` | 右值引用的右值引用 | `T&&` |

**规则**：只有右值引用的右值引用才折叠为右值引用，其他都折叠为左值引用。

### 10. 极简总结

**引用 = 变量的别名 → 必须初始化、不可重新绑定、不能为空 → const 引用可绑定右值、避免拷贝 → 函数参数大对象用 const& → 不要返回局部变量的引用 → 引用折叠是模板中理解转发引用的关键**
