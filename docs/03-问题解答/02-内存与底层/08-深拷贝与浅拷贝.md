# 深拷贝与浅拷贝
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[核心机制](../../02-CPP/05-核心机制.md)

### 1. 一句话概括

**浅拷贝** = 只复制指针地址，两个对象指向同一块内存；**深拷贝** = 重新分配内存，把内容也复制一份，两个对象各管各的。

***

### 2. 浅拷贝的问题

```cpp
class Buffer {
    int* data;
    size_t size;
public:
    Buffer(size_t n) : size(n), data(new int[n]) {}
    ~Buffer() { delete[] data; }
};

Buffer a(10);
Buffer b = a;  // 浅拷贝！
// 析构时：a 和 b 的 data 指向同一块内存 → double free！
```

浅拷贝的连锁问题：
```cpp
void process(Buffer buf) {  // 传值 → 浅拷贝
    // 修改 buf
    // 函数结束时 buf 析构 → 释放 data
}  // 外部原对象的 data 变为悬空指针！

Buffer create() {
    Buffer local(10);
    return local;  // C++11 之前：浅拷贝 + 析构 local → 悬空指针！
}
```

### 3. 深拷贝怎么做

```cpp
class Buffer {
    int* data;
    size_t size;
public:
    Buffer(size_t n) : size(n), data(new int[n]) {
        std::fill(data, data + size, 0);
    }
    ~Buffer() { delete[] data; }

    // 深拷贝构造
    Buffer(const Buffer& other) : size(other.size), data(new int[other.size]) {
        std::copy(other.data, other.data + size, data);
    }

    // 深拷贝赋值（赋值运算符重载）
    Buffer& operator=(const Buffer& other) {
        if (this != &other) {              // 自赋值检查
            delete[] data;                  // 释放旧资源
            size = other.size;
            data = new int[size];           // 分配新资源
            std::copy(other.data, other.data + size, data);  // 复制内容
        }
        return *this;
    }
};
```

### 4. 浅拷贝 vs 深拷贝

| 特性 | 浅拷贝 | 深拷贝 |
|------|:---:|:---:|
| 复制方式 | 复制指针值 | 重新分配+复制内容 |
| 共享内存 | 是 | 否 |
| 析构安全 | 不安全（double free） | 安全 |
| 性能 | 快（O(1)） | 慢（需要分配+拷贝，O(n)） |
| 默认行为 | 编译器默认 | 需要手动实现 |
| 独立修改 | 互相影响 | 各自独立 |
| 异常安全 | 无额外风险 | 需注意资源泄漏 |

### 5. Rule of Three（三法则）

如果需要自定义以下任何一个，就三个都要自定义：

1. **析构函数** — 需要释放资源
2. **拷贝构造函数** — 需要深拷贝
3. **拷贝赋值运算符** — 需要深拷贝+自赋值检查

```cpp
class RuleOfThree {
    int* data;
    size_t size;
public:
    // 构造函数
    RuleOfThree(size_t n) : size(n), data(new int[n]()) {}

    // 1. 析构函数
    ~RuleOfThree() {
        delete[] data;
    }

    // 2. 拷贝构造函数
    RuleOfThree(const RuleOfThree& other)
        : size(other.size), data(new int[other.size]) {
        std::copy(other.data, other.data + size, data);
    }

    // 3. 拷贝赋值运算符（使用 copy-and-swap 惯用法）
    RuleOfThree& operator=(const RuleOfThree& other) {
        RuleOfThree temp(other);  // 调用拷贝构造
        swap(temp);               // 交换资源
        return *this;
    }

    void swap(RuleOfThree& other) noexcept {
        using std::swap;
        swap(data, other.data);
        swap(size, other.size);
    }
};
```

**copy-and-swap 的优势**：
- 自赋值安全：通过临时对象自动处理
- 异常安全：如果拷贝构造抛出异常，原对象保持不变
- 代码复用：拷贝构造 + swap

### 6. Rule of Five（五法则）

C++11 加上移动语义后变成五个：

4. **移动构造函数**
5. **移动赋值运算符**

```cpp
class RuleOfFive {
    int* data;
    size_t size;
public:
    // 构造函数
    RuleOfFive(size_t n) : size(n), data(new int[n]()) {}

    // 1. 析构函数
    ~RuleOfFive() { delete[] data; }

    // 2. 拷贝构造函数
    RuleOfFive(const RuleOfFive& other)
        : size(other.size), data(new int[other.size]) {
        std::copy(other.data, other.data + size, data);
    }

    // 3. 拷贝赋值运算符（copy-and-swap）
    RuleOfFive& operator=(RuleOfFive other) {  // 传值而非传引用
        swap(other);
        return *this;
    }

    // 4. 移动构造函数（noexcept）
    RuleOfFive(RuleOfFive&& other) noexcept
        : data(nullptr), size(0) {
        swap(other);  // 窃取资源
    }

    // 5. 移动赋值运算符
    RuleOfFive& operator=(RuleOfFive&& other) noexcept {
        if (this != &other) {
            delete[] data;     // 释放旧资源
            data = other.data; // 窃取指针
            size = other.size;
            other.data = nullptr;  // 源对象置空
            other.size = 0;
        }
        return *this;
    }

    void swap(RuleOfFive& other) noexcept {
        using std::swap;
        swap(data, other.data);
        swap(size, other.size);
    }
};
```

**Rule of Zero**（零法则）—— 最佳实践：
```cpp
// 使用 RAII 容器，让编译器自动管理资源
class RuleOfZero {
    std::vector<int> data;  // 自动管理内存
    std::string name;       // 自动管理
    // 不需要手动定义构造/析构/拷贝/移动
};
```

### 7. 移动语义下的拷贝行为

```cpp
class StringBuffer {
    char* buf;
    size_t len;
public:
    StringBuffer(const char* s) : len(strlen(s)), buf(new char[len + 1]) {
        strcpy(buf, s);
    }

    // 移动构造：高效转交所有权
    StringBuffer(StringBuffer&& other) noexcept
        : buf(other.buf), len(other.len) {
        other.buf = nullptr;  // 源对象放弃所有权
        other.len = 0;
    }

    // 何时调用移动？
    StringBuffer a("hello");
    StringBuffer b = std::move(a);  // 移动构造
    StringBuffer c = a;             // 拷贝构造（a 非临时对象）

    StringBuffer d = StringBuffer("temp");  // 移动构造（临时对象）
    StringBuffer e = std::move(d);          // 移动构造
};
```

移动语义性能对比：
| 操作 | 拷贝（O(n)） | 移动（O(1)） |
|------|:-----------:|:-----------:|
| std::vector (1000元素) | ~1000次元素拷贝 | 3次指针赋值 |
| std::string (1KB) | 1次堆分配+拷贝 | 3次指针赋值 |
| 自定义 Buffer (1MB) | 1MB内存拷贝 | 3次指针赋值 |

### 8. 写时复制（Copy-on-Write, COW）

```cpp
#include <memory>

template <typename T>
class CowVector {
    std::shared_ptr<std::vector<T>> data;
public:
    CowVector() : data(std::make_shared<std::vector<T>>()) {}

    // 浅拷贝：共享同一份数据
    CowVector(const CowVector& other) : data(other.data) {}

    // 写时复制：修改时再真正复制
    void push_back(const T& value) {
        if (!data.unique()) {
            // 数据被共享 → 深拷贝
            data = std::make_shared<std::vector<T>>(*data);
        }
        data->push_back(value);
    }

    const T& operator[](size_t i) const {
        return (*data)[i];  // 读操作不触发复制
    }

    T& operator[](size_t i) {
        if (!data.unique()) {
            data = std::make_shared<std::vector<T>>(*data);
        }
        return (*data)[i];  // 写操作触发复制
    }
};
```

COW 适用场景：
- 大规模数据频繁读取、极少修改
- 字符串实现（std::string 曾使用 COW，C++11 后禁止）
- 共享内存中的只读数据

COW 的缺点：
- 多线程环境下引用计数有开销
- 写操作有延迟（分配+拷贝）
- C++11 移动语义已覆盖大部分 COW 场景

### 9. 深拷贝的高级实现

```cpp
// 异常安全的深拷贝赋值（不使用 copy-and-swap）
Buffer& operator=(const Buffer& other) {
    if (this == &other) return *this;

    int* new_data = new int[other.size];  // 先分配
    std::copy(other.data, other.data + other.size, new_data);

    delete[] data;       // 成功后再释放旧资源
    data = new_data;
    size = other.size;
    return *this;
}

// 延迟深拷贝（Lazy Copy）
class LazyBuffer {
    int* data;
    bool shared;
public:
    // 浅拷贝，标记为共享
    LazyBuffer(const LazyBuffer& other)
        : data(other.data), shared(true) {}

    // 真正需要写时再进行深拷贝
    int* get_data() {
        if (shared) {
            int* new_data = new int[size];
            std::copy(data, data + size, new_data);
            data = new_data;
            shared = false;
        }
        return data;
    }
};
```

### 10. 极简总结

**浅拷贝 = 复制指针 → 共享内存 → 析构崩溃；深拷贝 = 重新分配+复制 → 各管各的 → 安全；Rule of Three/Five 管理资源；移动语义 O(1) 效率；写时复制优化读多写少场景；优先用 Rule of Zero**
