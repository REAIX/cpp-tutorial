# 虚析构函数为什么重要
> 📖 相关章节：[继承与多态](../../02-CPP/04-继承与多态.md)、[类与对象](../../02-CPP/03-类与对象.md)

### 1. 核心速览

**基类析构函数必须是 virtual 的**，否则通过基类指针 delete 派生类对象时，只会调用基类析构，派生类析构被跳过 → 资源泄漏。

***

### 2. 问题演示

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    ~Base() { cout << "~Base" << endl; }  // 非 virtual！
};

class Derived : public Base {
    int* data;
public:
    Derived() { data = new int[100]; }
    ~Derived() { delete[] data; cout << "~Derived" << endl; }
};

int main() {
    Base* p = new Derived();
    delete p;  // 只调用 ~Base()，~Derived() 被跳过！
    // 结果：data 内存泄漏！
    return 0;
}
```

输出：
```
~Base
```
Derived 的析构函数**从未被调用**，100个int的内存永久泄漏。

### 3. 正确写法

```cpp
class Base {
public:
    virtual ~Base() = default;  // 虚析构！
};

class Derived : public Base {
    int* data;
public:
    Derived() { data = new int[100]; }
    ~Derived() override { delete[] data; cout << "~Derived\n"; }
};

int main() {
    Base* p = new Derived();
    delete p;  // 正确：先 ~Derived()，再 ~Base()
    return 0;
}
```

输出：
```
~Derived
~Base
```

### 4. 底层原理：vtable 与析构函数

虚析构函数通过 vtable 动态分发，与普通虚函数机制相同：

```
Base vtable:
+--------------------+
| type_info          |
| virtual ~Base()    | ← 基类析构函数地址
| ...其他虚函数...    |

Derived vtable:
+--------------------+
| type_info          |
| virtual ~Derived() | ← 派生类析构函数地址（覆盖了基类的）
| ...其他虚函数...    |
```

- 非虚析构：`delete p` 编译为 `call ~Base()`（静态绑定，CALL指令直接调用基类地址）
- 虚析构：`delete p` 编译为 `call [vptr + offset]`（动态绑定，通过vtable查找实际类型）

### 5. 什么时候需要虚析构

| 情况 | 是否需要虚析构 |
|------|:---:|
| 有虚函数的类 | ✅ 是 |
| 会被多态使用的基类 | ✅ 是 |
| 不会被继承的类 | ❌ 不需要 |
| 会被继承但不做多态删除 | ❌ 不需要（但不推荐） |
| 纯工具类/函数对象 | ❌ 不需要 |
| sealed/final 类 | ❌ 不需要 |

**经验法则：如果一个类有虚函数，就应该有虚析构。**

### 6. 虚析构的开销

| 开销项 | 说明 |
|--------|------|
| vptr 空间 | 每个对象多 8 字节（64位） |
| 动态分发 | 多一次间接查表（极小） |
| 不能内联 | 虚函数不能被 inline 展开 |
| 零额外开销 | 如果类已有虚函数，虚析构不增加额外成本 |

### 7. 使用智能指针时的注意事项

```cpp
// shared_ptr 会记住删除器，即使没有虚析构也能正确析构
shared_ptr<Base> sp = make_shared<Derived>();
// sp 析构时会正确调用 ~Derived()！

// unique_ptr 同理
unique_ptr<Base> up = make_unique<Derived>();
// 正确调用 ~Derived()

// 但原始指针仍需要虚析构
Base* raw = new Derived();
delete raw;  // 需要虚析构！
```

### 8. final 类与虚析构

```cpp
class MyFinal final {  // final 类不能被继承
public:
    ~MyFinal();  // 不需要虚析构，因为没有派生类
};

class Base {
public:
    virtual ~Base() = default;
};

class Derived final : public Base {
public:
    ~Derived() override;
    // Derived 被 final 标记，但基类已有虚析构，override 仍然是好的实践
};
```

### 9. 极简总结

**基类析构必须 virtual → 否则 delete 基类指针只析构基类 → 派生类资源泄漏 → shared_ptr/unique_ptr 自动处理但原始指针仍需虚析构**
