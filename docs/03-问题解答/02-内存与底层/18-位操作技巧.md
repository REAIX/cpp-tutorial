# 位操作实战技巧有哪些
> 📖 相关章节：[位操作实战](../../01-C语言/12-位操作实战.md)

> "位操作=直接拨动CPU的开关，0和1的排列组合就是一切。"——位运算是C/C++最底层的操作能力，在权限系统、状态机、协议解析中无处不在。

***

### 1. 通俗理解

- **位操作** = 直接对二进制的每一位进行操控，是最高效的数据处理方式
- 就像一排灯泡开关：设置位=打开灯，清除位=关闭灯，翻转位=切换状态，检查位=看灯亮不亮
- 位运算比算术运算快，因为CPU直接支持，不需要额外的计算单元
- 在嵌入式、协议解析、权限系统中，位操作是核心技能

| 概念 | 类比 | 说明 |
|------|------|------|
| 位掩码 | 遥控器按钮 | 用1和0的组合选择要操作的位 |
| 设置位 | 打开开关 | 把某位变成1 |
| 清除位 | 关闭开关 | 把某位变成0 |
| 翻转位 | 切换开关 | 0变1，1变0 |
| 位图 | 一排灯泡 | 用每一位表示一个状态 |

### 2. 技术说明

#### 1. 位掩码基本操作

**定义位掩码**：

```c
#define BIT_0  (1 << 0)   /* 0b00000001 */
#define BIT_1  (1 << 1)   /* 0b00000010 */
#define BIT_2  (1 << 2)   /* 0b00000100 */
#define BIT_3  (1 << 3)   /* 0b00001000 */
#define BIT_4  (1 << 4)   /* 0b00010000 */
#define BIT_5  (1 << 5)   /* 0b00100000 */
#define BIT_6  (1 << 6)   /* 0b01000000 */
#define BIT_7  (1 << 7)   /* 0b10000000 */
```

**四种基本操作**：

| 操作 | 公式 | 示例 |
|------|------|------|
| 设置第n位 | `x \|= (1 << n)` | `x \|= (1 << 3)` → 第3位变1 |
| 清除第n位 | `x &= ~(1 << n)` | `x &= ~(1 << 3)` → 第3位变0 |
| 翻转第n位 | `x ^= (1 << n)` | `x ^= (1 << 3)` → 第3位0↔1 |
| 检查第n位 | `(x >> n) & 1` | `if ((x >> 3) & 1)` → 第3位是否为1 |

**多位操作**：

```c
/* 设置第2-4位 */
x |= 0x1C;        /* 0b00011100 */

/* 清除第2-4位 */
x &= ~0x1C;       /* 0b11100011 */

/* 取出第2-4位的值 */
int val = (x >> 2) & 0x07;  /* 取3位 */

/* 设置第2-4位为指定值 */
x = (x & ~0x1C) | ((val & 0x07) << 2);
```

#### 2. 位运算常用技巧

| 技巧 | 公式 | 说明 |
|------|------|------|
| 判断2的幂 | `(x & (x - 1)) == 0 && x != 0` | 2的幂只有一个1 |
| 取最低位的1 | `x & (-x)` | 也叫lowbit |
| 去掉最低位的1 | `x & (x - 1)` | 常用于计数1的个数 |
| 判断奇偶 | `(x & 1)` | 1=奇数，0=偶数 |
| 乘以2的n次方 | `x << n` | 等价于x * (2^n) |
| 除以2的n次方 | `x >> n` | 等价于x / (2^n)，仅对正数 |
| 取模2的n次方 | `x & ((1 << n) - 1)` | 等价于x % (2^n) |
| 交换两数 | `a ^= b; b ^= a; a ^= b;` | 不用临时变量 |
| 取绝对值 | `(x ^ (x >> 31)) - (x >> 31)` | 32位整数 |
| 位反转 | 逐步交换 | 见下方代码 |

**popcount（统计1的个数）**：

```c
/* 方法1：逐位检查 */
int popcount_v1(unsigned int x) {
    int count = 0;
    while (x) {
        count += x & 1;
        x >>= 1;
    }
    return count;
}

/* 方法2：Brian Kernighan算法 */
int popcount_v2(unsigned int x) {
    int count = 0;
    while (x) {
        x &= x - 1;
        count++;
    }
    return count;
}

/* 方法3：查表法 */
static const int popcount_table[16] = {
    0, 1, 1, 2, 1, 2, 2, 3, 1, 2, 2, 3, 2, 3, 3, 4
};
int popcount_v3(unsigned int x) {
    int count = 0;
    while (x) {
        count += popcount_table[x & 0xF];
        x >>= 4;
    }
    return count;
}
```

**32位整数位反转**：

```c
unsigned int reverse_bits(unsigned int x) {
    x = ((x & 0x55555555) << 1) | ((x & 0xAAAAAAAA) >> 1);
    x = ((x & 0x33333333) << 2) | ((x & 0xCCCCCCCC) >> 2);
    x = ((x & 0x0F0F0F0F) << 4) | ((x & 0xF0F0F0F0) >> 4);
    x = ((x & 0x00FF00FF) << 8) | ((x & 0xFF00FF00) >> 8);
    x = ((x & 0x0000FFFF) << 16) | ((x & 0xFFFF0000) >> 16);
    return x;
}
```

#### 3. 字节序转换

| 函数 | 作用 | 说明 |
|------|------|------|
| `htons(x)` | 主机序转网络序（16位） | 小端机器上会翻转字节 |
| `htonl(x)` | 主机序转网络序（32位） | 小端机器上会翻转字节 |
| `ntohs(x)` | 网络序转主机序（16位） | 和htons互逆 |
| `ntohl(x)` | 网络序转主机序（32位） | 和htonl互逆 |

**手动实现**：

```c
#include <stdint.h>

uint16_t swap16(uint16_t x) {
    return (x << 8) | (x >> 8);
}

uint32_t swap32(uint32_t x) {
    return ((x & 0x000000FF) << 24) |
           ((x & 0x0000FF00) << 8)  |
           ((x & 0x00FF0000) >> 8)  |
           ((x & 0xFF000000) >> 24);
}

uint64_t swap64(uint64_t x) {
    return ((x & 0x00000000000000FFULL) << 56) |
           ((x & 0x000000000000FF00ULL) << 40) |
           ((x & 0x0000000000FF0000ULL) << 24) |
           ((x & 0x00000000FF000000ULL) << 8)  |
           ((x & 0x000000FF00000000ULL) >> 8)  |
           ((x & 0x0000FF0000000000ULL) >> 24) |
           ((x & 0x00FF000000000000ULL) >> 40) |
           ((x & 0xFF00000000000000ULL) >> 56);
}
```

#### 4. 位图（bitmap）数据结构

位图用每一位表示一个元素是否存在，空间效率极高。

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define BITMAP_SIZE(bits)  (((bits) + 7) / 8)

typedef struct {
    unsigned char* data;
    int size;
} bitmap_t;

bitmap_t* bitmap_create(int bits) {
    bitmap_t* bm = (bitmap_t*)malloc(sizeof(bitmap_t));
    bm->size = bits;
    bm->data = (unsigned char*)calloc(BITMAP_SIZE(bits), 1);
    return bm;
}

void bitmap_destroy(bitmap_t* bm) {
    free(bm->data);
    free(bm);
}

void bitmap_set(bitmap_t* bm, int index) {
    bm->data[index / 8] |= (1 << (index % 8));
}

void bitmap_clear(bitmap_t* bm, int index) {
    bm->data[index / 8] &= ~(1 << (index % 8));
}

int bitmap_test(bitmap_t* bm, int index) {
    return (bm->data[index / 8] >> (index % 8)) & 1;
}
```

#### 5. GCC内建函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `__builtin_popcount(x)` | 统计1的个数（32位） | `__builtin_popcount(0xFF)` → 8 |
| `__builtin_popcountll(x)` | 统计1的个数（64位） | `__builtin_popcountll(0xFFFF)` → 16 |
| `__builtin_clz(x)` | 前导零个数（32位） | `__builtin_clz(1)` → 31 |
| `__builtin_clzll(x)` | 前导零个数（64位） | `__builtin_clzll(1)` → 63 |
| `__builtin_ctz(x)` | 末尾零个数（32位） | `__builtin_ctz(8)` → 3 |
| `__builtin_ctzll(x)` | 末尾零个数（64位） | `__builtin_ctzll(8)` → 3 |
| `__builtin_parity(x)` | 1的个数的奇偶性 | `__builtin_parity(0xFF)` → 0（偶数） |

**注意**：`__builtin_clz(0)`和`__builtin_ctz(0)`是未定义行为。

**常用技巧**：

```c
/* 计算以2为底的对数（向下取整） */
int log2_int(unsigned int x) {
    return 31 - __builtin_clz(x);
}

/* 判断是否为2的幂 */
int is_power_of_2(unsigned int x) {
    return x != 0 && __builtin_popcount(x) == 1;
}

/* 向上对齐到2的幂 */
unsigned int next_power_of_2(unsigned int x) {
    if (x <= 1) return 1;
    return 1U << (32 - __builtin_clz(x - 1));
}
```

### 3. 代码示例

#### 1. 示例1：权限系统

```c
#include <stdio.h>

#define PERM_READ    (1 << 0)   /* 0b0001 */
#define PERM_WRITE   (1 << 1)   /* 0b0010 */
#define PERM_EXECUTE (1 << 2)   /* 0b0100 */
#define PERM_ADMIN   (1 << 3)   /* 0b1000 */

typedef unsigned char permission_t;

void print_permissions(permission_t perm) {
    printf("权限: ");
    if (perm & PERM_READ)    printf("读 ");
    if (perm & PERM_WRITE)   printf("写 ");
    if (perm & PERM_EXECUTE) printf("执行 ");
    if (perm & PERM_ADMIN)   printf("管理 ");
    printf("(0x%02X)\n", perm);
}

int main(void) {
    permission_t user_perm = PERM_READ | PERM_WRITE;
    permission_t admin_perm = PERM_READ | PERM_WRITE | PERM_EXECUTE | PERM_ADMIN;

    printf("普通用户: ");
    print_permissions(user_perm);

    printf("管理员: ");
    print_permissions(admin_perm);

    /* 添加执行权限 */
    user_perm |= PERM_EXECUTE;
    printf("添加执行权限后: ");
    print_permissions(user_perm);

    /* 移除写权限 */
    user_perm &= ~PERM_WRITE;
    printf("移除写权限后: ");
    print_permissions(user_perm);

    /* 检查是否有管理权限 */
    if (user_perm & PERM_ADMIN) {
        printf("有管理权限\n");
    } else {
        printf("无管理权限\n");
    }

    /* 翻转执行权限 */
    user_perm ^= PERM_EXECUTE;
    printf("翻转执行权限后: ");
    print_permissions(user_perm);

    return 0;
}
```

#### 2. 示例2：状态机

```c
#include <stdio.h>

typedef unsigned char state_t;

#define STATE_IDLE    (1 << 0)
#define STATE_RUNNING (1 << 1)
#define STATE_PAUSED  (1 << 2)
#define STATE_ERROR   (1 << 3)

typedef struct {
    state_t current;
    state_t history;
} machine_t;

void machine_init(machine_t* m) {
    m->current = STATE_IDLE;
    m->history = 0;
}

void machine_transition(machine_t* m, state_t new_state) {
    m->history |= m->current;
    m->current = new_state;
}

int machine_has_been_in(machine_t* m, state_t state) {
    return (m->history & state) || (m->current & state);
}

void machine_print(machine_t* m) {
    printf("当前: ");
    if (m->current & STATE_IDLE)    printf("空闲 ");
    if (m->current & STATE_RUNNING) printf("运行 ");
    if (m->current & STATE_PAUSED)  printf("暂停 ");
    if (m->current & STATE_ERROR)   printf("错误 ");
    printf("| 历史: 0x%02X\n", m->history);
}

int main(void) {
    machine_t m;
    machine_init(&m);
    machine_print(&m);

    machine_transition(&m, STATE_RUNNING);
    machine_print(&m);

    machine_transition(&m, STATE_PAUSED);
    machine_print(&m);

    machine_transition(&m, STATE_ERROR);
    machine_print(&m);

    printf("是否经历过运行状态: %s\n",
           machine_has_been_in(&m, STATE_RUNNING) ? "是" : "否");
    printf("是否经历过空闲状态: %s\n",
           machine_has_been_in(&m, STATE_IDLE) ? "是" : "否");

    return 0;
}
```

#### 3. 示例3：位图去重

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define MAX_NUM 1000

int bitmap_test_simple(const unsigned char* bm, int index, int total_bits) {
    if (index < 0 || index >= total_bits) return 0;
    return (bm[index / 8] >> (index % 8)) & 1;
}

int main(void) {
    unsigned char bitmap[BITMAP_SIZE(MAX_NUM)] = {0};
    int duplicates = 0;

    srand((unsigned)time(NULL));

    printf("生成随机数并去重:\n");
    for (int i = 0; i < 2000; i++) {
        int num = rand() % MAX_NUM;
        if (bitmap_test_simple(bitmap, num, MAX_NUM)) {
            duplicates++;
        } else {
            bitmap[num / 8] |= (1 << (num % 8));
        }
    }

    int unique_count = 0;
    for (int i = 0; i < MAX_NUM; i++) {
        if ((bitmap[i / 8] >> (i % 8)) & 1) {
            unique_count++;
        }
    }

    printf("重复次数: %d\n", duplicates);
    printf("唯一数字: %d\n", unique_count);
    printf("位图内存: %zu 字节（普通数组需 %d 字节）\n",
           sizeof(bitmap), MAX_NUM * (int)sizeof(int));

    return 0;
}
```

### 4. 常见问题

#### 1. 问题1：位运算的优先级容易出错怎么办

位运算的优先级低于算术运算和比较运算，容易出错。建议始终用括号明确优先级：

```c
/* 错误：& 优先级低于 == */
if (flags & FLAG_A == 0)    /* 实际是 flags & (FLAG_A == 0) */

/* 正确 */
if ((flags & FLAG_A) == 0)
```

#### 2. 问题2：有符号数的右移是什么行为

有符号数右移是实现定义的：可能是算术右移（补符号位）或逻辑右移（补0）。大多数平台是算术右移。如果需要逻辑右移，先转换为无符号类型：

```c
int x = -1;
unsigned int y = (unsigned int)x >> 3;  /* 保证逻辑右移 */
```

#### 3. 问题3：位域和位掩码哪个好

位域写法简单但不可移植（位序依赖编译器），位掩码写法繁琐但可移植且可控。网络协议、文件格式等跨平台场景必须用位掩码，内部数据结构可以用位域。

#### 4. 问题4：__builtin_popcount一定比手写快吗

大多数情况下是的，因为编译器会使用硬件指令（如x86的`POPCNT`）。但在没有硬件支持的平台上，编译器会退化为函数调用，可能不如查表法快。可以用`-mpopcnt`编译选项启用硬件指令。

### 5. 极简总结

**位操作是C/C++最底层的操作能力。四种基本操作：设置位（|=）、清除位（&= ~）、翻转位（^=）、检查位（>> & 1）。常用技巧：判断2的幂（x & (x-1)）、取最低位1（x & -x）、popcount（x &= x-1）。字节序转换用htons/htonl/ntohs/ntohl。位图用每一位表示元素存在性，空间极省。GCC内建函数__builtin_popcount/clz/ctz可加速常见位运算。**

| 要点 | 一句话 |
|------|--------|
| 设置位 | `x \|= (1 << n)` —— 把第n位变1 |
| 清除位 | `x &= ~(1 << n)` —— 把第n位变0 |
| 翻转位 | `x ^= (1 << n)` —— 第n位0↔1 |
| 检查位 | `(x >> n) & 1` —— 检查第n位 |
| 2的幂 | `x & (x - 1) == 0` —— 只有一个1 |
| lowbit | `x & (-x)` —— 取最低位的1 |
| 位图 | 每位表示一个元素——空间极省 |
| GCC内建 | `__builtin_popcount/clz/ctz` —— 硬件加速 |
