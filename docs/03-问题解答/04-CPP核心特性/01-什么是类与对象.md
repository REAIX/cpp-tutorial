# 什么是类与对象
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[继承与多态](../../02-CPP/04-继承与多态.md)、[核心机制](../../02-CPP/05-核心机制.md)、[异常处理](../../02-CPP/07-异常处理.md)、[移动语义](../../02-CPP/09-移动语义与完美转发.md)

> **A class is a blueprint, an object is a house built from it.** — 类是蓝图，对象是按蓝图建的房子。

***

### 1. 本质速解

**类**（Class）= 用户自定义的数据类型，是创建对象的**蓝图/模板**。**对象**（Object）= 类的**实例**，是按照类的定义创建出来的具体实体。

***

### 2. 生活类比

把类和对象比作**月饼模具和月饼**：

- **类** → 月饼模具：定义了月饼的形状、花纹、大小
- **对象** → 用模具压出来的月饼：每个都是独立的实体

一个模具（类）可以压出无数个月饼（对象），每个月饼有自己的馅料（数据），但形状都一样（方法相同）。

### 3. 类的基本结构

```cpp
#include <iostream>
#include <string>

class Student {
private:                    // 私有：外部不能直接访问
    std::string name_;      // 成员变量（属性）
    int age_;

public:                     // 公有：外部可以访问
    // 构造函数：初始化对象
    Student(std::string name, int age)
        : name_(std::move(name)), age_(age) {}

    // 成员函数（方法）
    void introduce() const {
        std::cout << "我叫" << name_
                  << "，今年" << age_ << "岁" << std::endl;
    }

    // Getter
    int get_age() const { return age_; }

    // Setter
    void set_age(int age) { age_ = age; }
};

int main() {
    Student s1("小明", 18);   // 创建对象（实例化）
    Student s2("小红", 20);   // 另一个对象

    s1.introduce();  // 我叫小明，今年18岁
    s2.introduce();  // 我叫小红，今年20岁

    s1.set_age(19);
    std::cout << s1.get_age() << std::endl;  // 19
}
```

### 4. 类 vs 对象

| 特性 | 类（Class） | 对象（Object） |
|------|:---:|:---:|
| 本质 | 类型定义（蓝图） | 类的实例（实体） |
| 内存占用 | 不占对象内存 | 每个对象独立占用内存 |
| 数量 | 一个类 | 可以创建无数对象 |
| 存储位置 | 代码段 | 栈或堆 |
| 生命周期 | 程序运行期间 | 取决于存储方式 |

```cpp
class Dog {
    std::string name_;
public:
    Dog(std::string name) : name_(std::move(name)) {}
    void bark() const { std::cout << name_ << ": 汪汪！" << std::endl; }
};

int main() {
    Dog d1("旺财");      // 栈上的对象
    Dog d2("来福");      // 另一个栈上对象
    Dog* d3 = new Dog("大黄");  // 堆上的对象
    d1.bark();           // 旺财: 汪汪！
    d2.bark();           // 来福: 汪汪！
    d3->bark();          // 大黄: 汪汪！
    delete d3;
}
```

### 5. 访问控制

C++ 提供三种访问说明符，控制类成员的可见性：

```cpp
class BankAccount {
private:        // 私有：只有类内部可以访问
    double balance_;

protected:      // 保护：类内部和派生类可以访问
    std::string account_id_;

public:         // 公有：任何地方都可以访问
    BankAccount(std::string id, double bal)
        : account_id_(std::move(id)), balance_(bal) {}

    double get_balance() const { return balance_; }  // 公有方法访问私有数据
    void deposit(double amount) { balance_ += amount; }
};
```

| 访问说明符 | 类内部 | 派生类 | 外部代码 |
|-----------|:---:|:---:|:---:|
| `public` | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ❌ |
| `private` | ✅ | ❌ | ❌ |

**设计原则**：数据成员通常设为 `private`，通过 `public` 方法（getter/setter）控制访问——这叫**封装**（Encapsulation）。

### 6. struct vs class

```cpp
// struct 默认访问权限为 public
struct Point {
    double x;  // 默认 public
    double y;
};

// class 默认访问权限为 private
class Circle {
    double radius_;  // 默认 private
public:
    Circle(double r) : radius_(r) {}
    double area() const { return 3.14159 * radius_ * radius_; }
};
```

| 特性 | `struct` | `class` |
|------|---------|---------|
| 默认访问权限 | `public` | `private` |
| 默认继承方式 | `public` | `private` |
| 其他 | 完全相同 | 完全相同 |

**惯例**：`struct` 用于纯数据结构（POD），`class` 用于有封装逻辑的类型。

### 7. 成员变量与成员函数

```cpp
class Counter {
    int count_;              // 非静态成员变量：每个对象各有一份
    static int total_;       // 静态成员变量：所有对象共享一份

public:
    Counter() : count_(0) { ++total_; }

    void increment() {       // 非静态成员函数：操作具体对象
        ++count_;
    }

    int get_count() const {
        return count_;
    }

    static int get_total() { // 静态成员函数：不依赖具体对象
        return total_;
    }
};

int Counter::total_ = 0;    // 静态成员需要在类外定义

int main() {
    Counter c1, c2;
    c1.increment();
    c1.increment();
    std::cout << c1.get_count() << std::endl;     // 2
    std::cout << c2.get_count() << std::endl;     // 0
    std::cout << Counter::get_total() << std::endl;  // 2
}
```

| 类型 | 归属 | 调用方式 |
|------|------|---------|
| 非静态成员变量 | 每个对象独立 | `obj.member` |
| 非静态成员函数 | 操作具体对象 | `obj.method()` |
| 静态成员变量 | 所有对象共享 | `Class::member` |
| 静态成员函数 | 不依赖对象 | `Class::method()` |

### 8. this 指针

每个非静态成员函数都隐含一个 `this` 指针，指向调用该函数的对象：

```cpp
class Chain {
    int value_ = 0;
public:
    Chain& add(int n) {
        this->value_ += n;  // this 指向调用对象
        return *this;       // 返回自身引用，支持链式调用
    }

    void print() const {
        std::cout << value_ << std::endl;
    }
};

int main() {
    Chain c;
    c.add(1).add(2).add(3);  // 链式调用
    c.print();                // 6
}
```

### 9. 对象的创建与销毁

```cpp
#include <iostream>
#include <string>

class Logger {
    std::string name_;
public:
    Logger(std::string name) : name_(std::move(name)) {
        std::cout << name_ << " 创建" << std::endl;
    }
    ~Logger() {
        std::cout << name_ << " 销毁" << std::endl;
    }
};

int main() {
    Logger a("栈对象");
    auto b = std::make_unique<Logger>("堆对象");

    {
        Logger c("块内对象");
    }  // c 在此销毁

    // b 在 main 结束时销毁
    // a 在 main 结束时销毁
}
// 输出：
// 栈对象 创建
// 堆对象 创建
// 块内对象 创建
// 块内对象 销毁
// 堆对象 销毁
// 栈对象 销毁
```

### 10. 极简总结

**类 = 蓝图/模板；对象 = 类的实例 → 封装通过访问控制实现 → struct 默认 public，class 默认 private → 静态成员共享，非静态成员独立 → this 指针指向当前对象 → 构造函数创建，析构函数销毁**
