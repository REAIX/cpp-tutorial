# 什么是构造函数与析构函数
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[继承与多态](../../02-CPP/04-继承与多态.md)、[核心机制](../../02-CPP/05-核心机制.md)、[异常处理](../../02-CPP/07-异常处理.md)、[移动语义](../../02-CPP/09-移动语义与完美转发.md)

> **Constructors build, destructors clean up. Together they form the foundation of RAII.** — 构造函数建造，析构函数清理，两者共同构成 RAII 的基础。

***

### 1. 核心提炼

**构造函数**（Constructor）= 对象创建时自动调用的特殊函数，负责初始化。**析构函数**（Destructor）= 对象销毁时自动调用的特殊函数，负责清理资源。

***

### 2. 生活类比

把对象比作**入住酒店**：

- **构造函数** → 入住登记：拿房卡、录入信息、缴纳押金（初始化资源）
- **析构函数** → 退房结算：归还房卡、检查房间、退还押金（释放资源）

如果你入住不登记（没构造），退房不结算（没析构），酒店就会乱套。

### 3. 构造函数

#### 默认构造函数

不需要参数的构造函数：

```cpp
#include <iostream>
#include <string>

class Box {
    double width_, height_;
public:
    // 默认构造函数
    Box() : width_(1.0), height_(1.0) {
        std::cout << "默认构造: " << width_ << "x" << height_ << std::endl;
    }

    void print() const {
        std::cout << width_ << "x" << height_ << std::endl;
    }
};

int main() {
    Box b1;           // 调用默认构造函数
    Box b2 = Box();   // 同上
    Box b3{};         // 同上（C++11 统一初始化）
}
```

#### 带参数的构造函数

```cpp
class Box {
    double width_, height_;
public:
    // 带参数的构造函数
    Box(double w, double h) : width_(w), height_(h) {
        std::cout << "参数构造: " << width_ << "x" << height_ << std::endl;
    }
};

int main() {
    Box b1(3.0, 4.0);       // 直接调用
    Box b2 = Box(3.0, 4.0); // 同上
    Box b3{3.0, 4.0};       // 统一初始化
}
```

#### 委托构造函数

一个构造函数调用另一个构造函数：

```cpp
class Box {
    double width_, height_;
public:
    Box(double w, double h) : width_(w), height_(h) {
        std::cout << "主构造函数" << std::endl;
    }

    // 委托构造：先调用 Box(1.0, 1.0)
    Box() : Box(1.0, 1.0) {
        std::cout << "委托构造函数" << std::endl;
    }
};
```

### 4. 析构函数

```cpp
#include <iostream>

class FileHandler {
    FILE* file_;
public:
    // 构造函数：打开文件
    FileHandler(const char* path) {
        file_ = fopen(path, "r");
        if (!file_) {
            throw std::runtime_error("无法打开文件");
        }
        std::cout << "文件已打开" << std::endl;
    }

    // 析构函数：关闭文件
    ~FileHandler() {
        if (file_) {
            fclose(file_);
            std::cout << "文件已关闭" << std::endl;
        }
    }

    // 禁止拷贝
    FileHandler(const FileHandler&) = delete;
    FileHandler& operator=(const FileHandler&) = delete;
};

void process() {
    FileHandler fh("data.txt");
    // 使用文件...
    // 函数结束，fh 自动析构，文件自动关闭
    // 即使抛出异常，析构函数也会被调用
}
```

**析构函数的特点**：

| 特性 | 说明 |
|------|------|
| 无参数 | 不能重载 |
| 无返回值 | 不返回任何类型 |
| 每个类只有一个 | 不能重载 |
| 自动调用 | 对象销毁时自动调用 |
| 虚析构函数 | 多态时基类应声明为 `virtual` |

### 5. 构造与析构的调用时机

```cpp
#include <iostream>
#include <memory>

class Obj {
    std::string name_;
public:
    explicit Obj(std::string name) : name_(std::move(name)) {
        std::cout << name_ << " 构造" << std::endl;
    }
    ~Obj() {
        std::cout << name_ << " 析构" << std::endl;
    }
};

Obj global("全局");  // 1. 程序启动前构造

int main() {
    std::cout << "--- main 开始 ---" << std::endl;

    Obj local("局部");                      // 2. 执行到这里构造
    static Obj static_obj("静态局部");       // 3. 首次执行构造
    auto heap = std::make_unique<Obj>("堆"); // 4. make_unique 时构造

    {
        Obj block("块内");                   // 5. 进入块时构造
    }                                        // 6. 块结束时析构

    std::cout << "--- main 结束 ---" << std::endl;
    // 析构顺序：heap → local → static_obj → global
}
```

**构造和析构的顺序**：

| 场景 | 构造顺序 | 析构顺序 |
|------|---------|---------|
| 同一作用域内的对象 | 按定义顺序 | 按定义**逆序** |
| 全局/静态对象 | 按定义顺序 | 按定义**逆序** |
| 成员变量 | 按声明顺序 | 按声明**逆序** |
| 继承体系 | 基类→派生类 | 派生类→基类 |

### 6. 成员初始化列表

```cpp
class Person {
    std::string name_;
    int age_;
    const int id_;       // const 成员必须在初始化列表初始化
    int& ref_;           // 引用成员必须在初始化列表初始化
public:
    // 正确：使用初始化列表
    Person(std::string name, int age, int id, int& ref)
        : name_(std::move(name)), age_(age), id_(id), ref_(ref) {
        std::cout << "Person 构造完成" << std::endl;
    }

    // 错误：不能在函数体内初始化 const 和引用
    // Person(std::string name, int age, int id, int& ref) {
    //     name_ = name;  // 这是赋值，不是初始化
    //     id_ = id;      // 错误！const 不能赋值
    //     ref_ = ref;    // 错误！引用必须初始化
    // }
};
```

**必须用初始化列表的情况**：

| 成员类型 | 原因 |
|---------|------|
| `const` 成员 | 不能赋值，只能初始化 |
| 引用成员 | 必须在创建时绑定 |
| 没有默认构造函数的类成员 | 无法默认构造后再赋值 |
| 基类需要参数 | 必须在初始化列表传参 |

**性能优势**：初始化列表直接构造，函数体内赋值是"先默认构造再赋值"，多一次操作。

### 7. 构造函数与 RAII

构造函数和析构函数是 RAII 的两大支柱：

```cpp
#include <iostream>
#include <mutex>
#include <fstream>
#include <memory>

// RAII 模式：构造获取资源，析构释放资源
class LockGuard {
    std::mutex& mtx_;
public:
    explicit LockGuard(std::mutex& mtx) : mtx_(mtx) {
        mtx_.lock();    // 构造时上锁
        std::cout << "上锁" << std::endl;
    }
    ~LockGuard() {
        mtx_.unlock();  // 析构时解锁
        std::cout << "解锁" << std::endl;
    }
    LockGuard(const LockGuard&) = delete;
    LockGuard& operator=(const LockGuard&) = delete;
};

std::mutex g_mutex;

void safe_function() {
    LockGuard lock(g_mutex);  // 自动上锁
    // 即使这里抛出异常，析构函数也会被调用
    // 不可能忘记解锁
}  // 自动解锁
```

### 8. 虚析构函数

多态场景下，基类的析构函数必须声明为 `virtual`：

```cpp
#include <iostream>

class Base {
public:
    ~Base() { std::cout << "Base 析构" << std::endl; }        // 非虚析构
    // virtual ~Base() { std::cout << "Base 析构" << std::endl; }  // 虚析构
};

class Derived : public Base {
    int* data_;
public:
    Derived() : data_(new int[100]) {}
    ~Derived() {
        delete[] data_;
        std::cout << "Derived 析构" << std::endl;
    }
};

int main() {
    Base* p = new Derived();
    delete p;  // 如果 Base 析构不是 virtual，只调用 Base::~Base()
               // Derived::~Derived() 不会被调用 → data_ 泄漏！
}
```

**规则**：只要类可能被继承，且通过基类指针删除，析构函数就必须是 `virtual`。

### 9. 构造函数类型总结

| 构造函数类型 | 声明 | 用途 |
|------------|------|------|
| 默认构造函数 | `ClassName()` | 无参创建对象 |
| 参数化构造函数 | `ClassName(args)` | 带参创建对象 |
| 拷贝构造函数 | `ClassName(const ClassName&)` | 从已有对象拷贝 |
| 移动构造函数 | `ClassName(ClassName&&)` | 从右值移动资源 |
| 委托构造函数 | `ClassName() : ClassName(args)` | 构造函数复用 |
| 转换构造函数 | `ClassName(OtherType)` | 隐式类型转换 |

### 10. 极简总结

**构造函数 = 对象创建时初始化；析构函数 = 对象销毁时清理 → 两者构成 RAII 基础 → 初始化列表比函数体内赋值更高效 → 多态基类析构必须 virtual → 构造顺序=定义顺序，析构顺序=逆序 → 析构函数即使异常也会被调用**
