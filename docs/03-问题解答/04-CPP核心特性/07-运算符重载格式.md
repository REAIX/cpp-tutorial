# 运算符重载语法格式
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[继承与多态](../../02-CPP/04-继承与多态.md)、[核心机制](../../02-CPP/05-核心机制.md)、[异常处理](../../02-CPP/07-异常处理.md)、[移动语义](../../02-CPP/09-移动语义与完美转发.md)

### 1. 一句话结论

**运算符重载 = 给自定义类型（类/结构体）赋予运算符能力，让对象可以像内置类型一样使用 `+`、`-`、`*`、`[]` 等运算符。**

***

### 2. 基本语法结构

#### 1. 核心语法公式

```cpp
返回类型 operator运算符符号(参数列表) {
    // 实现逻辑
}
```

#### 2. 两种形式对比

| 形式 | 语法 | 特点 |
|:----:|------|------|
| **成员函数** | `ReturnType operator@(参数)` | 左操作数是当前对象（`this`） |
| **友元/全局函数** | `ReturnType operator@(左参, 右参)` | 左右操作数都是显式参数 |

***

### 3. 成员函数形式（最常用）

```cpp
class Complex {
private:
    double real, imag;

public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // ===== 一元运算符 =====

    // 正号 +x
    Complex operator+() const {
        return *this;  // 返回自身副本
    }

    // 负号 -x
    Complex operator-() const {
        return {-real, -imag};
    }

    // 前置 ++x
    Complex& operator++() {
        ++real;
        ++imag;
        return *this;  // 返回引用
    }

    // 后置 x++（int 是哑元，区分前置/后置）
    Complex operator++(int) {
        Complex temp = *this;
        ++real;
        ++imag;
        return temp;   // 返回旧值（值拷贝）
    }

    // ===== 二元运算符 =====

    // 加法 a + b
    Complex operator+(const Complex& other) const {
        return {real + other.real, imag + other.imag};
    }

    // 减法 a - b
    Complex operator-(const Complex& other) const {
        return {real - other.real, imag - other.imag};
    }

    // 乘法 a * b
    Complex operator*(const Complex& other) const {
        return {
            real * other.real - imag * other.imag,
            real * other.imag + imag * other.real
        };
    }

    // 复合赋值 += （必须返回引用！）
    Complex& operator+=(const Complex& other) {
        real += other.real;
        imag += other.imag;
        return *this;
    }

    // ===== 比较运算符 =====
    bool operator==(const Complex& other) const {
        return (real == other.real) && (imag == other.imag);
    }

    bool operator!=(const Complex& other) const {
        return !(*this == other);  // 复用 ==
    }

    // ===== 下标运算符 =====
    double& operator[](int index) {
        if (index == 0) return real;
        if (index == 1) return imag;
        throw std::out_of_range("Index must be 0 or 1");
    }

    // const 版本
    const double& operator[](int index) const {
        if (index == 0) return real;
        if (index == 1) return imag;
        throw std::out_of_range("Index must be 0 or 1");
    }

    // ===== 函数调用运算符 () =====
    double operator()(double x) const {
        return real * x + imag;
    }
};
```

### 4. 友元函数形式（推荐用于对称运算符）

```cpp
class Vector2D {
public:
    double x, y;

    Vector2D(double x_ = 0, double y_ = 0) : x(x_), y(y_) {}

    // 输出流 << （必须是友元，左操作数是 ostream）
    friend std::ostream& operator<<(std::ostream& os, const Vector2D& v) {
        os << "(" << v.x << ", " << v.y << ")";
        return os;
    }

    // 输入流 >>
    friend std::istream& operator>>(std::istream& is, Vector2D& v) {
        is >> v.x >> v.y;
        return is;
    }
};

// 全局友元：左操作数不是类对象的情况
// 例如：5 + complex （数字在左边）
Complex operator+(double d, const Complex& c) {
    return Complex(d + c.real, c.imag);
}
```

### 5. 可重载的运算符完整列表

#### 1. 算术运算符

| 运算符 | 成员函数签名 | 友元函数签名 | 说明 |
|:------:|-------------|-------------|------|
| **一元 `+`** | `T operator+() const` | `T operator+(const T&)` | 取正 |
| **一元 `-`** | `T operator-() const` | `T operator-(const T&)` | 取负 |
| **`+`** | `T operator+(const T&) const` | `T operator+(const T&, const T&)` | 加法 |
| **`-`** | `T operator-(const T&) const` | `T operator-(const T&, const T&)` | 减法 |
| **`*`** | `T operator*(const T&) const` | `T operator*(const T&, const T&)` | 乘法 |
| **`/`** | `T operator/(const T&) const` | `T operator/(const T&, const T&)` | 除法 |
| **`%`** | `T operator%(const T&) const` | `T operator%(const T&, const T&)` | 取模 |

#### 2. 自增/自减运算符（重点！）

| 运算符 | 签名 | 返回类型 | 说明 |
|:------:|------|---------|------|
| **`++x`（前置）** | `T& operator++()` | `T&` 引用 | 先增后用，返回自身 |
| **`x++`（后置）** | `T operator++(int)` | `T` 值 | 用后增，返回旧值 |
| **`--x`（前置）** | `T& operator--()` | `T&` 引用 | 同上 |
| **`x--`（后置）** | `T operator--(int)` | `T` 值 | 同上 |

**关键区别**：后置版本的 `(int)` 参数是**哑元（dummy parameter）**，仅用于和前置版本区分，没有实际用途。

#### 3. 比较运算符

| 运算符 | 签名 | 返回类型 |
|:------:|------|--------|
| **`==`** | `bool operator==(const T&) const` | `bool` |
| **`!=`** | `bool operator!=(const T&) const` | `bool` |
| **`<`** | `bool operator<(const T&) const` | `bool` |
| **`>`** | `bool operator>(const T&) const` | `bool` |
| **`<=`** | `bool operator<=(const T&) const` | `bool` |
| **`>=`** | `bool operator>=(const T&) const` | `bool` |
| **`<=>`（C++20）** | `auto operator<=>(const T&) const` | 比较类别 |

#### 4. 逻辑与位运算符

| 运算符 | 签名 | 说明 |
|:------:|------|------|
| **`!`** | `bool operator!() const` | 逻辑非 |
| **`&&`** | `bool operator&&(const T&) const` | 逻辑与 |
| **`\|\|`** | `bool operator\|\|(const T&) const` | 逻辑或 |
| **`~`** | `T operator~() const` | 按位取反 |
| **`&`** | `T operator&(const T&) const` | 按位与 |
| **`\|`** | `T operator\|(const T&) const` | 按位或 |
| **`^`** | `T operator^(const T&) const` | 按位异或 |
| **`<<`** | `T operator<<(int) const` | 左移 |
| **`>>`** | `T operator>>(int) const` | 右移 |

#### 5. 赋值运算符（必须返回引用！⭐）

| 运算符 | 签名 | 必须返回 |
|:------:|------|--------|
| **`=`** | `T& operator=(const T&)` | `T&` 引用 |
| **`+=`** | `T& operator+=(const T&)` | `T&` 引用 |
| **`-=`** | `T& operator-=(const T&)` | `T&` 引用 |
| **`*=`** | `T& operator*=(const T&)` | `T&` 引用 |
| **`/=`** | `T& operator/=(const T&)` | `T&` 引用 |
| **`%=`** | `T& operator%=(const T&)` | `T&` 引用 |
| **`&=`** | `T& operator&=(const T&)` | `T&` 引用 |
| **`\|=`** | `T& operator\|=(const T&)` | `T&` 引用 |
| **`^=`** | `T& operator^=(const T&)` | `T&` 引用 |
| **`<<=`** | `T& operator<<=(int)` | `T&` 引用 |
| **`>>=`** | `T& operator>>=(int)` | `T&` 引用 |

#### 6. 下标与访问运算符

| 运算符 | 签名 | 说明 |
|:------:|------|------|
| **`[]`** | `T& operator[](size_t)` / `const T& operator[](size_t) const` | 下标访问 |
| **`->`** | `T* operator->()` | 智能指针解引用 |
| **`*`**（解引用） | `T& operator*() const` | 迭代器取值 |
| **`()`** | `Ret operator()(Args...)` | 函数对象（仿函数） |

#### 7. 内存管理运算符

```cpp
// new/delete 重载（必须是静态成员函数）
void* operator new(size_t size);
void operator delete(void* ptr) noexcept;
void* operator new[](size_t size);
void operator delete[](void* ptr) noexcept;
```

#### 8. 类型转换运算符

```cpp
// 转换为其他类型
explicit operator int() const;       // 转为 int
operator double() const;             // 转为 double
operator bool() const;               // 转为 bool
```

***

### 6. 不可重载的运算符

| 运算符 | 原因 |
|:------:|------|
| **`.`** (成员访问) | 语法核心，不能修改 |
| **`.*`** (成员指针访问) | 同上 |
| **`::`** (作用域解析) | 同上 |
| **`?:`** (三元条件运算符) | 不允许重载 |
| **`sizeof`** | 编译期计算，非表达式 |
| **`typeid`** | 运行时类型信息关键字 |
| **`static_cast` 等** | 强制转换关键字组 |

### 7. 选择成员 vs 友元的规则

#### 1. 使用成员函数的场景

```cpp
// 1. 修改左操作数（this）的：赋值、复合赋值、自增自减
MyClass& operator=(const MyClass&);
MyClass& operator+=(const MyClass&);
MyClass& operator++();          // 前置

// 2. 一元运算符
MyClass operator-() const;

// 3. 下标、调用、解引用、箭头
T& operator[](int);
Ret operator()(Args...);
T& operator*();
T* operator->();
```

#### 2. 使用友元函数的场景

```cpp
// 1. 需要左操作数类型转换的（保证对称性 a+b 和 b+a 都能用）
friend Vector operator*(double, const Vector&);

// 2. 流插入/提取（左操作数是 stream 对象）
friend ostream& operator<<(ostream&, const T&);
friend istream& operator>>(istream&, T&);

// 3. 两个不同类型对象的运算
friend Result operator+(const A&, const B&);
```

#### 3. 选择决策图

```
需要重载运算符？
    │
    ├── 是赋值/复合赋值/++--？ → 成员函数（返回引用）
    │
    ├── 是一元运算符？         → 成员函数
    │
    ├── 是 [] / () / * / -> ？ → 成员函数
    │
    ├── 左操作数可能是其他类型？→ 友元函数
    │
    └── 流运算符 << >> ？      → 友元函数（必须是！）
```

### 8. C++20 三路比较运算符 `<=>`

```cpp
class Point {
public:
    int x, y;

    // C++20：一行代码自动生成所有比较运算符！
    auto operator<=>(const Point&) const = default;
};

// 编译器自动生成：==, !=, <, >, <=, >=
Point p1{1, 2}, p2{3, 4};
if (p1 < p2) { ... }   // OK
if (p1 == p2) { ... }  // OK
if (p1 >= p2) { ... }  // OK
```

**三路比较返回值**：

| 返回值 | 含义 |
|:------:|------|
| `std::strong_ordering::less` | 小于 |
| `std::strong_ordering::equal` | 等于 |
| `std::strong_ordering::greater` | 大于 |

还有 `std::partial_ordering`（可比较 NaN）、`std::weak_ordering`（等价但不可替换）。

### 9. 完整可运行示例

```cpp
#include <iostream>
#include <stdexcept>

class Fraction {
private:
    int numerator;
    int denominator;

    void reduce() {
        int gcd_val = std::gcd(numerator, denominator);
        numerator /= gcd_val;
        denominator /= gcd_val;

        if (denominator < 0) {
            numerator = -numerator;
            denominator = -denominator;
        }
    }

public:
    Fraction(int num = 0, int den = 1)
        : numerator(num), denominator(den) {
        if (den == 0) throw std::invalid_argument("Denominator cannot be zero");
        reduce();
    }

    // ===== 算术运算符 =====
    Fraction operator+(const Fraction& other) const {
        return {
            numerator * other.denominator + other.numerator * denominator,
            denominator * other.denominator
        };
    }

    Fraction operator-(const Fraction& other) const {
        return {
            numerator * other.denominator - other.numerator * denominator,
            denominator * other.denominator
        };
    }

    Fraction operator*(const Fraction& other) const {
        return {numerator * other.numerator, denominator * other.denominator};
    }

    Fraction operator/(const Fraction& other) const {
        return {numerator * other.denominator, denominator * other.numerator};
    }

    // ===== 复合赋值（返回引用！）=====
    Fraction& operator+=(const Fraction& other) {
        *this = *this + other;
        return *this;
    }

    // ===== 自增自减 =====
    Fraction& operator++() {       // 前置 ++f
        numerator += denominator;
        reduce();
        return *this;
    }

    Fraction operator++(int) {     // 后置 f++
        Fraction temp = *this;
        ++(*this);
        return temp;
    }

    // ===== 比较运算符 =====
    bool operator==(const Fraction& other) const {
        return numerator == other.numerator && denominator == other.denominator;
    }

    auto operator<=>(const Fraction& other) const = default;  // C++20

    // ===== 一元运算符 =====
    Fraction operator+() const { return *this; }
    Fraction operator-() const { return {-numerator, denominator}; }
    bool operator!() const { return numerator == 0; }

    // ===== 流运算符（友元）=====
    friend std::ostream& operator<<(std::ostream& os, const Fraction& f) {
        os << f.numerator;
        if (f.denominator != 1) os << "/" << f.denominator;
        return os;
    }

    friend std::istream& operator>>(std::istream& is, Fraction& f) {
        char sep;
        is >> f.numerator >> sep >> f.denominator;
        f.reduce();
        return is;
    }

    // ===== 类型转换 =====
    explicit operator double() const {
        return static_cast<double>(numerator) / denominator;
    }
};

int main() {
    Fraction a(1, 2), b(1, 3), c;

    c = a + b;          // 1/2 + 1/3 = 5/6
    std::cout << a << " + " << b << " = " << c << "\n";

    c = a * b;          // 1/2 * 1/3 = 1/6
    std::cout << a << " * " << b << " = " << c << "\n";

    c = -a;             // -1/2
    std::cout << "-" << a << " = " << c << "\n";

    ++c;                // 1/2
    std::cout << "++" << (-a) << " = " << c << "\n";

    if (a > b) std::cout << a << " > " << b << "\n";  // C++20

    double d = static_cast<double>(a);  // 0.5
    std::cout << a << " = " << d << "\n";

    return 0;
}
```

### 10. 关键规则总结

| 规则 | 说明 |
|:----:|------|
| **返回引用** | 赋值、复合赋值、前置++/-- 必须返回 `T&` |
| **const 正确性** | 不修改对象的运算符加 `const` |
| **哑元参数** | 后置 `++/--` 用 `(int)` 区分前置 |
| **对称性** | `a+b` 和 `b+a` 都要能工作 → 用友元 |
| **异常安全** | 确保强异常安全（先计算再赋值） |
| **C++20** | 用 `<=>` + `= default` 自动生成所有比较运算符 |
| **流运算符** | `<<` `>>` 必须是友元函数（左操作数是 stream） |

***

### 11. 极简口诀

**成员函数改自己，友元函数连两边**
**赋值返回要引用，后置++加个int**
**流运算符必友元，C++20 <=> 一行全**
