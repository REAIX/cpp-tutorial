# C++ 四种类型转换
> 📖 相关章节：[核心机制](../../02-CPP/05-核心机制.md)

> "Cast with intention, not by accident" — 有意转换，勿凭偶然

### 1. 核心要义

C++ 提供四种具名类型转换：**static_cast**（常规转换）、**dynamic_cast**（安全向下转型）、**reinterpret_cast**（位模式重解释）、**const_cast**（去除 const）。四种转换各有明确用途，取代了 C 风格的暴力转换。

***

### 2. 四种转换一览

| 转换 | 用途 | 安全性 | 运行时检查 | 典型场景 |
|------|------|:---:|:---:|------|
| static_cast | 相关类型间的转换 | 中 | 无 | 数值转换、向上转型、void* 转换 |
| dynamic_cast | 多态向下转型 | 高 | 有（RTTI） | 基类指针转派生类指针 |
| reinterpret_cast | 底层位重解释 | 低 | 无 | 指针与整数互转、序列化 |
| const_cast | 去除/添加 const/volatile | 中 | 无 | 调用 const-incorrect 的旧接口 |

**选择优先级**：static_cast > dynamic_cast > const_cast > reinterpret_cast（越往后越危险）。

### 3. static_cast 详解

`static_cast` 是最常用的转换，用于编译期可确定安全性的相关类型之间的转换。

**适用场景**：

```cpp
// 1. 基本类型转换
double d = 3.14159;
int i = static_cast<int>(d);          // double → int，可能丢失精度

// 2. 向上转型（安全，派生类→基类）
Derived derived;
Base* base = static_cast<Base*>(&derived);
Base& ref = static_cast<Base&>(derived);

// 3. 向下转型（不安全，程序员自己保证）
Base* base = getBase();               // 可能指向 Derived，也可能不是
Derived* d = static_cast<Derived*>(base);  // 不检查，如果 base 不是 Derived 则 UB

// 4. void* 与其他指针类型互转
int value = 42;
void* vp = static_cast<void*>(&value);
int* ip = static_cast<int*>(vp);

// 5. 枚举与整数互转
enum class Color { Red, Green, Blue };
int n = static_cast<int>(Color::Red);  // 枚举 → 整数
Color c = static_cast<Color>(1);       // 整数 → 枚举（不检查范围）
```

**不能做的事**：

```cpp
// 不能去除 const
const int* cp = &value;
int* p = static_cast<int*>(cp);       // 编译错误！

// 不能在不相关类型间转换
struct A { int x; };
struct B { int x; };
A a;
B* b = static_cast<B*>(&a);           // 编译错误！类型不相关

// 不能转换指针到不同大小的整数
int* p = nullptr;
char c = static_cast<char>(p);        // 编译错误！
```

### 4. dynamic_cast 详解

`dynamic_cast` 利用 RTTI（运行时类型信息）进行安全的向下转型和交叉转型。

**前提条件**：基类必须有虚函数（需要 RTTI 支持）。

**指针版本**：转型失败返回 `nullptr`。

```cpp
class Animal {
public:
    virtual ~Animal() = default;
    virtual void speak() = 0;
};

class Dog : public Animal {
public:
    void speak() override { cout << "Woof"; }
    void fetch() { cout << "Fetch!"; }
};

class Cat : public Animal {
public:
    void speak() override { cout << "Meow"; }
    void purr() { cout << "Purr..."; }
};

// 安全向下转型
Animal* a = new Dog();
Dog* d = dynamic_cast<Dog*>(a);
if (d != nullptr) {
    d->fetch();                        // 安全，转型成功
}

Cat* c = dynamic_cast<Cat*>(a);
if (c == nullptr) {
    cout << "不是 Cat";                // 正确判断
}
```

**引用版本**：转型失败抛出 `std::bad_cast`。

```cpp
try {
    Dog& d = dynamic_cast<Dog&>(*a);   // 如果 a 不是 Dog，抛异常
    d.fetch();
} catch (const std::bad_cast& e) {
    cout << "转型失败: " << e.what();
}
```

**交叉转型（cross-cast）**：

```cpp
class Flyable {
public:
    virtual void fly() = 0;
    virtual ~Flyable() = default;
};

class Bat : public Animal, public Flyable {
public:
    void speak() override { cout << "Squeak"; }
    void fly() override { cout << "Fly!"; }
};

Animal* a = new Bat();
Flyable* f = dynamic_cast<Flyable*>(a);  // 交叉转型：Animal* → Flyable*
if (f) f->fly();
```

### 5. reinterpret_cast 详解

`reinterpret_cast` 对数据的位模式进行重新解释，是最危险的转换。

**适用场景（极少使用）**：

```cpp
// 1. 指针与足够大的整数互转（序列化、硬件地址）
uintptr_t addr = reinterpret_cast<uintptr_t>(ptr);
int* restored = reinterpret_cast<int*>(addr);

// 2. 不相关指针类型转换（网络协议、二进制解析）
char buffer[4] = {0x01, 0x02, 0x03, 0x04};
int32_t* val = reinterpret_cast<int32_t*>(buffer);  // 注意对齐问题！

// 3. 函数指针类型转换（极罕见，回调机制）
typedef void (*Callback)(int);
void myHandler(void* data) { /* ... */ }
Callback cb = reinterpret_cast<Callback>(myHandler);  // 实现定义行为
```

**常见陷阱**：

```cpp
// 陷阱1：对齐问题
char buf[5];                           // 可能未对齐到 4 字节
int* p = reinterpret_cast<int*>(buf);  // 可能导致硬件异常

// 陷阱2：类型双关（Type Punning）— 未定义行为
float f = 1.0f;
int& i = reinterpret_cast<int&>(f);    // UB！应用 memcpy 替代
// 正确做法：
int32_t bits;
std::memcpy(&bits, &f, sizeof(f));     // 合法且编译器会优化

// 陷阱3：不相关类型转换后使用
struct A { int x; };
struct B { double y; };
A a{42};
B& b = reinterpret_cast<B&>(a);        // 访问 b.y 是 UB
```

### 6. const_cast 详解

`const_cast` 是唯一能去除或添加 `const`/`volatile` 限定符的转换。

**合法使用场景**：

```cpp
// 场景1：调用 const-incorrect 的旧接口
void legacyFunc(int* p);               // 旧接口，不修改数据但参数不是 const

void safeWrapper(const int* p) {
    legacyFunc(const_cast<int*>(p));    // 安全：legacyFunc 不修改数据
}

// 场景2：实现 const 和非 const 重载，避免代码重复
class String {
    char* data_;
public:
    // const 版本
    const char& operator[](size_t i) const {
        // ... 边界检查等逻辑
        return data_[i];
    }
    // 非 const 版本调用 const 版本，避免重复
    char& operator[](size_t i) {
        return const_cast<char&>(
            static_cast<const String&>(*this)[i]
        );
    }
};
```

**未定义行为**：

```cpp
// 原对象是 const → 去掉 const 后修改 = UB
const int cx = 10;
int& r = const_cast<int&>(cx);
r = 20;                                // 未定义行为！cx 在只读段可能崩溃

// 原对象不是 const → 去掉 const 后修改 = 合法
int x = 10;
const int& cr = x;                     // cr 是 const 引用，但 x 本身不是 const
int& r = const_cast<int&>(cr);
r = 20;                                // 合法，x 变为 20
```

### 7. 为什么不用 C 风格转换

C 风格转换 `(Type)value` 等价于依次尝试 `const_cast`、`static_cast`、`static_cast + const_cast`、`reinterpret_cast`、`reinterpret_cast + const_cast`，取第一个能编译的。

```cpp
// C 风格：什么都能转，意图不明确
int* p = (int*)double_ptr;             // 可能是 reinterpret_cast
const int* cp = &value;
int* mp = (int*)cp;                    // 隐含 const_cast，危险！

// C++ 风格：意图明确，编译器检查
int* p = static_cast<int*>(void_ptr);  // 只能做合理的转换
// int* mp = static_cast<int*>(cp);    // 编译错误！必须显式 const_cast
int* mp = const_cast<int*>(cp);        // 意图明确：就是要去 const
```

**C 风格转换的问题**：

| 问题 | 说明 |
|------|------|
| 意图不明 | 无法区分是数值转换还是位重解释 |
| 隐含 const_cast | 可能意外去掉 const 而不自知 |
| 难以搜索 | `(int*)` 在代码中难以 grep |
| 无安全检查 | 编译器无法对暴力转换发出警告 |

### 8. 四种转换的安全等级

| 安全等级 | 转换 | 说明 |
|:---:|------|------|
| 高 | dynamic_cast | 运行时类型检查，失败有明确信号 |
| 中 | static_cast | 编译期检查类型相关性，但不检查运行时正确性 |
| 中 | const_cast | 只修改 cv 限定符，不改变类型，但误用导致 UB |
| 低 | reinterpret_cast | 几乎无检查，完全依赖程序员保证正确性 |

### 9. 常见误用与最佳实践

**误用1：用 static_cast 做向下转型**

```cpp
// 危险：如果 base 实际不是 Derived，UB
Base* base = getUnknownAnimal();
Derived* d = static_cast<Derived*>(base);  // 不安全！

// 正确：需要运行时检查时用 dynamic_cast
Derived* d = dynamic_cast<Derived*>(base);
if (d) { /* 安全使用 */ }
```

**误用2：用 reinterpret_cast 做类型双关**

```cpp
// 危险：违反严格别名规则
float f = 1.0f;
int i = reinterpret_cast<int&>(f);  // UB

// 正确：使用 memcpy
int bits;
std::memcpy(&bits, &f, sizeof(f));
```

**误用3：用 const_cast 修改原本 const 的对象**

```cpp
// 危险：修改原本 const 的对象是 UB
const std::string& getName() const;
std::string& name = const_cast<std::string&>(getName());
name = "hacked";                       // 如果原对象是 const，UB
```

**最佳实践**：

1. 优先使用 `static_cast`，它最安全
2. 向下转型必须用 `dynamic_cast`，不要用 `static_cast`
3. `reinterpret_cast` 只用于底层硬件/序列化，加注释说明原因
4. `const_cast` 只用于对接 const-incorrect 的旧接口
5. 禁止使用 C 风格转换
6. 如果频繁需要 `dynamic_cast`，说明设计有问题，考虑重构为多态

### 10. 完整示例：类型转换实战

```cpp
#include <iostream>
#include <cstring>
using namespace std;

// === 场景：图形编辑器中的类型转换 ===

class Shape {
public:
    virtual ~Shape() = default;
    virtual void draw() const = 0;
    virtual double area() const = 0;
};

class Circle : public Shape {
    double radius_;
public:
    Circle(double r) : radius_(r) {}
    void draw() const override { cout << "Circle(r=" << radius_ << ")\n"; }
    double area() const override { return 3.14159 * radius_ * radius_; }
    double getRadius() const { return radius_; }
};

class Rectangle : public Shape {
    double w_, h_;
public:
    Rectangle(double w, double h) : w_(w), h_(h) {}
    void draw() const override { cout << "Rectangle(" << w_ << "x" << h_ << ")\n"; }
    double area() const override { return w_ * h_; }
    double getWidth() const { return w_; }
};

// 正确：使用 dynamic_cast 安全向下转型
void scaleCircle(Shape* shape, double factor) {
    Circle* c = dynamic_cast<Circle*>(shape);
    if (c) {
        cout << "Scaling circle, old radius: " << c->getRadius() << "\n";
        // *c = Circle(c->getRadius() * factor);  // 实际修改
    } else {
        cout << "Not a circle!\n";
    }
}

// 正确：const_cast 用于消除 const 重载的代码重复
class ShapeProcessor {
public:
    Shape* findLargest(Shape** shapes, size_t n) {
        return const_cast<Shape*>(
            static_cast<const ShapeProcessor*>(this)->findLargest(shapes, n)
        );
    }

    const Shape* findLargest(Shape* const* shapes, size_t n) const {
        const Shape* largest = shapes[0];
        for (size_t i = 1; i < n; ++i) {
            if (shapes[i]->area() > largest->area())
                largest = shapes[i];
        }
        return largest;
    }
};

int main() {
    // static_cast：数值转换
    double pi = 3.14159;
    int approx = static_cast<int>(pi);
    cout << "pi as int: " << approx << "\n";

    // dynamic_cast：安全向下转型
    Shape* shapes[] = {
        new Circle(5.0),
        new Rectangle(3.0, 4.0)
    };

    for (auto s : shapes) {
        s->draw();
        Circle* c = dynamic_cast<Circle*>(s);
        if (c) cout << "  radius = " << c->getRadius() << "\n";
    }

    scaleCircle(shapes[0], 2.0);   // 是 Circle
    scaleCircle(shapes[1], 2.0);   // 不是 Circle

    // reinterpret_cast：序列化（谨慎使用）
    double value = 3.14;
    char bytes[sizeof(double)];
    std::memcpy(bytes, &value, sizeof(double));  // 正确做法，不用 reinterpret_cast

    // const_cast：对接旧接口
    const Shape* cs = shapes[0];
    // Shape* ns = static_cast<Shape*>(cs);     // 编译错误
    Shape* ns = const_cast<Shape*>(cs);         // 编译通过，但修改是 UB
    ns->draw();                                  // 只读操作，安全

    for (auto s : shapes) delete s;
    return 0;
}
```

### 11. 极简总结

**static_cast 常规转换 | dynamic_cast 安全向下（需虚函数）| reinterpret_cast 底层重解释（极危险）| const_cast 去 const（改原 const 对象是 UB）| 禁用 C 风格转换**
