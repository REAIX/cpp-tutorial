# 动态绑定与静态绑定
> 📖 相关章节：[继承与多态](../../02-CPP/04-继承与多态.md)

### 1. 先抓核心

**静态绑定**（早绑定）= 编译期确定调用哪个函数；**动态绑定**（晚绑定）= 运行时通过虚函数表确定调用哪个函数。**虚函数 = 动态绑定，非虚函数 = 静态绑定**。

***

### 2. 静态绑定原理

静态绑定在编译期就确定了要调用的函数地址，直接生成调用指令，无需运行时查找。

```cpp
class Base {
public:
    void foo() { cout << "Base::foo" << endl; }  // 非虚函数
    void bar() { cout << "Base::bar" << endl; }
};

class Derived : public Base {
public:
    void foo() { cout << "Derived::foo" << endl; }  // 隐藏，不是覆盖
    void bar() { cout << "Derived::bar" << endl; }
};

Base* p = new Derived();
p->foo();  // 输出 "Base::foo"（静态绑定，看指针类型 Base*）
p->bar();  // 输出 "Base::bar"（静态绑定，看指针类型 Base*）

Derived d;
d.foo();   // 输出 "Derived::foo"（静态绑定，看对象类型 Derived）
```

**编译器做了什么**：

```cpp
// p->foo() 编译后大致等价于：
Base::foo(p);  // 直接调用 Base::foo 的地址，没有查表过程

// 对应汇编（简化）：
// call Base::foo    ; 直接调用，地址在编译期确定
```

**静态绑定的特点**：

| 特性 | 说明 |
|------|------|
| 绑定时机 | 编译期 |
| 决定依据 | 指针/引用的静态类型 |
| 调用方式 | 直接调用函数地址 |
| 性能 | 最快，无额外开销 |
| 灵活性 | 低，无法实现多态 |

### 3. 动态绑定原理

动态绑定通过虚函数表（vtable）在运行时确定调用哪个函数。

```cpp
class Base {
public:
    virtual void foo() { cout << "Base::foo" << endl; }  // 虚函数
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void foo() override { cout << "Derived::foo" << endl; }
};

Base* p = new Derived();
p->foo();  // 输出 "Derived::foo"（动态绑定，看实际对象类型）
```

**编译器做了什么**：

```cpp
// p->foo() 编译后大致等价于：
// 1. 通过 p 找到 vptr
// 2. 通过 vptr 找到 vtable
// 3. 从 vtable 中取出 foo 的函数指针
// 4. 调用该函数指针

// 对应汇编（简化）：
// mov rax, [p]          ; 取对象地址
// mov rax, [rax]        ; 取 vptr（指向 vtable）
// call [rax + offset]   ; 通过 vtable 偏移调用 foo
```

**虚函数表机制详解**：

```
编译器为每个含虚函数的类生成一张 vtable：

Base vtable:              Derived vtable:
+------------------+     +------------------+
| Base::foo        |     | Derived::foo     |
| Base::~Base      |     | Derived::~Derived|
+------------------+     +------------------+

每个对象内部存一个 vptr 指向所属类的 vtable：

Derived 对象：
+------------------+
| vptr ──────────────→ Derived vtable
+------------------+
| Derived 成员     |
+------------------+
```

### 4. 绑定时机对比

| 特性 | 静态绑定 | 动态绑定 |
|------|:---:|:---:|
| 绑定时机 | 编译期 | 运行时 |
| 决定依据 | 指针/引用的静态类型 | 实际对象的动态类型 |
| 触发条件 | 非虚函数 | 虚函数 |
| 调用方式 | 直接调用（call 地址） | 间接调用（vptr→vtable→函数指针） |
| 性能 | 最快 | 稍慢（一次间接寻址） |
| 内联可能性 | 高 | 低（编译期无法确定目标） |
| 灵活性 | 低 | 高 |

**一个对象两种绑定**：

```cpp
class Base {
public:
    virtual void virtualFunc() { cout << "Base::virtual" << endl; }
    void normalFunc() { cout << "Base::normal" << endl; }
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void virtualFunc() override { cout << "Derived::virtual" << endl; }
    void normalFunc() { cout << "Derived::normal" << endl; }
};

Base* p = new Derived();
p->virtualFunc();  // 动态绑定 → "Derived::virtual"
p->normalFunc();   // 静态绑定 → "Base::normal"

// 同一个对象，同一个指针，两种绑定行为！
```

### 5. 动态绑定的触发条件

动态绑定只在通过指针或引用调用虚函数时发生。

```cpp
class Base {
public:
    virtual void foo() { cout << "Base::foo" << endl; }
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void foo() override { cout << "Derived::foo" << endl; }
};

Derived d;

// 1. 通过指针调用虚函数 → 动态绑定
Base* p = &d;
p->foo();  // "Derived::foo" ✓ 动态绑定

// 2. 通过引用调用虚函数 → 动态绑定
Base& r = d;
r.foo();   // "Derived::foo" ✓ 动态绑定

// 3. 通过对象调用虚函数 → 静态绑定（对象切片）
Base obj = d;
obj.foo(); // "Base::foo" ✗ 对象切片，无多态

// 4. 在构造/析构函数中调用虚函数 → 静态绑定
Base::Base() {
    foo();  // 调用 Base::foo，不是 Derived::foo！
}
```

**构造/析构中的虚函数陷阱**：

```cpp
class Base {
public:
    Base() { foo(); }                    // 调用 Base::foo
    virtual void foo() { cout << "Base::foo\n"; }
    virtual ~Base() { foo(); }           // 调用 Base::foo
};

class Derived : public Base {
public:
    Derived() : Base() {}                // Base 构造时，Derived 还没构造
    void foo() override { cout << "Derived::foo\n"; }
    ~Derived() {}                        // Base 析构时，Derived 已析构
};

Derived d;
// 构造时输出: "Base::foo"（不是 "Derived::foo"！）
// 析构时输出: "Base::foo"（不是 "Derived::foo"！）

// 原因：构造 Base 时，vptr 指向 Base 的 vtable
//       析构 Base 时，vptr 已恢复为 Base 的 vtable
```

### 6. 性能对比

**虚函数调用的开销**：

| 开销项 | 说明 | 量级 |
|--------|------|------|
| 间接寻址 | vptr→vtable→函数指针 | ~1-2 条额外指令 |
| 指令缓存 | 间接跳转可能破坏流水线 | ~2-10 个时钟周期 |
| 内联失败 | 编译器通常无法内联虚函数 | 可能损失更多优化 |
| 对象大小 | 每个对象多一个 vptr | 8 字节（64位） |

**基准测试示意**：

```cpp
// 静态绑定：非虚函数
class StaticBase {
public:
    int compute(int x) { return x * x; }  // 可内联
};

// 动态绑定：虚函数
class DynamicBase {
public:
    virtual int compute(int x) { return x * x; }  // 通常不可内联
};

// 在热循环中：
// StaticBase::compute  →  内联后约 1 个时钟周期
// DynamicBase::compute →  约 3-10 个时钟周期（间接调用 + 可能的缓存未命中）
```

**何时需要关心**：绝大多数场景下虚函数的开销可以忽略，只有在极热路径（每秒百万次调用）中才需要优化。

### 7. CRTP 静态多态

CRTP（Curiously Recurring Template Pattern）可以在编译期实现多态，零运行时开销。

```cpp
// CRTP 模式
template <typename Derived>
class Base {
public:
    void interface() {
        static_cast<Derived*>(this)->implementation();  // 静态绑定
    }
};

class ConcreteA : public Base<ConcreteA> {
public:
    void implementation() { cout << "ConcreteA" << endl; }
};

class ConcreteB : public Base<ConcreteB> {
public:
    void implementation() { cout << "ConcreteB" << endl; }
};

ConcreteA a;
a.interface();  // 静态绑定，调用 ConcreteA::implementation，可内联
```

**CRTP vs 虚函数对比**：

| 特性 | 虚函数 | CRTP |
|------|:---:|:---:|
| 绑定时机 | 运行时 | 编译期 |
| 性能开销 | 间接调用 | 零（可内联） |
| 对象大小 | 多一个 vptr | 无额外开销 |
| 异构容器 | 支持 | 不支持（类型不同） |
| 代码膨胀 | 无 | 有（每个派生类生成一份） |
| 灵活性 | 高 | 低 |

**CRTP 的局限**：

```cpp
// 虚函数：可以放在同一个容器中
vector<unique_ptr<Base>> objects;  // Base 是虚基类
objects.push_back(make_unique<ConcreteA>());
objects.push_back(make_unique<ConcreteB>());

// CRTP：不能放在同一个容器中（类型不同）
// vector<???> objects;  // Base<ConcreteA> 和 Base<ConcreteB> 是不同类型
// 无法统一存储
```

### 8. 何时用静态绑定，何时用动态绑定

**决策指南**：

| 场景 | 推荐 | 原因 |
|------|------|------|
| 需要运行时多态 | 虚函数（动态绑定） | 根据实际类型调用 |
| 不需要多态 | 非虚函数（静态绑定） | 更快，可内联 |
| 编译期多态 + 零开销 | CRTP（静态绑定） | 模板 + 内联 |
| 接口稳定，派生类少 | CRTP | 性能最优 |
| 接口经常变化，派生类多 | 虚函数 | 灵活性更高 |
| 需要异构容器 | 虚函数 | CRTP 无法统一类型 |

**最佳实践**：

1. 默认使用非虚函数（静态绑定），只有需要多态时才加 `virtual`
2. 基类析构函数如果有多态需求，必须声明为 `virtual`
3. 不要在构造/析构函数中调用虚函数
4. 极端性能场景考虑 CRTP
5. 用 `override` 关键字确保正确覆盖虚函数

### 9. 完整示例：静态绑定与动态绑定

```cpp
#include <iostream>
#include <vector>
#include <memory>
#include <chrono>
using namespace std;

// === 动态绑定：虚函数 ===
class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0;
    virtual void describe() const = 0;
};

class Circle : public Shape {
    double r_;
public:
    explicit Circle(double r) : r_(r) {}
    double area() const override { return 3.14159 * r_ * r_; }
    void describe() const override { cout << "Circle(r=" << r_ << ")"; }
};

class Square : public Shape {
    double s_;
public:
    explicit Square(double s) : s_(s) {}
    double area() const override { return s_ * s_; }
    void describe() const override { cout << "Square(s=" << s_ << ")"; }
};

// === 静态绑定：CRTP ===
template <typename Derived>
class FastShape {
public:
    double area() const {
        return static_cast<const Derived*>(this)->area_impl();
    }
};

class FastCircle : public FastShape<FastCircle> {
    double r_;
public:
    explicit FastCircle(double r) : r_(r) {}
    double area_impl() const { return 3.14159 * r_ * r_; }
};

class FastSquare : public FastShape<FastSquare> {
    double s_;
public:
    explicit FastSquare(double s) : s_(s) {}
    double area_impl() const { return s_ * s_; }
};

int main() {
    // 动态绑定：异构容器
    vector<unique_ptr<Shape>> shapes;
    shapes.push_back(make_unique<Circle>(5.0));
    shapes.push_back(make_unique<Square>(4.0));

    cout << "=== 动态绑定 ===" << endl;
    for (const auto& s : shapes) {
        s->describe();
        cout << " area=" << s->area() << endl;
    }

    // 静态绑定：CRTP（同类型批量处理）
    vector<FastCircle> circles;
    for (int i = 1; i <= 3; ++i)
        circles.emplace_back(i * 1.0);

    cout << "=== 静态绑定 (CRTP) ===" << endl;
    double total = 0;
    for (const auto& c : circles) {
        total += c.area();  // 静态绑定，可内联
    }
    cout << "Total circle area: " << total << endl;

    // 静态绑定 vs 动态绑定性能对比
    const int N = 10000000;

    // 动态绑定
    vector<unique_ptr<Shape>> dyn_shapes;
    for (int i = 0; i < N; ++i)
        dyn_shapes.push_back(make_unique<Circle>(1.0));

    auto start = chrono::high_resolution_clock::now();
    double sum = 0;
    for (const auto& s : dyn_shapes) sum += s->area();
    auto end = chrono::high_resolution_clock::now();
    cout << "Dynamic: " << chrono::duration<double>(end - start).count() << "s\n";

    // 静态绑定
    vector<FastCircle> fast_circles(N, FastCircle(1.0));
    start = chrono::high_resolution_clock::now();
    sum = 0;
    for (const auto& c : fast_circles) sum += c.area();
    end = chrono::high_resolution_clock::now();
    cout << "Static (CRTP): " << chrono::duration<double>(end - start).count() << "s\n";

    return 0;
}
```

### 10. 常见陷阱

**陷阱1：通过对象调用虚函数，期望多态**

```cpp
Derived d;
Base b = d;       // 对象切片
b.virtualFunc();  // 静态绑定！调用 Base 版本

// 正确：用指针或引用
Base& ref = d;
ref.virtualFunc();  // 动态绑定！调用 Derived 版本
```

**陷阱2：在构造函数中调用虚函数**

```cpp
class Base {
public:
    Base() { init(); }              // 调用 Base::init，不是 Derived::init
    virtual void init() { cout << "Base init\n"; }
};

class Derived : public Base {
public:
    void init() override { cout << "Derived init\n"; }
};

Derived d;  // 输出 "Base init"，不是 "Derived init"
```

**陷阱3：忘记 virtual 导致意外隐藏**

```cpp
class Base {
public:
    void foo() { cout << "Base\n"; }  // 忘记加 virtual
};

class Derived : public Base {
public:
    void foo() { cout << "Derived\n"; }  // 隐藏，不是覆盖
};

Base* p = new Derived();
p->foo();  // 输出 "Base"，不是 "Derived"！
```

**陷阱4：默认参数与虚函数**

```cpp
class Base {
public:
    virtual void foo(int x = 10) { cout << "Base: " << x << endl; }
};

class Derived : public Base {
public:
    void foo(int x = 20) override { cout << "Derived: " << x << endl; }
};

Base* p = new Derived();
p->foo();  // 输出 "Derived: 10" ！！
// 动态绑定选择 Derived::foo，但默认参数是静态绑定的，取 Base 的默认值 10
```

### 11. 极简总结

**虚函数 = 动态绑定（运行时通过 vtable 决定）| 非虚函数 = 静态绑定（编译期决定）| 构造/析构中虚函数退化成静态绑定 | CRTP = 编译期多态 = 零开销 | 默认参数始终静态绑定**
