# 智能指针选择指南
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[继承与多态](../../02-CPP/04-继承与多态.md)、[核心机制](../../02-CPP/05-核心机制.md)、[异常处理](../../02-CPP/07-异常处理.md)、[移动语义](../../02-CPP/09-移动语义与完美转发.md)

### 1. 核心速览

**unique_ptr** 独占所有权（默认选择）、**shared_ptr** 共享所有权（需要共享时）、**weak_ptr** 打破循环引用（观察者）。默认用 unique_ptr，需要共享才用 shared_ptr。

***

### 2. 决策树

```
需要指针吗？
├── 否 → 用对象或引用（首选）
└── 是 → 需要共享所有权吗？
         ├── 否 → unique_ptr（首选）
         │        ├── 需要自定义删除器？→ unique_ptr<T, Deleter>
         │        └── 数组？→ unique_ptr<T[]>
         └── 是 → shared_ptr
                  ├── 有循环引用吗？
                  │   └── 是 → 一方用 weak_ptr
                  └── 需要自定义删除器？→ shared_ptr<T>(p, Deleter)
```

**选择优先级**：对象/引用 > unique_ptr > shared_ptr > 裸指针

### 3. unique_ptr 详解

`unique_ptr` 独占所有权，不可拷贝，可移动。是智能指针的默认选择。

**基本用法**：

```cpp
#include <memory>  // 智能指针所需头文件
// 创建
auto p = std::make_unique<Widget>(42);  // C++14
// C++11: std::unique_ptr<Widget> p(new Widget(42));

// 不可拷贝
// auto p2 = p;                        // 编译错误！

// 可移动（所有权转移）
auto p2 = std::move(p);                // p 变为 nullptr，p2 持有对象
if (p == nullptr) cout << "p is null";  // true

// 访问
p2->doWork();                           // 像裸指针一样使用
*p2;                                    // 解引用

// 释放
p2.reset();                             // 释放对象，p2 变为 nullptr
p2.reset(new Widget(100));              // 释放旧对象，持有新对象

// 放弃所有权（不释放对象）
Widget* raw = p2.release();             // p2 变为 nullptr，返回裸指针
delete raw;                             // 调用者负责删除
```

**数组版本**：

```cpp
#include <memory>  // 智能指针所需头文件
auto arr = std::make_unique<int[]>(10);  // C++14
arr[0] = 42;
arr[9] = 100;

// 注意：unique_ptr<T[]> 没有 -> 和 *，只有 []
```

**自定义删除器**：

```cpp
#include <memory>  // 智能指针所需头文件
// 删除器作为模板参数
auto deleter = [](FILE* f) { fclose(f); };
std::unique_ptr<FILE, decltype(deleter)> file(fopen("test.txt", "r"), deleter);

// 更常见的场景：C 库资源
struct SDL_Deleter {
    void operator()(SDL_Window* w) const { SDL_DestroyWindow(w); }
};
std::unique_ptr<SDL_Window, SDL_Deleter> window(SDL_CreateWindow(...));

// 使用函数指针
std::unique_ptr<FILE, int(*)(FILE*)> file(fopen("test.txt", "r"), fclose);
```

**unique_ptr 作为工厂返回值**：

```cpp
#include <memory>  // 智能指针所需头文件
// 工厂函数返回 unique_ptr，调用者可以存入 shared_ptr
std::unique_ptr<Shape> createShape(ShapeType type) {
    switch (type) {
        case ShapeType::Circle:   return std::make_unique<Circle>(5.0);
        case ShapeType::Rectangle: return std::make_unique<Rectangle>(3.0, 4.0);
    }
    return nullptr;
}

// 调用者
auto shape = createShape(ShapeType::Circle);
shape->draw();

// 如果需要共享
std::shared_ptr<Shape> shared = createShape(ShapeType::Circle);  // 隐式转换
```

### 4. shared_ptr 详解

`shared_ptr` 共享所有权，通过引用计数管理生命周期。

**基本用法**：

```cpp
#include <memory>  // 智能指针所需头文件
// 创建
auto p1 = std::make_shared<Widget>(42);  // 推荐：一次分配
// std::shared_ptr<Widget> p1(new Widget(42));  // 两次分配，不推荐

// 共享所有权
auto p2 = p1;                           // 引用计数 = 2
auto p3 = p1;                           // 引用计数 = 3

// 查看引用计数
cout << p1.use_count();                  // 3

// 释放一个
p1.reset();                             // 引用计数 = 2
// p2, p3 仍持有对象

// 全部释放
p2.reset();                             // 引用计数 = 1
p3.reset();                             // 引用计数 = 0 → 对象被删除
```

**make_shared vs new**：

| 特性 | make_shared | shared_ptr(new) |
|------|:---:|:---:|
| 分配次数 | 1（对象+控制块一起） | 2（对象+控制块分开） |
| 缓存友好 | 好（对象和控制块相邻） | 差 |
| 异常安全 | 安全 | 可能有泄漏 |
| 自定义删除器 | 不支持 | 支持 |
| 自定义分配器 | 不支持 | 支持 |

```cpp
#include <memory>  // 智能指针所需头文件
// make_shared：一次分配
auto p1 = std::make_shared<Widget>(42);
// 内存布局：[控制块 | Widget对象]  ← 连续内存

// shared_ptr(new)：两次分配
std::shared_ptr<Widget> p2(new Widget(42));
// 内存布局：[控制块]  [Widget对象]  ← 分开分配
```

**别名构造（Aliasing Constructor）**：

```cpp
#include <memory>  // 智能指针所需头文件
struct Person {
    string name;
    int age;
};

auto person = std::make_shared<Person>();
person->name = "Alice";
person->age = 30;

// 别名构造：共享 person 的生命周期，但指向 name 成员
std::shared_ptr<string> name_ptr(person, &person->name);
// use_count = 2（person 和 name_ptr 共享所有权）
// name_ptr 指向 person->name

cout << *name_ptr;  // "Alice"
// person.reset() 不会释放 name，因为 name_ptr 还持有
```

**自定义删除器**：

```cpp
#include <memory>  // 智能指针所需头文件
// shared_ptr 的删除器不在模板参数中，更灵活
auto file = std::shared_ptr<FILE>(fopen("test.txt", "r"), fclose);

// 任意删除器
auto malloc_deleter = [](void* p) { free(p); };
auto buffer = std::shared_ptr<void>(malloc(1024), malloc_deleter);
```

### 5. weak_ptr 详解

`weak_ptr` 不增加引用计数，用于观察 shared_ptr 管理的对象。

**基本用法**：

```cpp
#include <memory>  // 智能指针所需头文件
auto sp = std::make_shared<Widget>(42);
std::weak_ptr<Widget> wp = sp;

// 检查是否过期
cout << wp.expired();           // false（sp 还持有对象）

// 访问对象（必须 lock）
if (auto locked = wp.lock()) {
    locked->doWork();           // 对象还活着，安全使用
} else {
    // 对象已被释放
}

// sp 释放后
sp.reset();
cout << wp.expired();           // true
if (auto locked = wp.lock()) {
    // 不会执行，对象已释放
}
```

**expired() vs lock()**：

```cpp
#include <memory>  // 智能指针所需头文件
// 不好的写法：expired + lock 有竞态
if (!wp.expired()) {
    auto sp = wp.lock();  // expired 和 lock 之间，对象可能被释放！
    sp->doWork();         // 可能崩溃
}

// 好的写法：直接 lock
if (auto sp = wp.lock()) {
    sp->doWork();         // 安全，sp 持有引用
}
```

**weak_ptr 的典型用途**：

```cpp
#include <memory>  // 智能指针所需头文件
// 1. 缓存
class Cache {
    std::map<string, std::weak_ptr<Data>> cache_;
public:
    std::shared_ptr<Data> get(const string& key) {
        if (auto sp = cache_[key].lock()) {
            return sp;              // 缓存命中
        }
        auto data = std::make_shared<Data>(key);
        cache_[key] = data;         // 缓存 weak_ptr
        return data;
    }
};

// 2. 观察者模式
class Subject {
    vector<std::weak_ptr<Observer>> observers_;
public:
    void notify() {
        for (auto it = observers_.begin(); it != observers_.end(); ) {
            if (auto sp = it->lock()) {
                sp->onNotify();
                ++it;
            } else {
                it = observers_.erase(it);  // 清理已销毁的观察者
            }
        }
    }
};
```

### 6. 性能对比

| 特性 | unique_ptr | shared_ptr | weak_ptr |
|------|:---:|:---:|:---:|
| 大小 | 与裸指针相同 | 2倍指针大小 | 2倍指针大小 |
| 构造开销 | 零 | 原子操作 | 原子操作 |
| 拷贝开销 | 不可拷贝 | 原子引用计数++ | 原子引用计数++ |
| 移动开销 | 指针拷贝 | 指针拷贝 | 指针拷贝 |
| 解引用开销 | 与裸指针相同 | 与裸指针相同 | 需先 lock() |
| 控制块 | 无 | 有 | 共享 |

**内存布局对比**：

```
unique_ptr<Widget>:
+----------+
| ptr_     |  → Widget
+----------+
大小：8字节（64位）

shared_ptr<Widget>:
+----------+          控制块：
| ptr_     |  ------→ +------------------+
+----------+          | strong_count     |
| ctrl_    |  ------→ | weak_count       |
+----------+          | 删除器/分配器     |
                      +------------------+
大小：16字节（64位）   → Widget
```

### 7. 线程安全

**shared_ptr 的线程安全**：

| 操作 | 线程安全？ | 说明 |
|------|:---:|------|
| 不同 shared_ptr 的读/写 | 安全 | 指向不同对象的 shared_ptr 互不影响 |
| 同一 shared_ptr 的读 | 安全 | 多线程同时读取同一 shared_ptr |
| 同一 shared_ptr 的写 | 不安全 | 多线程同时修改同一 shared_ptr（reset/赋值） |
| 引用计数的增减 | 安全 | 原子操作 |
| 对象的访问 | 不安全 | 需要外部同步 |

```cpp
#include <memory>  // 智能指针所需头文件
// 线程安全：不同 shared_ptr 对象
auto p1 = std::make_shared<Widget>();
auto p2 = std::make_shared<Widget>();
// 线程1: p1.reset()
// 线程2: p2.reset()
// 安全，互不影响

// 线程安全：引用计数
auto sp = std::make_shared<Widget>();
// 线程1: auto copy1 = sp;  // 引用计数原子++
// 线程2: auto copy2 = sp;  // 引用计数原子++
// 安全，引用计数是原子的

// 不安全：同一 shared_ptr 的写
std::shared_ptr<Widget> global_sp;
// 线程1: global_sp = std::make_shared<Widget>();
// 线程2: global_sp = std::make_shared<Widget>();
// 不安全！需要加锁或用 atomic<shared_ptr>（C++20）

// 不安全：对象访问
auto sp = std::make_shared<Widget>();
// 线程1: sp->modify();
// 线程2: sp->modify();
// 不安全！需要对象自己保证线程安全
```

### 8. 完整示例：智能指针实战

```cpp
#include <iostream>
#include <vector>
#include <memory>
using namespace std;

class Widget {
    int id_;
public:
    explicit Widget(int id) : id_(id) { cout << "Widget(" << id_ << ") constructed\n"; }
    ~Widget() { cout << "Widget(" << id_ << ") destroyed\n"; }
    void doWork() const { cout << "Widget(" << id_ << ") working\n"; }
    int id() const { return id_; }
};

// unique_ptr：独占所有权
class WidgetFactory {
public:
    static unique_ptr<Widget> create(int id) {
        return make_unique<Widget>(id);
    }
};

// shared_ptr：共享所有权
class WidgetPool {
    vector<shared_ptr<Widget>> pool_;
public:
    shared_ptr<Widget> acquire(int id) {
        // 查找空闲的
        for (auto& w : pool_) {
            if (w->id() == id) return w;
        }
        // 创建新的
        auto w = make_shared<Widget>(id);
        pool_.push_back(w);
        return w;
    }

    size_t size() const { return pool_.size(); }
};

// weak_ptr：缓存
class WidgetCache {
    map<int, weak_ptr<Widget>> cache_;
public:
    shared_ptr<Widget> get(int id, function<shared_ptr<Widget>(int)> creator) {
        if (auto sp = cache_[id].lock()) {
            cout << "Cache hit: Widget(" << id << ")\n";
            return sp;
        }
        cout << "Cache miss: Widget(" << id << ")\n";
        auto sp = creator(id);
        cache_[id] = sp;
        return sp;
    }
};

int main() {
    // === unique_ptr ===
    cout << "--- unique_ptr ---\n";
    {
        auto w = WidgetFactory::create(1);
        w->doWork();
        auto w2 = std::move(w);  // 所有权转移
        // w 是 nullptr
        w2->doWork();
    }  // Widget(1) 自动销毁

    // === shared_ptr ===
    cout << "\n--- shared_ptr ---\n";
    {
        auto sp1 = make_shared<Widget>(2);
        cout << "use_count: " << sp1.use_count() << "\n";  // 1

        auto sp2 = sp1;
        cout << "use_count: " << sp1.use_count() << "\n";  // 2

        sp1.reset();
        cout << "use_count after sp1.reset: " << sp2.use_count() << "\n";  // 1
    }  // Widget(2) 自动销毁

    // === weak_ptr ===
    cout << "\n--- weak_ptr ---\n";
    {
        WidgetCache cache;
        auto creator = [](int id) { return make_shared<Widget>(id); };

        {
            auto w1 = cache.get(3, creator);  // Cache miss
            auto w2 = cache.get(3, creator);  // Cache hit
            cout << "Inside scope, use_count: " << w1.use_count() << "\n";
        }  // Widget(3) 销毁

        auto w3 = cache.get(3, creator);  // Cache miss（对象已被释放）
    }

    // === 容器中的智能指针 ===
    cout << "\n--- Container ---\n";
    {
        vector<unique_ptr<Widget>> widgets;
        widgets.push_back(make_unique<Widget>(10));
        widgets.push_back(make_unique<Widget>(11));
        // widgets.push_back(make_unique<Widget>(12));  // OK
        // auto w = widgets[0];  // 编译错误！不可拷贝

        for (const auto& w : widgets) {
            w->doWork();
        }
    }  // 全部自动销毁

    return 0;
}
```

### 9. 常见陷阱

**陷阱1：用裸指针创建多个 shared_ptr**

```cpp
#include <memory>  // 智能指针所需头文件
Widget* raw = new Widget(1);
auto sp1 = shared_ptr<Widget>(raw);
auto sp2 = shared_ptr<Widget>(raw);  // 错误！两个独立的引用计数
// sp1 和 sp2 都会 delete raw → 双重释放！

// 正确：从 shared_ptr 拷贝
auto sp1 = make_shared<Widget>(1);
auto sp2 = sp1;  // 共享引用计数
```

**陷阱2：this 指针被 shared_ptr 管理**

```cpp
#include <memory>  // 智能指针所需头文件
class BadWidget {
public:
    shared_ptr<BadWidget> getSelf() {
        return shared_ptr<BadWidget>(this);  // 错误！创建新的引用计数
    }
};

auto sp1 = make_shared<BadWidget>();
auto sp2 = sp1->getSelf();  // 双重释放！

// 正确：使用 enable_shared_from_this
class GoodWidget : public std::enable_shared_from_this<GoodWidget> {
public:
    shared_ptr<GoodWidget> getSelf() {
        return shared_from_this();  // 共享已有的引用计数
    }
};
```

**陷阱3：unique_ptr 传参错误**

```cpp
#include <memory>  // 智能指针所需头文件
// 错误：按值传递 unique_ptr 会拷贝
void process(unique_ptr<Widget> w);  // 必须移动传入

auto p = make_unique<Widget>(1);
// process(p);              // 编译错误！不可拷贝
process(std::move(p));      // OK，p 变为 nullptr

// 如果不转移所有权，用引用或裸指针
void observe(const unique_ptr<Widget>& w);  // 不转移所有权
observe(p);  // OK，p 仍持有对象

// 或者直接传裸指针/引用
void observe(Widget* w);
void observe(Widget& w);
```

**陷阱4：shared_ptr 循环引用**

```cpp
#include <memory>  // 智能指针所需头文件
class Node {
public:
    shared_ptr<Node> next;
    shared_ptr<Node> prev;  // 应该用 weak_ptr！
};

auto a = make_shared<Node>();
auto b = make_shared<Node>();
a->next = b;
b->prev = a;  // 循环引用！内存泄漏！
// 详见 FAQ 56
```

### 10. 最佳实践

1. **默认用 unique_ptr**，只有需要共享所有权时才用 shared_ptr
2. **用 make_unique/make_shared** 创建智能指针，不要用 new
3. **不要用裸指针创建多个 shared_ptr**
4. **需要从 this 创建 shared_ptr 时用 enable_shared_from_this**
5. **weak_ptr 访问前必须 lock()**，不要用 expired() + lock()
6. **unique_ptr 传参**：转移所有权用 `std::move`，不转移用引用或裸指针
7. **shared_ptr 对象的访问不是线程安全的**，需要外部同步
8. **优先用对象和引用**，智能指针只在需要管理生命周期时使用

### 11. 极简总结

**默认 unique_ptr（零开销独占）→ 需要共享用 shared_ptr（引用计数）→ 打破循环用 weak_ptr（不增计数）→ make_unique/make_shared 创建 → 不要用裸指针创建多个 shared_ptr**
