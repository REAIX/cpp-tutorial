# 智能指针循环引用
> 📖 相关章节：[智能指针与内存管理](../../02-CPP/08-智能指针与内存管理.md)

### 1. 要点直击

**shared_ptr 循环引用** = A 持有 B 的 shared_ptr，B 持有 A 的 shared_ptr → 引用计数永远不为 0 → 内存泄漏。**解决方法**：一方改用 weak_ptr，打破循环。

***

### 2. 问题演示

**最简单的循环引用**：

```cpp
#include <memory>  // 智能指针所需头文件
class Node {
public:
    std::shared_ptr<Node> next;
    ~Node() { cout << "~Node" << endl; }
};

void test() {
    auto a = std::make_shared<Node>();
    auto b = std::make_shared<Node>();
    a->next = b;  // b 的引用计数 = 2（a + a->next）
    b->next = a;  // a 的引用计数 = 2（栈变量a + b->next）
}
// 离开作用域：
// 栈变量 a 析构 → a 引用计数 2-1=1（b->next 还持有 a）
// 栈变量 b 析构 → b 引用计数 2-1=1（a->next 还持有 b）
// 两个都不会被释放！内存泄漏！
// 不会输出 "~Node"
```

**引用计数变化过程**：

```
初始状态：
  a (栈) → Node_A [use_count=1]
  b (栈) → Node_B [use_count=1]

a->next = b 后：
  a (栈) → Node_A [use_count=1]
  b (栈) → Node_B [use_count=2]  ← a->next 也指向 B

b->next = a 后：
  a (栈) → Node_A [use_count=2]  ← b->next 也指向 A
  b (栈) → Node_B [use_count=2]

离开作用域后：
  Node_A [use_count=1]  ← b->next 仍指向 A
  Node_B [use_count=1]  ← a->next 仍指向 B
  互相持有，谁也释放不了！
```

**更隐蔽的循环引用**：

```cpp
#include <memory>  // 智能指针所需头文件
class Controller;
class View;

class Controller {
public:
    std::shared_ptr<View> view;
    ~Controller() { cout << "~Controller\n"; }
};

class View {
public:
    std::shared_ptr<Controller> controller;  // 循环引用！
    ~View() { cout << "~View\n"; }
};

void test() {
    auto ctrl = std::make_shared<Controller>();
    auto v = std::make_shared<View>();
    ctrl->view = v;
    v->controller = ctrl;
}
// 泄漏！Controller 和 View 互相持有
```

### 3. 解决方法：weak_ptr

将循环中的一方改为 `weak_ptr`，打破引用计数循环。

```cpp
#include <memory>  // 智能指针所需头文件
class Node {
public:
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;    // 用 weak_ptr 打破循环
    ~Node() { cout << "~Node" << endl; }
};

void test() {
    auto a = std::make_shared<Node>();
    auto b = std::make_shared<Node>();
    a->next = b;   // b 的引用计数 = 2
    b->prev = a;   // a 的引用计数仍为 1（weak_ptr 不增加计数）
}
// 离开作用域：
// 栈变量 a 析构 → a 引用计数 1-1=0 → 释放 Node_A
//   Node_A 析构 → a->next 释放 → b 引用计数 2-1=1
// 栈变量 b 析构 → b 引用计数 1-1=0 → 释放 Node_B
// 正确释放！输出两次 "~Node"
```

**Controller-View 的修复**：

```cpp
#include <memory>  // 智能指针所需头文件
class Controller {
public:
    std::shared_ptr<View> view;       // Controller 拥有 View
    ~Controller() { cout << "~Controller\n"; }
};

class View {
public:
    std::weak_ptr<Controller> controller;  // View 观察 Controller，不拥有
    ~View() { cout << "~View\n"; }

    void doSomething() {
        if (auto ctrl = controller.lock()) {
            // 安全使用 Controller
        } else {
            // Controller 已被释放
        }
    }
};
```

### 4. 常见循环引用场景

**场景1：双向链表**

```cpp
#include <memory>  // 智能指针所需头文件
template <typename T>
class LinkedList {
public:
    struct Node {
        T data;
        std::shared_ptr<Node> next;  // 前向指针用 shared_ptr
        std::weak_ptr<Node> prev;    // 后向指针用 weak_ptr
        Node(const T& d) : data(d) {}
    };

    std::shared_ptr<Node> head;

    void push_front(const T& data) {
        auto new_node = std::make_shared<Node>(data);
        if (head) {
            new_node->next = head;
            head->prev = new_node;     // weak_ptr，不增加计数
        }
        head = new_node;
    }

    void print() {
        for (auto cur = head; cur; cur = cur->next) {
            cout << cur->data << " ";
        }
        cout << endl;
    }

    void print_reverse() {
        // 先找到尾节点
        auto tail = head;
        while (tail && tail->next) tail = tail->next;
        // 反向遍历
        for (auto cur = tail; cur; ) {
            cout << cur->data << " ";
            if (auto prev = cur->prev.lock()) {
                cur = prev;
            } else {
                break;
            }
        }
        cout << endl;
    }
};
```

**场景2：观察者模式**

```cpp
#include <memory>  // 智能指针所需头文件
class Subject;

class Observer : public std::enable_shared_from_this<Observer> {
public:
    virtual ~Observer() { cout << "~Observer\n"; }
    virtual void onNotify(const string& event) = 0;

    void subscribe(std::shared_ptr<Subject> sub);
    void unsubscribe();
};

class Subject {
    vector<std::weak_ptr<Observer>> observers_;  // weak_ptr 避免循环
public:
    ~Subject() { cout << "~Subject\n"; }

    void subscribe(std::shared_ptr<Observer> obs) {
        observers_.push_back(obs);  // weak_ptr，不增加计数
    }

    void notify(const string& event) {
        // 清理已销毁的观察者，同时通知活着的
        for (auto it = observers_.begin(); it != observers_.end(); ) {
            if (auto sp = it->lock()) {
                sp->onNotify(event);
                ++it;
            } else {
                it = observers_.erase(it);  // 观察者已销毁，清理
            }
        }
    }
};

// Observer 持有 Subject 的 shared_ptr（拥有关系）
// Subject 持有 Observer 的 weak_ptr（观察关系）
// 没有循环引用
```

**场景3：父子关系**

```cpp
#include <memory>  // 智能指针所需头文件
class Child;

class Parent {
    vector<std::shared_ptr<Child>> children_;  // 父亲拥有孩子
public:
    ~Parent() { cout << "~Parent\n"; }
    void addChild(std::shared_ptr<Child> child) {
        children_.push_back(child);
    }
};

class Child {
    std::weak_ptr<Parent> parent_;  // 孩子观察父亲，不拥有
public:
    ~Child() { cout << "~Child\n"; }

    void setParent(std::shared_ptr<Parent> parent) {
        parent_ = parent;  // weak_ptr，不增加计数
    }

    std::shared_ptr<Parent> getParent() const {
        return parent_.lock();  // 安全获取
    }
};

void test() {
    auto parent = std::make_shared<Parent>();
    auto child = std::make_shared<Child>();

    child->setParent(parent);    // weak_ptr
    parent->addChild(child);     // shared_ptr

    // parent 引用计数 = 1（只有栈变量）
    // child 引用计数 = 2（栈变量 + parent->children_）
}
// 离开作用域：
// parent 析构 → parent 引用计数 0 → 释放 Parent
//   Parent 析构 → children_ 清空 → child 引用计数 1
// child 析构 → child 引用计数 0 → 释放 Child
// 正确释放！
```

**场景4：图结构**

```cpp
#include <memory>  // 智能指针所需头文件
class GraphNode {
    string name_;
    vector<std::shared_ptr<GraphNode>> neighbors_;    // 拥有邻居
    vector<std::weak_ptr<GraphNode>> references_;      // 引用邻居（不拥有）
public:
    GraphNode(const string& name) : name_(name) {}
    ~GraphNode() { cout << "~GraphNode(" << name_ << ")\n"; }

    void addNeighbor(std::shared_ptr<GraphNode> node) {
        neighbors_.push_back(node);
    }

    void addReference(std::weak_ptr<GraphNode> node) {
        references_.push_back(node);
    }
};

// 无向图：用 weak_ptr 避免循环
auto a = make_shared<GraphNode>("A");
auto b = make_shared<GraphNode>("B");
a->addNeighbor(b);
b->addReference(a);  // weak_ptr，打破循环
```

### 5. enable_shared_from_this

当对象需要返回指向自身的 `shared_ptr` 时，必须使用 `enable_shared_from_this`。

**问题**：

```cpp
#include <memory>  // 智能指针所需头文件
class BadWidget {
public:
    std::shared_ptr<BadWidget> getSelf() {
        // 错误！用 this 创建新的 shared_ptr，产生独立的引用计数
        return std::shared_ptr<BadWidget>(this);
    }
};

auto sp1 = std::make_shared<BadWidget>();
auto sp2 = sp1->getSelf();
// sp1 和 sp2 有各自独立的引用计数，都指向同一个对象
// sp1 析构 → delete 对象
// sp2 析构 → delete 已释放的对象 → UB！
```

**解决方案**：

```cpp
#include <memory>  // 智能指针所需头文件
class GoodWidget : public std::enable_shared_from_this<GoodWidget> {
public:
    std::shared_ptr<GoodWidget> getSelf() {
        return shared_from_this();  // 共享已有的引用计数
    }
};

auto sp1 = std::make_shared<GoodWidget>();
auto sp2 = sp1->getSelf();
// sp1 和 sp2 共享引用计数，use_count = 2
```

**典型使用场景**：

```cpp
#include <memory>  // 智能指针所需头文件
// 异步回调中保持自身存活
class AsyncWorker : public std::enable_shared_from_this<AsyncWorker> {
public:
    void startAsync() {
        // 捕获 shared_ptr，确保异步操作期间对象不被销毁
        auto self = shared_from_this();
        asyncOperation([self]() {
            self->onComplete();  // 安全，self 保证对象存活
        });
    }

    void onComplete() {
        cout << "Work complete!\n";
    }
};
```

**注意事项**：

```cpp
#include <memory>  // 智能指针所需头文件
// 错误：对象不是由 shared_ptr 管理时调用 shared_from_this()
GoodWidget w;
// auto sp = w.shared_from_this();  // UB！对象不在 shared_ptr 管理下

// 正确：必须先通过 shared_ptr 管理
auto sp = std::make_shared<GoodWidget>();
auto self = sp->shared_from_this();  // OK
```

### 6. 循环引用检测方法

**方法1：引用计数审计**

```cpp
#include <memory>  // 智能指针所需头文件
// 在关键位置打印 use_count
auto a = std::make_shared<Node>();
auto b = std::make_shared<Node>();
cout << "Before link: a=" << a.use_count() << " b=" << b.use_count() << "\n";
a->next = b;
b->next = a;
cout << "After link: a=" << a.use_count() << " b=" << b.use_count() << "\n";
// 如果离开作用域后 use_count > 0，说明有泄漏
```

**方法2：析构日志**

```cpp
#include <memory>  // 智能指针所需头文件
class Node {
public:
    int id;
    std::shared_ptr<Node> next;
    std::shared_ptr<Node> prev;
    Node(int i) : id(i) { cout << "Node(" << id << ") created\n"; }
    ~Node() { cout << "Node(" << id << ") destroyed\n"; }
};

// 如果程序结束时没有输出 "destroyed"，说明有循环引用
```

### 7. 完整示例：双向链表与循环引用

```cpp
#include <iostream>
#include <memory>
using namespace std;

// === 错误版本：循环引用 ===
class BadNode {
public:
    int value;
    shared_ptr<BadNode> next;
    shared_ptr<BadNode> prev;  // shared_ptr 导致循环引用
    BadNode(int v) : value(v) { cout << "BadNode(" << v << ") created\n"; }
    ~BadNode() { cout << "BadNode(" << value << ") destroyed\n"; }
};

void testBadList() {
    cout << "=== Bad List (circular reference) ===\n";
    auto a = make_shared<BadNode>(1);
    auto b = make_shared<BadNode>(2);
    auto c = make_shared<BadNode>(3);

    a->next = b;  b->prev = a;
    b->next = c;  c->prev = b;
    // 循环引用：a→b→a, b→c→b
    cout << "Leaving scope...\n";
    // 不会输出 destroyed！内存泄漏！
}

// === 正确版本：weak_ptr 打破循环 ===
class GoodNode {
public:
    int value;
    shared_ptr<GoodNode> next;
    weak_ptr<GoodNode> prev;   // weak_ptr 打破循环
    GoodNode(int v) : value(v) { cout << "GoodNode(" << v << ") created\n"; }
    ~GoodNode() { cout << "GoodNode(" << value << ") destroyed\n"; }
};

class DoublyLinkedList {
    shared_ptr<GoodNode> head_;
public:
    void push_front(int value) {
        auto new_node = make_shared<GoodNode>(value);
        if (head_) {
            new_node->next = head_;
            head_->prev = new_node;  // weak_ptr
        }
        head_ = new_node;
    }

    void push_back(int value) {
        auto new_node = make_shared<GoodNode>(value);
        if (!head_) {
            head_ = new_node;
            return;
        }
        auto tail = head_;
        while (tail->next) tail = tail->next;
        tail->next = new_node;
        new_node->prev = tail;  // weak_ptr
    }

    void print_forward() {
        cout << "Forward: ";
        for (auto cur = head_; cur; cur = cur->next) {
            cout << cur->value << " ";
        }
        cout << "\n";
    }

    void print_backward() {
        if (!head_) return;
        auto tail = head_;
        while (tail->next) tail = tail->next;
        cout << "Backward: ";
        for (auto cur = tail; cur; ) {
            cout << cur->value << " ";
            cur = cur->prev.lock();  // weak_ptr → shared_ptr
        }
        cout << "\n";
    }

    void clear() {
        head_.reset();  // 释放所有节点
    }
};

void testGoodList() {
    cout << "\n=== Good List (weak_ptr) ===\n";
    DoublyLinkedList list;
    list.push_back(1);
    list.push_back(2);
    list.push_back(3);
    list.print_forward();    // Forward: 1 2 3
    list.print_backward();   // Backward: 3 2 1

    cout << "Clearing list...\n";
    list.clear();  // 输出三次 destroyed
    cout << "List cleared.\n";
}

int main() {
    testBadList();
    testGoodList();
    return 0;
}
```

### 8. 常见陷阱

**陷阱1：weak_ptr 不增加引用计数，但 lock() 会**

```cpp
#include <memory>  // 智能指针所需头文件
auto sp = make_shared<Widget>();
weak_ptr<Widget> wp = sp;
cout << sp.use_count();  // 1（weak_ptr 不增加）

if (auto locked = wp.lock()) {
    cout << sp.use_count();  // 2（locked 是 shared_ptr，增加计数）
    // locked 离开作用域后，计数回到 1
}
```

**陷阱2：忘记检查 lock() 返回值**

```cpp
#include <memory>  // 智能指针所需头文件
weak_ptr<Widget> wp;
// ... wp 可能已过期

auto sp = wp.lock();
sp->doWork();  // 如果 wp 过期，sp 是 nullptr → 崩溃！

// 正确：必须检查
if (auto sp = wp.lock()) {
    sp->doWork();  // 安全
}
```

**陷阱3：enable_shared_from_this 在构造函数中使用**

```cpp
#include <memory>  // 智能指针所需头文件
class Widget : public std::enable_shared_from_this<Widget> {
public:
    Widget() {
        // auto self = shared_from_this();  // UB！对象还没被 shared_ptr 接管
    }

    void init() {
        auto self = shared_from_this();  // OK，构造完成后调用
    }
};
```

**陷阱4：多重循环引用**

```cpp
#include <memory>  // 智能指针所需头文件
// A → B → C → A：三重循环
class A { shared_ptr<B> b; };
class B { shared_ptr<C> c; };
class C { shared_ptr<A> a; };  // 循环！

// 解决：任意一处改为 weak_ptr
class C { weak_ptr<A> a; };    // 打破循环
```

### 9. 最佳实践

1. **所有权设计**：明确谁拥有谁，拥有方用 `shared_ptr`，被拥有方用 `weak_ptr` 回指
2. **树形结构**：父→子用 `shared_ptr`，子→父用 `weak_ptr`
3. **双向关系**：一方用 `shared_ptr`，另一方用 `weak_ptr`
4. **观察者模式**：Subject 持有 `weak_ptr<Observer>`
5. **缓存**：缓存持有 `weak_ptr`，不阻止对象被回收
6. **需要返回自身 shared_ptr 时**：继承 `enable_shared_from_this`
7. **定期审计**：检查析构函数是否被调用，确保无泄漏

### 10. 极简总结

**shared_ptr 循环引用 → 引用计数永不为0 → 泄漏 → 一方改用 weak_ptr 打破循环 | 父→子用 shared_ptr，子→父用 weak_ptr | 需要返回自身 shared_ptr 用 enable_shared_from_this**
