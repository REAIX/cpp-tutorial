# 左值右值与将亡值详解
> 📖 相关章节：[移动语义与完美转发](../../02-CPP/09-移动语义与完美转发.md)

### 1. 本质速解

**C++ 的表达式分为三种值类别：左值（lvalue）、将亡值（xvalue）、纯右值（prvalue），它们组合出泛左值（glvalue = lvalue + xvalue）和右值（rvalue = xvalue + prvalue）。搞懂值类别是理解移动语义的前提。**

***

### 2. 核心定义

| 值类别 | 全称 | 一句话解释 | 能否取地址 | 生命周期 |
|--------|------|-----------|:---:|------|
| lvalue | left value | 有名字、有地址，可以反复访问 | ✅ | 持久，直到离开作用域 |
| prvalue | pure rvalue | 纯临时值，没有名字 | ❌ | 临时，当前表达式结束即销毁 |
| xvalue | expiring value | 即将过期的左值，资源可以被"偷走" | ✅ | 即将销毁，还能访问一次 |
| glvalue | generalized lvalue | lvalue + xvalue 的统称 | — | — |
| rvalue | right value | prvalue + xvalue 的统称 | — | — |

**值类别关系图**：

```
            表达式
           /      \
       glvalue    rvalue
       /    \    /    \
   lvalue  xvalue    prvalue

   glvalue = lvalue + xvalue（有身份的表达式）
   rvalue  = xvalue + prvalue（可以移动的表达式）
   xvalue  = glvalue ∩ rvalue（既有身份，又可以移动）
```

**判断标准**：

- **有身份（identity）**：能取地址、能通过名字访问 → glvalue
- **可移动（movable）**：资源可以被窃取、用完即弃 → rvalue
- **两者都有**：xvalue（有身份但即将过期，资源可以偷）

***

### 3. 生活类比

| 值类别 | 生活类比 | 说明 |
|--------|---------|------|
| lvalue | 有名字的储物柜 | 你有钥匙（地址），随时可以存取东西，柜子一直在那 |
| prvalue | 临时快递箱 | 快递刚送到手上的箱子，拆完就扔，没有固定位置 |
| xvalue | 即将搬走的储物柜 | 柜子还在，你还能取一次东西，但马上要搬走了，里面的东西你不拿就没了 |
| glvalue | 所有有名字的柜子 | 包括还在用的和即将搬走的 |
| rvalue | 所有用完即弃的东西 | 包括临时快递箱和即将搬走的柜子里的东西 |

**具体场景**：

- `int x = 42;` → `x` 是储物柜（lvalue），`42` 是快递箱（prvalue）
- `std::move(x)` → 储物柜贴了"即将搬走"的标签（xvalue）
- `std::string("hello")` → 临时快递箱（prvalue）

***

### 4. 各种表达式的值类别

```cpp
int x = 10;
const int cx = 20;

// === lvalue（左值）===
x;                  // 变量名 → lvalue
cx;                 // const 变量也是 lvalue
std::cout;          // 命名对象 → lvalue
"hello";            // 字符串字面量 → lvalue（有地址，存在静态区）
int arr[5]; arr[0]; // 下标运算 → lvalue
*x;                 // 解引用 → lvalue
++x;                // 前置++ → lvalue（返回修改后的 x 本身）
std::cin >> x;      // 流提取 → lvalue

// === prvalue（纯右值）===
42;                         // 整数字面量 → prvalue
3.14;                       // 浮点字面量 → prvalue
true;                       // bool 字面量 → prvalue
nullptr;                    // 空指针字面量 → prvalue
int();                      // 默认构造的临时对象 → prvalue
std::string("hello");       // 类型转换产生的临时对象 → prvalue
x + 1;                      // 算术运算 → prvalue
x++;                        // 后置++ → prvalue（返回旧值的副本）
&x;                         // 取地址 → prvalue（地址值本身是纯右值）

// === xvalue（将亡值）===
std::move(x);                       // std::move 的结果 → xvalue
std::forward<int&&>(x);             // 完美转发右值 → xvalue
static_cast<int&&>(x);              // 转为右值引用 → xvalue
std::vector<int>{1,2,3}[0];         // 某些成员访问 → 视情况
struct A { int m; };
A().m;                              // 临时对象的成员 → xvalue（C++11起）
```

**快速判断表**：

| 表达式 | 值类别 | 原因 |
|--------|:---:|------|
| 变量名 `x` | lvalue | 有名字有地址 |
| 字符串字面量 `"hi"` | lvalue | 存在静态区，有地址 |
| 整数字面量 `42` | prvalue | 没有地址，纯值 |
| `x + y` | prvalue | 运算结果是临时值 |
| `*ptr` | lvalue | 解引用得到对象本身 |
| `&x` | prvalue | 地址值本身是纯右值 |
| `++x` | lvalue | 返回 x 本身（修改后） |
| `x++` | prvalue | 返回旧值副本 |
| `std::move(x)` | xvalue | 有身份但可移动 |
| `std::string("hi")` | prvalue | 临时对象 |

### 5. 值类别与引用类型的关系

值类别和引用类型是两套独立的概念，但经常被混淆。

| 概念 | 属于 | 说明 |
|------|------|------|
| 值类别 | 表达式的属性 | lvalue / xvalue / prvalue |
| 类型 | 变量/表达式的类型 | int / int& / int&& |

```cpp
int x = 10;

// 值类别 vs 类型
x;              // 值类别：lvalue，类型：int
std::move(x);   // 值类别：xvalue，类型：int&&
42;             // 值类别：prvalue，类型：int

// 左值引用绑定规则
int& lr = x;            // ✅ 左值引用绑定 lvalue
// int& lr2 = 42;       // ❌ 左值引用不能绑定 prvalue
const int& clr = 42;    // ✅ const 左值引用可以绑定 prvalue（延长生命周期）

// 右值引用绑定规则
int&& rr = 42;          // ✅ 右值引用绑定 prvalue
int&& rr2 = std::move(x); // ✅ 右值引用绑定 xvalue
// int&& rr3 = x;       // ❌ 右值引用不能绑定 lvalue
```

### 6. 常见误区

**误区1：左值一定在赋值号左边**

```cpp
const int x = 10;   // x 是 lvalue，但不能赋值
x = 20;             // ❌ 编译错误！const lvalue 不能放在赋值号左边

int arr[5];
arr[0] = 1;         // arr[0] 是 lvalue，在左边 ✅
// 但 "hello"[0] 也是 lvalue，你不能给它赋值

// "左值"这个名字是历史遗留，跟"在左边"没有必然关系
// 左值 = 有身份（能取地址），不是"能在左边"
```

**误区2：右值引用是右值**

```cpp
int&& rr = 42;

// rr 是右值引用，但 rr 作为表达式是 lvalue！
rr;             // 值类别：lvalue（有名字，能取地址）
&rr;            // ✅ 可以取地址

// 只有匿名的右值引用才是右值
std::move(rr);  // 值类别：xvalue

// 这就是为什么在函数体内需要再次 std::move
void process(std::string&& s) {
    // s 的类型是 std::string&&
    // 但 s 作为表达式是 lvalue！
    // 如果要把 s 传给另一个接受右值的函数，需要 std::move(s)
    other(std::move(s));  // ✅
    // other(s);          // ❌ s 是 lvalue，不能绑定到 string&&
}
```

**误区3：std::move 移动了任何东西**

```cpp
int x = 10;
int y = std::move(x);

// std::move 没有移动任何东西！
// 它只是把 x 从 lvalue 转成 xvalue
// 真正的"移动"发生在移动构造函数/移动赋值运算符里

cout << x;  // x 的值仍然是 10！（对基本类型，move 等于拷贝）
// 对于基本类型（int, double, 指针），std::move 就是拷贝，没有性能差异
// std::move 只对实现了移动语义的类类型（string, vector 等）才有意义
```

**误区4：临时对象立刻销毁**

```cpp
// const 引用或右值引用可以延长临时对象的生命周期
const std::string& s1 = std::string("hello");  // 生命周期延长到 s1 作用域结束
std::string&& s2 = std::string("world");        // 同样延长

cout << s1 << s2;  // ✅ 安全，临时对象还活着

// 但注意：只在直接绑定时延长，间接引用不会
const std::string& bad_ref = get_string();  // 如果返回引用，可能悬空
```

### 7. 值类别在函数重载中的选择

```cpp
class Widget {
public:
    // 左值引用限定：只能被 lvalue 调用
    void doWork() & {
        cout << "lvalue version\n";
    }

    // 右值引用限定：只能被 rvalue 调用
    void doWork() && {
        cout << "rvalue version\n";
    }
};

Widget w;
w.doWork();             // 调用 & 版本（w 是 lvalue）
Widget().doWork();      // 调用 && 版本（临时对象是 prvalue）
std::move(w).doWork();  // 调用 && 版本（std::move(w) 是 xvalue）
```

**引用限定的常见用途**：在右值对象上返回内部资源的引用是危险的。

```cpp
class Container {
    std::vector<int> data_;
public:
    // 危险：右值对象销毁后，返回的引用悬空
    // std::vector<int>& get() { return data_; }

    // 安全：左值对象返回引用，右值对象返回值
    std::vector<int>& get() & { return data_; }
    std::vector<int> get() && { return std::move(data_); }
};

Container c;
auto& ref = c.get();               // 调用 & 版本，返回引用 ✅
auto val = Container().get();      // 调用 && 版本，返回值（移动出来）✅
// auto& bad = Container().get();  // ❌ 编译错误！右值对象不能调用 & 版本
```

***

### 8. 极简总结

**lvalue = 有名字有地址 | prvalue = 临时值没名字 | xvalue = 有名字但快过期 | glvalue = lvalue + xvalue | rvalue = xvalue + prvalue | 右值引用变量本身是 lvalue | std::move 不移动任何东西 | 左值不一定能在赋值号左边**
