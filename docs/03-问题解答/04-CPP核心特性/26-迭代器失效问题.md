# 迭代器失效问题
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[继承与多态](../../02-CPP/04-继承与多态.md)、[核心机制](../../02-CPP/05-核心机制.md)、[异常处理](../../02-CPP/07-异常处理.md)、[移动语义](../../02-CPP/09-移动语义与完美转发.md)

### 1. 精髓速览

**迭代器失效** = 容器结构发生变化后，之前获取的迭代器可能指向无效内存，继续使用会导致未定义行为。不同容器的失效规则不同，必须牢记。

***

### 2. 各容器迭代器失效规则总览

| 操作 | vector | deque | list | map/set | unordered_map/set |
|------|:---:|:---:|:---:|:---:|:---:|
| push_back | 插入点之后失效 | 全部失效 | 不失效 | 不失效 | 可能全部失效(rehash) |
| push_front | - | 全部失效 | 不失效 | 不失效 | 可能全部失效(rehash) |
| insert | 插入点之后失效 | 全部失效 | 不失效 | 不失效 | 可能全部失效(rehash) |
| erase | 被删元素及其之后失效 | 被删处及两端失效 | 仅被删元素失效 | 仅被删元素失效 | 仅被删元素失效 |
| reserve | 全部失效 | - | - | - | - |
| resize | 全部失效 | - | - | - | - |
| rehash | - | - | - | - | 全部失效 |
| clear | 全部失效 | 全部失效 | 全部失效 | 全部失效 | 全部失效 |

**记忆口诀**：
- **连续内存容器**（vector/deque）：插入/删除可能移动元素，大量迭代器失效
- **节点容器**（list/map/set）：插入不影响，删除仅影响被删节点
- **哈希容器**：插入可能触发 rehash，导致全部失效

### 3. vector 迭代器失效详解

vector 是连续内存容器，插入可能导致重新分配，删除会导致后续元素前移。

**push_back 导致失效**：

```cpp
vector<int> v = {1, 2, 3};
auto it = v.begin();

v.push_back(4);   // 如果 capacity 不够，重新分配
// it 现在可能失效！指向旧内存

// 安全做法：预分配
v.reserve(100);   // 预分配足够空间
auto it = v.begin();
v.push_back(4);   // capacity 够，不重新分配，it 仍有效
```

**insert 导致失效**：

```cpp
vector<int> v = {1, 2, 3, 4, 5};
auto it = v.begin() + 2;  // 指向 3

v.insert(v.begin() + 1, 10);  // 在位置1插入10
// it 现在可能失效！插入点之后的元素被移动了
// v = {1, 10, 2, 3, 4, 5}
```

**erase 导致失效**：

```cpp
vector<int> v = {1, 2, 3, 4, 5};
auto it = v.begin() + 2;  // 指向 3

v.erase(v.begin() + 1);   // 删除 2
// it 失效！后续元素前移
// v = {1, 3, 4, 5}
```

**经典错误：遍历中删除**：

```cpp
vector<int> v = {1, 2, 3, 4, 5, 3, 6};

// 错误！erase 后 it 失效，++it 是 UB
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == 3) {
        v.erase(it);  // it 失效！
    }
}

// 正确写法1：erase 返回下一个有效迭代器
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 3) {
        it = v.erase(it);  // erase 返回被删元素之后的位置
    } else {
        ++it;
    }
}

// 正确写法2：C++20 std::erase_if
std::erase_if(v, [](int x) { return x == 3; });

// 正确写法3：从后往前删除（不移动未遍历的元素）
for (auto it = v.rbegin(); it != v.rend(); ) {
    if (*it == 3) {
        it = decltype(it)(v.erase(it.base()));  // 反向迭代器与 erase 配合较复杂
    } else {
        ++it;
    }
}
```

### 4. deque 迭代器失效详解

deque 是分段连续容器，插入和删除几乎总是导致所有迭代器失效。

```cpp
deque<int> dq = {1, 2, 3, 4, 5};
auto it = dq.begin() + 2;  // 指向 3

dq.push_back(6);    // 所有迭代器失效！
dq.push_front(0);   // 所有迭代器失效！
dq.erase(dq.begin());  // 所有迭代器失效！

// deque 的迭代器失效规则非常严格：
// - 任何插入操作 → 所有迭代器失效
// - 删除中间元素 → 所有迭代器失效
// - 删除首尾元素 → 仅被删元素的迭代器失效（引用和指针仍有效）

// 正确的遍历删除
for (auto it = dq.begin(); it != dq.end(); ) {
    if (*it == 3) {
        it = dq.erase(it);  // erase 返回下一个有效迭代器
    } else {
        ++it;
    }
}
```

**deque vs vector 迭代器失效对比**：

| 操作 | vector | deque |
|------|:---:|:---:|
| push_back（不扩容） | 插入点之后失效 | 全部失效 |
| push_back（扩容） | 全部失效 | 全部失效 |
| push_front | - | 全部失效 |
| erase 中间 | 被删及之后失效 | 全部失效 |
| erase 首尾 | 被删及之后失效 | 仅被删元素失效 |

### 5. list 迭代器失效详解

list 是双向链表，插入不影响任何迭代器，删除仅使被删元素的迭代器失效。

```cpp
list<int> lst = {1, 2, 3, 4, 5};
auto it1 = lst.begin();       // 指向 1
auto it2 = next(lst.begin(), 2);  // 指向 3

lst.push_back(6);    // it1, it2 仍有效
lst.push_front(0);   // it1, it2 仍有效
lst.insert(it2, 99); // it1, it2 仍有效，新节点在 it2 之前

// 删除
lst.erase(it2);      // it2 失效！it1 仍有效
// it2 不能再使用

// 正确的遍历删除
for (auto it = lst.begin(); it != lst.end(); ) {
    if (*it == 3) {
        it = lst.erase(it);  // erase 返回下一个迭代器
    } else {
        ++it;
    }
}

// list 特有：remove 更简洁
lst.remove(3);  // 删除所有值为3的元素，不会导致其他迭代器失效
lst.remove_if([](int x) { return x > 5; });  // 删除满足条件的元素
```

### 6. map/set 迭代器失效详解

关联容器（map/set/multimap/multiset）基于红黑树，插入不影响迭代器，删除仅使被删元素的迭代器失效。

```cpp
map<int, string> m = {{1, "a"}, {2, "b"}, {3, "c"}, {4, "d"}};
auto it1 = m.find(1);
auto it2 = m.find(3);

m.insert({5, "e"});  // it1, it2 仍有效
m[6] = "f";          // it1, it2 仍有效

// C++11 前：erase 后手动递增
for (auto it = m.begin(); it != m.end(); ) {
    if (it->first == 2) {
        m.erase(it++);  // 先拷贝 it，再自增，再删拷贝的
    } else {
        ++it;
    }
}

// C++11 起：erase 返回下一个迭代器
for (auto it = m.begin(); it != m.end(); ) {
    if (it->first == 2) {
        it = m.erase(it);  // C++11 起 erase 返回下一个迭代器
    } else {
        ++it;
    }
}

// C++17：extract 节点（不失效其他迭代器）
auto node = m.extract(3);  // 抽取节点，不影响其他迭代器
node.key() = 30;           // 修改 key
m.insert(std::move(node)); // 重新插入
```

**C++20 erase_if**：

```cpp
// C++20：统一的 erase_if
std::erase_if(m, [](const auto& pair) {
    return pair.second == "b";
});

// 也适用于 set
set<int> s = {1, 2, 3, 4, 5};
std::erase_if(s, [](int x) { return x % 2 == 0; });
// s = {1, 3, 5}
```

### 7. unordered_map 迭代器失效详解

unordered_map/set 基于哈希表，插入可能触发 rehash，导致所有迭代器失效。

```cpp
unordered_map<int, string> um = {{1, "a"}, {2, "b"}, {3, "c"}};
auto it = um.begin();

um.insert({4, "d"});  // 可能触发 rehash → it 失效！
um[5] = "e";          // 可能触发 rehash → it 失效！

// 预分配避免 rehash
um.reserve(1000);     // 预分配桶
um.max_load_factor(0.5f);  // 降低负载因子，减少 rehash 概率
auto it2 = um.begin();
um.insert({6, "f"});  // 不触发 rehash，it2 仍有效

// 删除：仅被删元素失效
for (auto it = um.begin(); it != um.end(); ) {
    if (it->first == 2) {
        it = um.erase(it);  // 仅 it 失效
    } else {
        ++it;
    }
}
```

**rehash 触发条件**：

```cpp
unordered_map<int, int> um;
um.max_load_factor();  // 默认 1.0

// 当 size >= bucket_count * max_load_factor 时触发 rehash
// rehash 后所有迭代器失效，但引用和指针仍有效（C++11 起）

// 安全做法：预分配
um.reserve(expected_size);  // 预分配足够的桶
```

### 8. 正确的 erase 写法总结

```cpp
// === 通用安全写法（C++11 起，所有容器适用）===
for (auto it = container.begin(); it != container.end(); ) {
    if (should_remove(*it)) {
        it = container.erase(it);  // erase 返回下一个有效迭代器
    } else {
        ++it;
    }
}

// === C++20 erase_if（最简洁）===
std::erase_if(container, predicate);

// === C++11 前：关联容器 ===
for (auto it = m.begin(); it != m.end(); ) {
    if (should_remove(*it)) {
        m.erase(it++);  // 先拷贝，再自增，再删拷贝的
    } else {
        ++it;
    }
}

// === C++11 前：序列容器 ===
for (auto it = v.begin(); it != v.end(); ) {
    if (should_remove(*it)) {
        it = v.erase(it);
    } else {
        ++it;
    }
}
```

**各容器 erase 返回值**：

| 容器 | erase 返回值 | C++11 前 |
|------|------|------|
| vector | 指向被删元素之后位置的迭代器 | 同（C++11 前也支持） |
| deque | 指向被删元素之后位置的迭代器 | 同 |
| list | 指向被删元素之后位置的迭代器 | 同 |
| map/set | 指向被删元素之后位置的迭代器 | C++11 前返回 void |
| unordered_map/set | 指向被删元素之后位置的迭代器 | C++11 起才有 |

### 9. 完整示例：安全遍历删除

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <map>
#include <unordered_map>
#include <algorithm>
using namespace std;

int main() {
    // === vector：erase + 返回值 ===
    vector<int> v = {1, 2, 3, 4, 5, 3, 6, 3, 7};
    cout << "Vector before: ";
    for (int x : v) cout << x << " ";
    cout << endl;

    for (auto it = v.begin(); it != v.end(); ) {
        if (*it == 3) {
            it = v.erase(it);
        } else {
            ++it;
        }
    }
    cout << "Vector after removing 3: ";
    for (int x : v) cout << x << " ";
    cout << endl;

    // === C++20 erase_if（如果可用）===
    // std::erase_if(v, [](int x) { return x > 5; });

    // === list：remove 更简洁 ===
    list<int> lst = {1, 2, 3, 4, 5, 3, 6};
    lst.remove(3);  // 一次删除所有 3
    cout << "List after remove(3): ";
    for (int x : lst) cout << x << " ";
    cout << endl;

    // === map：erase + 返回值 ===
    map<int, string> m = {{1, "a"}, {2, "b"}, {3, "c"}, {4, "d"}};
    for (auto it = m.begin(); it != m.end(); ) {
        if (it->first % 2 == 0) {
            it = m.erase(it);  // C++11 起
        } else {
            ++it;
        }
    }
    cout << "Map after removing even keys: ";
    for (const auto& [k, v] : m) cout << "{" << k << "," << v << "} ";
    cout << endl;

    // === unordered_map：注意 rehash ===
    unordered_map<int, string> um;
    um.reserve(100);  // 预分配，避免 rehash
    um = {{1, "a"}, {2, "b"}, {3, "c"}, {4, "d"}};

    for (auto it = um.begin(); it != um.end(); ) {
        if (it->first == 2) {
            it = um.erase(it);
        } else {
            ++it;
        }
    }
    cout << "Unordered_map after removing key 2: ";
    for (const auto& [k, v] : um) cout << "{" << k << "," << v << "} ";
    cout << endl;

    // === 嵌套容器：外层删除 + 内层删除 ===
    map<int, vector<int>> nested = {
        {1, {1, 2, 3}},
        {2, {4, 5, 6}},
        {3, {7, 8, 9}}
    };

    // 删除内层 vector 中的偶数
    for (auto& [key, vec] : nested) {
        for (auto it = vec.begin(); it != vec.end(); ) {
            if (*it % 2 == 0) {
                it = vec.erase(it);
            } else {
                ++it;
            }
        }
    }

    // 删除内层为空的外层条目
    for (auto it = nested.begin(); it != nested.end(); ) {
        if (it->second.empty()) {
            it = nested.erase(it);
        } else {
            ++it;
        }
    }

    cout << "Nested after cleanup: ";
    for (const auto& [k, vec] : nested) {
        cout << k << ":[";
        for (int x : vec) cout << x << " ";
        cout << "] ";
    }
    cout << endl;

    return 0;
}
```

### 10. 常见陷阱

**陷阱1：erase 后继续使用迭代器**

```cpp
// 错误：erase 后 it 已失效
auto it = v.begin();
v.erase(it);
cout << *it;  // UB！it 已失效

// 正确：使用 erase 返回值
it = v.erase(it);
cout << *it;  // OK，it 指向下一个元素
```

**陷阱2：在 range-for 中修改容器**

```cpp
// 错误：range-for 隐式使用迭代器
for (int x : v) {
    if (x == 3) v.push_back(10);  // 可能导致迭代器失效，UB
}

// 正确：显式使用迭代器
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 3) {
        v.push_back(10);  // it 可能失效！
        it = v.begin();   // 重新获取迭代器
    } else {
        ++it;
    }
}
```

**陷阱3：unordered_map 遍历中插入触发 rehash**

```cpp
unordered_map<int, int> um = {{1, 1}, {2, 2}};
for (auto& [k, v] : um) {
    um[k + 10] = v + 10;  // 插入可能触发 rehash → 迭代器失效 → UB
}

// 正确：先收集，再插入
vector<pair<int, int>> to_add;
for (const auto& [k, v] : um) {
    to_add.push_back({k + 10, v + 10});
}
for (const auto& [k, v] : to_add) {
    um[k] = v;
}
```

**陷阱4：保存 end() 迭代器**

```cpp
// 错误：end() 可能失效
auto end_it = v.end();
v.push_back(10);
// end_it 失效！
for (auto it = v.begin(); it != end_it; ++it) { /* UB */ }

// 正确：每次重新获取 end()
for (auto it = v.begin(); it != v.end(); ++it) { /* OK */ }
```

### 11. 极简总结

**连续容器(vector/deque)插入删除→大量迭代器失效 | 节点容器(list/map/set)删除→仅被删元素失效 | 哈希容器插入→可能rehash全失效 | erase用返回值获取下一个有效迭代器 | C++20用erase_if最安全**
