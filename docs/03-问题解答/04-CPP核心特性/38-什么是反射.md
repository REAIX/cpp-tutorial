# 什么是反射
> 📖 相关章节：[类与对象](../../02-CPP/03-类与对象.md)、[继承与多态](../../02-CPP/04-继承与多态.md)、[核心机制](../../02-CPP/05-核心机制.md)、[异常处理](../../02-CPP/07-异常处理.md)、[移动语义](../../02-CPP/09-移动语义与完美转发.md)

### 1. 核心速览

**反射** = 程序在运行时查看自身的结构（类名、成员变量、方法列表），并动态调用方法、访问字段。C++ 没有原生反射，但可以通过手动注册、宏+模板、第三方库等方式模拟。

***

### 2. 反射的定义

反射（Reflection）是一种能力：程序在运行时能够**自省**（introspection）和**自修改**（self-modification）。

- **自省**：运行时查询类型信息（有哪些字段、方法、基类）
- **自修改**：运行时动态创建实例、调用方法、访问字段

```
编译期知道的信息：  类名、成员列表、方法签名 → C++ 模板可以做到
运行时知道的信息：  对象的实际类型、字段值、方法地址 → 反射的目标
```

### 3. Java/C# 反射示例

#### 1. Java 反射

```java
// Java 反射：运行时查看类结构
import java.lang.reflect.*;

class Person {
    public String name;
    public int age;
    public void greet() { System.out.println("Hi, I'm " + name); }
}

public class Main {
    public static void main(String[] args) throws Exception {
        Person p = new Person();
        p.name = "Alice";
        p.age = 30;

        Class<?> cls = p.getClass();

        // 1. 获取类名
        System.out.println(cls.getName());  // "Person"

        // 2. 获取所有字段
        for (Field f : cls.getFields()) {
            System.out.println(f.getName() + " = " + f.get(p));
            // name = Alice
            // age = 30
        }

        // 3. 获取所有方法
        for (Method m : cls.getMethods()) {
            System.out.println(m.getName());
        }

        // 4. 动态调用方法
        Method greet = cls.getMethod("greet");
        greet.invoke(p);  // Hi, I'm Alice

        // 5. 动态修改字段
        Field nameField = cls.getField("name");
        nameField.set(p, "Bob");

        // 6. 动态创建实例
        Person p2 = (Person) cls.getDeclaredConstructor().newInstance();
    }
}
```

#### 2. C# 反射

```csharp
using System.Reflection;

class Person {
    public string Name { get; set; }
    public int Age { get; set; }
    public void Greet() => Console.WriteLine($"Hi, I'm {Name}");
}

// C# 反射
var type = typeof(Person);
var props = type.GetProperties();   // 获取属性
var methods = type.GetMethods();    // 获取方法

// 动态创建实例
var person = Activator.CreateInstance(type);
// 动态设置属性
type.GetProperty("Name").SetValue(person, "Alice");
// 动态调用方法
type.GetMethod("Greet").Invoke(person, null);
```

### 4. C++ 为什么没有原生反射

| 原因 | 说明 |
|------|------|
| 零开销原则 | 不用的功能不该有运行时开销 |
| 编译后信息丢失 | C++ 编译后类型信息大部分被擦除 |
| 设计哲学 | C++ 信任程序员，不做运行时检查 |
| ABI 兼容 | 反射元数据会影响二进制兼容性 |
| 编译速度 | 生成反射元数据会显著增加编译时间 |

C++ 的 RTTI（Run-Time Type Information）非常有限：

```cpp
// C++ 仅有的运行时类型信息
#include <typeinfo>

class Animal { public: virtual ~Animal() = default; };
class Dog : public Animal {};

Animal* a = new Dog();

// typeid：获取类型名（不可靠，实现相关）
std::cout << typeid(*a).name() << std::endl;  // 可能输出 "3Dog" 或其他乱码

// dynamic_cast：安全向下转型
Dog* d = dynamic_cast<Dog*>(a);  // 如果 a 不是 Dog，返回 nullptr

// 仅此而已！无法枚举字段、方法、基类
```

### 5. C++ 的替代方案

#### 1. 方案1：手动注册

最原始但最可控的方式——手动为每个类编写元数据：

```cpp
#include <iostream>
#include <string>
#include <functional>
#include <map>

class Widget {
public:
    int x = 0, y = 0;
    std::string name = "unnamed";

    // 手动注册成员信息
    struct FieldInfo {
        std::string name;
        std::function<void(Widget&, const std::string&)> setter;
        std::function<std::string(const Widget&)> getter;
    };

    static const std::vector<FieldInfo>& fields() {
        static std::vector<FieldInfo> f = {
            {"x", [](Widget& w, const std::string& v) { w.x = std::stoi(v); },
                 [](const Widget& w) { return std::to_string(w.x); }},
            {"y", [](Widget& w, const std::string& v) { w.y = std::stoi(v); },
                 [](const Widget& w) { return std::to_string(w.y); }},
            {"name", [](Widget& w, const std::string& v) { w.name = v; },
                    [](const Widget& w) { return w.name; }}
        };
        return f;
    }
};

// 通用序列化函数
std::string serialize(const Widget& w) {
    std::string result = "{";
    for (const auto& f : Widget::fields()) {
        result += "\"" + f.name + "\":\"" + f.getter(w) + "\",";
    }
    if (!result.empty()) result.back() = '}';
    return result;
}

// 通用反序列化函数
void deserialize(Widget& w, const std::map<std::string, std::string>& data) {
    for (const auto& f : Widget::fields()) {
        auto it = data.find(f.name);
        if (it != data.end()) f.setter(w, it->second);
    }
}

int main() {
    Widget w;
    w.x = 10; w.y = 20; w.name = "btn";
    std::cout << serialize(w) << std::endl;
    // {"x":"10","y":"20","name":"btn"}
}
```

**优点**：完全可控、无宏、编译快
**缺点**：手动维护、容易遗漏、代码冗余

#### 2. 方案2：宏 + 模板

用宏减少手动注册的重复代码：

```cpp
#include <iostream>
#include <string>
#include <tuple>

// 反射宏
#define REFLECT_FIELDS(...) \
    auto reflect_fields() { return std::make_tuple(__VA_ARGS__); } \
    auto reflect_fields() const { return std::make_tuple(__VA_ARGS__); }

#define FIELD(name) std::make_pair(#name, std::ref(name))

struct Person {
    std::string name;
    int age;
    double height;

    REFLECT_FIELDS(
        FIELD(name),
        FIELD(age),
        FIELD(height)
    )
};

// 遍历所有字段
template <typename T, typename Func, size_t... Is>
void for_each_field_impl(T& obj, Func func, std::index_sequence<Is...>) {
    auto fields = obj.reflect_fields();
    (func(std::get<Is>(fields).first, std::get<Is>(fields).second), ...);
}

template <typename T, typename Func>
void for_each_field(T& obj, Func func) {
    constexpr size_t N = std::tuple_size_v<decltype(obj.reflect_fields())>;
    for_each_field_impl(obj, func, std::make_index_sequence<N>{});
}

// 使用
int main() {
    Person p{"Alice", 30, 1.65};

    for_each_field(p, [](const char* name, auto& value) {
        std::cout << name << " = " << value << std::endl;
    });
    // name = Alice
    // age = 30
    // height = 1.65
}
```

**优点**：代码简洁、编译期生成
**缺点**：宏不安全、调试困难、不支持继承

#### 3. 方案3：Boost.PFR（编译期聚合体反射）

Boost.PFR 可以自动反射聚合体（aggregate）的成员，无需任何宏：

```cpp
#include <boost/pfr.hpp>
#include <iostream>
#include <string>

struct Person {
    std::string name;
    int age;
    double height;
    // 不需要任何宏！只要是聚合体就行
};

int main() {
    Person p{"Alice", 30, 1.65};

    // 自动遍历所有字段
    boost::pfr::for_each_field(p, [](const auto& field) {
        std::cout << field << std::endl;
    });
    // Alice
    // 30
    // 1.65

    // 获取字段数量
    constexpr size_t N = boost::pfr::tuple_size_v<Person>;  // 3

    // 按索引访问
    std::cout << boost::pfr::get<0>(p) << std::endl;  // Alice
    std::cout << boost::pfr::get<1>(p) << std::endl;  // 30
}
```

**优点**：零宏、自动推导、编译期
**缺点**：只支持聚合体（无自定义构造函数、无私有成员、无虚函数）

#### 4. 方案4：RTTR（运行时类型反射库）

RTTR 是一个功能完整的运行时反射库：

```cpp
#include <rttr/registration>
#include <rttr/type>
#include <iostream>

class Person {
public:
    std::string name;
    int age;

    void greet() { std::cout << "Hi, I'm " << name << std::endl; }
};

// 注册反射信息
RTTR_REGISTRATION {
    rttr::registration::class_<Person>("Person")
        .constructor<>()
        .property("name", &Person::name)
        .property("age", &Person::age)
        .method("greet", &Person::greet);
}

int main() {
    // 运行时查询类型
    rttr::type t = rttr::type::get<Person>();
    std::cout << t.get_name() << std::endl;  // "Person"

    // 遍历属性
    for (auto& prop : t.get_properties()) {
        std::cout << "property: " << prop.get_name() << std::endl;
    }

    // 动态创建实例
    rttr::variant var = t.create();
    Person* p = var.get_value<Person*>();
    p->name = "Alice";
    p->age = 30;

    // 动态调用方法
    rttr::method greet = t.get_method("greet");
    greet.invoke(var);
}
```

**优点**：功能完整、运行时反射
**缺点**：需要手动注册、有运行时开销、外部依赖

#### 5. 方案5：Magic Enum（枚举反射）

```cpp
#include <magic_enum.hpp>
#include <iostream>

enum class Color { Red, Green, Blue };

int main() {
    // 枚举值 → 字符串
    std::cout << magic_enum::enum_name(Color::Red) << std::endl;  // "Red"

    // 字符串 → 枚举值
    auto c = magic_enum::enum_cast<Color>("Green");
    if (c) std::cout << static_cast<int>(c.value()) << std::endl;  // 1

    // 遍历所有枚举值
    for (auto [name, value] : magic_enum::enum_entries<Color>()) {
        std::cout << name << " = " << static_cast<int>(value) << std::endl;
    }
}
```

### 6. 反射方案对比

| 方案 | 编译期/运行时 | 需要宏 | 支持类类型 | 支持私有成员 | 性能开销 |
|------|:---:|:---:|:---:|:---:|:---:|
| 手动注册 | 运行时 | 否 | 是 | 是 | 低 |
| 宏+模板 | 编译期 | 是 | 部分 | 否 | 零 |
| Boost.PFR | 编译期 | 否 | 仅聚合体 | 否 | 零 |
| RTTR | 运行时 | 是 | 是 | 是 | 中 |
| Magic Enum | 编译期 | 否 | 仅枚举 | — | 零 |
| C++26 反射 | 编译期 | 否 | 是 | 是 | 零 |

### 7. 反射的优缺点

| 优点 | 缺点 |
|------|------|
| 序列化/反序列化自动化 | 运行时反射有性能开销 |
| ORM 数据库映射 | 类型安全降低 |
| 插件系统/动态加载 | 编译器实现复杂 |
| UI 绑定（属性编辑器） | 调试困难 |
| 代码生成 | 增加编译时间 |
| 通用算法（遍历任意结构） | 反射代码与业务代码耦合 |

### 8. C++26 静态反射提案

C++26 可能引入静态反射（P2996 提案），这是 C++ 社区期待已久的特性：

```cpp
// C++26 静态反射（提案语法，尚未最终确定）
#include <meta>

struct Person {
    std::string name;
    int age;
    double height;
};

template <typename T>
void print_members(const T& obj) {
    // 编译期遍历所有成员
    template for (constexpr auto member : std::meta::members_of(^T)) {
        std::cout << std::meta::name_of(member) << ": "
                  << obj.[member] << std::endl;
    }
}

int main() {
    Person p{"Alice", 30, 1.65};
    print_members(p);
    // name: Alice
    // age: 30
    // height: 1.65
}
```

**注意**：以上语法基于提案，最终标准可能有变化。C++26 反射的核心特性包括：

| 特性 | 说明 |
|------|------|
| `members_of` | 获取类型的所有成员 |
| `name_of` | 获取成员名称 |
| `type_of` | 获取成员类型 |
| `template for` | 编译期遍历 |
| `^T` | 获取类型的元信息（meta type） |

### 9. 序列化与反射

反射最常见的应用场景是序列化/反序列化：

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <map>

// 简单的键值对序列化（基于手动反射）
class Serializable {
public:
    virtual ~Serializable() = default;

    // 子类需要实现这两个方法
    virtual std::map<std::string, std::string> to_map() const = 0;
    virtual void from_map(const std::map<std::string, std::string>&) = 0;

    std::string to_json() const {
        std::ostringstream oss;
        oss << "{";
        bool first = true;
        for (const auto& [k, v] : to_map()) {
            if (!first) oss << ",";
            oss << "\"" << k << "\":\"" << v << "\"";
            first = false;
        }
        oss << "}";
        return oss.str();
    }

    void from_json(const std::string& json) {
        // 简化：假设输入是 {"key":"value","key2":"value2"} 格式
        std::map<std::string, std::string> data;
        // ... 解析 json 到 data ...
        from_map(data);
    }
};

class Config : public Serializable {
public:
    std::string host = "localhost";
    int port = 8080;
    bool verbose = false;

    std::map<std::string, std::string> to_map() const override {
        return {
            {"host", host},
            {"port", std::to_string(port)},
            {"verbose", verbose ? "true" : "false"}
        };
    }

    void from_map(const std::map<std::string, std::string>& data) override {
        if (data.count("host")) host = data.at("host");
        if (data.count("port")) port = std::stoi(data.at("port"));
        if (data.count("verbose")) verbose = (data.at("verbose") == "true");
    }
};

int main() {
    Config cfg;
    cfg.host = "example.com";
    cfg.port = 443;
    cfg.verbose = true;

    std::cout << cfg.to_json() << std::endl;
    // {"host":"example.com","port":"443","verbose":"true"}

    Config cfg2;
    cfg2.from_json("{\"host\":\"test.com\",\"port\":\"3000\"}");
    std::cout << cfg2.host << ":" << cfg2.port << std::endl;  // test.com:3000
}
```

### 10. 完整示例：轻量级反射系统

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <map>
#include <functional>
#include <any>

// 字段描述
struct FieldDescriptor {
    std::string name;
    std::type_info const* type;
    std::function<std::any(void*)> getter;
    std::function<void(void*, const std::any&)> setter;
};

// 类型描述
struct TypeDescriptor {
    std::string name;
    std::vector<FieldDescriptor> fields;
    std::function<void*()> constructor;
};

// 反射注册表
class ReflectionRegistry {
    std::map<std::string, TypeDescriptor> types_;
public:
    static ReflectionRegistry& instance() {
        static ReflectionRegistry reg;
        return reg;
    }

    void register_type(const TypeDescriptor& desc) {
        types_[desc.name] = desc;
    }

    TypeDescriptor* get_type(const std::string& name) {
        auto it = types_.find(name);
        return it != types_.end() ? &it->second : nullptr;
    }
};

// 注册宏
#define REFLECT_BEGIN(Type) \
    static void reflect_register() { \
        TypeDescriptor desc; \
        desc.name = #Type; \
        desc.constructor = []() -> void* { return new Type(); };

#define REFLECT_FIELD(Type, field) \
        desc.fields.push_back({#field, &typeid(Type::field), \
            [](void* obj) -> std::any { return static_cast<Type*>(obj)->field; }, \
            [](void* obj, const std::any& val) { static_cast<Type*>(obj)->field = std::any_cast<decltype(Type::field)>(val); }});

#define REFLECT_END() \
        ReflectionRegistry::instance().register_type(desc); \
    }

// 使用
class Player {
public:
    std::string name = "unnamed";
    int level = 1;
    double hp = 100.0;

    REFLECT_BEGIN(Player)
    REFLECT_FIELD(Player, name)
    REFLECT_FIELD(Player, level)
    REFLECT_FIELD(Player, hp)
    REFLECT_END()
};

int main() {
    // 注册
    Player::reflect_register();

    // 运行时反射
    TypeDescriptor* type = ReflectionRegistry::instance().get_type("Player");
    if (type) {
        std::cout << "Type: " << type->name << std::endl;
        std::cout << "Fields:" << std::endl;
        for (const auto& f : type->fields) {
            std::cout << "  " << f.name << std::endl;
        }

        // 动态创建实例
        void* obj = type->constructor();

        // 动态设置字段
        for (auto& f : type->fields) {
            if (f.name == "name") f.setter(obj, std::any(std::string("Hero")));
            if (f.name == "level") f.setter(obj, std::any(42));
            if (f.name == "hp") f.setter(obj, std::any(99.5));
        }

        // 动态读取字段
        for (auto& f : type->fields) {
            std::cout << f.name << " = ";
            auto val = f.getter(obj);
            if (val.type() == typeid(std::string))
                std::cout << std::any_cast<std::string>(val);
            else if (val.type() == typeid(int))
                std::cout << std::any_cast<int>(val);
            else if (val.type() == typeid(double))
                std::cout << std::any_cast<double>(val);
            std::cout << std::endl;
        }

        delete static_cast<Player*>(obj);
    }
}
```

### 11. 极简总结

**反射 = 运行时查看类型结构 → C++ 没有原生反射 → 手动注册/宏+模板/第三方库/等C++26**

| 你的需求 | 推荐方案 |
|----------|----------|
| 枚举转字符串 | Magic Enum |
| 聚合体序列化 | Boost.PFR |
| 完整运行时反射 | RTTR |
| 简单序列化 | 手动注册 |
| 未来项目 | 等待 C++26 静态反射 |
