# 泛型、模板、模板编程、类型萃取详解
> 📖 相关章节：[模板基础](../../02-CPP/10-模板基础.md)、[模板进阶](../../02-CPP/11-模板进阶.md)

## 1. 什么是泛型？

### 1. 核心概念

**泛型（Generic Programming）** = 让代码"通用任意类型"。

一套代码可以支持：`int`、`float`、`string`、自定义类……不用为每种类型写重复逻辑。

### 2. 优点

- **代码复用**：写一次，多处使用
- **类型安全**：编译期检查，避免运行时错误
- **无冗余**：消除重复代码

### 3. 不同语言的叫法

| 语言 | 叫法 | 实现方式 |
|------|------|----------|
| Java / C# | 泛型（Generics） | 运行时擦除 / 具体化 |
| C++ | 模板（Templates） | 编译期生成 |
| Rust | 泛型（Generics） | 单态化（Monomorphization） |

## 2. 什么是模板？

### 1. 核心概念

**模板（Template）** = C++ 实现泛型的工具。

你写一个"模板"，编译器根据你传入的类型，自动生成对应版本的代码。

### 2. 函数模板示例

```cpp
// 模板定义
template <typename T>
T add(T a, T b) {
    return a + b;
}

// 编译器自动生成：
// int add(int a, int b);
// double add(double a, double b);
// string add(string a, string b);
```

### 3. 使用示例

```cpp
#include <iostream>
#include <string>

template <typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    // 编译器自动推导类型
    std::cout << add(1, 2) << std::endl;           // int: 3
    std::cout << add(1.5, 2.5) << std::endl;       // double: 4.0
    std::cout << add(std::string("Hello, "),
                     std::string("World!")) << std::endl;  // string

    return 0;
}
```

### 4. 特点

- **编译期生成**：每个类型生成独立版本
- **运行零开销**：没有虚函数表、没有动态分发
- **类型安全**：编译期检查，不支持的操作会报错

## 3. 什么是模板编程？

### 1. 核心概念

**模板元编程（Template Metaprogramming, TMP）** = 在编译期运行逻辑。

把计算、判断、分支、循环，全部放到编译阶段完成，运行时不花任何性能。

### 2. 编译期计算示例

```cpp
// 编译期计算阶乘
template <int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

// 递归终止条件
template <>
struct Factorial<0> {
    static constexpr int value = 1;
};

int main() {
    // 编译期计算，运行时直接使用结果
    constexpr int result = Factorial<5>::value;  // 120
    std::cout << result << std::endl;
    return 0;
}
```

### 3. 作用

- **极致性能**：编译期计算，运行时无开销
- **编译期检查**：提前发现错误
- **STL 底层大量使用**：迭代器、容器、算法都依赖模板

### 4. 现代 C++ 的改进

C++11 引入 `constexpr` 后，很多模板元编程可以用更简洁的方式实现：

```cpp
// C++11 之前：模板元编程
template <int N>
struct Factorial { ... };

// C++11 及以后：constexpr 函数
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

int main() {
    constexpr int result = factorial(5);  // 编译期计算
    return 0;
}
```

## 4. 什么是类型萃取？

### 1. 核心概念

**类型萃取（Type Traits）** = 编译期"查看类型信息"的工具。

可以在编译期判断：
- 是不是整数
- 是不是指针
- 是不是类
- 是否可拷贝
- 是否是浮点型

### 2. 基本用法

```cpp
#include <type_traits>
#include <iostream>

int main() {
    // 判断类型特性
    std::cout << std::boolalpha;
    std::cout << "int is integral: "
              << std::is_integral<int>::value << std::endl;        // true
    std::cout << "double is integral: "
              << std::is_integral<double>::value << std::endl;     // false
    std::cout << "int* is pointer: "
              << std::is_pointer<int*>::value << std::endl;        // true
    std::cout << "int is class: "
              << std::is_class<int>::value << std::endl;           // false

    return 0;
}
```

### 3. C++17 简化写法

```cpp
#include <type_traits>

// C++11/14 写法
std::is_integral<int>::value

// C++17 写法（更简洁）
std::is_integral_v<int>
```

### 4. 实战应用：智能适配不同类型

```cpp
#include <type_traits>
#include <iostream>
#include <string>

// 针对整数类型的优化
template <typename T>
typename std::enable_if<std::is_integral_v<T>, T>::type
process(T value) {
    std::cout << "Processing integer: " << value << std::endl;
    return value * 2;
}

// 针对浮点类型的优化
template <typename T>
typename std::enable_if<std::is_floating_point_v<T>, T>::type
process(T value) {
    std::cout << "Processing float: " << value << std::endl;
    return value * 1.5;
}

// C++17 更简洁的写法（if constexpr）
template <typename T>
auto process_cpp17(T value) {
    if constexpr (std::is_integral_v<T>) {
        std::cout << "Integer: " << value << std::endl;
        return value * 2;
    } else if constexpr (std::is_floating_point_v<T>) {
        std::cout << "Float: " << value << std::endl;
        return value * 1.5;
    }
}

int main() {
    process(42);        // Processing integer: 42
    process(3.14);      // Processing float: 3.14
    return 0;
}
```

### 5. 常见类型萃取工具

| 类型萃取 | 作用 | 示例 |
|----------|------|------|
| `is_integral` | 是否整数类型 | `int`, `long`, `char` |
| `is_floating_point` | 是否浮点类型 | `float`, `double` |
| `is_pointer` | 是否指针类型 | `int*`, `void*` |
| `is_class` | 是否类类型 | `std::string`, 自定义类 |
| `is_same` | 两个类型是否相同 | `is_same<int, int>` |
| `remove_const` | 去除 const 修饰 | `const int` → `int` |
| `decay` | 类型退化 | `int&` → `int`, `int[]` → `int*` |

## 5. 综合实战：通用容器

```cpp
#include <iostream>
#include <vector>
#include <type_traits>
#include <string>

// 通用打印函数，支持所有可打印类型
template <typename T>
void print_container(const std::vector<T>& container) {
    std::cout << "[ ";
    for (const auto& item : container) {
        std::cout << item << " ";
    }
    std::cout << "]" << std::endl;
}

// 针对字符串的特殊处理
template <typename T>
typename std::enable_if<std::is_same_v<T, std::string>, void>::type
print_special(const std::vector<T>& container) {
    std::cout << "Strings: [ ";
    for (const auto& s : container) {
        std::cout << "\"" << s << "\" ";
    }
    std::cout << "]" << std::endl;
}

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};
    std::vector<double> floats = {1.1, 2.2, 3.3};
    std::vector<std::string> strs = {"Hello", "World"};

    print_container(nums);     // [ 1 2 3 4 5 ]
    print_container(floats);   // [ 1.1 2.2 3.3 ]
    print_container(strs);     // [ Hello World ]

    print_special(strs);       // Strings: [ "Hello" "World" ]

    return 0;
}
```

## 6. 总结

### 1. 四个概念的关系

```
泛型（Generic）
  └─> 是一种编程范式/思想
       └─> C++ 用模板（Template）实现
            └─> 模板编程（TMP）是高级用法
                 └─> 类型萃取（Type Traits）是辅助工具
```

### 2. 对比表格

| 概念 | 本质 | 作用 | 关键特性 |
|------|------|------|----------|
| **泛型** | 编程范式 | 代码通用化 | 类型参数化 |
| **模板** | C++ 语言特性 | 实现泛型 | 编译期生成 |
| **模板编程** | 高级技巧 | 编译期计算 | 零运行时开销 |
| **类型萃取** | 工具库 | 查询类型信息 | 编译期判断 |

### 3. 核心原则

- 泛型是思想，模板是实现
- 模板在编译期生成代码，运行零开销
- 类型萃取让模板"智能"适配不同类型
- 现代 C++（C++17/20）用 `if constexpr`、`concepts` 简化模板编程
