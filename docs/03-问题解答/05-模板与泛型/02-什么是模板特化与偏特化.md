# 什么是模板特化与偏特化
> 📖 相关章节：[模板基础](../../02-CPP/10-模板基础.md)

> 特化是从通用走向特殊，偏特化是半通用的艺术。

***

### 1. 核心提炼

模板特化是为特定类型提供定制实现：全特化锁定所有模板参数，偏特化锁定部分参数或对参数施加约束，两者都让编译器在匹配时优先选择更"特殊"的版本。

***

### 2. 全特化（Full Specialization）

全特化将模板的所有参数都固定为具体类型，提供一个完全定制的实现：

```cpp
#include <iostream>
#include <cstring>

template<typename T>
struct TypeInfo {
    static const char* name() { return "未知类型"; }
    static std::size_t size() { return sizeof(T); }
};

template<>
struct TypeInfo<int> {
    static const char* name() { return "int"; }
    static std::size_t size() { return sizeof(int); }
};

template<>
struct TypeInfo<double> {
    static const char* name() { return "double"; }
    static std::size_t size() { return sizeof(double); }
};

template<>
struct TypeInfo<const char*> {
    static const char* name() { return "const char*"; }
    static std::size_t size() { return sizeof(const char*); }
};

int main() {
    std::cout << TypeInfo<char>::name()    << ": " << TypeInfo<char>::size()    << "\n";
    std::cout << TypeInfo<int>::name()     << ": " << TypeInfo<int>::size()     << "\n";
    std::cout << TypeInfo<double>::name()  << ": " << TypeInfo<double>::size()  << "\n";
    std::cout << TypeInfo<const char*>::name() << ": " << TypeInfo<const char*>::size() << "\n";
}
```

输出：

```
未知类型: 1
int: 4
double: 8
const char*: 8
```

全特化语法要点：

| 要素 | 写法 | 说明 |
|------|------|------|
| 声明 | `template<> struct Name<具体类型>` | 空的template<> |
| 定义 | 完整实现，无模板参数 | 所有类型已确定 |
| 成员函数特化 | `template<> void f<int>(int)` | 可只特化某个成员 |
| 优先级 | 全特化 > 偏特化 > 主模板 | 编译器选最特殊 |

**成员函数级别的全特化**：

```cpp
#include <iostream>

template<typename T>
class Container {
public:
    void process(T val) {
        std::cout << "通用处理: " << val << "\n";
    }
};

template<>
void Container<int>::process(int val) {
    std::cout << "int专用处理: " << val * 2 << "\n";
}

int main() {
    Container<double> cd;
    Container<int> ci;

    cd.process(3.14);
    ci.process(42);
}
```

### 3. 偏特化（Partial Specialization）

偏特化只固定部分模板参数，或对参数施加约束，剩余参数仍为模板参数：

```cpp
#include <iostream>

template<typename T, typename U>
struct Pair {
    void describe() {
        std::cout << "通用 Pair<T, U>\n";
    }
};

template<typename T>
struct Pair<T, T> {
    void describe() {
        std::cout << "相同类型的 Pair<T, T>\n";
    }
};

template<typename T>
struct Pair<T, int> {
    void describe() {
        std::cout << "第二参数为int的 Pair<T, int>\n";
    }
};

template<typename T, typename U>
struct Pair<T*, U*> {
    void describe() {
        std::cout << "双指针 Pair<T*, U*>\n";
    }
};

int main() {
    Pair<double, char>{}.describe();
    Pair<int, int>{}.describe();
    Pair<double, int>{}.describe();
    Pair<int*, double*>{}.describe();
}
```

输出：

```
通用 Pair<T, U>
相同类型的 Pair<T, T>
第二参数为int的 Pair<T, int>
双指针 Pair<T*, U*>
```

偏特化的常见模式：

| 偏特化模式 | 示例 | 含义 |
|-----------|------|------|
| 固定某个参数 | `Pair<T, int>` | 第二参数锁定为int |
| 两参数相同 | `Pair<T, T>` | 两个参数类型一致 |
| 指针变体 | `Pair<T*, U*>` | 两个参数都是指针 |
| 引用变体 | `Wrapper<T&>` | 参数是引用 |
| 数组变体 | `Array<T, N>` | 固定大小数组 |
| 模板模板参数 | `Container<C, T>` | C本身是模板 |

### 4. 函数模板特化 vs 重载

函数模板的全特化存在，但**推荐使用重载而非特化**：

```cpp
#include <iostream>
#include <cstring>

template<typename T>
void describe(T val) {
    std::cout << "通用: " << val << "\n";
}

template<>
void describe<const char*>(const char* val) {
    std::cout << "特化字符串: " << val << "\n";
}

void describe(int val) {
    std::cout << "重载int: " << val << "\n";
}

int main() {
    describe(3.14);
    describe("hello");
    describe(42);

    const char* s = "world";
    describe(s);
}
```

输出：

```
通用: 3.14
特化字符串: hello
重载int: 42
特化字符串: world
```

**为什么推荐重载而非特化**：

```cpp
#include <iostream>

template<typename T>
void call(T val) {
    std::cout << "主模板\n";
}

template<>
void call<int*>(int* val) {
    std::cout << "int*全特化\n";
}

template<typename T>
void call(T* val) {
    std::cout << "指针重载\n";
}

int main() {
    int x = 10;
    call(&x);
}
```

输出：

```
指针重载
```

原因：重载解析先选模板，特化不影响重载选择。`call(T*)` 比 `call(T)` 更匹配 `int*`，编译器选了 `call(T*)` 后根本不会考虑 `call<int*>` 的全特化。

| 特性 | 函数模板特化 | 函数重载 |
|------|------------|---------|
| 参与重载解析 | ❌ 不参与 | ✅ 参与 |
| 优先级 | 仅在主模板被选中后 | 正常参与选择 |
| 偏特化 | ❌ 不支持 | ✅ 通过重载实现 |
| 可见性 | 容易被忽略 | 直观 |
| 推荐度 | ⚠️ 不推荐 | ✅ 推荐 |

> ⚠️ 函数模板**不支持偏特化**，只能用重载或SFINAE/if-constexpr替代。

### 5. 类模板偏特化的高级模式

```cpp
#include <iostream>
#include <vector>
#include <array>

template<typename T>
struct IsPointer {
    static constexpr bool value = false;
    using element_type = T;
};

template<typename T>
struct IsPointer<T*> {
    static constexpr bool value = true;
    using element_type = T;
};

template<typename T>
struct IsPointer<T* const> {
    static constexpr bool value = true;
    using element_type = T;
};

template<typename T>
inline constexpr bool is_pointer_v = IsPointer<T>::value;

template<typename T, std::size_t N>
struct ArrayInfo {
    static constexpr std::size_t size = N;
    using element_type = T;
    static void print() {
        std::cout << "数组: " << N << " 个 " << typeid(T).name() << "\n";
    }
};

template<typename T>
struct ArrayInfo<T, 0> {
    static constexpr std::size_t size = 0;
    using element_type = T;
    static void print() {
        std::cout << "空数组\n";
    }
};

template<typename T, std::size_t N>
struct ArrayInfo<T[N]> {
    static constexpr std::size_t size = N;
    using element_type = T;
    static void print() {
        std::cout << "原生数组特化: " << N << " 个 " << typeid(T).name() << "\n";
    }
};

int main() {
    std::cout << "int* 是指针: " << is_pointer_v<int*> << "\n";
    std::cout << "int  是指针: " << is_pointer_v<int> << "\n";
    std::cout << "int* const 是指针: " << is_pointer_v<int* const> << "\n";

    ArrayInfo<int, 5>::print();
    ArrayInfo<double, 0>::print();
}
```

### 6. type_traits中的特化应用

标准库的 `type_traits` 大量使用模板特化：

```cpp
#include <iostream>
#include <type_traits>

template<typename T>
struct RemoveReference {
    using type = T;
};

template<typename T>
struct RemoveReference<T&> {
    using type = T;
};

template<typename T>
struct RemoveReference<T&&> {
    using type = T;
};

template<typename T>
using remove_reference_t = typename RemoveReference<T>::type;

template<typename T>
struct AddPointer {
    using type = T*;
};

template<typename T>
struct AddPointer<T&> {
    using type = T*;
};

template<typename T>
struct AddPointer<T&&> {
    using type = T*;
};

template<typename T>
using add_pointer_t = typename AddPointer<T>::type;

template<bool Cond, typename T = void>
struct EnableIf {};

template<typename T>
struct EnableIf<true, T> {
    using type = T;
};

template<bool Cond, typename T = void>
using enable_if_t = typename EnableIf<Cond, T>::type;

template<typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
void only_integral(T val) {
    std::cout << "整数: " << val << "\n";
}

int main() {
    using A = remove_reference_t<int&>;
    using B = remove_reference_t<int&&>;
    using C = remove_reference_t<int>;

    std::cout << std::is_same_v<A, int> << "\n";
    std::cout << std::is_same_v<B, int> << "\n";
    std::cout << std::is_same_v<C, int> << "\n";

    using D = add_pointer_t<int&>;
    std::cout << std::is_same_v<D, int*> << "\n";

    only_integral(42);
    only_integral(3.14);
}
```

type_traits特化模式一览：

| 特化模式 | 示例 | 作用 |
|---------|------|------|
| 引用移除 | `RemoveReference<T&>` | 剥离引用 |
| const移除 | `RemoveConst<const T>` | 剥离const |
| 指针检测 | `IsPointer<T*>` | 类型判断 |
| 条件启用 | `EnableIf<true, T>` | SFINAE |
| 条件选择 | `Conditional<true, A, B>` | 编译期分支 |

### 7. 偏序规则与匹配优先级

当多个偏特化都匹配时，编译器选择"更特殊"的那个：

```cpp
#include <iostream>

template<typename T>
struct S {
    void who() { std::cout << "主模板\n"; }
};

template<typename T>
struct S<T*> {
    void who() { std::cout << "指针偏特化\n"; }
};

template<typename T>
struct S<T* const> {
    void who() { std::cout << "const指针偏特化\n"; }
};

template<>
struct S<int*> {
    void who() { std::cout << "int*全特化\n"; }
};

int main() {
    S<double>{}.who();
    S<double*>{}.who();
    S<double* const>{}.who();
    S<int*>{}.who();
}
```

输出：

```
主模板
指针偏特化
const指针偏特化
int*全特化
```

优先级规则：

```
全特化 < 偏特化（更具体） < 偏特化（较通用） < 主模板
  ↑                                        ↑
最优先                                   最后选择
```

| 调用 | 候选项 | 选择 | 原因 |
|------|--------|------|------|
| `S<double>` | 主模板 | 主模板 | 唯一匹配 |
| `S<double*>` | 主模板、`S<T*>` | `S<T*>` | 偏特化更特殊 |
| `S<double* const>` | 主模板、`S<T*>`、`S<T* const>` | `S<T* const>` | 最特殊 |
| `S<int*>` | 主模板、`S<T*>`、`S<int*>` | `S<int*>` | 全特化最优先 |

> ⚠️ 如果两个偏特化同样特殊，编译器会报歧义错误。

### 8. 常见陷阱与误区

**陷阱1：特化不参与重载解析**

```cpp
#include <iostream>

template<typename T>
void f(T) { std::cout << "主模板\n"; }

template<>
void f<int*>(int*) { std::cout << "int*特化\n"; }

template<typename T>
void f(T*) { std::cout << "指针重载\n"; }

int main() {
    int* p = nullptr;
    f(p);
}
```

输出：`指针重载`（特化版本被跳过）

**陷阱2：全特化声明必须与定义在同一命名空间**

```cpp
#include <iostream>

namespace N {
    template<typename T>
    struct Wrapper {
        T value;
    };
}

template<>
struct N::Wrapper<int> {
    int value;
    int doubled() const { return value * 2; }
};

int main() {
    N::Wrapper<double> wd{3.14};
    N::Wrapper<int> wi{42};
    std::cout << wi.doubled() << "\n";
}
```

**陷阱3：偏特化不能改变模板参数个数**

```cpp
template<typename T, typename U>
struct Pair {};

template<typename T>
struct Pair<T, T> {};

template<typename T>
struct Pair<T> {};
```

最后一行非法——偏特化不能减少模板参数个数。

**陷阱4：函数模板不支持偏特化**

```cpp
template<typename T, typename U>
void func(T, U) {}

template<typename T>
void func<T, int>(T, int) {}
```

最后一行非法——函数模板偏特化不存在。应使用重载：

```cpp
template<typename T>
void func(T, int) {}
```

陷阱汇总：

| 陷阱 | 说明 | 正确做法 |
|------|------|---------|
| 函数模板偏特化 | 不存在 | 用重载替代 |
| 特化不参与重载解析 | 只在主模板选中后考虑 | 用重载替代 |
| 跨命名空间特化 | 需在原命名空间特化 | 在同一命名空间 |
| 改变参数个数 | 偏特化参数必须匹配 | 保持参数个数一致 |
| 歧义偏特化 | 两个偏特化同样特殊 | 确保只有一个最特殊 |

### 9. 变量模板的特化

C++14引入变量模板，同样支持特化：

```cpp
#include <iostream>
#include <type_traits>

template<typename T>
constexpr const char* type_name = "未知";

template<>
constexpr const char* type_name<int> = "int";

template<>
constexpr const char* type_name<double> = "double";

template<>
constexpr const char* type_name<float> = "float";

template<typename T>
constexpr const char* type_name<T*> = "指针";

template<typename T>
constexpr bool is_smart_pointer = false;

template<typename T>
constexpr bool is_smart_pointer<std::unique_ptr<T>> = true;

template<typename T>
constexpr bool is_smart_pointer<std::shared_ptr<T>> = true;

int main() {
    std::cout << type_name<int> << "\n";
    std::cout << type_name<double> << "\n";
    std::cout << type_name<char> << "\n";
    std::cout << type_name<int*> << "\n";

    std::cout << std::boolalpha;
    std::cout << "unique_ptr: " << is_smart_pointer<std::unique_ptr<int>> << "\n";
    std::cout << "shared_ptr: " << is_smart_pointer<std::shared_ptr<int>> << "\n";
    std::cout << "raw ptr:    " << is_smart_pointer<int*> << "\n";
}
```

### 10. 特化与SFINAE/Concepts的关系

```cpp
#include <iostream>
#include <type_traits>
#include <concepts>

template<typename T, typename = void>
struct HasSize : std::false_type {};

template<typename T>
struct HasSize<T, std::void_t<decltype(std::declval<T>().size())>> : std::true_type {};

template<typename T>
inline constexpr bool has_size_v = HasSize<T>::value;

template<typename T>
    requires std::is_integral_v<T>
T add(T a, T b) {
    std::cout << "整数版本\n";
    return a + b;
}

template<typename T>
    requires (!std::is_integral_v<T>)
T add(T a, T b) {
    std::cout << "非整数版本\n";
    return a + b;
}

int main() {
    std::cout << std::boolalpha;
    std::cout << "string有size: " << has_size_v<std::string> << "\n";
    std::cout << "int有size:    " << has_size_v<int> << "\n";

    add(1, 2);
    add(1.5, 2.5);
}
```

三种编译期分支机制对比：

| 机制 | C++版本 | 复杂度 | 错误信息 | 适用场景 |
|------|---------|--------|---------|---------|
| 模板特化 | C++98 | 中等 | 一般 | 类型判断、条件类型 |
| SFINAE | C++11 | 高 | 难读 | 条件启用函数/类 |
| Concepts | C++20 | 低 | 清晰 | 约束模板参数 |

***

### 11. 极简总结

| 概念 | 要点 |
|------|------|
| 全特化 | 固定所有模板参数，`template<>` |
| 偏特化 | 固定部分参数或施加约束，仅类模板支持 |
| 函数模板 | 不支持偏特化，用重载替代 |
| 优先级 | 全特化 > 更具体的偏特化 > 主模板 |
| type_traits | 大量使用偏特化实现类型判断 |
| 偏序规则 | 编译器选"更特殊"的版本 |
| 常见陷阱 | 特化不参与重载解析、函数无偏特化 |
| 现代替代 | Concepts比SFINAE更清晰 |
