# 什么是可变参数模板
> 📖 相关章节：[模板基础](../../02-CPP/10-模板基础.md)、[模板进阶](../../02-CPP/11-模板进阶.md)、[Concepts](../../02-CPP/23-Concepts.md)

> 一个包，展开万千。

***

### 1. 要义概览

可变参数模板（Variadic Template）允许模板接受任意数量、任意类型的参数，通过参数包（parameter pack）和包展开（pack expansion）机制，在编译期生成针对每种参数组合的代码。

***

### 2. 参数包基础

C++11引入了两种参数包：模板参数包和函数参数包：

```cpp
#include <iostream>

template<typename... Types>
struct TypeList {
    static constexpr std::size_t count = sizeof...(Types);
};

template<typename... Args>
void print_count() {
    std::cout << "参数个数: " << sizeof...(Args) << "\n";
}

template<typename... Args>
void print_sizes() {
    std::size_t sizes[] = {sizeof(Args)...};
    std::cout << "各类型大小: ";
    for (auto s : sizes) {
        std::cout << s << " ";
    }
    std::cout << "\n";
}

int main() {
    std::cout << "空列表: " << TypeList<>::count << "\n";
    std::cout << "int列表: " << TypeList<int>::count << "\n";
    std::cout << "混合列表: " << TypeList<int, double, char>::count << "\n";

    print_count<>();
    print_count<int>();
    print_count<int, double, char>();

    print_sizes<int, double, char>();
}
```

输出：

```
空列表: 0
int列表: 1
混合列表: 3
参数个数: 0
参数个数: 1
参数个数: 3
各类型大小: 4 8 1
```

参数包核心语法：

| 语法 | 名称 | 含义 |
|------|------|------|
| `typename... Types` | 模板参数包 | 接受0个或多个类型 |
| `Types...` | 包展开 | 将参数包展开为逗号分隔列表 |
| `sizeof...(Types)` | 包大小 | 返回参数个数（编译期常量） |
| `Args... args` | 函数参数包 | 接受0个或多个函数参数 |
| `args...` | 函数包展开 | 展开函数参数 |

***

### 3. 包展开的多种形式

包展开是可变参数模板的核心操作，可以在不同上下文中展开：

```cpp
#include <iostream>
#include <vector>
#include <memory>
#include <tuple>

template<typename... Args>
void expand_examples(Args... args) {
    std::size_t n = sizeof...(Args);
    std::cout << "参数个数: " << n << "\n";

    int arr[] = {(std::cout << args << " ", 0)...};
    (void)arr;
    std::cout << "\n";
}

template<typename... Args>
std::vector<std::common_type_t<Args...>> make_vector(Args... args) {
    return {args...};
}

template<typename T, typename... Args>
std::unique_ptr<T> my_make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

template<typename... Bases>
class MultiInherit : public Bases... {
public:
    MultiInherit(const Bases&... bases) : Bases(bases)... {}
};

struct A { int a = 1; };
struct B { double b = 2.0; };
struct C { const char* c = "three"; };

int main() {
    expand_examples(1, 2.5, "hello");

    auto v = make_vector(1, 2, 3, 4, 5);
    std::cout << "vector大小: " << v.size() << "\n";

    MultiInherit<A, B, C> mi;
    std::cout << mi.a << " " << mi.b << " " << mi.c << "\n";
}
```

包展开上下文一览：

| 展开位置 | 语法 | 示例 |
|---------|------|------|
| 函数参数 | `f(args...)` | `new T(std::forward<Args>(args)...)` |
| 初始化列表 | `{args...}` | `return {args...}` |
| 基类列表 | `class D : public Bases...` | 多继承 |
| 成员初始化 | `: Bases(bases)...` | 基类构造 |
| 模板参数 | `Container<Args...>` | 传递包给另一模板 |
| 数组初始化 | `{expr...}` | `{sizeof(Args)...}` |
| 捕获列表 | `[args...]` | Lambda捕获 |

### 4. 递归模式处理参数包

C++11/14中，处理参数包的经典方式是递归：

```cpp
#include <iostream>
#include <string>

void print() {
    std::cout << "\n";
}

template<typename T, typename... Rest>
void print(T&& first, Rest&&... rest) {
    std::cout << std::forward<T>(first);
    if constexpr (sizeof...(rest) > 0) {
        std::cout << ", ";
    }
    print(std::forward<Rest>(rest)...);
}

template<typename T>
T sum(T val) {
    return val;
}

template<typename T, typename... Rest>
T sum(T first, Rest... rest) {
    return first + sum(rest...);
}

template<typename T>
T max_val(T val) {
    return val;
}

template<typename T, typename... Rest>
T max_val(T first, Rest... rest) {
    T rest_max = max_val(rest...);
    return first > rest_max ? first : rest_max;
}

int main() {
    print(1, 2.5, "hello", 'x');
    std::cout << "sum: " << sum(1, 2, 3, 4, 5) << "\n";
    std::cout << "max: " << max_val(3, 7, 2, 9, 1) << "\n";
}
```

输出：

```
1, 2.5, hello, x
sum: 15
max: 9
```

递归模式结构：

```
递归调用链:
print(1, 2.5, "hello", 'x')
  → print(1) + print(2.5, "hello", 'x')
    → print(2.5) + print("hello", 'x')
      → print("hello") + print('x')
        → print('x') + print()     ← 终止条件
```

递归模式要素：

| 要素 | 说明 |
|------|------|
| 终止条件 | 无参数或单参数的重载版本 |
| 递归步骤 | 处理第一个参数，转发剩余包 |
| 展开 | `rest...` 递归调用时自动展开 |

### 5. C++17折叠表达式

C++17引入折叠表达式，大幅简化参数包的处理：

```cpp
#include <iostream>
#include <vector>

template<typename... Args>
auto fold_sum(Args... args) {
    return (args + ...);
}

template<typename... Args>
auto fold_product(Args... args) {
    return (args * ...);
}

template<typename... Args>
bool fold_all(Args... args) {
    return (... && args);
}

template<typename... Args>
bool fold_any(Args... args) {
    return (... || args);
}

template<typename... Args>
void fold_print(Args... args) {
    ((std::cout << args << " "), ...);
    std::cout << "\n";
}

template<typename... Args>
void fold_print_sep(const std::string& sep, Args... args) {
    std::string s;
    ((s += (s.empty() ? "" : sep) + std::to_string(args)), ...);
    std::cout << s << "\n";
}

int main() {
    std::cout << "sum: " << fold_sum(1, 2, 3, 4, 5) << "\n";
    std::cout << "product: " << fold_product(1, 2, 3, 4) << "\n";
    std::cout << "all: " << fold_all(true, true, false) << "\n";
    std::cout << "any: " << fold_any(false, false, true) << "\n";

    fold_print("hello", "world", "!");
    fold_print_sep(", ", 1, 2, 3, 4);
}
```

输出：

```
sum: 15
product: 24
all: 0
any: 1
hello world !
1, 2, 3, 4
```

四种折叠形式：

| 形式 | 语法 | 展开（N=3） | 初始值 |
|------|------|------------|--------|
| 一元右折叠 | `(pack op ...)` | `((e1 op e2) op e3)` | 无 |
| 一元左折叠 | `(... op pack)` | `(e1 op (e2 op e3))` | 无 |
| 二元右折叠 | `(pack op ... op init)` | `(e1 op (e2 op (e3 op init)))` | 有 |
| 二元左折叠 | `(init op ... op pack)` | `(((init op e1) op e2) op e3)` | 有 |

> ⚠️ 一元折叠在空包时：`&&`返回true，`||`返回false，逗号返回void，其他操作符未定义行为。

```cpp
#include <iostream>

template<typename... Args>
auto safe_sum(Args... args) {
    return (args + ... + 0);
}

template<typename... Args>
auto safe_product(Args... args) {
    return (1 * ... * args);
}

int main() {
    std::cout << "空包求和: " << safe_sum() << "\n";
    std::cout << "空包求积: " << safe_product() << "\n";
    std::cout << "非空求和: " << safe_sum(1, 2, 3) << "\n";
    std::cout << "非空求积: " << safe_product(2, 3, 4) << "\n";
}
```

### 6. 完美转发与参数包

结合完美转发，可变参数模板可以零开销地转发任意参数：

```cpp
#include <iostream>
#include <utility>
#include <string>
#include <memory>

struct Config {
    std::string name;
    int timeout;
    bool verbose;

    Config(std::string n, int t, bool v)
        : name(std::move(n)), timeout(t), verbose(v) {
        std::cout << "构造 Config: " << name << "\n";
    }
};

template<typename T, typename... Args>
std::unique_ptr<T> my_make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

template<typename Container, typename... Args>
void emplace_wrapper(Container& c, Args&&... args) {
    c.emplace_back(std::forward<Args>(args)...);
}

class EventDispatcher {
public:
    template<typename Handler, typename... Args>
    void dispatch(Handler&& handler, Args&&... args) {
        std::forward<Handler>(handler)(std::forward<Args>(args)...);
    }
};

int main() {
    auto cfg = my_make_unique<Config>("server", 30, true);

    std::vector<std::string> vec;
    emplace_wrapper(vec, "hello");
    std::string s = "world";
    emplace_wrapper(vec, std::move(s));

    EventDispatcher ed;
    ed.dispatch([](int x, double y) {
        std::cout << "处理: " << x << ", " << y << "\n";
    }, 42, 3.14);
}
```

完美转发参数包的关键模式：

```cpp
template<typename... Args>
void wrapper(Args&&... args) {
    target(std::forward<Args>(args)...);
}
```

| 组成部分 | 作用 |
|---------|------|
| `Args&&... args` | 转发引用参数包 |
| `std::forward<Args>(args)...` | 逐个完美转发 |
| `...` 在 `std::forward` 之后 | 展开整个表达式 |

### 7. 模拟make_unique实现

```cpp
#include <iostream>
#include <memory>
#include <utility>

template<typename T>
struct _Unique_ptr {
    T* ptr;

    _Unique_ptr(T* p) : ptr(p) {}
    ~_Unique_ptr() { delete ptr; }

    _Unique_ptr(const _Unique_ptr&) = delete;
    _Unique_ptr& operator=(const _Unique_ptr&) = delete;

    _Unique_ptr(_Unique_ptr&& other) noexcept : ptr(other.ptr) {
        other.ptr = nullptr;
    }

    T& operator*() { return *ptr; }
    T* operator->() { return ptr; }
};

template<typename T, typename... Args>
_Unique_ptr<T> my_make_unique(Args&&... args) {
    return _Unique_ptr<T>(new T(std::forward<Args>(args)...));
}

struct Point {
    double x, y;
    Point(double x_, double y_) : x(x_), y(y_) {
        std::cout << "构造 Point(" << x << ", " << y << ")\n";
    }
    ~Point() {
        std::cout << "析构 Point(" << x << ", " << y << ")\n";
    }
};

int main() {
    {
        auto p = my_make_unique<Point>(3.0, 4.0);
        std::cout << "点: (" << p->x << ", " << p->y << ")\n";
    }

    auto s = my_make_unique<std::string>(5, 'X');
    std::cout << "字符串: " << *s << "\n";

    auto v = my_make_unique<std::vector<int>>(3, 100);
    std::cout << "vector: ";
    for (int i : *v) std::cout << i << " ";
    std::cout << "\n";
}
```

### 8. 简化tuple实现

tuple是可变参数模板的典型应用：

```cpp
#include <iostream>
#include <type_traits>

template<typename... Types>
class Tuple;

template<>
class Tuple<> {
public:
    static constexpr std::size_t size() { return 0; }
};

template<typename Head, typename... Tail>
class Tuple<Head, Tail...> : private Tuple<Tail...> {
    Head head_;

public:
    Tuple(Head h, Tail... t) : Tuple<Tail...>(t...), head_(std::move(h)) {}

    Head& head() { return head_; }
    const Head& head() const { return head_; }

    Tuple<Tail...>& tail() { return *this; }
    const Tuple<Tail...>& tail() const { return *this; }

    static constexpr std::size_t size() { return 1 + sizeof...(Tail); }
};

template<std::size_t I, typename Tuple>
struct TupleElement;

template<typename Head, typename... Tail>
struct TupleElement<0, Tuple<Head, Tail...>> {
    using type = Head;

    static Head& get(Tuple<Head, Tail...>& t) { return t.head(); }
    static const Head& get(const Tuple<Head, Tail...>& t) { return t.head(); }
};

template<std::size_t I, typename Head, typename... Tail>
struct TupleElement<I, Tuple<Head, Tail...>> {
    using type = typename TupleElement<I - 1, Tuple<Tail...>>::type;

    static type& get(Tuple<Head, Tail...>& t) {
        return TupleElement<I - 1, Tuple<Tail...>>::get(t.tail());
    }
    static const type& get(const Tuple<Head, Tail...>& t) {
        return TupleElement<I - 1, Tuple<Tail...>>::get(t.tail());
    }
};

template<std::size_t I, typename... Types>
typename TupleElement<I, Tuple<Types...>>::type& get(Tuple<Types...>& t) {
    return TupleElement<I, Tuple<Types...>>::get(t);
}

int main() {
    Tuple<int, double, const char*> t(42, 3.14, "hello");

    std::cout << "size: " << t.size() << "\n";
    std::cout << "get<0>: " << get<0>(t) << "\n";
    std::cout << "get<1>: " << get<1>(t) << "\n";
    std::cout << "get<2>: " << get<2>(t) << "\n";
}
```

输出：

```
size: 3
get<0>: 42
get<1>: 3.14
get<2>: hello
```

Tuple递归继承结构：

```
Tuple<int, double, const char*>
  └── Tuple<double, const char*>
        └── Tuple<const char*>
              └── Tuple<>
```

### 9. 编译期类型操作

可变参数模板常用于编译期类型列表操作：

```cpp
#include <iostream>
#include <type_traits>

template<typename... Types>
struct TypeList {};

template<typename List>
struct Length;

template<typename... Types>
struct Length<TypeList<Types...>> {
    static constexpr std::size_t value = sizeof...(Types);
};

template<typename T, typename List>
struct Contains;

template<typename T>
struct Contains<T, TypeList<>> : std::false_type {};

template<typename T, typename... Rest>
struct Contains<T, TypeList<T, Rest...>> : std::true_type {};

template<typename T, typename First, typename... Rest>
struct Contains<T, TypeList<First, Rest...>> : Contains<T, TypeList<Rest...>> {};

template<typename List, typename T>
struct Append;

template<typename... Types, typename T>
struct Append<TypeList<Types...>, T> {
    using type = TypeList<Types..., T>;
};

template<typename List>
struct PrintTypes;

template<>
struct PrintTypes<TypeList<>> {
    static void print() { std::cout << "\n"; }
};

template<typename First, typename... Rest>
struct PrintTypes<TypeList<First, Rest...>> {
    static void print() {
        std::cout << typeid(First).name() << " ";
        PrintTypes<TypeList<Rest...>>::print();
    }
};

int main() {
    using MyList = TypeList<int, double, char>;

    std::cout << "长度: " << Length<MyList>::value << "\n";
    std::cout << "包含int: " << Contains<int, MyList>::value << "\n";
    std::cout << "包含float: " << Contains<float, MyList>::value << "\n";

    using Extended = Append<MyList, float>::type;
    std::cout << "扩展后长度: " << Length<Extended>::value << "\n";
}
```

### 10. 常见陷阱与最佳实践

**陷阱1：空包的折叠表达式**

```cpp
#include <iostream>

template<typename... Args>
auto bad_sum(Args... args) {
    return (args + ...);
}

template<typename... Args>
auto good_sum(Args... args) {
    return (0 + ... + args);
}

int main() {
    good_sum();
}
```

**陷阱2：参数包必须紧邻展开**

```cpp
#include <iostream>
#include <vector>

template<typename... Args>
void wrong(Args... args) {
}

template<typename... Args>
void right(Args... args) {
    std::size_t sizes[] = {sizeof(Args)...};
    for (auto s : sizes) std::cout << s << " ";
    std::cout << "\n";
}
```

**陷阱3：包展开位置限制**

```cpp
template<typename... Args>
struct S {
    Args... members;
};
```

以上非法——不能展开为非静态数据成员声明。

最佳实践汇总：

| 实践 | 说明 |
|------|------|
| 优先用折叠表达式 | C++17起比递归更简洁 |
| 空包用二元折叠 | 提供初始值避免未定义行为 |
| 完美转发用 `std::forward<Args>(args)...` | 保持值类别 |
| 递归需终止条件 | 零参数或单参数重载 |
| 避免过度递归 | 深度过大可能超出编译器限制 |
| 用if constexpr替代SFINAE | C++17起更清晰 |

***

### 11. 极简总结

| 概念 | 要点 |
|------|------|
| 参数包 | `typename... Types` 接受0个或多个类型 |
| sizeof... | 编译期获取参数包大小 |
| 包展开 | `...` 语法展开为逗号分隔列表 |
| 递归模式 | C++11/14处理参数包的经典方式 |
| 折叠表达式 | C++17简化，四种形式 |
| 完美转发 | `std::forward<Args>(args)...` 零开销透传 |
| make_unique | `new T(std::forward<Args>(args)...)` |
| tuple | 递归继承+偏特化实现 |
| 空包注意 | 一元折叠空包仅 `&&`/`||`/`,` 有定义 |
