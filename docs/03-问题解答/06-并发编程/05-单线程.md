# 单线程详解
> 📖 相关章节：[多线程基础](../../02-CPP/27-多线程基础.md)

## 1. 什么是单线程？

**单线程**是指程序在执行过程中只有**一个执行流**，代码按顺序依次执行。

### 1. 与多线程的对比

```
单线程：只有一条执行路径，代码按顺序执行
多线程：有多条执行路径，多个任务可以并发执行
```

### 2. 示例对比

```cpp
// 单线程执行
void single_thread() {
    task1();  // 先执行 task1
    task2();  // task1 完成后执行 task2
    task3();  // task2 完成后执行 task3
}

// 多线程执行
void multi_thread() {
    std::thread t1(task1);  // 同时执行
    std::thread t2(task2);  // 同时执行
    std::thread t3(task3);  // 同时执行
    t1.join();
    t2.join();
    t3.join();
}
```

### 3. 单线程的特点

| 特点 | 说明 |
|------|------|
| **执行顺序** | 代码按顺序执行，不会并发 |
| **资源竞争** | 没有线程间的资源竞争 |
| **复杂度** | 代码逻辑简单，容易理解和调试 |
| **性能** | 无法利用多核CPU，适合I/O密集型任务 |

## 2. 单线程下，代码会出现线程不安全吗？

**答：不会。**

### 1. 为什么单线程不会有线程安全问题？

```cpp
// 单线程环境
int counter = 0;

void increment() {
    counter++;  // 在单线程中是安全的
}

int main() {
    increment();  // counter = 1
    increment();  // counter = 2
    increment();  // counter = 3
    // 结果确定，没有竞争条件
    return 0;
}
```

### 2. 线程安全问题的根源

```
线程安全问题只在多线程环境下出现：
- 多个线程同时访问共享数据
- 至少有一个线程在写入数据
- 没有适当的同步机制
```

### 3. 单线程中的其他问题

虽然单线程没有线程安全问题，但可能有其他问题：

```cpp
// 单线程中的问题：不是线程安全问题，而是逻辑错误
int divide(int a, int b) {
    return a / b;  // 可能除以零
}

// 单线程中的问题：空指针解引用
void process(int* ptr) {
    *ptr = 42;  // 如果 ptr 是 nullptr，会崩溃
}
```

## 3. 怎么判断是不是单线程？

### 1. 方法1：检查是否创建了额外线程

```cpp
#include <thread>

int main() {
    // 如果没有创建 std::thread，通常是单线程
    // main 函数本身在主线程中执行
    
    std::cout << "主线程 ID: " << std::this_thread::get_id() << std::endl;
    
    // 如果看到类似 std::thread t(func) 的代码，就是多线程
    return 0;
}
```

### 2. 方法2：使用线程本地存储测试

```cpp
#include <thread>

thread_local int tls_value = 0;

void check_thread() {
    tls_value++;
    std::cout << "tls_value: " << tls_value << std::endl;
}

int main() {
    check_thread();  // 输出: tls_value: 1
    check_thread();  // 输出: tls_value: 2（同一线程，值累加）
    
    // 如果创建新线程
    std::thread t(check_thread);  // 输出: tls_value: 1（新线程，独立副本）
    t.join();
    
    return 0;
}
```

### 3. 方法3：检查线程数量

```cpp
#include <thread>
#include <future>

int main() {
    // 获取硬件并发数（CPU核心数）
    unsigned int cores = std::thread::hardware_concurrency();
    std::cout << "CPU cores: " << cores << std::endl;
    
    // 如果程序只使用一个线程，就是单线程
    return 0;
}
```

### 4. 方法4：查看程序执行模式

```cpp
// 单线程程序的典型结构
int main() {
    // 顺序执行的代码
    init();
    process();
    cleanup();
    return 0;
}

// 多线程程序的典型结构
int main() {
    // 创建多个线程
    std::thread t1(task1);
    std::thread t2(task2);
    
    // 主线程可以做其他事情
    main_task();
    
    // 等待子线程完成
    t1.join();
    t2.join();
    return 0;
}
```

## 4. 总结

| 问题 | 答案 |
|------|------|
| 什么是单线程？ | 只有一个执行流，代码按顺序执行 |
| 单线程会有线程安全问题吗？ | 不会，线程安全问题只在多线程环境下出现 |
| 怎么判断单线程？ | 检查是否创建了额外线程、使用线程本地存储测试 |

**关键要点：**
- 线程安全问题的三个条件：多线程、共享数据、写操作
- 单线程没有多线程，所以不会有线程安全问题
- 单线程可能有其他问题（除零、空指针等），但不是线程安全问题

---

## 4. 极简口诀

```
单线程，顺序跑，代码一行接一行
没有并发无竞争，线程安全不用愁
判断是否单线程，看有无新线程创建
```
