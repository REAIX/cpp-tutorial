# 原子操作与原子变量详解
> 📖 相关章节：[原子操作与异步编程](../../02-CPP/29-原子操作与异步编程.md)

## 1. 什么是原子操作？

**原子操作**（Atomic Operation）是指**不可中断**的操作，要么完全执行，要么完全不执行，不会被其他线程中断。

### 1. 与非原子操作的对比

```cpp
// 非原子操作：可能被中断
int counter = 0;
counter++;  // 等价于: counter = counter + 1;（三步操作）
// 1. 读取 counter 的值
// 2. 加 1
// 3. 写回 counter

// 原子操作：不可中断
std::atomic<int> atomic_counter(0);
atomic_counter.fetch_add(1);  // 一步完成，不可中断
```

### 2. 原子操作的特点

| 特性 | 说明 |
|------|------|
| **不可中断** | 操作过程中不会被其他线程打断 |
| **原子性** | 操作要么完全成功，要么完全失败 |
| **线程安全** | 不需要额外的锁保护 |
| **无锁** | 通常使用硬件支持实现，比互斥锁更快 |

## 2. 什么是原子变量？

**原子变量**是支持原子操作的变量，定义在 `<atomic>` 头文件中。

### 1. 常见的原子类型

```cpp
#include <atomic>

std::atomic<bool> flag;           // 原子布尔
std::atomic<char> c;              // 原子字符
std::atomic<int> i;               // 原子整型
std::atomic<long> l;              // 原子长整型
std::atomic<long long> ll;        // 原子长长整型
std::atomic<uintptr_t> ptr;       // 原子指针类型
```

### 2. 原子变量的内存模型

```cpp
// 默认内存顺序（memory_order_seq_cst）
std::atomic<int> x(0);

// 指定内存顺序
std::atomic<int> y(0);
y.store(42, std::memory_order_relaxed);
```

## 3. 如何使用原子操作？

### 1. 基本操作

```cpp
#include <atomic>
#include <iostream>

int main() {
    std::atomic<int> counter(0);
    
    // 加载（读取）
    int value = counter.load();  // 原子读取
    
    // 存储（写入）
    counter.store(42);  // 原子写入
    
    // 交换
    int old_value = counter.exchange(100);  // 返回旧值，写入新值
    
    std::cout << "old_value: " << old_value << std::endl;  // 输出: 42
    std::cout << "new_value: " << counter.load() << std::endl;  // 输出: 100
    
    return 0;
}
```

### 2. 算术操作

```cpp
std::atomic<int> counter(0);

// 原子加法
counter.fetch_add(1);  // counter = counter + 1
counter.fetch_add(5);  // counter = counter + 5

// 原子减法
counter.fetch_sub(1);  // counter = counter - 1

// 原子位操作
std::atomic<int> flags(0);
flags.fetch_or(0x01);   // 按位或
flags.fetch_and(0xFE);  // 按位与
flags.fetch_xor(0xFF);  // 按位异或

// 复合赋值（C++20）
counter += 1;  // 等价于 fetch_add(1)
counter -= 1;  // 等价于 fetch_sub(1)
```

### 3. 比较并交换（CAS）

```cpp
std::atomic<int> value(10);

int expected = 10;
int desired = 20;

// CAS: 如果 value == expected，则设置为 desired
bool success = value.compare_exchange_strong(expected, desired);

// success == true: 交换成功，value = 20
// success == false: 交换失败，expected = 当前 value 的值

// 循环CAS模式
while (!value.compare_exchange_weak(expected, desired)) {
    // 如果失败，expected 已经被更新为当前值
    // 重试直到成功
}
```

### 4. 内存顺序

```cpp
#include <atomic>

std::atomic<int> x(0);

// memory_order_relaxed: 松散内存顺序，不保证顺序
x.store(1, std::memory_order_relaxed);

// memory_order_release: 释放语义，确保之前的写操作可见
x.store(2, std::memory_order_release);

// memory_order_acquire: 获取语义，确保之后的读操作可见
int val = x.load(std::memory_order_acquire);

// memory_order_seq_cst: 顺序一致性（默认），最强的内存顺序
x.store(3, std::memory_order_seq_cst);
```

## 4. 原子操作 vs 互斥锁

```cpp
// 使用互斥锁
#include <mutex>
int counter = 0;
std::mutex mtx;

void increment_mutex() {
    std::lock_guard<std::mutex> lock(mtx);
    counter++;
}

// 使用原子操作
#include <atomic>
std::atomic<int> atomic_counter(0);

void increment_atomic() {
    atomic_counter.fetch_add(1);
}
```

### 1. 对比表

| 特性 | 原子操作 | 互斥锁 |
|------|----------|--------|
| **性能** | 更高（硬件支持） | 较低（操作系统调度） |
| **适用场景** | 简单的计数器、标志位 | 复杂的临界区 |
| **灵活性** | 有限（只能进行原子操作） | 高（任意代码） |
| **死锁风险** | 无 | 有 |

## 5. 常见使用场景

### 1. 计数器

```cpp
#include <atomic>
#include <thread>

std::atomic<int> count(0);

void worker() {
    for (int i = 0; i < 1000; ++i) {
        count.fetch_add(1);  // 线程安全的计数
    }
}

int main() {
    std::thread t1(worker);
    std::thread t2(worker);
    t1.join();
    t2.join();
    // count = 2000（正确结果）
    return 0;
}
```

### 2. 标志位

```cpp
#include <atomic>
#include <thread>

std::atomic<bool> running(true);

void worker() {
    while (running.load()) {
        // 执行任务
    }
}

int main() {
    std::thread t(worker);
    // ...
    running.store(false);  // 停止工作线程
    t.join();
    return 0;
}
```

### 3. 无锁数据结构

```cpp
#include <atomic>

template<typename T>
struct Node {
    T data;
    std::atomic<Node*> next;
};

template<typename T>
class LockFreeStack {
    std::atomic<Node<T>*> head;
public:
    void push(T data) {
        Node<T>* new_node = new Node<T>{data};
        new_node->next = head.load();
        while (!head.compare_exchange_weak(new_node->next, new_node)) {}
    }
};
```

## 6. 注意事项

### 1. 不是所有操作都是原子的

```cpp
std::atomic<int> x(0);

// 原子操作
x.fetch_add(1);  // OK

// 非原子操作（虽然 x 是原子变量）
x = x + 1;  // 不是原子的！先读取，再加，再写入
```

### 2. 内存顺序的选择

```cpp
// 选择合适的内存顺序
std::atomic<int> x(0);

// 简单计数器可以使用 relaxed
x.fetch_add(1, std::memory_order_relaxed);

// 需要同步时使用 release/acquire
x.store(42, std::memory_order_release);
int val = x.load(std::memory_order_acquire);
```

### 3. 原子变量的复制

```cpp
std::atomic<int> a(10);
// std::atomic<int> b = a;  // 错误！原子变量不可复制

// 正确做法：通过 load/store 复制
std::atomic<int> b(a.load());
```

## 7. 总结

| 概念 | 说明 |
|------|------|
| **原子操作** | 不可中断的操作，要么完全执行，要么完全不执行 |
| **原子变量** | 支持原子操作的变量，定义在 `<atomic>` 中 |
| **CAS** | 比较并交换，无锁编程的基础 |
| **内存顺序** | 控制原子操作的内存可见性 |

**核心要点：**
- 原子操作是线程安全的，不需要额外的锁
- 适用于简单的计数器、标志位等场景
- 复杂场景需要使用互斥锁
- 选择合适的内存顺序可以提高性能
