# [多线程通讯](23-多线程通讯与数据获取.md)入门详解（通俗易懂版）

## 1. 什么是[多线程通讯](23-多线程通讯与数据获取.md)？

想象一下：你（主线程）让你的朋友（子线程）去帮你买一杯奶茶。

- **同步通讯**：你站在原地等朋友回来，拿到奶茶后才继续做其他事
- **异步通讯**：你让朋友去买奶茶，自己继续看电视，朋友买回来后通知你

[多线程通讯](23-多线程通讯与数据获取.md)就是主线程和子线程之间传递数据和信息的方式。

## 2. 主线程如何获取子线程的数据？

### 1. 方法1：共享笔记（共享变量 + 互斥锁）

**场景**：你和朋友共用一个笔记本，你让朋友把奶茶的价格写在上面。

```cpp
#include <iostream>
#include <thread>
#include <mutex>

// 共享的笔记本（需要加锁保护）
std::mutex notebook_lock;  // 笔记本的锁
std::string shared_note;   // 共享的笔记内容

// 子线程（朋友）：去买奶茶，把价格写在笔记本上
void buy_milk_tea() {
    std::cout << "朋友：出发去买奶茶..." << std::endl;

    // 模拟买奶茶需要2秒
    std::this_thread::sleep_for(std::chrono::seconds(2));

    // 拿到奶茶后，写在共享笔记本上
    {
        // 先上锁
        std::lock_guard<std::mutex> lock(notebook_lock);
        shared_note = "奶茶价格：15元";
        std::cout << "朋友：已经把价格写在笔记本上了" << std::endl;
    }
    // 自动解锁
}

int main() {
    std::cout << "我：让朋友去买奶茶" << std::endl;

    // 创建子线程（让朋友去买奶茶）
    std::thread friend_thread(buy_milk_tea);

    // 等待朋友回来（阻塞等待）
    friend_thread.join();

    // 读取笔记本上的价格
    {
        std::lock_guard<std::mutex> lock(notebook_lock);
        std::cout << "我：看到笔记本上写着：" << shared_note << std::endl;
    }

    return 0;
}
```

**关键点**：
- 互斥锁保证同一时间只有一个线程访问共享数据
- 就像只有一把钥匙，谁拿到谁用
- 避免两个线程同时修改数据导致混乱

### 2. 方法2：快递传递（消息队列）

**场景**：工人把做好的产品放到快递站，你需要时去取。

```cpp
#include <thread>
#include <mutex>
#include <queue>
#include <condition_variable>
#include <iostream>

std::queue<int> message_queue;  // 快递站（消息队列）
std::mutex mtx;                 // 快递站钥匙
std::condition_variable cv;     // 快递到站通知铃
bool done = false;              // 下班标志

void producer() {
    for (int i = 0; i < 5; ++i) {
        {
            std::lock_guard<std::mutex> lock(mtx);  // 打开快递站门
            message_queue.push(i);                   // 放包裹进去
            std::cout << "Produced: " << i << std::endl;
        }
        cv.notify_one();  // 按门铃通知有新快递
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    {
        std::lock_guard<std::mutex> lock(mtx);
        done = true;  // 告诉消费者下班了
    }
    cv.notify_one();
}

void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        // 等着门铃响，或者下班了
        cv.wait(lock, []{ return !message_queue.empty() || done; });

        // 取走所有包裹
        while (!message_queue.empty()) {
            int data = message_queue.front();
            message_queue.pop();
            std::cout << "Consumed: " << data << std::endl;
        }

        if (done) break;  // 下班就回家
    }
}

int main() {
    std::thread t1(producer);
    std::thread t2(consumer);
    t1.join();
    t2.join();
    return 0;
}
```

**关键点**：
- 条件变量像门铃，有消息时通知等待的线程
- 消费者不用一直轮询，没消息时可以睡觉（wait）
- 比共享内存更解耦，生产者和消费者不用直接打交道

### 3. 方法3：预约送货（std::future）

**场景**：你跟工人说："做好后送到我办公室"，然后你继续做自己的事。

```cpp
#include <thread>
#include <future>
#include <iostream>

int compute() {
    // 模拟耗时计算
    std::this_thread::sleep_for(std::chrono::seconds(2));
    return 42;
}

int main() {
    // 创建 future，异步执行 compute
    std::future<int> fut = std::async(std::launch::async, compute);

    // 主线程可以做其他事情，不会阻塞
    std::cout << "Main thread doing other work..." << std::endl;

    // 获取子线程的结果（会阻塞直到结果可用）
    int result = fut.get();
    std::cout << "Result from thread: " << result << std::endl;

    return 0;
}
```

**关键点**：
- `std::future` 像是一个预约单，承诺未来会给结果
- 主线程可以继续工作，需要结果时才调用 `get()` 获取
- 这是最推荐的[多线程通讯](23-多线程通讯与数据获取.md)方式之一

---

### 4. 方法4：装电话（回调函数）

**场景**：你给工人装个电话，告诉他："做完了打电话给我"。

```cpp
#include <thread>
#include <functional>
#include <iostream>

void worker(std::function<void(const std::string&)> callback) {
    std::this_thread::sleep_for(std::chrono::seconds(1));
    callback("Hello from callback!");  // 调用回调传递数据
}

int main() {
    // 定义回调函数
    auto callback = [](const std::string& msg) {
        std::cout << "Callback received: " << msg << std::endl;
    };

    std::thread t(worker, callback);
    t.detach();  // 分离线程

    // 主线程继续执行
    std::cout << "Main continues..." << std::endl;
    std::this_thread::sleep_for(std::chrono::seconds(2));

    return 0;
}
```

**关键点**：
- 回调函数是事件驱动的通讯方式
- 子线程完成时主动通知主线程
- 注意 `detach()` 后需要确保程序不提前退出

## 3. 常见通讯方式对比

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **共享内存** | 简单直接 | 需要同步，易出错 | 简单数据共享 |
| **消息队列** | 解耦性好 | 有一定开销 | 生产者-消费者模式 |
| **std::future** | 异步获取结果 | 获取时会阻塞 | 需要获取计算结果 |
| **回调函数** | 事件驱动 | 代码较复杂 | 异步通知场景 |
| **条件变量** | 高效等待 | 需要配合 mutex | 等待特定条件 |

---

## 4. 总结

### 1. 主线程获取子线程数据的方法：

1. **共享变量 + 互斥锁**：简单直接，但需要手动同步
2. **消息队列**：解耦性好，适合生产者-消费者模式
3. **std::future**：异步执行，获取结果时阻塞
4. **回调函数**：子线程完成时主动通知主线程

### 2. 核心原则：

- 尽量使用高层抽象（`std::future`、`std::async`）而非手动管理线程
- 避免共享可变状态，使用消息传递
- 合理选择同步机制，避免死锁和数据竞争

---

## 4. 极简口诀

```
线程通讯有多种，共享内存最常用
future异步拿结果，回调函数来通知
主线要拿子线程数据，互斥锁来保护它
想要主线不阻塞，detach异步都可以
```

- 工人做完就走，不耽误你做别的事

**场景3：预约送货（std::future）**
- 你跟工人说："做好后送到我办公室"
- 然后你继续做自己的事

**场景4：装电话（回调函数）**
- 你给工人装个电话，告诉他："做完了打电话给我"

- 你不用主动去问

## 2. [多线程通讯](23-多线程通讯与数据获取.md)方式

### 1. 共享内存（Shared Memory）

**比喻**：大家共用一个白板，轮流使用

```cpp
#include <thread>
#include <mutex>
#include <iostream>

// 共享数据 = 白板
std::mutex mtx;           // 白板钥匙（互斥锁）
int shared_data = 0;      // 白板上写的内容

void producer() {
    for (int i = 0; i < 10; ++i) {
        std::lock_guard<std::mutex> lock(mtx);  // 拿到钥匙
        shared_data = i;  // 在白板上写内容
        std::cout << "Producer: " << shared_data << std::endl;
    }  // 自动归还钥匙
}

void consumer() {
    for (int i = 0; i < 10; ++i) {
        std::lock_guard<std::mutex> lock(mtx);  // 拿到钥匙
        std::cout << "Consumer: " << shared_data << std::endl;  // 看白板上的内容
    }  // 自动归还钥匙
}

int main() {
    std::thread t1(producer);  // 工人A
    std::thread t2(consumer);  // 工人B
    t1.join();
    t2.join();
    return 0;
}
```

**关键点**：
- 互斥锁（mutex）保证同一时间只有一个线程访问共享数据
- 就像只有一把钥匙，谁拿到谁用
- 避免两个线程同时修改数据导致混乱

### 2. 消息队列（Message Queue）

**比喻**：工人把做好的产品放到快递站，你需要时去取

```cpp
#include <thread>
#include <mutex>
#include <queue>
#include <condition_variable>
#include <iostream>

std::queue<int> message_queue;  // 快递站（消息队列）
std::mutex mtx;                 // 快递站钥匙
std::condition_variable cv;     // 快递到站通知铃
bool done = false;              // 下班标志

void producer() {
    for (int i = 0; i < 5; ++i) {
        {
            std::lock_guard<std::mutex> lock(mtx);  // 打开快递站门
            message_queue.push(i);                   // 放包裹进去
            std::cout << "Produced: " << i << std::endl;
        }
        cv.notify_one();  // 按门铃通知有新快递
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    {
        std::lock_guard<std::mutex> lock(mtx);
        done = true;  // 告诉消费者下班了
    }
    cv.notify_one();
}

void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        // 等着门铃响，或者下班了
        cv.wait(lock, []{ return !message_queue.empty() || done; });

        // 取走所有包裹
        while (!message_queue.empty()) {
            int data = message_queue.front();
            message_queue.pop();
            std::cout << "Consumed: " << data << std::endl;
        }

        if (done) break;  // 下班就回家
    }
}

int main() {
    std::thread t1(producer);
    std::thread t2(consumer);
    t1.join();
    t2.join();
    return 0;
}
```

**关键点**：
- 条件变量（condition_variable）像门铃，有消息时通知等待的线程
- 消费者不用一直轮询，没消息时可以睡觉（wait）
- 比共享内存更解耦，生产者和消费者不用直接打交道

int main() {

## 3. 主线程获取子线程数据

### 1. 方法1：共享变量 + 互斥锁（白板留言）

**比喻**：工人在白板上写结果，你等他写完后去看

```cpp
#include <thread>
#include <mutex>
#include <iostream>

std::mutex mtx;           // 白板钥匙
std::string thread_result; // 白板

void worker() {
    // 子线程计算（工人干活）
    std::this_thread::sleep_for(std::chrono::seconds(1));

    {
        std::lock_guard<std::mutex> lock(mtx);  // 拿钥匙
        thread_result = "Hello from worker!";   // 在白板上写结果
    }  // 还钥匙
}

int main() {
    std::thread t(worker);

    // 主线程做其他事情
    std::cout << "Main thread waiting..." << std::endl;

    t.join();  // 等待子线程完成

    // 获取子线程结果
    {
        std::lock_guard<std::mutex> lock(mtx);
        std::cout << thread_result << std::endl;
    }

    return 0;
}
```

### 2. 方法2：使用 std::future

## 4. 如何不让子线程阻塞主线程

### 1. 使用 detach()

```cpp
#include <thread>
#include <iostream>
#include <chrono>

void worker() {
    for (int i = 0; i < 5; ++i) {
        std::cout << "Worker: " << i << std::endl;
        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
}

int main() {
    std::thread t(worker);
    t.detach();  // 分离线程，主线程不会等待

    // 主线程继续执行，不会被阻塞
    std::cout << "Main thread continues immediately" << std::endl;
    std::this_thread::sleep_for(std::chrono::seconds(3));  // 等待足够长时间让子线程完成

    return 0;
}
```

### 2. 使用 std::async

```cpp
#include <future>
#include <iostream>
#include <chrono>

int long_computation() {
    std::this_thread::sleep_for(std::chrono::seconds(3));
    return 42;
}

int main() {
    // 异步执行，不阻塞主线程
    std::future<int> fut = std::async(std::launch::async, long_computation);

    // 主线程可以做其他事情
    std::cout << "Main doing work..." << std::endl;
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "Main still working..." << std::endl;

    // 需要结果时才获取（会阻塞）
    int result = fut.get();
    std::cout << "Result: " << result << std::endl;

    return 0;
}
```

### 3. 轮询 + 原子标志

```cpp
#include <thread>
#include <atomic>
#include <iostream>
#include <chrono>

std::atomic<bool> done(false);
int result = 0;

void worker() {
    std::this_thread::sleep_for(std::chrono::seconds(2));
    result = 100;
    done.store(true);  // 设置完成标志
}

int main() {
    std::thread t(worker);
    t.detach();

    // 轮询检查，不阻塞主线程
    while (!done.load()) {
        std::cout << "Waiting for result..." << std::endl;
        std::this_thread::sleep_for(std::chrono::milliseconds(500));
    }

    std::cout << "Result: " << result << std::endl;

    return 0;
}
```

### 4. 使用条件变量

```cpp
#include <thread>
#include <mutex>
#include <condition_variable>
#include <iostream>
#include <chrono>

std::mutex mtx;
std::condition_variable cv;
bool ready = false;
int result = 0;

void worker() {
    std::this_thread::sleep_for(std::chrono::seconds(2));

    {
        std::lock_guard<std::mutex> lock(mtx);
        result = 200;
        ready = true;
    }
    cv.notify_one();  // 通知主线程
}

int main() {
    std::thread t(worker);

    {
        std::unique_lock<std::mutex> lock(mtx);
        // 等待条件满足，期间主线程可以做其他事情
        cv.wait(lock, []{ return ready; });
    }

    std::cout << "Result: " << result << std::endl;
    t.join();

    return 0;
}
```

## 5. 实战示例：多线程数据收集

```cpp
#include <thread>
#include <future>
#include <vector>
#include <iostream>

int compute(int id) {
    std::this_thread::sleep_for(std::chrono::milliseconds(100 * id));
    return id * 10;
}

int main() {
    std::vector<std::future<int>> futures;

    // 启动多个子线程
    for (int i = 1; i <= 5; ++i) {
        futures.push_back(std::async(std::launch::async, compute, i));
    }

    // 主线程可以做其他工作
    std::cout << "All threads started. Main continues..." << std::endl;

    // 收集所有结果
    std::vector<int> results;
    for (auto& fut : futures) {
        results.push_back(fut.get());  // 获取每个线程的结果
    }

    // 打印结果
    std::cout << "Results: ";
    for (int r : results) {
        std::cout << r << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

## 6. 常见通讯方式对比

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **共享内存** | 简单直接 | 需要同步，易出错 | 简单数据共享 |
| **消息队列** | 解耦性好 | 有一定开销 | 生产者-消费者模式 |
| **std::future** | 异步获取结果 | 获取时会阻塞 | 需要获取计算结果 |
| **回调函数** | 事件驱动 | 代码较复杂 | 异步通知场景 |
| **条件变量** | 高效等待 | 需要配合 mutex | 等待特定条件 |

## 7. 总结

### 1. 主线程获取子线程数据的方法：

1. **共享变量 + 互斥锁**：简单直接，但需要手动同步
2. **std::future**：异步执行，获取结果时阻塞
3. **回调函数**：子线程完成时主动通知主线程
4. **条件变量**：主线程等待特定条件

### 2. 不阻塞主线程的方法：

1. **detach()**：分离线程，主线程不等待
2. **std::async**：异步执行，需要结果时再获取
3. **轮询**：定期检查子线程状态
4. **条件变量**：主线程等待条件，期间可以做其他事

**核心原则：**
- 尽量使用高层抽象（`std::future`、`std::async`）而非手动管理线程
- 避免共享可变状态，使用消息传递
- 合理选择同步机制，避免死锁和数据竞争
