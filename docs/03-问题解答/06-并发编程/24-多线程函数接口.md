# 多线程函数接口详解
> 📖 相关章节：[多线程基础](../../02-CPP/27-多线程基础.md)、[Lambda与函数对象](../../02-CPP/13-Lambda与函数对象.md)

## 1. 线程管理接口

### 1. std::thread

**功能**：创建和管理线程

```cpp
#include <thread>

// 构造函数
std::thread t(func, arg1, arg2, ...);

// 参数说明：
// func: 线程要执行的函数/可调用对象
// arg1, arg2, ...: 传递给func的参数

// 常用成员函数
t.join();       // 等待线程结束（阻塞）
t.detach();     // 分离线程（不阻塞）
t.joinable();   // 检查线程是否可join
t.get_id();     // 获取线程ID
t.swap(t2);     // 交换两个线程
```

**示例**：
```cpp
void worker(int id, const std::string& name) {
    std::cout << "Worker " << id << ": " << name << std::endl;
}

int main() {
    std::thread t(worker, 1, "Alice");  // 创建线程，传递参数
    t.join();  // 等待线程完成
    return 0;
}
```

### 2. std::this_thread 命名空间

```cpp
#include <thread>

// 获取当前线程ID
std::thread::id id = std::this_thread::get_id();

// 暂停线程一段时间
std::this_thread::sleep_for(std::chrono::seconds(1));

// 让出CPU时间片
std::this_thread::yield();

// 暂停直到指定时间点
std::this_thread::sleep_until(some_time_point);
```

## 2. 互斥锁接口

### 1. std::mutex

**功能**：基本互斥锁

```cpp
#include <mutex>

std::mutex mtx;

mtx.lock();         // 加锁（阻塞直到获取锁）
mtx.unlock();       // 解锁
mtx.try_lock();     // 尝试加锁（不阻塞，返回bool）
```

### 2. std::lock_guard

**功能**：RAII风格的锁管理（自动加锁/解锁）

```cpp
{
    std::lock_guard<std::mutex> lock(mtx);  // 构造时加锁
    // 临界区代码
}  // 析构时自动解锁
```

### 3. std::unique_lock

**功能**：更灵活的锁管理

```cpp
std::unique_lock<std::mutex> lock(mtx);  // 默认加锁

lock.lock();     // 手动加锁
lock.unlock();   // 手动解锁
lock.try_lock(); // 尝试加锁
lock.release();  // 释放锁的所有权（不解锁）
```

### 4. std::recursive_mutex

**功能**：可重入互斥锁（同一线程可多次加锁）

```cpp
std::recursive_mutex rmtx;

void recursive_func(int n) {
    std::lock_guard<std::recursive_mutex> lock(rmtx);
    if (n > 0) {
        recursive_func(n - 1);  // 同一线程可再次加锁
    }
}
```

## 3. 条件变量接口

### 1. std::condition_variable

**功能**：线程间的条件通知

```cpp
#include <condition_variable>

std::condition_variable cv;
std::mutex mtx;
bool ready = false;

// 等待条件（生产者-消费者模式）
void consumer() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, []{ return ready; });  // 等待直到ready为true
    // 条件满足，继续执行
}

// 通知等待的线程
void producer() {
    {
        std::lock_guard<std::mutex> lock(mtx);
        ready = true;
    }
    cv.notify_one();   // 通知一个等待的线程
    // cv.notify_all(); // 通知所有等待的线程
}
```

**参数说明**：
- `wait(lock, predicate)`：
  - `lock`：必须是 `std::unique_lock<std::mutex>`
  - `predicate`：返回bool的函数/lambda，检查条件是否满足
- `notify_one()`：唤醒一个等待的线程
- `notify_all()`：唤醒所有等待的线程

## 4. 原子操作接口

### 1. std::atomic 模板

**功能**：原子类型，支持原子操作

```cpp
#include <atomic>

std::atomic<int> counter(0);

// 基本操作
counter.store(42);           // 原子写入
int val = counter.load();    // 原子读取
int old = counter.exchange(100);  // 原子交换

// 算术操作
counter.fetch_add(1);   // counter += 1（返回旧值）
counter.fetch_sub(1);   // counter -= 1
counter.fetch_or(0x01); // counter |= 0x01

// 复合赋值（C++20）
counter += 1;
counter -= 1;

// 比较并交换（CAS）
int expected = 10;
int desired = 20;
bool success = counter.compare_exchange_strong(expected, desired);
```

**内存顺序参数**：
```cpp
// 默认顺序一致性（最强）
counter.store(42, std::memory_order_seq_cst);

// 松散顺序（最弱，性能最好）
counter.store(42, std::memory_order_relaxed);

// 释放语义（保证之前的写操作可见）
counter.store(42, std::memory_order_release);

// 获取语义（保证之后的读操作可见）
int val = counter.load(std::memory_order_acquire);
```

## 5. 异步操作接口

### 1. std::async

**功能**：异步执行函数，返回future

```cpp
#include <future>

// 异步执行，返回future
std::future<int> fut = std::async(std::launch::async, func, args...);

// 参数说明：
// std::launch::async: 强制在新线程执行
// std::launch::deferred: 延迟执行（调用get()时才执行）
// func: 要执行的函数
// args: 传递给func的参数

// 获取结果（阻塞直到完成）
int result = fut.get();

// 检查是否就绪
if (fut.wait_for(std::chrono::seconds(0)) == std::future_status::ready) {
    // 结果已就绪
}
```

### 2. std::future / std::shared_future

**功能**：获取异步操作的结果

```cpp
std::future<int> fut = std::async(std::launch::async, []{ return 42; });

// 获取结果（只能调用一次）
int result = fut.get();

// 等待一段时间
std::future_status status = fut.wait_for(std::chrono::seconds(1));
if (status == std::future_status::ready) { /* 就绪 */ }
else if (status == std::future_status::timeout) { /* 超时 */ }
else if (status == std::future_status::deferred) { /* 延迟执行 */ }

// shared_future 允许多次获取结果
std::shared_future<int> sf = fut.share();
int r1 = sf.get();
int r2 = sf.get();  // OK
```

### 3. std::promise

**功能**：设置异步操作的结果

```cpp
#include <future>

void worker(std::promise<int>&& prom) {
    // 计算结果
    int result = 42;
    prom.set_value(result);  // 设置结果
}

int main() {
    std::promise<int> prom;
    std::future<int> fut = prom.get_future();
    
    std::thread t(worker, std::move(prom));
    t.detach();
    
    int result = fut.get();  // 获取结果
    return 0;
}
```

### 4. std::packaged_task

**功能**：包装可调用对象，关联future

```cpp
std::packaged_task<int(int)> task([](int x){ return x * 2; });

std::future<int> fut = task.get_future();  // 获取关联的future

// 在新线程中执行
std::thread t(std::move(task), 10);
t.join();

int result = fut.get();  // result = 20
```

## 6. 线程局部存储

### 1. thread_local 关键字

**功能**：每个线程有独立的变量副本

```cpp
thread_local int counter = 0;  // 每个线程有自己的counter

void increment() {
    counter++;
    std::cout << counter << std::endl;
}

int main() {
    std::thread t1(increment);  // 输出 1
    std::thread t2(increment);  // 输出 1
    t1.join();
    t2.join();
    return 0;
}
```

## 8. 实战示例：生产者-消费者模式

```cpp
#include <thread>
#include <mutex>
#include <queue>
#include <condition_variable>
#include <iostream>

std::queue<int> queue;
std::mutex mtx;
std::condition_variable cv;
bool done = false;

void producer(int id) {
    for (int i = 0; i < 3; ++i) {
        {
            std::lock_guard<std::mutex> lock(mtx);
            queue.push(id * 10 + i);
            std::cout << "Producer " << id << ": " << queue.back() << std::endl;
        }
        cv.notify_one();
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
}

void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, []{ return !queue.empty() || done; });
        
        while (!queue.empty()) {
            int item = queue.front();
            queue.pop();
            std::cout << "Consumer: " << item << std::endl;
        }
        
        if (done) break;
    }
}

int main() {
    std::thread t1(producer, 1);
    std::thread t2(producer, 2);
    std::thread t3(consumer);
    
    t1.join();
    t2.join();
    
    {
        std::lock_guard<std::mutex> lock(mtx);
        done = true;
    }
    cv.notify_one();
    
    t3.join();
    return 0;
}
```

## 9. 总结

### 1. 参数传递注意事项

1. **值传递**：参数被拷贝到线程内部
   ```cpp
   std::thread t(func, value);  // value被拷贝
   ```

2. **引用传递**：需要使用 `std::ref`
   ```cpp
   int x = 10;
   std::thread t(func, std::ref(x));  // 传递引用
   ```

3. **指针传递**：注意生命周期
   ```cpp
   int* p = new int(42);
   std::thread t(func, p);
   t.detach();  // 确保指针在线程结束前有效
   ```

### 2. 常用设计模式

1. **生产者-消费者**：使用队列 + 条件变量
2. **线程池**：预创建线程处理任务
3. **读写锁**：使用 `std::shared_mutex`（C++17）
4. **无锁编程**：使用原子操作

---

## 9. 极简口诀

```
线程创建用thread，join等待detach离
互斥锁用mutex，lock_guard自动管
条件变量来通知，wait等待notify唤
原子操作不阻塞，fetch_add最常用
async异步去执行，future结果等它回
promise包装传结果，packaged_task任务包
```
