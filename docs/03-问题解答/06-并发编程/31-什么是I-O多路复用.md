# 什么是I/O多路复用
> 📖 相关章节：[多线程基础](../../02-CPP/27-多线程基础.md)、[线程同步](../../02-CPP/28-线程同步.md)、[原子操作](../../02-CPP/29-原子操作与异步编程.md)、[无锁编程](../../02-CPP/33-无锁编程.md)

> "I/O多路复用=一个前台同时监控100部电话，哪部响了接哪部，而不是雇100个前台一人盯一部。"——一个线程监控多个I/O通道，是高并发服务器的核心技术。

***

### 1. 通俗理解

- **I/O多路复用** = 让一个线程同时监控多个文件描述符（fd），哪个就绪了就处理哪个
- 不需要为每个连接创建一个线程——一个线程就能管理成千上万个连接
- 就像餐厅一个服务员同时照看多张桌子，哪桌叫了就去哪桌服务

| 概念 | 类比 | 说明 |
|------|------|------|
| I/O多路复用 | 一个前台监控多部电话 | 一个线程监控多个fd |
| select | 前台逐个检查每部电话是否响了 | 每次都要遍历所有fd |
| epoll | 电话响了自动亮灯提示 | 只处理就绪的fd，不用遍历 |
| 阻塞I/O | 一部电话没挂断就不能接别的 | 一个连接阻塞整个线程 |

***

### 2. 技术说明

#### 1. 为什么需要I/O多路复用

**传统模型的问题**：

| 模型 | 方式 | 问题 |
|------|------|------|
| 阻塞I/O | 一个线程处理一个连接 | 1000个连接需要1000个线程，线程开销巨大 |
| 非阻塞I/O | 轮询所有连接 | CPU空转，效率极低 |
| I/O多路复用 | 一个线程监控多个连接 | 高效、低开销 |

**C10K问题**：1万个并发连接，如果每个连接一个线程，每个线程8MB栈，就需要80GB内存——不现实。I/O多路复用让一个线程处理上万个连接成为可能。

#### 2. select/poll/epoll/kqueue/IOCP对比

| 维度 | select | poll | epoll | kqueue | IOCP |
|------|--------|------|-------|--------|------|
| 平台 | 跨平台 | 跨平台 | Linux | macOS/BSD | Windows |
| 最大fd数 | 1024（FD_SETSIZE） | 无限制 | 无限制 | 无限制 | 无限制 |
| 内核/用户态拷贝 | 每次全量拷贝 | 每次全量拷贝 | 只拷贝就绪fd | 只拷贝就绪事件 | 只返回完成事件 |
| 就绪检测 | 线性扫描所有fd | 线性扫描所有fd | 事件驱动，只返回就绪fd | 事件驱动 | 事件驱动 |
| 时间复杂度 | O(n) | O(n) | O(1) | O(1) | O(1) |
| 触发模式 | 水平触发 | 水平触发 | 水平+边缘 | 水平+边缘 | 完成通知 |
| 适用规模 | 几十到几百 | 几百到几千 | 几千到百万 | 几千到百万 | 几千到百万 |

#### 3. select原理与局限

**工作流程**：

```
1. 构建fd_set（要监控的fd集合）
2. 调用select()，传入fd_set
3. 内核遍历所有fd，检查是否有事件
4. 修改fd_set，标记哪些fd就绪
5. 返回用户态，程序再次遍历fd_set找就绪fd
```

**三大局限**：

| 局限 | 说明 |
|------|------|
| FD_SETSIZE限制 | 默认1024，修改需重新编译 |
| 全量拷贝 | 每次调用都要把整个fd_set从用户态拷贝到内核态，再拷贝回来 |
| 线性扫描 | 内核和用户态都要遍历所有fd，O(n)效率 |

#### 4. epoll原理

**核心数据结构**：

```
┌─────────────────────────────────────────────┐
│              epoll 内核结构                    │
│                                              │
│   ┌──────────────┐    ┌──────────────────┐  │
│   │   红黑树      │    │   就绪链表        │  │
│   │  (存储所有    │    │  (存储就绪的fd)   │  │
│   │   监控的fd)   │    │                  │  │
│   │              │    │  fd5 → fd12 →    │  │
│   │  fd1 fd3 fd5 │    │  fd3             │  │
│   │  fd7 fd12... │    │                  │  │
│   └──────┬───────┘    └────────┬─────────┘  │
│          │                     │             │
│          │  fd就绪时自动        │             │
│          │  加入就绪链表 ───────→             │
│          │                     │             │
└──────────┼─────────────────────┼─────────────┘
           │                     │
   epoll_ctl(添加/删除fd)   epoll_wait(获取就绪fd)
```

**epoll三大API**：

| API | 作用 | 说明 |
|-----|------|------|
| `epoll_create` | 创建epoll实例 | 返回epoll fd |
| `epoll_ctl` | 添加/修改/删除监控的fd | 注册事件回调 |
| `epoll_wait` | 等待就绪事件 | 只返回就绪的fd |

**LT vs ET触发模式**：

| 模式 | 全称 | 行为 | 类比 |
|------|------|------|------|
| LT（水平触发） | Level Triggered | 只要fd有数据可读，每次epoll_wait都会返回 | 水位没过传感器就一直报警 |
| ET（边缘触发） | Edge Triggered | 只在fd状态变化时通知一次，必须一次读完所有数据 | 水位刚过传感器时报警一次，之后不再报 |

**ET模式注意事项**：必须用非阻塞I/O + 循环读直到EAGAIN，否则可能丢失数据。

### 3. 代码示例

#### 1. select基本用法

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <sys/select.h>

#define MAX_CLIENTS  FD_SETSIZE
#define PORT         8080

int main(void) {
    int listen_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (listen_fd < 0) {
        perror("socket");
        return 1;
    }

    int opt = 1;
    setsockopt(listen_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(PORT);

    bind(listen_fd, (struct sockaddr*)&addr, sizeof(addr));
    listen(listen_fd, 5);

    int client_fds[MAX_CLIENTS];
    for (int i = 0; i < MAX_CLIENTS; i++) {
        client_fds[i] = -1;
    }

    printf("select服务器启动，端口 %d\n", PORT);

    while (1) {
        fd_set read_fds;
        FD_ZERO(&read_fds);
        FD_SET(listen_fd, &read_fds);

        int max_fd = listen_fd;

        for (int i = 0; i < MAX_CLIENTS; i++) {
            if (client_fds[i] >= 0) {
                FD_SET(client_fds[i], &read_fds);
                if (client_fds[i] > max_fd) {
                    max_fd = client_fds[i];
                }
            }
        }

        int ready = select(max_fd + 1, &read_fds, NULL, NULL, NULL);
        if (ready < 0) {
            perror("select");
            continue;
        }

        if (FD_ISSET(listen_fd, &read_fds)) {
            struct sockaddr_in client_addr;
            socklen_t client_len = sizeof(client_addr);
            int new_fd = accept(listen_fd, (struct sockaddr*)&client_addr, &client_len);
            if (new_fd >= 0) {
                for (int i = 0; i < MAX_CLIENTS; i++) {
                    if (client_fds[i] < 0) {
                        client_fds[i] = new_fd;
                        printf("新客户端连接，fd=%d\n", new_fd);
                        break;
                    }
                }
            }
        }

        for (int i = 0; i < MAX_CLIENTS; i++) {
            if (client_fds[i] >= 0 && FD_ISSET(client_fds[i], &read_fds)) {
                char buf[1024];
                ssize_t n = read(client_fds[i], buf, sizeof(buf) - 1);
                if (n <= 0) {
                    close(client_fds[i]);
                    printf("客户端断开，fd=%d\n", client_fds[i]);
                    client_fds[i] = -1;
                } else {
                    buf[n] = '\0';
                    printf("收到数据(fd=%d): %s", client_fds[i], buf);
                    write(client_fds[i], buf, n);
                }
            }
        }
    }

    close(listen_fd);
    return 0;
}
```

#### 2. epoll基本用法（LT模式）

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <sys/epoll.h>

#define MAX_EVENTS  64
#define PORT        8080

int main(void) {
    int listen_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (listen_fd < 0) {
        perror("socket");
        return 1;
    }

    int opt = 1;
    setsockopt(listen_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(PORT);

    bind(listen_fd, (struct sockaddr*)&addr, sizeof(addr));
    listen(listen_fd, 128);

    int epfd = epoll_create1(0);
    if (epfd < 0) {
        perror("epoll_create1");
        return 1;
    }

    struct epoll_event ev;
    ev.events = EPOLLIN;
    ev.data.fd = listen_fd;
    epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);

    printf("epoll服务器启动，端口 %d\n", PORT);

    struct epoll_event events[MAX_EVENTS];

    while (1) {
        int nfds = epoll_wait(epfd, events, MAX_EVENTS, -1);
        if (nfds < 0) {
            perror("epoll_wait");
            continue;
        }

        for (int i = 0; i < nfds; i++) {
            if (events[i].data.fd == listen_fd) {
                struct sockaddr_in client_addr;
                socklen_t client_len = sizeof(client_addr);
                int new_fd = accept(listen_fd, (struct sockaddr*)&client_addr, &client_len);
                if (new_fd >= 0) {
                    printf("新客户端连接，fd=%d\n", new_fd);
                    ev.events = EPOLLIN;
                    ev.data.fd = new_fd;
                    epoll_ctl(epfd, EPOLL_CTL_ADD, new_fd, &ev);
                }
            } else {
                char buf[1024];
                ssize_t n = read(events[i].data.fd, buf, sizeof(buf) - 1);
                if (n <= 0) {
                    printf("客户端断开，fd=%d\n", events[i].data.fd);
                    epoll_ctl(epfd, EPOLL_CTL_DEL, events[i].data.fd, NULL);
                    close(events[i].data.fd);
                } else {
                    buf[n] = '\0';
                    printf("收到数据(fd=%d): %s", events[i].data.fd, buf);
                    write(events[i].data.fd, buf, n);
                }
            }
        }
    }

    close(listen_fd);
    close(epfd);
    return 0;
}
```

### 4. 适用场景

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 几十个连接 | select | 简单够用，跨平台 |
| 几百个连接 | poll | 无FD_SETSIZE限制 |
| 几千到百万连接（Linux） | epoll | O(1)效率，C10K/C10M解决方案 |
| 几千到百万连接（macOS） | kqueue | BSD系统上的高效方案 |
| 几千到百万连接（Windows） | IOCP | Windows上的异步I/O方案 |
| 跨平台需求 | libevent/libuv | 封装了各平台的多路复用API |

***

### 5. 常见问题

#### 1. 问题1：epoll一定比select好吗

不一定。连接数少（几十个）时，select性能足够，且代码更简单、跨平台更好。epoll的优势在连接数多时才明显。

#### 2. 问题2：ET模式一定比LT模式好吗

不一定。ET模式效率更高（减少epoll_wait调用次数），但编程复杂——必须循环读直到EAGAIN，且必须用非阻塞fd。LT模式更安全，不容易丢数据。

#### 3. 问题3：I/O多路复用能处理计算密集型任务吗

不能。I/O多路复用解决的是I/O等待问题，如果任务本身是CPU密集型的，会阻塞整个事件循环。解决方法：配合线程池，把计算任务交给工作线程。

***

### 6. 极简总结

**I/O多路复用让一个线程同时监控多个I/O通道，是高并发服务器的核心技术。select有1024限制且O(n)扫描，epoll用红黑树+就绪链表实现O(1)效率，支持百万级连接。LT模式安全简单，ET模式高效但编程复杂。**

| 要点 | 一句话 |
|------|--------|
| I/O多路复用 | 一个线程监控多个fd——高并发服务器的核心技术 |
| select | 1024限制 + 全量拷贝 + 线性扫描——小规模够用 |
| epoll | 红黑树+就绪链表 + O(1)——Linux高并发首选 |
| LT vs ET | LT水平触发安全简单，ET边缘触发高效但需非阻塞+循环读 |
| C10K | 万级并发——I/O多路复用是解决方案 |
| 跨平台 | libevent/libuv封装了各平台差异 |
