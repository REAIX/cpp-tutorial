# 跨平台是什么意思

### 1. 核心提炼

**跨平台** = 同一份代码能在不同操作系统/硬件架构上编译运行。三个层次：**源码级**（重新编译）、**二进制级**（直接运行）、**Web级**（浏览器运行）。C/C++ 是源码级跨平台。

***

### 2. 三个层次

| 层次 | 方式 | 示例 | 原理 |
|------|------|------|------|
| 源码级跨平台 | 同一份源码，不同平台编译 | C/C++ | 编译器为每个平台生成不同的机器码 |
| 二进制级跨平台 | 编译一次，到处运行 | Java | 字节码在虚拟机上运行 |
| Web级跨平台 | 浏览器运行 | JavaScript/WebAssembly | 浏览器屏蔽平台差异 |

C/C++ 是**源码级跨平台**，不是二进制级。Windows 上编译的 `.exe` 无法在 Linux 上运行。

```
源码级：  源码 → [Windows编译器] → Windows可执行文件
          源码 → [Linux编译器]   → Linux可执行文件
          源码 → [macOS编译器]   → macOS可执行文件

二进制级：源码 → [javac] → 字节码 → [Windows JVM] → 运行
                                        [Linux JVM]  → 运行
                                        [macOS JVM]  → 运行
```

### 3. 四种实现方法

#### 1. 方法1：条件编译

用预处理器宏在编译期选择平台相关代码：

```cpp
// 平台检测
#ifdef _WIN32
    #define PLATFORM_WINDOWS 1
#elif defined(__linux__)
    #define PLATFORM_LINUX 1
#elif defined(__APPLE__)
    #define PLATFORM_MACOS 1
#elif defined(__FreeBSD__)
    #define PLATFORM_FREEBSD 1
#else
    #define PLATFORM_UNKNOWN 1
#endif

// 条件编译选择实现
#ifdef PLATFORM_WINDOWS
    #include <windows.h>
    void sleep_ms(unsigned int ms) { Sleep(ms); }

    void create_directory(const std::string& path) {
        CreateDirectoryA(path.c_str(), nullptr);
    }

#elif defined(PLATFORM_LINUX) || defined(PLATFORM_MACOS)
    #include <unistd.h>
    #include <sys/stat.h>
    void sleep_ms(unsigned int ms) { usleep(ms * 1000); }

    void create_directory(const std::string& path) {
        mkdir(path.c_str(), 0755);
    }
#endif
```

**编译器检测**：

```cpp
// 编译器检测
#if defined(_MSC_VER)
    // MSVC
#elif defined(__GNUC__)
    // GCC
#elif defined(__clang__)
    // Clang
#endif

// 架构检测
#if defined(_M_X64) || defined(__x86_64__)
    // x86-64
#elif defined(_M_ARM64) || defined(__aarch64__)
    // ARM64
#elif defined(__arm__)
    // ARM32
#endif
```

#### 2. 方法2：抽象层（Platform Abstraction Layer）

将平台相关代码封装到统一接口后面：

```cpp
// platform.h — 统一接口
#pragma once
#include <string>
#include <vector>

class IFileSystem {
public:
    virtual ~IFileSystem() = default;
    virtual bool exists(const std::string& path) = 0;
    virtual bool create_directory(const std::string& path) = 0;
    virtual std::vector<std::string> list_files(const std::string& dir) = 0;
    virtual std::string read_file(const std::string& path) = 0;
    virtual bool write_file(const std::string& path, const std::string& content) = 0;
};

class IThread {
public:
    virtual ~IThread() = default;
    virtual void start() = 0;
    virtual void join() = 0;
    virtual void sleep_ms(unsigned int ms) = 0;
};

// 工厂函数
std::unique_ptr<IFileSystem> create_filesystem();
std::unique_ptr<IThread> create_thread();
```

```cpp
// platform_windows.cpp
#include "platform.h"
#include <windows.h>

class WinFileSystem : public IFileSystem {
public:
    bool exists(const std::string& path) override {
        return GetFileAttributesA(path.c_str()) != INVALID_FILE_ATTRIBUTES;
    }
    bool create_directory(const std::string& path) override {
        return CreateDirectoryA(path.c_str(), nullptr) != 0;
    }
    // ... 其他实现
};

std::unique_ptr<IFileSystem> create_filesystem() {
    return std::make_unique<WinFileSystem>();
}
```

```cpp
// platform_linux.cpp
#include "platform.h"
#include <sys/stat.h>
#include <dirent.h>

class LinuxFileSystem : public IFileSystem {
public:
    bool exists(const std::string& path) override {
        struct stat st;
        return stat(path.c_str(), &st) == 0;
    }
    bool create_directory(const std::string& path) override {
        return mkdir(path.c_str(), 0755) == 0;
    }
    // ... 其他实现
};

std::unique_ptr<IFileSystem> create_filesystem() {
    return std::make_unique<LinuxFileSystem>();
}
```

**业务代码只依赖抽象接口**：

```cpp
// 业务代码 — 完全不关心平台
void app_init() {
    auto fs = create_filesystem();
    if (!fs->exists("/data/config")) {
        fs->create_directory("/data/config");
    }
}
```

#### 3. 方法3：CMake 跨平台构建

CMake 是 C/C++ 跨平台构建的标准工具：

```cmake
cmake_minimum_required(VERSION 3.20)
project(MyApp VERSION 1.0 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 源文件
set(SOURCES
    src/main.cpp
    src/app.cpp
)

# 平台相关源文件
if(WIN32)
    list(APPEND SOURCES src/platform_windows.cpp)
elseif(UNIX)
    list(APPEND SOURCES src/platform_linux.cpp)
endif()

add_executable(myapp ${SOURCES})

# 平台相关链接库
if(WIN32)
    target_link_libraries(myapp PRIVATE ws2_32)   # Windows 网络
elseif(UNIX)
    target_link_libraries(myapp PRIVATE pthread)   # Linux 线程
    target_link_libraries(myapp PRIVATE dl)        # 动态加载
endif()

# 平台相关编译选项
if(MSVC)
    target_compile_options(myapp PRIVATE /W4 /utf-8)
else()
    target_compile_options(myapp PRIVATE -Wall -Wextra -Wpedantic)
endif()

# 安装规则（跨平台）
install(TARGETS myapp DESTINATION bin)
```

```cmake
# 跨平台查找库
find_package(Threads REQUIRED)
target_link_libraries(myapp PRIVATE Threads::Threads)

# 条件编译定义
if(CMAKE_BUILD_TYPE STREQUAL "Debug")
    target_compile_definitions(myapp PRIVATE DEBUG_MODE)
endif()

# 跨平台生成文件路径
set(CONFIG_DIR "${CMAKE_CURRENT_SOURCE_DIR}/config")
target_compile_definitions(myapp PRIVATE CONFIG_DIR="${CONFIG_DIR}")
```

#### 4. 方法4：跨平台库

| 库 | 用途 | 跨平台方式 |
|------|------|-----------|
| Qt | GUI + 系统抽象 | 内部封装平台差异 |
| SDL | 游戏开发 | 内部封装平台差异 |
| Boost | 通用库 | 内部封装平台差异 |
| POSIX | 类Unix统一接口 | Linux/macOS 共用 |
| libuv | 异步I/O | 内部封装平台差异 |
| spdlog | 日志 | 纯头文件 |
| fmt | 格式化 | 纯头文件 |

```cpp
// 使用跨平台库替代平台相关代码
#include <filesystem>  // C++17 文件系统，跨平台
#include <thread>      // C++11 线程，跨平台
#include <chrono>      // C++11 时间，跨平台

// 不再需要条件编译！
void cross_platform_code() {
    // 创建目录 — 跨平台
    std::filesystem::create_directory("data");

    // 休眠 — 跨平台
    std::this_thread::sleep_for(std::chrono::milliseconds(100));

    // 获取文件大小 — 跨平台
    auto size = std::filesystem::file_size("config.txt");
}
```

### 4. 常见平台差异

#### 1. 文件系统差异

| 差异 | Windows | Linux/macOS |
|------|---------|-------------|
| 路径分隔符 | `\`（反斜杠） | `/`（斜杠） |
| 换行符 | `\r\n`（CRLF） | `\n`（LF） |
| 绝对路径 | `C:\Users\...` | `/home/user/...` |
| 环境变量分隔符 | `;` | `:` |
| 动态库后缀 | `.dll` | `.so` / `.dylib` |
| 可执行文件后缀 | `.exe` | 无后缀 |
| 文件名大小写 | 不敏感 | 敏感 |

```cpp
// 路径处理：使用 std::filesystem（C++17）
#include <filesystem>

// 正确：使用 path 自动处理分隔符
std::filesystem::path dir = "data";
std::filesystem::path file = dir / "config" / "settings.json";
// Windows: "data\\config\\settings.json"
// Linux:   "data/config/settings.json"

// 错误：硬编码路径分隔符
std::string path = "data\\config\\settings.json";  // Linux 上失败
```

#### 2. 系统 API 差异

| 功能 | Windows | Linux/macOS |
|------|---------|-------------|
| 线程 | `CreateThread` | `pthread_create` |
| 网络 | Winsock (`WSAStartup`) | BSD socket |
| 动态加载 | `LoadLibrary` | `dlopen` |
| 进程 | `CreateProcess` | `fork` + `exec` |
| 共享内存 | `CreateFileMapping` | `shm_open` / `mmap` |
| 互斥锁 | `CRITICAL_SECTION` | `pthread_mutex` |

```cpp
// 网络：Winsock vs BSD socket
#ifdef _WIN32
    #include <winsock2.h>
    #include <ws2tcpip.h>
    #pragma comment(lib, "ws2_32.lib")
#else
    #include <sys/socket.h>
    #include <netinet/in.h>
    #include <arpa/inet.h>
    #include <unistd.h>
#endif

class SocketInit {
public:
    SocketInit() {
    #ifdef _WIN32
        WSADATA wsa;
        WSAStartup(MAKEWORD(2, 2), &wsa);
    #endif
    }
    ~SocketInit() {
    #ifdef _WIN32
        WSACleanup();
    #endif
    }
};

int socket_close(int fd) {
#ifdef _WIN32
    return closesocket(fd);
#else
    return close(fd);
#endif
}
```

#### 3. 编译器差异

| 差异 | MSVC | GCC/Clang |
|------|------|-----------|
| 编译选项 | `/O2`, `/W4` | `-O2`, `-Wall` |
| 导出符号 | `__declspec(dllexport)` | `__attribute__((visibility("default")))` |
| 对齐 | `__declspec(align(16))` | `__attribute__((aligned(16)))` |
| 内联汇编 | `__asm` | `asm()` |
| 警告控制 | `#pragma warning(disable:4996)` | `#pragma GCC diagnostic ignored "-W..."` |

```cpp
// 跨平台导出宏
#ifdef _WIN32
    #ifdef MYLIB_EXPORTS
        #define MYLIB_API __declspec(dllexport)
    #else
        #define MYLIB_API __declspec(dllimport)
    #endif
#else
    #define MYLIB_API __attribute__((visibility("default")))
#endif

class MYLIB_API MyClass {
public:
    void do_something();
};
```

### 5. CMake 跨平台配置完整示例

```cmake
cmake_minimum_required(VERSION 3.20)
project(CrossPlatformApp VERSION 1.0)

# C++ 标准
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)

# 源文件
file(GLOB_RECURSE SOURCES "src/*.cpp")

# 平台检测与配置
message(STATUS "Platform: ${CMAKE_SYSTEM_NAME}")
message(STATUS "Compiler: ${CMAKE_CXX_COMPILER_ID}")

# 可执行文件
add_executable(myapp ${SOURCES})

# 包含目录
target_include_directories(myapp PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/include
)

# 平台相关配置
if(WIN32)
    message(STATUS "Configuring for Windows")
    target_compile_definitions(myapp PRIVATE
        PLATFORM_WINDOWS
        WIN32_LEAN_AND_MEAN
        NOMINMAX
    )
    target_link_libraries(myapp PRIVATE
        ws2_32      # 网络
        winmm       # 多媒体
        dbghelp     # 调试
    )
    # Windows 子系统
    if(NOT CMAKE_BUILD_TYPE STREQUAL "Debug")
        set_target_properties(myapp PROPERTIES
            WIN32_EXECUTABLE YES
        )
    endif()

elseif(APPLE)
    message(STATUS "Configuring for macOS")
    target_compile_definitions(myapp PRIVATE PLATFORM_MACOS)
    find_library(FOUNDATION Foundation)
    target_link_libraries(myapp PRIVATE ${FOUNDATION})

elseif(UNIX)
    message(STATUS "Configuring for Linux")
    target_compile_definitions(myapp PRIVATE PLATFORM_LINUX)
    target_link_libraries(myapp PRIVATE
        pthread     # 线程
        dl          # 动态加载
        rt          # 实时扩展
    )
endif()

# 编译器相关选项
if(MSVC)
    target_compile_options(myapp PRIVATE /W4 /utf-8 /permissive-)
    # 静态链接运行时
    set_property(TARGET myapp PROPERTY
        MSVC_RUNTIME_LIBRARY "MultiThreaded$<$<CONFIG:Debug>:Debug>")
else()
    target_compile_options(myapp PRIVATE
        -Wall -Wextra -Wpedantic -Werror
    )
endif()

# 安装
install(TARGETS myapp DESTINATION bin)
install(DIRECTORY include/ DESTINATION include)
```

### 6. Qt 跨平台开发

Qt 是 C++ 跨平台 GUI 开发的首选框架：

```cpp
#include <QApplication>
#include <QPushButton>
#include <QFile>
#include <QDir>
#include <QThread>

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);

    // GUI — 自动适配平台风格
    QPushButton button("Hello Cross-Platform!");
    button.resize(200, 100);
    button.show();

    // 文件操作 — 跨平台
    QString config_path = QDir::homePath() + "/.myapp/config.ini";
    QFile config(config_path);
    if (config.open(QIODevice::ReadOnly)) {
        // 读取配置...
    }

    // 线程 — 跨平台
    QThread* thread = QThread::create([]() {
        QThread::msleep(1000);  // 跨平台休眠
    });
    thread->start();

    return app.exec();
}
```

Qt 的跨平台封装：

| Qt 类 | 封装的功能 | 原始平台 API |
|-------|-----------|-------------|
| `QFile` | 文件操作 | WinAPI / POSIX |
| `QDir` | 目录操作 | WinAPI / POSIX |
| `QThread` | 线程 | CreateThread / pthread |
| `QTcpSocket` | TCP 网络 | Winsock / BSD socket |
| `QProcess` | 进程 | CreateProcess / fork+exec |
| `QSettings` | 注册表/配置文件 | Windows Registry / INI |

### 7. 跨平台最佳实践

1. **优先使用标准库**：C++17 `<filesystem>`, `<thread>`, `<chrono>` 已经跨平台
2. **平台代码隔离**：将平台相关代码放在独立文件中
3. **用 CMake 管理**：不要手写 Makefile 或 .sln
4. **CI 多平台测试**：GitHub Actions 支持 Windows/Linux/macOS
5. **避免硬编码路径**：用 `std::filesystem::path` 拼接
6. **注意字节序**：网络传输用大端序，x86 是小端序

```cpp
// 字节序处理
#include <cstdint>
#include <cstring>

// 检测字节序
constexpr bool is_little_endian() {
    uint16_t x = 1;
    return *reinterpret_cast<uint8_t*>(&x) == 1;
}

// 主机序 → 网络序（大端）
uint32_t host_to_network(uint32_t val) {
    if constexpr (is_little_endian()) {
        return ((val & 0xFF000000) >> 24) |
               ((val & 0x00FF0000) >> 8)  |
               ((val & 0x0000FF00) << 8)  |
               ((val & 0x000000FF) << 24);
    }
    return val;
}
```

### 8. 常见陷阱

#### 1. 陷阱1：硬编码路径分隔符

```cpp
// 错误
std::string path = "data\\config\\settings.json";  // Linux 上失败

// 正确
std::filesystem::path path = "data" / "config" / "settings.json";
```

#### 2. 陷阱2：假设文件名大小写

```cpp
// 错误：Windows 不区分大小写，Linux 区分
#include "MyHeader.h"  // Windows 能找到 myheader.h，Linux 找不到

// 正确：文件名大小写与实际文件完全一致
#include "myheader.h"
```

#### 3. 陷阱3：忽略换行符差异

```cpp
// 错误：假设换行符是 \n
while (std::getline(file, line)) {
    // Windows 上行末可能有 \r
    if (!line.empty() && line.back() == '\r') {
        line.pop_back();  // 去掉 \r
    }
}
```

#### 4. 陷阱4：编译器扩展

```cpp
// 错误：使用 MSVC 特有扩展
__int64 big_num = 0;  // GCC 不识别

// 正确：使用标准类型
int64_t big_num = 0;  // #include <cstdint>
```

### 9. 极简总结

**跨平台 = 源码级（C/C++）→ 条件编译 + 抽象层 + CMake + 跨平台库**

| 方法 | 适用场景 | 复杂度 |
|------|----------|--------|
| 条件编译 | 少量平台差异 | 低 |
| 抽象层 | 大量平台差异 | 中 |
| CMake | 构建系统跨平台 | 中 |
| 跨平台库 | 通用功能 | 低 |
| C++17 标准库 | 文件系统/线程/时间 | 最低 |
