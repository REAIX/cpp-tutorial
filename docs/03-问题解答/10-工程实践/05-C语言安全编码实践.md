# C语言安全编码实践
> 📖 相关章节：[编码规范](../../04-工程实践/00-编码规范.md)、[设计模式](../../04-工程实践/03-设计模式.md)、[单元测试](../../04-工程实践/06-单元测试.md)、[代码审查](../../04-工程实践/08-代码审查.md)

> "安全编码=给房子装锁——不安全编码=门不关、窗户开着，黑客只需要找到一个入口。"

***

### 1. 核心定义

- **安全编码** = 编写不会被恶意输入、边界条件、并发访问等因素破坏的代码
- C语言因为没有边界检查、没有异常机制，安全编码尤为重要

| | 安全编码 | 不安全编码 |
|---|---|---|
| 输入处理 | 验证所有外部输入 | 信任所有输入 |
| 内存操作 | 检查边界、长度 | 随意读写 |
| 指针管理 | free后置NULL、检查空指针 | 野指针、悬空指针 |
| 错误处理 | 检查每个返回值 | 忽略返回值 |
| 编译选项 | 开启安全编译选项 | 默认编译 |

***

### 2. 生活类比

**安全编码 = 给房子装锁**

| 比喻 | 含义 |
|------|------|
| 给房子装锁 | 安全编码——每道门、每扇窗都要检查 |
| 门不关、窗户开着 | 不安全编码——只要有一个入口，小偷就能进来 |
| 小偷 | 黑客——只需要找到一个漏洞 |
| 换锁 | 用安全函数替代不安全函数——`fgets` 替代 `gets` |
| 装监控 | 开启编译器安全选项——`-Wall -Werror -fstack-protector` |
| 保安检查 | 输入验证——所有进入的数据都要检查 |

**具体场景**：

- **缓冲区溢出** = 水杯只有500ml容量，你硬倒1升水进去，水漫出来把桌子淹了
- **格式化字符串漏洞** = 你把空白支票交给别人填金额，别人想填多少填多少
- **Use-After-Free** = 你把房子卖了，但还留着钥匙，偶尔还回去住
- **Double Free** = 你把同一套房子卖了两次

### 3. 常见安全漏洞与防护

#### 1. 漏洞1：缓冲区溢出

**原因**：`gets`/`strcpy`/`sprintf` 不检查长度，写入超过缓冲区大小。

```c
#include <stdio.h>
#include <string.h>

void unsafe(void) {
    char buf[64];
    gets(buf);
    strcpy(buf, "very long string that exceeds 64 bytes very long string that exceeds 64 bytes");
    sprintf(buf, "%s %s %s", str1, str2, str3);
}

void safe(void) {
    char buf[64];
    fgets(buf, sizeof(buf), stdin);
    strncpy(buf, "hello", sizeof(buf) - 1);
    buf[sizeof(buf) - 1] = '\0';
    snprintf(buf, sizeof(buf), "%s %s", str1, str2);
}
```

| 不安全函数 | 问题 | 安全替代 |
|-----------|------|---------|
| `gets(buf)` | 无长度限制 | `fgets(buf, size, stdin)` |
| `strcpy(dst, src)` | 不检查目标大小 | `strncpy(dst, src, size-1)` |
| `sprintf(buf, fmt, ...)` | 不检查输出长度 | `snprintf(buf, size, fmt, ...)` |

#### 2. 漏洞2：格式化字符串漏洞

**原因**：`printf(user_input)` 直接用用户输入作为格式串，用户可以注入 `%s`、`%n` 等读取或写入内存。

```c
#include <stdio.h>

void unsafe(const char* user_input) {
    printf(user_input);
}

void safe(const char* user_input) {
    printf("%s", user_input);
}
```

| 格式符 | 危险 | 说明 |
|--------|------|------|
| `%s` | 读取栈上数据 | 可泄露内存内容 |
| `%x` | 读取栈上十六进制值 | 可泄露地址 |
| `%n` | 向栈上地址写入已输出字节数 | 可修改内存 |

#### 3. 漏洞3：整数溢出

**原因**：乘法/加法结果超出类型范围，回绕到错误值。

```c
#include <stdio.h>
#include <limits.h>
#include <stdint.h>

int unsafe_multiply(int a, int b) {
    return a * b;
}

int safe_multiply(int a, int b, int* result) {
    if (a > 0 && b > 0 && a > INT_MAX / b) return -1;
    if (a > 0 && b < 0 && b < INT_MIN / a) return -1;
    if (a < 0 && b > 0 && a < INT_MIN / b) return -1;
    if (a < 0 && b < 0 && a < INT_MAX / b) return -1;
    *result = a * b;
    return 0;
}

void safe_allocate(int count, int element_size) {
    if (count <= 0 || element_size <= 0) {
        fprintf(stderr, "invalid parameters\n");
        return;
    }
    if (count > INT_MAX / element_size) {
        fprintf(stderr, "integer overflow in allocation size\n");
        return;
    }
    void* ptr = malloc((size_t)count * (size_t)element_size);
    if (!ptr) {
        fprintf(stderr, "allocation failed\n");
        return;
    }
}
```

#### 4. 漏洞4：使用未初始化变量

**原因**：局部变量未初始化就使用，值是栈上的随机残留数据。

```c
#include <stdio.h>
#include <string.h>

void unsafe(void) {
    int flag;
    char buf[128];

    if (flag) {
        printf("maybe executed, maybe not\n");
    }
}

void safe(void) {
    int flag = 0;
    char buf[128];
    memset(buf, 0, sizeof(buf));

    if (flag) {
        printf("never executed\n");
    }
}
```

#### 5. 漏洞5：释放后使用（Use-After-Free）

**原因**：`free` 后继续使用指针，内存可能已被分配给其他用途。

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void unsafe(void) {
    char* ptr = malloc(100);
    strcpy(ptr, "hello");
    free(ptr);
    printf("%s\n", ptr);
}

void safe(void) {
    char* ptr = malloc(100);
    if (!ptr) return;
    strcpy(ptr, "hello");
    printf("%s\n", ptr);
    free(ptr);
    ptr = NULL;

    if (ptr != NULL) {
        printf("%s\n", ptr);
    }
}
```

#### 6. 漏洞6：双重释放（Double Free）

**原因**：同一指针 `free` 两次，导致堆管理器状态混乱。

```c
#include <stdlib.h>

void unsafe(void) {
    char* ptr = malloc(100);
    free(ptr);
    free(ptr);
}

void safe(void) {
    char* ptr = malloc(100);
    if (!ptr) return;
    free(ptr);
    ptr = NULL;
}
```

**`free(NULL)` 是安全的**（标准保证），所以 free 后置 NULL 可以防止 Double Free。

#### 7. 漏洞7：TOCTOU竞态

**原因**：检查时间（Time of Check）与使用时间（Time of Use）之间状态变化。

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/stat.h>

void unsafe(const char* filename) {
    struct stat st;
    if (lstat(filename, &st) == 0) {
        if (S_ISREG(st.st_mode)) {
            FILE* f = fopen(filename, "r");
        }
    }
}

void safe(const char* filename) {
    int fd = open(filename, O_RDONLY | O_NOFOLLOW);
    if (fd < 0) {
        perror("open");
        return;
    }
    struct stat st;
    if (fstat(fd, &st) == 0 && S_ISREG(st.st_mode)) {
        FILE* f = fdopen(fd, "r");
    } else {
        close(fd);
    }
}
```

### 4. 安全函数替代表

| 不安全函数 | 安全替代 | 说明 |
|-----------|---------|------|
| `gets()` | `fgets()` | 限制读取长度 |
| `strcpy()` | `strncpy()` / `strlcpy()` | 限制拷贝长度 |
| `strcat()` | `strncat()` / `strlcat()` | 限制追加长度 |
| `sprintf()` | `snprintf()` | 限制输出长度 |
| `vsprintf()` | `vsnprintf()` | 限制输出长度 |
| `scanf("%s")` | `scanf("%99s")` | 限制输入长度 |
| `atoi()` | `strtol()` | 错误检测 |
| `strtok()` | `strtok_r()` / `strsep()` | 线程安全 |

**安全替代代码示例**：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void safe_string_ops(void) {
    char buf[64];

    fgets(buf, sizeof(buf), stdin);
    buf[strcspn(buf, "\n")] = '\0';

    char dst[64];
    strncpy(dst, "source string", sizeof(dst) - 1);
    dst[sizeof(dst) - 1] = '\0';

    snprintf(buf, sizeof(buf), "value=%d", 42);

    const char* num_str = "12345";
    char* endptr;
    long val = strtol(num_str, &endptr, 10);
    if (endptr == num_str) {
        fprintf(stderr, "not a number\n");
    }

    char str[] = "one,two,three";
    char* saveptr;
    char* token = strtok_r(str, ",", &saveptr);
    while (token) {
        printf("%s\n", token);
        token = strtok_r(NULL, ",", &saveptr);
    }
}
```

### 5. 输入验证原则

#### 1. 四条核心原则

| 原则 | 说明 |
|------|------|
| 永远不信任外部输入 | 所有来自用户、文件、网络的数据都不可信 |
| 白名单优于黑名单 | 定义"什么是合法的"比"什么是非法的"更安全 |
| 验证长度、范围、格式、类型 | 四个维度都要检查 |
| 失败时拒绝 | 验证不通过直接拒绝，不要尝试修复 |

#### 2. 代码示例：安全的输入验证函数

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>
#include <stdbool.h>

bool validate_username(const char* input, size_t max_len) {
    if (!input) return false;

    size_t len = strlen(input);
    if (len == 0 || len > max_len) return false;

    for (size_t i = 0; i < len; i++) {
        char c = input[i];
        if (!(isalnum((unsigned char)c) || c == '_' || c == '-')) {
            return false;
        }
    }

    return true;
}

bool validate_int_range(const char* input, int min_val, int max_val, int* out) {
    if (!input || !out) return false;

    char* endptr;
    long val = strtol(input, &endptr, 10);

    if (endptr == input || *endptr != '\0') return false;
    if (val < min_val || val > max_val) return false;

    *out = (int)val;
    return true;
}

bool validate_path(const char* input, size_t max_len) {
    if (!input) return false;

    size_t len = strlen(input);
    if (len == 0 || len > max_len) return false;

    if (strstr(input, "..") != NULL) return false;
    if (input[0] == '/') return false;

    return true;
}

int main(void) {
    char username[64];
    fgets(username, sizeof(username), stdin);
    username[strcspn(username, "\n")] = '\0';

    if (!validate_username(username, 32)) {
        fprintf(stderr, "invalid username\n");
        return 1;
    }

    char age_str[16];
    fgets(age_str, sizeof(age_str), stdin);
    age_str[strcspn(age_str, "\n")] = '\0';

    int age;
    if (!validate_int_range(age_str, 0, 150, &age)) {
        fprintf(stderr, "invalid age\n");
        return 1;
    }

    printf("username=%s, age=%d\n", username, age);
    return 0;
}
```

### 6. 安全编译选项

#### 1. GCC/Clang 安全编译选项

| 选项 | 作用 | 说明 |
|------|------|------|
| `-Wall -Wextra` | 开启常见警告 | 发现潜在问题 |
| `-Werror` | 警告视为错误 | 强制修复所有警告 |
| `-fstack-protector-strong` | 栈保护 | 在函数入口插入canary，检测栈溢出 |
| `-D_FORTIFY_SOURCE=2` | 运行时缓冲区检查 | 在编译时替换不安全函数为安全版本 |
| `-fPIE -pie` | 位置无关可执行文件 | 启用ASLR（地址空间随机化） |
| `-Wl,-z,relro,-z,now` | 只读重定位 | 防止GOT覆写攻击 |
| `-fno-omit-frame-pointer` | 保留帧指针 | 便于调试和栈回溯 |
| `-Wformat -Wformat-security` | 格式化字符串检查 | 防止格式化字符串漏洞 |

#### 2. 安全的 Makefile 编译选项

```makefile
CC = gcc
CFLAGS = -std=c11 -Wall -Wextra -Werror \
         -fstack-protector-strong \
         -D_FORTIFY_SOURCE=2 \
         -fPIE \
         -Wformat -Wformat-security \
         -fno-omit-frame-pointer

LDFLAGS = -pie -Wl,-z,relro,-z,now

TARGET = myapp
SRCS = main.c utils.c
OBJS = $(SRCS:.c=.o)

$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) -o $@ $^ $(LDFLAGS)

%.o: %.c
	$(CC) $(CFLAGS) -c -o $@ $<

clean:
	rm -f $(OBJS) $(TARGET)

.PHONY: clean
```

#### 3. 各选项防护的攻击类型

| 攻击类型 | 防护选项 | 原理 |
|---------|---------|------|
| 栈缓冲区溢出 | `-fstack-protector-strong` | 函数入口放canary，返回前检查 |
| 格式化字符串 | `-Wformat-security` | 编译时检查printf格式串 |
| GOT覆写 | `-Wl,-z,relro,-z,now` | 启动时解析所有符号，标记GOT只读 |
| 代码注入 | `-fPIE -pie` | ASLR使地址随机化，攻击者无法预测 |
| 运行时溢出 | `-D_FORTIFY_SOURCE=2` | 用带长度检查的函数替换不安全函数 |

***

### 7. 极简总结

**C语言安全编码核心：用安全函数替代不安全函数（fgets/strncpy/snprintf）、永远验证输入、free后置NULL、开启编译器安全选项。记住：不安全函数表中的每一个都曾导致真实的安全事故。**

| 要点 | 一句话 |
|------|--------|
| 安全函数替代 | `gets→fgets`、`strcpy→strncpy`、`sprintf→snprintf` |
| 输入验证 | 永远不信任外部输入，白名单优于黑名单 |
| 指针管理 | free后置NULL，防止Use-After-Free和Double Free |
| 整数溢出 | 乘法/加法前检查是否会溢出 |
| 格式化字符串 | 永远用 `printf("%s", input)` 而非 `printf(input)` |
| 编译选项 | `-Wall -Werror -fstack-protector-strong -D_FORTIFY_SOURCE=2 -pie` |
| TOCTOU | 用文件描述符（fd）而非文件名操作，避免竞态 |
