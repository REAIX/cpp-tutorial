# 程序自我更新与删除卸载
> 📖 相关章节：[编码规范](../../04-工程实践/00-编码规范.md)、[设计模式](../../04-工程实践/03-设计模式.md)、[单元测试](../../04-工程实践/05-单元测试.md)、[代码审查](../../04-工程实践/07-代码审查.md)

> "蛇蜕皮"——程序要替换自己，就像蛇在蜕皮过程中活着，旧皮脱落新皮长出。核心难点：运行中的文件被锁定，无法直接替换/删除。

***

### 1. 核心定义

| 概念 | 定义 | 核心难点 |
|------|------|----------|
| 程序自我更新 | 运行中的程序替换自身为新版本 | 运行中的exe被系统锁定，无法覆盖 |
| 程序自删除 | 运行中的程序删除自身的可执行文件 | 自己还在运行，怎么删自己？ |
| 程序卸载 | 程序移除自身及所有相关文件 | 需要清理的文件分散在各处 |

**核心矛盾**：程序要替换/删除自己，但自己还在运行。

***

### 2. 生活类比

| 概念 | 类比 | 说明 |
|------|------|------|
| 自我更新 | 蛇蜕皮 | 蛇在蜕皮过程中活着，旧皮脱落新皮长出 |
| 自删除 | 自己拆自己的房子 | 人还在房子里住着，怎么拆？答案是：先搬出去再拆 |
| 卸载 | 搬家后还原毛坯房 | 不光搬走家具，还要把装修都拆掉 |

**具体场景**：

- **自我更新**：你穿着衣服想换新衣服，但不能光着身子——你需要先穿上新衣服再脱旧的，或者让别人帮你换。
- **自删除**：你站在桥上想拆桥，但桥是你站的地方——你需要先走到岸上，再拆桥。
- **核心难点**：程序运行时文件被锁定（Windows）或被占用，无法直接替换/删除。

***

### 3. 为什么自更新/自删除困难

| 平台 | 文件锁定行为 | 能否删除运行中的文件 | 说明 |
|------|-------------|-------------------|------|
| Windows | 运行中的exe被系统锁定 | ❌ 不能 | 尝试删除/覆盖会返回"文件被占用"错误 |
| Linux | 运行中的文件可以unlink | ✅ 能 | unlink删除目录项，但进程继续运行（文件描述符仍指向inode） |

**Windows文件锁定机制**：

```
程序启动 → 系统打开exe文件 → 文件被锁定（独占访问）
→ 其他进程无法写入/删除该文件
→ 程序退出 → 锁释放 → 文件可以被替换/删除
```

**Linux文件系统机制**：

```
程序启动 → 系统打开文件 → 增加inode引用计数
→ unlink删除目录项（文件名），但inode和数据仍存在
→ 进程通过文件描述符继续访问inode
→ 进程退出 → 引用计数归零 → 数据被回收
```

**核心矛盾**：

| | Windows | Linux |
|---|---|---|
| 替换运行中的文件 | ❌ 不行 | ✅ 可以（unlink后写入同名新文件） |
| 删除运行中的文件 | ❌ 不行 | ✅ 可以（unlink） |
| 替换后进程是否用新文件 | 不适用 | ❌ 旧进程仍用旧文件（inode不变） |

### 4. Windows下的自更新方案

#### 1. 方案1：启动辅助进程

**原理**：启动一个独立的更新程序（updater.exe），然后原程序退出，updater替换文件后重新启动。

**步骤**：

```
1. 下载新版本到临时目录
2. 启动updater.exe，传入参数（旧程序路径、新版本路径）
3. 原程序退出（释放文件锁）
4. updater.exe等待原程序退出
5. updater.exe替换文件
6. updater.exe启动新版本
7. updater.exe退出
```

**代码示例**：

```cpp
#include <windows.h>
#include <string>

void self_update(const std::string& new_version_path) {
    char self_path[MAX_PATH];
    GetModuleFileNameA(NULL, self_path, MAX_PATH);

    std::string updater_path = "updater.exe";
    std::string cmd_line = updater_path
        + " \"" + std::string(self_path) + "\""
        + " \"" + new_version_path + "\"";

    STARTUPINFOA si = { sizeof(si) };
    PROCESS_INFORMATION pi;

    if (CreateProcessA(
            updater_path.c_str(),
            const_cast<LPSTR>(cmd_line.c_str()),
            NULL, NULL, FALSE,
            CREATE_NEW_CONSOLE,
            NULL, NULL, &si, &pi)) {
        CloseHandle(pi.hProcess);
        CloseHandle(pi.hThread);
        exit(0);
    }
}
```

**updater.exe的实现**：

```cpp
#include <windows.h>
#include <string>

int main(int argc, char* argv[]) {
    if (argc < 3) return 1;

    std::string target_path = argv[1];
    std::string new_version_path = argv[2];

    HANDLE hProcess = NULL;
    DWORD pid = 0;
    {
        HANDLE snapshot = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
        PROCESSENTRY32 pe = { sizeof(pe) };
        if (Process32First(snapshot, &pe)) {
            do {
                std::string exe_name = pe.szExeFile;
                if (target_path.find(exe_name) != std::string::npos) {
                    pid = pe.th32ProcessID;
                    break;
                }
            } while (Process32Next(snapshot, &pe));
        }
        CloseHandle(snapshot);
    }

    if (pid > 0) {
        hProcess = OpenProcess(SYNCHRONIZE, FALSE, pid);
        if (hProcess) {
            WaitForSingleObject(hProcess, 30000);
            CloseHandle(hProcess);
        }
    }

    Sleep(500);

    if (!CopyFileA(new_version_path.c_str(), target_path.c_str(), FALSE)) {
        return 1;
    }

    ShellExecuteA(NULL, "open", target_path.c_str(), NULL, NULL, SW_SHOW);
    return 0;
}
```

#### 2. 方案2：批处理脚本

**原理**：生成一个.bat脚本，原程序退出后脚本执行替换。

**代码示例**：

```cpp
#include <windows.h>
#include <fstream>
#include <string>

void update_via_batch(const std::string& new_version_path) {
    char self_path[MAX_PATH];
    GetModuleFileNameA(NULL, self_path, MAX_PATH);

    std::string batch_path = "update.bat";
    std::ofstream bat(batch_path);

    bat << "@echo off\n";
    bat << "ping 127.0.0.1 -n 3 > nul\n";
    bat << "copy /Y \"" << new_version_path << "\" \"" << self_path << "\"\n";
    bat << "start \"\" \"" << self_path << "\"\n";
    bat << "del \"%~f0\"\n";
    bat.close();

    ShellExecuteA(NULL, "open", batch_path.c_str(), NULL, NULL, SW_HIDE);
    exit(0);
}
```

#### 3. 方案3：MoveFileEx延迟替换

**原理**：Windows API，注册一个"下次重启时替换"的操作。

**代码示例**：

```cpp
#include <windows.h>
#include <iostream>

void update_on_reboot(const char* new_version_path, const char* target_path) {
    if (!MoveFileExA(new_version_path, target_path,
                     MOVEFILE_DELAY_UNTIL_REBOOT | MOVEFILE_REPLACE_EXISTING)) {
        DWORD err = GetLastError();
        std::cerr << "MoveFileEx failed, error: " << err << "\n";
        return;
    }
    std::cout << "Update scheduled for next reboot.\n";
}
```

**注意**：此方案需要重启才能生效，适用于非紧急更新。

#### 4. 方案4：热更新（DLL替换）

**原理**：主exe不变，只更新加载的DLL。

**代码示例**：

```cpp
#include <windows.h>
#include <iostream>

void hot_update_dll(const char* dll_path, const char* new_dll_path) {
    HMODULE hModule = GetModuleHandleA(dll_path);
    if (hModule) {
        FreeLibrary(hModule);
    }

    if (!CopyFileA(new_dll_path, dll_path, FALSE)) {
        std::cerr << "Copy DLL failed\n";
        return;
    }

    hModule = LoadLibraryA(dll_path);
    if (!hModule) {
        std::cerr << "LoadLibrary failed\n";
        return;
    }

    std::cout << "DLL updated successfully\n";
}
```

**四种方案对比**：

| 方案 | 用户体验 | 复杂度 | 是否需要重启 | 适用场景 |
|------|---------|--------|------------|---------|
| 辅助进程 | 无感更新 | 中 | 否 | 推荐方案 |
| 批处理脚本 | 简单可靠 | 低 | 否 | 快速实现 |
| MoveFileEx | 需要重启 | 低 | 是 | 非紧急更新 |
| DLL热更新 | 无感更新 | 高 | 否 | 插件式架构 |

### 5. Linux下的自更新方案

#### 1. 方案1：exec替换

**原理**：fork后子进程替换文件，exec重新执行。

**代码示例**：

```cpp
#include <unistd.h>
#include <sys/wait.h>
#include <iostream>
#include <string>

void self_update_exec(const std::string& new_version_path) {
    char self_path[4096];
    ssize_t len = readlink("/proc/self/exe", self_path, sizeof(self_path) - 1);
    if (len == -1) return;
    self_path[len] = '\0';

    pid_t pid = fork();
    if (pid == 0) {
        sleep(1);
        execlp("cp", "cp", "-f", new_version_path.c_str(), self_path, NULL);
        _exit(1);
    } else if (pid > 0) {
        int status;
        waitpid(pid, &status, 0);
        if (WIFEXITED(status) && WEXITSTATUS(status) == 0) {
            execl(self_path, self_path, NULL);
        }
    }
}
```

#### 2. 方案2：unlink + 写入新文件

**原理**：Linux允许删除正在运行的文件（unlink），然后写入同名新文件。

**代码示例**：

```cpp
#include <unistd.h>
#include <fcntl.h>
#include <iostream>
#include <string>

void self_update_unlink(const std::string& new_version_path) {
    char self_path[4096];
    ssize_t len = readlink("/proc/self/exe", self_path, sizeof(self_path) - 1);
    if (len == -1) return;
    self_path[len] = '\0';

    if (unlink(self_path) != 0) {
        std::cerr << "unlink failed\n";
        return;
    }

    int src_fd = open(new_version_path.c_str(), O_RDONLY);
    if (src_fd < 0) return;

    int dst_fd = open(self_path, O_WRONLY | O_CREAT | O_TRUNC, 0755);
    if (dst_fd < 0) {
        close(src_fd);
        return;
    }

    char buf[4096];
    ssize_t n;
    while ((n = read(src_fd, buf, sizeof(buf))) > 0) {
        write(dst_fd, buf, n);
    }

    close(src_fd);
    close(dst_fd);

    execl(self_path, self_path, NULL);
}
```

#### 3. 方案3：符号链接替换

**原理**：程序通过符号链接运行，更新时替换符号链接指向。

**代码示例**：

```cpp
#include <unistd.h>
#include <iostream>
#include <string>

void self_update_symlink(const std::string& new_version_path) {
    char self_path[4096];
    ssize_t len = readlink("/proc/self/exe", self_path, sizeof(self_path) - 1);
    if (len == -1) return;
    self_path[len] = '\0';

    std::string symlink_path = "/usr/local/bin/myapp";
    std::string tmp_link = symlink_path + ".tmp";

    unlink(tmp_link.c_str());
    if (symlink(new_version_path.c_str(), tmp_link.c_str()) != 0) {
        std::cerr << "symlink failed\n";
        return;
    }

    if (rename(tmp_link.c_str(), symlink_path.c_str()) != 0) {
        std::cerr << "rename failed\n";
        unlink(tmp_link.c_str());
        return;
    }

    std::cout << "Symlink updated atomically\n";
}
```

**三种方案对比**：

| 方案 | 原子性 | 复杂度 | 说明 |
|------|--------|--------|------|
| exec替换 | 非原子 | 中 | fork+替换+exec，最常用 |
| unlink+写入 | 非原子 | 中 | 直接操作文件，有短暂不一致窗口 |
| 符号链接替换 | 原子 | 低 | rename是原子操作，推荐方案 |

### 6. 自删除方案

#### 1. Windows自删除

**方案1：批处理脚本删除**

```cpp
#include <windows.h>
#include <fstream>
#include <string>

void self_delete_batch() {
    char self_path[MAX_PATH];
    GetModuleFileNameA(NULL, self_path, MAX_PATH);

    std::string batch_path = "self_delete.bat";
    std::ofstream bat(batch_path);

    bat << "@echo off\n";
    bat << "ping 127.0.0.1 -n 3 > nul\n";
    bat << "del /f /q \"" << self_path << "\"\n";
    bat << "del \"%~f0\"\n";
    bat.close();

    ShellExecuteA(NULL, "open", batch_path.c_str(), NULL, NULL, SW_HIDE);
    exit(0);
}
```

**方案2：CreateProcess启动cmd /c del**

```cpp
#include <windows.h>
#include <string>

void self_delete_cmd() {
    char self_path[MAX_PATH];
    GetModuleFileNameA(NULL, self_path, MAX_PATH);

    std::string cmd = "cmd.exe /c ping 127.0.0.1 -n 3 > nul & del /f /q \"";
    cmd += self_path;
    cmd += "\"";

    STARTUPINFOA si = { sizeof(si) };
    si.dwFlags = STARTF_USESHOWWINDOW;
    si.wShowWindow = SW_HIDE;
    PROCESS_INFORMATION pi;

    if (CreateProcessA(NULL, const_cast<LPSTR>(cmd.c_str()),
                       NULL, NULL, FALSE,
                       CREATE_NO_WINDOW,
                       NULL, NULL, &si, &pi)) {
        CloseHandle(pi.hProcess);
        CloseHandle(pi.hThread);
    }

    exit(0);
}
```

#### 2. Linux自删除

**方案1：unlink(argv[0])**

```c
#include <unistd.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    printf("I am about to delete myself...\n");

    if (unlink(argv[0]) == 0) {
        printf("Self-deleted successfully.\n");
    } else {
        perror("unlink failed");
    }

    return 0;
}
```

**方案2：atexit注册删除回调**

```c
#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>

static char self_path[4096];

void self_delete_callback(void) {
    unlink(self_path);
}

int main(int argc, char* argv[]) {
    ssize_t len = readlink("/proc/self/exe", self_path, sizeof(self_path) - 1);
    if (len > 0) {
        self_path[len] = '\0';
        atexit(self_delete_callback);
    }

    printf("Program running. Will self-delete on exit.\n");
    return 0;
}
```

**Windows vs Linux自删除对比**：

| | Windows | Linux |
|---|---|---|
| 能否直接删除运行中的文件 | ❌ 不能 | ✅ 可以（unlink） |
| 常用方案 | 批处理脚本 / cmd进程 | unlink(argv[0]) / atexit |
| 复杂度 | 中（需要辅助进程） | 低（直接unlink） |

### 7. 完整卸载方案

**卸载清单**：

| 类别 | 示例 | 说明 |
|------|------|------|
| 可执行文件 | /usr/bin/myapp, C:\Program Files\MyApp | 主程序 |
| 配置文件 | ~/.myapp/config, C:\Users\xxx\AppData\Roaming\MyApp | 用户配置 |
| 数据文件 | ~/.myapp/data, C:\ProgramData\MyApp | 运行时数据 |
| 注册表(Windows) | HKLM\SOFTWARE\MyApp, HKCU\SOFTWARE\MyApp | 注册表项 |
| 服务 | systemd service, Windows Service | 系统服务 |
| 快捷方式 | /usr/share/applications/*.desktop, 桌面快捷方式 | 启动入口 |
| 临时文件 | /tmp/myapp*, %TEMP%\MyApp | 临时数据 |
| 日志文件 | /var/log/myapp, %LOCALAPPDATA%\MyApp\logs | 日志 |

**卸载程序实现思路**：

```cpp
#include <iostream>
#include <vector>
#include <string>

struct UninstallItem {
    std::string path;
    std::string type;
    bool required;
};

class Uninstaller {
    std::vector<UninstallItem> items;

public:
    void add_item(const std::string& path, const std::string& type, bool required = true) {
        items.push_back({path, type, required});
    }

    void show_plan() {
        std::cout << "=== Uninstall Plan ===\n";
        for (const auto& item : items) {
            std::cout << "  [" << item.type << "] " << item.path << "\n";
        }
        std::cout << "Total: " << items.size() << " items\n";
    }

    int execute() {
        int failed = 0;
        for (const auto& item : items) {
            bool ok = remove_item(item);
            if (!ok && item.required) {
                std::cerr << "Failed to remove: " << item.path << "\n";
                failed++;
            }
        }
        return failed;
    }

private:
    bool remove_item(const UninstallItem& item) {
        if (item.type == "file" || item.type == "dir") {
            return (std::remove(item.path.c_str()) == 0);
        }
        return false;
    }
};

int main() {
    Uninstaller uninstaller;

    uninstaller.add_item("/usr/bin/myapp", "file");
    uninstaller.add_item("/etc/myapp/config.conf", "file");
    uninstaller.add_item("/var/lib/myapp", "dir");
    uninstaller.add_item("/usr/share/applications/myapp.desktop", "file");
    uninstaller.add_item("/tmp/myapp_*", "file", false);

    uninstaller.show_plan();

    std::cout << "Proceed with uninstall? (y/n): ";
    char confirm;
    std::cin >> confirm;

    if (confirm == 'y' || confirm == 'Y') {
        int failed = uninstaller.execute();
        std::cout << "Uninstall " << (failed == 0 ? "completed" : "completed with errors") << "\n";
    }

    return 0;
}
```

### 8. 安全注意事项

| 序号 | 安全要点 | 说明 | 违反后果 |
|------|---------|------|---------|
| 1 | 下载更新必须验证签名/校验和 | 防止篡改的更新包被安装 | 安装恶意代码 |
| 2 | 更新过程需要回滚机制 | 更新失败时恢复旧版本 | 程序无法启动 |
| 3 | 权限问题 | 需要管理员/root权限才能替换程序文件 | 替换失败 |
| 4 | 防止中间人攻击 | 使用HTTPS下载更新包 | 更新包被劫持替换 |

**安全更新流程**：

```
1. 通过HTTPS下载更新包和签名
2. 验证签名（RSA/ECDSA）或校验和（SHA-256）
3. 备份当前版本（用于回滚）
4. 执行替换
5. 验证新版本可正常运行
6. 验证失败 → 回滚到旧版本
7. 验证成功 → 删除备份和旧版本
```

**签名验证示例**：

```cpp
#include <openssl/evp.h>
#include <fstream>
#include <vector>
#include <iostream>

bool verify_update_signature(const std::string& file_path,
                             const std::string& sig_path,
                             const std::string& pub_key_path) {
    FILE* f = fopen(pub_key_path.c_str(), "r");
    if (!f) return false;
    EVP_PKEY* pkey = PEM_read_PUBKEY(f, NULL, NULL, NULL);
    fclose(f);
    if (!pkey) return false;

    EVP_MD_CTX* ctx = EVP_MD_CTX_new();
    EVP_DigestVerifyInit(ctx, NULL, EVP_sha256(), NULL, pkey);

    std::ifstream ifs(file_path, std::ios::binary);
    std::vector<char> buf(4096);
    while (ifs.read(buf.data(), buf.size())) {
        EVP_DigestVerifyUpdate(ctx, buf.data(), ifs.gcount());
    }
    if (ifs.gcount() > 0) {
        EVP_DigestVerifyUpdate(ctx, buf.data(), ifs.gcount());
    }

    std::ifstream sigf(sig_path, std::ios::binary);
    std::vector<unsigned char> sig((std::istreambuf_iterator<char>(sigf)),
                                    std::istreambuf_iterator<char>());

    int result = EVP_DigestVerifyFinal(ctx, sig.data(), sig.size());

    EVP_MD_CTX_free(ctx);
    EVP_PKEY_free(pkey);

    return result == 1;
}
```

**回滚机制示例**：

```cpp
#include <filesystem>
#include <iostream>

namespace fs = std::filesystem;

bool update_with_rollback(const fs::path& target,
                          const fs::path& new_version) {
    fs::path backup = target;
    backup += ".bak";

    try {
        fs::copy_file(target, backup, fs::copy_options::overwrite_existing);
        fs::copy_file(new_version, target, fs::copy_options::overwrite_existing);

        if (!verify_new_version(target)) {
            std::cerr << "Verification failed, rolling back...\n";
            fs::copy_file(backup, target, fs::copy_options::overwrite_existing);
            fs::remove(backup);
            return false;
        }

        fs::remove(backup);
        return true;
    } catch (const fs::filesystem_error& e) {
        std::cerr << "Update error: " << e.what() << "\n";
        if (fs::exists(backup)) {
            fs::copy_file(backup, target, fs::copy_options::overwrite_existing);
            fs::remove(backup);
        }
        return false;
    }
}
```

### 9. 极简总结

**自更新核心难点：运行中的文件被锁定无法替换。Windows方案：启动updater进程后退出→替换→重启。Linux方案：unlink+写入+exec。自删除：Windows用批处理脚本，Linux直接unlink。安全原则：验证签名、支持回滚、最小权限。**

| 操作 | Windows | Linux |
|------|---------|-------|
| 自更新（推荐） | 启动updater.exe→退出→替换→重启 | 符号链接替换（原子）或unlink+写入+exec |
| 自删除 | 批处理脚本 / cmd进程 | unlink(argv[0]) |
| 卸载 | 清理文件+注册表+服务+快捷方式 | 清理文件+服务+desktop文件 |
| 安全 | HTTPS下载+签名验证+回滚机制+最小权限 | 同左 |
