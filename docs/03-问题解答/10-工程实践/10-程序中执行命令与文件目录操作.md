# 程序中执行命令与文件目录操作
> 📖 相关章节：[编码规范](../../04-工程实践/00-编码规范.md)、[设计模式](../../04-工程实践/03-设计模式.md)、[单元测试](../../04-工程实践/06-单元测试.md)、[代码审查](../../04-工程实践/08-代码审查.md)

> "打电话叫外卖"——执行命令就是程序调用外部服务，"整理文件柜"——文件目录操作就是创建文件夹、移动文件、查找文件。核心原则：不拼接命令、用绝对路径、检查返回值、C++17优先。

***

### 1. 核心定义

| 概念 | 定义 | 典型用途 |
|------|------|----------|
| 执行命令 | 在程序中调用系统命令或其他程序 | 调用外部工具、执行脚本、获取系统信息 |
| 文件操作 | 在程序中创建/读取/写入/删除文件 | 读写配置、处理数据、日志记录 |
| 目录操作 | 在程序中创建/删除/遍历目录 | 管理项目结构、批量处理文件 |

***

### 2. 生活类比

| 概念 | 类比 | 说明 |
|------|------|------|
| 执行命令 | 打电话叫外卖 | 你（程序）打电话（调用API）给餐厅（外部程序），餐厅做好饭送过来 |
| 文件操作 | 在文件柜中存取文件 | 打开抽屉（fopen）、放入文件（fwrite）、取出文件（fread）、关上抽屉（fclose） |
| 目录操作 | 在文件柜中整理文件 | 创建新文件夹（mkdir）、把文件分类放好（move）、清点所有文件（遍历） |

**具体场景**：

- **执行命令**：你的程序需要压缩文件，不需要自己实现压缩算法，直接调用`zip`命令即可——就像你不需要自己做菜，打电话叫外卖就行。
- **文件操作**：你的程序需要保存用户配置——就像把文件放进文件柜，下次用的时候再取出来。
- **目录操作**：你的程序需要扫描某个目录下所有图片——就像在文件柜中逐个抽屉翻找特定类型的文件。

### 3. 执行系统命令

#### 1. C语言方式：system()

**原理**：调用shell执行命令。

```c
#include <stdlib.h>
#include <stdio.h>

int main(void) {
    int ret = system("ls -la");
    if (ret == -1) {
        perror("system() failed");
        return 1;
    }
    printf("Command exited with status: %d\n", ret);
    return 0;
}
```

**危险**：`system()`有命令注入风险，不要拼接用户输入。

```c
#include <stdlib.h>
#include <stdio.h>

void dangerous(const char* filename) {
    char cmd[256];
    snprintf(cmd, sizeof(cmd), "cat %s", filename);
    system(cmd);
}

int main(void) {
    dangerous("test.txt; rm -rf /");
    return 0;
}
```

#### 2. C语言方式：popen()

**原理**：执行命令并获取输出。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    FILE* fp = popen("dir", "r");
    if (!fp) {
        perror("popen failed");
        return 1;
    }

    char buf[256];
    while (fgets(buf, sizeof(buf), fp) != NULL) {
        printf("%s", buf);
    }

    int status = pclose(fp);
    printf("Exit status: %d\n", status);
    return 0;
}
```

**同样有命令注入风险**，不要拼接用户输入到popen的命令中。

#### 3. POSIX方式：fork + exec

**原理**：创建子进程，替换为要执行的程序。这是最安全的方式，没有命令注入风险。

**exec系列函数**：

| 函数 | 参数形式 | 路径搜索 | 环境变量 |
|------|---------|---------|---------|
| `execl` | 列表（可变参数） | 完整路径 | 继承当前 |
| `execv` | 数组（argv[]） | 完整路径 | 继承当前 |
| `execle` | 列表 + 环境变量 | 完整路径 | 自定义 |
| `execve` | 数组 + 环境变量 | 完整路径 | 自定义 |
| `execlp` | 列表 | 搜索PATH | 继承当前 |
| `execvp` | 数组 | 搜索PATH | 继承当前 |

**代码示例**：

```c
#include <unistd.h>
#include <sys/wait.h>
#include <stdio.h>

int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        char* argv[] = {"ls", "-la", NULL};
        execvp("ls", argv);
        perror("execvp failed");
        _exit(1);
    } else if (pid > 0) {
        int status;
        waitpid(pid, &status, 0);
        if (WIFEXITED(status)) {
            printf("Child exited with status: %d\n", WEXITSTATUS(status));
        }
    } else {
        perror("fork failed");
        return 1;
    }
    return 0;
}
```

#### 4. Windows方式：CreateProcess

**原理**：Windows API创建新进程。

```cpp
#include <windows.h>
#include <iostream>

int main() {
    STARTUPINFOA si = { sizeof(si) };
    PROCESS_INFORMATION pi;

    char cmd[] = "cmd.exe /c dir";

    if (CreateProcessA(
            NULL, cmd,
            NULL, NULL, FALSE,
            0, NULL, NULL,
            &si, &pi)) {
        WaitForSingleObject(pi.hProcess, INFINITE);

        DWORD exit_code;
        GetExitCodeProcess(pi.hProcess, &exit_code);
        std::cout << "Exit code: " << exit_code << "\n";

        CloseHandle(pi.hProcess);
        CloseHandle(pi.hThread);
    } else {
        std::cerr << "CreateProcess failed, error: " << GetLastError() << "\n";
    }
    return 0;
}
```

#### 5. C++方式：std::system

与C的`system()`相同，仍有命令注入风险。

```cpp
#include <cstdlib>

int main() {
    std::system("ls -la");
    return 0;
}
```

#### 6. 获取输出：重定向到管道

**POSIX方式**：pipe + fork + dup2 + exec

```c
#include <unistd.h>
#include <sys/wait.h>
#include <stdio.h>
#include <string.h>

int main(void) {
    int pipefd[2];
    if (pipe(pipefd) == -1) {
        perror("pipe");
        return 1;
    }

    pid_t pid = fork();
    if (pid == 0) {
        close(pipefd[0]);
        dup2(pipefd[1], STDOUT_FILENO);
        close(pipefd[1]);

        char* argv[] = {"ls", "-la", NULL};
        execvp("ls", argv);
        _exit(1);
    } else if (pid > 0) {
        close(pipefd[1]);

        char buf[256];
        ssize_t n;
        while ((n = read(pipefd[0], buf, sizeof(buf) - 1)) > 0) {
            buf[n] = '\0';
            printf("%s", buf);
        }
        close(pipefd[0]);

        int status;
        waitpid(pid, &status, 0);
    }
    return 0;
}
```

**各方式对比**：

| 方式 | 安全性 | 能获取输出 | 平台 | 推荐度 |
|------|--------|-----------|------|--------|
| `system()` | ❌ 有注入风险 | ❌ 不能 | 全平台 | 不推荐 |
| `popen()` | ❌ 有注入风险 | ✅ 能 | POSIX | 不推荐 |
| `fork+exec` | ✅ 安全 | 需配合pipe | POSIX | ★★★★★ |
| `CreateProcess` | ✅ 安全 | 需配合管道 | Windows | ★★★★★ |
| `std::system` | ❌ 有注入风险 | ❌ 不能 | 全平台 | 不推荐 |

### 4. 执行命令的安全注意事项

| 风险 | 说明 | 解决方案 |
|------|------|---------|
| 命令注入 | 用户输入包含 `;rm -rf /` | 用exec系列替代system |
| 路径劫持 | 环境变量被篡改 | 用绝对路径 |
| 权限提升 | 以高权限执行用户命令 | 最小权限原则 |
| 输出解析 | 命令输出格式变化 | 用API替代命令 |

**安全 vs 不安全示例**：

```c
#include <stdlib.h>
#include <unistd.h>
#include <stdio.h>

void unsafe_command(const char* filename) {
    char cmd[256];
    snprintf(cmd, sizeof(cmd), "cat %s", filename);
    system(cmd);
}

void safe_command(const char* filename) {
    pid_t pid = fork();
    if (pid == 0) {
        execl("/bin/cat", "cat", filename, NULL);
        _exit(1);
    } else if (pid > 0) {
        int status;
        waitpid(pid, &status, 0);
    }
}
```

**为什么exec安全**：exec系列函数直接将参数传给目标程序，不经过shell解析，所以`filename`中的`; rm -rf /`只会被当作cat的参数，不会被当作另一个命令执行。

### 5. 文件操作

#### 1. C语言文件操作

| 函数 | 作用 | 说明 |
|------|------|------|
| `fopen` | 打开文件 | 返回FILE*指针 |
| `fclose` | 关闭文件 | 刷新缓冲区并释放资源 |
| `fread` | 读取文件 | 二进制读取 |
| `fwrite` | 写入文件 | 二进制写入 |
| `fseek` | 设置文件位置 | 定位到指定位置 |
| `ftell` | 获取当前位置 | 返回当前偏移量 |
| `rewind` | 回到文件开头 | 等价于fseek(fp, 0, SEEK_SET) |
| `remove` | 删除文件 | 删除指定文件 |
| `rename` | 重命名文件 | 重命名或移动文件 |
| `tmpfile` | 创建临时文件 | 自动删除的临时文件 |
| `tmpnam` | 生成临时文件名 | 生成不重复的文件名 |

**代码示例**：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    FILE* fp = fopen("test.txt", "w");
    if (!fp) {
        perror("fopen write");
        return 1;
    }
    fprintf(fp, "Hello, World!\n");
    fwrite("Binary data", 1, 11, fp);
    fclose(fp);

    fp = fopen("test.txt", "r");
    if (!fp) {
        perror("fopen read");
        return 1;
    }

    char line[256];
    while (fgets(line, sizeof(line), fp)) {
        printf("%s", line);
    }

    fseek(fp, 0, SEEK_END);
    long size = ftell(fp);
    printf("File size: %ld bytes\n", size);

    fclose(fp);

    FILE* tmp = tmpfile();
    if (tmp) {
        fprintf(tmp, "Temporary data\n");
        rewind(tmp);
        char buf[256];
        if (fgets(buf, sizeof(buf), tmp)) {
            printf("Temp: %s", buf);
        }
        fclose(tmp);
    }

    return 0;
}
```

#### 2. POSIX文件操作

| 函数 | 作用 | 说明 |
|------|------|------|
| `open` | 打开文件 | 返回文件描述符fd |
| `close` | 关闭文件 | 关闭fd |
| `read` | 读取文件 | 从fd读取 |
| `write` | 写入文件 | 向fd写入 |
| `lseek` | 设置文件位置 | 定位fd |
| `stat/fstat` | 获取文件信息 | 大小、权限、时间等 |
| `access` | 检查文件权限 | 是否可读/写/执行 |
| `chmod` | 修改权限 | 改变文件权限 |
| `chown` | 修改所有者 | 改变文件所有者 |

**代码示例**：

```c
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <stdio.h>

int main(void) {
    int fd = open("test.txt", O_RDWR | O_CREAT, 0644);
    if (fd < 0) {
        perror("open");
        return 1;
    }

    write(fd, "Hello, POSIX!\n", 14);

    lseek(fd, 0, SEEK_SET);

    char buf[64];
    ssize_t n = read(fd, buf, sizeof(buf) - 1);
    if (n > 0) {
        buf[n] = '\0';
        printf("Read: %s", buf);
    }

    struct stat st;
    if (fstat(fd, &st) == 0) {
        printf("Size: %lld bytes\n", (long long)st.st_size);
        printf("Permissions: %o\n", st.st_mode & 0777);
    }

    close(fd);

    if (access("test.txt", R_OK | W_OK) == 0) {
        printf("File is readable and writable\n");
    }

    chmod("test.txt", 0600);

    return 0;
}
```

#### 3. C++文件操作

**std::fstream/ifstream/ofstream**：

```cpp
#include <fstream>
#include <iostream>
#include <string>

int main() {
    {
        std::ofstream ofs("test.txt");
        if (!ofs) {
            std::cerr << "Failed to open for writing\n";
            return 1;
        }
        ofs << "Hello, C++!\n";
        ofs.write("Binary data", 11);
    }

    {
        std::ifstream ifs("test.txt");
        if (!ifs) {
            std::cerr << "Failed to open for reading\n";
            return 1;
        }

        std::string line;
        while (std::getline(ifs, line)) {
            std::cout << line << "\n";
        }

        ifs.seekg(0, std::ios::end);
        auto size = ifs.tellg();
        std::cout << "File size: " << size << " bytes\n";
    }

    return 0;
}
```

**C++17 std::filesystem**：

```cpp
#include <filesystem>
#include <iostream>

namespace fs = std::filesystem;

int main() {
    fs::path p = "test.txt";

    if (fs::exists(p)) {
        std::cout << "File size: " << fs::file_size(p) << " bytes\n";
        std::cout << "Last modified: "
                  << fs::last_write_time(p).time_since_epoch().count() << "\n";
    }

    fs::path copy_p = "test_copy.txt";
    fs::copy_file(p, copy_p, fs::copy_options::overwrite_existing);

    fs::rename(copy_p, "test_renamed.txt");

    fs::remove("test_renamed.txt");

    return 0;
}
```

### 6. 目录操作

#### 1. C语言/POSIX目录操作

| 函数 | 作用 | 说明 |
|------|------|------|
| `mkdir` | 创建目录 | 创建一个目录 |
| `rmdir` | 删除目录 | 只能删除空目录 |
| `opendir` | 打开目录 | 返回DIR*指针 |
| `readdir` | 读取目录项 | 逐个读取目录内容 |
| `closedir` | 关闭目录 | 释放资源 |
| `chdir` | 切换当前目录 | 改变工作目录 |
| `getcwd` | 获取当前目录 | 返回当前工作目录 |

**代码示例：遍历目录**：

```c
#include <dirent.h>
#include <stdio.h>
#include <sys/stat.h>
#include <unistd.h>

void list_directory(const char* path) {
    DIR* dir = opendir(path);
    if (!dir) {
        perror("opendir");
        return;
    }

    struct dirent* entry;
    while ((entry = readdir(dir)) != NULL) {
        if (entry->d_name[0] == '.') continue;

        char full_path[1024];
        snprintf(full_path, sizeof(full_path), "%s/%s", path, entry->d_name);

        struct stat st;
        if (stat(full_path, &st) == 0) {
            if (S_ISDIR(st.st_mode)) {
                printf("[DIR]  %s\n", entry->d_name);
            } else if (S_ISREG(st.st_mode)) {
                printf("[FILE] %s (%lld bytes)\n", entry->d_name, (long long)st.st_size);
            }
        }
    }

    closedir(dir);
}

int main(void) {
    char cwd[1024];
    if (getcwd(cwd, sizeof(cwd))) {
        printf("Current directory: %s\n", cwd);
    }

    list_directory(".");

    mkdir("test_dir", 0755);
    rmdir("test_dir");

    return 0;
}
```

#### 2. C++17 std::filesystem

| 函数/类 | 作用 | 说明 |
|---------|------|------|
| `create_directory` | 创建目录 | 创建单个目录 |
| `create_directories` | 创建多级目录 | 递归创建所有不存在的目录 |
| `remove` | 删除文件/空目录 | 删除单个文件或空目录 |
| `remove_all` | 递归删除 | 删除目录及其所有内容 |
| `exists` | 检查是否存在 | 文件或目录 |
| `is_directory` | 是否为目录 | 判断类型 |
| `is_regular_file` | 是否为普通文件 | 判断类型 |
| `directory_iterator` | 遍历目录 | 非递归遍历 |
| `recursive_directory_iterator` | 递归遍历 | 递归遍历所有子目录 |
| `copy` | 复制 | 复制文件或目录 |
| `move` | 移动 | 移动文件或目录 |
| `rename` | 重命名 | 重命名文件或目录 |
| `space` | 磁盘空间 | 获取可用/总/已用空间 |

**代码示例：完整的目录操作**：

```cpp
#include <filesystem>
#include <iostream>
#include <vector>
#include <algorithm>

namespace fs = std::filesystem;

void demo_directory_operations() {
    fs::create_directories("a/b/c");

    std::ofstream("a/file1.txt");
    std::ofstream("a/b/file2.txt");
    std::ofstream("a/b/c/file3.txt");

    std::cout << "=== Non-recursive traversal ===\n";
    for (const auto& entry : fs::directory_iterator("a")) {
        std::cout << entry.path().string();
        if (fs::is_directory(entry)) std::cout << "/";
        std::cout << "\n";
    }

    std::cout << "\n=== Recursive traversal ===\n";
    std::vector<fs::path> files;
    for (const auto& entry : fs::recursive_directory_iterator("a")) {
        std::cout << entry.path().string() << "\n";
        if (fs::is_regular_file(entry)) {
            files.push_back(entry.path());
        }
    }

    std::cout << "\n=== Disk space ===\n";
    auto space_info = fs::space(".");
    std::cout << "Available: " << space_info.available / (1024 * 1024) << " MB\n";
    std::cout << "Capacity:  " << space_info.capacity / (1024 * 1024) << " MB\n";
    std::cout << "Free:      " << space_info.free / (1024 * 1024) << " MB\n";

    fs::copy("a/file1.txt", "a/file1_copy.txt", fs::copy_options::overwrite_existing);

    fs::remove("a/file1_copy.txt");

    fs::remove_all("a");
}
```

### 7. 跨平台文件目录操作对比

| 操作 | POSIX | Windows API | C++17 filesystem |
|------|-------|-------------|-----------------|
| 创建目录 | `mkdir()` | `CreateDirectory()` | `create_directory()` |
| 删除目录 | `rmdir()` | `RemoveDirectory()` | `remove()` |
| 遍历目录 | `opendir/readdir` | `FindFirstFile` | `directory_iterator` |
| 获取当前目录 | `getcwd()` | `GetCurrentDirectory()` | `current_path()` |
| 检查文件存在 | `access()` | `GetFileAttributes()` | `exists()` |
| 复制文件 | 无标准 | `CopyFile()` | `copy()` |
| 移动/重命名 | `rename()` | `MoveFile()` | `rename()` |
| 删除文件 | `unlink()` | `DeleteFile()` | `remove()` |
| 获取文件大小 | `stat()` | `GetFileSize()` | `file_size()` |
| 修改权限 | `chmod()` | 无直接等价 | `permissions()` |

**跨平台建议**：

| 场景 | 推荐 |
|------|------|
| C++17及以上项目 | `std::filesystem`（跨平台首选） |
| C语言项目 | `#ifdef` 条件编译封装 |
| 需要精细控制 | 直接使用平台API |

**条件编译封装示例**：

```cpp
#include <string>

bool create_dir(const std::string& path) {
#ifdef _WIN32
    return CreateDirectoryA(path.c_str(), NULL) != 0
        || GetLastError() == ERROR_ALREADY_EXISTS;
#else
    return mkdir(path.c_str(), 0755) == 0
        || errno == EEXIST;
#endif
}
```

### 8. 文件监控

| 平台 | API | 说明 |
|------|-----|------|
| Linux | inotify | 监控文件创建、修改、删除、移动等事件 |
| Windows | `ReadDirectoryChangesW` | 监控目录变化 |
| macOS | kqueue / FSEvents | BSD事件通知机制 |
| 跨平台 | 第三方库（efsw） | 封装各平台API |

**Linux inotify示例**：

```c
#include <sys/inotify.h>
#include <unistd.h>
#include <stdio.h>
#include <string.h>

#define EVENT_SIZE (sizeof(struct inotify_event))
#define BUF_LEN (1024 * (EVENT_SIZE + 16))

int main(void) {
    int fd = inotify_init();
    if (fd < 0) {
        perror("inotify_init");
        return 1;
    }

    int wd = inotify_add_watch(fd, ".", IN_CREATE | IN_MODIFY | IN_DELETE);
    if (wd < 0) {
        perror("inotify_add_watch");
        close(fd);
        return 1;
    }

    char buf[BUF_LEN];
    while (1) {
        ssize_t len = read(fd, buf, BUF_LEN);
        if (len < 0) {
            perror("read");
            break;
        }

        ssize_t i = 0;
        while (i < len) {
            struct inotify_event* event = (struct inotify_event*)&buf[i];
            if (event->len > 0) {
                if (event->mask & IN_CREATE) {
                    printf("Created: %s\n", event->name);
                }
                if (event->mask & IN_MODIFY) {
                    printf("Modified: %s\n", event->name);
                }
                if (event->mask & IN_DELETE) {
                    printf("Deleted: %s\n", event->name);
                }
            }
            i += EVENT_SIZE + event->len;
        }
    }

    inotify_rm_watch(fd, wd);
    close(fd);
    return 0;
}
```

**Windows ReadDirectoryChangesW示例**：

```cpp
#include <windows.h>
#include <iostream>

void monitor_directory(const char* path) {
    HANDLE hDir = CreateFileA(
        path,
        FILE_LIST_DIRECTORY,
        FILE_SHARE_READ | FILE_SHARE_WRITE | FILE_SHARE_DELETE,
        NULL,
        OPEN_EXISTING,
        FILE_FLAG_BACKUP_SEMANTICS,
        NULL);

    if (hDir == INVALID_HANDLE_VALUE) {
        std::cerr << "Failed to open directory\n";
        return;
    }

    BYTE buf[4096];
    DWORD bytes_returned;

    while (ReadDirectoryChangesW(
            hDir,
            buf, sizeof(buf),
            TRUE,
            FILE_NOTIFY_CHANGE_FILE_NAME |
            FILE_NOTIFY_CHANGE_DIR_NAME |
            FILE_NOTIFY_CHANGE_SIZE |
            FILE_NOTIFY_CHANGE_LAST_WRITE,
            &bytes_returned,
            NULL, NULL)) {

        BYTE* ptr = buf;
        while (ptr < buf + bytes_returned) {
            FILE_NOTIFY_INFORMATION* info = (FILE_NOTIFY_INFORMATION*)ptr;

            wchar_t filename[MAX_PATH];
            memcpy(filename, info->FileName, info->FileNameLength);
            filename[info->FileNameLength / sizeof(wchar_t)] = L'\0';

            switch (info->Action) {
                case FILE_ACTION_ADDED:
                    std::wcout << L"Added: " << filename << L"\n";
                    break;
                case FILE_ACTION_MODIFIED:
                    std::wcout << L"Modified: " << filename << L"\n";
                    break;
                case FILE_ACTION_REMOVED:
                    std::wcout << L"Removed: " << filename << L"\n";
                    break;
                case FILE_ACTION_RENAMED_NEW_NAME:
                    std::wcout << L"Renamed to: " << filename << L"\n";
                    break;
            }

            if (info->NextEntryOffset == 0) break;
            ptr += info->NextEntryOffset;
        }
    }

    CloseHandle(hDir);
}
```

### 9. 极简总结

**执行命令：优先用fork+exec（POSIX）或CreateProcess（Windows），避免system()命令注入。文件操作：C用fopen/POSIX API，C++17用std::filesystem（跨平台首选）。核心原则：不拼接命令、用绝对路径、检查返回值、C++17优先。**

| 类别 | 推荐方式 | 一句话 |
|------|---------|--------|
| 执行命令(POSIX) | `fork + execvp` | 安全，无命令注入风险 |
| 执行命令(Windows) | `CreateProcess` | 安全，Windows原生API |
| 获取命令输出 | `pipe + fork + dup2 + exec` | 安全地捕获输出 |
| 文件操作(C) | `fopen/fread/fwrite` | 标准C库 |
| 文件操作(POSIX) | `open/read/write` | 底层控制 |
| 文件操作(C++) | `std::filesystem` | 跨平台首选 |
| 目录操作(C++) | `std::filesystem` | `directory_iterator`遍历 |
| 文件监控 | `inotify`/`ReadDirectoryChangesW` | 平台原生API |
