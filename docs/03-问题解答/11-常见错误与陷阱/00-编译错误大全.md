## 1. 缺少分号 `expected ';'`

**错误信息：** `error: expected ';' after expression`

**含义：** 编译器在应该出现分号的地方没有找到分号。

**原因：** C/C++ 每条语句必须以分号结尾，忘记写分号是最常见的错误。

```cpp
// ❌ 错误：缺少分号
int x = 10
int y = 20

// ✅ 正确：每条语句末尾加分号
int x = 10;
int y = 20;
```

**注意：** 编译器报错的行号可能是下一行，因为编译器在下一行开头才发现缺少分号。

## 2. 未声明的标识符 `undeclared identifier`

**错误信息：** `error: use of undeclared identifier 'xxx'`

**含义：** 使用了一个编译器不认识的变量名或函数名。

**原因：** 变量未定义、拼写错误、缺少头文件、作用域问题。

```cpp
// ❌ 错误：变量未声明
int main() {
    cout << x << endl;  // x 未声明
    return 0;
}

// ✅ 正确：先声明再使用
int main() {
    int x = 10;
    std::cout << x << std::endl;
    return 0;
}
```

```cpp
// ❌ 错误：缺少头文件
int main() {
    printf("hello");  // 未包含 <cstdio>
}

// ✅ 正确：包含所需头文件
#include <cstdio>
int main() {
    printf("hello");
}
```

## 3. 没有匹配的函数 `no matching function`

**错误信息：** `error: no matching function for call to 'xxx'`

**含义：** 调用函数时，参数类型或数量与任何已知函数声明不匹配。

**原因：** 参数类型错误、参数数量不对、函数未声明。

```cpp
// ❌ 错误：参数类型不匹配
#include <cmath>
int main() {
    double result = sqrt("hello");  // sqrt 需要数值参数
}

// ✅ 正确：传入正确类型的参数
#include <cmath>
int main() {
    double result = sqrt(2.0);
}
```

## 4. 重定义 `redefinition`

**错误信息：** `error: redefinition of 'xxx'`

**含义：** 同一个变量、函数或类被定义了两次。

**原因：** 头文件重复包含、在同一作用域中重复定义。

```cpp
// ❌ 错误：重复定义
int x = 10;
int x = 20;  // 重定义

// ✅ 正确：使用赋值或只定义一次
int x = 10;
x = 20;  // 赋值，不是重定义
```

```cpp
// ❌ 错误：头文件重复包含导致重定义
// a.h
int globalVar = 10;
// main.cpp
#include "a.h"
#include "a.h"  // 重定义！

// ✅ 正确：使用头文件保护
// a.h
#ifndef A_H
#define A_H
int globalVar = 10;
#endif
```

## 5. 类型转换错误 `cannot convert`

**错误信息：** `error: cannot convert 'xxx' to 'yyy'`

**含义：** 编译器无法将一种类型自动转换为另一种类型。

**原因：** 隐式转换不被允许，需要显式转换。

```cpp
// ❌ 错误：不能隐式转换
int* ptr = 100;  // int 不能隐式转为 int*

// ✅ 正确：显式转换
int* ptr = (int*)100;  // C 风格
int* ptr2 = reinterpret_cast<int*>(100);  // C++ 风格
```

## 6. 未声明的标识符（命名空间）`was not declared`

**错误信息：** `error: 'cout' was not declared in this scope`

**含义：** 标识符在当前作用域中不可见。

**原因：** 忘记 `using namespace std;` 或忘记加 `std::` 前缀。

```cpp
// ❌ 错误：缺少命名空间限定
#include <iostream>
int main() {
    cout << "hello" << endl;  // 未声明
}

// ✅ 正确：方式一，加 std:: 前缀
#include <iostream>
int main() {
    std::cout << "hello" << std::endl;
}

// ✅ 正确：方式二，使用 using 声明
#include <iostream>
using namespace std;
int main() {
    cout << "hello" << endl;
}
```

## 7. 缺少右括号 `expected ')'`

**错误信息：** `error: expected ')'`

**含义：** 括号不匹配，缺少右括号。

**原因：** 函数调用或条件表达式中的括号没有成对出现。

```cpp
// ❌ 错误：括号不匹配
if (x > 0 {
    // ...
}

// ✅ 正确：括号成对
if (x > 0) {
    // ...
}
```

## 8. 不命名类型 `does not name a type`

**错误信息：** `error: 'string' does not name a type`

**含义：** 编译器不认识某个类型名。

**原因：** 缺少头文件或命名空间限定。

```cpp
// ❌ 错误：缺少头文件
string name = "hello";  // string 未定义

// ✅ 正确：包含头文件
#include <string>
std::string name = "hello";
```

## 9. 无可行转换 `no viable conversion`

**错误信息：** `error: no viable conversion from 'xxx' to 'yyy'`

**含义：** 两种类型之间不存在可行的转换路径。

**原因：** 类型不兼容且没有定义转换运算符。

```cpp
// ❌ 错误：string 字面量不能转为 string*
std::string* p = "hello";  // 不可行

// ✅ 正确
std::string s = "hello";
std::string* p = &s;
```

## 10. 缺少右大括号 `expected '}'`

**错误信息：** `error: expected '}' at end of input`

**含义：** 文件结束时大括号不匹配。

**原因：** 某个代码块缺少闭合的 `}`。

```cpp
// ❌ 错误：缺少右大括号
int main() {
    if (true) {
        // 忘记关闭

// ✅ 正确：大括号成对
int main() {
    if (true) {
    }
    return 0;
}
```

## 11. 不完整类型 `incomplete type`

**错误信息：** `error: variable has incomplete type 'xxx'`

**含义：** 编译器看到了类型的前向声明但没有完整定义。

**原因：** 只声明了类/结构体但没有定义就使用。

```cpp
// ❌ 错误：不完整类型
class MyClass;
MyClass obj;  // 无法创建对象，类型不完整

// ✅ 正确：提供完整定义
class MyClass {
    int data;
};
MyClass obj;
```

## 12. 非void函数没有返回值

**错误信息：** `warning: non-void function does not return a value`

**含义：** 声明返回非 `void` 类型的函数没有 `return` 语句。

**原因：** 忘记写 `return` 或某个分支缺少 `return`。

```cpp
// ❌ 错误：缺少 return
int add(int a, int b) {
    int sum = a + b;
    // 忘记 return sum;
}

// ✅ 正确：确保所有路径都有返回值
int add(int a, int b) {
    return a + b;
}
```

## 13. 结构体/类没有成员 `no member named`

**错误信息：** `error: no member named 'xxx' in 'yyy'`

**含义：** 访问了结构体或类中不存在的成员。

**原因：** 拼写错误、成员是私有的、使用了错误的类型。

```cpp
// ❌ 错误：成员名拼写错误
struct Person {
    std::string name;
    int age;
};
Person p;
p.nmae = "Tom";  // 拼写错误

// ✅ 正确
p.name = "Tom";
```

## 14. 冲突声明 `conflicting declaration`

**错误信息：** `error: conflicting declaration 'xxx'`

**含义：** 同一名称被声明为不同类型。

**原因：** 在不同位置对同一名称做了不同类型的声明。

```cpp
// ❌ 错误：冲突声明
typedef int MyType;
typedef double MyType;  // 冲突！

// ✅ 正确：使用不同名称
typedef int MyIntType;
typedef double MyDoubleType;
```

## 15. 缺少表达式 `expected expression`

**错误信息：** `error: expected expression`

**含义：** 编译器期望一个表达式但什么都没找到。

**原因：** 语法错误，如空的条件、多余的逗号。

```cpp
// ❌ 错误：条件为空
if () {  // 缺少表达式
    // ...
}

// ✅ 正确
if (x > 0) {
    // ...
}
```

## 16. 下标操作对象不是数组

**错误信息：** `error: subscripted value is not an array, pointer, or vector`

**含义：** 对非数组/指针类型的变量使用了 `[]` 运算符。

```cpp
// ❌ 错误：对非数组使用下标
int x = 10;
x[0] = 5;  // x 不是数组

// ✅ 正确
int arr[10];
arr[0] = 5;
```

## 17. 无效操作数 `invalid operands`

**错误信息：** `error: invalid operands to binary expression ('xxx' and 'yyy')`

**含义：** 两个操作数类型不支持该运算符。

```cpp
// ❌ 错误：不能对 string 和 int 做 %
#include <string>
std::string s = "hello";
s % 2;  // 无效操作

// ✅ 正确：对整数取模
int n = 10;
int r = n % 2;
```

## 18. 无法初始化变量 `cannot initialize`

**错误信息：** `error: cannot initialize a variable of type 'xxx' with an lvalue of type 'yyy'`

**含义：** 初始化值的类型与变量类型不匹配。

```cpp
// ❌ 错误：类型不匹配
int& ref = 10;  // 非常量引用不能绑定到右值

// ✅ 正确
const int& ref = 10;  // 常量引用可以绑定到右值
```

## 19. 缺少限定符 `expected unqualified-id`

**错误信息：** `error: expected unqualified-id`

**含义：** 编译器期望一个标识符但遇到了其他符号。

**原因：** 语法错误，如多余的符号、关键字误用。

```cpp
// ❌ 错误：多余的分号
class MyClass;;  // 多余分号通常只是警告

// ❌ 错误：在不应出现的位置使用符号
int 123abc = 10;  // 标识符不能以数字开头

// ✅ 正确
int abc123 = 10;
```

## 20. 模板实例化错误

**错误信息：** `error: no matching function for call to 'xxx<...>'`

**含义：** 模板参数推导失败或没有匹配的模板特化。

```cpp
// ❌ 错误：模板参数不匹配
template<typename T>
T add(T a, T b) { return a + b; }
add(1, 1.5);  // T 无法同时推导为 int 和 double

// ✅ 正确：显式指定模板参数
add<int>(1, 1);      // 或
add<double>(1.0, 1.5); // 或
add<double>(1, 1.5);
```

## 调试编译错误的通用技巧

| 技巧 | 说明 |
|------|------|
| **看第一个错误** | 一个错误可能引发连锁反应，修复第一个往往能解决多个 |
| **看行号** | 错误行号可能偏移，检查报错行和前一行 |
| **逐个编译** | 注释掉部分代码，逐步缩小错误范围 |
| **开启全部警告** | 使用 `-Wall -Wextra` 编译选项 |
| **检查拼写** | C/C++ 区分大小写，`Main` ≠ `main` |
