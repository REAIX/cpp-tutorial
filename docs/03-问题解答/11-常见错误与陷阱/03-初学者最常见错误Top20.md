## 1. `=` 与 `==` 混淆

这是 C/C++ 最臭名昭著的陷阱之一。`=` 是赋值，`==` 是比较。

```cpp
// ❌ 错误：if 中用了赋值
int x = 5;
if (x = 10) {  // 把 10 赋给 x，条件永远为真！
    std::cout << "x is 10" << std::endl;  // 总是执行
}

// ✅ 正确：使用 == 比较
if (x == 10) {
    std::cout << "x is 10" << std::endl;
}
```

**防御技巧：** 将常量放在左边，如果误写为 `=` 编译器会报错：

```cpp
// ✅ 防御性写法
if (10 == x) {  // 如果写成 10 = x，编译器会报错
    // ...
}
```

## 2. `scanf` 忘记 `&`

```cpp
// ❌ 错误：scanf 忘记取地址符
int num;
scanf("%d", num);   // 应该传地址，传了值 → 段错误！

// ✅ 正确：加上 &
scanf("%d", &num);

// 注意：字符串不需要 &，因为数组名本身就是地址
char name[100];
scanf("%s", name);  // 正确，name 是地址
```

## 3. 数组越界（差一错误 Off-by-One）

C/C++ 数组下标从 0 开始，长度为 N 的数组有效下标是 0 到 N-1。

```cpp
// ❌ 错误：循环条件写错
int arr[10];
for (int i = 0; i <= 10; i++) {  // i=10 时越界！
    arr[i] = i;
}

// ✅ 正确：i < 10
for (int i = 0; i < 10; i++) {
    arr[i] = i;
}
```

**常见差一错误模式：**

| 场景 | ❌ 错误 | ✅ 正确 |
|------|--------|--------|
| 遍历 N 个元素 | `i <= N` | `i < N` |
| 二分查找边界 | `high = N` | `high = N - 1` |
| 字符串长度 | `i <= strlen(s)` | `i < strlen(s)` |

## 4. 未初始化变量

```cpp
// ❌ 错误：使用未初始化的变量
int sum;
for (int i = 0; i < 10; i++) {
    sum += i;  // sum 初始值不确定！
}

// ✅ 正确：初始化变量
int sum = 0;
for (int i = 0; i < 10; i++) {
    sum += i;
}
```

## 5. `switch` 缺少 `break`

```cpp
// ❌ 错误：忘记 break，导致 fall-through
int day = 3;
switch (day) {
    case 1: std::cout << "Monday" << std::endl;
    case 2: std::cout << "Tuesday" << std::endl;
    case 3: std::cout << "Wednesday" << std::endl;  // 从这里开始
    case 4: std::cout << "Thursday" << std::endl;   // 继续执行
    case 5: std::cout << "Friday" << std::endl;     // 继续执行
    // 输出 Wednesday Thursday Friday
}

// ✅ 正确：每个 case 后加 break
switch (day) {
    case 1: std::cout << "Monday" << std::endl; break;
    case 2: std::cout << "Tuesday" << std::endl; break;
    case 3: std::cout << "Wednesday" << std::endl; break;
    case 4: std::cout << "Thursday" << std::endl; break;
    case 5: std::cout << "Friday" << std::endl; break;
}
```

## 6. 整数除法

```cpp
// ❌ 错误：两个整数相除结果还是整数
int a = 5, b = 2;
double result = a / b;  // 结果是 2.0，不是 2.5！

// ✅ 正确：至少一个操作数是浮点数
double result = (double)a / b;  // 2.5
double result2 = 5.0 / 2;      // 2.5
double result3 = a * 1.0 / b;  // 2.5
```

## 7. C 风格字符串比较用 `==`

```cpp
// ❌ 错误：用 == 比较字符串（比较的是指针地址）
char s1[] = "hello";
char s2[] = "hello";
if (s1 == s2) {  // 比较地址，永远为 false！
    std::cout << "equal" << std::endl;
}

// ✅ 正确：使用 strcmp
if (strcmp(s1, s2) == 0) {
    std::cout << "equal" << std::endl;
}

// ✅ 正确：使用 C++ string
std::string s3 = "hello";
std::string s4 = "hello";
if (s3 == s4) {  // C++ string 的 == 是值比较
    std::cout << "equal" << std::endl;
}
```

## 8. 数组作为函数参数退化

```cpp
// ❌ 错误：以为 sizeof 能获取数组大小
void printArray(int arr[]) {
    int len = sizeof(arr) / sizeof(arr[0]);  // 错误！arr 是指针
    // sizeof(arr) = 8（64位指针大小），不是数组大小
}

// ✅ 正确：显式传递长度
void printArray(int arr[], int len) {
    for (int i = 0; i < len; i++) {
        std::cout << arr[i] << " ";
    }
}

// ✅ 正确：使用模板保留数组大小
template<size_t N>
void printArray(int (&arr)[N]) {
    for (size_t i = 0; i < N; i++) {
        std::cout << arr[i] << " ";
    }
}
```

## 9. 悬挂指针

```cpp
// ❌ 错误：返回局部变量的地址
int* createValue() {
    int x = 42;
    return &x;  // x 在函数返回后销毁，指针悬挂！
}

// ✅ 正确：返回值而非地址
int createValue() {
    return 42;
}

// ✅ 正确：使用 new 分配堆内存
int* createValue() {
    return new int(42);  // 调用者负责 delete
}
```

## 10. `main` 函数签名错误

```cpp
// ❌ 错误：错误的 main 函数签名
void main() { }        // 错误！main 必须返回 int
int main(int a) { }    // 错误！参数不对

// ✅ 正确：标准签名
int main() { return 0; }
int main(int argc, char* argv[]) { return 0; }
```

## 11. 循环变量作用域问题

```cpp
// ❌ 错误（C++98 风格）：循环变量在循环外仍可见
for (int i = 0; i < 10; i++) { }
std::cout << i << std::endl;  // C++98 可以，C++11 报错

// ✅ 正确：在需要的作用域内声明变量
int i = 0;
for (; i < 10; i++) { }
std::cout << i << std::endl;  // i = 10
```

## 12. 全局与局部变量同名

```cpp
// ❌ 错误：局部变量遮蔽全局变量
int count = 100;
void func() {
    int count = 0;  // 遮蔽了全局 count
    count++;        // 修改的是局部 count
}

// ✅ 正确：避免同名，或使用作用域运算符
int g_count = 100;
void func() {
    g_count++;  // 明确修改全局变量
}
```

## 13. `sizeof` 对指针

```cpp
// ❌ 错误：对指针用 sizeof 以为得到数组大小
int arr[10];
int* p = arr;
std::cout << sizeof(arr) << std::endl;  // 40（10 * 4）
std::cout << sizeof(p) << std::endl;    // 8（指针大小，64位系统）

// ✅ 正确：在定义数组的作用域内使用 sizeof
int len = sizeof(arr) / sizeof(arr[0]);  // 10
```

## 14. 字符与字符串混淆

```cpp
// ❌ 错误：单引号 vs 双引号
char c = "a";    // 错误！"a" 是字符串，类型是 const char*
char* s = 'a';   // 错误！'a' 是字符，类型是 char

// ✅ 正确
char c = 'a';     // 单引号是字符
const char* s = "a";  // 双引号是字符串
```

## 15. 头文件重复包含

```cpp
// ❌ 错误：没有头文件保护，重复包含导致重定义
// myheader.h
struct Point { int x, y; };

// file.cpp
#include "myheader.h"
#include "myheader.h"  // 重定义错误！

// ✅ 正确：使用头文件保护
// myheader.h
#ifndef MYHEADER_H
#define MYHEADER_H
struct Point { int x, y; };
#endif

// ✅ 正确（C++20）：使用 #pragma once
// myheader.h
#pragma once
struct Point { int x, y; };
```

## 16. `new`/`delete` 不匹配

```cpp
// ❌ 错误：new 与 delete[] 混用
int* p1 = new int(10);
delete[] p1;  // 错误！应该用 delete

int* p2 = new int[10];
delete p2;    // 错误！应该用 delete[]

// ✅ 正确：配对使用
int* p1 = new int(10);
delete p1;

int* p2 = new int[10];
delete[] p2;
```

## 17. 有符号与无符号比较

```cpp
// ❌ 错误：有符号与无符号比较
int n = -1;
unsigned int m = 10;
if (n < m) {  // n 被转为无符号，变成 4294967295，比较结果为 false！
    std::cout << "n < m" << std::endl;
}

// ✅ 正确：统一类型
if (static_cast<int>(m) > n) {
    std::cout << "n < m" << std::endl;
}

// ✅ 正确：循环中使用 size_t
for (size_t i = 0; i < vec.size(); i++) {  // size_t 是无符号类型
    // ...
}
```

## 18. 返回局部变量地址

```cpp
// ❌ 错误：返回局部数组的地址
int* getArray() {
    int arr[10] = {0};
    return arr;  // 返回局部数组地址，函数返回后无效！
}

// ✅ 正确：使用 static 或堆分配
int* getArray() {
    static int arr[10] = {0};  // static 变量生命周期到程序结束
    return arr;
}

// ✅ 正确：使用 std::array 或 std::vector
std::vector<int> getArray() {
    return std::vector<int>(10, 0);
}
```

## 19. 多文件变量重复定义

```cpp
// ❌ 错误：头文件中定义全局变量
// config.h
int maxCount = 100;  // 每个包含此头文件的 .cpp 都会定义一份

// ✅ 正确：头文件声明，源文件定义
// config.h
extern int maxCount;  // 声明
// config.cpp
int maxCount = 100;   // 定义
```

## 20. 忘记 `namespace`

```cpp
// ❌ 错误：直接使用 std 中的名称
#include <iostream>
#include <string>
int main() {
    string name = "hello";  // 未声明 string
    cout << name << endl;   // 未声明 cout
}

// ✅ 正确：方式一，加 std:: 前缀
std::string name = "hello";
std::cout << name << std::endl;

// ✅ 正确：方式二，using 声明
using std::string;
using std::cout;
using std::endl;

// ✅ 正确：方式三，using namespace（不推荐在头文件中使用）
using namespace std;
```

## 预防措施总结

| 措施 | 预防的错误 |
|------|----------|
| 编译时加 `-Wall -Wextra` | 大部分逻辑错误 |
| 使用 `-Werror` | 将警告视为错误 |
| 使用 `-Wold-style-cast` | C 风格转换 |
| 使用 `clang-tidy` | 代码质量检查 |
| 使用智能指针 | 内存管理错误 |
| 使用 `std::string` | 字符串相关错误 |
| 使用 `std::vector` | 数组越界 |
| 代码审查 | 所有类型错误 |
