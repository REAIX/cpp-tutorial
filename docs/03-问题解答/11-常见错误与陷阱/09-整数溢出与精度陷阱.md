# 整数溢出与精度陷阱
> 📖 相关章节：[陷阱与技巧](../../04-工程实践/10-陷阱与技巧.md)、[内存管理](../../01-C语言/09-内存管理.md)

整数溢出和浮点精度问题是 C/C++ 中隐蔽而危险的陷阱。它们不会导致编译错误，甚至不会导致运行时崩溃，但会产生完全错误的结果。本文详细讲解这些问题的原理和防范方法。

## 整数溢出

### 什么是整数溢出？

每种整数类型都有其表示范围，当运算结果超出这个范围时，就发生了溢出。

| 类型 | 典型范围（32位系统） | 典型范围（64位系统） |
|------|---------------------|---------------------|
| `char` | -128 ~ 127 | -128 ~ 127 |
| `short` | -32768 ~ 32767 | -32768 ~ 32767 |
| `int` | -2147483648 ~ 2147483647 | -2147483648 ~ 2147483647 |
| `long` | -2147483648 ~ 2147483647 | -9223372036854775808 ~ 9223372036854775807 |
| `unsigned int` | 0 ~ 4294967295 | 0 ~ 4294967295 |

### 有符号溢出 vs 无符号溢出

| 类型 | 溢出行为 | 是否 UB |
|------|---------|--------|
| 有符号整数溢出 | 未定义行为 | ✅ 是 UB |
| 无符号整数溢出 | 回绕（wrap around） | ❌ 不是 UB |

```cpp
// ❌ UB：有符号整数溢出
int x = INT_MAX;  // 2147483647
int y = x + 1;    // UB！结果不可预测

// ✅ 定义良好：无符号整数回绕
unsigned int x = UINT_MAX;  // 4294967295
unsigned int y = x + 1;     // y = 0（回绕）
```

### 1. 加法溢出

```cpp
// ❌ 错误：加法溢出
int a = 2000000000;
int b = 2000000000;
int sum = a + b;  // UB！结果超出 int 范围

// ✅ 正确：检查溢出
int safeAdd(int a, int b) {
    if (b > 0 && a > INT_MAX - b) {
        // 会溢出
        throw std::overflow_error("addition overflow");
    }
    if (b < 0 && a < INT_MIN - b) {
        // 会下溢
        throw std::overflow_error("addition underflow");
    }
    return a + b;
}

// ✅ 正确：使用更大的类型
long long sum = (long long)a + b;
```

### 2. 乘法溢出

```cpp
// ❌ 错误：乘法溢出
int a = 100000;
int b = 100000;
int product = a * b;  // UB！10^10 超出 int 范围

// ✅ 正确：使用更大的类型
long long product = (long long)a * b;  // 注意：先转型再乘

// ❌ 错误：转型太晚
long long product2 = a * b;  // a*b 先按 int 计算，已经溢出！

// ✅ 正确：先转型
long long product3 = (long long)a * (long long)b;
```

### 3. 减法下溢

```cpp
// ❌ 错误：无符号减法下溢
unsigned int a = 5;
unsigned int b = 10;
unsigned int diff = a - b;  // 不是 -5，而是 4294967291！

// ✅ 正确：先检查
if (a >= b) {
    unsigned int diff = a - b;
} else {
    // 处理 a < b 的情况
}

// ✅ 正确：使用有符号类型
int diff = (int)a - (int)b;  // -5
```

## 有符号与无符号比较陷阱

### 4. 有符号与无符号比较

```cpp
// ❌ 错误：有符号与无符号比较
int n = -1;
unsigned int m = 10;
if (n < m) {
    // 不会执行！n 被隐式转为 unsigned int
    // -1 变成 4294967295，大于 10
    std::cout << "n < m" << std::endl;
}

// ✅ 正确：统一类型
if (n < (int)m) {  // 或者 if ((unsigned int)n < m) 根据意图
    std::cout << "n < m" << std::endl;
}
```

### 5. `size_t` 陷阱

```cpp
// ❌ 错误：size_t 是无符号类型
std::vector<int> v = {1, 2, 3};
for (int i = v.size() - 1; i >= 0; i--) {
    // 如果 v 为空，v.size() - 1 = (size_t)0 - 1 = 极大值
    // i 被赋极大值，i >= 0 为真 → 越界访问
    std::cout << v[i] << std::endl;
}

// ✅ 正确：使用迭代器或避免无符号下溢
for (int i = (int)v.size() - 1; i >= 0; i--) {
    std::cout << v[i] << std::endl;
}

// ✅ 更好：使用反向迭代器
for (auto it = v.rbegin(); it != v.rend(); ++it) {
    std::cout << *it << std::endl;
}
```

## 浮点精度问题

### 6. 0.1 + 0.2 ≠ 0.3

```cpp
// ❌ 错误：浮点数精度问题
double a = 0.1;
double b = 0.2;
if (a + b == 0.3) {
    // 不会执行！0.1 + 0.2 ≈ 0.30000000000000004
    std::cout << "equal" << std::endl;
}

std::cout << std::setprecision(20) << a + b << std::endl;
// 输出：0.30000000000000004

// ✅ 正确：使用 epsilon 比较
#include <cmath>
bool almostEqual(double a, double b, double epsilon = 1e-9) {
    return std::fabs(a - b) < epsilon;
}

if (almostEqual(a + b, 0.3)) {
    std::cout << "approximately equal" << std::endl;
}
```

**为什么 0.1 + 0.2 ≠ 0.3？**

十进制的 0.1 在二进制中是无限循环小数：0.0001100110011...，无法精确表示。

| 十进制数 | 二进制表示 | 精确？ |
|---------|-----------|--------|
| 0.5 | 0.1 | ✅ |
| 0.25 | 0.01 | ✅ |
| 0.125 | 0.001 | ✅ |
| 0.1 | 0.000110011... | ❌ |
| 0.2 | 0.001100110... | ❌ |
| 0.3 | 0.010011001... | ❌ |

### 7. 用 `==` 比较浮点数

```cpp
// ❌ 错误：直接比较浮点数
double x = 1.0 / 3.0;
double y = 1.0;
y = y / 3.0;
y = y * 3.0;
if (y == 1.0) {  // 可能不相等！
    std::cout << "equal" << std::endl;
}

// ✅ 正确：使用 epsilon 或相对误差
bool approxEqual(double a, double b, double eps = 1e-9) {
    double diff = std::fabs(a - b);
    if (diff <= eps) return true;
    // 对于很大的数，使用相对误差
    return diff <= eps * std::max(std::fabs(a), std::fabs(b));
}
```

### 8. 浮点数特殊值

```cpp
// 浮点数有三个特殊值
double inf = 1.0 / 0.0;      // 无穷大
double neginf = -1.0 / 0.0;  // 负无穷大
double nan = 0.0 / 0.0;      // NaN（Not a Number）

// ❌ 错误：NaN 不等于任何值，包括自己！
if (nan == nan) { }     // false！
if (nan != nan) { }     // true！这是检测 NaN 的方法

// ✅ 正确：使用标准库函数
#include <cmath>
if (std::isnan(nan)) { }    // true
if (std::isinf(inf)) { }    // true
if (std::isfinite(1.0)) { } // true
```

### 9. `float` vs `double` 精度

| 类型 | 有效数字 | 字节数 | 范围 |
|------|---------|-------|------|
| `float` | ~7 位 | 4 | ±3.4×10³⁸ |
| `double` | ~15 位 | 8 | ±1.7×10³⁰⁸ |
| `long double` | ~18-19 位 | 8-16 | 平台相关 |

```cpp
// ❌ 错误：float 精度不够
float f = 123456789.0f;
std::cout << std::setprecision(10) << f << std::endl;
// 输出：123456792.0  ← 7 位以后就不准了！

// ✅ 正确：需要精度时使用 double
double d = 123456789.0;
std::cout << std::setprecision(10) << d << std::endl;
// 输出：123456789.0  ← 精确
```

## 整数除法陷阱

### 10. 整数除法截断

```cpp
// ❌ 错误：整数除法截断小数部分
int a = 7, b = 2;
double result = a / b;  // result = 3.0，不是 3.5！

// ✅ 正确：至少一个操作数转为浮点
double result = (double)a / b;  // 3.5
double result2 = 7.0 / 2;      // 3.5
double result3 = a * 1.0 / b;  // 3.5
```

### 11. 负数整数除法

```cpp
// C++11 之前：负数除法向零或向负无穷截断，由实现定义
// C++11 之后：总是向零截断
int a = -7, b = 2;
int q = a / b;   // -3（向零截断，不是 -4）
int r = a % b;   // -1（符号与被除数相同）

// ❌ 常见错误：假设取模结果总是正数
int index = -1 % 10;  // -1，不是 9！
arr[index];           // 越界！

// ✅ 正确：处理负数取模
int safeMod(int a, int b) {
    int r = a % b;
    return r >= 0 ? r : r + b;
}
```

### 12. 隐式类型转换导致的溢出

```cpp
// ❌ 错误：隐式转换导致精度丢失
int big = 1234567890;
float f = big;  // float 只有 7 位有效数字
int back = f;   // back = 1234567936，不是 1234567890！

// ❌ 错误：混合运算中的隐式转换
int a = 3;
float b = a / 2;  // b = 1.0，不是 1.5！先整数除法再转 float

// ✅ 正确
float c = (float)a / 2;  // 1.5
float d = a / 2.0f;      // 1.5
```

## 防范措施总结

### 整数溢出防范

| 措施 | 说明 |
|------|------|
| 使用更大的类型 | `long long` 代替 `int` |
| 运算前检查 | 比较是否接近类型极限 |
| 使用安全函数 | 自定义 `safeAdd`、`safeMul` 等 |
| 编译器内置函数 | `__builtin_add_overflow`（GCC/Clang） |
| 开启 UBSan | `-fsanitize=undefined` 检测有符号溢出 |

### 浮点精度防范

| 措施 | 说明 |
|------|------|
| 使用 `double` | 默认使用 `double`，不用 `float` |
| Epsilon 比较 | 不用 `==`，用 `fabs(a-b) < epsilon` |
| 避免累积误差 | 重新排列运算顺序，Kahan 求和 |
| 使用十进制库 | 需要精确计算时用 `std::decimal` 或第三方库 |
| 注意特殊值 | 检查 `isnan`、`isinf` |

### 编译选项

```bash
# 开启所有警告
g++ -Wall -Wextra -Wpedantic main.cpp

# 检测有符号溢出
g++ -fsanitize=undefined main.cpp

# 检测整数溢出（GCC 特有）
g++ -ftrapv main.cpp  # 有符号溢出时触发 SIGABRT

# 检测浮点异常
g++ -ffloat-store main.cpp
```
