# 怎么搭建开发环境
> 📖 相关章节：[VSCode配置](../../05-开发环境与IDE/00-VSCode核心配置.md)、[CMake基础](../../05-开发环境与IDE/03-CMake基础入门.md)、[GCC编译器](../../05-开发环境与IDE/07-GCC编译器基础.md)

## 一个生活类比

你要画画，首先得准备好画室——画架、颜料、画笔、灯光，缺一不可。如果画架不稳、颜料干涸、灯光昏暗，再好的画技也发挥不出来。

**开发环境就是程序员的"画室"。** 编译器、编辑器、调试器、构建工具，这些基础设施配置好了，你才能专注于写代码本身。

## Windows 环境

### 方案一：MinGW-w64（推荐初学者）

`MinGW-w64` 是 `Windows` 上的 `GCC` 移植版，轻量且免费。

**步骤：**

1. **安装 `MSYS2`**

   下载 https://www.msys2.org/ ，运行安装程序，默认路径 `C:\msys64`

2. **安装 `GCC` 工具链**

   打开 `MSYS2 UCRT64` 终端，执行：
   ```bash
   pacman -Syu
   pacman -S mingw-w64-ucrt-x86_64-gcc
   pacman -S mingw-w64-ucrt-x86_64-gdb
   pacman -S mingw-w64-ucrt-x86_64-cmake
   pacman -S mingw-w64-ucrt-x86_64-ninja
   ```

3. **配置 `PATH` 环境变量**

   将 `C:\msys64\ucrt64\bin` 添加到系统 `PATH`：
   - 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
   - 在"系统变量"中找到 `Path`，点击编辑
   - 新增 `C:\msys64\ucrt64\bin`

4. **验证安装**

   打开 `CMD` 或 `PowerShell`：
   ```bash
   g++ --version
   gdb --version
   cmake --version
   ```

### 方案二：Visual Studio + MSVC

适合不想折腾命令行的 `Windows` 用户。

**步骤：**

1. 下载 `Visual Studio Community`（免费）：https://visualstudio.microsoft.com/
2. 安装时勾选"使用 `C++` 的桌面开发"
3. 等待安装完成（约10-20GB）
4. 打开 `VS`，创建新项目 → 控制台应用 → 写代码 → `F5` 运行

**优点：** 开箱即用，调试器强大
**缺点：** 体积大，仅限 `Windows`

### 方案三：WSL2（Windows Subsystem for Linux）

在 `Windows` 中运行真正的 `Linux` 环境，适合需要 `Linux` 开发体验的人。

**步骤：**

1. 以管理员身份打开 `PowerShell`：
   ```powershell
   wsl --install
   ```
2. 重启电脑
3. 打开 `Ubuntu` 终端，安装工具：
   ```bash
   sudo apt update
   sudo apt install build-essential gdb cmake
   ```
4. 用 `VS Code` 的 `Remote - WSL` 插件连接 `WSL` 开发

## Linux 环境

### Ubuntu / Debian

```bash
# 更新包列表
sudo apt update

# 安装完整编译工具链
sudo apt install build-essential gdb cmake

# build-essential 包含：gcc, g++, make, libc-dev
```

验证：
```bash
g++ --version
gdb --version
cmake --version
```

### Fedora

```bash
sudo dnf install gcc-c++ gdb cmake make
```

### Arch Linux

```bash
sudo pacman -S gcc gdb cmake make
```

## macOS 环境

### 安装命令行工具

```bash
xcode-select --install
```

这会安装 `Clang`、`LLDB`、`make` 等基础工具。

验证：
```bash
clang++ --version
lldb --version
```

### 安装 CMake

```bash
# 通过 Homebrew
brew install cmake

# 或从官网下载：https://cmake.org/download/
```

### 注意：macOS 上是 Clang 不是 GCC

`macOS` 上 `gcc`/`g++` 命令实际上是 `Clang` 的别名。如果需要真正的 `GCC`：

```bash
brew install gcc
# 然后用 g++-13 等命令调用
```

## 配置 VS Code

无论哪个平台，`VS Code` 的配置流程基本一致：

### 1. 安装必要插件

| 插件 | 作用 |
|------|------|
| `C/C++` | 代码补全、调试支持 |
| `CMake Tools` | `CMake` 项目管理 |
| `CMake` | `CMakeLists.txt` 语法高亮 |
| `Code Runner` | 一键运行单文件 |

### 2. 配置编译器路径

创建 `.vscode/c_cpp_properties.json`：
```json
{
    "configurations": [
        {
            "name": "Win32",
            "compilerPath": "C:/msys64/ucrt64/bin/g++.exe",
            "cStandard": "c17",
            "cppStandard": "c++17",
            "intelliSenseMode": "gcc-x64"
        }
    ]
}
```

### 3. 配置调试

创建 `.vscode/launch.json`：
```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Debug C++",
            "type": "cppdbg",
            "request": "launch",
            "program": "${fileDirname}/${fileBasenameNoExtension}.exe",
            "args": [],
            "cwd": "${workspaceFolder}",
            "environment": [],
            "MIMode": "gdb",
            "miDebuggerPath": "gdb",
            "preLaunchTask": "build"
        }
    ]
}
```

### 4. 配置构建任务

创建 `.vscode/tasks.json`：
```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "build",
            "type": "shell",
            "command": "g++",
            "args": [
                "-std=c++17", "-Wall", "-g",
                "${file}",
                "-o", "${fileDirname}/${fileBasenameNoExtension}.exe"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}
```

## 常见坑与排障

### "g++不是内部或外部命令"

**原因：** 编译器未安装或未加入 `PATH`

**解决：**
1. 确认已安装 `MinGW`/`MSYS2`
2. 确认 `PATH` 中包含 `bin` 目录
3. 重启终端（`PATH` 修改后需要重启才生效）

### "中文乱码"

**原因：** `Windows` 终端默认使用 `GBK`，而源文件可能是 `UTF-8`

**解决：**
```bash
# 方法1：编译时指定编码
g++ -finput-charset=UTF-8 -fexec-charset=GBK main.cpp -o app

# 方法2：终端切换到UTF-8
chcp 65001
```

### "头文件找不到"

**原因：** 编译器不知道头文件在哪

**解决：**
```bash
# 用 -I 指定头文件路径
g++ -I./include main.cpp -o app
```

### "undefined reference"

**原因：** 链接阶段找不到函数实现

**解决：**
- 确保所有 `.cpp` 文件都参与编译
- 确保链接了需要的库（`-l` 选项）

### "VS Code 代码补全不工作"

**解决：**
1. 检查 `c_cpp_properties.json` 中 `compilerPath` 是否正确
2. 按 `Ctrl+Shift+P` → `C/C++: Reset IntelliSense Database`
3. 重启 `VS Code`

### "CMake 找不到编译器"

**解决：**
```bash
# 指定编译器
cmake -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ ..
```

## 环境验证清单

搭建完环境后，逐项验证：

| 检查项 | 验证命令 | 期望结果 |
|--------|---------|---------|
| 编译器 | `g++ --version` | 显示版本号 |
| 调试器 | `gdb --version` | 显示版本号 |
| 构建工具 | `cmake --version` | 显示版本号 |
| 编译测试 | `g++ -std=c++17 hello.cpp -o hello && ./hello` | 正常运行 |
| 调试测试 | `gdb ./hello` → `r` | 正常运行 |
| VS Code 补全 | 输入 `std::` | 出现补全列表 |
| VS Code 调试 | 设断点按 `F5` | 在断点处暂停 |

## 不同需求的推荐方案

| 需求 | 推荐方案 |
|------|---------|
| 刚入门，想快速开始 | `VS Code` + `MinGW`（`MSYS2`） |
| `Windows` 深度开发 | `Visual Studio Community` |
| 想学 `Linux` 开发 | `WSL2` + `VS Code Remote` |
| 跨平台项目 | `CMake` + `VS Code`/`CLion` |
| 最简安装 | `MSYS2` 一键搞定 |

## 总结

搭建开发环境是学习编程的第一步，也是最容易被卡住的一步。关键原则：

1. **不要同时装多个编译器**——初学者一个就够了
2. **遇到问题先搜索**——99%的环境问题别人都遇到过
3. **验证每一步**——装完一个工具就测试一下，别等全装完才发现问题
4. **记录你的配置**——把安装步骤和遇到的问题记下来，下次重装时省时间

**环境搭建是一次性的苦差事，熬过去就好了。** 如果实在搞不定，先用在线编译器（如 `Compiler Explorer`、`OnlineGDB`）写代码，同时慢慢解决本地环境问题。
