# 什么是半同步半异步模式
> 📖 相关章节：[网络编程](../../02-CPP/35-网络编程.md)、[IO多路复用](../../08-高性能网络与异步IO/01-IO多路复用深入.md)、[Reactor模式](../../08-高性能网络与异步IO/02-Reactor模式.md)

> "精髓速览：半同步半异步=异步层负责高效IO，同步层负责简单业务，中间用队列衔接。就像餐厅前台异步接单，后厨同步做菜，出菜口是两者的桥梁。"

***

### 1. 通俗理解

- **半同步半异步** = 系统分为异步IO层和同步业务层，通过队列解耦
- 异步层：用事件驱动处理网络IO，高并发、高吞吐
- 同步层：用传统同步方式处理业务逻辑，简单直观
- 就像快递站：前台异步收件（来者不拒），后台同步分拣（一件件处理）

| 概念 | 类比 | 说明 |
|------|------|------|
| 异步层 | 快递前台 | 高效接收/发送网络数据 |
| 同步层 | 后厨 | 按顺序处理业务逻辑 |
| 队列 | 出菜口/传菜窗口 | 异步层和同步层之间的缓冲 |
| 生产者 | 前台（异步层） | 往队列放入任务 |
| 消费者 | 后厨（同步层） | 从队列取出任务处理 |

***

### 2. 技术说明

#### 1. 模式原理

**为什么需要半同步半异步**：

| 纯异步的问题 | 纯同步的问题 |
|-------------|-------------|
| 回调地狱（callback hell） | 线程-per-连接，无法高并发 |
| 业务逻辑难以编写 | 阻塞IO浪费线程资源 |
| 错误处理复杂 | 上下文切换开销大 |
| 代码可读性差 | 扩展性差 |

**半同步半异步的解决思路**：

```
┌──────────────────────────────────────────────────────┐
│                半同步半异步架构                        │
│                                                      │
│  ┌──────────────────────────────────────────────┐   │
│  │            异步层 (Reactor)                    │   │
│  │                                               │   │
│  │  epoll_wait → 读取请求 → 放入队列              │   │
│  │  epoll_wait → 写入响应 ← 从队列取结果          │   │
│  └──────────────────┬───────────────────────────┘   │
│                     │                                │
│              ┌──────▼──────┐                         │
│              │  任务队列    │  ← 生产者-消费者模式     │
│              │  (有界队列)  │                         │
│              └──────┬──────┘                         │
│                     │                                │
│  ┌──────────────────▼───────────────────────────┐   │
│  │            同步层 (线程池)                     │   │
│  │                                               │   │
│  │  线程1: 取任务 → 处理业务 → 放结果             │   │
│  │  线程2: 取任务 → 处理业务 → 放结果             │   │
│  │  线程3: 取任务 → 处理业务 → 放结果             │   │
│  └──────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
```

**三层架构**：

| 层次 | 职责 | 线程模型 |
|------|------|---------|
| 异步IO层 | 网络读写、连接管理 | 1个或少数几个Reactor线程 |
| 队列层 | 任务缓冲、解耦 | 无线程，纯数据结构 |
| 同步业务层 | 业务逻辑处理 | 线程池 |

#### 2. 分层设计

**异步层的设计要点**：

| 要点 | 说明 |
|------|------|
| 只做IO | 不执行任何业务逻辑 |
| 非阻塞 | 所有IO操作非阻塞 |
| 快速响应 | 尽快将数据读入并放入队列 |
| 零拷贝 | 尽量减少数据拷贝 |
| 背压 | 队列满时通知上游减速 |

**同步层的设计要点**：

| 要点 | 说明 |
|------|------|
| 只做业务 | 不关心网络IO细节 |
| 可阻塞 | 允许阻塞操作（数据库、文件） |
| 线程安全 | 共享数据需要加锁 |
| 超时控制 | 每个任务有执行超时 |

**队列层的设计要点**：

| 要点 | 说明 |
|------|------|
| 有界队列 | 防止内存溢出 |
| 高效入队出队 | 无锁或有锁队列 |
| 背压机制 | 队列满时丢弃或等待 |
| 优先级 | 紧急任务优先处理 |

#### 3. 异步队列的实现

**有界阻塞队列**：

```cpp
template<typename T>
class BoundedBlockingQueue {
public:
    BoundedBlockingQueue(size_t capacity)
        : capacity_(capacity) {}

    // 生产者调用：放入任务
    bool produce(T item, int timeout_ms = -1) {
        std::unique_lock<std::mutex> lock(mutex_);

        if (timeout_ms < 0) {
            // 阻塞等待
            not_full_.wait(lock, [this] {
                return queue_.size() < capacity_;
            });
        } else {
            // 超时等待
            if (!not_full_.wait_for(lock,
                std::chrono::milliseconds(timeout_ms),
                [this] { return queue_.size() < capacity_; })) {
                return false;  // 超时，队列满
            }
        }

        queue_.push(std::move(item));
        not_empty_.notify_one();
        return true;
    }

    // 消费者调用：取出任务
    T consume() {
        std::unique_lock<std::mutex> lock(mutex_);
        not_empty_.wait(lock, [this] { return !queue_.empty(); });

        T item = std::move(queue_.front());
        queue_.pop();
        not_full_.notify_one();
        return item;
    }

    size_t size() const {
        std::lock_guard<std::mutex> lock(mutex_);
        return queue_.size();
    }

private:
    std::queue<T> queue_;
    size_t capacity_;
    mutable std::mutex mutex_;
    std::condition_variable not_full_;
    std::condition_variable not_empty_;
};
```

**无锁队列（单生产者单消费者）**：

```cpp
template<typename T, size_t Size>
class SPSCQueue {
public:
    SPSCQueue() : head_(0), tail_(0) {}

    bool push(const T& item) {
        size_t next = (tail_ + 1) % (Size + 1);
        if (next == head_.load(std::memory_order_acquire)) {
            return false;  // 队列满
        }
        buffer_[tail_] = item;
        tail_.store(next, std::memory_order_release);
        return true;
    }

    bool pop(T& item) {
        if (head_.load(std::memory_order_acquire) ==
            tail_.load(std::memory_order_acquire)) {
            return false;  // 队列空
        }
        item = buffer_[head_];
        head_.store((head_ + 1) % (Size + 1), std::memory_order_release);
        return true;
    }

private:
    alignas(64) std::atomic<size_t> head_;  // 缓存行对齐，避免伪共享
    alignas(64) std::atomic<size_t> tail_;
    T buffer_[Size + 1];
};
```

#### 4. 在服务器中的应用

**典型应用：HTTP服务器**

```
客户端请求 → 异步层接收HTTP请求 → 放入任务队列
                                      ↓
                              同步层线程池处理：
                              1. 解析HTTP请求
                              2. 路由到处理函数
                              3. 执行业务逻辑（可能查数据库）
                              4. 生成HTTP响应
                                      ↓
                              放入响应队列 → 异步层发送响应
```

**典型应用：游戏服务器**

```
玩家操作 → 异步层接收消息 → 放入逻辑队列
                              ↓
                        逻辑线程（单线程）：
                        1. 解析消息
                        2. 更新游戏状态
                        3. 生成广播消息
                              ↓
                        放入广播队列 → 异步层群发消息
```

**典型应用：消息中间件**

```
生产者消息 → 异步层接收 → 放入写入队列
                              ↓
                        同步层线程池：
                        1. 消息校验
                        2. 持久化存储
                        3. 更新索引
                              ↓
                        放入投递队列 → 异步层推送给消费者
```

### 3. 代码示例

#### 1. 完整的半同步半异步服务器

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <sys/epoll.h>
#include <errno.h>
#include <thread>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <functional>
#include <string>
#include <atomic>

#define PORT         8080
#define MAX_EVENTS   1024
#define QUEUE_SIZE   10000

// 任务：异步层→同步层
struct Task {
    int fd;                  // 客户端fd
    std::string request;     // 请求数据
};

// 结果：同步层→异步层
struct Result {
    int fd;                  // 客户端fd
    std::string response;    // 响应数据
};

// 有界阻塞队列
template<typename T>
class BlockingQueue {
public:
    BlockingQueue(size_t capacity) : capacity_(capacity), stopped_(false) {}

    bool push(T item) {
        std::unique_lock<std::mutex> lock(mutex_);
        not_full_.wait(lock, [this] {
            return queue_.size() < capacity_ || stopped_;
        });
        if (stopped_) return false;
        queue_.push(std::move(item));
        not_empty_.notify_one();
        return true;
    }

    bool pop(T& item) {
        std::unique_lock<std::mutex> lock(mutex_);
        not_empty_.wait(lock, [this] {
            return !queue_.empty() || stopped_;
        });
        if (stopped_ && queue_.empty()) return false;
        item = std::move(queue_.front());
        queue_.pop();
        not_full_.notify_one();
        return true;
    }

    void stop() {
        std::lock_guard<std::mutex> lock(mutex_);
        stopped_ = true;
        not_full_.notify_all();
        not_empty_.notify_all();
    }

private:
    std::queue<T> queue_;
    size_t capacity_;
    bool stopped_;
    std::mutex mutex_;
    std::condition_variable not_full_;
    std::condition_variable not_empty_;
};

// 半同步半异步服务器
class HalfSyncHalfAsyncServer {
public:
    HalfSyncHalfAsyncServer(int worker_count = 4)
        : task_queue_(QUEUE_SIZE), result_queue_(QUEUE_SIZE),
          running_(false), worker_count_(worker_count) {}

    void start() {
        running_ = true;

        // 启动同步层工作线程
        for (int i = 0; i < worker_count_; i++) {
            workers_.emplace_back(&HalfSyncHalfAsyncServer::workerLoop, this, i);
        }

        // 启动异步层Reactor线程
        reactor_thread_ = std::thread(&HalfSyncHalfAsyncServer::reactorLoop, this);

        printf("服务器启动: 1个Reactor线程 + %d个工作线程\n", worker_count_);
    }

    void stop() {
        running_ = false;
        task_queue_.stop();
        result_queue_.stop();

        for (auto& t : workers_) {
            if (t.joinable()) t.join();
        }
        if (reactor_thread_.joinable()) reactor_thread_.join();
    }

private:
    // 异步层：Reactor事件循环
    void reactorLoop() {
        int listen_fd = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
        int opt = 1;
        setsockopt(listen_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        struct sockaddr_in addr = {
            .sin_family = AF_INET,
            .sin_addr.s_addr = INADDR_ANY,
            .sin_port = htons(PORT)
        };
        bind(listen_fd, (struct sockaddr*)&addr, sizeof(addr));
        listen(listen_fd, 512);

        int epfd = epoll_create1(0);

        struct epoll_event ev;
        ev.events = EPOLLIN | EPOLLET;
        ev.data.fd = listen_fd;
        epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);

        struct epoll_event* events = new epoll_event[MAX_EVENTS];

        while (running_) {
            int nfds = epoll_wait(epfd, events, MAX_EVENTS, 100);

            for (int i = 0; i < nfds; i++) {
                if (events[i].data.fd == listen_fd) {
                    // 接受新连接
                    while (1) {
                        int client_fd = accept(listen_fd, NULL, NULL);
                        if (client_fd < 0) {
                            if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                            break;
                        }
                        // 设置非阻塞
                        int flags = fcntl(client_fd, F_GETFL, 0);
                        fcntl(client_fd, F_SETFL, flags | O_NONBLOCK);

                        struct epoll_event cev;
                        cev.events = EPOLLIN | EPOLLET;
                        cev.data.fd = client_fd;
                        epoll_ctl(epfd, EPOLL_CTL_ADD, client_fd, &cev);
                        printf("[Reactor] 新连接 fd=%d\n", client_fd);
                    }
                } else if (events[i].events & EPOLLIN) {
                    // 读取请求数据
                    int fd = events[i].data.fd;
                    char buf[4096];
                    std::string request;

                    while (1) {
                        int n = read(fd, buf, sizeof(buf));
                        if (n > 0) {
                            request.append(buf, n);
                        } else if (n == 0) {
                            close(fd);
                            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                            break;
                        } else {
                            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                                // 数据读完了，放入任务队列
                                if (!request.empty()) {
                                    Task task{fd, request};
                                    task_queue_.push(std::move(task));
                                }
                                break;
                            }
                            close(fd);
                            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                            break;
                        }
                    }
                }
            }

            // 发送同步层处理完的响应
            Result result;
            while (true) {
                // 非阻塞检查结果队列
                std::unique_lock<std::mutex> lock(result_mutex_);
                if (result_queue_internal_.empty()) break;
                result = std::move(result_queue_internal_.front());
                result_queue_internal_.pop();
                lock.unlock();

                // 发送响应
                write(result.fd, result.response.data(),
                      result.response.size());
            }
        }

        delete[] events;
        close(epfd);
        close(listen_fd);
    }

    // 同步层：工作线程循环
    void workerLoop(int id) {
        printf("[Worker %d] 启动\n", id);

        while (running_) {
            Task task;
            if (!task_queue_.pop(task)) break;

            // 同步处理业务逻辑
            std::string response = processBusiness(task.request);

            // 将结果放入响应队列
            Result result{task.fd, response};
            {
                std::lock_guard<std::mutex> lock(result_mutex_);
                result_queue_internal_.push(std::move(result));
            }
        }

        printf("[Worker %d] 退出\n", id);
    }

    // 业务处理（同步，可以阻塞）
    std::string processBusiness(const std::string& request) {
        // 模拟业务处理耗时
        std::this_thread::sleep_for(std::chrono::milliseconds(1));

        // 模拟业务逻辑：回显 + 处理标记
        std::string response = "HTTP/1.1 200 OK\r\n"
                              "Content-Length: 13\r\n"
                              "\r\n"
                              "Hello, World!";
        return response;
    }

    BlockingQueue<Task> task_queue_;
    BlockingQueue<Result> result_queue_;
    std::queue<Result> result_queue_internal_;  // 响应队列
    std::mutex result_mutex_;
    std::atomic<bool> running_;
    int worker_count_;
    std::vector<std::thread> workers_;
    std::thread reactor_thread_;
};

int main(void) {
    HalfSyncHalfAsyncServer server(4);
    server.start();

    printf("按回车键停止服务器...\n");
    getchar();

    server.stop();
    return 0;
}
```

#### 2. 分层更清晰的版本

```cpp
#include <stdio.h>
#include <string>
#include <functional>
#include <vector>
#include <thread>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <memory>

// ============ 队列层 ============

template<typename T>
class ThreadSafeQueue {
public:
    void push(T item) {
        {
            std::lock_guard<std::mutex> lock(mutex_);
            queue_.push(std::move(item));
        }
        cv_.notify_one();
    }

    bool pop(T& item, int timeout_ms = 100) {
        std::unique_lock<std::mutex> lock(mutex_);
        if (!cv_.wait_for(lock, std::chrono::milliseconds(timeout_ms),
                         [this] { return !queue_.empty(); })) {
            return false;
        }
        item = std::move(queue_.front());
        queue_.pop();
        return true;
    }

private:
    std::queue<T> queue_;
    std::mutex mutex_;
    std::condition_variable cv_;
};

// ============ 异步层 ============

class AsyncLayer {
public:
    using RequestCallback = std::function<void(int fd, const std::string& data)>;

    void setRequestCallback(RequestCallback cb) {
        on_request_ = cb;
    }

    // 模拟接收到请求
    void simulateRequest(int fd, const std::string& data) {
        printf("[异步层] 收到请求 fd=%d, 数据长度=%zu\n", fd, data.size());
        if (on_request_) {
            on_request_(fd, data);
        }
    }

    // 发送响应
    void sendResponse(int fd, const std::string& data) {
        printf("[异步层] 发送响应 fd=%d, 数据长度=%zu\n", fd, data.size());
        // 实际实现中这里调用write发送
    }

private:
    RequestCallback on_request_;
};

// ============ 同步层 ============

class SyncLayer {
public:
    using ProcessFunc = std::function<std::string(const std::string&)>;

    SyncLayer(int thread_count, ProcessFunc func)
        : process_func_(func), running_(true) {
        for (int i = 0; i < thread_count; i++) {
            threads_.emplace_back(&SyncLayer::workerLoop, this, i);
        }
    }

    ~SyncLayer() {
        running_ = false;
        for (auto& t : threads_) {
            if (t.joinable()) t.join();
        }
    }

    // 提交任务
    void submit(int fd, const std::string& request) {
        task_queue_.push({fd, request});
    }

    // 获取结果
    bool getResult(int& fd, std::string& response) {
        return result_queue_.pop(fd_response_{0, ""}, 0)
            ? true : false;
    }

private:
    struct Task { int fd; std::string request; };
    struct fd_response_ { int fd; std::string response; };

    void workerLoop(int id) {
        while (running_) {
            Task task;
            if (!task_queue_.pop(task, 100)) continue;

            // 同步处理业务
            std::string response = process_func_(task.request);

            // 放入结果队列
            result_queue_.push({task.fd, response});
        }
    }

    ThreadSafeQueue<Task> task_queue_;
    ThreadSafeQueue<fd_response_> result_queue_;
    ProcessFunc process_func_;
    std::vector<std::thread> threads_;
    std::atomic<bool> running_;
};

// ============ 组合 ============

int main(void) {
    // 创建异步层
    AsyncLayer async_layer;

    // 创建同步层（4个工作线程）
    SyncLayer sync_layer(4, [](const std::string& request) -> std::string {
        printf("[同步层] 处理请求: %s\n", request.c_str());
        // 模拟业务处理
        return "处理结果: " + request;
    });

    // 连接两层：异步层收到请求 → 放入同步层队列
    async_layer.setRequestCallback([&sync_layer](int fd, const std::string& data) {
        sync_layer.submit(fd, data);
    });

    // 模拟请求
    async_layer.simulateRequest(1, "查询用户信息");
    async_layer.simulateRequest(2, "创建订单");
    async_layer.simulateRequest(3, "更新库存");

    // 等待处理完成
    std::this_thread::sleep_for(std::chrono::milliseconds(100));

    printf("\n半同步半异步模式运行完成\n");
    return 0;
}
```

### 4. 常见问题

#### Q1：半同步半异步和Reactor模式有什么区别？

Reactor模式是IO多路复用的框架，半同步半异步是分层架构模式。半同步半异步可以用Reactor实现异步层，但Reactor本身不要求分层。muduo就是Reactor+线程池，本质上也是半同步半异步。

#### Q2：队列大小怎么定？

根据业务峰值和消费速度计算。公式：队列大小 = 峰值QPS × 允许的排队时间。例如峰值10000 QPS，允许排队100ms，则队列大小=1000。建议有界队列，防止OOM。

#### Q3：同步层线程数怎么定？

CPU密集型：线程数 = CPU核心数 + 1
IO密集型：线程数 = CPU核心数 × (1 + 等待时间/计算时间)
混合型：根据实际压测调整

#### Q4：异步层和同步层之间的数据拷贝怎么优化？

1. 使用shared_ptr共享数据，避免拷贝
2. 使用move语义转移数据所有权
3. 使用内存池减少分配开销
4. 对于大块数据，使用零拷贝技术

#### Q5：什么时候不适合用半同步半异步？

- 纯IO转发（如代理服务器）：不需要同步层，纯异步更高效
- 请求间有严格顺序要求：队列可能打乱顺序
- 极低延迟要求：队列增加了一跳延迟

### 5. 总结

半同步半异步模式的核心价值是**让IO和业务各司其职**：异步层用事件驱动处理高并发IO，同步层用传统方式编写简单业务逻辑，两者通过队列解耦。这种分层设计既获得了异步IO的高性能，又保持了同步编程的简单性，是大多数业务服务器的首选架构。
