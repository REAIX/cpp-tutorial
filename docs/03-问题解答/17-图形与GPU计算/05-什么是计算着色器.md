# 什么是计算着色器
> 📖 相关章节：[图形编程概述](../../11-图形与GPU计算/00-图形编程概述.md)

> **计算着色器是GPU上的"自由人"——它不属于图形管线，可以做任何并行计算。** 不需要顶点、不需要光栅化、不需要帧缓冲——你只需要告诉GPU"数据在哪、怎么算"，它就帮你并行处理。

***

### 1. 先抓核心

**计算着色器（Compute Shader）** 是一种可编程着色器，运行在GPU上但不参与图形渲染管线。它绕过顶点处理、光栅化、片段着色等阶段，直接在GPU上执行通用并行计算（GPGPU），是图形API内置的通用计算方案。

***

### 2. 生活类比

| 类比 | 说明 |
|------|------|
| 计算着色器 = 工厂里的独立车间 | 不在主流水线上，但可以用工厂的设备和工人 |
| 图形管线 = 主流水线 | 必须按顺序走：切割→焊接→上色→质检 |
| 计算着色器 = 自由车间 | 你想做什么就做什么，不受流水线约束 |

**具体场景**：图像模糊——图形管线需要渲染一个全屏四边形，让片段着色器处理每个像素；计算着色器直接说"给我图像数据，我每个线程处理一个像素"，不需要任何图形概念。

***

### 3. 计算着色器与图形管线的区别

#### 3.1 执行路径对比

```
图形管线路径（渲染一个后处理效果）：
┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
│ 顶点   │──→│ 光栅化 │──→│ 片段   │──→│ 输出   │──→│ 帧缓冲 │
│ 着色器  │   │        │   │ 着色器  │   │ 合并   │   │        │
└────────┘   └────────┘   └────────┘   └────────┘   └────────┘
  必须走完整个管线，即使你只需要片段着色器的功能

计算着色器路径（同样的后处理效果）：
┌────────────┐   ┌────────┐
│ 计算着色器  │──→│ 存储   │
│            │   │ 缓冲区 │
└────────────┘   └────────┘
  直接计算，无需经过图形管线
```

#### 3.2 功能对比

| 维度 | 图形管线 | 计算着色器 |
|------|---------|-----------|
| 输入 | 顶点数据 | 任意数据（缓冲区/纹理） |
| 输出 | 帧缓冲像素 | 任意数据（缓冲区/纹理） |
| 执行单位 | 顶点/片段 | 工作组（Work Group） |
| 是否需要图元 | 是（三角形等） | 否 |
| 是否需要帧缓冲 | 是 | 否 |
| 数据访问模式 | 由管线决定 | 完全自由 |
| 线程间通信 | 有限 | 共享内存+屏障 |
| 适用场景 | 渲染 | 通用计算 |

### 4. 计算着色器的工作模型

#### 4.1 工作组层次

```
全局工作组（Global Work Group）
┌───────────────────────────────────────────────────┐
│                                                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐            │
│  │ 局部工作组│  │ 局部工作组│  │ 局部工作组│            │
│  │ (0,0)   │  │ (1,0)   │  │ (2,0)   │            │
│  │ ┌──┬──┐ │  │ ┌──┬──┐ │  │ ┌──┬──┐ │            │
│  │ │T0│T1│ │  │ │T0│T1│ │  │ │T0│T1│ │            │
│  │ ├──┼──┤ │  │ ├──┼──┤ │  │ ├──┼──┤ │            │
│  │ │T2│T3│ │  │ │T2│T3│ │  │ │T2│T3│ │            │
│  │ └──┴──┘ │  │ └──┴──┘ │  │ └──┴──┘ │            │
│  └─────────┘  └─────────┘  └─────────┘            │
│                                                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐            │
│  │ (0,1)   │  │ (1,1)   │  │ (2,1)   │            │
│  └─────────┘  └─────────┘  └─────────┘            │
└───────────────────────────────────────────────────┘

gl_WorkGroupID      = 局部工作组的ID（如(1,0)）
gl_LocalInvocationID = 组内线程的局部ID（如(0,1)）
gl_GlobalInvocationID = 全局线程ID = 工作组ID × 组大小 + 局部ID
gl_NumWorkGroups    = 工作组总数
gl_WorkGroupSize    = 每个工作组的线程数
```

#### 4.2 GLSL计算着色器基础

```glsl
#version 460 core

// 声明局部工作组大小：8×8×1 = 64个线程
layout(local_size_x = 8, local_size_y = 8, local_size_z = 1) in;

// 输入/输出缓冲区
layout(binding = 0, rgba8) uniform readonly image2D inputImage;
layout(binding = 1, rgba8) uniform writeonly image2D outputImage;

void main() {
    // 计算全局线程ID
    ivec2 pixelCoord = ivec2(gl_GlobalInvocationID.xy);

    // 获取图像尺寸
    ivec2 imageSize = imageSize(inputImage);

    // 边界检查
    if (pixelCoord.x >= imageSize.x || pixelCoord.y >= imageSize.y) {
        return;
    }

    // 读取输入像素
    vec4 color = imageLoad(inputImage, pixelCoord);

    // 处理：灰度转换
    float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));

    // 写入输出
    imageStore(outputImage, pixelCoord, vec4(vec3(gray), color.a));
}
```

#### 4.3 共享内存与同步

```glsl
// 计算着色器中的共享内存（类似CUDA shared memory）
#version 460 core
layout(local_size_x = 256) in;

layout(binding = 0) buffer InputBuffer {
    float data[];
} input_buf;

layout(binding = 1) buffer OutputBuffer {
    float result[];
} output_buf;

// 共享内存：同一工作组内的线程共享
shared float sharedData[256];

void main() {
    uint localIdx = gl_LocalInvocationID.x;
    uint globalIdx = gl_GlobalInvocationID.x;

    // 从全局内存加载到共享内存
    sharedData[localIdx] = input_buf.data[globalIdx];

    // 同步：确保所有线程都完成加载
    barrier();

    // 前缀和计算（Scan）
    for (uint stride = 1; stride < 256; stride *= 2) {
        float val = 0.0;
        if (localIdx >= stride) {
            val = sharedData[localIdx - stride];
        }
        barrier();  // 确保上一轮计算完成
        if (localIdx >= stride) {
            sharedData[localIdx] += val;
        }
        barrier();  // 确保本轮计算完成
    }

    // 写回全局内存
    output_buf.result[globalIdx] = sharedData[localIdx];
}
```

### 5. GPGPU的应用场景

#### 5.1 图像处理

```glsl
// 高斯模糊（分离式：水平+垂直两次pass）
#version 460 core
layout(local_size_x = 16, local_size_y = 16) in;

layout(binding = 0) uniform sampler2D srcImage;
layout(binding = 0, rgba32f) uniform writeonly image2D dstImage;

uniform bool horizontal;

const float weight[5] = float[](
    0.2270270270, 0.1945945946, 0.1216216216,
    0.0540540540, 0.0162162162
);

void main() {
    ivec2 coord = ivec2(gl_GlobalInvocationID.xy);
    vec2 texSize = vec2(textureSize(srcImage, 0));
    vec2 texCoord = (vec2(coord) + 0.5) / texSize;

    // 中心像素
    vec3 result = texture(srcImage, texCoord).rgb * weight[0];

    if (horizontal) {
        for (int i = 1; i < 5; i++) {
            vec2 offset = vec2(float(i), 0.0) / texSize;
            result += texture(srcImage, texCoord + offset).rgb * weight[i];
            result += texture(srcImage, texCoord - offset).rgb * weight[i];
        }
    } else {
        for (int i = 1; i < 5; i++) {
            vec2 offset = vec2(0.0, float(i)) / texSize;
            result += texture(srcImage, texCoord + offset).rgb * weight[i];
            result += texture(srcImage, texCoord - offset).rgb * weight[i];
        }
    }

    imageStore(dstImage, coord, vec4(result, 1.0));
}
```

#### 5.2 粒子系统

```glsl
// 粒子更新计算着色器
#version 460 core
layout(local_size_x = 256) in;

struct Particle {
    vec2 position;
    vec2 velocity;
    vec4 color;
    float life;
    float padding[3];
};

layout(binding = 0) buffer ParticleBuffer {
    Particle particles[];
};

uniform float deltaTime;
uniform vec2 gravity;

void main() {
    uint idx = gl_GlobalInvocationID.x;

    Particle p = particles[idx];

    // 更新速度（加入重力）
    p.velocity += gravity * deltaTime;

    // 更新位置
    p.position += p.velocity * deltaTime;

    // 减少生命值
    p.life -= deltaTime;

    // 如果粒子死亡，重置
    if (p.life <= 0.0) {
        p.position = vec2(0.0, 0.0);
        p.velocity = vec2(
            (float(idx % 100) - 50.0) * 0.02,
            (float(idx / 100) - 50.0) * 0.02
        );
        p.life = 2.0 + fract(sin(float(idx)) * 43758.5453) * 3.0;
        p.color = vec4(1.0, 0.5, 0.1, 1.0);
    }

    // 根据生命值调整透明度
    p.color.a = clamp(p.life, 0.0, 1.0);

    particles[idx] = p;
}
```

#### 5.3 物理模拟

```glsl
// 简单的布料模拟（弹簧-质点模型）
#version 460 core
layout(local_size_x = 32, local_size_y = 32) in;

struct MassPoint {
    vec3 position;
    vec3 velocity;
    vec3 force;
    float mass;
    bool fixed;
};

layout(binding = 0) buffer PointBuffer {
    MassPoint points[];
};

uniform float deltaTime;
uniform float stiffness;
uniform float damping;
uniform int gridWidth;

void main() {
    ivec2 coord = ivec2(gl_GlobalInvocationID.xy);
    int idx = coord.y * gridWidth + coord.x;

    if (idx >= gridWidth * gridWidth) return;

    MassPoint p = points[idx];
    if (p.fixed) return;  // 固定点不移动

    vec3 force = vec3(0.0);

    // 重力
    force += vec3(0.0, -9.81 * p.mass, 0.0);

    // 弹簧力（与相邻4个点的连接）
    ivec2 neighbors[4] = ivec2[](
        coord + ivec2(1, 0), coord + ivec2(-1, 0),
        coord + ivec2(0, 1), coord + ivec2(0, -1)
    );

    for (int i = 0; i < 4; i++) {
        ivec2 nCoord = neighbors[i];
        if (nCoord.x >= 0 && nCoord.x < gridWidth &&
            nCoord.y >= 0 && nCoord.y < gridWidth) {
            int nIdx = nCoord.y * gridWidth + nCoord.x;
            MassPoint neighbor = points[nIdx];

            vec3 diff = neighbor.position - p.position;
            float dist = length(diff);
            vec3 dir = normalize(diff);

            // 胡克定律：F = -k * (dist - restLength) * dir
            float restLength = 1.0;  // 静止长度
            force += stiffness * (dist - restLength) * dir;

            // 阻尼力
            force += damping * (neighbor.velocity - p.velocity);
        }
    }

    // 半隐式欧拉积分
    p.velocity += (force / p.mass) * deltaTime;
    p.position += p.velocity * deltaTime;

    points[idx] = p;
}
```

#### 5.4 排序算法

```glsl
// 双调排序（Bitonic Sort）计算着色器
#version 460 core
layout(local_size_x = 256) in;

layout(binding = 0) buffer DataBuffer {
    uint data[];
};

uniform uint step;    // 当前步骤
uniform uint stage;   // 当前阶段

void main() {
    uint idx = gl_GlobalInvocationID.x;

    // 计算比较伙伴的索引
    uint pairDistance = 1u << (stage - step);
    uint blockWidth = 2u << step;

    uint leftIdx = (idx / blockWidth) * blockWidth + idx % (blockWidth / 2);
    uint rightIdx = leftIdx + pairDistance;

    uint leftVal = data[leftIdx];
    uint rightVal = data[rightIdx];

    // 确定排序方向
    bool ascending = ((idx / (1u << stage)) % 2) == 0;

    // 比较并交换
    if (ascending) {
        if (leftVal > rightVal) {
            data[leftIdx] = rightVal;
            data[rightIdx] = leftVal;
        }
    } else {
        if (leftVal < rightVal) {
            data[leftIdx] = rightVal;
            data[rightIdx] = leftVal;
        }
    }
}
```

### 6. 计算着色器与CUDA的对比

| 维度 | 计算着色器 | CUDA |
|------|-----------|------|
| 所属 | 图形API（OpenGL/Vulkan/DirectX） | NVIDIA专有平台 |
| 硬件支持 | 所有GPU | 仅NVIDIA GPU |
| 语言 | GLSL/HLSL/MSL | CUDA C/C++ |
| 线程组织 | 工作组(Work Group) | Grid/Block/Thread |
| 共享内存 | `shared` | `__shared__` |
| 同步 | `barrier()` | `__syncthreads()` |
| 与图形集成 | 天然集成 | 需要互操作 |
| 生态/库 | 较少 | 丰富（cuBLAS/cuDNN等） |
| 调试 | RenderDoc/NSight | Nsight/cu-gdb |
| 学习曲线 | 需要先学图形API | 独立学习 |

```glsl
// 计算着色器（GLSL）
layout(local_size_x = 256) in;
shared float sdata[256];

void main() {
    uint tid = gl_LocalInvocationID.x;
    sdata[tid] = data[gl_GlobalInvocationID.x];
    barrier();
    // ... 计算
}

// CUDA等价代码
__global__ void kernel(float* data) {
    __shared__ float sdata[256];
    int tid = threadIdx.x;
    sdata[tid] = data[blockIdx.x * blockDim.x + threadIdx.x];
    __syncthreads();
    // ... 计算
}
```

### 7. OpenGL中使用计算着色器

```cpp
// C++端：创建和使用计算着色器
#include <glad/glad.h>

// 编译计算着色器
GLuint createComputeShader(const char* source) {
    GLuint shader = glCreateShader(GL_COMPUTE_SHADER);
    glShaderSource(shader, 1, &source, NULL);
    glCompileShader(shader);

    GLuint program = glCreateProgram();
    glAttachShader(program, shader);
    glLinkProgram(program);

    return program;
}

// 使用计算着色器
void dispatchCompute(GLuint program, int width, int height) {
    glUseProgram(program);

    // 绑定纹理/缓冲区
    glBindImageTexture(0, inputTexture, 0, GL_FALSE, 0, GL_READ_ONLY, GL_RGBA8);
    glBindImageTexture(1, outputTexture, 0, GL_FALSE, 0, GL_WRITE_ONLY, GL_RGBA8);

    // 计算工作组数量（向上取整）
    int localSizeX = 8, localSizeY = 8;  // 与着色器中声明的一致
    int numGroupsX = (width + localSizeX - 1) / localSizeX;
    int numGroupsY = (height + localSizeY - 1) / localSizeY;

    // 派发计算
    glDispatchCompute(numGroupsX, numGroupsY, 1);

    // 等待计算完成
    glMemoryBarrier(GL_SHADER_IMAGE_ACCESS_BARRIER_BIT);
}
```

### 8. 常见误区

| 误区 | 事实 |
|------|------|
| 计算着色器可以替代所有图形管线 | 渲染仍然需要图形管线，计算着色器做辅助 |
| 计算着色器比片段着色器快 | 取决于场景，后处理两者性能接近 |
| 计算着色器不需要同步 | 工作组内需要`barrier()`，组间需要内存屏障 |
| 计算着色器可以替代CUDA | 功能上可以，但CUDA生态和工具链更成熟 |
| 计算着色器是新技术 | OpenGL 4.3（2012年）就引入了 |

***

### 9. 总结

| 维度 | 核心要点 |
|------|---------|
| 本质 | GPU上的通用并行计算，脱离图形管线 |
| 线程模型 | 全局工作组→局部工作组→线程 |
| 通信方式 | 共享内存 + barrier() 同步 |
| 与图形管线 | 独立执行，通过缓冲区/纹理交换数据 |
| 与CUDA | 功能类似，但跨平台且与图形集成更好 |

**核心记忆**：计算着色器 = GPU通用计算的图形API方案。不需要顶点、不需要光栅化，直接告诉GPU"数据在这、怎么算"，就能做图像处理、物理模拟、排序等任何并行计算。
