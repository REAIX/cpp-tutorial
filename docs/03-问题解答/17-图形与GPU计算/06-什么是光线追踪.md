# 什么是光线追踪
> 📖 相关章节：[图形编程概述](../../11-图形与GPU计算/00-图形编程概述.md)

> **光线追踪就是从眼睛出发，逆向追踪光的路径——现实中光从光源出发打到物体再进入眼睛，光线追踪反过来，从眼睛出发找光源。** 这种"逆向思维"让它能精确模拟反射、折射、阴影等真实光学效果。

***

### 1. 一句话概括

**光线追踪（Ray Tracing）** 是一种渲染技术，通过从相机发射光线、检测与场景中物体的交点、递归追踪反射和折射光线来计算像素颜色。它能产生物理上正确的光影效果，但计算量极大——直到硬件RT核心的出现，才让实时光线追踪成为可能。

***

### 2. 生活类比

| 类比 | 说明 |
|------|------|
| 光栅化 = 画家画画 | 先画轮廓再填色，快速但不够真实 |
| 光线追踪 = 照相机拍照 | 模拟光的物理传播，慢但真实 |
| 光线 = 视线 | 你看到什么，光线就追踪到什么 |
| 反射 = 镜子 | 光线碰到镜子后改变方向继续追踪 |
| 折射 = 水面 | 光线穿过水面时弯折 |
| 阴影 = 遮挡 | 光线被挡住的地方就是阴影 |

**具体场景**：站在房间里看一面镜子——光栅化需要额外技术模拟镜面反射，光线追踪只需"光线碰到镜子后改变方向继续追踪"，自然得到真实反射。

***

### 3. 光线追踪原理

#### 3.1 基本算法

```
对于屏幕上的每个像素：
1. 从相机发射一条光线穿过该像素
2. 找到光线与场景中最近的交点
3. 在交点处：
   a. 计算直接光照（从交点向光源发射阴影光线）
   b. 如果表面有反射，递归发射反射光线
   c. 如果表面有折射，递归发射折射光线
4. 将所有贡献相加，得到该像素的颜色

递归终止条件：
- 光线离开场景（到达天空盒）
- 达到最大递归深度
- 光线能量低于阈值
```

#### 3.2 伪代码

```cpp
// 光线追踪核心算法
struct Ray {
    Vec3 origin;     // 光线起点
    Vec3 direction;  // 光线方向（单位向量）
};

struct HitInfo {
    float t;         // 交点距离
    Vec3 point;      // 交点位置
    Vec3 normal;     // 交点法线
    Material material; // 交点材质
};

// 追踪一条光线，返回颜色
Vec3 traceRay(const Ray& ray, const Scene& scene, int depth) {
    if (depth <= 0) {
        return Vec3(0.0f);  // 超过最大深度，返回黑色
    }

    // 找到最近的交点
    HitInfo hit;
    if (!scene.intersect(ray, hit)) {
        return scene.skyColor(ray.direction);  // 没有交点，返回天空颜色
    }

    Vec3 color(0.0f);

    // 1. 环境光
    color += hit.material.ambient * hit.material.albedo;

    // 2. 对每个光源计算直接光照
    for (const auto& light : scene.lights) {
        // 从交点向光源发射阴影光线
        Vec3 toLight = light.position - hit.point;
        float distToLight = length(toLight);
        Vec3 lightDir = toLight / distToLight;

        Ray shadowRay = {hit.point + hit.normal * 0.001f, lightDir};
        HitInfo shadowHit;

        // 如果阴影光线被遮挡，该光源不贡献光照
        if (scene.intersect(shadowRay, shadowHit) && shadowHit.t < distToLight) {
            continue;  // 在阴影中
        }

        // 漫反射（Lambert）
        float NdotL = max(dot(hit.normal, lightDir), 0.0f);
        color += hit.material.diffuse * hit.material.albedo * light.color * NdotL;

        // 镜面反射（Blinn-Phong）
        Vec3 viewDir = normalize(-ray.direction);
        Vec3 halfDir = normalize(lightDir + viewDir);
        float NdotH = max(dot(hit.normal, halfDir), 0.0f);
        float spec = pow(NdotH, hit.material.shininess);
        color += hit.material.specular * light.color * spec;
    }

    // 3. 递归追踪反射光线
    if (hit.material.reflectivity > 0.0f && depth > 0) {
        Vec3 reflectDir = reflect(ray.direction, hit.normal);
        Ray reflectRay = {hit.point + hit.normal * 0.001f, reflectDir};
        Vec3 reflectColor = traceRay(reflectRay, scene, depth - 1);
        color += hit.material.reflectivity * reflectColor;
    }

    // 4. 递归追踪折射光线（透明材质）
    if (hit.material.transparency > 0.0f && depth > 0) {
        Vec3 refractDir = refract(ray.direction, hit.normal, hit.material.ior);
        Ray refractRay = {hit.point - hit.normal * 0.001f, refractDir};
        Vec3 refractColor = traceRay(refractRay, scene, depth - 1);
        color += hit.material.transparency * refractColor;
    }

    return color;
}
```

#### 3.3 光线与基本几何体的求交

```cpp
// 光线与球体求交
bool intersectSphere(const Ray& ray, const Sphere& sphere, float& t) {
    Vec3 oc = ray.origin - sphere.center;
    float a = dot(ray.direction, ray.direction);           // |d|²
    float b = 2.0f * dot(oc, ray.direction);               // 2(o·d)
    float c = dot(oc, oc) - sphere.radius * sphere.radius; // |o|²-r²

    float discriminant = b * b - 4.0f * a * c;
    if (discriminant < 0.0f) return false;  // 无交点

    float sqrtD = sqrt(discriminant);
    float t0 = (-b - sqrtD) / (2.0f * a);  // 近交点
    float t1 = (-b + sqrtD) / (2.0f * a);  // 远交点

    if (t0 > 0.001f) { t = t0; return true; }
    if (t1 > 0.001f) { t = t1; return true; }
    return false;
}

// 光线与三角形求交（Möller-Trumbore算法）
bool intersectTriangle(const Ray& ray, const Triangle& tri, float& t) {
    Vec3 edge1 = tri.v1 - tri.v0;
    Vec3 edge2 = tri.v2 - tri.v0;
    Vec3 h = cross(ray.direction, edge2);
    float a = dot(edge1, h);

    if (fabs(a) < 1e-8f) return false;  // 光线与三角形平行

    float f = 1.0f / a;
    Vec3 s = ray.origin - tri.v0;
    float u = f * dot(s, h);
    if (u < 0.0f || u > 1.0f) return false;

    Vec3 q = cross(s, edge1);
    float v = f * dot(ray.direction, q);
    if (v < 0.0f || u + v > 1.0f) return false;

    t = f * dot(edge2, q);
    return t > 0.001f;
}
```

### 4. BVH加速结构

#### 4.1 为什么需要加速结构

```
暴力求交的问题：
- 场景有100万个三角形
- 屏幕有200万个像素
- 总计：200万 × 100万 = 2万亿次求交测试
- 即使每次1ns，也需要2000秒！

BVH的解决思路：
- 把空间划分为层次包围盒
- 光线先与包围盒求交（极快）
- 只有穿过包围盒的光线才与内部三角形求交
- 典型加速：从O(n)降到O(log n)
```

#### 4.2 BVH结构

```
场景BVH示例：

            [整个场景包围盒]
           /                  \
    [左半部分包围盒]      [右半部分包围盒]
    /          \           /          \
[物体A]    [物体B]    [物体C]    [物体D,E包围盒]
                                   /        \
                              [物体D]    [物体E]

光线追踪过程：
1. 光线与根节点包围盒求交 → 命中
2. 与左子树求交 → 命中
3. 与物体A求交 → 命中，t=5.0
4. 与物体B求交 → 未命中
5. 与右子树求交 → 未命中（跳过整个右子树！）
6. 最终结果：与物体A相交，t=5.0

只需5次包围盒测试 + 2次三角形测试，而非5次三角形测试
```

#### 4.3 BVH构建

```cpp
// 简化的BVH构建（中点分割法）
struct BVHNode {
    AABB bounds;       // 包围盒
    int leftChild;     // 左子节点索引（-1表示叶子）
    int rightChild;    // 右子节点索引
    int firstTriangle; // 叶子节点：起始三角形索引
    int triangleCount; // 叶子节点：三角形数量
};

int buildBVH(std::vector<BVHNode>& nodes,
             std::vector<Triangle>& triangles,
             int start, int end) {
    BVHNode node;

    // 计算所有三角形的包围盒
    node.bounds = computeBounds(triangles, start, end);

    int count = end - start;
    if (count <= 4) {
        // 叶子节点：直接存储三角形
        node.leftChild = -1;
        node.firstTriangle = start;
        node.triangleCount = count;
        nodes.push_back(node);
        return nodes.size() - 1;
    }

    // 选择分割轴（选择包围盒最长的轴）
    int axis = node.bounds.longestAxis();
    float mid = node.bounds.center(axis);

    // 按中点分割
    int midIndex = start;
    for (int i = start; i < end; i++) {
        if (triangles[i].centroid(axis) < mid) {
            std::swap(triangles[i], triangles[midIndex]);
            midIndex++;
        }
    }

    // 如果分割失败（所有三角形在同一侧），强制对半分
    if (midIndex == start || midIndex == end) {
        midIndex = (start + end) / 2;
    }

    // 递归构建子树
    node.leftChild = buildBVH(nodes, triangles, start, midIndex);
    node.rightChild = buildBVH(nodes, triangles, midIndex, end);
    node.triangleCount = 0;  // 内部节点没有三角形

    nodes.push_back(node);
    return nodes.size() - 1;
}
```

#### 4.4 BVH遍历

```cpp
// BVH遍历求交
bool intersectBVH(const Ray& ray, const BVHNode* nodes,
                  const Triangle* triangles, HitInfo& hit, int nodeIdx) {
    const BVHNode& node = nodes[nodeIdx];

    // 先与包围盒求交
    if (!intersectAABB(ray, node.bounds)) {
        return false;
    }

    // 叶子节点：与三角形求交
    if (node.leftChild == -1) {
        bool found = false;
        for (int i = 0; i < node.triangleCount; i++) {
            float t;
            if (intersectTriangle(ray, triangles[node.firstTriangle + i], t)) {
                if (t < hit.t) {
                    hit.t = t;
                    found = true;
                }
            }
        }
        return found;
    }

    // 内部节点：递归遍历子树
    bool hitLeft = intersectBVH(ray, nodes, triangles, hit, node.leftChild);
    bool hitRight = intersectBVH(ray, nodes, triangles, hit, node.rightChild);

    return hitLeft || hitRight;
}
```

### 5. 实时光线追踪（RT核心）

#### 5.1 硬件加速原理

```
传统软件光线追踪（GPU计算着色器）：
光线求交 → 软件遍历BVH → 软件三角形测试
速度：每条光线约100-500个周期

RT核心硬件加速：
光线求交 → RT核心遍历BVH → RT核心三角形测试
速度：每条光线约10-50个周期（10-50倍加速）

NVIDIA RT核心的功能：
1. BVH遍历加速（硬件实现包围盒测试）
2. 光线-三角形求交加速（硬件实现Möller-Trumbore）
3. 与流处理器并行工作（异步执行）
```

// Vulkan光线追踪着色器

// 光线生成着色器
#version 460
#extension GL_EXT_ray_tracing : require

layout(binding = 0, set = 0) uniform accelerationStructureEXT topLevelAS;
layout(binding = 1, set = 0) uniform CameraData {
    mat4 viewInverse;
    mat4 projInverse;
} camera;

layout(location = 0) rayPayloadEXT vec3 hitColor;

void main() {
    // 计算光线方向
    const vec2 pixelCenter = vec2(gl_LaunchIDEXT.xy) + vec2(0.5);
    const vec2 inUV = pixelCenter / vec2(gl_LaunchSizeEXT.xy);
    vec2 d = inUV * 2.0 - 1.0;

    vec4 origin = camera.viewInverse * vec4(0, 0, 0, 1);
    vec4 target = camera.projInverse * vec4(d.x, d.y, 1, 1);
    vec4 direction = camera.viewInverse * vec4(normalize(target.xyz), 0);

    // 发射光线
    uint flags = gl_RayFlagsOpaqueEXT;
    float tMin = 0.001;
    float tMax = 10000.0;

    traceRayEXT(topLevelAS, flags, 0xFF, 0, 0, 0,
                origin.xyz, tMin, direction.xyz, tMax, 0);

    // 输出颜色
    imageStore(resultImage, ivec2(gl_LaunchIDEXT.xy), vec4(hitColor, 1.0));
}

// 最近命中着色器
#version 460
#extension GL_EXT_ray_tracing : require

hitAttributeEXT vec2 barycentricCoord;

layout(location = 0) rayPayloadInEXT vec3 hitColor;

void main() {
    // 计算交点处的颜色
    vec3 bary = vec3(1.0 - barycentricCoord.x - barycentricCoord.y,
                     barycentricCoord.x, barycentricCoord.y);
    hitColor = bary.x * vertexColor[0] + bary.y * vertexColor[1] + bary.z * vertexColor[2];
}

// 未命中着色器
#version 460
#extension GL_EXT_ray_tracing : require

layout(location = 0) rayPayloadInEXT vec3 hitColor;

void main() {
    hitColor = vec3(0.5, 0.7, 1.0);  // 天空蓝色

### 6. 光追 vs 光栅化

| 维度 | 光栅化 | 光线追踪 |
|------|--------|---------|
| 原理 | 投影三角形到屏幕，逐像素填充 | 从像素发射光线，追踪光路 |
| 反射 | 需要额外技术（环境映射/SSR） | 自然支持，递归追踪即可 |
| 阴影 | 阴影贴图（有锯齿/走样） | 精确硬阴影，软阴影需多次采样 |
| 折射 | 极难实现 | 自然支持 |
| 全局光照 | 需要近似（GI体积/探针） | 路径追踪自然实现 |
| 性能 | 极快（硬件高度优化） | 慢（计算量大） |
| 质量 | 足够好，但有瑕疵 | 物理正确，照片级 |
| 适用场景 | 实时游戏 | 离线渲染/高端实时 |

#### 6.1 混合方案：光栅化 + 光追

```
现代游戏引擎的典型方案：

1. 光栅化：渲染基础几何体（G-Buffer）
2. 光追反射：仅对反射面发射光线
3. 光追阴影：仅对关键光源发射阴影光线
4. 光追全局光照：仅对少量采样点追踪间接光
5. 降噪：对光追结果进行时域/空域降噪

优势：光栅化处理主要渲染，光追只处理需要高质量效果的部分
```

### 7. 路径追踪：光追的蒙特卡洛扩展

```cpp
// 路径追踪：通过随机采样实现全局光照
Vec3 pathTrace(const Ray& ray, const Scene& scene, int depth, RNG& rng) {
    if (depth <= 0) return Vec3(0.0f);

    HitInfo hit;
    if (!scene.intersect(ray, hit)) {
        return scene.environmentMap(ray.direction);
    }

    Vec3 emitted = hit.material.emissive;  // 自发光
    Vec3 color(0.0f);

    // 俄罗斯轮盘赌：随机终止路径
    float continueProb = min(1.0f, maxComponent(hit.material.albedo));
    if (rng.random() > continueProb) return emitted;
    float pdf = 1.0f / continueProb;

    // 在交点处随机采样一个方向
    Vec3 wi = hit.material.sampleDirection(hit.normal, rng);
    float cosTheta = dot(hit.normal, wi);
    if (cosTheta <= 0.0f) return emitted;

    // 计算BRDF
    Vec3 f = hit.material.evaluate(ray.direction, wi, hit.normal);

    // 递归追踪
    Ray newRay = {hit.point + hit.normal * 0.001f, wi};
    Vec3 incoming = pathTrace(newRay, scene, depth - 1, rng);

    // 渲染方程
    color = emitted + f * incoming * cosTheta / (pdf * hit.material.pdf(wi));

    return color;
}

// 对每个像素多次采样取平均
Vec3 renderPixel(int x, int y, const Scene& scene, int samples) {
    Vec3 color(0.0f);
    RNG rng(x * 7919 + y * 104729);

    for (int s = 0; s < samples; s++) {
        Ray ray = camera.generateRay(x, y, rng);
        color += pathTrace(ray, scene, 5, rng);
    }

    return color / float(samples);  // 蒙特卡洛估计
}
```

### 8. 常见误区

| 误区 | 事实 |
|------|------|
| 光追完全替代光栅化 | 当前是混合方案，光栅化仍是基础 |
| RTX卡才能跑光追 | 软件光追任何GPU都行，RT核心只是加速 |
| 光追一定比光栅化好看 | 采样不足时光追噪点严重 |
| 光追只用于反射和阴影 | 路径追踪能实现完整全局光照 |

### 9. 总结

| 概念 | 核心要点 |
|------|---------|
| 光线追踪原理 | 从相机发射光线，逆向追踪光路 |
| BVH加速 | 层次包围盒，将求交从O(n)降到O(log n) |
| RT核心 | 硬件加速BVH遍历和三角形求交 |
| 光追vs光栅化 | 光追质量高但慢，光栅化快但有瑕疵 |
| 路径追踪 | 蒙特卡洛采样的光追，实现完整全局光照 |

**核心记忆**：光线追踪 = 逆向追踪光路 + 递归反射/折射 + BVH加速 + RT核心硬件加速。它是渲染的"正确"方法，但计算量大，现代方案是光栅化+光追混合。
