## 1. 平衡树

### 1. 问题引入

在[C语言模块](../01-C语言/26-链表与数据结构.md)中，我们学习了二叉搜索树（BST）。BST在理想情况下查找效率为O(log n)，但如果按有序序列插入，BST会退化为链表，查找效率降为O(n)。

```
理想BST（平衡）：        退化BST（链表）：
       4                    1
      / \                    \
     2   6                    2
    / \ / \                    \
   1  3 5  7                    3
                                  \
                                   4
                                    \
                                     5
                                      \
                                       6
                                        \
                                         7

查找效率：O(log n)          查找效率：O(n)
```

**平衡树**就是为了解决BST退化问题而生的——通过旋转操作，始终保持树的"矮胖"形态。

---

### 2. AVL树

#### 1. 思想

AVL树是最早被发明的自平衡二叉搜索树，由Adelson-Velsky和Landis于1962年提出。

**核心规则**：每个节点的左右子树高度差（平衡因子）的绝对值不超过1。

**平衡因子（Balance Factor）**：`BF = 左子树高度 - 右子树高度`

- BF ∈ {-1, 0, 1} → 平衡
- BF = 2 或 BF = -2 → 失衡，需要旋转修复

#### 2. 四种旋转操作

失衡时，根据插入位置与失衡节点的关系，分为四种情况：

| 失衡类型 | 平衡因子 | 插入位置 | 修复操作 |
|---------|---------|---------|---------|
| LL（左左） | BF=2, 左子BF=1 | 左子树的左子 | 右旋 |
| RR（右右） | BF=-2, 右子BF=-1 | 右子树的右子 | 左旋 |
| LR（左右） | BF=2, 左子BF=-1 | 左子树的右子 | 先左旋再右旋 |
| RL（右左） | BF=-2, 右子BF=1 | 右子树的左子 | 先右旋再左旋 |

**右旋图示（LL型）：**
```
     5(BF=2)              3(BF=0)
    /                     / \
   3(BF=1)    →          2   5
  /
 2
```

**先左旋再右旋图示（LR型）：**
```
     5(BF=2)          5(BF=2)          4(BF=0)
    /                 /                 / \
   2(BF=-1)   →     4(BF=1)    →     2   5
    \               /
     4             2
```

#### 3. C++实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct AVLNode {
    int key;
    int height;
    AVLNode* left;
    AVLNode* right;
    AVLNode(int k) : key(k), height(1), left(nullptr), right(nullptr) {}
};

int get_height(AVLNode* node) {
    return node ? node->height : 0;
}

int get_balance(AVLNode* node) {
    return node ? get_height(node->left) - get_height(node->right) : 0;
}

void update_height(AVLNode* node) {
    if (node) {
        node->height = 1 + max(get_height(node->left), get_height(node->right));
    }
}

AVLNode* rotate_right(AVLNode* y) {
    AVLNode* x = y->left;
    AVLNode* T2 = x->right;
    x->right = y;
    y->left = T2;
    update_height(y);
    update_height(x);
    return x;
}

AVLNode* rotate_left(AVLNode* x) {
    AVLNode* y = x->right;
    AVLNode* T2 = y->left;
    y->left = x;
    x->right = T2;
    update_height(x);
    update_height(y);
    return y;
}

AVLNode* rebalance(AVLNode* node) {
    update_height(node);
    int bf = get_balance(node);

    // LL型：左子树过深，且左子树的左子树更深
    if (bf > 1 && get_balance(node->left) >= 0) {
        return rotate_right(node);
    }
    // LR型：左子树过深，但左子树的右子树更深
    if (bf > 1 && get_balance(node->left) < 0) {
        node->left = rotate_left(node->left);
        return rotate_right(node);
    }
    // RR型：右子树过深，且右子树的右子树更深
    if (bf < -1 && get_balance(node->right) <= 0) {
        return rotate_left(node);
    }
    // RL型：右子树过深，但右子树的左子树更深
    if (bf < -1 && get_balance(node->right) > 0) {
        node->right = rotate_right(node->right);
        return rotate_left(node);
    }
    return node;
}

AVLNode* avl_insert(AVLNode* root, int key) {
    if (!root) return new AVLNode(key);
    if (key < root->key) {
        root->left = avl_insert(root->left, key);
    } else if (key > root->key) {
        root->right = avl_insert(root->right, key);
    } else {
        return root; // 不插入重复值
    }
    return rebalance(root);
}

AVLNode* find_min(AVLNode* node) {
    while (node->left) node = node->left;
    return node;
}

AVLNode* avl_delete(AVLNode* root, int key) {
    if (!root) return nullptr;
    if (key < root->key) {
        root->left = avl_delete(root->left, key);
    } else if (key > root->key) {
        root->right = avl_delete(root->right, key);
    } else {
        // 找到要删除的节点
        if (!root->left || !root->right) {
            AVLNode* temp = root->left ? root->left : root->right;
            delete root;
            return temp;
        }
        // 有两个子节点：用右子树最小值替换
        AVLNode* temp = find_min(root->right);
        root->key = temp->key;
        root->right = avl_delete(root->right, temp->key);
    }
    return rebalance(root);
}

void inorder(AVLNode* root) {
    if (root) {
        inorder(root->left);
        cout << root->key << "(h=" << root->height << ") ";
        inorder(root->right);
    }
}

int main() {
    AVLNode* root = nullptr;
    // 按序插入1~7，如果不平衡会退化为链表
    // 但AVL树会自动旋转保持平衡
    for (int i = 1; i <= 7; i++) {
        root = avl_insert(root, i);
    }
    cout << "中序遍历：";
    inorder(root);
    cout << endl;
    // 删除节点后自动重平衡
    root = avl_delete(root, 3);
    cout << "删除3后：";
    inorder(root);
    cout << endl;
    return 0;
}
```

#### 4. 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 查找 | O(log n) | O(1) |
| 插入 | O(log n) | O(1) |
| 删除 | O(log n) | O(1) |

#### 5. 适用场景

- 查找密集型场景（查找远多于插入/删除）
- 需要严格平衡保证最坏情况性能
- 数据库内存索引

### 3. 红黑树

#### 1. 思想

红黑树是一种"近似平衡"的二叉搜索树，通过着色规则和旋转来维持平衡。它不像AVL树那样追求严格平衡，而是保证**最长路径不超过最短路径的2倍**，从而减少了旋转次数。

#### 2. 五条规则

1. 每个节点非红即黑
2. 根节点是黑色
3. 叶子节点（NIL）是黑色
4. 红色节点的两个子节点必须是黑色（不能有连续红节点）
5. 从任一节点到其所有叶子节点的路径上，黑色节点数量相同（黑高相同）

**为什么这5条规则能保证平衡？**

规则4确保没有两个红色节点相邻 → 最长路径（红黑交替）最多是最短路径（全黑）的2倍 → 树高 ≤ 2·log₂(n+1) → 查找O(log n)。

#### 3. 插入修复的3种情况

新插入的节点默认为红色（避免违反规则5）。插入后若违反规则4（父节点也是红色），需修复：

| 情况 | 叔叔节点颜色 | 操作 |
|------|------------|------|
| 情况1 | 红色 | 将父和叔改为黑色，祖父改为红色，向上递归 |
| 情况2 | 黑色，且当前节点是"内侧"子节点 | 对父节点旋转，转化为情况3 |
| 情况3 | 黑色，且当前节点是"外侧"子节点 | 对祖父旋转，交换父和祖父的颜色 |

```
情况1：叔叔是红色
       G(黑)                    G(红) ← 继续向上修复
      /   \                    /   \
    P(红)  U(红)    →       P(黑)  U(黑)
   /                        /
  N(红)                    N(红)

情况3：叔叔是黑色，N是外侧子节点
       G(黑)                 P(黑)
      /   \                 /   \
    P(红)  U(黑)    →     N(红)  G(红)
   /                               \
  N(红)                             U(黑)
```

#### 4. 为什么STL的map/set用红黑树而非AVL树？

| 对比维度 | AVL树 | 红黑树 |
|---------|-------|--------|
| 平衡严格度 | 严格（高度差≤1） | 近似（最长≤2倍最短） |
| 查找效率 | 略优（更矮） | 略逊 |
| 插入/删除旋转次数 | 较多（最多O(log n)次旋转） | 较少（插入最多2次，删除最多3次旋转） |
| 适用场景 | 查找密集 | 插入/删除频繁 |
| STL选择 | — | ✅ 综合性能更优 |

**STL选择红黑树的原因**：实际应用中插入/删除操作往往比查找更频繁，红黑树在增删时旋转次数少，综合性能更优。

#### 5. 适用场景

- 需要兼顾查找和增删的综合性能（STL map/set底层）
- 操作系统内核的进程调度（CFS公平调度器）
- 内存管理（伙伴系统的替代）

### 2. 二叉堆

#### 1. 思想

二叉堆是一棵满足**堆性质**的完全二叉树：
- **最大堆**：每个节点 ≥ 其子节点 → 根节点最大
- **最小堆**：每个节点 ≤ 其子节点 → 根节点最小

用数组存储（下标从0开始）：
- 父节点：`(i - 1) / 2`
- 左子节点：`2 * i + 1`
- 右子节点：`2 * i + 2`

#### 2. 两个核心操作

**上浮（sift up）**：插入新元素后，从底部向上调整，恢复堆性质。

```
插入20到最大堆：
[50, 30, 40, 10, 20, 35]  →  [50, 30, 40, 10, 20, 35, 20]（先放末尾）
                                          ↑ 新元素
20比父35小，不动 → 堆性质已满足

若插入60：
[50, 30, 40, 10, 20, 35, 60]  → 60>35，上浮
[50, 30, 60, 10, 20, 35, 40]  → 60>50，继续上浮
[60, 30, 50, 10, 20, 35, 40]  → 60是根，停止
```

**下沉（sift down）**：删除堆顶后，将末尾元素移到堆顶，向下调整恢复堆性质。

```
删除最大堆堆顶60：
[60, 30, 50, 10, 20, 35, 40]  → 末尾40移到堆顶
[40, 30, 50, 10, 20, 35]      → 40<50，与较大子节点交换
[50, 30, 40, 10, 20, 35]      → 40>35，停止
```

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

class MaxHeap {
private:
    vector<int> data;

    void sift_up(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (data[i] > data[parent]) {
                swap(data[i], data[parent]);
                i = parent;
            } else {
                break;
            }
        }
    }

    void sift_down(int i) {
        int n = data.size();
        while (true) {
            int largest = i;
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            if (left < n && data[left] > data[largest]) largest = left;
            if (right < n && data[right] > data[largest]) largest = right;
            if (largest != i) {
                swap(data[i], data[largest]);
                i = largest;
            } else {
                break;
            }
        }
    }

public:
    void push(int val) {
        data.push_back(val);
        sift_up(data.size() - 1);
    }

    void pop() {
        if (data.empty()) return;
        data[0] = data.back();
        data.pop_back();
        if (!data.empty()) sift_down(0);
    }

    int top() const { return data.empty() ? -1 : data[0]; }
    bool empty() const { return data.empty(); }
    int size() const { return data.size(); }
};

int main() {
    MaxHeap heap;
    int arr[] = {3, 1, 6, 5, 2, 4};
    for (int x : arr) heap.push(x);
    cout << "堆顶（最大值）：" << heap.top() << endl; // 6
    cout << "依次弹出：";
    while (!heap.empty()) {
        cout << heap.top() << " ";
        heap.pop();
    }
    cout << endl;
    return 0;
}
```

#### 4. 复杂度分析

| 操作 | 时间复杂度 |
|-----|-----------|
| 插入（push） | O(log n) |
| 删除堆顶（pop） | O(log n) |
| 获取堆顶（top） | O(1) |
| 建堆 | O(n) |

### 3. 优先队列

#### 1. 思想

优先队列是堆的抽象接口：元素按优先级出队，而非按入队顺序。C++ STL提供了`std::priority_queue`。

#### 2. C++ std::priority_queue用法

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <functional> // greater
using namespace std;

int main() {
    // 默认是最大堆
    priority_queue<int> max_pq;
    max_pq.push(3);
    max_pq.push(1);
    max_pq.push(6);
    cout << "最大堆顶部：" << max_pq.top() << endl; // 6

    // 最小堆：传入greater比较器
    priority_queue<int, vector<int>, greater<int>> min_pq;
    min_pq.push(3);
    min_pq.push(1);
    min_pq.push(6);
    cout << "最小堆顶部：" << min_pq.top() << endl; // 1

    // 自定义类型的优先队列
    struct Task {
        int priority;
        string name;
        bool operator>(const Task& other) const {
            return priority > other.priority; // 优先级数值小的先出
        }
    };
    priority_queue<Task, vector<Task>, greater<Task>> task_pq;
    task_pq.push({1, "紧急任务"});
    task_pq.push({3, "普通任务"});
    task_pq.push({2, "重要任务"});
    while (!task_pq.empty()) {
        cout << "执行：" << task_pq.top().name
             << "（优先级=" << task_pq.top().priority << "）" << endl;
        task_pq.pop();
    }
    return 0;
}
```

### 4. Top-K问题

#### 1. 问题

给定n个整数，找出其中最大的前K个。

#### 2. 思想

维护一个大小为K的**最小堆**：
1. 先用前K个元素建最小堆
2. 对剩余每个元素：若大于堆顶，替换堆顶并下沉
3. 最终堆中就是最大的K个元素

**为什么用最小堆？** 堆顶是K个元素中的最小值，新元素只需和"门槛"比较即可。

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

vector<int> top_k_largest(const vector<int>& nums, int k) {
    // 最小堆，堆顶是K个元素中的最小值
    priority_queue<int, vector<int>, greater<int>> min_heap;
    for (int i = 0; i < (int)nums.size(); i++) {
        if ((int)min_heap.size() < k) {
            min_heap.push(nums[i]);
        } else if (nums[i] > min_heap.top()) {
            min_heap.pop();
            min_heap.push(nums[i]);
        }
    }
    vector<int> result;
    while (!min_heap.empty()) {
        result.push_back(min_heap.top());
        min_heap.pop();
    }
    return result;
}

int main() {
    vector<int> nums = {3, 1, 6, 5, 2, 4, 8, 7, 9, 0};
    int k = 3;
    vector<int> result = top_k_largest(nums, k);
    cout << "前" << k << "大的元素：";
    for (int x : result) cout << x << " ";
    cout << endl;
    return 0;
}
```

#### 4. 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 排序法 | O(n log n) | O(1) |
| 最小堆法 | O(n log k) | O(k) |

当 k << n 时，最小堆法远优于排序法。

### 5. 堆排序回顾

### 2. Dijkstra最短路径

#### 1. 问题

给定一个带权有向图和一个起点，求起点到其他所有节点的最短路径。

#### 2. 思想

Dijkstra算法采用**贪心策略**：每次选择当前距离最短的未访问节点，用它更新邻居的距离。

**关键洞察**：如果所有边权非负，那么当前最近的节点，其最短距离已经确定，不可能被更优路径替代。

**优先队列优化**：用最小堆存储`{距离, 节点}`，每次取距离最小的节点，时间复杂度从O(V²)降到O((V+E)log V)。

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
using namespace std;

const int INF = INT_MAX;

struct Edge {
    int to;
    int weight;
};

vector<int> dijkstra(int n, const vector<vector<Edge>>& graph, int start) {
    vector<int> dist(n, INF);
    dist[start] = 0;
    // 最小堆：{距离, 节点}
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    pq.push({0, start});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        // 已有更短路径，跳过
        if (d > dist[u]) continue;
        for (const auto& e : graph[u]) {
            int v = e.to;
            int new_dist = dist[u] + e.weight;
            if (new_dist < dist[v]) {
                dist[v] = new_dist;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

int main() {
    int n = 5; // 5个节点，编号0~4
    vector<vector<Edge>> graph(n);
    // 建图：邻接表
    graph[0].push_back({1, 10});
    graph[0].push_back({2, 3});
    graph[1].push_back({2, 1});
    graph[1].push_back({3, 2});
    graph[2].push_back({1, 4});
    graph[2].push_back({3, 8});
    graph[2].push_back({4, 2});
    graph[3].push_back({4, 5});
    graph[4].push_back({3, 5});

    vector<int> dist = dijkstra(n, graph, 0);
    cout << "从节点0出发的最短距离：" << endl;
    for (int i = 0; i < n; i++) {
        cout << "  到节点" << i << "：" << (dist[i] == INF ? -1 : dist[i]) << endl;
    }
    return 0;
}
```

#### 4. 复杂度分析

| 实现方式 | 时间复杂度 | 空间复杂度 |
|---------|-----------|-----------|
| 朴素数组 | O(V²) | O(V) |
| 优先队列 | O((V+E)log V) | O(V+E) |

#### 5. 适用场景

- 导航系统最短路径
- 网络路由协议（OSPF）
- 地图应用路径规划

**限制**：不能处理负权边（负权边需用Bellman-Ford算法）。

### 3. 拓扑排序

#### 1. 问题

给定一个有向无环图（DAG），求一种节点排列顺序，使得每条边的起点在终点之前。

**实际场景**：课程先修关系、编译依赖、任务调度。

#### 2. 思想（Kahn算法）

反复找到入度为0的节点，输出它并删除其出边，直到所有节点被输出。若最终有节点未被输出，说明图中有环。

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

vector<int> topological_sort(int n, const vector<vector<int>>& graph) {
    vector<int> in_degree(n, 0);
    for (int u = 0; u < n; u++) {
        for (int v : graph[u]) {
            in_degree[v]++;
        }
    }
    queue<int> q;
    for (int i = 0; i < n; i++) {
        if (in_degree[i] == 0) q.push(i);
    }
    vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);
        for (int v : graph[u]) {
            if (--in_degree[v] == 0) {
                q.push(v);
            }
        }
    }
    // 若order大小不等于n，说明有环
    return order;
}

int main() {
    // 课程依赖：0→1→2→3 表示课程1依赖课程0
    int n = 6;
    vector<vector<int>> graph(n);
    graph[0].push_back(1);
    graph[0].push_back(2);
    graph[1].push_back(3);
    graph[2].push_back(3);
    graph[3].push_back(4);
    graph[3].push_back(5);
    graph[4].push_back(5);

    vector<int> order = topological_sort(n, graph);
    if ((int)order.size() != n) {
        cout << "图中存在环，无法拓扑排序！" << endl;
    } else {
        cout << "拓扑排序结果（修课顺序）：";
        for (int v : order) cout << v << " ";
        cout << endl;
    }
    return 0;
}
```

#### 4. 复杂度分析

| 复杂度 | 值 |
|--------|-----|
| 时间 | O(V + E) |
| 空间 | O(V + E) |

#### 5. 适用场景

- 编译系统依赖分析（Makefile）
- 课程先修关系排课
- 并行任务调度
- 检测有向图是否有环

### 4. 最小生成树

#### 1. 问题

给定一个连通无向带权图，找一棵包含所有节点的生成树，使得边权之和最小。

#### 2. Prim算法（从节点出发）

**思想**：从一个节点开始，每次选择与当前生成树相连的权值最小的边，将新节点加入生成树，直到包含所有节点。

**类比**：像城市修路——从一个城市开始，每次修一条到最近未连通城市的路。

- 时间复杂度（优先队列版）：O((V+E)log V)
- 适用于稠密图

#### 3. Kruskal算法（从边出发）

**思想**：将所有边按权值从小到大排序，依次选取不形成环的边，直到选够V-1条。

**判断是否成环**：使用并查集（Union-Find），若边的两端已在同一集合则跳过。

- 时间复杂度：O(E log E)（排序为主）
- 适用于稀疏图

#### 4. 适用场景

- 网络布线（使线缆总长最短）
- 公路/铁路建设规划
- 集群通信网络设计

## 4. 动态规划

### 1. 问题引入

许多问题具有天然的递归结构，但直接递归会产生大量重复计算，导致指数级时间复杂度。动态规划（Dynamic Programming, DP）通过**记忆化**避免重复计算，将指数级降为多项式级。

---

> 💡 **通俗理解 - 动态规划是什么？**

想象你在考试：
- **递归**：每道题都从头推导，即使和前面的题用了相同公式
- **记忆化**：把中间结果写在草稿纸上，下次直接查
- **DP**：提前把所有可能用到的中间结果按顺序算好，填表即可

---

> 🔬 **抽象理解 - DP的两个核心性质**

1. **最优子结构**：大问题的最优解包含小问题的最优解
2. **重叠子问题**：递归过程中会反复求解相同的子问题

两个条件都满足时，才适合用动态规划。

---

> 📜 **古文引用**

> **"不积跬步，无以至千里。"** ——《荀子·劝学》
>
> 动态规划正是如此：每一步的最优选择积累起来，构成全局最优解。

---

### 2. DP解题四步法

| 步骤 | 内容 | 关键问题 |
|------|------|---------|
| 1. 定义状态 | dp[i]或dp[i][j]代表什么 | "状态"要能描述子问题 |
| 2. 状态转移方程 | dp[i]如何从更小的子问题推导 | 这是DP的灵魂 |
| 3. 初始化 | dp的边界值是什么 | 最小子问题的答案 |
| 4. 遍历顺序 | 按什么顺序填表 | 确保计算dp[i]时依赖值已算好 |

---

### 3. 斐波那契数列：从递归到DP

#### 1. 问题

斐波那契数列：F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)。求F(n)。

#### 2. 方法一：直接递归（指数级）

```cpp
int fib_recursive(int n) {
    if (n <= 1) return n;
    return fib_recursive(n - 1) + fib_recursive(n - 2);
}
```

**问题**：F(5)的递归树有大量重复计算：
```
              F(5)
            /      \
        F(4)        F(3)
       /    \      /    \
    F(3)   F(2)  F(2)   F(1)
   /   \   / \   / \
 F(2) F(1) ...  ...
```
F(3)算了2次，F(2)算了3次！时间复杂度O(2ⁿ)。

#### 3. 方法二：记忆化递归（自顶向下）

```cpp
#include <iostream>
#include <vector>
using namespace std;

int fib_memo(int n, vector<int>& memo) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n]; // 已计算过，直接返回
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo);
    return memo[n];
}

int main() {
    int n = 10;
    vector<int> memo(n + 1, -1);
    cout << "F(" << n << ") = " << fib_memo(n, memo) << endl;
    return 0;
}
```

**改进**：每个子问题只算一次，时间复杂度O(n)。

#### 4. 方法三：动态规划（自底向上）

```cpp
#include <iostream>
#include <vector>
using namespace std;

int fib_dp(int n) {
    if (n <= 1) return n;
    vector<int> dp(n + 1);
    // 步骤3：初始化
    dp[0] = 0;
    dp[1] = 1;
    // 步骤4：从前往后填表
    for (int i = 2; i <= n; i++) {
        // 步骤2：状态转移方程
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}

// 空间优化：只需前两个值
int fib_optimized(int n) {
    if (n <= 1) return n;
    int prev2 = 0, prev1 = 1;
    for (int i = 2; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

int main() {
    int n = 10;
    cout << "F(" << n << ") = " << fib_dp(n) << endl;
    cout << "F(" << n << ") = " << fib_optimized(n) << endl;
    return 0;
}
```

#### 5. 三种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 直接递归 | O(2ⁿ) | O(n) | 简单但极慢 |
| 记忆化递归 | O(n) | O(n) | 自顶向下，按需计算 |
| 动态规划 | O(n) | O(n)→O(1) | 自底向上，可优化空间 |

### 4. 0-1背包问题

#### 1. 问题

有n个物品，每个物品有重量w[i]和价值v[i]。背包容量为W。每个物品**只能选或不选**（0-1），求背包能装下的最大价值。

#### 2. 思想

**步骤1：定义状态**

`dp[i][j]` = 从前i个物品中选，背包容量为j时的最大价值

**步骤2：状态转移方程**

对于第i个物品，有两种选择：
- **不选**：`dp[i][j] = dp[i-1][j]`（和没这个物品一样）
- **选**（前提：j ≥ w[i]）：`dp[i][j] = dp[i-1][j-w[i]] + v[i]`

取两者最大值：
```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])  （若 j ≥ w[i]）
dp[i][j] = dp[i-1][j]                                  （若 j < w[i]）
```

**步骤3：初始化**

`dp[0][j] = 0`（0个物品，价值为0）

**步骤4：遍历顺序**

外层循环物品i（1→n），内层循环容量j（0→W）

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int knapsack_01(const vector<int>& w, const vector<int>& v, int W) {
    int n = w.size();
    // dp[i][j]：前i个物品、容量j时的最大价值
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= W; j++) {
            dp[i][j] = dp[i - 1][j]; // 不选第i个物品
            if (j >= w[i - 1]) {
                dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i - 1]] + v[i - 1]);
            }
        }
    }
    return dp[n][W];
}

// 空间优化：一维数组（逆序遍历容量）
int knapsack_01_optimized(const vector<int>& w, const vector<int>& v, int W) {
    int n = w.size();
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; i++) {
        // 必须逆序！保证dp[j-w[i]]是上一轮的值
        for (int j = W; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[W];
}

int main() {
    vector<int> w = {2, 3, 4, 5};   // 重量
    vector<int> v = {3, 4, 5, 6};   // 价值
    int W = 8;                       // 背包容量
    cout << "最大价值（二维）：" << knapsack_01(w, v, W) << endl;
    cout << "最大价值（一维）：" << knapsack_01_optimized(w, v, W) << endl;
    return 0;
}
```

**为什么一维优化必须逆序遍历？**

正序遍历时，`dp[j - w[i]]`可能已被当前轮次更新过（即第i个物品被选了多次），而0-1背包每个物品只能选一次。逆序遍历保证`dp[j - w[i]]`仍是上一轮（第i-1个物品）的值。

#### 4. 复杂度分析

| 实现 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二维DP | O(n·W) | O(n·W) |
| 一维优化 | O(n·W) | O(W) |

#### 5. 适用场景

- 资源分配问题
- 投资组合优化
- 背包类竞赛题

### 5. 最长公共子序列（LCS）

#### 1. 问题

给定两个字符串s1和s2，求它们的最长公共子序列的长度。

**子序列**：不要求连续，但要求保持相对顺序。如"ace"是"abcde"的子序列。

#### 2. 思想

**步骤1：定义状态**

`dp[i][j]` = s1前i个字符与s2前j个字符的LCS长度

**步骤2：状态转移方程**

- 若`s1[i-1] == s2[j-1]`：当前字符匹配，LCS长度+1
  `dp[i][j] = dp[i-1][j-1] + 1`
- 若`s1[i-1] != s2[j-1]`：取两种选择的最大值
  `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

**步骤3：初始化**

`dp[0][j] = 0`，`dp[i][0] = 0`（空串的LCS为0）

**步骤4：遍历顺序**

外层i（1→len1），内层j（1→len2）

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

int lcs(const string& s1, const string& s2) {
    int m = s1.size();
    int n = s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i - 1] == s2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}

// 回溯求具体LCS字符串
string lcs_string(const string& s1, const string& s2) {
    int m = s1.size();
    int n = s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i - 1] == s2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    // 从右下角回溯
    string result;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (s1[i - 1] == s2[j - 1]) {
            result = s1[i - 1] + result;
            i--; j--;
        } else if (dp[i - 1][j] > dp[i][j - 1]) {
            i--;
        } else {
            j--;
        }
    }
    return result;
}

int main() {
    string s1 = "ABCBDAB";
    string s2 = "BDCABA";
    cout << "LCS长度：" << lcs(s1, s2) << endl;
    cout << "LCS内容：" << lcs_string(s1, s2) << endl;
    return 0;
}
```

#### 4. 复杂度分析

| 复杂度 | 值 |
|--------|-----|
| 时间 | O(m·n) |
| 空间 | O(m·n) |

#### 5. 适用场景

- 文本差异比较（diff工具）
- DNA序列比对
- 版本控制系统（Git的合并算法）

### 6. DP解题思路总结

```
遇到一个问题，如何判断是否用DP？

1. 能否拆成子问题？        → 是 → 继续
2. 子问题是否重叠？        → 是 → 适合DP
3. 是否求最优解/计数？     → 是 → 大概率DP

DP四步法：
┌─────────────────────────────────────────────┐
│  1. 定义状态：dp[?] 代表什么含义？            │
│  2. 状态转移：dp[i] = f(dp[更小的i])          │
│  3. 初始化：dp的边界值                        │
│  4. 遍历顺序：确保依赖值先算好                 │
└─────────────────────────────────────────────┘

常见DP分类：
- 线性DP：斐波那契、爬楼梯、打家劫舍
- 背包DP：0-1背包、完全背包、多重背包
- 区间DP：矩阵链乘法、戳气球
- 树形DP：树的最大独立集
- 状态压缩DP：旅行商问题
```

## 5. 回溯算法

### 1. 问题引入

有些问题需要"尝试所有可能"，比如N皇后、全排列、子集。暴力枚举的搜索空间往往呈指数级增长，回溯算法通过**试探+撤销**系统地搜索，配合**剪枝**大幅减少无效搜索。

---

> 💡 **通俗理解 - 回溯算法是什么？**

走迷宫时：
- 每到一个岔路口，选一条路走
- 走到死胡同，**退回**上一个岔路口，换条路
- 记住走过的路，不再重复
- 这就是回溯：**走不通就退，换条路再试**

---

> 🔬 **抽象理解 - 回溯的本质**

回溯 = **深度优先搜索 + 状态重置**

```
做选择 → 递归 → 撤销选择
```

它隐式地遍历了一棵**决策树**，树的每个节点代表一个选择，每条根到叶子的路径代表一个完整解。

### 2. 回溯算法框架

```cpp
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        收集结果;
        return;
    }
    for (选择 : 选择列表) {
        做选择;
        backtrack(路径, 选择列表);
        撤销选择;  // 关键！回到上一个状态
    }
}
```

### 3. N皇后问题

#### 1. 问题

在N×N的棋盘上放置N个皇后，使得任意两个皇后不在同一行、同一列、同一对角线上。

#### 2. 思想

逐行放置皇后。每行选一个列位置，检查是否与已放置的皇后冲突：
- 同列：`col[i] == col[j]`
- 主对角线：`row1 - col1 == row2 - col2`
- 副对角线：`row1 + col1 == row2 + col2`

冲突则跳过（剪枝），不冲突则递归下一行。

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

class NQueens {
private:
    int n;
    vector<vector<string>> solutions;

    // 检查在(row, col)放置皇后是否合法
    bool is_valid(const vector<string>& board, int row, int col) {
        // 检查同列（上方行）
        for (int i = 0; i < row; i++) {
            if (board[i][col] == 'Q') return false;
        }
        // 检查左上方对角线
        for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--) {
            if (board[i][j] == 'Q') return false;
        }
        // 检查右上方对角线
        for (int i = row - 1, j = col + 1; i >= 0 && j < n; i--, j++) {
            if (board[i][j] == 'Q') return false;
        }
        return true;
    }

    void backtrack(vector<string>& board, int row) {
        // 结束条件：所有行都放置了皇后
        if (row == n) {
            solutions.push_back(board);
            return;
        }
        for (int col = 0; col < n; col++) {
            // 剪枝：跳过不合法位置
            if (!is_valid(board, row, col)) continue;
            // 做选择
            board[row][col] = 'Q';
            // 递归下一行
            backtrack(board, row + 1);
            // 撤销选择
            board[row][col] = '.';
        }
    }

public:
    NQueens(int size) : n(size) {}

    vector<vector<string>> solve() {
        solutions.clear();
        vector<string> board(n, string(n, '.'));
        backtrack(board, 0);
        return solutions;
    }
};

int main() {
    int n = 4;
    NQueens solver(n);
    auto solutions = solver.solve();
    cout << n << "皇后问题共有 " << solutions.size() << " 种解法：" << endl;
    for (int i = 0; i < (int)solutions.size(); i++) {
        cout << "解法" << i + 1 << "：" << endl;
        for (const auto& row : solutions[i]) {
            cout << "  " << row << endl;
        }
        cout << endl;
    }
    return 0;
}
```

#### 4. 复杂度分析

| 复杂度 | 值 | 说明 |
|--------|-----|------|
| 时间 | O(N!) | 最坏情况遍历所有排列 |
| 空间 | O(N) | 递归深度 + 棋盘 |

剪枝后实际远小于O(N!)。

### 4. 子集与组合问题

#### 1. 问题一：子集

给定一组不含重复元素的整数，返回所有可能的子集。

#### 2. 思想

每个元素有"选"或"不选"两种可能，构成一棵二叉决策树。回溯遍历这棵树即可。

#### 3. C++实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Subsets {
private:
    vector<vector<int>> result;

    void backtrack(const vector<int>& nums, int start, vector<int>& path) {
        // 每个节点都是一个合法子集
        result.push_back(path);
        // 从start开始，避免重复（保证子集元素顺序）
        for (int i = start; i < (int)nums.size(); i++) {
            path.push_back(nums[i]);        // 做选择
            backtrack(nums, i + 1, path);   // 递归（i+1，不回头）
            path.pop_back();                // 撤销选择
        }
    }

public:
    vector<vector<int>> solve(const vector<int>& nums) {
        result.clear();
        vector<int> path;
        backtrack(nums, 0, path);
        return result;
    }
};

int main() {
    vector<int> nums = {1, 2, 3};
    Subsets solver;
    auto subsets = solver.solve(nums);
    cout << "所有子集：" << endl;
    for (const auto& s : subsets) {
        cout << "  {";
        for (int i = 0; i < (int)s.size(); i++) {
            cout << s[i] << (i < (int)s.size() - 1 ? ", " : "");
        }
        cout << "}" << endl;
    }
    return 0;
}
```

#### 4. 问题二：组合

给定整数n和k，返回1~n中选k个数的所有组合。

#### 5. C++实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Combinations {
private:
    vector<vector<int>> result;

    void backtrack(int n, int k, int start, vector<int>& path) {
        // 结束条件：已选够k个数
        if ((int)path.size() == k) {
            result.push_back(path);
            return;
        }
        // 剪枝：i的上界优化
        // 还需选 k - path.size() 个，所以i最大从 n - (k - path.size()) + 1 开始
        int need = k - (int)path.size();
        for (int i = start; i <= n - need + 1; i++) {
            path.push_back(i);          // 做选择
            backtrack(n, k, i + 1, path); // 递归
            path.pop_back();            // 撤销选择
        }
    }

public:
    vector<vector<int>> solve(int n, int k) {
        result.clear();
        vector<int> path;
        backtrack(n, k, 1, path);
        return result;
    }
};

int main() {
    int n = 4, k = 2;
    Combinations solver;
    auto combos = solver.solve(n, k);
    cout << "C(" << n << "," << k << ") 的所有组合：" << endl;
    for (const auto& c : combos) {
        cout << "  {";
        for (int i = 0; i < (int)c.size(); i++) {
            cout << c[i] << (i < (int)c.size() - 1 ? ", " : "");
        }
        cout << "}" << endl;
    }
    return 0;
}
```

### 5. 剪枝优化

剪枝是回溯算法的灵魂——在搜索过程中提前判断某条路不可能得到合法解，直接跳过。

#### 1. 常见剪枝策略

| 策略 | 说明 | 示例 |
|------|------|------|
| 约束剪枝 | 不满足约束条件直接跳过 | N皇后检查列/对角线冲突 |
| 边界剪枝 | 剩余选择不够凑成合法解 | 组合问题中`i <= n - need + 1` |
| 最优性剪枝 | 当前解已不可能优于已知最优解 | 旅行商问题中当前路径已超过已知最短路径 |
| 重复剪枝 | 跳过会产生重复解的选择 | 含重复元素时，同层相同值只取一次 |

#### 2. 重复元素剪枝示例

```cpp
// 子集II：数组含重复元素，子集不能重复
void backtrack_with_dup(vector<int>& nums, int start, vector<int>& path,
                        vector<vector<int>>& result) {
    result.push_back(path);
    for (int i = start; i < (int)nums.size(); i++) {
        // 剪枝：同层中相同值只取第一次，避免重复子集
        if (i > start && nums[i] == nums[i - 1]) continue;
        path.push_back(nums[i]);
        backtrack_with_dup(nums, i + 1, path, result);
        path.pop_back();
    }
}
// 注意：调用前需先排序 nums
```

### 6. 回溯算法总结

```
回溯 = DFS + 状态重置

核心模板：
  做选择 → 递归 → 撤销选择

何时使用回溯？
  ✅ 需要找出所有解（子集、排列、组合）
  ✅ 需要找出满足约束的解（N皇后、数独）
  ✅ 搜索空间是树形结构

优化关键：
  🔪 剪枝——越早剪枝，效率越高
  📊 剪枝的好坏决定了回溯的实际性能
```

### 1. 问题引入

### 2. STL容器选择决策树

```
需要存储什么？
│
├─ 键值对 → map / unordered_map
│   ├─ 需要有序遍历 → map（红黑树）
│   └─ 只需快速查找 → unordered_map（哈希表）
│
├─ 单值集合 → set / unordered_set
│   ├─ 需要有序 → set
│   └─ 只需快速查找 → unordered_set
│
├─ 序列容器
│   ├─ 频繁头尾操作 → deque
│   ├─ 频繁中间插入/删除 → list
│   ├─ 随机访问为主 → vector
│   └─ 固定大小 → array
│
└─ 适配器
    ├─ 优先级出队 → priority_queue
    ├─ 后进先出 → stack
    └─ 先进先出 → queue
```

### 3. STL算法分类

| 分类 | 说明 | 代表算法 |
|------|------|---------|
| 非修改序列 | 不改变元素值 | `find`, `count`, `search`, `equal` |
| 修改序列 | 改变元素值或顺序 | `copy`, `transform`, `replace`, `fill`, `remove` |
| 排序与相关 | 排序、查找、合并 | `sort`, `stable_sort`, `nth_element`, `lower_bound`, `upper_bound` |
| 数值运算 | 累加、内积等 | `accumulate`, `inner_product`, `partial_sum` |

### 4. 常用算法实战

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

void print(const vector<int>& v) {
    for (int x : v) cout << x << " ";
    cout << endl;
}

int main() {
    vector<int> v = {5, 2, 8, 1, 9, 3, 7, 4, 6};

    // 1. sort：快速排序（实际为内省排序）
    vector<int> v1 = v;
    sort(v1.begin(), v1.end());
    cout << "sort排序："; print(v1);

    // 2. stable_sort：稳定排序（相等元素保持原顺序）
    vector<pair<int,char>> v2 = {{3,'a'}, {1,'b'}, {3,'c'}, {2,'d'}};
    stable_sort(v2.begin(), v2.end(),
                [](const auto& a, const auto& b) { return a.first < b.first; });
    cout << "stable_sort（3a在3c前）：";
    for (auto& p : v2) cout << p.first << p.second << " ";
    cout << endl;

    // 3. nth_element：第n小元素就位（不保证其他元素有序）
    vector<int> v3 = v;
    nth_element(v3.begin(), v3.begin() + 3, v3.end());
    cout << "nth_element（第4小元素）：" << v3[3] << endl;

    // 4. partial_sort：前k个排序，其余不保证
    vector<int> v4 = v;
    partial_sort(v4.begin(), v4.begin() + 3, v4.end());
    cout << "partial_sort（前3小）：";
    for (int i = 0; i < 3; i++) cout << v4[i] << " ";
    cout << "... ";
    print(v4);

    // 5. lower_bound / upper_bound（要求有序序列）
    vector<int> v5 = {1, 2, 2, 2, 3, 4, 5};
    auto lo = lower_bound(v5.begin(), v5.end(), 2); // 第一个≥2的位置
    auto hi = upper_bound(v5.begin(), v5.end(), 2); // 第一个>2的位置
    cout << "lower_bound(2) 索引：" << (lo - v5.begin()) << endl; // 1
    cout << "upper_bound(2) 索引：" << (hi - v5.begin()) << endl; // 4
    cout << "2的个数：" << (hi - lo) << endl; // 3

    // 6. accumulate：累加
    int sum = accumulate(v.begin(), v.end(), 0);
    cout << "累加和：" << sum << endl;

    return 0;
}
```

**算法选择建议**：

| 需求 | 推荐算法 | 时间复杂度 |
|------|---------|-----------|
| 完全排序 | `sort` | O(n log n) |
| 稳定排序 | `stable_sort` | O(n log n) |
| 只需第k小 | `nth_element` | O(n) 平均 |
| 前k小且有序 | `partial_sort` | O(n log k) |
| 有序序列查找 | `lower_bound` / `upper_bound` | O(log n) |
