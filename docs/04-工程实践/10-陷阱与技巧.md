## 本章导读

本章总结C/C++开发中常见的陷阱和实用技巧：

- **内存陷阱** - 内存泄漏、越界、野指针
- **并发陷阱** - 竞态条件、死锁
- **性能技巧** - 优化方法和最佳实践
- **调试技巧** - 问题定位和解决

### 1. 概念与定义

**内存陷阱（memory pitfall）**：C++中用于表示程序内存使用不正确的陷阱。内存陷阱可以分为内存泄漏、缓冲区溢出、野指针、空指针等。例如内存泄漏表示程序未能释放已分配内存，缓冲区溢出表示程序访问了缓冲区越界的元素，野指针表示指针指向已释放内存，空指针表示指针不指向任何对象。

**并发陷阱（concurrency pitfall）**：C++中用于表示程序并发使用不正确的陷阱。并发陷阱可以分为竞态条件、死锁、活锁、虚假共享等。例如竞态条件表示程序的执行结果依赖于线程的执行顺序，死锁表示程序的线程相互等待，活锁表示程序的线程不断改变状态但无法继续执行，虚假共享表示多个线程同时访问同一缓存行。

**性能技巧（performance technique）**：C++中用于提高程序性能的技巧。性能技巧可以分为使用`std::vector`代替`std::list`、使用`std::unordered_map`代替`std::map`、使用`std::move`代替拷贝等。例如使用`std::vector`代替`std::list`可以提高内存访问的效率，使用`std::unordered_map`代替`std::map`可以提高查找的效率，使用`std::move`代替拷贝可以减少内存拷贝的开销。

**调试技巧（debugging technique）**：C++中用于调试程序的技巧。调试技巧可以分为使用GDB调试器、使用日志调试、使用断言调试等。例如使用GDB调试器可以查找程序的错误，使用日志调试可以输出程序的运行状态，使用断言调试可以检查程序的正确性。

**内存泄漏（memory leak）**：C++中用于表示程序未能释放已分配内存的陷阱。内存泄漏可以分为堆内存泄漏、栈内存泄漏、全局内存泄漏等。例如堆内存泄漏表示程序未能释放堆内存，栈内存泄漏表示程序未能释放栈内存，全局内存泄漏表示程序未能释放全局内存。

**缓冲区溢出（buffer overflow）**：C++中用于表示程序访问了缓冲区越界元素的陷阱。缓冲区溢出可以分为栈缓冲区溢出、堆缓冲区溢出、全局缓冲区溢出等。例如栈缓冲区溢出表示程序访问了栈缓冲区越界的元素，堆缓冲区溢出表示程序访问了堆缓冲区越界的元素，全局缓冲区溢出表示程序访问了全局缓冲区越界的元素。

## 1. 内存陷阱

### 1. 陷阱1：内存泄漏

#### 1. 问题示例

```c
void memory_leak_example(void) {
    int *ptr = malloc(100 * sizeof(int));
    
    /* 使用ptr... */
    
    /* 忘记释放！ */
    return;  /* 内存泄漏 */
}

void memory_leak_example2(void) {
    int *ptr = malloc(100 * sizeof(int));
    
    if (some_error) {
        return;  /* 提前返回，忘记释放 */
    }
    
    free(ptr);
}
```

#### 2. 解决方案

```c
/* 方案1：确保所有路径都释放 */
void correct_example1(void) {
    int *ptr = malloc(100 * sizeof(int));
    if (!ptr) return;
    
    if (some_error) {
        free(ptr);  /* 提前释放 */
        return;
    }
    
    free(ptr);
}

/* 方案2：使用goto统一清理 */
void correct_example2(void) {
    int *ptr1 = malloc(100 * sizeof(int));
    int *ptr2 = malloc(200 * sizeof(int));
    
    if (!ptr1 || !ptr2) {
        goto cleanup;
    }
    
    /* 使用内存... */
    
cleanup:
    if (ptr1) free(ptr1);
    if (ptr2) free(ptr2);
}

/* 方案3：C++使用RAII */
void cpp_example(void) {
    std::unique_ptr<int[]> ptr(new int[100]);
    
    /* 自动释放，无需手动free */
}
```

### 2. 陷阱2：缓冲区溢出

#### 1. 问题示例

```c
void buffer_overflow_example(void) {
    char buffer[10];
    strcpy(buffer, "This is a very long string");  /* 溢出！ */
}

void buffer_overflow_example2(void) {
    int arr[10];
    for (int i = 0; i <= 10; i++) {  /* 越界！ */
        arr[i] = i;
    }
}
```

#### 2. 解决方案

```c
/* 方案1：使用安全函数 */
void safe_example1(void) {
    char buffer[10];
    strncpy(buffer, "This is a very long string", sizeof(buffer) - 1);
    buffer[sizeof(buffer) - 1] = '\0';  /* 确保终止 */
}

/* 方案2：检查边界 */
void safe_example2(void) {
    int arr[10];
    for (int i = 0; i < 10; i++) {  /* 正确 */
        arr[i] = i;
    }
}

/* 方案3：使用snprintf */
void safe_example3(void) {
    char buffer[10];
    snprintf(buffer, sizeof(buffer), "%s", "long string");
}
```

### 3. 陷阱2.5：无符号转有符号溢出

#### 1. 问题示例

```c
#include <stdio.h>
#include <stdint.h>

void unsigned_to_signed_issue(void) {
    unsigned short u = 50000;
    short s = (short)u;  /* 溢出！ */
    
    printf("无符号: %u\n", u);   /* 输出: 50000 */
    printf("有符号: %d\n", s);   /* 输出: -15536 */
}

void array_index_issue(void) {
    int arr[10];
    unsigned int index = -1;  /* 隐式转换，变成很大的正数 */
    
    /* 危险！index是4294967295，导致越界访问 */
    arr[index] = 100;  /* 未定义行为！ */
}

void comparison_issue(void) {
    int i = -1;
    unsigned int u = 1;
    
    /* 陷阱：i被转换为无符号数进行比较 */
    if (i < u) {
        printf("-1 < 1\n");  /* 不会执行！ */
    }
    /* 实际：-1转为4294967295，大于1 */
}
```

#### 2. 转换原理

无符号数转换为有符号数时，如果超出有符号类型的表示范围，使用公式：

```
有符号值 = 无符号值 - 2^n
```

其中 `n` 是有符号类型的位数。

**示例计算（16位short）：**

| 无符号值 | 计算 | 有符号结果 |
|---------|------|-----------|
| 50000 | 50000 - 65536 | -15536 |
| 65535 | 65535 - 65536 | -1 |
| 32768 | 32768 - 65536 | -32768 |
| 32767 | 不溢出 | 32767 |

#### 3. 解决方案

```c
#include <limits.h>
#include <stdbool.h>

/* 方案1：检查范围 */
bool safe_unsigned_to_signed(unsigned int u, int *result) {
    if (u > INT_MAX) {
        return false;  /* 超出范围 */
    }
    *result = (int)u;
    return true;
}

/* 方案2：使用size_t处理数组索引 */
void safe_array_access(int arr[], size_t size, size_t index) {
    if (index < size) {
        arr[index] = 100;  /* 安全 */
    }
}

/* 方案3：避免混用有符号和无符号 */
void safe_comparison(void) {
    int i = -1;
    unsigned int u = 1;
    
    /* 显式转换，明确意图 */
    if (i < 0 || (unsigned int)i < u) {
        printf("i is less than u or negative\n");
    }
}

/* 方案4：使用断言检查 */
#include <assert.h>
void process_unsigned(unsigned int value) {
    assert(value <= INT_MAX);  /* 调试时检查 */
    int signed_value = (int)value;
    /* ... */
}
```

#### 4. 最佳实践

| 场景 | 建议 |
|------|------|
| 数组索引 | 使用 `size_t` 而非 `int` |
| 循环变量 | 避免无符号与有符号混用 |
| 比较操作 | 显式转换，明确意图 |
| 类型转换 | 检查范围后再转换 |

### 4. 陷阱3：野指针

#### 1. 问题示例

```c
void dangling_pointer_example(void) {
    int *ptr = malloc(sizeof(int));
    *ptr = 42;
    
    free(ptr);
    
    /* ptr现在是野指针 */
    printf("%d\n", *ptr);  /* 未定义行为！ */
}

void dangling_pointer_example2(void) {
    int *ptr = NULL;
    {
        int local = 42;
        ptr = &local;
    }  /* local被销毁 */
    
    printf("%d\n", *ptr);  /* 未定义行为！ */
}
```

#### 2. 解决方案

```c
void safe_pointer_example(void) {
    int *ptr = malloc(sizeof(int));
    if (!ptr) return;
    
    *ptr = 42;
    free(ptr);
    ptr = NULL;  /* 置空，防止野指针 */
    
    /* 检查NULL */
    if (ptr) {
        printf("%d\n", *ptr);
    }
}

/* 使用宏简化 */
#define SAFE_FREE(ptr) do { \
    if (ptr) { \
        free(ptr); \
        ptr = NULL; \
    } \
} while(0)
```

## 2. 并发陷阱

### 1. 陷阱1：竞态条件

#### 1. 问题示例

```c
int counter = 0;

void *thread_func(void *arg) {
    for (int i = 0; i < 1000; i++) {
        counter++;  /* 非原子操作，竞态条件！ */
    }
    return NULL;
}
```

#### 2. 解决方案

```c
#include <stdatomic.h>
#include <pthread.h>

/* 方案1：使用原子变量 */
atomic_int counter = 0;

void *thread_func_atomic(void *arg) {
    for (int i = 0; i < 1000; i++) {
        atomic_fetch_add(&counter, 1);  /* 原子操作 */
    }
    return NULL;
}

/* 方案2：使用互斥锁 */
int counter2 = 0;
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;

void *thread_func_mutex(void *arg) {
    for (int i = 0; i < 1000; i++) {
        pthread_mutex_lock(&mutex);
        counter2++;
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}
```

### 2. 陷阱2：死锁

#### 1. 问题示例

```c
pthread_mutex_t mutex1 = PTHREAD_MUTEX_INITIALIZER;
pthread_mutex_t mutex2 = PTHREAD_MUTEX_INITIALIZER;

void *thread1(void *arg) {
    pthread_mutex_lock(&mutex1);
    pthread_mutex_lock(&mutex2);  /* 可能死锁 */
    /* ... */
    pthread_mutex_unlock(&mutex2);
    pthread_mutex_unlock(&mutex1);
    return NULL;
}

void *thread2(void *arg) {
    pthread_mutex_lock(&mutex2);
    pthread_mutex_lock(&mutex1);  /* 死锁！ */
    /* ... */
    pthread_mutex_unlock(&mutex1);
    pthread_mutex_unlock(&mutex2);
    return NULL;
}
```

#### 2. 解决方案

```c
/* 方案1：按固定顺序加锁 */
void *thread1_safe(void *arg) {
    pthread_mutex_lock(&mutex1);
    pthread_mutex_lock(&mutex2);  /* 总是先mutex1后mutex2 */
    /* ... */
    pthread_mutex_unlock(&mutex2);
    pthread_mutex_unlock(&mutex1);
    return NULL;
}

void *thread2_safe(void *arg) {
    pthread_mutex_lock(&mutex1);  /* 也先mutex1后mutex2 */
    pthread_mutex_lock(&mutex2);
    /* ... */
    pthread_mutex_unlock(&mutex2);
    pthread_mutex_unlock(&mutex1);
    return NULL;
}

/* 方案2：使用trylock */
void *thread_trylock(void *arg) {
    if (pthread_mutex_trylock(&mutex1) == 0) {
        if (pthread_mutex_trylock(&mutex2) == 0) {
            /* 成功获取两个锁 */
            /* ... */
            pthread_mutex_unlock(&mutex2);
        }
        pthread_mutex_unlock(&mutex1);
    }
    return NULL;
}
```

## 3. 性能技巧

### 1. 技巧1：减少内存分配

```c
/* 慢：频繁分配 */
void slow_example(void) {
    for (int i = 0; i < 10000; i++) {
        char *buffer = malloc(1024);
        /* 使用buffer */
        free(buffer);
    }
}

/* 快：重用内存 */
void fast_example(void) {
    char *buffer = malloc(1024);
    
    for (int i = 0; i < 10000; i++) {
        /* 使用buffer */
    }
    
    free(buffer);
}
```

### 2. 技巧2：缓存友好

```c
/* 慢：列优先访问 */
void slow_matrix(int **matrix, int rows, int cols) {
    for (int j = 0; j < cols; j++) {
        for (int i = 0; i < rows; i++) {
            matrix[i][j] = 0;  /* 缓存不友好 */
        }
    }
}

/* 快：行优先访问 */
void fast_matrix(int **matrix, int rows, int cols) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            matrix[i][j] = 0;  /* 缓存友好 */
        }
    }
}
```

### 3. 技巧3：避免不必要的拷贝

```c
/* 慢：值传递 */
void slow_function(std::vector<int> data) {
    /* 拷贝整个vector */
}

/* 快：引用传递 */
void fast_function(const std::vector<int> &data) {
    /* 不拷贝 */
}
```

## 4. 调试技巧

### 1. 技巧1：使用断言

```c
#include <assert.h>

void process_array(int *arr, int size) {
    assert(arr != NULL);        /* 检查非空 */
    assert(size > 0);           /* 检查大小 */
    assert(size < 10000);       /* 检查合理范围 */
    
    /* 处理数组 */
}

/* 自定义断言 */
#ifdef DEBUG
#define DEBUG_ASSERT(cond, msg) \
    do { \
        if (!(cond)) { \
            fprintf(stderr, "Assertion failed: %s\n", msg); \
            fprintf(stderr, "File: %s, Line: %d\n", __FILE__, __LINE__); \
            abort(); \
        } \
    } while(0)
#else
#define DEBUG_ASSERT(cond, msg)
#endif
```

### 2. 技巧2：日志记录

```c
#ifdef DEBUG
#define LOG_DEBUG(fmt, ...) \
    fprintf(stderr, "[DEBUG] %s:%d: " fmt "\n", __FILE__, __LINE__, ##__VA_ARGS__)
#else
#define LOG_DEBUG(fmt, ...)
#endif

#define LOG_ERROR(fmt, ...) \
    fprintf(stderr, "[ERROR] %s:%d: " fmt "\n", __FILE__, __LINE__, ##__VA_ARGS__)

void process_data(int *data, int size) {
    LOG_DEBUG("Processing %d elements", size);
    
    if (!data) {
        LOG_ERROR("data is NULL");
        return;
    }
    
    /* 处理数据 */
}
```

## 5. 最佳实践

### 1. 代码规范

```c
/* 1. 初始化变量 */
int *ptr = NULL;  /* 而不是 int *ptr; */
int count = 0;

/* 2. 检查返回值 */
FILE *fp = fopen("file.txt", "r");
if (!fp) {
    perror("fopen failed");
    return -1;
}

/* 3. 使用const */
void print_string(const char *str) {
    printf("%s\n", str);  /* 不会修改str */
}

/* 4. 限制作用域 */
void function(void) {
    for (int i = 0; i < 10; i++) {  /* i的作用域在循环内 */
        /* ... */
    }
}

/* 5. 避免魔法数字 */
#define MAX_BUFFER_SIZE 1024
char buffer[MAX_BUFFER_SIZE];  /* 而不是 char buffer[1024]; */
```

### 2. 防御性编程

```c
/* 检查所有输入 */
int safe_divide(int a, int b) {
    if (b == 0) {
        LOG_ERROR("Division by zero");
        return 0;
    }
    return a / b;
}

/* 检查数组边界 */
int safe_array_get(int *arr, int size, int index) {
    if (!arr || index < 0 || index >= size) {
        LOG_ERROR("Invalid array access");
        return -1;
    }
    return arr[index];
}

/* 检查整数溢出 */
int safe_add(int a, int b) {
    if (a > 0 && b > INT_MAX - a) {
        LOG_ERROR("Integer overflow");
        return -1;
    }
    return a + b;
}
```

## 6. 本章小结

### 1. 陷阱总结

| 类型 | 常见问题 | 解决方案 |
|-----|---------|---------|
| 内存 | 泄漏、越界、野指针 | 及时释放、检查边界、置空指针 |
| 并发 | 竞态、死锁 | 原子操作、互斥锁、有序加锁 |
| 性能 | 频繁分配、缓存不友好 | 重用内存、优化访问模式 |

### 2. 最佳实践

```
1. 防御性编程 - 检查所有输入和返回值
2. 资源管理 - RAII、及时释放
3. 代码规范 - 一致的风格、有意义的命名
4. 测试驱动 - 编写测试用例
5. 持续重构 - 保持代码整洁
```
