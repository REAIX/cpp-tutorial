## 1. 关键字全览

### 1. 概念与定义

**关键字（keyword）**：C++语言预定义的保留标识符，具有特殊的语法含义，不能用作变量名、函数名或其他标识符。关键字是语言的核心组成部分，编译器通过关键字来解析代码结构。

**标识符（identifier）**：程序员自定义的名称，用于命名变量、函数、类等。标识符不能与关键字同名。

## 2. C++特有关键字详解

### 2.1 class / struct / union 区别

#### 概念与定义

**class**：C++中用于定义类的关键字，默认成员访问权限为`private`，支持继承、多态等面向对象特性。

**struct**：C++中用于定义结构体的关键字，默认成员访问权限为`public`，与`class`功能几乎完全相同，仅在默认权限上有差异。

**union**：C++中用于定义联合体的关键字，所有成员共享同一内存空间，同一时刻只能存储一个成员的值。

#### 对比表

| 特性 | class | struct | union |
|------|-------|--------|-------|
| 默认访问权限 | private | public | public |
| 默认继承权限 | private | public | — |
| 成员共享内存 | 否 | 否 | 是 |
| 支持虚函数 | 是 | 是 | 有限支持 |
| 支持静态成员 | 是 | 是 | 是 |
| 可有构造/析构 | 是 | 是 | 有限(C++11起) |

#### 代码示例

```cpp
// class - 默认private
class MyClass {
    int x;           // 默认private
public:
    int y;           // 显式public
    void func() {}
};

// struct - 默认public
struct MyStruct {
    int x;           // 默认public
private:
    int y;           // 显式private
};

// union - 共享内存
union MyUnion {
    int i;
    float f;
    char c;
};  // sizeof(MyUnion) == max(sizeof(int), sizeof(float), sizeof(char))

// C++11: union可以有构造函数（限制成员类型）
union SafeUnion {
    int i;
    float f;
    SafeUnion() : i(0) {}
    ~SafeUnion() {}
};
```

#### 使用建议

- 需要封装时用`class`，明确表达"这是一个有行为的对象"
- 纯数据容器用`struct`，明确表达"这是一组数据的集合"
- 需要节省内存且成员互斥时用`union`

### 2.2 virtual / override / final

#### 概念与定义

**virtual**：声明虚函数，支持运行时多态。虚函数通过虚函数表（vtable）实现动态绑定。

**override**（C++11）：显式标记派生类重写了基类的虚函数，编译器会检查基类是否存在对应虚函数。

**final**（C++11）：标记类不可被继承，或虚函数不可被重写。

#### 代码示例

```cpp
class Base {
public:
    virtual void func1() { cout << "Base::func1" << endl; }
    virtual void func2() { cout << "Base::func2" << endl; }
    virtual void func3() final { cout << "Base::func3 final" << endl; }
};

class Derived : public Base {
public:
    // override确保正确重写基类虚函数
    void func1() override { cout << "Derived::func1" << endl; }

    // 错误！基类没有func4虚函数，编译报错
    // void func4() override { cout << "Derived::func4" << endl; }

    // 错误！func3被声明为final，不能重写
    // void func3() override { cout << "Derived::func3" << endl; }
};

// final修饰类，不可被继承
class FinalClass final {
public:
    void func() {}
};

// 错误！FinalClass被声明为final
// class Child : public FinalClass {};
```

#### 使用建议

- 派生类重写虚函数时**始终使用`override`**，防止拼写错误或签名不匹配
- 不希望被继承的类或被重写的函数使用`final`
- 析构函数在多态场景下**必须声明为`virtual`**

### 2.3 new / delete vs malloc / free

#### 概念与定义

**new / delete**：C++运算符，在分配/释放内存的同时调用构造/析构函数，支持重载，可抛出异常。

**malloc / free**：C标准库函数，仅分配/释放内存，不调用构造/析构函数，返回`void*`，失败返回`NULL`。

#### 对比表

| 特性 | new/delete | malloc/free |
|------|-----------|-------------|
| 性质 | C++运算符 | C标准库函数 |
| 构造/析构 | 自动调用 | 不调用 |
| 返回类型 | 类型安全指针 | `void*` |
| 失败处理 | 抛出`bad_alloc` | 返回`NULL` |
| 大小计算 | 自动计算 | 手动计算 |
| 重载 | 可重载 | 不可重载 |
| 数组 | `new[]`/`delete[]` | 手动计算 |

#### 代码示例

```cpp
class Foo {
public:
    Foo() { cout << "构造" << endl; }
    ~Foo() { cout << "析构" << endl; }
};

// new/delete - 调用构造和析构
Foo* p1 = new Foo();    // 输出: 构造
delete p1;              // 输出: 析构

// malloc/free - 不调用构造和析构！
Foo* p2 = (Foo*)malloc(sizeof(Foo));  // 无输出
free(p2);                             // 无输出 → 资源泄漏！

// 数组
int* arr1 = new int[10];
delete[] arr1;          // 注意：必须用delete[]

int* arr2 = (int*)malloc(10 * sizeof(int));
free(arr2);

// 定位new（placement new）
char buffer[sizeof(Foo)];
Foo* p3 = new(buffer) Foo();  // 在buffer上构造
p3->~Foo();                    // 手动析构
```

#### 使用建议

- C++中**始终使用`new/delete`**，不要混用
- `new`搭配`delete`，`new[]`搭配`delete[]`，不可混用
- 优先使用智能指针（`unique_ptr`/`shared_ptr`），避免手动管理内存

### 2.4 try / catch / throw

#### 概念与定义

**try**：标记可能抛出异常的代码区域。

**catch**：捕获并处理特定类型的异常。

**throw**：抛出异常对象，中断正常执行流程。

**noexcept**（C++11）：声明函数不会抛出异常，编译器可据此优化。

#### 代码示例

```cpp
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0) {
        throw std::invalid_argument("除数不能为零");
    }
    return a / b;
}

void example() {
    try {
        double result = divide(10.0, 0.0);
        cout << result << endl;
    } catch (const std::invalid_argument& e) {
        cerr << "参数错误: " << e.what() << endl;
    } catch (const std::exception& e) {
        cerr << "异常: " << e.what() << endl;
    } catch (...) {
        cerr << "未知异常" << endl;
    }
}

// noexcept声明
void safe_func() noexcept {
    // 保证不抛异常
}

// 条件noexcept
void maybe_throw() noexcept(noexcept(divide(1.0, 2.0))) {
    // 如果divide不抛异常，此函数也不抛
}
```

#### 使用建议

- 按引用捕获异常（`catch (const exception& e)`），避免对象切片
- 异常类型使用标准异常类或其派生类
- 不要用异常替代正常的控制流
- 析构函数和移动操作应标记为`noexcept`

### 2.5 template / typename

#### 概念与定义

**template**：声明模板，支持泛型编程，包括函数模板和类模板。

**typename**：在模板中指定类型参数；在依赖类型前消除歧义，告诉编译器某个标识符是类型。

#### 代码示例

```cpp
// 函数模板
template<typename T>
T max_val(T a, T b) {
    return (a > b) ? a : b;
}

// 类模板
template<typename T, int N>
class Array {
    T data[N];
public:
    T& operator[](int i) { return data[i]; }
    int size() const { return N; }
};

// typename消除歧义
template<typename T>
void print_container(const T& container) {
    // 必须用typename，告诉编译器value_type是类型
    typename T::value_type val = container.front();
    cout << val << endl;
}

// 变参模板(C++11)
template<typename... Args>
void print(Args... args) {
    (cout << ... << args) << endl;  // C++17折叠表达式
}

// 模板特化
template<>
const char* max_val(const char* a, const char* b) {
    return (strcmp(a, b) > 0) ? a : b;
}
```

#### 使用建议

- 优先使用`typename`而非`class`声明模板类型参数，语义更清晰
- 在依赖类型前必须加`typename`关键字
- 复杂模板使用概念（C++20 concept）约束

### 2.6 namespace / using

#### 概念与定义

**namespace**：声明命名空间，防止名称冲突，组织代码逻辑。

**using**：引入命名空间成员、声明类型别名（C++11替代`typedef`）。

#### 代码示例

```cpp
// 命名空间定义
namespace Math {
    constexpr double PI = 3.14159265;

    double circle_area(double r) {
        return PI * r * r;
    }

    namespace Detail {  // 嵌套命名空间
        double helper() { return 0.0; }
    }
}

// C++17嵌套命名空间简写
namespace Company::Project::Module {
    void func() {}
}

// using声明
using Math::PI;           // 引入特定成员
using Math::circle_area;

// using指令（不推荐在头文件中使用）
using namespace std;      // 引入整个命名空间

// using类型别名（替代typedef）
using IntPtr = int*;                    // 等价于 typedef int* IntPtr;
using Callback = void(*)(int, int);     // 函数指针别名
template<typename T> using Vec = std::vector<T>;  // 模板别名

// using在派生类中引入基类构造函数
class Base {
public:
    Base(int x) {}
};

class Derived : public Base {
public:
    using Base::Base;  // 继承基类构造函数
};
```

#### 使用建议

- 头文件中**不要**使用`using namespace`
- 使用`using`声明特定成员，而非整个命名空间
- 类型别名优先使用`using`而非`typedef`

### 2.7 constexpr / consteval / constinit

#### 概念与定义

**constexpr**（C++11）：声明常量表达式，可在编译期求值。修饰变量表示编译期常量，修饰函数表示可能在编译期执行。

**consteval**（C++20）：声明立即函数（immediate function），**必须**在编译期求值。

**constinit**（C++20）：声明变量在编译期初始化，避免静态初始化顺序问题，但变量本身不一定是const。

#### 代码示例

```cpp
// constexpr - 可在编译期求值
constexpr int factorial(int n) {
    return (n <= 1) ? 1 : n * factorial(n - 1);
}

constexpr int val = factorial(5);  // 编译期计算：120
int runtime_val = factorial(10);   // 也可以运行时调用

// constexpr if (C++17)
template<typename T>
auto process(T x) {
    if constexpr (is_integral_v<T>) {
        return x + 1;      // 整型分支
    } else {
        return x + 0.5;    // 浮点分支
    }
}

// consteval - 必须在编译期求值
consteval int square(int n) {
    return n * n;
}

constexpr int s1 = square(5);  // OK：编译期求值
// int x = 10; int s2 = square(x);  // 错误！x不是编译期常量

// constinit - 编译期初始化，但运行时可修改
constinit int global_val = factorial(5);  // 编译期初始化
global_val = 100;  // OK：运行时可以修改

// 对比
constexpr int a = 42;   // 编译期常量，不可修改
constinit int b = 42;   // 编译期初始化，可修改
const int c = 42;       // 运行期初始化（可能），不可修改
```

#### 使用建议

- 能用`constexpr`就用，让编译器帮你优化
- 需要强制编译期求值时用`consteval`
- 全局变量避免静态初始化顺序问题时用`constinit`

### 2.8 concept / requires

#### 概念与定义

**concept**（C++20）：定义命名约束，描述模板参数应满足的要求，是泛型编程的类型约束机制。

**requires**（C++20）：在模板中指定约束条件，或定义约束表达式。

#### 代码示例

```cpp
#include <concepts>

// 定义概念
template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
};

template<typename T>
concept Printable = requires(T t, std::ostream& os) {
    { os << t } -> std::same_as<std::ostream&>;
};

// 使用概念约束模板
template<Addable T>
T add(T a, T b) {
    return a + b;
}

// requires子句
template<typename T>
    requires requires(T a, T b) { a + b; }
T add2(T a, T b) {
    return a + b;
}

// 简写形式
void print(const Printable auto& x) {
    cout << x << endl;
}

// 标准库概念
template<std::integral T>       // 整型
T gcd(T a, T b) { /* ... */ }

template<std::ranges::range R>  // 范围
void process(R&& r) { /* ... */ }
```

#### 使用建议

- C++20项目中优先使用概念替代SFINAE
- 使用标准库概念（`<concepts>`头文件）
- 为领域特定约束定义自定义概念

### 2.9 co_await / co_return / co_yield

#### 概念与定义

**co_await**（C++20）：挂起协程，等待异步操作完成。

**co_return**（C++20）：从协程返回值，协程中使用`co_return`替代`return`。

**co_yield**（C++20）：产出值并挂起协程，用于生成器模式。

#### 代码示例

```cpp
#include <coroutine>
#include <iostream>

// 简单生成器协程
struct Generator {
    struct promise_type {
        int current_value;

        Generator get_return_object() {
            return Generator{std::coroutine_handle<promise_type>::from_promise(*this)};
        }
        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        std::suspend_always yield_value(int value) {
            current_value = value;
            return {};
        }
        void return_void() {}
        void unhandled_exception() { throw; }
    };

    std::coroutine_handle<promise_type> handle;

    ~Generator() { if (handle) handle.destroy(); }

    bool next() { handle.resume(); return !handle.done(); }
    int value() { return handle.promise().current_value; }
};

// 使用co_yield的生成器
Generator range(int start, int end) {
    for (int i = start; i < end; ++i) {
        co_yield i;  // 产出值并挂起
    }
}

// 使用
void use_generator() {
    auto gen = range(1, 5);
    while (gen.next()) {
        cout << gen.value() << " ";  // 输出: 1 2 3 4
    }
}
```

#### 使用建议

- 协程是C++20的高级特性，建议先掌握异步编程基础
- 使用成熟的协程库（如cppcoro）而非手写promise_type
- 协程适用于I/O密集型场景，不适用于CPU密集型计算

### 3.6 上下文关键字

部分标识符只在特定上下文中作为关键字，其他位置可作为普通标识符：

| 上下文关键字 | 上下文 |
|-------------|--------|
| `override` | 成员函数声明末尾 |

| `import` | 模块声明中 |
| `module` | 模块声明中 |

```cpp
// override作为关键字

    void func() override;  // 关键字
};

// override作为变量名（合法但不推荐）
int override = 10;  // 可以编译，但不要这样做
```

## 4. 关键字与标识符的区别

### 4.1 核心区别

| 特性 | 关键字 | 标识符 |
|------|--------|--------|
| 定义者 | 语言规范 | 程序员 |
| 可否重定义 | 不可 | 可以 |
| 数量 | 固定（约90+个） | 无限 |
| 含义 | 预定义 | 自定义 |
| 保留 | 始终保留 | 作用域内有效 |

### 4.2 容易混淆的情况

```cpp
// 1. sizeof是关键字，不是函数
int x = sizeof(int);   // 关键字，编译期求值
int y = strlen("abc"); // 函数，运行时调用

// 2. nullptr是关键字，NULL是宏
int* p1 = nullptr;     // 关键字，类型为nullptr_t
int* p2 = NULL;        // 宏，定义为0或((void*)0)

// 3. override/final是上下文关键字
int override = 10;     // 合法：此处override不是关键字
void foo() override;   // 关键字：此处override是关键字

// 4. auto含义变化
// C语言：auto int x = 10;  // 自动存储期（几乎不用）
// C++11：auto x = 10;      // 类型推导

// 5. class和typename在模板中可互换
template<class T>     // OK
template<typename T>  // OK，推荐
```

## 5. 常见误用

### 5.1 误用1：混用new/delete与malloc/free

```cpp
// 错误！
int* p = new int(10);
free(p);  // 未定义行为！new分配的内存必须用delete释放

// 正确
int* p = new int(10);
delete p;
```

### 5.2 误用2：忘记override导致隐藏

```cpp
class Base {
public:
    virtual void func(int x) { cout << "Base" << endl; }
};

class Derived : public Base {
public:
    // 拼写错误或签名不匹配，不会报错，但不是重写！
    void func(double x) { cout << "Derived" << endl; }  // 隐藏，不是重写
};

// 正确：使用override
class Derived2 : public Base {
public:
    void func(int x) override { cout << "Derived2" << endl; }
};
```

### 5.3 误用3：struct与class混用导致访问权限问题

```cpp
class MyClass {
    int x;  // private！外部无法访问
};

struct MyStruct {
    int x;  // public！外部可访问
};

// 常见错误：用class定义数据容器却忘记加public
class Point {
    int x, y;  // 忘记public，外部无法访问
public:
    int getX() const { return x; }  // 只能通过getter
};
```

### 5.4 误用4：constexpr函数不一定是编译期求值

```cpp
constexpr int add(int a, int b) {
    return a + b;
}

constexpr int x = add(1, 2);   // 编译期求值
int runtime = 10;
int y = add(runtime, 20);      // 运行时求值！不是编译期

// 如果需要强制编译期求值，使用consteval（C++20）
consteval int add_compile(int a, int b) {
    return a + b;
}

constexpr int z = add_compile(1, 2);  // OK
// int w = add_compile(runtime, 20);  // 编译错误！
```

### 5.5 误用5：using namespace滥用

```cpp
// 头文件中绝对不要这样写！
// myheader.h
using namespace std;  // 污染所有包含此头文件的代码的命名空间

// 正确做法：在头文件中使用完全限定名
// myheader.h
std::string greet(const std::string& name);

// 源文件中可以局部使用
// mysource.cpp
#include "myheader.h"
using namespace std;  // 仅影响此源文件
```

### 5.6 误用6：volatile误用为线程同步

```cpp
// 错误！volatile不保证线程安全
volatile bool flag = false;

// 线程1
flag = true;

// 线程2
while (!flag) {  // 可能永远看不到flag变为true
    // 编译器可能优化掉对flag的读取
}

// 正确：使用atomic
#include <atomic>
std::atomic<bool> flag{false};

// 线程1
flag.store(true, std::memory_order_release);

// 线程2
while (!flag.load(std::memory_order_acquire)) {
    // 保证能看到flag的变化
}
```

### 5.7 误用7：delete与delete[]混用

```cpp
// 错误！
int* arr = new int[10];
delete arr;    // 未定义行为！必须用delete[]

// 正确
int* arr = new int[10];
delete[] arr;

// 单个对象
int* p = new int(10);
delete p;      // 正确
// delete[] p; // 错误！
```

### 5.8 误用8：auto推导出意外类型

```cpp
std::vector<int> vec = {1, 2, 3};

// 错误：auto推导为值类型，发生拷贝
auto val = vec[0];       // int，拷贝
auto& ref = vec[0];      // int&，引用

// 错误：auto推导为指针而非数组
int arr[10] = {};
auto a = arr;            // int*，数组退化为指针

// 常见陷阱：花括号初始化
auto x1 = 10;           // int
auto x2 = {10};         // std::initializer_list<int>！
auto x3{10};            // C++11: initializer_list; C++17: int
```

## 总结

### 关键字学习路线

```
基础关键字（数据类型、控制流）
    ↓
面向对象关键字（class、virtual、override）
    ↓
模板与泛型（template、typename、concept）
    ↓
现代C++（constexpr、auto、decltype）
    ↓
高级特性（协程、模块、概念）
```

### 核心要点

1. **关键字是保留的**：不能用作标识符，编译器会直接报错
2. **理解每个关键字的语义**：不只是语法，更要理解设计意图
3. **关注版本差异**：不同C++标准引入的关键字不同
4. **注意上下文关键字**：`override`、`final`等只在特定位置是关键字
5. **避免常见误用**：混用new/malloc、滥用using namespace等

### 关键字速查

- 需要多态？→ `virtual` + `override` + `final`
- 需要泛型？→ `template` + `typename` + `concept`
- 需要编译期计算？→ `constexpr` / `consteval`
- 需要异常安全？→ `try` / `catch` / `throw` + `noexcept`
- 需要协程？→ `co_await` / `co_return` / `co_yield`
