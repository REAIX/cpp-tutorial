## 🟢 1. 模糊测试概述

### 1.1 什么是模糊测试

模糊测试（Fuzzing）是一种自动化软件测试技术，通过向目标程序提供大量非预期输入，观察程序是否出现异常行为（崩溃、断言失败、内存泄漏等），从而发现潜在的安全漏洞。

```
模糊测试基本流程：

┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  语料库      │───▶│  输入生成/    │───▶│  目标程序    │
│  (种子)      │    │  变异引擎     │    │  (被测程序)  │
└─────────────┘    └──────────────┘    └──────┬──────┘
       ▲                                       │
       │              ┌──────────────┐         │
       │              │  覆盖率反馈   │◀────────┤
       └──────────────│  /崩溃收集    │         │
                      └──────────────┘    ┌────┴────┐
                                          │ 正常/   │
                                          │ 异常    │
                                          └─────────┘
```

### 1.2 模糊测试发展历史

```
模糊测试发展时间线：

1989 - Barton Miller（威斯康星大学）首次提出模糊测试概念
  │     使用随机数据测试Unix命令行工具
  │
2005 - Peach Fuzzer发布（基于模型的模糊测试）
  │
2007 - Sulley框架发布（协议模糊测试）
  │
2013 - AFL（American Fuzzy Lop）发布
  │     引入覆盖率引导，革命性突破
  │
2015 - LibFuzzer集成到Clang/LLVM
  │     进程内模糊测试，性能大幅提升
  │
2016 - Honggfuzz发布（Google支持）
  │
2017 - Syzkaller发布（内核模糊测试）
  │
2019 - AFL++发布（AFL社区增强版）
  │
2020 - OSS-Fuzz大规模应用
  │     覆盖900+开源项目，发现40000+漏洞
  │
2022 - CI/CD集成模糊测试成为标准实践
  │
2024 - AI辅助模糊测试（大模型生成种子/变异策略）
```

## 🟡 2. 模糊测试分类

### 2.1 按输入生成方式分类

```
模糊测试三大类型：

1. 变异型（Mutation-based）
   ┌──────────┐    ┌──────────┐    ┌──────────┐
   │ 合法输入  │───▶│ 随机变异  │───▶│ 变异输入  │
   │ (种子)    │    │ (位翻转/  │    │          │
   └──────────┘    │ 插入/删除)│    └──────────┘
                   └──────────┘
   代表：AFL、LibFuzzer

2. 生成型（Generation-based）
   ┌──────────┐    ┌──────────┐    ┌──────────┐
   │ 输入规范  │───▶│ 语法生成  │───▶│ 合成输入  │
   │ (语法/    │    │ (按规则   │    │          │
   │  模型)    │    │  构造)    │    └──────────┘
   └──────────┘    └──────────┘
   代表：Peach、Sulley、Domato

3. 导向型（Guided/Directional）
   ┌──────────┐    ┌──────────┐    ┌──────────┐
   │ 目标条件  │───▶│ 路径求解  │───▶│ 针对输入  │
   │ (目标点/  │    │ (符号执行/│    │          │
   │  约束)    │    │  梯度)    │    └──────────┘
   └──────────┘    └──────────┘
   代表：AFLGo、QSYM、Angora
```

### 2.3 变异策略详解

```cpp
// 常见变异策略实现

#include <cstdint>
#include <cstdlib>
#include <cstring>
#include <random>
#include <vector>
#include <string>

class FuzzerMutator {
public:
    FuzzerMutator() : rng_(std::random_device{}()) {}

    // 1. 位翻转（Bit Flip）
    // 随机选择一个位并翻转
    std::vector<uint8_t> bitFlip(const std::vector<uint8_t>& input) {
        auto mutated = input;
        std::uniform_int_distribution<size_t> posDist(0, input.size() * 8 - 1);
        size_t bitPos = posDist(rng_);
        size_t bytePos = bitPos / 8;
        size_t bitOffset = bitPos % 8;
        mutated[bytePos] ^= (1 << bitOffset);  // 翻转指定位
        return mutated;
    }

    // 2. 字节翻转（Byte Flip）
    // 翻转整个字节（异或0xFF）
    std::vector<uint8_t> byteFlip(const std::vector<uint8_t>& input) {
        auto mutated = input;
        std::uniform_int_distribution<size_t> posDist(0, input.size() - 1);
        size_t pos = posDist(rng_);
        mutated[pos] ^= 0xFF;
        return mutated;
    }

    // 3. 有趣值插入（Interesting Values）
    // 插入边界值和特殊值
    std::vector<uint8_t> insertInteresting(const std::vector<uint8_t>& input) {
        static const std::vector<int32_t> interestingValues = {
            0,          // 零
            1, -1,      // 正负一
            127, -128,  // int8边界
            255,        // uint8最大值
            32767, -32768, // int16边界
            65535,      // uint16最大值
            0x7FFFFFFF, 0x80000000, // int32边界
            0xFFFFFFFF, // uint32最大值
        };

        auto mutated = input;
        std::uniform_int_distribution<size_t> posDist(0, input.size() - 1);
        std::uniform_int_distribution<size_t> valDist(0, interestingValues.size() - 1);

        size_t pos = posDist(rng_);
        int32_t val = interestingValues[valDist(rng_)];

        // 以小端序写入
        for (size_t i = 0; i < sizeof(int32_t) && pos + i < mutated.size(); i++) {
            mutated[pos + i] = (val >> (i * 8)) & 0xFF;
        }
        return mutated;
    }

    // 4. Havoc（大范围随机变异）
    // 同时应用多种变异操作
    std::vector<uint8_t> havoc(const std::vector<uint8_t>& input) {
        auto mutated = input;
        std::uniform_int_distribution<int> opCount(2, 8);
        std::uniform_int_distribution<int> opDist(0, 6);

        int count = opCount(rng_);
        for (int i = 0; i < count; i++) {
            int op = opDist(rng_);
            switch (op) {
                case 0: mutated = bitFlip(mutated); break;
                case 1: mutated = byteFlip(mutated); break;
                case 2: mutated = insertInteresting(mutated); break;
                case 3: {
                    // 随机删除一段数据
                    std::uniform_int_distribution<size_t> posDist(0, mutated.size() / 2);
                    std::uniform_int_distribution<size_t> lenDist(1, mutated.size() / 4);
                    size_t pos = posDist(rng_);
                    size_t len = lenDist(rng_);
                    if (pos + len <= mutated.size()) {
                        mutated.erase(mutated.begin() + pos, mutated.begin() + pos + len);
                    }
                    break;
                }
                case 4: {
                    // 随机插入一段数据
                    std::uniform_int_distribution<size_t> posDist(0, mutated.size());
                    std::uniform_int_distribution<size_t> lenDist(1, 32);
                    std::uniform_int_distribution<uint8_t> byteDist(0, 255);
                    size_t pos = posDist(rng_);
                    size_t len = lenDist(rng_);
                    std::vector<uint8_t> insertData(len);
                    for (auto& b : insertData) b = byteDist(rng_);
                    mutated.insert(mutated.begin() + pos, insertData.begin(), insertData.end());
                    break;
                }
                case 5: {
                    // 从语料库中复制一段数据
                    // （简化版，实际AFL会从其他种子中复制）
                    std::uniform_int_distribution<size_t> posDist(0, mutated.size() / 2);
                    size_t pos = posDist(rng_);
                    size_t len = std::min(size_t(8), mutated.size() - pos);
                    // 复制自身的一段到另一位置
                    std::uniform_int_distribution<size_t> srcDist(0, mutated.size() - len);
                    size_t src = srcDist(rng_);
                    std::memcpy(mutated.data() + pos, mutated.data() + src, len);
                    break;
                }
                case 6: {
                    // 用随机字节覆盖一段
                    std::uniform_int_distribution<size_t> posDist(0, mutated.size() / 2);
                    std::uniform_int_distribution<size_t> lenDist(1, 16);
                    std::uniform_int_distribution<uint8_t> byteDist(0, 255);
                    size_t pos = posDist(rng_);
                    size_t len = lenDist(rng_);
                    for (size_t j = 0; j < len && pos + j < mutated.size(); j++) {
                        mutated[pos + j] = byteDist(rng_);
                    }
                    break;
                }
            }
        }
        return mutated;
    }

    // 5. 拼接（Splice）
    // 将两个不同输入的前后半部分拼接
    std::vector<uint8_t> splice(const std::vector<uint8_t>& a,
                                 const std::vector<uint8_t>& b) {
        std::uniform_int_distribution<size_t> cutDist(1, std::min(a.size(), b.size()) - 1);
        size_t cutPoint = cutDist(rng_);

        std::vector<uint8_t> result;
        result.insert(result.end(), a.begin(), a.begin() + cutPoint);
        result.insert(result.end(), b.begin() + cutPoint, b.end());
        return result;
    }

private:
    std::mt19937 rng_;
};
```

### 2.4 生成型模糊测试

```cpp
// 基于语法的输入生成器示例（JSON模糊测试）

#include <string>
#include <random>
#include <sstream>

class JsonFuzzer {
public:
    JsonFuzzer() : rng_(std::random_device{}()) {}

    // 生成随机JSON值
    std::string generate() {
        std::uniform_int_distribution<int> typeDist(0, 5);
        int type = typeDist(rng_);
        switch (type) {
            case 0: return generateNull();
            case 1: return generateBool();
            case 2: return generateNumber();
            case 3: return generateString();
            case 4: return generateArray();
            case 5: return generateObject();
            default: return "null";
        }
    }

private:
    std::string generateNull() { return "null"; }

    std::string generateBool() {
        return rng_() % 2 ? "true" : "false";
    }

    std::string generateNumber() {
        std::uniform_int_distribution<int> typeDist(0, 3);
        switch (typeDist(rng_)) {
            case 0: return "0";                           // 零
            case 1: return std::to_string(rng_());        // 随机整数
            case 2: {                                     // 随机浮点数
                double d = static_cast<double>(rng_()) / rng_();
                std::ostringstream oss;
                oss << d;
                return oss.str();
            }
            case 3: {                                     // 特殊值
                static const std::vector<std::string> special = {
                    "1e308", "-1e308", "1e-308", "Infinity", "-Infinity",
                    "NaN", "1.7976931348623157e+308",  // DBL_MAX
                    "2.2250738585072014e-308",          // DBL_MIN
                };
                std::uniform_int_distribution<size_t> idx(0, special.size() - 1);
                return special[idx(rng_)];
            }
            default: return "0";
        }
    }

    std::string generateString() {
        std::uniform_int_distribution<size_t> lenDist(0, 32);
        std::uniform_int_distribution<int> charDist(0, 4);
        size_t len = lenDist(rng_);

        std::string result = "\"";
        for (size_t i = 0; i < len; i++) {
            switch (charDist(rng_)) {
                case 0: result += static_cast<char>(rng_() % 128); break;  // ASCII
                case 1: result += "\\n"; break;   // 转义字符
                case 2: result += "\\t"; break;
                case 3: result += "\\u0041"; break;  // Unicode转义
                case 4: result += static_cast<char>(0xC0 + (rng_() % 4));  // UTF-8多字节
                        result += static_cast<char>(0x80 + (rng_() % 64));
                        break;
            }
        }
        result += "\"";
        return result;
    }

    std::string generateArray() {
        std::uniform_int_distribution<size_t> lenDist(0, 5);
        size_t len = lenDist(rng_);

        std::string result = "[";
        for (size_t i = 0; i < len; i++) {
            if (i > 0) result += ", ";
            result += generate();  // 递归生成
        }
        result += "]";
        return result;
    }

    std::string generateObject() {
        std::uniform_int_distribution<size_t> lenDist(0, 4);
        size_t len = lenDist(rng_);

        std::string result = "{";
        for (size_t i = 0; i < len; i++) {
            if (i > 0) result += ", ";
            result += generateString() + ": " + generate();  // 键值对
        }
        result += "}";
        return result;
    }

    std::mt19937 rng_;
};
```

### 2.5 导向型模糊测试

```
导向型模糊测试（Directed Fuzzing）：

目标：更快到达特定代码位置（如危险函数调用点）

方法：
1. 模拟退火距离计算
   ┌─────────────────────────────────────┐
   │  控制流图(CFG)                       │
   │                                      │
   │  A ──▶ B ──▶ C ──▶ [目标点]         │
```

### 3.4 C++目标程序适配

```cpp
// AFL目标程序适配示例：模糊测试一个JSON解析器

#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <string>
#include <fstream>
#include <sstream>

// 简单的JSON解析器（被测目标）
class SimpleJsonParser {
public:
    enum ParseResult {
        PARSE_OK,
        PARSE_INVALID_VALUE,
        PARSE_EXPECT_COMMA_OR_BRACKET,
        PARSE_EXPECT_KEY,
        PARSE_EXPECT_COLON,
        PARSE_NUMBER_TOO_BIG,
        PARSE_MISS_QUOTATION_MARK,
        PARSE_ROOT_NOT_SINGULAR
    };

    ParseResult parse(const std::string& json) {
        pos_ = 0;
        json_ = json;
        parseWhitespace();
        if (json_.empty()) return PARSE_INVALID_VALUE;
        ParseResult ret = parseValue();
        if (ret == PARSE_OK) {
            parseWhitespace();
            if (pos_ < json_.size()) return PARSE_ROOT_NOT_SINGULAR;
        }
        return ret;
    }

private:
    size_t pos_;
    std::string json_;

    void parseWhitespace() {
        while (pos_ < json_.size() &&
               (json_[pos_] == ' ' || json_[pos_] == '\t' ||
                json_[pos_] == '\n' || json_[pos_] == '\r')) {
            pos_++;
        }
    }

    ParseResult parseValue() {
        if (pos_ >= json_.size()) return PARSE_EXPECT_COMMA_OR_BRACKET;
        switch (json_[pos_]) {
            case 'n': return parseLiteral("null");
            case 't': return parseLiteral("true");
            case 'f': return parseLiteral("false");
            case '"': return parseString();
            case '[': return parseArray();
            case '{': return parseObject();
            default:  return parseNumber();
        }
    }

    ParseResult parseLiteral(const char* literal) {
        size_t len = strlen(literal);
        if (json_.compare(pos_, len, literal) == 0) {
            pos_ += len;
            return PARSE_OK;
        }
        return PARSE_INVALID_VALUE;
    }

    ParseResult parseNumber() {
        // 简化的数字解析
        size_t start = pos_;
        if (pos_ < json_.size() && json_[pos_] == '-') pos_++;
        if (pos_ >= json_.size() || !isdigit(json_[pos_]))
            return PARSE_INVALID_VALUE;
        while (pos_ < json_.size() && isdigit(json_[pos_])) pos_++;
        if (pos_ < json_.size() && json_[pos_] == '.') {
            pos_++;
            if (pos_ >= json_.size() || !isdigit(json_[pos_]))
                return PARSE_INVALID_VALUE;
            while (pos_ < json_.size() && isdigit(json_[pos_])) pos_++;
        }
        if (pos_ < json_.size() && (json_[pos_] == 'e' || json_[pos_] == 'E')) {
            pos_++;
            if (pos_ < json_.size() && (json_[pos_] == '+' || json_[pos_] == '-'))
                pos_++;
            if (pos_ >= json_.size() || !isdigit(json_[pos_]))
                return PARSE_INVALID_VALUE;
            while (pos_ < json_.size() && isdigit(json_[pos_])) pos_++;
        }
        // 尝试转换检测溢出
        try {
            size_t idx;
            std::stod(json_.substr(start, pos_ - start), &idx);
        } catch (...) {
            return PARSE_NUMBER_TOO_BIG;
        }
        return PARSE_OK;
    }

    ParseResult parseString() {
        pos_++;  // 跳过开始引号
        while (pos_ < json_.size()) {
            if (json_[pos_] == '\\') {
                pos_ += 2;  // 跳过转义字符
            } else if (json_[pos_] == '"') {
                pos_++;  // 跳过结束引号
                return PARSE_OK;
            } else {
                pos_++;
            }
        }
        return PARSE_MISS_QUOTATION_MARK;
    }

    ParseResult parseArray() {
        pos_++;  // 跳过 '['
        parseWhitespace();
        if (pos_ < json_.size() && json_[pos_] == ']') {
            pos_++;
            return PARSE_OK;
        }
        for (;;) {
            ParseResult ret = parseValue();
            if (ret != PARSE_OK) return ret;
            parseWhitespace();
            if (pos_ >= json_.size()) return PARSE_EXPECT_COMMA_OR_BRACKET;
            if (json_[pos_] == ',') {
                pos_++;
                parseWhitespace();
            } else if (json_[pos_] == ']') {
                pos_++;
                return PARSE_OK;
            } else {
                return PARSE_EXPECT_COMMA_OR_BRACKET;
            }
        }
    }

    ParseResult parseObject() {
        pos_++;  // 跳过 '{'
        parseWhitespace();
        if (pos_ < json_.size() && json_[pos_] == '}') {
            pos_++;
            return PARSE_OK;
        }
        for (;;) {
            if (pos_ >= json_.size() || json_[pos_] != '"')
                return PARSE_EXPECT_KEY;
            ParseResult ret = parseString();
            if (ret != PARSE_OK) return ret;
            parseWhitespace();
            if (pos_ >= json_.size() || json_[pos_] != ':')
                return PARSE_EXPECT_COLON;
            pos_++;
            parseWhitespace();
            ret = parseValue();
            if (ret != PARSE_OK) return ret;
            parseWhitespace();
            if (pos_ >= json_.size()) return PARSE_EXPECT_COMMA_OR_BRACKET;
            if (json_[pos_] == ',') {
                pos_++;
                parseWhitespace();
            } else if (json_[pos_] == '}') {
                pos_++;
                return PARSE_OK;
            } else {
                return PARSE_EXPECT_COMMA_OR_BRACKET;
            }
        }
    }
};

// ============ AFL主函数 ============

int main(int argc, char* argv[]) {
    if (argc < 2) {
        fprintf(stderr, "用法: %s <输入文件>\n", argv[0]);
        return 1;
    }

    // 读取输入文件
    std::ifstream file(argv[1], std::ios::binary);
    if (!file.is_open()) {
        fprintf(stderr, "无法打开文件: %s\n", argv[1]);
        return 1;
    }

    std::stringstream buffer;
    buffer << file.rdbuf();
    std::string input = buffer.str();

    // 解析输入
    SimpleJsonParser parser;
    SimpleJsonParser::ParseResult result = parser.parse(input);

    // 返回值影响AFL的执行路径追踪
    // 不同的返回值会产生不同的覆盖率信号
    return static_cast<int>(result);
}
```

### 4.3 LibFuzzer高级特性

```cpp
// LibFuzzer 自定义变异器

#include <cstdint>
#include <cstddef>
#include <cstring>
#include <random>

// 自定义变异器
// 可以实现协议感知的变异
extern "C" size_t LLVMFuzzerCustomMutator(
    uint8_t* data,          // 可修改的输入缓冲区
    size_t size,            // 当前输入大小
    size_t max_size,        // 最大允许大小
    unsigned int seed       // 随机种子
) {
    std::mt19937 rng(seed);

    // 选择变异策略
    std::uniform_int_distribution<int> strategyDist(0, 3);
    int strategy = strategyDist(rng);

    switch (strategy) {
        case 0: {
            // 策略1：修改头部字段
            if (size >= 4) {
                std::uniform_int_distribution<int> fieldDist(0, 3);
                int field = fieldDist(rng);
                data[field] ^= 0xFF;  // 翻转头部字节
            }
            return size;
        }
        case 1: {
            // 策略2：修改有效载荷
            if (size > 4) {
                std::uniform_int_distribution<size_t> posDist(4, size - 1);
                size_t pos = posDist(rng_);
                data[pos] = rng() % 256;
            }
            return size;
        }
        case 2: {
            // 策略3：截断输入
            if (size > 4) {
                std::uniform_int_distribution<size_t> lenDist(4, size);
                return lenDist(rng);
            }
            return size;
        }
        case 3: {
            // 策略4：扩展输入
            if (size < max_size) {
                size_t newSize = std::min(size + (rng() % 32 + 1), max_size);
                for (size_t i = size; i < newSize; i++) {
                    data[i] = rng() % 256;
                }
                return newSize;
            }
            return size;
        }
    }
    return size;
}

// 自定义交叉操作（将两个输入合并）
extern "C" size_t LLVMFuzzerCustomCrossOver(
    const uint8_t* data1, size_t size1,
    const uint8_t* data2, size_t size2,
    uint8_t* out, size_t max_out_size,
    unsigned int seed
) {
    std::mt19937 rng(seed);

    // 简单的交叉策略：取data1的前半部分和data2的后半部分
    size_t cut1 = size1 / 2;
    size_t cut2 = size2 / 2;
    size_t outSize = 0;

    // 复制data1的前半部分
    size_t copyLen = std::min(cut1, max_out_size);
    memcpy(out, data1, copyLen);
    outSize = copyLen;

    // 复制data2的后半部分
    copyLen = std::min(size2 - cut2, max_out_size - outSize);
    memcpy(out + outSize, data2 + cut2, copyLen);
    outSize += copyLen;

    return outSize;
}
```

### 4.5 结构感知模糊测试

```cpp
// 使用FuzzedDataProvider进行结构感知模糊测试

#include <cstdint>
#include <cstddef>
#include <string>
#include <vector>
#include <optional>

// FuzzedDataProvider头文件（LLVM提供）
#include <fuzzer/FuzzedDataProvider.h>

// 被测试的协议解析器
class ProtocolParser {
public:
    struct Header {
        uint8_t version;
        uint8_t type;
        uint16_t flags;
        uint32_t length;
    };

    struct Packet {
        Header header;
        std::vector<uint8_t> payload;
        std::optional<uint32_t> checksum;
    };

    bool parse(const uint8_t* data, size_t size) {
        if (size < sizeof(Header)) return false;

        Header header;
        memcpy(&header, data, sizeof(Header));

        // 版本检查
        if (header.version != 1 && header.version != 2) return false;

        // 长度检查
        if (header.length > size - sizeof(Header)) return false;

        // 解析有效载荷
        const uint8_t* payload = data + sizeof(Header);

        switch (header.type) {
            case 0x01: return parseDataPacket(header, payload, header.length);
            case 0x02: return parseControlPacket(header, payload, header.length);
            case 0x03: return parseAckPacket(header, payload, header.length);
            default:   return false;
        }
    }

private:
    bool parseDataPacket(const Header& hdr, const uint8_t* data, size_t len) {
        // 数据包解析逻辑
        return len > 0;
    }

    bool parseControlPacket(const Header& hdr, const uint8_t* data, size_t len) {
        // 控制包解析逻辑
        return len >= 4;
    }

    bool parseAckPacket(const Header& hdr, const uint8_t* data, size_t len) {
        // 确认包解析逻辑
        return len == 4;
    }
};

// 使用FuzzedDataProvider的结构感知模糊测试
extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
    FuzzedDataProvider provider(data, size);

    // 按协议结构消费数据
    uint8_t version = provider.ConsumeIntegralInRange<uint8_t>(1, 2);
    uint8_t type = provider.ConsumeIntegralInRange<uint8_t>(0, 3);
    uint16_t flags = provider.ConsumeIntegral<uint16_t>();
    uint32_t length = provider.ConsumeIntegral<uint32_t>();

    // 消费剩余数据作为有效载荷
    std::vector<uint8_t> payload = provider.ConsumeRemainingBytes<uint8_t>();

    // 构造协议数据包
    std::vector<uint8_t> packet;
    packet.push_back(version);
    packet.push_back(type);
    packet.push_back(flags & 0xFF);
    packet.push_back((flags >> 8) & 0xFF);
    packet.push_back(length & 0xFF);
    packet.push_back((length >> 8) & 0xFF);
    packet.push_back((length >> 16) & 0xFF);
    packet.push_back((length >> 24) & 0xFF);
    packet.insert(packet.end(), payload.begin(), payload.end());

    // 测试解析器
    ProtocolParser parser;
    parser.parse(packet.data(), packet.size());

    return 0;
}
```

## 🟡 5. 覆盖率引导技术

### 5.1 覆盖率类型

```
覆盖率类型对比：

1. 基本块覆盖率（Basic Block Coverage）
   ┌──────────────────────────────────┐
   │  记录每个基本块是否被执行         │
   │  优点：简单高效                   │
   │  缺点：粒度太粗，可能遗漏路径     │
   │                                  │
   │  A ──▶ B ──▶ C                  │
   │  基本块：A=1, B=1, C=1           │
   │  覆盖率：3/3 = 100%              │
   └──────────────────────────────────┘

2. 边覆盖率（Edge Coverage，AFL使用）
   ┌──────────────────────────────────┐
   │  记录基本块之间的转移是否被执行   │
   │  优点：更精确，能区分不同路径     │
   │  缺点：需要更多存储空间           │
   │                                  │
   │  A ──▶ B ──▶ C                  │
   │  边：A→B=1, B→C=1               │
   │  vs                              │
   │  A ──▶ C ──▶ B                  │
   │  边：A→C=1, C→B=1               │
   │  （基本块覆盖相同，边覆盖不同）   │
   └──────────────────────────────────┘

3. 路径覆盖率（Path Coverage）
   ┌──────────────────────────────────┐
   │  记录完整的执行路径               │
   │  优点：最精确                     │
   │  缺点：路径爆炸，不可扩展         │
   │                                  │
   │  路径1：A→B→C→D                 │
   │  路径2：A→B→E→D                 │
   │  路径3：A→F→C→D                 │
   │  ...（指数级增长）                │
   └──────────────────────────────────┘

4. 上下文敏感覆盖率（Context-Sensitive）
   ┌──────────────────────────────────┐
   │  记录调用上下文中的边覆盖         │
   │  优点：区分不同调用上下文         │
   │  缺点：存储开销大                 │
   │                                  │
   │  foo()调用bar()：foo→bar=1       │
   │  baz()调用bar()：baz→bar=1       │
   │  （同一函数不同调用者区分记录）   │
   └──────────────────────────────────┘
```

### 5.2 AFL边覆盖实现

```cpp
// AFL边覆盖率追踪原理

// AFL使用共享内存位图记录边覆盖
// 位图大小：1 << 16 = 65536个桶

// 插桩代码（编译器自动插入）
// 在每个基本块转移点插入：
//
//   cur_location = <COMPILE_TIME_RANDOM>;   // 当前位置ID
//   shared_mem[cur_location ^ prev_location]++;  // 记录边
//   prev_location = cur_location >> 1;       // 右移1位避免A→B和B→A混淆

// 示例：
// 基本块A的ID = 0x1234
// 基本块B的ID = 0x5678
//
// A→B的边ID = 0x1234 ^ 0x5678 = 0x444C
// B→A的边ID = 0x5678 ^ (0x1234 >> 1) = 0x5678 ^ 0x091A = 0x5F62
// （A→B和B→A是不同的边）

// 共享内存位图结构
struct CoverageMap {
    static constexpr size_t MAP_SIZE = 1 << 16;  // 65536

    // 每个桶记录该边被执行的次数
    // 使用8位计数器，溢出时饱和
    uint8_t edges[MAP_SIZE];

    void recordEdge(uint32_t current, uint32_t previous) {
        uint32_t edgeId = current ^ previous;
        // 饱和计数：不超过255
        if (edges[edgeId] < 255) {
            edges[edgeId]++;
        }
    }

    // 计算新覆盖率
    // 返回新发现的边数
    size_t countNewEdges(const CoverageMap& other) const {
        size_t newEdges = 0;
        for (size_t i = 0; i < MAP_SIZE; i++) {
            if (edges[i] && !other.edges[i]) {
                newEdges++;
            }
        }
        return newEdges;
    }
};

// AFL的覆盖率评分策略
class CoverageScorer {
public:
    // 计算输入的覆盖率分数
    // 分数越高，输入越有价值
    double score(const CoverageMap& current, const CoverageMap& baseline) {
        size_t newEdges = 0;
        size_t newHitCounts = 0;

        for (size_t i = 0; i < CoverageMap::MAP_SIZE; i++) {
            if (current.edges[i] && !baseline.edges[i]) {
                newEdges++;  // 发现新边
            }
            if (current.edges[i] > baseline.edges[i]) {
                newHitCounts++;  // 发现新的执行次数
            }
        }

        // 新边权重更高
        return newEdges * 10.0 + newHitCounts * 1.0;
    }

    // 判断输入是否"有趣"（值得保留）
    bool isInteresting(const CoverageMap& current, const CoverageMap& baseline) {
        for (size_t i = 0; i < CoverageMap::MAP_SIZE; i++) {
            // 新边
            if (current.edges[i] && !baseline.edges[i]) return true;
            // 新的执行次数桶
            // AFL将执行次数分为8个桶：
            // 1, 2, 3, 4-7, 8-15, 16-31, 32-127, 128+
            if (getBucket(current.edges[i]) > getBucket(baseline.edges[i])) {
                return true;
            }
        }
        return false;
    }

private:
    // 执行次数到桶的映射
    static int getBucket(uint8_t count) {
        if (count == 0) return 0;
        if (count == 1) return 1;
        if (count == 2) return 2;
        if (count == 3) return 3;
        if (count <= 7) return 4;
        if (count <= 15) return 5;
        if (count <= 31) return 6;
        if (count <= 127) return 7;
        return 8;
    }
};
```

### 5.3 语料蒸馏

```
语料蒸馏（Corpus Minimization）：

目的：从大量语料中选出最小的子集，保持相同的覆盖率

过程：

│ 2. seed_002 (15B) → 新覆盖率 +8  → 保留 ✓       │

│                                                  │
```

```
   │      input[1] == 'A' &&                  │
   │      input[2] == 'G' &&                  │

   ┌──────────────────────────────────────────┐

   │  - 共享内存竞争                          │
   │  - 大型程序插桩开销                      │
   │  - 网络模糊测试速度限制                  │
   └──────────────────────────────────────────┘
```

### 6.2 崩溃去重

```cpp
// 崩溃去重方法

#include <string>
#include <vector>
#include <set>
#include <map>
#include <fstream>
#include <sstream>

class CrashDeduplicator {
public:
    // 方法1：基于调用栈哈希去重
    // 两个崩溃如果调用栈相同，很可能是同一个漏洞
    struct StackHash {
        std::string hash;

        static StackHash fromStackTrace(const std::vector<std::string>& stack) {
            // 取调用栈的前N帧计算哈希
            std::string combined;
            int framesToUse = std::min(static_cast<int>(stack.size()), 5);
            for (int i = 0; i < framesToUse; i++) {
                combined += stack[i] + ";";
            }
            // 简单哈希（实际应使用更安全的哈希函数）
            size_t h = 0;
            for (char c : combined) {
                h = h * 31 + c;
            }
            StackHash sh;
            sh.hash = std::to_string(h);
            return sh;
        }

        bool operator<(const StackHash& other) const {
            return hash < other.hash;
        }
    };

    // 方法2：基于覆盖率去重
    // 两个崩溃如果触发了相同的覆盖率路径，可能是同一漏洞
    struct CoverageHash {
        std::set<uint32_t> coveredEdges;

        static CoverageHash fromCoverage(const uint8_t* map, size_t size) {
            CoverageHash ch;
            for (size_t i = 0; i < size; i++) {
                if (map[i] > 0) {
                    ch.coveredEdges.insert(static_cast<uint32_t>(i));
                }
            }
            return ch;
        }

        bool operator<(const CoverageHash& other) const {
            return coveredEdges < other.coveredEdges;
        }
    };

    // 方法3：基于崩溃点地址去重
    // 两个崩溃如果崩溃地址相同，可能是同一漏洞
    struct CrashAddress {
        uintptr_t address;

        bool operator<(const CrashAddress& other) const {
            return address < other.address;
        }
    };

    // 综合去重
    struct CrashInfo {
        std::string crashFile;       // 崩溃输入文件路径
        int signal;                   // 信号编号
        StackHash stackHash;          // 调用栈哈希
        CoverageHash coverageHash;    // 覆盖率哈希
        CrashAddress crashAddress;    // 崩溃地址
        std::string asanOutput;       // ASan输出
    };

    // 添加崩溃并判断是否为新崩溃
    bool addCrash(const CrashInfo& crash) {
        // 综合判断：调用栈+覆盖率+地址
        std::string dedupKey = crash.stackHash.hash + "_" +
                               std::to_string(crash.crashAddress.address);

        if (seenCrashes_.find(dedupKey) != seenCrashes_.end()) {
            return false;  // 重复崩溃
        }

        seenCrashes_.insert(dedupKey);
        uniqueCrashes_.push_back(crash);
        return true;  // 新崩溃
    }

    size_t uniqueCount() const { return uniqueCrashes_.size(); }

private:
    std::set<std::string> seenCrashes_;
    std::vector<CrashInfo> uniqueCrashes_;
};
```

```cpp
// 崩溃可利用性评估

#include <string>
#include <map>

// 基于信号和ASan输出的简单可利用性评估
class ExploitabilityEvaluator {
public:
    enum Exploitability {
        HIGH,       // 高可利用性（远程代码执行）
        MEDIUM,     // 中可利用性（信息泄露/拒绝服务）
        LOW,        // 低可利用性（拒绝服务）
        UNKNOWN     // 未知
    };

    struct Evaluation {
        Exploitability level;
        std::string vulnerabilityType;
        std::string description;
    };

    Evaluation evaluate(int signal, const std::string& asanOutput) {
        Evaluation eval;

        // 根据ASan输出判断漏洞类型
        if (asanOutput.find("heap-buffer-overflow") != std::string::npos) {
            eval.level = HIGH;
            eval.vulnerabilityType = "堆缓冲区溢出";
            eval.description = "堆上的越界读写，可能实现任意代码执行";
        }
        else if (asanOutput.find("stack-buffer-overflow") != std::string::npos) {
            eval.level = HIGH;
            eval.vulnerabilityType = "栈缓冲区溢出";
            eval.description = "栈上的越界写，可能覆盖返回地址实现代码执行";
        }
        else if (asanOutput.find("heap-use-after-free") != std::string::npos) {
            eval.level = HIGH;
            eval.vulnerabilityType = "释放后使用(UAF)";
            eval.description = "使用已释放的堆内存，可能实现任意代码执行";
        }
        else if (asanOutput.find("double-free") != std::string::npos) {
            eval.level = MEDIUM;
            eval.vulnerabilityType = "双重释放";
            eval.description = "同一内存被释放两次，可能导致堆元数据损坏";
        }
        else if (asanOutput.find("stack-use-after-return") != std::string::npos) {
            eval.level = MEDIUM;
            eval.vulnerabilityType = "返回后使用栈";
            eval.description = "访问函数返回后的栈变量，信息泄露风险";
        }
        else if (asanOutput.find("global-buffer-overflow") != std::string::npos) {
            eval.level = MEDIUM;
            eval.vulnerabilityType = "全局缓冲区溢出";
            eval.description = "全局变量越界访问，可能修改关键数据";
        }
        else if (signal == 11) {
            // SIGSEGV，无ASan信息
            eval.level = LOW;
            eval.vulnerabilityType = "段错误";
            eval.description = "空指针解引用或无效内存访问，通常是拒绝服务";
        }
        else if (signal == 6) {
            // SIGABRT
            eval.level = LOW;
            eval.vulnerabilityType = "断言失败";
            eval.description = "程序断言失败，通常是拒绝服务";
        }
        else if (signal == 8) {
            // SIGFPE
            eval.level = LOW;
            eval.vulnerabilityType = "算术异常";
            eval.description = "除零或浮点异常，通常是拒绝服务";
        }
        else {
            eval.level = UNKNOWN;
            eval.vulnerabilityType = "未知";
            eval.description = "无法确定漏洞类型和可利用性";
        }

        return eval;
    }

    // 生成崩溃分析报告
    std::string generateReport(const std::string& crashFile,
                                int signal,
                                const std::string& asanOutput,
                                const Evaluation& eval) {
        std::string levelStr;
        switch (eval.level) {
            case HIGH:   levelStr = "🔴 高"; break;
            case MEDIUM: levelStr = "🟡 中"; break;
            case LOW:    levelStr = "🟢 低"; break;
            default:     levelStr = "⚪ 未知"; break;
        }

        return "=== 崩溃分析报告 ===\n"
               "崩溃文件: " + crashFile + "\n"
               "信号: " + std::to_string(signal) + "\n"
               "漏洞类型: " + eval.vulnerabilityType + "\n"
               "可利用性: " + levelStr + "\n"
               "描述: " + eval.description + "\n"
               "ASan输出:\n" + asanOutput + "\n";
    }
};
```

### 7.5 自动化漏洞报告工具

```python
# 自动化崩溃分析和报告生成脚本

import subprocess
import os
import hashlib
import json
from datetime import datetime

class CrashAnalyzer:
    """崩溃分析器：自动分析模糊测试发现的崩溃"""

    def __init__(self, target_binary, crashes_dir):
        self.target = target_binary
        self.crashes_dir = crashes_dir
        self.results = []

    def analyze_all(self):
        """分析所有崩溃文件"""
        for filename in os.listdir(self.crashes_dir):
            filepath = os.path.join(self.crashes_dir, filename)
            if os.path.isfile(filepath):
                result = self.analyze_crash(filepath)
                if result:
                    self.results.append(result)
        return self.deduplicate()

    def analyze_crash(self, crash_file):
        """分析单个崩溃文件"""
        try:
            # 运行目标程序并捕获ASan输出
            result = subprocess.run(
                [self.target, crash_file],
                capture_output=True,
                timeout=10,
                env={**os.environ, 'ASAN_OPTIONS': 'detect_leaks=0'}
            )

            # 提取信息
            asan_output = result.stderr.decode('utf-8', errors='replace')
            signal = -result.returncode if result.returncode < 0 else 0

            # 计算文件哈希
            with open(crash_file, 'rb') as f:
                file_hash = hashlib.sha256(f.read()).hexdigest()

            # 提取崩溃类型
            crash_type = self._extract_crash_type(asan_output)

            # 提取调用栈
            stack_trace = self._extract_stack_trace(asan_output)

            # 提取崩溃地址
            crash_address = self._extract_crash_address(asan_output)

            return {
                'file': crash_file,
                'hash': file_hash,
                'signal': signal,
                'crash_type': crash_type,
                'crash_address': crash_address,
                'stack_trace': stack_trace,
                'asan_output': asan_output,
                'file_size': os.path.getsize(crash_file),
                'timestamp': datetime.now().isoformat()
            }
        except subprocess.TimeoutExpired:
            return None
        except Exception as e:
            return None

    def _extract_crash_type(self, asan_output):
        """从ASan输出中提取崩溃类型"""
        for line in asan_output.split('\n'):
            if 'ERROR: AddressSanitizer:' in line:
                return line.split('ERROR: AddressSanitizer:')[1].strip()
            if 'ERROR: UndefinedBehaviorSanitizer:' in line:
                return line.split('ERROR: UndefinedBehaviorSanitizer:')[1].strip()
            if 'ERROR: MemorySanitizer:' in line:
                return line.split('ERROR: MemorySanitizer:')[1].strip()
        return 'unknown'

    def _extract_stack_trace(self, asan_output):
        """提取调用栈"""
        stack = []
        in_stack = False
        for line in asan_output.split('\n'):
            if '#0 ' in line or in_stack:
                in_stack = True
                if line.strip().startswith('#'):
                    stack.append(line.strip())
                elif not line.strip():
                    break
        return stack[:10]  # 最多取10帧

    def _extract_crash_address(self, asan_output):
        """提取崩溃地址"""
        for line in asan_output.split('\n'):
            if 'on address' in line.lower() or 'at 0x' in line.lower():
                # 提取地址
                import re
                match = re.search(r'0x[0-9a-fA-F]+', line)
                if match:
                    return match.group()
        return 'unknown'

    def deduplicate(self):
        """崩溃去重"""
        unique = {}
        for result in self.results:
            # 使用崩溃类型+调用栈前3帧作为去重键
            key = result['crash_type']
            if result['stack_trace']:
                key += '_' + '_'.join(result['stack_trace'][:3])
            if key not in unique:
                unique[key] = result
            else:
                # 保留更小的崩溃输入
                if result['file_size'] < unique[key]['file_size']:
                    unique[key] = result
        return list(unique.values())

    def generate_report(self, output_file):
        """生成分析报告"""
        unique_crashes = self.deduplicate()

        report = {
            'summary': {
                'total_crashes': len(self.results),
                'unique_crashes': len(unique_crashes),
                'analysis_time': datetime.now().isoformat()
            },
            'crashes': unique_crashes
        }

        with open(output_file, 'w', encoding='utf-8') as f:
            json.dump(report, f, indent=2, ensure_ascii=False)

        return report
```

### 7.6 CI/CD集成模糊测试

```yaml
# GitHub Actions 集成LibFuzzer示例

name: Fuzz Testing

on:
  push:
    branches: [ main ]
  schedule:
    - cron: '0 2 * * *'  # 每天凌晨2点运行

jobs:
  fuzz:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        sanitizer: [address, undefined, memory]

    steps:
      - uses: actions/checkout@v4

      - name: Install dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y clang llvm

      - name: Build fuzzer
        run: |
          export CC=clang
          export CXX=clang++
          export CFLAGS="-fsanitize=fuzzer,${{ matrix.sanitizer }} -g"
          export CXXFLAGS="-fsanitize=fuzzer,${{ matrix.sanitizer }} -g"
          mkdir build && cd build
          cmake .. -DCMAKE_C_FLAGS="$CFLAGS" -DCMAKE_CXX_FLAGS="$CXXFLAGS"
          make -j$(nproc)

      - name: Run fuzzer
        run: |
          cd build
          # 运行模糊测试，限制时间和执行次数
          for target in bin/*_fuzzer; do
            timeout 3600 ./$target -max_total_time=600 -max_len=4096 \
              -artifact_prefix=crashes/ corpus/
          done

      - name: Check for crashes
        if: always()
        run: |
          if [ -d "build/crashes" ] && [ "$(ls -A build/crashes)" ]; then
            echo "::error::Fuzzer found crashes!"
            ls -la build/crashes/
            exit 1
          fi

      - name: Upload crashes
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: crashes-${{ matrix.sanitizer }}
          path: build/crashes/

      - name: Upload corpus
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: corpus-${{ matrix.sanitizer }}
          path: build/corpus/
```

## 🟢 8. 本章小结

本章讲解了模糊测试与漏洞挖掘的核心知识，要点如下：

| 主题 | 核心要点 |
|------|---------|
| 模糊测试概述 | 自动化漏洞发现技术、发展历史、与其它测试方法对比 |
| 模糊测试分类 | 变异型/生成型/导向型、黑盒/灰盒/白盒、变异策略详解 |
| AFL与AFL++ | Fork Server架构、编译插桩、并行模糊测试、AFL++增强特性 |
| LibFuzzer | 进程内模糊测试、LLVMFuzzerTestOneInput、自定义变异器、结构感知测试 |
| 覆盖率引导 | 边覆盖原理、AFL位图、语料蒸馏、覆盖率局限性 |
| 崩溃分析 | 崩溃去重（调用栈/覆盖率/地址）、最小化、可利用性评估 |
| 漏洞报告 | 报告模板、CVE申请流程、负责任披露、CI/CD集成 |

**关键理解**：

1. **模糊测试是最有效的漏洞发现方法**：自动化程度高，发现的是真实可利用漏洞
2. **覆盖率引导是核心**：AFL的边覆盖率追踪是模糊测试的革命性突破
3. **变异策略决定效率**：好的变异策略（位翻转、有趣值、Havoc）能更快发现漏洞
4. **崩溃分析需要专业知识**：去重、最小化、可利用性评估是漏洞挖掘的关键步骤
5. **负责任披露是底线**：发现漏洞后应先通知厂商，给予修复时间后再公开
6. **CI/CD集成是趋势**：将模糊测试纳入持续集成，在开发阶段就发现漏洞

> **安全建议**：模糊测试不是万能的，应与静态分析、代码审计、渗透测试等方法结合使用，构建多层次的安全保障体系。
