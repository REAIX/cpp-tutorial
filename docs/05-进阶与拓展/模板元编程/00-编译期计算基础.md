# 编译期计算基础

> C++编译期计算核心：constexpr/consteval/constinit与编译期编程基础

---

> **If it can be done at compile time, it should be done at compile time.**
> （如果能在编译期完成，就应该在编译期完成。）

> **constexpr：让计算从运行期提前到编译期。**
> （constexpr: move computation from runtime to compile time.）

---

> **🎯 编译期计算：零运行时开销的终极武器。**

> 💡 **通俗理解 - 什么是编译期计算？**

想象你在餐厅点菜：
- **运行期计算**：你点了菜，厨师现场做，你要等（程序运行时才计算）
- **编译期计算**：菜已经提前做好了，你一点就上菜（编译时就算好了，运行直接用）

**编译期计算就是把"现场做"变成"提前做"！**

比如：
```cpp
// 运行期计算：每次运行都要算
int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}
int result = factorial(10);  // 运行时计算

// 编译期计算：编译时就算好了，运行时直接用结果
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}
constexpr int result = factorial(10);  // 编译时计算，result = 3628800
```

> 🔬 **抽象理解 - 编译期计算的本质**：
> - **constexpr**：标记"可以在编译期求值"的函数或变量，但也可在运行期求值
> - **consteval**：C++20引入，标记"必须在编译期求值"的函数（立即函数）
> - **constinit**：C++20引入，标记"必须在编译期初始化"的变量，避免静态初始化顺序问题
> - **编译期if**：`if constexpr`，在编译期根据条件选择代码分支
> - **static_assert**：编译期断言，在编译期检查条件是否成立
> - **编译期与运行期的边界**：理解什么能做、什么不能做是关键

## 1. constexpr详解

### 1.1 概念与定义

**constexpr**：C++11引入的关键字，用于声明可以在编译期求值的变量或函数。constexpr变量必须在编译期初始化，constexpr函数**可能**在编译期求值（取决于调用上下文）。

**constexpr函数的规则**：
- C++11：函数体只能包含一条return语句（极其受限）
- C++14：大幅放宽，允许局部变量、if/for/while等控制流
- C++17/20：进一步放宽，允许更多运行期构造

### 1.2 constexpr变量

```cpp
// constexpr变量：必须在编译期初始化
constexpr int max_size = 100;           // 编译期常量
constexpr double pi = 3.14159265;       // 编译期常量
constexpr int square_val = 10 * 10;     // 编译期计算

// 与const的区别
const int runtime_val = std::rand();    // OK：const可以在运行期初始化
// constexpr int bad_val = std::rand(); // 错误！constexpr必须在编译期初始化

// constexpr变量隐含const属性
constexpr int x = 42;
// x = 100;  // 错误！constexpr变量不可修改
```

### 1.3 constexpr函数

```cpp
// C++11风格的constexpr函数（极其受限）
constexpr int factorial_cxx11(int n) {
    return n <= 1 ? 1 : n * factorial_cxx11(n - 1);
}

// C++14风格的constexpr函数（大幅放宽）
constexpr int factorial(int n) {
    int result = 1;          // 允许局部变量
    for (int i = 2; i <= n; ++i) {  // 允许for循环
        result *= i;
    }
    return result;
}

// constexpr函数的双重性：编译期或运行期
constexpr int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}

int main() {
    // 编译期求值：参数是编译期常量，结果也是编译期常量
    constexpr int fib10 = fib(10);     // 编译期计算
    static_assert(fib10 == 55);

    // 运行期求值：参数是运行期值，函数在运行期执行
    int n;
    std::cin >> n;
    int result = fib(n);               // 运行期计算
    std::cout << result << std::endl;

    return 0;
}
```

### 1.4 constexpr与浮点数

```cpp
// constexpr支持浮点数运算
constexpr double circle_area(double radius) {
    constexpr double pi = 3.14159265358979323846;
    return pi * radius * radius;
}

constexpr double area = circle_area(5.0);  // 编译期计算
static_assert(area > 78.0 && area < 79.0);

// constexpr支持数学函数（C++26进一步扩展）
// C++23起，许多<cmath>函数成为constexpr

constexpr double sqrt_val = std::sqrt(2.0);  // C++23
#endif
```

### 1.5 constexpr构造函数

```cpp
// constexpr构造函数允许创建编译期对象
struct Point {
    constexpr Point(double x_, double y_) : x(x_), y(y_) {}
    constexpr double distance() const {
        return x * x + y * y;  // 简化，不调用sqrt
    }
    double x, y;
};

constexpr Point p{3.0, 4.0};
constexpr double dist = p.distance();  // 编译期计算
static_assert(dist == 25.0);

// constexpr支持复杂类型
struct Color {
    constexpr Color(unsigned char r_, unsigned char g_, unsigned char b_)
        : r(r_), g(g_), b(b_) {}
    unsigned char r, g, b;
};

constexpr Color red{255, 0, 0};
constexpr Color green{0, 255, 0};
```

### 1.6 constexpr与标准库

```cpp
#include <array>
#include <algorithm>

// C++17起，许多标准库算法成为constexpr
constexpr bool test_sort() {
    std::array<int, 5> arr{5, 3, 1, 4, 2};
    std::sort(arr.begin(), arr.end());  // C++20 constexpr
    return std::is_sorted(arr.begin(), arr.end());
}

static_assert(test_sort());

// constexpr string（C++20起有限支持）
// 注意：constexpr string在C++20中可以用于编译期，
// 但不能跨越编译期/运行期边界
constexpr size_t str_len() {
    const char* s = "hello";
    size_t len = 0;
    while (s[len]) ++len;
    return len;
}

static_assert(str_len() == 5);
```

### 1.7 编译器如何处理constexpr

理解编译器如何处理constexpr，有助于写出更高效的编译期代码。

```cpp
// 编译器处理constexpr的过程：
// 1. 解析阶段：编译器识别constexpr标记
// 2. 常量求值阶段：如果上下文要求常量表达式，编译器尝试在编译期求值
// 3. 如果求值成功：结果直接嵌入生成的代码中
// 4. 如果求值失败（如依赖运行时值）：退化为运行时调用

// 示例：观察编译器的行为
constexpr int power(int base, int exp) {
    int result = 1;
    for (int i = 0; i < exp; ++i) {
        result *= base;
    }
    return result;
}

// 情况1：编译期求值——参数都是常量
constexpr int p1 = power(2, 10);  // 编译期计算，p1 = 1024
// 编译器生成的代码等价于：
// constexpr int p1 = 1024;  // 直接嵌入结果

// 情况2：运行时求值——参数包含运行时值
int base = 2;
int exp = 10;
int p2 = power(base, exp);  // 运行时调用
// 编译器生成的代码等价于：
// int p2;  // 调用power函数计算

// 情况3：混合上下文
constexpr int p3 = power(2, 10);  // 编译期
int p4 = power(2, 10);            // 可能编译期（编译器优化），也可能运行时
// 注意：p4不是constexpr变量，编译器有权选择是否在编译期求值
```

```cpp
// 编译器生成的代码对比（伪汇编）

// 源代码：
// constexpr int factorial(int n) { return n <= 1 ? 1 : n * factorial(n-1); }
// constexpr int result = factorial(5);

// 编译器在编译期求值后，生成的代码等价于：
// mov eax, 120  ; 直接使用计算结果，没有函数调用

// 如果是运行时调用：
// int x = factorial(n);
// call factorial  ; 运行时函数调用
// mov dword ptr [x], eax

// 关键区别：
// - 编译期求值：结果直接嵌入代码，零运行时开销
// - 运行时求值：需要函数调用开销（但可能被内联优化）
```

```cpp
// std::is_constant_evaluated()：区分编译期和运行时上下文
#include <type_traits>

// 这个函数允许在同一个函数中为编译期和运行时提供不同实现
constexpr int smart_fibonacci(int n) {
    if (std::is_constant_evaluated()) {
        // 编译期：使用简单但保证正确的方法
        // 编译器对递归constexpr有深度限制，但保证正确性
        if (n <= 1) return n;
        return smart_fibonacci(n - 1) + smart_fibonacci(n - 2);
    } else {
        // 运行期：使用优化的迭代方法
        if (n <= 1) return n;
        int a = 0, b = 1;
        for (int i = 2; i <= n; ++i) {
            int temp = a + b;
            a = b;
            b = temp;
        }
        return b;
    }
}

// 编译期调用：使用递归版本
constexpr int fib_compile = smart_fibonacci(10);  // 55

// 运行期调用：使用迭代版本（更高效）
int runtime_n = 20;
int fib_runtime = smart_fibonacci(runtime_n);  // 使用迭代

// 注意陷阱：不要在if constexpr的条件中使用is_constant_evaluated
constexpr int bad_example(int n) {
    // 错误用法：if constexpr的条件必须是常量表达式
    // if constexpr (std::is_constant_evaluated()) { ... }  // 总是true！
    // 正确用法：使用普通if
    if (std::is_constant_evaluated()) {  // 正确
        return n * 2;
    } else {
        return n + n;
    }
}
```

### 1.8 constexpr常见陷阱与误区

```cpp
// 陷阱1：constexpr不保证编译期求值
constexpr int add(int a, int b) { return a + b; }

int x = 5;
int result = add(x, 3);  // 运行时调用！x不是编译期常量
// 解决：使用consteval强制编译期求值，或使用constexpr变量

// 陷阱2：constexpr函数中的未定义行为
constexpr int bad_divide(int a, int b) {
    return a / b;  // b=0时是未定义行为
}
// constexpr int bad = bad_divide(10, 0);  // 编译错误或未定义行为
// 解决：添加检查
constexpr int safe_divide(int a, int b) {
    return b != 0 ? a / b : 0;  // 安全处理
}

// 陷阱3：constexpr构造函数与虚函数
struct Bad {
    virtual void foo() { }  // 虚函数
    constexpr Bad() { }     // C++20前错误，C++20允许但有限制
};

// 陷阱4：constexpr中的reinterpret_cast
constexpr int bad_cast(int* p) {
    // return reinterpret_cast<intptr_t>(p);  // 错误！reinterpret_cast不允许
    return *p;  // OK
}

// 陷阱5：constexpr函数的递归深度限制
constexpr int deep_recursion(int n) {
    return n <= 0 ? 0 : 1 + deep_recursion(n - 1);
}
// constexpr int too_deep = deep_recursion(100000);  // 可能超出编译器限制
// 不同编译器的限制：
// - GCC: 默认512层（-fconstexpr-depth=N调整）
// - Clang: 默认512层
// - MSVC: 默认1024层

// 陷阱6：constexpr变量的生命周期
constexpr auto make_array() {
    std::array<int, 3> arr{1, 2, 3};
    return arr;  // OK：返回值拷贝
}
constexpr auto arr = make_array();  // OK

// 但注意：constexpr函数内的static变量
constexpr int counter_bad() {
    // static int count = 0;  // 错误！constexpr函数不能有static局部变量
    // ++count;
    // return count;
    return 0;
}
```

```cpp
// 陷阱7：constexpr与模板的结合
template<typename T>
constexpr T max_val(T a, T b) {
    return a > b ? a : b;
}

// 这在编译期和运行期都可以工作
constexpr int m1 = max_val(3, 5);  // 编译期
int a = 3, b = 5;
int m2 = max_val(a, b);  // 运行期

// 但如果T不支持编译期比较呢？
struct Complex {
    double real, imag;
    constexpr bool operator>(const Complex& other) const {
        // C++20前：constexpr函数中不能使用>
        // C++20后：允许
        return real * real + imag * imag >
               other.real * other.real + other.imag * imag;
    }
};

constexpr Complex c1{3.0, 4.0};
constexpr Complex c2{1.0, 1.0};
constexpr bool result = c1 > c2;  // C++20 OK

// 陷阱8：constexpr lambda
auto make_multiplier(int factor) {
    // C++17: lambda默认不是constexpr
    // C++20: lambda可以是constexpr
    return [factor](int x) constexpr {
        return x * factor;
    };
}

// constexpr lambda在编译期使用
constexpr auto doubler = make_multiplier(2);
constexpr int doubled = doubler(21);  // 42
```

### 1.9 constexpr完整实战案例：编译期查找表

```cpp
#include <array>
#include <cstdint>
#include <iostream>

// 完整案例：编译期CRC32查找表
class CRC32 {
    // 编译期生成CRC32查找表
    static constexpr std::array<uint32_t, 256> make_table() {
        std::array<uint32_t, 256> table{};
        for (std::size_t i = 0; i < 256; ++i) {
            uint32_t crc = static_cast<uint32_t>(i);
            for (int j = 0; j < 8; ++j) {
                if (crc & 1) {
                    crc = (crc >> 1) ^ 0xEDB88320u;
                } else {
                    crc >>= 1;
                }
            }
            table[i] = crc;
        }
        return table;
    }

    // 编译期生成，运行时使用
    static constexpr auto table_ = make_table();

public:
    // 运行时计算CRC32
    static uint32_t compute(const void* data, std::size_t length) {
        uint32_t crc = 0xFFFFFFFFu;
        const auto* bytes = static_cast<const uint8_t*>(data);
        for (std::size_t i = 0; i < length; ++i) {
            crc = (crc >> 8) ^ table_[(crc ^ bytes[i]) & 0xFF];
        }
        return crc ^ 0xFFFFFFFFu;
    }

    // 编译期计算CRC32（consteval版本）
    consteval static uint32_t compute_const(const char* str) {
        uint32_t crc = 0xFFFFFFFFu;
        while (*str) {
            crc = (crc >> 8) ^ table_[(crc ^ static_cast<uint8_t>(*str)) & 0xFF];
            ++str;
        }
        return crc ^ 0xFFFFFFFFu;
    }
};

// 编译期计算字符串的CRC32
constexpr uint32_t cmd_open_crc = CRC32::compute_const("open");
constexpr uint32_t cmd_close_crc = CRC32::compute_const("close");
constexpr uint32_t cmd_exit_crc = CRC32::compute_const("exit");

// 运行时使用
int main() {
    const char* test = "open";
    uint32_t crc = CRC32::compute(test, 4);
    if (crc == cmd_open_crc) {
        std::cout << "匹配open命令" << std::endl;
    }
    return 0;
}
```

## 2. consteval立即函数

### 2.1 概念与定义

**consteval**：C++20引入的关键字，声明"立即函数"（immediate function）。与constexpr不同，consteval函数**必须**在编译期求值，不允许在运行期调用。

### 2.2 基本用法

```cpp
// consteval函数：必须在编译期求值
consteval int square(int n) {
    return n * n;
}

constexpr int result1 = square(5);     // OK：编译期求值
static_assert(result1 == 25);

int x = 10;
// int result2 = square(x);           // 错误！x不是编译期常量

// 与constexpr的对比
constexpr int maybe_compile_time(int n) {
    return n * n;
}

constexpr int a = maybe_compile_time(5);  // 编译期
int b = maybe_compile_time(x);            // 运行期，OK
```

### 2.3 consteval的应用场景

```cpp
// 场景1：编译期哈希计算
consteval unsigned int hash_string(const char* str) {
    unsigned int hash = 5381;
    while (*str) {
        hash = ((hash << 5) + hash) + static_cast<unsigned char>(*str++);
    }
    return hash;
}

// 编译期计算字符串哈希，运行时直接使用
constexpr unsigned int cmd_hash = hash_string("execute");
constexpr unsigned int quit_hash = hash_string("quit");

void process_command(const std::string& cmd) {
    // 运行期哈希用于比较（注意：这里不是consteval）
    unsigned int h = 5381;
    for (char c : cmd) {
        h = ((h << 5) + h) + static_cast<unsigned char>(c);
    }
    if (h == cmd_hash) { /* 执行命令 */ }
    else if (h == quit_hash) { /* 退出 */ }
}

// 场景2：编译期类型ID生成
consteval size_t type_id_generator() {
    return __COUNTER__;  // 每次调用递增的编译期计数器
}

// 场景3：编译期配置验证
consteval bool is_valid_config(int buffer_size, int alignment) {
    return buffer_size > 0 && buffer_size % alignment == 0;
}

static_assert(is_valid_config(1024, 16));
// static_assert(is_valid_config(1000, 16));  // 编译错误！
```

### 2.4 consteval与constexpr的协作

```cpp
// consteval函数可以调用constexpr函数
constexpr int helper(int n) {
    return n * 2;
}

consteval int compute(int n) {
    return helper(n) + 1;  // OK：constexpr可在编译期求值
}

// constexpr函数可以调用consteval函数（仅当在编译期上下文中）
constexpr int wrapper(int n) {
    // return compute(n);  // 错误！n可能不是编译期常量
    return n * 2 + 1;
}

// 正确方式：在consteval上下文中调用
consteval int safe_wrapper(int n) {
    return compute(n);  // OK：整个函数是consteval
}
```

### 2.5 consteval实战案例：编译期字符串哈希与命令分发

```cpp
#include <iostream>
#include <string>
#include <string_view>

// 完整案例：使用consteval实现编译期命令哈希的命令分发系统

// FNV-1a哈希算法
consteval uint32_t fnv1a(const char* str) {
    uint32_t hash = 2166136261u;
    while (*str) {
        hash ^= static_cast<uint8_t>(*str++);
        hash *= 16777619u;
    }
    return hash;
}

// 编译期计算所有命令的哈希值
constexpr uint32_t HASH_OPEN   = fnv1a("open");
constexpr uint32_t HASH_CLOSE  = fnv1a("close");
constexpr uint32_t HASH_READ   = fnv1a("read");
constexpr uint32_t HASH_WRITE  = fnv1a("write");
constexpr uint32_t HASH_EXIT   = fnv1a("exit");
constexpr uint32_t HASH_HELP   = fnv1a("help");

// 运行时哈希计算（用于匹配用户输入）
uint32_t runtime_fnv1a(const std::string& str) {
    uint32_t hash = 2166136261u;
    for (char c : str) {
        hash ^= static_cast<uint8_t>(c);
        hash *= 16777619u;
    }
    return hash;
}

// 命令处理函数
void cmd_open()   { std::cout << "打开文件" << std::endl; }
void cmd_close()  { std::cout << "关闭文件" << std::endl; }
void cmd_read()   { std::cout << "读取数据" << std::endl; }
void cmd_write()  { std::cout << "写入数据" << std::endl; }
void cmd_exit()   { std::cout << "退出程序" << std::endl; }
void cmd_help()   { std::cout << "帮助信息" << std::endl; }

// 命令分发器
void dispatch(const std::string& cmd) {
    uint32_t hash = runtime_fnv1a(cmd);
    switch (hash) {
        case HASH_OPEN:  cmd_open();  break;
        case HASH_CLOSE: cmd_close(); break;
        case HASH_READ:  cmd_read();  break;
        case HASH_WRITE: cmd_write(); break;
        case HASH_EXIT:  cmd_exit();  break;
        case HASH_HELP:  cmd_help();  break;
        default:
            std::cout << "未知命令: " << cmd << std::endl;
    }
}

int main() {
    dispatch("open");   // 打开文件
    dispatch("read");   // 读取数据
    dispatch("exit");   // 退出程序
    dispatch("unknown"); // 未知命令: unknown
    return 0;

// - 运行时只需计算输入字符串的哈希并比较
```

## 3. constinit编译期初始化

### 3.1 概念与定义

**constinit**：C++20引入的关键字，声明必须在编译期初始化的变量。与constexpr不同，constinit变量**可以修改**，但必须**在编译期完成初始化**。主要用于解决"静态初始化顺序惨案"（Static Initialization Order Fiasco）。

### 3.2 静态初始化顺序问题

```cpp
// 文件A.cpp
int global_a = 100;  // 动态初始化

// 文件B.cpp
extern int global_a;
int global_b = global_a + 1;  // 依赖global_a的初始化顺序！
// 如果global_a在global_b之后初始化，global_b = 1（未定义行为）
```

### 3.3 constinit解决初始化顺序问题

```cpp
// constinit确保编译期初始化，消除初始化顺序依赖
constinit int global_config = 42;  // 编译期初始化，不依赖运行期

// 其他文件可以安全使用global_config
// 因为它在编译期就已经初始化完毕

// constinit与constexpr的区别
constexpr int ce_val = 42;    // 编译期初始化 + 不可修改
constinit int ci_val = 42;    // 编译期初始化 + 可以修改

int main() {
    // ce_val = 100;  // 错误！constexpr不可修改
    ci_val = 100;     // OK！constinit可以修改
    return 0;
}
```

## 4. 编译期if：if constexpr

### 4.1 概念与定义

**if constexpr**：C++17引入的编译期条件判断。与普通if不同，if constexpr在编译期求值条件，**未选中的分支会被丢弃**（不会编译），这避免了无效代码导致的编译错误。

### 4.2 基本用法

```cpp
#include <type_traits>
#include <iostream>
#include <string>

// 不使用if constexpr：SFINAE或重载，代码冗余
// 使用if constexpr：一个函数搞定
template<typename T>
auto process(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;  // 整数：乘以2
    } else if constexpr (std::is_floating_point_v<T>) {
        return value + 0.5;  // 浮点数：加0.5
    } else {
        return value;  // 其他类型：原样返回
    }
}

int main() {
    std::cout << process(10) << std::endl;      // 输出20
    std::cout << process(3.14) << std::endl;    // 输出3.64
    std::cout << process("hello") << std::endl; // 输出hello
    return 0;
}
```

### 4.3 if constexpr避免编译错误

```cpp
#include <vector>
#include <type_traits>

// 没有if constexpr：对非容器类型调用size()会编译错误
template<typename T>
auto get_size(const T& container) {
    if constexpr (requires { container.size(); }) {  // C++20概念
        return container.size();
    } else {
        return sizeof(T);
    }
}

// 经典示例：递归可变参数模板的终止条件
template<typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first;
    if constexpr (sizeof...(rest) > 0) {
        std::cout << ", ";
        print(rest...);  // 仅当还有参数时才递归
    } else {
        std::cout << std::endl;
    }
}

int main() {
    print(1, 2.5, "hello", 'c');  // 输出：1, 2.5, hello, c
    return 0;
}
```

### 4.4 if constexpr与类型推导

```cpp

#include <tuple>

void print_tuple_impl(const Tuple& t, std::index_sequence<Indices...>) {
    ((std::cout << (Indices == 0 ? "" : ", ") << std::get<Indices>(t)), ...);
}

template<typename... Args>
void print_tuple(const std::tuple<Args...>& t) {
    std::cout << "(";
    print_tuple_impl(t, std::index_sequence_for<Args...>{});
    std::cout << ")" << std::endl;
}

// if constexpr实现编译期类型转换
template<typename To, typename From>
To safe_cast(From value) {
    if constexpr (std::is_same_v<From, To>) {
        return value;  // 同类型直接返回
    } else if constexpr (std::is_integral_v<From> && std::is_floating_point_v<To>) {
        return static_cast<To>(value);  // 整数转浮点
    } else if constexpr (std::is_floating_point_v<From> && std::is_integral_v<To>) {
        // 浮点转整数：检查范围
        if (value > static_cast<From>(std::numeric_limits<To>::max()) ||
            value < static_cast<From>(std::numeric_limits<To>::min())) {
            throw std::overflow_error("转换溢出");
        }
        return static_cast<To>(value);
    } else {
        return static_cast<To>(value);  // 其他情况
    }
}
```

### 4.5 if constexpr的注意事项

```cpp
}

// 注意3：if constexpr与普通if的区别

        // 编译期判断：如果sizeof(T) <= 4，此分支完全不存在

    } else {

}
```

### 5.1 概念与定义

```cpp
    return result;
}
// 优势：代码更简洁、编译更快、可读性更好

// 最佳实践2：使用consteval确保编译期求值
// 当函数必须在编译期执行时，使用consteval而非constexpr
consteval unsigned int hash(const char* s) {
    unsigned int h = 0;
    while (*s) h = h * 31 + *s++;
    return h;
}
constexpr auto CMD_HASH = hash("command");  // 保证编译期求值

// 最佳实践3：编译期生成查找表，运行时使用
template<typename T, std::size_t N, typename Generator>
constexpr std::array<T, N> make_lookup_table(Generator gen) {
    std::array<T, N> table{};
    for (std::size_t i = 0; i < N; ++i) {
        table[i] = gen(i);
    }
    return table;
}

// 编译期生成平方查找表
constexpr auto square_table = make_lookup_table<int, 100>(
    [](std::size_t i) constexpr { return static_cast<int>(i * i); }
);

// 最佳实践4：使用static_assert验证编译期假设
template<typename T>
class SafeContainer {
    static_assert(std::is_nothrow_move_constructible_v<T>,
        "T必须是无异常移动构造的");
    static_assert(sizeof(T) <= 256,
        "T的大小不能超过256字节");
    // ...
};

// 最佳实践5：使用if constexpr替代SFINAE
// 不推荐：SFINAE
template<typename T>
std::enable_if_t<std::is_integral_v<T>, T> process_old(T x) {
    return x * 2;
}

// 推荐：if constexpr
template<typename T>
auto process_new(T x) {
    if constexpr (std::is_integral_v<T>) {
        return x * 2;
    } else if constexpr (std::is_floating_point_v<T>) {
        return x + 0.5;
    } else {
        return x;
    }
}

// 最佳实践6：避免过度使用编译期计算
// 编译期计算适合：
// - 常量定义（数学常量、查找表）
// - 类型检查（static_assert）
// - 模板约束（if constexpr, Concepts）
// - 性能关键路径的优化

// 不适合：
// - 复杂的业务逻辑（编译时间不可接受）
// - 需要运行时数据的计算
// - 调试频繁的代码（编译期错误难以调试）
```

```cpp
    static constexpr std::uintptr_t STATUS = BaseAddr + 0x04;
    static constexpr std::uintptr_t DATA   = BaseAddr + 0x08;

template<int DecimalPlaces>
struct FixedPoint {
    static constexpr int scale = DecimalPlaces;
    int64_t value;

    constexpr FixedPoint(double d = 0.0)
        : value(static_cast<int64_t>(d * power(10, DecimalPlaces))) {}

    static constexpr int64_t power(int base, int exp) {
        int64_t result = 1;
        for (int i = 0; i < exp; ++i) result *= base;
        return result;
    }

    constexpr double to_double() const {
        return static_cast<double>(value) / power(10, DecimalPlaces);
    }

    constexpr FixedPoint operator+(const FixedPoint& other) const {
        FixedPoint result;
        result.value = value + other.value;
        return result;
    }
};
```

## 小结

本章介绍了C++编译期计算的基础设施：

| 特性 | 引入版本 | 核心作用 | 是否必须编译期求值 |
|------|---------|---------|-------------------|
| `constexpr` | C++11 | 标记可在编译期求值的函数/变量 | 否（取决于上下文） |
| `consteval` | C++20 | 标记必须在编译期求值的函数 | 是 |
| `constinit` | C++20 | 标记必须在编译期初始化的变量 | 初始化时是 |
| `if constexpr` | C++17 | 编译期条件分支 | 条件部分是 |
| `static_assert` | C++11 | 编译期断言 | 是 |

**关键要点**：

1. **constexpr是编译期计算的基石**：理解其"可能"在编译期求值的特性
2. **consteval确保编译期求值**：适用于必须编译期完成的场景
3. **constinit解决初始化顺序问题**：全局变量的安全初始化
4. **if constexpr是模板编程利器**：避免SFINAE的复杂性
5. **static_assert是编译期安全网**：尽早发现设计违规
6. **理解编译期与运行期的边界**：合理选择，避免过度使用

编译期计算是C++零开销抽象的核心支撑，掌握这些基础将为后续的模板元编程打下坚实基础。
