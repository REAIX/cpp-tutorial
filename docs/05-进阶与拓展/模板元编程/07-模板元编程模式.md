# 模板元编程模式

> 掌握模板元编程常用模式，编写优雅高效的编译期代码

***

> **Patterns are the vocabulary of template metaprogramming.**
> （模式是模板元编程的词汇表。）

> **Good metaprograms read like declarations of intent, not like clever tricks.**
> （好的元程序读起来像意图声明，而不是聪明的小把戏。）

---

> **🎯 模式是经验的结晶。**
>
> （模板元编程模式是C++社区多年实践的总结，掌握这些模式可以避免重复造轮子，写出更清晰、更可维护的编译期代码。）

> 💡 **通俗理解 - 什么是模板元编程模式？**

想象一下：

- **编译期计算** 就像"在开工前算好所有尺寸"——程序运行前就得出结果
- **类型操作** 就像"流水线上的筛选器"——在编译期过滤和变换类型
- **SFINAE** 就像"试衣间"——不合适就换一件，不会报错
- **标签分发** 就像"快递分拣"——根据标签选择不同的处理通道

> 🔬 **抽象理解 - 模板元编程模式的本质**：
>
> - **编译期计算**：利用模板实例化机制在编译期执行计算
> - **类型操作**：对类型集合进行过滤、变换、查找等操作
> - **条件选择**：根据类型特征在编译期选择不同实现
> - **代码生成**：通过模板实例化自动生成重复代码

## 🟢 1. 编译期计算模式

### 1.1 阶乘

```cpp
// 编译期阶乘计算

// C++11 风格：模板递归
template<unsigned N>
struct Factorial {
    static constexpr unsigned value = N * Factorial<N - 1>::value;
};

template<>
struct Factorial<0> {
    static constexpr unsigned value = 1;
};

static_assert(Factorial<5>::value == 120);
static_assert(Factorial<10>::value == 3628800);

// C++14 风格：constexpr函数（推荐）
constexpr unsigned factorial(unsigned n) {
    unsigned result = 1;
    for (unsigned i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

static_assert(factorial(5) == 120);
static_assert(factorial(10) == 3628800);

// C++20 风格：consteval确保编译期执行
consteval unsigned factorial_cxe(unsigned n) {
    unsigned result = 1;
    for (unsigned i = 2; i <= n; ++i) result *= i;
    return result;
}

// factorial_cxe(5) 保证在编译期计算
```

### 1.2 斐波那契

```cpp
// 编译期斐波那契数列

// 模板递归版本
template<unsigned N>
struct Fibonacci {
    static constexpr unsigned value =
        Fibonacci<N - 1>::value + Fibonacci<N - 2>::value;
};

template<>
struct Fibonacci<0> { static constexpr unsigned value = 0; };

template<>
struct Fibonacci<1> { static constexpr unsigned value = 1; };

static_assert(Fibonacci<10>::value == 55);

// 问题：指数级模板实例化
// Fibonacci<10> 会实例化 Fibonacci<9>, Fibonacci<8>, ...
// Fibonacci<9> 又实例化 Fibonacci<8>, Fibonacci<7>, ...
// 大量重复实例化

// 优化：线性实例化版本
template<unsigned N, unsigned A = 0, unsigned B = 1>
struct FibonacciOpt {
    static constexpr unsigned value = FibonacciOpt<N - 1, B, A + B>::value;
};

template<unsigned A, unsigned B>
struct FibonacciOpt<0, A, B> {
    static constexpr unsigned value = A;
};

static_assert(FibonacciOpt<10>::value == 55);

// constexpr函数版本（推荐，无实例化开销）
constexpr unsigned fibonacci(unsigned n) {
    if (n <= 1) return n;
    unsigned a = 0, b = 1;
    for (unsigned i = 2; i <= n; ++i) {
        unsigned tmp = a + b;
        a = b;
        b = tmp;
    }
    return b;
}

static_assert(fibonacci(10) == 55);
```

## 🟡 2. 类型操作模式

### 2.1 类型列表

```cpp
// 类型列表（TypeList）——模板元编程的核心数据结构

// 定义
template<typename... Ts>
struct TypeList {};

// 基本操作：长度
template<typename List>
struct Length;

template<typename... Ts>
struct Length<TypeList<Ts...>> {
    static constexpr size_t value = sizeof...(Ts);
};

static_assert(Length<TypeList<int, double, char>>::value == 3);

// 基本操作：头部元素
template<typename List>
struct Head;

template<typename T, typename... Ts>
struct Head<TypeList<T, Ts...>> {
    using type = T;
};

static_assert(std::is_same_v<Head<TypeList<int, double, char>>::type, int>);

// 基本操作：尾部列表
template<typename List>
struct Tail;

template<typename T, typename... Ts>
struct Tail<TypeList<T, Ts...>> {
    using type = TypeList<Ts...>;
};

static_assert(std::is_same_v<
    Tail<TypeList<int, double, char>>::type,
    TypeList<double, char>>);

// 基本操作：追加类型
template<typename List, typename T>
struct Append;

template<typename... Ts, typename T>
struct Append<TypeList<Ts...>, T> {
    using type = TypeList<Ts..., T>;
};

static_assert(std::is_same_v<
    Append<TypeList<int, double>, char>::type,
    TypeList<int, double, char>>);

// 基本操作：按索引访问
template<typename List, size_t Index>
struct At;

template<typename T, typename... Ts>
struct At<TypeList<T, Ts...>, 0> {
    using type = T;
};

template<typename T, typename... Ts, size_t Index>
struct At<TypeList<T, Ts...>, Index> {
    using type = typename At<TypeList<Ts...>, Index - 1>::type;
};

static_assert(std::is_same_v<
    At<TypeList<int, double, char>, 1>::type,
    double>);
```

### 2.2 类型过滤

```cpp
// 编译期类型过滤

// 过滤：保留满足谓词的类型
template<typename List, template<typename> class Predicate>
struct Filter;

// 辅助：将满足条件的类型追加到结果列表
template<typename Result, typename Remaining,
         template<typename> class Predicate>
struct FilterImpl;

template<typename... Rs, template<typename> class Predicate>
struct FilterImpl<TypeList<Rs...>, TypeList<>, Predicate> {
    using type = TypeList<Rs...>;
};

template<typename... Rs, typename T, typename... Ts,
         template<typename> class Predicate>
struct FilterImpl<TypeList<Rs...>, TypeList<T, Ts...>, Predicate> {
    using type = typename std::conditional_t<
        Predicate<T>::value,
        FilterImpl<TypeList<Rs..., T>, TypeList<Ts...>, Predicate>,
        FilterImpl<TypeList<Rs...>, TypeList<Ts...>, Predicate>
    >::type;
};

template<typename... Ts, template<typename> class Predicate>
struct Filter<TypeList<Ts...>, Predicate> {
    using type = typename FilterImpl<TypeList<>, TypeList<Ts...>, Predicate>::type;
};

// 使用示例：过滤出整数类型
template<typename T>
struct IsIntegral : std::is_integral<T> {};

using AllTypes = TypeList<int, double, char, float, long, std::string>;
using OnlyIntegrals = Filter<AllTypes, IsIntegral>::type;
// OnlyIntegrals = TypeList<int, char, long>

static_assert(Length<OnlyIntegrals>::value == 3);
```

## 🟡 3. SFINAE模式进阶

### 3.1 enable_if模式

```cpp
// enable_if三种放置位置

// 模式1：返回类型（最常用）
template<typename T>
auto serialize(const T& value)
    -> std::enable_if_t<std::is_arithmetic_v<T>, std::string>
{
    return std::to_string(value);
}

// 模式2：默认模板参数（推荐，避免函数签名冲突）
template<typename T,
         std::enable_if_t<std::is_integral_v<T>, int> = 0>
std::string format(T value) {
    return std::to_string(value);
}

template<typename T,
         std::enable_if_t<std::is_floating_point_v<T>, int> = 0>
std::string format(T value) {
    return std::format("{:.2f}", value);
}

// 模式3：函数参数（较少使用）
template<typename T>
void print(T value,
           typename std::enable_if_t<std::is_integral_v<T>>* = nullptr)
{
    std::cout << "整数: " << value << std::endl;
}

// 三种方式对比：
// ┌──────────────┬──────────┬──────────┬──────────┐
// │ 放置位置      │ 可读性    │ 重载安全  │ 推荐度    │
// ├──────────────┼──────────┼──────────┼──────────┤
// │ 返回类型      │ 一般      │ 有歧义风险│ ★★★     │
// │ 默认模板参数  │ 好        │ 安全      │ ★★★★★  │
// │ 函数参数      │ 差        │ 安全      │ ★★      │
// └──────────────┴──────────┴──────────┴──────────┘
```

### 3.2 void_t模式

```cpp
// void_t：检测类型特征的标准模式

// 通用检测模板
template<typename T, typename = void>
struct has_serialize : std::false_type {};

template<typename T>
struct has_serialize<T, std::void_t<
    decltype(std::declval<const T&>().serialize())
>> : std::true_type {};

template<typename T>
inline constexpr bool has_serialize_v = has_serialize<T>::value;

// 检测成员类型
template<typename T, typename = void>
struct has_value_type : std::false_type {};

template<typename T>
struct has_value_type<T, std::void_t<typename T::value_type>>
    : std::true_type {};

// 检测运算符
template<typename T, typename = void>
struct is_iterable : std::false_type {};

template<typename T>
struct is_iterable<T, std::void_t<
    decltype(std::declval<T&>().begin()),
    decltype(std::declval<T&>().end())
>> : std::true_type {};

// 使用void_t实现概念检测
template<typename T, typename = void>
struct is_string_like : std::false_type {};

template<typename T>
struct is_string_like<T, std::void_t<
    decltype(std::declval<T&>().size()),
    decltype(std::declval<T&>().data()),
    typename T::value_type
>> : std::true_type {};

static_assert(is_string_like<std::string>::value);
static_assert(!is_string_like<int>::value);
```

## 🟡 4. 标签分发模式

```cpp
// 标签分发：通过标签类型选择不同重载

// 定义标签体系
struct random_access_iterator_tag {};
struct bidirectional_iterator_tag {};
struct forward_iterator_tag {};
struct input_iterator_tag {};

// 根据迭代器类别选择最优实现
template<typename Iterator>
void advance_impl(Iterator& it, int n,
                  random_access_iterator_tag) {
    it += n;  // O(1)
}

template<typename Iterator>
void advance_impl(Iterator& it, int n,
                  bidirectional_iterator_tag) {
    if (n >= 0) {
        for (int i = 0; i < n; ++i) ++it;
    } else {
        for (int i = 0; i < -n; ++i) --it;
    }
}

template<typename Iterator>
void advance_impl(Iterator& it, int n,
                  input_iterator_tag) {
    for (int i = 0; i < n; ++i) ++it;  // 只能前进
}

// 统一接口：根据迭代器特征分发
template<typename Iterator>
void my_advance(Iterator& it, int n) {
    advance_impl(it, n,
        typename std::iterator_traits<Iterator>::iterator_category{});
}

// 标签分发 vs SFINAE：
// 标签分发：代码更清晰，错误信息更友好
// SFINAE：更灵活，可以检测任意表达式
// 建议：优先使用标签分发，需要复杂条件时用SFINAE
```

## 🟢 5. if constexpr模式

```cpp
// C++17 if constexpr：编译期条件分支

// 基本用法
template<typename T>
auto process(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;
    } else if constexpr (std::is_floating_point_v<T>) {
        return value + 0.5;
    } else {
        return value;
    }
}

// 递归模板终止：替代偏特化
template<typename T, typename... Ts>
void print_all(const T& first, const Ts&... rest) {
    std::cout << first;
    if constexpr (sizeof...(rest) > 0) {
        std::cout << ", ";
        print_all(rest...);
    } else {
        std::cout << std::endl;
    }
}

// 编译期类型处理
template<typename T>
std::string to_string_impl(T value) {
    if constexpr (std::is_same_v<T, bool>) {
        return value ? "true" : "false";
    } else if constexpr (std::is_integral_v<T>) {
        return std::to_string(value);
    } else if constexpr (std::is_floating_point_v<T>) {
        return std::format("{:.6f}", value);
    } else if constexpr (std::is_convertible_v<T, std::string>) {
        return static_cast<std::string>(value);
    } else {
        return "<unknown type>";
    }
}

// if constexpr vs SFINAE：
// if constexpr：
//   ✅ 代码更直观
//   ✅ 错误信息更清晰
//   ❌ 不能改变函数签名（返回类型必须兼容）
// SFINAE：
//   ✅ 可以选择不同的函数签名
//   ✅ 可以用于类模板偏特化
//   ❌ 代码晦涩，错误信息难读
```

## 🟢 6. 折叠表达式模式

```cpp
// C++17 折叠表达式：简化可变参数模板操作

// 一元右折叠: (pack op ...)
// 一元左折叠: (... op pack)
// 二元右折叠: (pack op ... op init)
// 二元左折叠: (init op ... op pack)

// 求和
template<typename... Ts>
auto sum(Ts... args) {
    return (args + ...);  // 一元右折叠: arg1 + (arg2 + (arg3 + ...))
}

static_assert(sum(1, 2, 3, 4, 5) == 15);

// 带初始值的求和
template<typename... Ts>
auto sum_with_init(Ts... args) {
    return (0 + ... + args);  // 二元左折叠: ((0 + arg1) + arg2) + ...
}

// 逻辑与
template<typename... Ts>
bool all_true(Ts... args) {
    return (... && args);  // 一元左折叠
}

static_assert(all_true(true, true, true));
static_assert(!all_true(true, false, true));

// 逻辑或
template<typename... Ts>
bool any_true(Ts... args) {
    return (... || args);
}

// 打印所有参数
template<typename... Ts>
void print_all_fold(const Ts&... args) {
    ((std::cout << args << ' '), ...);  // 逗号折叠
    std::cout << std::endl;
}

// 调用多个函数
template<typename... Fs>
void call_all(Fs&&... fs) {
    (std::forward<Fs>(fs)(), ...);  // 依次调用每个函数
}

// 类型检查：所有类型都是整数
template<typename... Ts>
constexpr bool all_integral_v = (std::is_integral_v<Ts> && ...);

static_assert(all_integral_v<int, long, char>);
static_assert(!all_integral_v<int, double, char>);

// 类型检查：任一类型是浮点
template<typename... Ts>
constexpr bool any_floating_v = (std::is_floating_point_v<Ts> || ...);

// 编译期最大值
template<auto... Values>
constexpr auto max_value = std::max({Values...});

static_assert(max_value<1, 5, 3, 8, 2> == 8);
```

## 🟢 7. 变量模板模式

```cpp
// C++14 变量模板：简化trait使用

// 基本形式
template<typename T>
constexpr bool is_pointer_v = std::is_pointer<T>::value;

// 自定义trait的变量模板
template<typename T>
inline constexpr bool is_numeric_v =
    std::is_arithmetic_v<T> && !std::is_same_v<T, bool>;

// 组合trait
template<typename T>
inline constexpr bool is_string_v =
    std::is_same_v<T, std::string> ||
    std::is_same_v<T, std::string_view> ||
    std::is_same_v<T, const char*>;

// 类型列表的变量模板
template<typename T, typename... Ts>
inline constexpr bool is_one_of_v =
    (std::is_same_v<T, Ts> || ...);

static_assert(is_one_of_v<int, char, double, int, float>);
static_assert(!is_one_of_v<long, char, double, int, float>);

// 使用变量模板简化SFINAE
template<typename T,
         std::enable_if_t<is_numeric_v<T>, int> = 0>
T clamp(T value, T lo, T hi) {
    return value < lo ? lo : (value > hi ? hi : value);
}

// 变量模板 vs 类型trait：
// 变量模板: is_numeric_v<int>     → 直接返回bool值
// 类型trait: is_numeric<int>::value → 需要::value

// 变量模板的优势：
// 1. 使用更简洁
// 2. 可以内联计算
// 3. 可以组合多个条件
// 4. C++17标准库已全面提供_v版本
```

## 🟢 8. 本章小结

| 模式 | 适用场景 | C++版本 | 复杂度 |
|------|---------|---------|--------|
| 编译期计算 | 常量计算、查表 | C++11+ | 低 |
| 类型列表/过滤 | 类型集合操作 | C++11+ | 高 |
| enable_if | 条件启用函数/类 | C++11+ | 中 |
| void_t | 检测类型特征 | C++17 | 中 |
| 标签分发 | 按类别选择实现 | C++11+ | 低 |
| if constexpr | 编译期条件分支 | C++17 | 低 |
| 折叠表达式 | 可变参数操作 | C++17 | 低 |
| 变量模板 | 简化trait使用 | C++14+ | 低 |

**关键理解**：

1. **优先使用现代特性**：if constexpr比SFINAE更清晰，折叠表达式比递归模板更简洁
2. **编译期计算首选constexpr函数**：比模板递归更直观，编译更快
3. **类型操作是元编程的核心**：TypeList是编译期数据结构的基础
4. **void_t是检测特征的利器**：简洁优雅地检测类型是否具有某特征
5. **标签分发优于SFINAE**：代码更清晰，错误信息更友好
6. **变量模板简化代码**：减少`::value`的冗余写法
7. **C++20 Concepts是终极方案**：新项目应优先使用Concepts替代SFINAE
