# 高级并发数据结构

> 掌握无锁编程与高级并发数据结构，构建高性能并发系统

***

> **Lock-free programming is like juggling chainsaws — impressive when it works, catastrophic when it doesn't.** — Unknown
> （无锁编程就像抛电锯——成功时令人惊叹，失败时灾难性。）

> **If you think lock-free programming is the solution, you're probably solving the wrong problem.**
> （如果你认为无锁编程是解决方案，那你可能在解决错误的问题。）

> **🎯 少即是多，快即是稳。**
>
> （高级并发数据结构通过原子操作和精巧的算法设计，减少了锁竞争和线程阻塞，在极端并发场景下保持高性能。但无锁不是万能药，选择合适的工具比追求极致更重要。）

> 💡 **通俗理解 - 什么是高级并发数据结构？**

想象一下：

- **互斥锁** 就像"单间厕所"——一次只能一个人用，其他人排队等待
- **无锁编程** 就像"旋转门"——不用等门完全关闭，下一个人就可以进
- **CAS** 就像"抢答器"——谁先按到就是谁的，没按到就再试
- **ABA问题** 就像"偷梁换柱"——值从A变成B又变回A，你以为没变过

> 🔬 **抽象理解 - 高级并发数据结构的本质**：
>
> - **无锁（Lock-free）**：系统整体总有进展，不会全部阻塞
> - **无等待（Wait-free）**：每个线程都有有限步骤内完成的保证
> - **原子操作**：不可分割的操作，硬件级别的线程安全
> - **内存序**：控制原子操作之间的可见性和排序约束

## 🟡 1. 无锁编程基础

### 1.1 CAS与FAA

```cpp
// CAS (Compare-And-Swap) —— 无锁编程的基石
// 原子地比较并交换值

// C++11 std::atomic::compare_exchange_weak/strong
std::atomic<int> value{0};

// CAS操作
int expected = 0;
bool success = value.compare_exchange_strong(
    expected,    // 期望值（如果失败，会被更新为当前值）
    1            // 新值
);
// 如果value == expected，则value = 1，返回true
// 如果value != expected，则expected = value，返回false

// CAS循环模式（无锁编程的基本模式）
void atomic_add(std::atomic<int>& val, int delta) {
    int old = val.load(std::memory_order_relaxed);
    while (!val.compare_exchange_weak(
        old,              // 期望当前值
        old + delta,      // 新值
        std::memory_order_acquire,  // 成功时的内存序
        std::memory_order_relaxed   // 失败时的内存序
    )) {
        // CAS失败，old已被更新为当前值，重试
    }
}

// FAA (Fetch-And-Add) —— 原子地加并返回旧值
int old_val = val.fetch_add(1, std::memory_order_relaxed);
// 等价于: old_val = val; val += 1; （原子地）

// CAS vs FAA：
// CAS：更通用，可以实现任意原子更新
// FAA：更高效，x86有直接指令支持（lock xadd）
```

### 1.2 无锁 vs 无等待

```
并发安全级别：

┌──────────────┬──────────────────────────────────────┐
│ 级别          │ 保证                                  │
├──────────────┼──────────────────────────────────────┤
│ 阻塞         │ 线程可能无限等待（互斥锁）             │
│ 无障碍       │ 线程可以中止其他线程保证自己进展        │
│ 无锁         │ 系统整体总有进展，但个别线程可能饥饿    │
│ 无等待       │ 每个线程在有限步骤内完成操作           │
└──────────────┴──────────────────────────────────────┘

无锁（Lock-free）：
- 至少一个线程在有限步骤内完成操作
- 其他线程可能不断CAS失败（饥饿）
- 典型实现：CAS循环

无等待（Wait-free）：
- 每个线程都在有限步骤内完成操作
- 没有饥饿问题
- 典型实现：fetch_add、原子读写

选择建议：
- 优先使用互斥锁（简单、正确、性能通常足够）
- 高竞争场景考虑无锁数据结构
- 无等待只在极端场景需要
```

## 🔴 2. 无锁栈

### 2.1 Treiber栈

```cpp
// Treiber栈——经典的无锁栈实现

#include <atomic>
#include <memory>

template<typename T>
class LockFreeStack {
    struct Node {
        T data;
        Node* next;
        Node(T val) : data(std::move(val)), next(nullptr) {}
    };

    std::atomic<Node*> head_{nullptr};

public:
    void push(T value) {
        Node* new_node = new Node(std::move(value));
        new_node->next = head_.load(std::memory_order_relaxed);

        // CAS：如果head没变，更新为新节点
        while (!head_.compare_exchange_weak(
            new_node->next,       // 期望当前head
            new_node,             // 新head
            std::memory_order_release,
            std::memory_order_relaxed
        )) {
            // CAS失败，new_node->next已被更新为当前head
            // 直接重试
        }
    }

    // 弹出栈顶元素
    // 注意：存在ABA问题和内存回收问题
    std::optional<T> pop() {
        Node* old_head = head_.load(std::memory_order_acquire);

        while (old_head != nullptr) {
            if (head_.compare_exchange_weak(
                old_head,
                old_head->next,
                std::memory_order_acquire,
                std::memory_order_relaxed
            )) {
                // 成功弹出
                T result = std::move(old_head->data);
                // ❌ 危险：不能立即delete！
                // 其他线程可能还在访问old_head
                // 需要使用hazard pointer或RCU等安全回收机制
                return result;
            }
        }
        return std::nullopt;  // 栈为空
    }

    ~LockFreeStack() {
        while (pop()) {}
    }
};
```

### 2.2 带引用计数的无锁栈

```cpp
// 使用引用计数解决内存回收问题

template<typename T>
class RefCountStack {
    struct Node;

    // 外部引用计数 + 内部引用计数
    struct RefCountedNode {
        Node* node;
        int external_count;  // 外部计数（在head中的引用）
    };

    struct Node {
        T data;
        std::atomic<int> internal_count;  // 内部计数（弹出的线程持有）
        RefCountedNode next;
        Node(T val) : data(std::move(val)), internal_count(0) {}
    };

    std::atomic<RefCountedNode> head_{RefCountedNode{nullptr, 0}};

    void push(T value) {
        RefCountedNode new_node;
        new_node.node = new Node(std::move(value));
        new_node.external_count = 1;
        new_node.node->next = head_.load(std::memory_order_relaxed);

        while (!head_.compare_exchange_weak(
            new_node.node->next,
            new_node,
            std::memory_order_release,
            std::memory_order_relaxed
        )) {}
    }

    std::optional<T> pop() {
        RefCountedNode old_head = head_.load(std::memory_order_acquire);

        while (true) {
            // 增加外部引用计数
            RefCountedNode new_head = old_head;
            ++new_head.external_count;

            if (head_.compare_exchange_strong(
                old_head, new_head,
                std::memory_order_acquire,
                std::memory_order_relaxed
            )) {
                break;
            }
        }

        if (old_head.node == nullptr) {
            return std::nullopt;
        }

        // 尝试弹出
        RefCountedNode next = old_head.node->next.load(
            std::memory_order_relaxed);

        if (head_.compare_exchange_strong(
            old_head, next,
            std::memory_order_acquire,
            std::memory_order_relaxed
        )) {
            // 成功弹出
            int count_increase = old_head.external_count - 2;
            if (old_head.node->internal_count.fetch_add(
                    count_increase, std::memory_order_release) == -count_increase) {
                delete old_head.node;
            }
            return std::move(old_head.node->data);
        } else {
            // 失败，减少内部计数
            if (old_head.node->internal_count.fetch_sub(
                    1, std::memory_order_relaxed) == 1) {
                old_head.node->internal_count.load(std::memory_order_acquire);
                delete old_head.node;
            }
            return std::nullopt;
        }
    }
};
```

## 🔴 3. 无锁队列

### 3.1 Michael-Scott队列

```cpp
// Michael-Scott无锁队列——被广泛使用的无锁队列算法

#include <atomic>
#include <optional>

template<typename T>
class LockFreeQueue {
    struct Node {
        T data;
        std::atomic<Node*> next;

        Node() : next(nullptr) {}  // 哨兵节点
        Node(T val) : data(std::move(val)), next(nullptr) {}
    };

    std::atomic<Node*> head_;
    std::atomic<Node*> tail_;

public:
    LockFreeQueue() {
        Node* sentinel = new Node();  // 哨兵节点，简化空队列处理
        head_.store(sentinel, std::memory_order_relaxed);
        tail_.store(sentinel, std::memory_order_relaxed);
    }

    void enqueue(T value) {
        Node* new_node = new Node(std::move(value));

        while (true) {
            Node* cur_tail = tail_.load(std::memory_order_acquire);
            Node* next = cur_tail->next.load(std::memory_order_acquire);

            // 检查tail是否仍然一致
            if (cur_tail == tail_.load(std::memory_order_acquire)) {
                if (next == nullptr) {
                    // tail->next为空，尝试插入新节点
                    if (cur_tail->next.compare_exchange_weak(
                        next, new_node,
                        std::memory_order_release,
                        std::memory_order_relaxed
                    )) {
                        // 插入成功，尝试推进tail
                        tail_.compare_exchange_strong(
                            cur_tail, new_node,
                            std::memory_order_release,
                            std::memory_order_relaxed
                        );
                        return;
                    }
                } else {
                    // tail落后了，帮助推进tail
                    tail_.compare_exchange_strong(
                        cur_tail, next,
                        std::memory_order_release,
                        std::memory_order_relaxed
                    );
                }
            }
        }
    }

    std::optional<T> dequeue() {
        while (true) {
            Node* cur_head = head_.load(std::memory_order_acquire);
            Node* cur_tail = tail_.load(std::memory_order_acquire);
            Node* next = cur_head->next.load(std::memory_order_acquire);

            // 检查head是否仍然一致
            if (cur_head == head_.load(std::memory_order_acquire)) {
                if (cur_head == cur_tail) {
                    if (next == nullptr) {
                        return std::nullopt;  // 队列为空
                    }
                    // tail落后了，帮助推进
                    tail_.compare_exchange_strong(
                        cur_tail, next,
                        std::memory_order_release,
                        std::memory_order_relaxed
                    );
                } else {
                    // 读取数据，尝试弹出head
                    T result = std::move(next->data);
                    if (head_.compare_exchange_strong(
                        cur_head, next,
                        std::memory_order_release,
                        std::memory_order_relaxed
                    )) {
                        // 成功弹出
                        // ❌ 不能立即delete cur_head（ABA问题）
                        // 需要延迟回收
                        return result;
                    }
                }
            }
        }
    }
};
```

## 🟡 4. 并发哈希表

### 4.1 分段锁哈希表

```cpp
// 分段锁哈希表：高并发场景的实用方案

#include <vector>
#include <list>
#include <mutex>
#include <shared_mutex>
#include <functional>

template<typename Key, typename Value,
         typename Hash = std::hash<Key>>
class ConcurrentHashMap {
    struct Bucket {
        std::list<std::pair<Key, Value>> entries;
        mutable std::shared_mutex mutex;

        void insert(const Key& key, const Value& value) {
            std::unique_lock lock(mutex);  // 写锁
            for (auto& [k, v] : entries) {
                if (k == key) { v = value; return; }
            }
            entries.emplace_back(key, value);
        }

        std::optional<Value> find(const Key& key) const {
            std::shared_lock lock(mutex);  // 读锁
            for (const auto& [k, v] : entries) {
                if (k == key) return v;
            }
            return std::nullopt;
        }

        bool erase(const Key& key) {
            std::unique_lock lock(mutex);
            for (auto it = entries.begin(); it != entries.end(); ++it) {
                if (it->first == key) {
                    entries.erase(it);
                    return true;
                }
            }
            return false;
        }
    };

    std::vector<Bucket> buckets_;
    Hash hash_;
    size_t bucket_count_;

    size_t get_bucket(const Key& key) const {
        return hash_(key) % bucket_count_;
    }

public:
    explicit ConcurrentHashMap(size_t bucket_count = 64)
        : buckets_(bucket_count), bucket_count_(bucket_count) {}

    void insert(const Key& key, const Value& value) {
        buckets_[get_bucket(key)].insert(key, value);
    }

    std::optional<Value> find(const Key& key) const {
        return buckets_[get_bucket(key)].find(key);
    }

    bool erase(const Key& key) {
        return buckets_[get_bucket(key)].erase(key);
    }
};

// 分段锁 vs 全局锁：
// ┌──────────────┬──────────┬──────────┐
// │ 方案          │ 读并发    │ 写并发    │
// ├──────────────┼──────────┼──────────┤
// │ 全局互斥锁    │ 串行     │ 串行     │
// │ 全局读写锁    │ 并行     │ 串行     │
// │ 分段锁(64段)  │ 并行     │ 64路并行 │
// │ 无锁哈希表    │ 完全并行 │ 完全并行 │
// └──────────────┴──────────┴──────────┘
```

## 🟡 5. 读写锁优化的链表

```cpp
// 读写锁优化的并发链表

#include <shared_mutex>
#include <optional>

template<typename T>
class ConcurrentLinkedList {
    struct Node {
        T data;
        Node* next;
        std::shared_mutex mutex;  // 每个节点一把锁
        Node(T val) : data(std::move(val)), next(nullptr) {}
    };

    Node* head_{nullptr};
    mutable std::shared_mutex head_mutex_;

public:
    // 查找：使用读锁，允许多线程并发读
    bool contains(const T& value) const {
        std::shared_lock head_lock(head_mutex_);
        Node* current = head_;
        while (current) {
            std::shared_lock node_lock(current->mutex);
            if (current->data == value) return true;
            Node* next = current->next;
            node_lock.unlock();
            current = next;
        }
        return false;
    }

    // 插入：使用写锁
    void insert(const T& value) {
        Node* new_node = new Node(value);

        std::unique_lock head_lock(head_mutex_);
        new_node->next = head_;
        head_ = new_node;
    }

    // 删除：手把手加锁（hand-over-hand locking）
    bool remove(const T& value) {
        std::unique_lock head_lock(head_mutex_);

        if (!head_) return false;

        // 检查头节点
        if (head_->data == value) {
            Node* old_head = head_;
            head_ = head_->next;
            head_lock.unlock();
            delete old_head;
            return true;
        }

        // 遍历链表
        Node* prev = head_;
        std::unique_lock prev_lock(prev->mutex);

        while (Node* current = prev->next) {
            std::unique_lock current_lock(current->mutex);

            if (current->data == value) {
                prev->next = current->next;
                current_lock.unlock();
                prev_lock.unlock();
                delete current;
                return true;
            }

            prev_lock.unlock();
            prev = current;
            prev_lock = std::move(current_lock);
        }

        return false;
    }
};
```

## 🔴 6. Hazard Pointer

### 6.1 原理与实现

```cpp
// Hazard Pointer：安全回收无锁数据结构中的内存

// 核心思想：
// 线程在访问共享节点前，先声明"我正在用这个节点"
// 其他线程在删除节点前，检查是否有人正在使用
// 如果有人在用，将节点加入待删除列表，延迟回收

#include <atomic>
#include <array>
#include <vector>

template<typename T, size_t K = 2>
class HazardPointerManager {
    // 每个线程最多K个hazard pointer
    struct HPRecord {
        std::atomic<T*> pointers[K];
        std::atomic<bool> active;

        HPRecord() : active(false) {
            for (size_t i = 0; i < K; ++i) {
                pointers[i].store(nullptr, std::memory_order_relaxed);
            }
        }
    };

    static constexpr size_t MAX_THREADS = 128;
    std::array<HPRecord, MAX_THREADS> hp_records_;

    // 获取当前线程的HP记录
    static thread_local HPRecord* my_record_;

    HPRecord* acquire_record() {
        for (auto& rec : hp_records_) {
            bool expected = false;
            if (rec.active.compare_exchange_strong(
                    expected, true, std::memory_order_acquire)) {
                return &rec;
            }
        }
        return nullptr;  // 超过最大线程数
    }

public:
    // 声明hazard pointer
    void set(size_t idx, T* ptr) {
        if (!my_record_) my_record_ = acquire_record();
        my_record_->pointers[idx].store(ptr, std::memory_order_release);
    }

    // 清除hazard pointer
    void clear(size_t idx) {
        if (my_record_) {
            my_record_->pointers[idx].store(
                nullptr, std::memory_order_release);
        }
    }

    // 清除所有hazard pointer
    void clear_all() {
        if (my_record_) {
            for (size_t i = 0; i < K; ++i) {
                my_record_->pointers[i].store(
                    nullptr, std::memory_order_release);
            }
        }
    }

    // 安全回收：检查节点是否被任何hazard pointer保护
    void retire(T* ptr) {
        // 检查是否被保护
        for (auto& rec : hp_records_) {
            if (!rec.active.load(std::memory_order_acquire)) continue;
            for (size_t i = 0; i < K; ++i) {
                if (rec.pointers[i].load(std::memory_order_acquire) == ptr) {
                    // 被保护，加入待删除列表
                    // 实际实现中会用更复杂的延迟回收策略
                    return;
                }
            }
        }
        // 没有被保护，安全删除
        delete ptr;
    }
};
```

## 🟡 7. RCU（Read-Copy-Update）

### 7.1 RCU原理

```
RCU (Read-Copy-Update) 核心思想：

1. 读者无锁访问（甚至不需要原子操作）
2. 写者创建副本，修改副本，然后原子地替换指针
3. 等待所有旧读者离开后，回收旧数据

读者操作：
  ptr = rcu_dereference(shared_ptr);  // 读取共享指针
  use(ptr);                            // 使用数据（无锁！）
  // 读者不需要任何同步操作

写者操作：
  old = rcu_dereference(shared_ptr);
  new = copy(old);           // 创建副本
  modify(new);               // 修改副本
  rcu_assign_pointer(shared_ptr, new);  // 原子替换
  synchronize_rcu();         // 等待所有旧读者
  free(old);                 // 安全回收

适用场景：
- 读多写少（读远多于写）
- 读者对延迟敏感
- Linux内核广泛使用RCU
```

### 7.2 C++ RCU实现

```cpp
// 简化的RCU实现

#include <atomic>
#include <memory>
#include <thread>

class SimpleRCU {
    std::atomic<int> reader_count_{0};
    std::atomic<int> epoch_{0};

public:
    // 读者进入RCU临界区
    void read_lock() {
        reader_count_.fetch_add(1, std::memory_order_acquire);
    }

    // 读者离开RCU临界区
    void read_unlock() {
        reader_count_.fetch_sub(1, std::memory_order_release);
    }

    // 等待所有读者完成
    void synchronize() {
        int current_epoch = epoch_.load(std::memory_order_acquire);
        // 等待当前epoch的所有读者离开
        while (reader_count_.load(std::memory_order_acquire) > 0) {
            std::this_thread::yield();
        }
        epoch_.store(current_epoch + 1, std::memory_order_release);
    }

    // RAII守卫
    class ReadGuard {
        SimpleRCU& rcu_;
    public:
        ReadGuard(SimpleRCU& rcu) : rcu_(rcu) { rcu_.read_lock(); }
        ~ReadGuard() { rcu_.read_unlock(); }
    };

    // 延迟回调（宽限期结束后执行）
    template<typename Func>
    void call(Func&& func) {
        synchronize();
        func();
    }
};

// 使用RCU保护共享数据
template<typename T>
class RCUProtected {
    std::atomic<T*> ptr_{nullptr};
    SimpleRCU rcu_;

public:
    RCUProtected() = default;

    // 读取（无锁！）
    const T* read() const {
        return ptr_.load(std::memory_order_acquire);
    }

    // 更新（写者）
    void update(std::unique_ptr<T> new_data) {
        T* old = ptr_.exchange(new_data.release(),
                               std::memory_order_acq_rel);
        if (old) {
            rcu_.call([old]() { delete old; });
        }
    }
};
```

## 🔴 8. ABA问题与解决方案

### 8.1 ABA问题

```
ABA问题：

线程1: 读取head = A
线程1: 被抢占...
线程2: 弹出A，head = B
线程2: 删除A
线程3: 分配新节点，恰好复用了A的地址
线程3: 将A压入栈，head = A
线程1: 恢复执行，CAS(A, B) 成功！
       但此时A已经不是原来的A了！

时间线：
t0: head → A → B → C
t1: 线程1读head=A
t2: 线程2弹出A: head → B → C, delete A
t3: 线程3 push A' (新节点，复用A的地址): head → A' → B → C
t4: 线程1 CAS(head, A, B) 成功！
    head → B → C, 但A'丢失了！

后果：A'节点泄漏，数据丢失
```

### 8.2 解决方案

```cpp
// 方案1：带版本号的指针（最常用）

// 将指针和版本号打包在一个64/128位原子变量中
template<typename T>
class VersionedPointer {
    // 低位存指针，高位存版本号
    // 假设64位系统，指针低48位有效，高16位用于版本号
    struct Packed {
        uintptr_t ptr   : 48;  // 指针
        uintptr_t version : 16;  // 版本号
    };

    std::atomic<uint64_t> packed_;

public:
    VersionedPointer() : packed_(0) {}

    T* load() {
        Packed p;
        p = *reinterpret_cast<Packed*>(&packed_);
        return reinterpret_cast<T*>(p.ptr);
    }

    bool compare_exchange(T*& expected, T* desired) {
        uint64_t old_packed = packed_.load(std::memory_order_acquire);
        Packed old_p = *reinterpret_cast<Packed*>(&old_packed);

        if (reinterpret_cast<T*>(old_p.ptr) != expected) {
            expected = reinterpret_cast<T*>(old_p.ptr);
            return false;
        }

        Packed new_p;
        new_p.ptr = reinterpret_cast<uintptr_t>(desired);
        new_p.version = old_p.version + 1;  // 版本号+1

        uint64_t new_packed = *reinterpret_cast<uint64_t*>(&new_p);
        return packed_.compare_exchange_strong(
            old_packed, new_packed,
            std::memory_order_release,
            std::memory_order_relaxed
        );
    }
};
```

## 🟢 9. 本章小结

| 主题 | 核心要点 |
|------|---------|
| 无锁基础 | CAS/FAA原子操作，无锁≠无等待 |
| 无锁栈 | Treiber栈，CAS循环push/pop，内存回收问题 |
| 无锁队列 | Michael-Scott队列，哨兵节点，帮助推进 |
| 并发哈希表 | 分段锁实用方案，读写锁优化读性能 |
| 读写锁链表 | hand-over-hand locking，细粒度锁 |
| Hazard Pointer | 声明式保护，延迟回收，解决ABA |
| RCU | 读无锁，写复制更新，适合读多写少 |
| ABA问题 | 版本号指针、Hazard Pointer、Epoch回收 |

**关键理解**：

1. **无锁编程极其困难**：正确性难以验证，优先使用锁
2. **CAS是无锁编程的基石**：几乎所有无锁算法都基于CAS
3. **内存回收是最大挑战**：不能立即delete，需要延迟回收
4. **ABA问题无处不在**：版本号指针是最常用的解决方案
5. **分段锁是实用方案**：性能接近无锁，实现简单得多
6. **RCU适合读多写少**：读者完全无锁，Linux内核大量使用
7. **先测量再优化**：锁竞争不严重时，互斥锁性能足够好
8. **测试并发代码极其重要**：使用ThreadSanitizer检测数据竞争

> **下一步**：在实际项目中，优先使用标准库并发容器（如`std::shared_mutex`），只在性能瓶颈明确时才考虑高级无锁数据结构。
