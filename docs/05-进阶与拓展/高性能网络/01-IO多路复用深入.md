> 💡 **通俗理解 - IO多路复用**

想象快递分拣中心：
- **select**：快递员逐个检查每个包裹是否到达 → 效率低
- **poll**：和select类似，但包裹数量不限 → 还是逐个检查
- **epoll**：包裹到达时自动通知 → 效率极高

**IO多路复用就是让内核帮我们"盯着"多个文件描述符，哪个有数据了就通知我们！**

> 🔬 **抽象理解 - IO多路复用**：
> - **select**：是"遍历检查"模型，每次调用需传入所有fd，内核遍历后返回就绪fd
> - **poll**：与select类似，但用链表结构突破fd数量限制
> - **epoll**：是"事件注册+就绪通知"模型，fd注册一次，内核通过回调维护就绪队列
> - **ET模式**：是"边沿触发"，只在状态变化时通知一次，需一次性读完所有数据
> - **LT模式**：是"水平触发"，只要缓冲区有数据就持续通知，编程更安全

## 1. select深入分析

### 1.1 select原理

select是最早的IO多路复用机制，通过`fd_set`位图来管理文件描述符集合：

```
┌──────────────────────────────────────────────────────────────┐
│                    select 工作原理                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   用户空间                        内核空间                    │
│   ┌──────────────────┐          ┌──────────────────┐        │
│   │ fd_set readfds   │  拷贝    │                  │        │
│   │ [1 0 1 0 0 ...]  │────────▶│ 遍历所有fd       │        │
│   │                  │          │ 检查是否就绪      │        │
│   │ fd_set writefds  │────────▶│ 修改fd_set       │        │
│   │ [0 1 0 0 1 ...]  │  拷贝    │ 只保留就绪的fd    │        │
│   │                  │◀────────│                  │        │
│   └──────────────────┘          └──────────────────┘        │
│                                                              │
│   问题：                                                      │
│   1. 每次调用都需要拷贝整个fd_set                              │
│   2. 内核需要遍历所有fd（O(n)）                                │
│   3. 返回后用户也需要遍历所有fd找就绪的                         │
│   4. fd_set大小固定（FD_SETSIZE=1024）                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 select API详解

```cpp
#include <iostream>
#include <sys/select.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cstring>

// select服务器完整示例
class SelectServer {
public:
    SelectServer(int port) : port_(port), maxfd_(-1) {
        // 初始化fd_set
        FD_ZERO(&readfds_);
    }

    void start() {
        // 创建监听socket
        listenfd_ = socket(AF_INET, SOCK_STREAM, 0);
        int opt = 1;
        setsockopt(listenfd_, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd_, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd_, 128);

        // 添加监听fd到readfds
        FD_SET(listenfd_, &readfds_);
        maxfd_ = listenfd_;

        std::cout << "Select服务器启动，端口: " << port_ << std::endl;

        while (true) {
            // 每次循环都要重新设置fd_set（因为select会修改它）
            fd_set tmp_readfds = readfds_;

            // select等待事件
            int ready = select(maxfd_ + 1, &tmp_readfds, nullptr, nullptr, nullptr);
            if (ready < 0) {
                perror("select");
                continue;
            }

            // 遍历所有fd，找出就绪的
            for (int fd = 0; fd <= maxfd_; ++fd) {
                if (!FD_ISSET(fd, &tmp_readfds)) continue;

                if (fd == listenfd_) {
                    // 新连接到达
                    handle_new_connection();
                } else {
                    // 客户端数据到达
                    handle_client_data(fd);
                }
            }
        }
    }

private:
    void handle_new_connection() {
        int clientfd = accept(listenfd_, nullptr, nullptr);
        if (clientfd < 0) return;

        // 检查是否超过select限制
        if (clientfd >= FD_SETSIZE) {
            std::cerr << "超过FD_SETSIZE限制(" << FD_SETSIZE
                      << ")，拒绝连接" << std::endl;
            close(clientfd);
            return;
        }

        FD_SET(clientfd, &readfds_);
        if (clientfd > maxfd_) maxfd_ = clientfd;
        std::cout << "新连接: fd=" << clientfd << std::endl;
    }

    void handle_client_data(int fd) {
        char buffer[4096];
        ssize_t n = recv(fd, buffer, sizeof(buffer), 0);

        if (n <= 0) {
            // 连接关闭或出错
            FD_CLR(fd, &readfds_);
            close(fd);
            std::cout << "连接关闭: fd=" << fd << std::endl;

            // 更新maxfd_
            update_maxfd();
        } else {
            // 回显数据
            send(fd, buffer, n, 0);
        }
    }

    void update_maxfd() {
        maxfd_ = listenfd_;
        for (int fd = 0; fd < FD_SETSIZE; ++fd) {
            if (FD_ISSET(fd, &readfds_) && fd > maxfd_) {
                maxfd_ = fd;
            }
        }
    }

    int port_;
    int listenfd_;
    int maxfd_;
    fd_set readfds_;
};

int main() {
    SelectServer server(8080);
    server.start();
    return 0;
}
```

### 1.3 select的局限性

| 局限 | 说明 | 影响 |
|------|------|------|
| **FD_SETSIZE限制** | 默认1024 | 无法处理大量连接 |
| **O(n)遍历** | 内核和用户都需遍历所有fd | 连接多时效率低 |
| **数据拷贝** | 每次调用拷贝整个fd_set | 开销随fd数量增长 |
| **fd_set重置** | 每次调用后需重建fd_set | 编程不便且易出错 |
| **无状态** | 不记录上次状态 | 每次都要重新传入所有fd |

## 2. poll深入分析

### 2.1 poll原理

poll使用`pollfd`结构体数组替代了select的位图，突破了FD_SETSIZE限制：

```
┌──────────────────────────────────────────────────────────────┐
│                    poll 工作原理                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   pollfd结构体数组：                                          │
│   ┌──────────────────────────────────────────┐              │
│   │ fd=3, events=POLLIN,  revents=0          │              │
│   │ fd=5, events=POLLIN,  revents=POLLIN ✓   │ ← 就绪      │
│   │ fd=7, events=POLLIN,  revents=0          │              │
│   │ fd=9, events=POLLOUT, revents=POLLOUT ✓  │ ← 就绪      │
│   │ ...                                       │              │
│   └──────────────────────────────────────────┘              │
│                                                              │
│   改进：                                                      │
│   ✅ 无fd数量限制（用动态数组替代位图）                         │
│   ✅ 输入(events)和输出(revents)分离                          │
│                                                              │
│   仍存在的问题：                                              │
│   ❌ 内核仍需遍历所有fd（O(n)）                                │
│   ❌ 用户仍需遍历找就绪fd                                      │
│   ❌ 每次调用仍需拷贝整个数组                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 poll API详解

```cpp
#include <iostream>
#include <poll.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cstring>
#include <vector>

// poll服务器完整示例
class PollServer {
public:
    PollServer(int port) : port_(port) {}

    void start() {
        listenfd_ = socket(AF_INET, SOCK_STREAM, 0);
        int opt = 1;
        setsockopt(listenfd_, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd_, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd_, 128);

        // 添加监听fd
        struct pollfd pfd{};
        pfd.fd = listenfd_;
        pfd.events = POLLIN;
        pfd.revents = 0;
        pollfds_.push_back(pfd);

        std::cout << "Poll服务器启动，端口: " << port_ << std::endl;

        while (true) {
            // poll等待事件，无超时
            int ready = poll(pollfds_.data(), pollfds_.size(), -1);
            if (ready < 0) {
                perror("poll");
                continue;
            }

            // 遍历所有fd找就绪的
            for (size_t i = 0; i < pollfds_.size() && ready > 0; ++i) {
                if (pollfds_[i].revents == 0) continue;

                ready--;  // 减少剩余就绪计数

                if (pollfds_[i].fd == listenfd_) {
                    handle_new_connection();
                } else {
                    if (pollfds_[i].revents & (POLLERR | POLLHUP | POLLNVAL)) {
                        // 错误或挂断
                        remove_fd(i);
                        i--;
                    } else if (pollfds_[i].revents & POLLIN) {
                        handle_client_data(i);
                    }
                }
            }
        }
    }

private:
    void handle_new_connection() {
        int clientfd = accept(listenfd_, nullptr, nullptr);
        if (clientfd < 0) return;

        struct pollfd pfd{};
        pfd.fd = clientfd;
        pfd.events = POLLIN;
        pfd.revents = 0;
        pollfds_.push_back(pfd);

        std::cout << "新连接: fd=" << clientfd
                  << ", 总连接数: " << pollfds_.size() - 1 << std::endl;
    }

    void handle_client_data(size_t index) {
        char buffer[4096];
        ssize_t n = recv(pollfds_[index].fd, buffer, sizeof(buffer), 0);

        if (n <= 0) {
            remove_fd(index);
        } else {
            send(pollfds_[index].fd, buffer, n, 0);
        }
    }

    void remove_fd(size_t index) {
        std::cout << "连接关闭: fd=" << pollfds_[index].fd << std::endl;
        close(pollfds_[index].fd);
        // 将最后一个元素移到当前位置，避免移动整个数组
        if (index != pollfds_.size() - 1) {
            pollfds_[index] = pollfds_.back();
        }
        pollfds_.pop_back();
    }

    int port_;
    int listenfd_;
    std::vector<struct pollfd> pollfds_;
};

int main() {
    PollServer server(8080);
    server.start();
    return 0;
}
```

### 2.3 select与poll对比

| 特性 | select | poll |
|------|--------|------|
| **fd数量限制** | FD_SETSIZE(1024) | 无限制（受系统资源限制） |
| **数据结构** | 位图(fd_set) | 结构体数组(pollfd) |
| **输入输出分离** | 否（修改原fd_set） | 是（events/revents分离） |
| **内核遍历** | O(n) | O(n) |
| **用户遍历** | O(n) | O(n) |
| **每次拷贝** | 整个fd_set | 整个数组 |
| **可移植性** | 最好（所有平台） | 较好（大多数平台） |

## 3. epoll深入分析

### 3.1 epoll原理

epoll采用"事件注册 + 就绪通知"模型，彻底解决了select/poll的O(n)问题：

```
┌──────────────────────────────────────────────────────────────┐
│                    epoll 工作原理                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   步骤1：epoll_create —— 创建epoll实例                        │
│   ┌──────────────────────────────────────────────┐          │
│   │  创建红黑树（存储注册的fd）                     │          │
│   │  创建就绪队列（存储就绪的fd）                   │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   步骤2：epoll_ctl —— 注册/修改/删除fd                        │
│   ┌──────────────────────────────────────────────┐          │
│   │  将fd插入红黑树                                │          │
│   │  注册事件回调                                  │          │
│   │  只需注册一次，不需要每次重复传入               │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   步骤3：epoll_wait —— 等待事件                               │
│   ┌──────────────────────────────────────────────┐          │
│   │  当fd就绪时，内核通过回调将fd加入就绪队列       │          │
│   │  epoll_wait直接返回就绪队列中的fd              │          │
│   │  只返回就绪的fd，不需要遍历所有fd              │          │
│   │  时间复杂度：O(就绪fd数量)，与总fd数无关        │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   关键优势：                                                  │
│   ✅ 注册一次，持续监控（不需要每次传入所有fd）                 │
│   ✅ O(1)通知（只返回就绪的fd）                                │
│   ✅ 无fd数量限制（受系统资源限制）                             │
│   ✅ 内存映射（共享内核与用户空间）                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 epoll API详解

```cpp
#include <iostream>
#include <sys/epoll.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <fcntl.h>
#include <cstring>
#include <vector>
#include <unordered_map>

// epoll服务器完整示例
class EpollServer {
public:
    EpollServer(int port)
        : port_(port), listenfd_(-1), epfd_(-1) {}

    ~EpollServer() {
        if (epfd_ >= 0) close(epfd_);
        if (listenfd_ >= 0) close(listenfd_);
    }

    void start() {
        // 创建监听socket
        listenfd_ = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
        int opt = 1;
        setsockopt(listenfd_, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
        setsockopt(listenfd_, SOL_SOCKET, SO_REUSEPORT, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd_, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd_, 128);

        // 创建epoll实例
        epfd_ = epoll_create1(EPOLL_CLOEXEC);

        // 注册监听fd（使用ET模式）
        struct epoll_event ev{};
        ev.events = EPOLLIN | EPOLLET;  // 可读事件 + 边沿触发
        ev.data.fd = listenfd_;
        epoll_ctl(epfd_, EPOLL_CTL_ADD, listenfd_, &ev);

        std::cout << "Epoll服务器启动，端口: " << port_ << std::endl;

        // 事件循环
        std::vector<struct epoll_event> events(MAX_EVENTS);

        while (true) {
            int nfds = epoll_wait(epfd_, events.data(), MAX_EVENTS, -1);
            if (nfds < 0) {
                if (errno == EINTR) continue;
                perror("epoll_wait");
                break;
            }

            for (int i = 0; i < nfds; ++i) {
                if (events[i].data.fd == listenfd_) {
                    // 新连接到达（ET模式需循环accept直到EAGAIN）
                    handle_accept();
                } else if (events[i].events & (EPOLLERR | EPOLLHUP)) {
                    // 错误或挂断
                    remove_connection(events[i].data.fd);
                } else if (events[i].events & EPOLLIN) {
                    // 数据可读
                    handle_read(events[i].data.fd);
                } else if (events[i].events & EPOLLOUT) {
                    // 数据可写
                    handle_write(events[i].data.fd);
                }
            }
        }
    }

private:
    void handle_accept() {
        while (true) {
            sockaddr_in client_addr{};
            socklen_t len = sizeof(client_addr);
            int clientfd = accept4(listenfd_, (sockaddr*)&client_addr,
                                   &len, SOCK_NONBLOCK);
            if (clientfd < 0) {
                if (errno == EAGAIN || errno == EWOULDBLOCK) {
                    break;  // 所有连接已处理完
                }
                perror("accept");
                break;
            }

            // 设置TCP选项
            int val = 1;
            setsockopt(clientfd, IPPROTO_TCP, TCP_NODELAY, &val, sizeof(val));

            // 注册到epoll
            struct epoll_event ev{};
            ev.events = EPOLLIN | EPOLLET | EPOLLRDHUP;  // ET模式
            ev.data.fd = clientfd;
            epoll_ctl(epfd_, EPOLL_CTL_ADD, clientfd, &ev);

            char ip[INET_ADDRSTRLEN];
            inet_ntop(AF_INET, &client_addr.sin_addr, ip, sizeof(ip));
            std::cout << "新连接: " << ip << ":"
                      << ntohs(client_addr.sin_port)
                      << " fd=" << clientfd << std::endl;
        }
    }

    void handle_read(int fd) {
        char buffer[4096];
        // ET模式需循环读取直到EAGAIN
        while (true) {
            ssize_t n = recv(fd, buffer, sizeof(buffer), 0);
            if (n > 0) {
                // 回显数据
                send(fd, buffer, n, MSG_NOSIGNAL);
            } else if (n == 0) {
                // 连接关闭
                remove_connection(fd);
                break;
            } else {
                if (errno == EAGAIN || errno == EWOULDBLOCK) {
                    break;  // 数据已读完
                }
                remove_connection(fd);
                break;
            }
        }
    }

    void handle_write(int fd) {
        // 处理可写事件（通常用于异步写入）
        // 如果没有数据要写，可以取消EPOLLOUT关注
        struct epoll_event ev{};
        ev.events = EPOLLIN | EPOLLET | EPOLLRDHUP;
        ev.data.fd = fd;
        epoll_ctl(epfd_, EPOLL_CTL_MOD, fd, &ev);
    }

    void remove_connection(int fd) {
        epoll_ctl(epfd_, EPOLL_CTL_DEL, fd, nullptr);
        close(fd);
        std::cout << "连接关闭: fd=" << fd << std::endl;
    }

    static constexpr int MAX_EVENTS = 1024;
    int port_;
    int listenfd_;
    int epfd_;
};

int main() {
    EpollServer server(8080);
    server.start();
    return 0;
}
```

### 3.3 三种IO多路复用对比

| 特性 | select | poll | epoll |
|------|--------|------|-------|
| **fd数量限制** | 1024 | 无限制 | 无限制 |
| **内核遍历** | O(n) | O(n) | O(1) |
| **用户遍历** | O(n) | O(n) | O(k) k=就绪数 |
| **数据拷贝** | 每次全量 | 每次全量 | 首次注册+mmap |
| **fd状态维护** | 用户维护 | 用户维护 | 内核维护 |
| **触发模式** | LT | LT | LT + ET |
| **平台支持** | 全平台 | 大多数 | 仅Linux |

## 4. epoll的ET与LT模式

### 4.1 LT模式（Level Triggered，水平触发）

```
┌──────────────────────────────────────────────────────────────┐
│                    LT模式（水平触发）                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   缓冲区状态：                                               │
│   ┌──────────────────────────────────────────────┐          │
│   │  ████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░  │          │
│   │  ↑ 数据                                      │          │
│   │  有数据就持续通知，直到读完为止                  │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   时间线：                                                    │
│   t1: 数据到达 → epoll_wait返回（通知可读）                    │
│   t2: 只读了一部分 → epoll_wait仍返回（还有数据）              │
│   t3: 只读了一部分 → epoll_wait仍返回（还有数据）              │
│   t4: 全部读完 → epoll_wait不再返回（缓冲区空）               │
│                                                              │
│   特点：                                                      │
│   ✅ 编程简单，不需要一次性读完                                │
│   ✅ 不会漏掉事件                                             │
│   ❌ 通知频率较高，效率略低                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```

│                    ET模式（边沿触发）                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   缓冲区状态变化：                                           │
│   ┌──────────────────────────────────────────────┐          │
│   │  空空空 → 数据到达！状态变化（边沿）           │          │
│   │  ████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░  │          │

│   └──────────────────────────────────────────────┘          │
│                                                              │
│   时间线：                                                    │
│   t1: 数据到达 → epoll_wait返回（通知一次）                    │
│   t2: 只读了一部分 → 不再通知！                                │
│   t3: 只读了一部分 → 不再通知！                                │
│   ⚠️ 数据滞留在缓冲区，不会被处理！                            │
│   t4: 新数据到达 → epoll_wait返回（状态再次变化）              │
│                                                              │
│   正确做法：                                                  │
│   t1: 数据到达 → 循环读取直到EAGAIN                           │
│   t2: 确保所有数据被读完                                      │
│                                                              │
│   特点：                                                      │
│   ✅ 通知频率低，效率高                                       │
│   ✅ 减少epoll_wait调用次数                                   │
│   ❌ 编程复杂，必须一次性读完                                  │
│   ❌ 可能漏掉事件（处理不当）                                  │
│                                                              │
```

### 4.3 ET与LT代码对比

```cpp
#include <iostream>
#include <sys/epoll.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cerrno>
#include <cstring>
#include <vector>

// LT模式读取——简单直接
void read_lt(int epfd, int fd) {
    char buffer[4096];

    // LT模式：读一次就行，下次还有数据会再次通知
    ssize_t n = recv(fd, buffer, sizeof(buffer), 0);
    if (n > 0) {
        // 处理数据
        send(fd, buffer, n, 0);
    } else if (n == 0) {
        // 连接关闭
        epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
        close(fd);
    } else {
        perror("recv");
    }
}

// ET模式读取——必须循环读完
void read_et(int epfd, int fd) {
    char buffer[4096];

    // ET模式：必须循环读取直到EAGAIN
    while (true) {
        ssize_t n = recv(fd, buffer, sizeof(buffer), 0);

        if (n > 0) {
            // 处理数据
            send(fd, buffer, n, MSG_NOSIGNAL);
        } else if (n == 0) {
            // 连接关闭
            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
            close(fd);
            break;
        } else {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                // 数据已全部读完，这是正常退出
                break;
            }
            // 真正的错误
            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
            close(fd);
            break;
        }
    }
}

// ET模式写入——需要处理EAGAIN
void write_et(int epfd, int fd, const std::string& data) {
    size_t total = data.size();
    size_t sent = 0;

    while (sent < total) {
        ssize_t n = send(fd, data.data() + sent, total - sent,
                          MSG_NOSIGNAL);

        if (n > 0) {
            sent += n;
        } else if (n < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                // 发送缓冲区满，注册EPOLLOUT事件
                // 等缓冲区可写时再继续发送
                struct epoll_event ev{};
                ev.events = EPOLLIN | EPOLLOUT | EPOLLET;
                ev.data.fd = fd;
                epoll_ctl(epfd, EPOLL_CTL_MOD, fd, &ev);

                // 保存未发送完的数据，等EPOLLOUT时继续
                // ...（需要应用层缓冲区）
                break;
            } else {
                // 真正的错误
                close(fd);
                break;
            }
        }
    }
}

// 完整的ET模式epoll服务器
class EpollETServer {
public:
    EpollETServer(int port) : port_(port) {}

    void start() {
        listenfd_ = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
        int opt = 1;
        setsockopt(listenfd_, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd_, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd_, 128);

        epfd_ = epoll_create1(0);

        // 监听fd使用LT模式（更安全）
        struct epoll_event ev{};
        ev.events = EPOLLIN;  // LT模式
        ev.data.fd = listenfd_;
        epoll_ctl(epfd_, EPOLL_CTL_ADD, listenfd_, &ev);

        std::cout << "ET模式Epoll服务器启动，端口: " << port_ << std::endl;

        std::vector<struct epoll_event> events(1024);

        while (true) {
            int nfds = epoll_wait(epfd_, events.data(), events.size(), -1);
            for (int i = 0; i < nfds; ++i) {
                if (events[i].data.fd == listenfd_) {
                    // accept用循环处理（虽然listenfd是LT，但循环accept更高效）
                    while (true) {
                        int clientfd = accept4(listenfd_, nullptr, nullptr,
                                               SOCK_NONBLOCK);
                        if (clientfd < 0) break;

                        // 客户端fd使用ET模式
                        struct epoll_event client_ev{};
                        client_ev.events = EPOLLIN | EPOLLET | EPOLLRDHUP;
                        client_ev.data.fd = clientfd;
                        epoll_ctl(epfd_, EPOLL_CTL_ADD, clientfd, &client_ev);
                    }
                } else {
                    int fd = events[i].data.fd;
                    if (events[i].events & EPOLLRDHUP) {
                        close(fd);
                        continue;
                    }
                    if (events[i].events & EPOLLIN) {
                        read_et(epfd_, fd);
                    }
                }
            }
        }
    }

private:
    int port_;
    int listenfd_;
    int epfd_;
};
```

```cpp
        item->fd = fd;

        item->callback = [](EpItem* self) {

            output[count].events = node->events;
            count++;
            node = node->next;
        }

        // 清空就绪队列
        rdllist = nullptr;

        return count;
```

```cpp
    virtual void modify_fd(int fd, uint32_t events) = 0;

public:
    EpollPoller() : epfd_(epoll_create1(0)) {}

        struct epoll_event ev{};
        ev.events = events;
        ev.data.fd = fd;
        epoll_ctl(epfd_, EPOLL_CTL_ADD, fd, &ev);
        callbacks_[fd] = std::move(cb);

        struct epoll_event ev{};
        ev.events = events;
        ev.data.fd = fd;
        epoll_ctl(epfd_, EPOLL_CTL_MOD, fd, &ev);

        callbacks_.erase(fd);

                it->second(events[i].data.fd, events[i].events);
            }
        }
```

```
│   │                   │            │              │          │
│   │ 完成队列 (CQ)     │◄──────────▶│              │          │
│   │ ┌──┐┌──┐┌──┐     │   共享内存  │              │          │
│   │ │C1││C2││C3│     │            │              │          │
│   │ └──┘└──┘└──┘     │            └──────────────┘          │
│   │  ↑ IO完成结果     │                                      │
│   └──────────────────┘                                      │
│                                                              │
│   关键特性：                                                  │
│   ✅ 共享内存——无系统调用开销（SQPOLL模式）                    │
│   ✅ 批量提交——一次提交多个IO请求                              │
│   ✅ 真正异步——不依赖文件描述符是否可读/可写                    │
│   ✅ 统一接口——文件IO和网络IO使用同一套API                     │
│   ✅ 链式请求——IO操作可以链式依赖                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```cpp
#include <iostream>
#include <cstring>

#ifdef __linux__
#include <liburing.h>

// io_uring TCP服务器示例
class IOUringServer {
public:
    IOUringServer(int port, unsigned int queue_depth = 128)
        : port_(port), queue_depth_(queue_depth) {}

    void start() {
        // 初始化io_uring
        struct io_uring ring;
        if (io_uring_queue_init(queue_depth_, &ring, 0) < 0) {
            perror("io_uring_queue_init");
            return;
        }

        // 创建监听socket
        int listenfd = socket(AF_INET, SOCK_STREAM, 0);
        int opt = 1;
        setsockopt(listenfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd, 128);

        std::cout << "io_uring服务器启动，端口: " << port_ << std::endl;

        // 提交accept请求
        submit_accept(&ring, listenfd);

        // 事件循环
        while (true) {
            // 等待完成事件
            struct io_uring_cqe* cqe;
            int ret = io_uring_wait_cqe(&ring, &cqe);

            if (ret < 0) {
                perror("io_uring_wait_cqe");
                continue;
            }

            // 处理完成事件
            int result = cqe->res;
            auto* req = (Request*)io_uring_cqe_get_data(cqe);

            if (req->type == RequestType::ACCEPT) {
                // accept完成
                if (result >= 0) {
                    int clientfd = result;
                    std::cout << "新连接: fd=" << clientfd << std::endl;

                    // 为新连接提交recv请求
                    submit_recv(&ring, clientfd);
                }
                // 继续提交accept
                submit_accept(&ring, listenfd);
            } else if (req->type == RequestType::RECV) {
                // recv完成
                if (result > 0) {
                    // 回显数据
                    submit_send(&ring, req->fd, result);
                } else {
                    // 连接关闭
                    close(req->fd);
                }
            } else if (req->type == RequestType::SEND) {
                // send完成，继续recv
                if (result >= 0) {
                    submit_recv(&ring, req->fd);
                }
            }

            io_uring_cqe_seen(&ring, cqe);
        }

        io_uring_queue_exit(&ring);
        close(listenfd);
    }

private:
    enum class RequestType { ACCEPT, RECV, SEND };

    struct Request {
        RequestType type;
        int fd;
        char buffer[4096];
    };

    void submit_accept(struct io_uring* ring, int listenfd) {
        struct io_uring_sqe* sqe = io_uring_get_sqe(ring);
        auto* req = new Request{RequestType::ACCEPT, listenfd, {}};

        sockaddr_in client_addr{};
        socklen_t client_len = sizeof(client_addr);

        io_uring_prep_accept(sqe, listenfd,
                              (sockaddr*)&client_addr, &client_len, 0);
        io_uring_sqe_set_data(sqe, req);
        io_uring_submit(ring);
    }

    void submit_recv(struct io_uring* ring, int fd) {
        struct io_uring_sqe* sqe = io_uring_get_sqe(ring);
        auto* req = new Request{RequestType::RECV, fd, {}};

        io_uring_prep_recv(sqe, fd, req->buffer, sizeof(req->buffer), 0);
        io_uring_sqe_set_data(sqe, req);
        io_uring_submit(ring);
    }

    void submit_send(struct io_uring* ring, int fd, int len) {
        struct io_uring_sqe* sqe = io_uring_get_sqe(ring);
        auto* req = new Request{RequestType::SEND, fd, {}};

        io_uring_prep_send(sqe, fd, req->buffer, len, 0);
        io_uring_sqe_set_data(sqe, req);
        io_uring_submit(ring);
    }

    int port_;
    unsigned int queue_depth_;
};
```

## 8. 小结

### 核心要点回顾

| 要点 | 说明 |
|------|------|
| **select** | 最早的IO多路复用，有1024限制，O(n)遍历 |
| **poll** | 突破fd数量限制，但仍O(n)遍历 |
| **epoll** | 事件注册+回调通知，O(1)效率，Linux首选 |
| **LT模式** | 水平触发，编程简单，不会漏事件 |
| **ET模式** | 边沿触发，效率更高，需循环读写 |
| **红黑树** | epoll存储注册fd的数据结构，O(log n)操作 |
| **就绪队列** | epoll存储就绪fd的双向链表，O(1)获取 |
| **kqueue** | BSD/macOS的IO多路复用，类似epoll |
| **IOCP** | Windows的完成端口模型，真正的异步IO |
| **io_uring** | Linux新一代异步IO，共享内存+批量提交 |

### 性能对比

| 机制 | fd数量 | 时间复杂度 | 平台 | 适用场景 |
|------|--------|-----------|------|---------|
| select | ≤1024 | O(n) | 全平台 | 少量连接 |
| poll | 无限制 | O(n) | 大多数 | 中等连接 |
| epoll | 无限制 | O(1) | Linux | 大量连接 |
| kqueue | 无限制 | O(1) | BSD/macOS | 大量连接 |
| IOCP | 无限制 | O(1) | Windows | 大量连接 |
| io_uring | 无限制 | O(1) | Linux 5.1+ | 超高性能 |
