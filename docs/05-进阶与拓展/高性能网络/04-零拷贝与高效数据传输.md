# 零拷贝与高效数据传输

> 掌握减少数据拷贝、提升传输效率的核心技术

---

> **Zero-copy is not about copying zero bytes; it's about avoiding unnecessary copies.**
> （零拷贝不是拷贝零字节，而是避免不必要的拷贝。）

> **零拷贝：让数据直达目的地，不做无谓搬运。**

---

> 🎯 **直奔主题，不做无用功。**

> （消除不必要的数据拷贝，让每一次传输都高效。）

---

> 💡 **通俗理解 - 零拷贝**

想象搬家：
- **传统方式**：从旧家搬到卡车，再从卡车搬到新家 → 搬了两次
- **零拷贝**：直接从旧家搬到新家 → 只搬一次

**零拷贝就是让数据从源头直达目的地，避免在内核空间和用户空间之间来回搬运！**

> 🔬 **抽象理解 - 零拷贝**：
> - **传统拷贝**：数据从内核缓冲区拷贝到用户缓冲区，再从用户缓冲区拷贝回内核缓冲区
> - **mmap**：将文件映射到用户空间，避免read的系统调用和拷贝
> - **sendfile**：内核直接将数据从文件描述符传输到socket，无需经过用户空间
> - **splice**：在两个文件描述符之间移动数据，零拷贝
> - **MSG_ZEROCOPY**：Linux 4.14+的socket零拷贝，减少内核到网卡的拷贝

## 1. 传统数据拷贝流程

### 1.1 传统read + write流程

```
┌──────────────────────────────────────────────────────────────┐
│              传统 read() + write() 数据拷贝                    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   用户空间                        内核空间                    │
│   ┌──────────────┐              ┌──────────────┐            │
│   │              │   read()     │              │            │
│   │  用户缓冲区   │◀────────────│ 内核读缓冲区  │            │
│   │  (user buf)  │   拷贝2     │ (page cache) │            │
│   │              │              │              │            │
│   │              │   write()    │              │            │
│   │  用户缓冲区   │────────────▶│ 内核写缓冲区  │            │
│   │  (user buf)  │   拷贝3     │ (socket buf) │            │
│   └──────────────┘              └──────────────┘            │
│                                         │                    │
│                                         │ 拷贝4              │
│                                         ▼                    │
│                                  ┌──────────────┐           │
│                                  │  网卡DMA缓冲  │           │
│                                  └──────────────┘           │
│                                                              │
│   磁盘 ──DMA拷贝1──▶ 内核读缓冲区                             │
│                                                              │
│   总共4次拷贝：                                              │
│   拷贝1: 磁盘 → 内核读缓冲区 (DMA)                           │
│   拷贝2: 内核读缓冲区 → 用户缓冲区 (CPU)                      │
│   拷贝3: 用户缓冲区 → 内核写缓冲区 (CPU)                      │
│   拷贝4: 内核写缓冲区 → 网卡缓冲区 (DMA)                      │
│                                                              │
│   4次上下文切换：                                            │
│   切换1: 用户态 → 内核态 (read系统调用)                       │
│   切换2: 内核态 → 用户态 (read返回)                           │
│   切换3: 用户态 → 内核态 (write系统调用)                      │
│   切换4: 内核态 → 用户态 (write返回)                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 传统拷贝代码示例

```cpp
#include <iostream>
#include <fcntl.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <cstring>
#include <chrono>

// 传统方式：读取文件并发送到网络
void traditional_sendfile(const char* filename, int sockfd) {
    int fd = open(filename, O_RDONLY);
    if (fd < 0) {
        perror("open");
        return;
    }

    char buffer[65536];  // 用户缓冲区
    ssize_t total_sent = 0;

    auto start = std::chrono::high_resolution_clock::now();

    while (true) {
        // 第1步：从文件读取到用户缓冲区
        // 涉及：内核态切换 + 内核缓冲区→用户缓冲区拷贝
        ssize_t n = read(fd, buffer, sizeof(buffer));
        if (n <= 0) break;

        // 第2步：从用户缓冲区写入到socket
        // 涉及：内核态切换 + 用户缓冲区→socket缓冲区拷贝
        ssize_t sent = send(sockfd, buffer, n, 0);
        if (sent < 0) {
            perror("send");
            break;
        }
        total_sent += sent;
    }

    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(
                  end - start).count();

    std::cout << "传统方式发送: " << total_sent << " 字节, "
              << "耗时: " << ms << "ms" << std::endl;

    close(fd);
}

// 测量传统拷贝的开销
void measure_traditional_copy() {
    // 创建测试文件
    const char* test_file = "/tmp/zerocopy_test.dat";
    int fd = open(test_file, O_CREAT | O_WRONLY | O_TRUNC, 0644);
    char data[65536];
    memset(data, 'A', sizeof(data));
    for (int i = 0; i < 1000; ++i) {  // 64MB
        write(fd, data, sizeof(data));
    }
    close(fd);

    // 创建socket
    int sockfd = socket(AF_INET, SOCK_STREAM, 0);
    sockaddr_in addr{};
    addr.sin_family = AF_INET;
    addr.sin_port = htons(9090);
    inet_pton(AF_INET, "127.0.0.1", &addr.sin_addr);
    // connect(sockfd, ...);

    traditional_sendfile(test_file, sockfd);

    close(sockfd);
    unlink(test_file);
}
```

### 1.3 拷贝开销分析

| 操作 | CPU拷贝 | DMA拷贝 | 上下文切换 |
|------|---------|---------|-----------|
| read() | 1次 | 1次 | 2次 |
| write() | 1次 | 1次 | 2次 |
| **总计** | **2次** | **2次** | **4次** |

```
┌──────────────────────────────────────────────────────────────┐
│                  各零拷贝技术减少的拷贝次数                     │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   技术方案          CPU拷贝   DMA拷贝   上下文切换             │
│   ─────────────────────────────────────────────              │
│   传统read+write     2        2         4                    │
│   mmap+write         1        2         4                    │
│   sendfile           1        2         2                    │
│   sendfile+DMA-SG    0        2         2                    │
│   splice             0        2         2                    │
│   MSG_ZEROCOPY       0        1         2                    │
│                                                              │
│   理想状态：0次CPU拷贝 + 1次DMA拷贝 + 最少上下文切换           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 2. sendfile

### 2.1 sendfile原理

sendfile在内核中直接将数据从文件传输到socket，无需经过用户空间：

```
┌──────────────────────────────────────────────────────────────┐
│                    sendfile 数据流                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   用户空间                        内核空间                    │
│   ┌──────────────┐              ┌──────────────┐            │
│   │              │              │              │            │
│   │  不需要      │   sendfile() │ 内核读缓冲区  │            │
│   │  用户缓冲区  │◀────────────│ (page cache) │            │
│   │              │              │      │       │            │
│   │              │              │      │拷贝2  │            │
│   │              │              │      ▼       │            │
│   │              │              │ 内核写缓冲区  │            │
│   │              │              │ (socket buf) │            │
│   └──────────────┘              └──────┬───────┘            │
│                                         │                    │
│                                         │ 拷贝3(DMA)         │
│                                         ▼                    │
│                                  ┌──────────────┐           │
│                                  │  网卡DMA缓冲  │           │
│                                  └──────────────┘           │
│                                                              │
│   磁盘 ──DMA拷贝1──▶ 内核读缓冲区                             │
│                                                              │
│   总共3次拷贝（减少1次CPU拷贝）：                              │
│   拷贝1: 磁盘 → 内核读缓冲区 (DMA)                           │
│   拷贝2: 内核读缓冲区 → 内核写缓冲区 (CPU) ← 唯一的CPU拷贝   │
│   拷贝3: 内核写缓冲区 → 网卡缓冲区 (DMA)                      │
│                                                              │
│   2次上下文切换（减少2次）：                                  │
│   切换1: 用户态 → 内核态 (sendfile系统调用)                   │
│   切换2: 内核态 → 用户态 (sendfile返回)                       │
│                                                              │
│   Linux 2.6.33+ 支持DMA Scatter-Gather：                     │
│   拷贝2被消除！数据直接从page cache到网卡，零CPU拷贝！         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 sendfile代码示例

```cpp
#include <iostream>
#include <fcntl.h>
#include <unistd.h>
#include <sys/socket.h>
#include <sys/sendfile.h>
#include <netinet/in.h>
#include <cstring>
#include <chrono>

// sendfile方式：零拷贝发送文件
void zero_copy_sendfile(const char* filename, int sockfd) {
    int fd = open(filename, O_RDONLY);
    if (fd < 0) {
        perror("open");
        return;
    }

    // 获取文件大小
    off_t offset = 0;
    off_t file_size = lseek(fd, 0, SEEK_END);
    lseek(fd, 0, SEEK_SET);

    auto start = std::chrono::high_resolution_clock::now();

    // 一次调用，内核直接将文件数据传输到socket
    // 数据不经过用户空间！
    ssize_t sent = sendfile(sockfd, fd, &offset, file_size);

    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(
                  end - start).count();

    if (sent < 0) {
        perror("sendfile");
    } else {
        std::cout << "sendfile发送: " << sent << " 字节, "
                  << "耗时: " << ms << "ms" << std::endl;
    }

    close(fd);
}

// 大文件分块sendfile
void sendfile_chunked(const char* filename, int sockfd,
                      size_t chunk_size = 1024 * 1024) {
    int fd = open(filename, O_RDONLY);
    if (fd < 0) {
        perror("open");
        return;
    }

    off_t offset = 0;
    off_t file_size = lseek(fd, 0, SEEK_END);
    lseek(fd, 0, SEEK_SET);

    ssize_t total_sent = 0;

    while (offset < file_size) {
        // 每次发送一个块
        size_t to_send = std::min(
            (off_t)chunk_size, file_size - offset);

        ssize_t sent = sendfile(sockfd, fd, &offset, to_send);
        if (sent < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                continue;  // socket缓冲区满，重试
            }
            perror("sendfile");
            break;
        }
        total_sent += sent;
    }

    std::cout << "分块sendfile发送: " << total_sent << " 字节" << std::endl;
    close(fd);
}

// HTTP静态文件服务器（使用sendfile）
class StaticFileServer {
public:
    StaticFileServer(int port, const std::string& doc_root)
        : port_(port), doc_root_(doc_root) {}

    void start() {
        int listenfd = socket(AF_INET, SOCK_STREAM, 0);
        int opt = 1;
        setsockopt(listenfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd, 128);

        std::cout << "静态文件服务器启动，端口: " << port_ << std::endl;

        while (true) {
            int clientfd = accept(listenfd, nullptr, nullptr);
            if (clientfd < 0) continue;
            handle_request(clientfd);
            close(clientfd);
        }
    }

private:
    void handle_request(int clientfd) {
        char buffer[4096];
        ssize_t n = recv(clientfd, buffer, sizeof(buffer) - 1, 0);
        if (n <= 0) return;
        buffer[n] = '\0';

        // 简单解析HTTP请求
        std::string request(buffer);
        size_t path_start = request.find("GET ");
        if (path_start == std::string::npos) return;

        size_t path_end = request.find(" ", path_start + 4);
        std::string path = request.substr(path_start + 4, path_end - path_start - 4);

        if (path == "/") path = "/index.html";
        std::string filepath = doc_root_ + path;

        // 打开文件
        int fd = open(filepath.c_str(), O_RDONLY);
        if (fd < 0) {
            const char* not_found = "HTTP/1.1 404 Not Found\r\n\r\n";
            send(clientfd, not_found, strlen(not_found), 0);
            return;
        }

        // 获取文件大小
        off_t file_size = lseek(fd, 0, SEEK_END);
        lseek(fd, 0, SEEK_SET);

        // 发送HTTP响应头
        std::string header = "HTTP/1.1 200 OK\r\n"
                             "Content-Length: " + std::to_string(file_size) + "\r\n"
                             "Connection: close\r\n\r\n";
        send(clientfd, header.data(), header.size(), 0);

        // 使用sendfile零拷贝发送文件内容
        off_t offset = 0;
        while (offset < file_size) {
            ssize_t sent = sendfile(clientfd, fd, &offset,
                                     file_size - offset);
            if (sent <= 0) break;
        }

        close(fd);
    }

    int port_;
    std::string doc_root_;
};
```

## 3. splice与tee

### 3.1 splice原理

splice在两个文件描述符之间移动数据，至少一端必须是管道：

```
┌──────────────────────────────────────────────────────────────┐
│                    splice 数据流                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   splice(file_fd ↔ pipe_fd ↔ socket_fd)                     │
│                                                              │
│   ┌──────────┐    splice     ┌──────────┐    splice         │
│   │ 文件fd   │──────────────▶│ 管道     │──────────────▶   │
│   │(page    │   内核缓冲区   │(pipe    │   内核缓冲区      │
│   │ cache)  │   指针传递    │ buffer) │   指针传递        │
│   └──────────┘              └──────────┘                    │
│                                                              │
│   关键：数据通过指针在内核空间传递，不拷贝实际数据！            │
│                                                              │
│   步骤：                                                      │
│   1. splice(file, pipe_in) —— 文件数据"移动"到管道           │
│   2. splice(pipe_out, socket) —— 管道数据"移动"到socket      │
│                                                              │
│   零CPU拷贝！只有DMA参与数据传输                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 splice代码示例

```cpp
#include <iostream>
#include <fcntl.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <cerrno>
#include <cstring>

// splice方式：零拷贝代理转发
void splice_proxy(int clientfd, int serverfd) {
    // 创建两根管道
    int pipe1[2], pipe2[2];
    pipe(pipe1);  // client → server 方向
    pipe(pipe2);  // server → client 方向

    // 双向数据转发
    while (true) {
        // 从客户端读取数据到管道
        ssize_t n = splice(clientfd, nullptr, pipe1[1], nullptr,
                            65536, SPLICE_F_MOVE | SPLICE_F_NONBLOCK);
        if (n <= 0) break;

        // 从管道写入服务器
        splice(pipe1[0], nullptr, serverfd, nullptr,
               n, SPLICE_F_MOVE);

        // 从服务器读取数据到管道
        n = splice(serverfd, nullptr, pipe2[1], nullptr,
                    65536, SPLICE_F_MOVE | SPLICE_F_NONBLOCK);
        if (n <= 0) break;

        // 从管道写入客户端
        splice(pipe2[0], nullptr, clientfd, nullptr,
               n, SPLICE_F_MOVE);
    }

    close(pipe1[0]); close(pipe1[1]);
    close(pipe2[0]); close(pipe2[1]);
}

// TCP代理服务器（使用splice零拷贝）
class SpliceProxyServer {
public:
    SpliceProxyServer(int listen_port, const char* target_host, int target_port)
        : listen_port_(listen_port), target_port_(target_port),
          target_host_(target_host) {}

    void start() {
        int listenfd = socket(AF_INET, SOCK_STREAM, 0);
        int opt = 1;
        setsockopt(listenfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(listen_port_);
        addr.sin_addr.s_addr = INADDR_ANY;

        bind(listenfd, (sockaddr*)&addr, sizeof(addr));
        listen(listenfd, 128);

        std::cout << "Splice代理服务器启动，端口: " << listen_port_ << std::endl;

        while (true) {
            int clientfd = accept(listenfd, nullptr, nullptr);
            if (clientfd < 0) continue;

            // 连接目标服务器
            int serverfd = socket(AF_INET, SOCK_STREAM, 0);
            sockaddr_in target_addr{};
            target_addr.sin_family = AF_INET;
            target_addr.sin_port = htons(target_port_);
            inet_pton(AF_INET, target_host_.c_str(), &target_addr.sin_addr);

            if (connect(serverfd, (sockaddr*)&target_addr,
                        sizeof(target_addr)) < 0) {
                close(clientfd);
                close(serverfd);
                continue;
            }

            // 使用splice零拷贝转发
            splice_proxy(clientfd, serverfd);

            close(clientfd);
            close(serverfd);
        }
    }

private:
    int listen_port_;
    int target_port_;
    std::string target_host_;
};

// tee：在两个管道之间复制数据（不消耗源数据）
void tee_example() {
    int pipe1[2], pipe2[2];
    pipe(pipe1);
    pipe(pipe2);

    // 向pipe1写入数据
    const char* msg = "Hello, tee!";
    write(pipe1[1], msg, strlen(msg));

    // tee：将pipe1的数据复制到pipe2（pipe1的数据不消耗）
    ssize_t n = tee(pipe1[0], pipe2[1], 65536, 0);

    if (n > 0) {
        char buf1[256], buf2[256];

        // 从pipe1读取（数据仍在）
        ssize_t n1 = read(pipe1[0], buf1, sizeof(buf1) - 1);
        buf1[n1] = '\0';

        // 从pipe2读取（tee复制的数据）
        ssize_t n2 = read(pipe2[0], buf2, sizeof(buf2) - 1);
        buf2[n2] = '\0';

        std::cout << "pipe1: " << buf1 << std::endl;
        std::cout << "pipe2: " << buf2 << std::endl;
    }

    close(pipe1[0]); close(pipe1[1]);
    close(pipe2[0]); close(pipe2[1]);
}
```

## 4. mmap与共享内存

### 4.1 mmap原理

mmap将文件映射到进程的虚拟地址空间，访问文件就像访问内存一样：

```
┌──────────────────────────────────────────────────────────────┐
│                    mmap 数据流                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   用户空间                        内核空间                    │
│   ┌──────────────┐              ┌──────────────┐            │
│   │              │              │              │            │
│   │  mmap映射区  │◀───虚拟────▶│ page cache   │            │
│   │  (虚拟内存)  │   内存映射   │ (文件缓存)   │            │
│   │              │              │              │            │
│   │  直接访问    │              │              │            │
│   │  像访问内存  │              │              │            │
│   │  一样访问    │              │              │            │
│   └──────────────┘              └──────────────┘            │
│                                                              │
│   优势：                                                      │
│   ✅ 避免read/write系统调用                                   │
│   ✅ 避免内核→用户空间的数据拷贝                               │
│   ✅ 多进程可共享同一映射（共享内存）                          │
│   ✅ 支持随机访问                                            │
│                                                              │
│   注意：                                                      │
│   ⚠️ write()时仍需从page cache拷贝到socket缓冲区             │
│   ⚠️ 文件修改需要msync同步到磁盘                              │
│   ⚠️ 映射大文件会占用虚拟地址空间                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 mmap代码示例

```cpp
#include <iostream>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <cstring>
#include <chrono>

// mmap方式读取文件
void mmap_read_file(const char* filename) {
    int fd = open(filename, O_RDONLY);
    if (fd < 0) {
        perror("open");
        return;
    }

    // 获取文件大小
    struct stat st{};
    fstat(fd, &st);
    size_t file_size = st.st_size;

    // 将文件映射到内存
    void* mapped = mmap(nullptr, file_size, PROT_READ,
                         MAP_PRIVATE, fd, 0);
    if (mapped == MAP_FAILED) {
        perror("mmap");
        close(fd);
        return;
    }

    // 像访问内存一样访问文件内容
    char* data = static_cast<char*>(mapped);
    std::cout << "文件前100字节: ";
    std::cout.write(data, std::min(file_size, (size_t)100));
    std::cout << std::endl;

    // 解除映射
    munmap(mapped, file_size);
    close(fd);
}

// mmap方式写入文件
void mmap_write_file(const char* filename, size_t size) {
    int fd = open(filename, O_RDWR | O_CREAT | O_TRUNC, 0644);
    if (fd < 0) {
        perror("open");
        return;
    }

    // 设置文件大小
    if (ftruncate(fd, size) < 0) {
        perror("ftruncate");
        close(fd);
        return;
    }

    // 映射文件
    void* mapped = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                         MAP_SHARED, fd, 0);
    if (mapped == MAP_FAILED) {
        perror("mmap");
        close(fd);
        return;
    }

    // 直接写入数据到映射区
    char* data = static_cast<char*>(mapped);
    memset(data, 'X', size);

    // 同步到磁盘
    msync(mapped, size, MS_SYNC);

    munmap(mapped, size);
    close(fd);
}

// mmap + write 发送文件（减少一次拷贝）
void mmap_sendfile(const char* filename, int sockfd) {
    int fd = open(filename, O_RDONLY);
    if (fd < 0) return;

    struct stat st{};
    fstat(fd, &st);

    void* mapped = mmap(nullptr, st.st_size, PROT_READ,
                         MAP_PRIVATE, fd, 0);
    if (mapped == MAP_FAILED) {
        close(fd);
        return;
    }

    // 直接从映射区发送，避免了一次read拷贝
    send(sockfd, mapped, st.st_size, MSG_NOSIGNAL);

    munmap(mapped, st.st_size);
    close(fd);
}
```

### 4.3 共享内存IPC

```cpp
#include <iostream>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <cstring>
#include <semaphore.h>

// 共享内存通信——生产者
void shared_memory_producer() {
    // 创建共享内存对象
    int fd = shm_open("/my_shm", O_CREAT | O_RDWR, 0666);
    ftruncate(fd, 4096);

    // 映射共享内存
    void* ptr = mmap(nullptr, 4096, PROT_READ | PROT_WRITE,
                      MAP_SHARED, fd, 0);

    // 创建信号量
    sem_t* sem = sem_open("/my_sem", O_CREAT, 0666, 0);

    // 写入数据
    const char* message = "Hello from producer!";
    memcpy(ptr, message, strlen(message) + 1);

    // 通知消费者
    sem_post(sem);

    // 清理
    munmap(ptr, 4096);
    close(fd);
    sem_close(sem);
}

// 共享内存通信——消费者
void shared_memory_consumer() {
    // 打开共享内存
    int fd = shm_open("/my_shm", O_RDWR, 0666);

    void* ptr = mmap(nullptr, 4096, PROT_READ | PROT_WRITE,
                      MAP_SHARED, fd, 0);

    // 等待数据
    sem_t* sem = sem_open("/my_sem", 0);
    sem_wait(sem);

    // 读取数据
    char* data = static_cast<char*>(ptr);
    std::cout << "收到: " << data << std::endl;

    // 清理
    munmap(ptr, 4096);
    close(fd);
    sem_close(sem);
    shm_unlink("/my_shm");
    sem_unlink("/my_sem");
}

// 高性能共享内存环形缓冲区
template<size_t Size = 65536>
class SharedRingBuffer {
public:
    SharedRingBuffer(const char* name, bool create) {
        if (create) {
            fd_ = shm_open(name, O_CREAT | O_RDWR, 0666);
            ftruncate(fd_, sizeof(Header) + Size);
        } else {
            fd_ = shm_open(name, O_RDWR, 0666);
        }

        void* ptr = mmap(nullptr, sizeof(Header) + Size,
                          PROT_READ | PROT_WRITE, MAP_SHARED, fd_, 0);
        header_ = static_cast<Header*>(ptr);
        buffer_ = static_cast<char*>(ptr) + sizeof(Header);

        if (create) {
            header_->read_pos = 0;
            header_->write_pos = 0;
            header_->sem = sem_open("/ring_sem", O_CREAT, 0666, 0);
        } else {
            header_->sem = sem_open("/ring_sem", 0);
        }
    }

    ~SharedRingBuffer() {
        munmap(header_, sizeof(Header) + Size);
        close(fd_);
        sem_close(header_->sem);
    }

    // 写入数据
    bool write(const void* data, size_t len) {
        size_t available = Size - (header_->write_pos - header_->read_pos);
        if (len > available) return false;

        size_t write_idx = header_->write_pos % Size;
        size_t first_chunk = std::min(len, Size - write_idx);

        memcpy(buffer_ + write_idx, data, first_chunk);
        if (len > first_chunk) {
            memcpy(buffer_, static_cast<const char*>(data) + first_chunk,
                   len - first_chunk);
        }

        header_->write_pos += len;
        sem_post(header_->sem);
        return true;
    }

    // 读取数据
    size_t read(void* data, size_t max_len) {
        sem_wait(header_->sem);

        size_t available = header_->write_pos - header_->read_pos;
        size_t to_read = std::min(available, max_len);

        size_t read_idx = header_->read_pos % Size;
        size_t first_chunk = std::min(to_read, Size - read_idx);

        memcpy(data, buffer_ + read_idx, first_chunk);
        if (to_read > first_chunk) {
            memcpy(static_cast<char*>(data) + first_chunk,
                   buffer_, to_read - first_chunk);
        }

        header_->read_pos += to_read;
        return to_read;
    }

private:
    struct Header {
        size_t read_pos;
        size_t write_pos;
        sem_t* sem;
    };

    int fd_;
    Header* header_;
    char* buffer_;
};
```

## 5. DMA传输

### 5.1 DMA原理

DMA（Direct Memory Access）允许硬件设备直接访问内存，无需CPU参与：

```
┌──────────────────────────────────────────────────────────────┐
│                    DMA 传输原理                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   传统方式（CPU参与）：                                       │
│   ┌──────┐    CPU拷贝    ┌──────────┐    CPU拷贝    ┌──────┐│
│   │ 磁盘 │─────────────▶│ 内存     │─────────────▶│ 网卡 ││
│   └──────┘              └──────────┘              └──────┘│
│   CPU忙于搬运数据，无法执行其他任务                           │
│                                                              │
│   DMA方式（CPU不参与）：                                      │
│   ┌──────┐   DMA传输    ┌──────────┐   DMA传输    ┌──────┐│
│   │ 磁盘 │─────────────▶│ 内存     │─────────────▶│ 网卡 ││
│   └──────┘              └──────────┘              └──────┘│
│   CPU只需设置DMA控制器，然后可以做其他事                      │
│                                                              │
│   DMA Scatter-Gather（分散-收集）：                           │
│   ┌──────┐                    ┌──────┐                      │
│   │ 磁盘 │──── DMA ────▶     │ 网卡 │                      │
│   └──────┘                    └──────┘                      │
│       │                           ▲                         │
│       │   ┌──────────┐           │                         │
│       └──▶│ page     │───DMA────┘                         │
│           │ cache    │   (直接传输)                         │
│           │ 片段1    │                                     │
│           │ 片段2    │                                     │
│           │ 片段3    │                                     │
│           └──────────┘                                     │
│                                                              │
│   Scatter-Gather允许DMA从多个不连续的内存区域收集数据          │
│   一次性发送到网卡，无需将数据拼接到连续内存                   │
│   这是sendfile零CPU拷贝的关键！                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 6. MSG_ZEROCOPY

### 6.1 MSG_ZEROCOPY原理

MSG_ZEROCOPY是Linux 4.14引入的socket零拷贝选项：

```
┌──────────────────────────────────────────────────────────────┐
│                  MSG_ZEROCOPY 数据流                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   传统send()：                                               │
│   用户缓冲区 ──CPU拷贝──▶ 内核socket缓冲区 ──DMA──▶ 网卡     │
│                                                              │
│   MSG_ZEROCOPY：                                             │
│   用户缓冲区 ────────DMA────────────────────────▶ 网卡       │
│                    (直接从用户空间读取)                       │
│                                                              │
│   工作流程：                                                  │
│   1. send(fd, buf, len, MSG_ZEROCOPY)                       │
│   2. 内核将用户缓冲区锁定（防止被换出）                       │
│   3. 内核将用户缓冲区地址传给网卡                             │
│   4. 网卡DMA直接从用户缓冲区读取数据                          │
│   5. 传输完成后，内核通过socket错误队列通知应用               │
│   6. 应用收到通知后才能释放缓冲区                             │
│                                                              │
│   注意事项：                                                  │
│   ⚠️ 必须等待完成通知后才能释放缓冲区                         │
│   ⚠️ 需要处理socket错误队列                                  │
│   ⚠️ 小数据量可能反而更慢（页锁定开销）                       │
│   ⚠️ 适合大数据块传输（通常 > 10KB）                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 6.2 MSG_ZEROCOPY代码示例

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cstring>
#include <cerrno>

// MSG_ZEROCOPY 发送数据
void msg_zerocopy_send(int sockfd, const void* data, size_t len) {
    // 发送数据时使用MSG_ZEROCOPY标志
    ssize_t sent = send(sockfd, data, len, MSG_ZEROCOPY | MSG_NOSIGNAL);

    if (sent < 0) {
        if (errno == ENOBUFS) {
            // 没有足够的内存进行零拷贝，回退到普通发送
            std::cout << "零拷贝不可用，回退到普通发送" << std::endl;
            send(sockfd, data, len, MSG_NOSIGNAL);
            return;
        }
        perror("send");
        return;
    }

    // 等待零拷贝完成通知
    wait_zerocopy_completion(sockfd);

    // 完成后才能安全释放数据缓冲区
}

// 等待零拷贝完成通知
void wait_zerocopy_completion(int sockfd) {
    char ctrl_buffer[512];
    struct msghdr msg{};
    struct iovec iov{};
    char data_buffer[1];

    msg.msg_iov = &iov;
    msg.msg_iovlen = 1;
    iov.iov_base = data_buffer;
    iov.iov_len = sizeof(data_buffer);
    msg.msg_control = ctrl_buffer;
    msg.msg_controllen = sizeof(ctrl_buffer);

    // 从错误队列读取完成通知
    ssize_t ret = recvmsg(sockfd, &msg, MSG_ERRQUEUE);
    if (ret < 0) {
        perror("recvmsg");
        return;
    }

    // 解析完成通知
    for (struct cmsghdr* cmsg = CMSG_FIRSTHDR(&msg);
         cmsg != nullptr;
         cmsg = CMSG_NXTHDR(&msg, cmsg)) {
        if (cmsg->cmsg_level == SOL_IP &&
            cmsg->cmsg_type == IP_RECVERR) {
            struct sock_extended_err* err =
                (struct sock_extended_err*)CMSG_DATA(cmsg);

            if (err->ee_origin == SO_EE_ORIGIN_ZEROCOPY) {
                uint32_t lo = err->ee_info;  // 起始ID
                uint32_t hi = err->ee_data;  // 结束ID

                if (err->ee_code & SO_EE_CODE_ZEROCOPY_COPIED) {
                    // 数据被拷贝了（零拷贝失败，回退到拷贝模式）
                    std::cout << "零拷贝回退到拷贝模式, range: "
                              << lo << "-" << hi << std::endl;
                } else {
                    // 零拷贝成功完成
                    std::cout << "零拷贝完成, range: "
                              << lo << "-" << hi << std::endl;
                }
            }
        }
    }
}

// 完整的MSG_ZEROCOPY使用示例
class ZeroCopySender {
public:
    ZeroCopySender(const char* host, int port) {
        sockfd_ = socket(AF_INET, SOCK_STREAM, 0);

        // 启用零拷贝
        int val = 1;
        setsockopt(sockfd_, SOL_SOCKET, SO_ZEROCOPY, &val, sizeof(val));

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(port);
        inet_pton(AF_INET, host, &addr.sin_addr);

        connect(sockfd_, (sockaddr*)&addr, sizeof(addr));
    }

    ~ZeroCopySender() {
        if (sockfd_ >= 0) close(sockfd_);
    }

    // 发送大数据块
    void send_large_data(const void* data, size_t len) {
        // 大数据使用零拷贝
        if (len >= 10240) {  // > 10KB
            ssize_t sent = send(sockfd_, data, len,
                                MSG_ZEROCOPY | MSG_NOSIGNAL);
            if (sent >= 0) {
                pending_completions_++;
            }
        } else {
            // 小数据使用普通发送
            send(sockfd_, data, len, MSG_NOSIGNAL);
        }
    }

    // 处理所有完成通知
    void process_completions() {
        while (pending_completions_ > 0) {
            wait_zerocopy_completion(sockfd_);
            pending_completions_--;
        }
    }

private:
    int sockfd_;
    int pending_completions_ = 0;
};
```

### 7.3 零拷贝性能对比

```cpp
#include <iostream>
#include <fcntl.h>
#include <unistd.h>
#include <sys/mman.h>
#include <sys/sendfile.h>
#include <sys/socket.h>
#include <chrono>
#include <cstring>
#include <vector>

// 性能对比测试
class ZeroCopyBenchmark {
public:
    struct Result {
        std::string method;
        size_t bytes;
        double time_ms;
        double throughput_mbps;
    };

    static Result benchmark_traditional(int fd, int sockfd, size_t file_size) {
        char buffer[65536];
        size_t total = 0;

        auto start = std::chrono::high_resolution_clock::now();
        lseek(fd, 0, SEEK_SET);

        while (total < file_size) {
            ssize_t n = read(fd, buffer, sizeof(buffer));
            if (n <= 0) break;
            send(sockfd, buffer, n, MSG_NOSIGNAL);
            total += n;
        }

        auto end = std::chrono::high_resolution_clock::now();
        double ms = std::chrono::duration<double, std::milli>(end - start).count();

        return {"read+write", total, ms, (total / 1024.0 / 1024.0) / (ms / 1000.0)};
    }

    static Result benchmark_sendfile(int fd, int sockfd, size_t file_size) {
        off_t offset = 0;

        auto start = std::chrono::high_resolution_clock::now();

        while (offset < (off_t)file_size) {
            ssize_t sent = sendfile(sockfd, fd, &offset, file_size - offset);
            if (sent <= 0) break;
        }

        auto end = std::chrono::high_resolution_clock::now();
        double ms = std::chrono::duration<double, std::milli>(end - start).count();

        return {"sendfile", (size_t)offset, ms, (offset / 1024.0 / 1024.0) / (ms / 1000.0)};
    }

    static Result benchmark_mmap(int fd, int sockfd, size_t file_size) {
        auto start = std::chrono::high_resolution_clock::now();

        void* mapped = mmap(nullptr, file_size, PROT_READ,
                             MAP_PRIVATE, fd, 0);
        if (mapped == MAP_FAILED) {
            return {"mmap+write", 0, 0, 0};
        }

        send(sockfd, mapped, file_size, MSG_NOSIGNAL);
        munmap(mapped, file_size);

        auto end = std::chrono::high_resolution_clock::now();
        double ms = std::chrono::duration<double, std::milli>(end - start).count();

        return {"mmap+write", file_size, ms, (file_size / 1024.0 / 1024.0) / (ms / 1000.0)};
    }

    static void print_results(const std::vector<Result>& results) {
        std::cout << "========== 零拷贝性能对比 ==========" << std::endl;
        std::cout << "方法\t\t\t数据量(MB)\t耗时(ms)\t吞吐(MB/s)" << std::endl;
        std::cout << std::string(70, '-') << std::endl;

        for (const auto& r : results) {
            std::cout << r.method << "\t\t"
                      << r.bytes / 1024.0 / 1024.0 << "\t\t"
                      << r.time_ms << "\t\t"
                      << r.throughput_mbps << std::endl;
        }
    }
};
```

## 8. 小结

### 核心要点回顾

| 要点 | 说明 |
|------|------|
| **传统拷贝** | 4次拷贝（2CPU+2DMA），4次上下文切换 |
| **sendfile** | 3次拷贝（1CPU+2DMA），2次切换；DMA-SG下零CPU拷贝 |
| **splice** | 零CPU拷贝，通过管道在fd间传递数据指针 |
| **tee** | 在两个管道间复制数据，不消耗源数据 |
| **mmap** | 文件映射到用户空间，避免read系统调用 |
| **共享内存** | 最快的IPC方式，多进程直接访问同一内存 |
| **DMA** | 硬件直接访问内存，CPU不参与数据搬运 |
| **MSG_ZEROCOPY** | Linux 4.14+，用户空间到网卡的零拷贝 |

### 技术选择速查

| 场景 | 推荐技术 | 拷贝次数 |
|------|---------|---------|
| 文件→网络 | sendfile | 0~1 CPU |
| socket→socket | splice | 0 CPU |
| 文件→修改→网络 | mmap+write | 1 CPU |
| 用户缓冲→网络 | MSG_ZEROCOPY | 0 CPU |
| 进程间通信 | mmap共享内存 | 0 CPU |
| 小数据 | 普通read/write | 2 CPU |
