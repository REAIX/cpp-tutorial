# 模板元编程模式

> C++编译期编程核心模式：递归、模式匹配、编译期数据结构与算法

---

> **Template metaprogramming is programming with types instead of values.**
> （模板元编程是用类型而非值来编程。）

> **编译期算法：让类型成为数据，让模板成为函数。**
> （Compile-time algorithms: types as data, templates as functions.）

---

> **🎯 模板元编程模式：编译期的算法与数据结构。**

> 💡 **通俗理解 - 什么是模板元编程模式？**

想象你在玩乐高积木：
- **编译期递归**：一块一块地搭，每一步都基于上一步的结果
- **模式匹配**：根据积木的形状选择不同的搭建方式
- **编译期数据结构**：用类型搭建"类型列表"，像积木列表一样管理
- **编译期算法**：对类型列表做"过滤"、"变换"，像整理积木一样

**模板元编程就是"用类型搭积木"的编程方式！**

```cpp
// 编译期递归：计算阶乘
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};
template<>
struct Factorial<0> {
    static constexpr int value = 1;
};
static_assert(Factorial<5>::value == 120);

// 编译期数据结构：类型列表
template<typename... Ts>
struct TypeList {};

using MyTypes = TypeList<int, double, std::string>;
static_assert(TypeListSize<MyTypes>::value == 3);
```

> 🔬 **抽象理解 - 模板元编程模式**：
> - **编译期递归**：模板实例化自身，通过特化终止递归
> - **模板模式匹配**：通过偏特化和全特化匹配不同的类型模式
> - **Typelist**：编译期类型容器，是模板元编程的基础数据结构
> - **编译期算法**：在Typelist上实现遍历、过滤、变换等操作
> - **编译期字符串**：在编译期处理字符串字面量

## 1. 编译期递归

### 1.1 概念与定义

**编译期递归**：模板实例化自身的机制。通过递归实例化，模板可以在编译期执行循环计算。递归终止通过模板特化实现。

**编译期递归的要素**：
1. 递归模板：调用自身的模板
2. 终止条件：特化版本，停止递归
3. 递归步进：每次递归向终止条件靠近

### 1.2 经典编译期递归

```cpp
// 阶乘：编译期递归的经典例子
template<unsigned int N>
struct Factorial {
    static constexpr unsigned long long value = N * Factorial<N - 1>::value;
};

template<>
struct Factorial<0> {
    static constexpr unsigned long long value = 1;
};

static_assert(Factorial<0>::value == 1);
static_assert(Factorial<5>::value == 120);
static_assert(Factorial<10>::value == 3628800);

// 斐波那契数列
template<unsigned int N>
struct Fibonacci {
    static constexpr unsigned long long value =
        Fibonacci<N - 1>::value + Fibonacci<N - 2>::value;
};

template<>
struct Fibonacci<0> {
    static constexpr unsigned long long value = 0;
};

template<>
struct Fibonacci<1> {
    static constexpr unsigned long long value = 1;
};

static_assert(Fibonacci<10>::value == 55);

// 注意：Fibonacci的模板递归有指数级实例化问题
// 优化：使用线性递归
template<unsigned int N>
struct FibonacciOpt {
private:
    static constexpr unsigned long long fib_impl(unsigned int n,
                                                   unsigned long long a,
                                                   unsigned long long b) {
        return n == 0 ? a : fib_impl(n - 1, b, a + b);
    }
public:
    static constexpr unsigned long long value = fib_impl(N, 0, 1);
};

static_assert(FibonacciOpt<10>::value == 55);
```

### 1.3 编译期递归与可变参数模板

```cpp
// 编译期求和
template<typename... Ts>
struct Sum;

template<>
struct Sum<> {
    static constexpr int value = 0;
};

template<typename T, typename... Rest>
struct Sum<T, Rest...> {
    static constexpr int value = sizeof(T) + Sum<Rest...>::value;
};

static_assert(Sum<int, double, char>::value == sizeof(int) + sizeof(double) + sizeof(char));

// 编译期打印类型列表
template<typename... Ts>
struct PrintTypes;

template<typename First, typename... Rest>
struct PrintTypes<First, Rest...> {
    static void print() {
        std::cout << typeid(First).name();
        if constexpr (sizeof...(Rest) > 0) {
            std::cout << ", ";
            PrintTypes<Rest...>::print();
        } else {
            std::cout << std::endl;
        }
    }
};

// C++17折叠表达式简化递归
template<typename... Ts>
constexpr size_t total_size() {
    return (sizeof(Ts) + ...);  // 折叠表达式
}

static_assert(total_size<int, double, char>() == sizeof(int) + sizeof(double) + sizeof(char));

// 编译期判断是否包含某类型
template<typename T, typename... Ts>
struct Contains : std::bool_constant<(std::is_same_v<T, Ts> || ...)> {};

static_assert(Contains<int, double, int, char>::value);
static_assert(!Contains<float, double, int, char>::value);
```

### 1.4 编译期递归的注意事项

```cpp
// 注意1：递归深度限制
// 编译器通常有模板递归深度限制（如1024）
// 超过限制会导致编译错误

// 注意2：避免重复实例化
// Fibonacci<N>会实例化Fibonacci<N-1>和Fibonacci<N-2>
// 导致指数级实例化数量

// 注意3：使用constexpr函数替代模板递归
// C++14起，constexpr函数可以替代大部分模板递归
constexpr unsigned long long factorial(unsigned int n) {
    unsigned long long result = 1;
    for (unsigned int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

static_assert(factorial(10) == 3628800);
// 比模板递归更简洁，编译更快

// 注意4：编译期递归vs运行时递归
// 编译期递归：结果在编译期计算，零运行时开销
// 运行时递归：在运行时计算，有运行时开销
// 但编译期递归会增加编译时间
```

## 2. 模板模式匹配

### 2.1 概念与定义

**模板模式匹配**：通过模板特化和偏特化，根据类型的"模式"选择不同的实现。类似于函数式编程中的模式匹配，但发生在编译期。

### 2.2 基本模式匹配

```cpp
// 模式1：匹配指针类型
template<typename T>
struct IsPointer : std::false_type {};

template<typename T>
struct IsPointer<T*> : std::true_type {};

static_assert(IsPointer<int>::value == false);
static_assert(IsPointer<int*>::value == true);
static_assert(IsPointer<int**>::value == true);

// 模式2：匹配数组类型
template<typename T>
struct IsArray : std::false_type {};

template<typename T, std::size_t N>
struct IsArray<T[N]> : std::true_type {};

static_assert(IsArray<int>::value == false);
static_assert(IsArray<int[10]>::value == true);

// 模式3：匹配函数类型
template<typename T>
struct IsFunction : std::false_type {};

template<typename R, typename... Args>
struct IsFunction<R(Args...)> : std::true_type {};

template<typename R, typename... Args>
struct IsFunction<R(Args...,...)> : std::true_type {};  // 可变参数函数
```

### 2.3 递归模式匹配

```cpp
// 递归移除所有指针
template<typename T>
struct RemoveAllPointers {
    using type = T;
};

template<typename T>
struct RemoveAllPointers<T*> {
    using type = typename RemoveAllPointers<T>::type;
};

static_assert(std::is_same_v<RemoveAllPointers<int***>::type, int>);

// 递归移除所有const
template<typename T>
struct RemoveAllConst {
    using type = T;
};

template<typename T>
struct RemoveAllConst<const T> {
    using type = typename RemoveAllConst<T>::type;
};

template<typename T>
struct RemoveAllConst<T*> {
    using type = typename RemoveAllConst<T>::type*;
};

// 递归计算维度
template<typename T>
struct Dimension {
    static constexpr int value = 0;
};

template<typename T, std::size_t N>
struct Dimension<T[N]> {
    static constexpr int value = 1 + Dimension<T>::value;
};

static_assert(Dimension<int>::value == 0);
static_assert(Dimension<int[10]>::value == 1);
static_assert(Dimension<int[10][20]>::value == 2);
static_assert(Dimension<int[10][20][30]>::value == 3);
```

### 2.4 复杂模式匹配

```cpp
// 匹配成员函数指针
template<typename T>
struct IsMemberFunctionPointer : std::false_type {};

template<typename R, typename C, typename... Args>
struct IsMemberFunctionPointer<R(C::*)(Args...)> : std::true_type {};

template<typename R, typename C, typename... Args>
struct IsMemberFunctionPointer<R(C::*)(Args...) const> : std::true_type {};

template<typename R, typename C, typename... Args>
struct IsMemberFunctionPointer<R(C::*)(Args...) volatile> : std::true_type {};

template<typename R, typename C, typename... Args>
struct IsMemberFunctionPointer<R(C::*)(Args...) const volatile> : std::true_type {};

// 匹配可调用对象
template<typename T, typename = void>
struct FunctionTraits;

// 匹配普通函数
template<typename R, typename... Args>
struct FunctionTraits<R(Args...)> {
    using return_type = R;
    using args_tuple = std::tuple<Args...>;
    static constexpr std::size_t arity = sizeof...(Args);
};

// 匹配函数指针
template<typename R, typename... Args>
struct FunctionTraits<R(*)(Args...)> : FunctionTraits<R(Args...)> {};

// 匹配成员函数指针
template<typename R, typename C, typename... Args>
struct FunctionTraits<R(C::*)(Args...)> : FunctionTraits<R(Args...)> {
    using class_type = C;
};

// 匹配lambda（通过operator()）
template<typename T>
struct FunctionTraits : FunctionTraits<decltype(&T::operator())> {};
```

## 3. 编译期数据结构Typelist

### 3.1 概念与定义

**Typelist**：编译期类型列表，是模板元编程的核心数据结构。类似于运行期的vector/list，但存储的是类型而非值。Typelist是不可变的，所有操作返回新的Typelist。

### 3.2 Typelist定义

```cpp
// 基本Typelist定义
template<typename... Ts>
struct TypeList {
    static constexpr std::size_t size = sizeof...(Ts);
    static constexpr bool empty = sizeof...(Ts) == 0;
};

// 空列表
using EmptyList = TypeList<>;
static_assert(EmptyList::size == 0);
static_assert(EmptyList::empty == true);

// 非空列表
using IntDoubleChar = TypeList<int, double, char>;
static_assert(IntDoubleChar::size == 3);
static_assert(IntDoubleChar::empty == false);
```

### 3.3 Typelist基本操作

```cpp
// 前端元素
template<typename List>
struct Front;

template<typename Head, typename... Tail>
struct Front<TypeList<Head, Tail...>> {
    using type = Head;
};

template<typename List>
using Front_t = typename Front<List>::type;

static_assert(std::is_same_v<Front_t<TypeList<int, double, char>>, int>);

// 尾部列表
template<typename List>
struct PopFront;

template<typename Head, typename... Tail>
struct PopFront<TypeList<Head, Tail...>> {
    using type = TypeList<Tail...>;
};

template<typename List>
using PopFront_t = typename PopFront<List>::type;

static_assert(std::is_same_v<PopFront_t<TypeList<int, double, char>>,
                              TypeList<double, char>>);

// 前端插入
template<typename T, typename List>
struct PushFront;

template<typename T, typename... Ts>
struct PushFront<T, TypeList<Ts...>> {
    using type = TypeList<T, Ts...>;
};

template<typename T, typename List>
using PushFront_t = typename PushFront<T, List>::type;

static_assert(std::is_same_v<PushFront_t<float, TypeList<int, double>>,
                              TypeList<float, int, double>>);

// 后端插入
template<typename T, typename List>
struct PushBack;

template<typename T, typename... Ts>
struct PushBack<T, TypeList<Ts...>> {
    using type = TypeList<Ts..., T>;
};

template<typename T, typename List>
using PushBack_t = typename PushBack<T, List>::type;

static_assert(std::is_same_v<PushBack_t<float, TypeList<int, double>>,
                              TypeList<int, double, float>>);
```

### 3.4 Typelist高级操作

```cpp
// 按索引访问
template<std::size_t N, typename List>
struct At;

template<std::size_t N, typename Head, typename... Tail>
struct At<N, TypeList<Head, Tail...>> {
    using type = typename At<N - 1, TypeList<Tail...>>::type;
};

template<typename Head, typename... Tail>
struct At<0, TypeList<Head, Tail...>> {
    using type = Head;
};

template<std::size_t N, typename List>
using At_t = typename At<N, List>::type;

static_assert(std::is_same_v<At_t<0, TypeList<int, double, char>>, int>);
static_assert(std::is_same_v<At_t<1, TypeList<int, double, char>>, double>);
static_assert(std::is_same_v<At_t<2, TypeList<int, double, char>>, char>);

// 查找类型索引
template<typename T, typename List>
struct IndexOf;

template<typename T, typename... Tail>
struct IndexOf<T, TypeList<T, Tail...>> {
    static constexpr int value = 0;
};

template<typename T, typename Head, typename... Tail>
struct IndexOf<T, TypeList<Head, Tail...>> {
    static constexpr int value = 1 + IndexOf<T, TypeList<Tail...>>::value;
};

template<typename T>
struct IndexOf<T, TypeList<>> {
    static constexpr int value = -1;  // 未找到
};

static_assert(IndexOf<int, TypeList<int, double, char>>::value == 0);
static_assert(IndexOf<double, TypeList<int, double, char>>::value == 1);
static_assert(IndexOf<float, TypeList<int, double, char>>::value == -1);

// 判断是否包含
template<typename T, typename List>
struct Contains;

template<typename T>
struct Contains<T, TypeList<>> : std::false_type {};

template<typename T, typename... Tail>
struct Contains<T, TypeList<T, Tail...>> : std::true_type {};

template<typename T, typename Head, typename... Tail>
struct Contains<T, TypeList<Head, Tail...>> : Contains<T, TypeList<Tail...>> {};

static_assert(Contains<int, TypeList<int, double, char>>::value);
static_assert(!Contains<float, TypeList<int, double, char>>::value);
```

### 3.5 Typelist拼接

```cpp
// 拼接两个Typelist
template<typename List1, typename List2>
struct Concat;

template<typename... Ts1, typename... Ts2>
struct Concat<TypeList<Ts1...>, TypeList<Ts2...>> {
    using type = TypeList<Ts1..., Ts2...>;
};

template<typename List1, typename List2>
using Concat_t = typename Concat<List1, List2>::type;

static_assert(std::is_same_v<
    Concat_t<TypeList<int, double>, TypeList<char, float>>,
    TypeList<int, double, char, float>
>);

// 反转Typelist
template<typename List>
struct Reverse;

template<>
struct Reverse<TypeList<>> {
    using type = TypeList<>;
};

template<typename Head, typename... Tail>
struct Reverse<TypeList<Head, Tail...>> {
    using type = Concat_t<typename Reverse<TypeList<Tail...>>::type,
                          TypeList<Head>>;
};

template<typename List>
using Reverse_t = typename Reverse<List>::type;

static_assert(std::is_same_v<
    Reverse_t<TypeList<int, double, char>>,
    TypeList<char, double, int>
>);
```

## 4. 编译期算法

### 4.1 遍历算法

```cpp
// 编译期遍历：对每个类型执行操作
template<typename List, template<typename> class Func>
struct ForEach;

template<template<typename> class Func>
struct ForEach<TypeList<>, Func> {
    static void apply() { /* 空列表，什么都不做 */ }
};

template<typename Head, typename... Tail, template<typename> class Func>
struct ForEach<TypeList<Head, Tail...>, Func> {
    static void apply() {
        Func<Head>::apply();                    // 对Head执行操作
        ForEach<TypeList<Tail...>, Func>::apply();  // 递归处理Tail
    }
};

// 使用示例：打印所有类型名称
template<typename T>
struct PrintTypeName {
    static void apply() {
        std::cout << typeid(T).name() << std::endl;
    }
};

// 使用
using MyTypes = TypeList<int, double, std::string>;
// ForEach<MyTypes, PrintTypeName>::apply();

// C++17折叠表达式简化遍历
template<typename... Ts>
void print_all_types(TypeList<Ts...>) {
    (std::cout << ... << typeid(Ts).name()) << std::endl;
}

// 编译期遍历：对每个类型创建实例
template<typename List, template<typename> class Wrapper>
struct WrapEach;

template<typename... Ts, template<typename> class Wrapper>
struct WrapEach<TypeList<Ts...>, Wrapper> {
    using type = TypeList<Wrapper<Ts>...>;
};

template<typename List, template<typename> class Wrapper>
using WrapEach_t = typename WrapEach<List, Wrapper>::type;

// 示例：将所有类型包装为std::optional
using RawTypes = TypeList<int, double, std::string>;
using OptionalTypes = WrapEach_t<RawTypes, std::optional>;
// OptionalTypes = TypeList<std::optional<int>, std::optional<double>, std::optional<std::string>>
```

### 4.2 过滤算法

```cpp
// 编译期过滤：根据条件筛选类型
template<template<typename> class Pred, typename List>
struct Filter;

template<template<typename> class Pred>
struct Filter<Pred, TypeList<>> {
    using type = TypeList<>;
};

template<template<typename> class Pred, typename Head, typename... Tail>
struct Filter<Pred, TypeList<Head, Tail...>> {
private:
    using filtered_tail = typename Filter<Pred, TypeList<Tail...>>::type;
public:
    using type = std::conditional_t<
        Pred<Head>::value,
        PushFront_t<Head, filtered_tail>,
        filtered_tail
    >;
};

template<template<typename> class Pred, typename List>
using Filter_t = typename Filter<Pred, List>::type;

// 使用示例：过滤出整数类型
template<typename T>
using IsIntegral = std::is_integral<T>;

using MixedTypes = TypeList<int, double, char, float, long, std::string>;
using IntTypes = Filter_t<IsIntegral, MixedTypes>;
// IntTypes = TypeList<int, char, long>

// 过滤出指针类型
template<typename T>
using IsPointerPred = std::is_pointer<T>;

using PtrTypes = Filter_t<IsPointerPred, TypeList<int*, double, char*, float>>;
// PtrTypes = TypeList<int*, char*>
```

### 4.3 变换算法

```cpp
// 编译期变换：对每个类型应用类型函数
template<template<typename> class Func, typename List>
struct Transform;

template<template<typename> class Func, typename... Ts>
struct Transform<Func, TypeList<Ts...>> {
    using type = TypeList<typename Func<Ts>::type...>;
};

template<template<typename> class Func, typename List>
using Transform_t = typename Transform<Func, List>::type;

// 使用示例1：添加指针
template<typename T>
struct AddPointer { using type = T*; };

using ValueTypes = TypeList<int, double, char>;
using PtrTypes2 = Transform_t<AddPointer, ValueTypes>;
// PtrTypes2 = TypeList<int*, double*, char*>

// 使用示例2：添加const
template<typename T>
struct AddConst { using type = const T; };

using ConstTypes = Transform_t<AddConst, ValueTypes>;
// ConstTypes = TypeList<const int, const double, const char>

// 使用示例3：移除指针
template<typename T>
using RemovePointerWrap = std::remove_pointer<T>;

using BackToValues = Transform_t<RemovePointerWrap, PtrTypes2>;
// BackToValues = TypeList<int, double, char>

// 编译期累积（类似std::accumulate）
template<template<typename, typename> class BinOp, typename Init, typename List>
struct Accumulate;

template<template<typename, typename> class BinOp, typename Init>
struct Accumulate<BinOp, Init, TypeList<>> {
    using type = Init;
};

template<template<typename, typename> class BinOp,
         typename Init, typename Head, typename... Tail>
struct Accumulate<BinOp, Init, TypeList<Head, Tail...>> {
    using type = typename Accumulate<
        BinOp,
        typename BinOp<Init, Head>::type,
        TypeList<Tail...>
    >::type;
};
```

### 4.4 排序算法

```cpp
// 编译期排序：按类型大小排序
template<typename List>
struct SortBySize;

template<>
struct SortBySize<TypeList<>> {
    using type = TypeList<>;
};

template<typename Head, typename... Tail>
struct SortBySize<TypeList<Head, Tail...>> {
private:
    using sorted_tail = typename SortBySize<TypeList<Tail...>>::type;

    // 插入排序：将Head插入到已排序的列表中
    template<typename T, typename L>
    struct InsertSorted;

    template<typename T>
    struct InsertSorted<T, TypeList<>> {
        using type = TypeList<T>;
    };

    template<typename T, typename H, typename... Ts>
    struct InsertSorted<T, TypeList<H, Ts...>> {
        using type = std::conditional_t<
            (sizeof(T) <= sizeof(H)),
            TypeList<T, H, Ts...>,
            PushFront_t<H, typename InsertSorted<T, TypeList<Ts...>>::type>
        >;
    };
public:
    using type = typename InsertSorted<Head, sorted_tail>::type;
};

template<typename List>
using SortBySize_t = typename SortBySize<List>::type;

// 使用示例
using Unsorted = TypeList<double, char, int, long double>;
using Sorted = SortBySize_t<Unsorted>;
// Sorted = TypeList<char, int, double, long double>（按sizeof从小到大）
```

## 5. 编译期字符串处理

### 5.1 编译期字符串的挑战

```cpp
// C++的模板参数不能直接使用字符串字面量
// template<const char* S>  // 可以，但链接时需要外部符号
// struct Foo {};

// C++20允许类模板使用字符串字面量作为非类型参数
// 但需要满足结构化类型要求
```

```cpp
// 编译期字符串拼接
template<std::size_t N1, std::size_t N2>
consteval auto concat_strings(const char (&s1)[N1], const char (&s2)[N2]) {
    // C++20 constexpr支持动态分配
    char result[N1 + N2 - 1]{};  // -1因为两个字符串各有一个'\0'
    for (std::size_t i = 0; i < N1 - 1; ++i) result[i] = s1[i];
    for (std::size_t i = 0; i < N2 - 1; ++i) result[N1 - 1 + i] = s2[i];
    return result;
}

// 使用ConstString的拼接
template<ConstString S1, ConstString S2>
struct ConcatString {
    static constexpr auto value = [] {
        constexpr auto N1 = S1.size();
        constexpr auto N2 = S2.size();
        char result[N1 + N2 + 1]{};
        for (std::size_t i = 0; i < N1; ++i) result[i] = S1[i];
        for (std::size_t i = 0; i < N2; ++i) result[N1 + i] = S2[i];
        return ConstString<N1 + N2 + 1>(result);
    }();
};

            len += 10;  // 估算每个参数最多10个字符
        } else {
            ++len;
        }
        ++fmt;
    }
    return len;
}
```

### 5.5 编译期字符串解析

```cpp
// 编译期整数解析
consteval int parse_int(const char* s) {
    int result = 0;
    bool negative = false;
    if (*s == '-') { negative = true; ++s; }
    while (*s >= '0' && *s <= '9') {
        result = result * 10 + (*s - '0');
        ++s;
    }
    return negative ? -result : result;
}

static_assert(parse_int("42") == 42);
static_assert(parse_int("-123") == -123);
static_assert(parse_int("0") == 0);

// 编译期十六进制解析
consteval int parse_hex(const char* s) {
    int result = 0;
    while (*s) {
        result *= 16;
        if (*s >= '0' && *s <= '9') result += *s - '0';
        else if (*s >= 'a' && *s <= 'f') result += *s - 'a' + 10;
        else if (*s >= 'A' && *s <= 'F') result += *s - 'A' + 10;
        ++s;
    }
    return result;
}

static_assert(parse_hex("FF") == 255);
static_assert(parse_hex("10") == 16);

// 编译期版本号解析
struct Version {
    int major, minor, patch;
};

consteval Version parse_version(const char* s) {
    Version v{0, 0, 0};
    int* current = &v.major;
    while (*s) {
        if (*s == '.') {
            current = (current == &v.major) ? &v.minor : &v.patch;
        } else if (*s >= '0' && *s <= '9') {
            *current = *current * 10 + (*s - '0');
        }
        ++s;
    }
    return v;
}

constexpr auto ver = parse_version("1.2.3");
static_assert(ver.major == 1);
static_assert(ver.minor == 2);
static_assert(ver.patch == 3);
```

### 5.6 编译期递归的常见陷阱

```cpp
// 陷阱1：递归深度超限
// 编译器对模板递归深度有限制（通常1024层）
// 解决：使用constexpr函数替代模板递归
// 或使用分治法减少递归深度

// 陷阱2：Fibonacci的指数级实例化
// Fibonacci<N>需要实例化Fibonacci<N-1>和Fibonacci<N-2>
// 导致2^N个模板实例化
// 解决：使用线性递归或constexpr函数

// 陷阱3：编译期递归的编译时间
// 深度递归会显著增加编译时间
// 对比：
template<int N>
struct SlowSum {
    static constexpr int value = N + SlowSum<N-1>::value;
};
template<>
struct SlowSum<0> {
    static constexpr int value = 0;
};
// SlowSum<1000>需要1000个模板实例化

// 更快的替代方案：constexpr函数
constexpr int fast_sum(int n) {
    int result = 0;
    for (int i = 0; i <= n; ++i) result += i;
    return result;
}
// fast_sum(1000)只需一次函数调用

// 陷阱4：Typelist操作的编译时间
// 深度嵌套的Typelist操作（如Reverse）会导致O(N^2)的模板实例化
// 解决：使用更高效的实现
template<typename... Ts>
struct TypeList;

// 高效的反转：使用辅助结构累积结果
template<typename Result, typename Remaining>
struct ReverseImpl;

template<typename... Rs>
struct ReverseImpl<TypeList<Rs...>, TypeList<>> {
    using type = TypeList<Rs...>;
};

template<typename... Rs, typename H, typename... Ts>
struct ReverseImpl<TypeList<Rs...>, TypeList<H, Ts...>> {
    using type = typename ReverseImpl<TypeList<H, Rs...>, TypeList<Ts...>>::type;
};

template<typename List>
using FastReverse_t = typename ReverseImpl<TypeList<>, List>::type;

// 这个实现是O(N)的，而非原始Reverse的O(N^2)
```

## 小结

本章介绍了模板元编程的核心模式：

| 模式 | 作用 | 关键技术 |
|------|------|---------|
| 编译期递归 | 编译期循环计算 | 模板递归 + 特化终止 |
| 模板模式匹配 | 根据类型模式选择实现 | 偏特化/全特化 |
| Typelist | 编译期类型容器 | 可变参数模板 |
| 编译期算法 | 类型列表操作 | 递归 + 条件类型 |
| 编译期字符串 | 编译期字符串处理 | consteval + ConstString |

**关键要点**：

1. **编译期递归是模板元编程的基础**：理解递归和终止条件
2. **constexpr函数可以替代大部分模板递归**：更简洁、编译更快
3. **Typelist是编译期数据结构的核心**：掌握其基本操作
4. **编译期算法遵循函数式编程范式**：不可变、递归、高阶函数
5. **编译期字符串处理在C++20后大幅改善**：consteval + 结构化类型
6. **折叠表达式简化了可变参数模板**：C++17后应优先使用

模板元编程模式是构建复杂编译期逻辑的基础，掌握这些模式将使你能够编写更强大的编译期程序。
