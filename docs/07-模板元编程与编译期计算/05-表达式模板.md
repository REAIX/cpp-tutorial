# 表达式模板

> C++高性能计算核心：表达式模板原理与实现

---

> **Expression templates: zero-overhead abstraction for mathematical expressions.**
> （表达式模板：数学表达式的零开销抽象。）

> **将表达式编码到类型中，让编译器帮你消除临时对象。**
> （Encode expressions into types, let the compiler eliminate temporaries for you.）

---

> **🎯 表达式模板：让数学运算像手写循环一样快。**

> 💡 **通俗理解 - 什么是表达式模板？**

想象你在做数学作业：
- **普通方式**：每算一步就写一个中间结果（创建临时对象）
  - `temp1 = a + b; temp2 = temp1 * c; result = temp2 + d;`
- **表达式模板**：把整个公式记下来，最后一步算出结果（惰性求值）
  - `result = (a + b) * c + d;` → 一次遍历，不产生临时对象

**表达式模板就是"先记公式，最后统一计算"的技术！**

```cpp
// 普通向量运算：产生临时对象
Vector a, b, c, d;
Vector result = a + b;      // 临时对象1
Vector temp = result * c;   // 临时对象2
result = temp + d;          // 最终结果

// 表达式模板：无临时对象
Vector a, b, c, d;
Vector result = a + b * c + d;  // 编译期构建表达式树，一次遍历计算
// 等价于：for(i) result[i] = a[i] + b[i]*c[i] + d[i];
```

> 🔬 **抽象理解 - 表达式模板的本质**：
> - **表达式编码**：将运算表达式编码到类型系统中
> - **惰性求值**：不立即计算，等到需要结果时才计算
> - **模板表示表达式树**：用嵌套模板类型表示表达式结构
> - **内联优化**：编译器可以将整个表达式内联为一个循环
> - **消除临时对象**：避免中间结果的内存分配和拷贝

## 1. 表达式模板原理

### 1.1 概念与定义

**表达式模板（Expression Templates）**：一种C++模板编程技术，通过将运算表达式编码到类型系统中，实现惰性求值和消除临时对象。表达式模板广泛用于线性代数库（如Eigen、Blaze）中，使高级抽象的代码性能与手写循环相当。

**表达式模板的核心思想**：
1. 运算符返回的不是结果值，而是表示表达式的模板类型
2. 模板类型嵌套形成表达式树
3. 赋值时遍历表达式树，逐元素计算

### 1.2 问题：临时对象的性能损失

```cpp
#include <vector>
#include <iostream>
#include <chrono>

// 普通向量类：运算产生临时对象
class NaiveVector {
    std::vector<double> data_;
public:
    explicit NaiveVector(std::size_t n) : data_(n) {}
    NaiveVector(std::initializer_list<double> init) : data_(init) {}

    double& operator[](std::size_t i) { return data_[i]; }
    const double& operator[](std::size_t i) const { return data_[i]; }
    std::size_t size() const { return data_.size(); }

    // 运算符返回新向量（临时对象）
    NaiveVector operator+(const NaiveVector& other) const {
        NaiveVector result(size());
        for (std::size_t i = 0; i < size(); ++i) {
            result[i] = data_[i] + other[i];
        }
        return result;  // 临时对象！
    }

    NaiveVector operator*(const NaiveVector& other) const {
        NaiveVector result(size());
        for (std::size_t i = 0; i < size(); ++i) {
            result[i] = data_[i] * other[i];
        }
        return result;  // 临时对象！
    }
};

// 问题：a + b * c + d 会产生2个临时对象
// 1. temp1 = b * c  （一次遍历 + 内存分配）
// 2. temp2 = a + temp1  （一次遍历 + 内存分配）
// 3. result = temp2 + d  （一次遍历 + 内存分配）
// 总共3次遍历 + 2个临时对象

// 理想情况：一次遍历，无临时对象
// for(i) result[i] = a[i] + b[i]*c[i] + d[i];
```

### 1.3 表达式模板的基本思路

```cpp
// 表达式模板的关键：运算符返回"表达式对象"而非"结果对象"

// 表达式对象的类型编码了整个表达式
// a + b * c 的类型可能是：VecAdd<VecRef, VecMul<VecRef, VecRef>>
// 这个类型在编译期完全确定，可以被内联优化

// 表达式模板的工作流程：
// 1. a + b 返回 VecAdd<VecRef, VecRef> 对象（不计算）
// 2. (a + b) * c 返回 VecMul<VecAdd<VecRef, VecRef>, VecRef> 对象（不计算）
// 3. result = (a + b) * c 赋值时才遍历计算

// 类型编码示例
template<typename L, typename R>
struct VecAdd {
    const L& left;
    const R& right;

    double operator[](std::size_t i) const {
        return left[i] + right[i];  // 逐元素计算
    }

    std::size_t size() const { return left.size(); }
};

template<typename L, typename R>
struct VecMul {
    const L& left;
    const R& right;

    double operator[](std::size_t i) const {
        return left[i] * right[i];  // 逐元素计算
    }

    std::size_t size() const { return left.size(); }
};
```

## 2. 惰性求值

### 2.1 概念与定义

**惰性求值（Lazy Evaluation）**：运算不立即执行，而是将运算记录下来，等到真正需要结果时才执行。表达式模板通过返回表达式对象而非结果对象来实现惰性求值。

### 2.2 惰性求值的实现

```cpp
#include <vector>
#include <cstddef>

// 前向声明
template<typename Expr>
class VecExpr;

// 向量表达式基类（CRTP）
template<typename Derived>
class VecExprBase {
public:
    const Derived& derived() const {
        return static_cast<const Derived&>(*this);
    }

    double operator[](std::size_t i) const {
        return derived()[i];
    }

    std::size_t size() const {
        return derived().size();
    }
};

// 具体向量类
class Vec : public VecExprBase<Vec> {
    std::vector<double> data_;
public:
    explicit Vec(std::size_t n = 0) : data_(n) {}
    Vec(std::initializer_list<double> init) : data_(init) {}

    double& operator[](std::size_t i) { return data_[i]; }
    const double& operator[](std::size_t i) const { return data_[i]; }
    std::size_t size() const { return data_.size(); }

    // 赋值运算符：触发求值
    template<typename Expr>
    Vec& operator=(const VecExprBase<Expr>& expr) {
        const Expr& e = expr.derived();
        for (std::size_t i = 0; i < size(); ++i) {
            data_[i] = e[i];  // 逐元素求值
        }
        return *this;
    }
};

// 加法表达式
template<typename L, typename R>
class VecAdd : public VecExprBase<VecAdd<L, R>> {
    const L& left_;
    const R& right_;
public:
    VecAdd(const L& l, const R& r) : left_(l), right_(r) {}

    double operator[](std::size_t i) const {
        return left_[i] + right_[i];
    }

    std::size_t size() const { return left_.size(); }
};

// 乘法表达式
template<typename L, typename R>
class VecMul : public VecExprBase<VecMul<L, R>> {
    const L& left_;
    const R& right_;
public:
    VecMul(const L& l, const R& r) : left_(l), right_(r) {}

    double operator[](std::size_t i) const {
        return left_[i] * right_[i];
    }

    std::size_t size() const { return left_.size(); }
};

// 运算符重载：返回表达式对象
template<typename L, typename R>
VecAdd<L, R> operator+(const VecExprBase<L>& l, const VecExprBase<R>& r) {
    return VecAdd<L, R>(l.derived(), r.derived());
}

template<typename L, typename R>
VecMul<L, R> operator*(const VecExprBase<L>& l, const VecExprBase<R>& r) {
    return VecMul<L, R>(l.derived(), r.derived());
}
```

### 2.3 惰性求值的效果

```cpp
int main() {
    Vec a{1.0, 2.0, 3.0};
    Vec b{4.0, 5.0, 6.0};
    Vec c{7.0, 8.0, 9.0};

    // a + b 返回 VecAdd<Vec, Vec> 对象（不计算）
    auto expr1 = a + b;
    // expr1的类型是 VecAdd<Vec, Vec>

    // (a + b) * c 返回 VecMul<VecAdd<Vec, Vec>, Vec> 对象（不计算）
    auto expr2 = (a + b) * c;
    // expr2的类型是 VecMul<VecAdd<Vec, Vec>, Vec>

    // 赋值时才遍历计算
    Vec result(3);
    result = (a + b) * c;
    // 等价于：for(i) result[i] = (a[i] + b[i]) * c[i];
    // 一次遍历，无临时对象！

    // 验证结果
    // result[0] = (1+4)*7 = 35
    // result[1] = (2+5)*8 = 56
    // result[2] = (3+6)*9 = 81
    return 0;
}
```

## 3. 避免临时对象

### 3.1 临时对象的问题

```cpp
// 临时对象的问题：
// 1. 内存分配开销：每次运算都分配新内存
// 2. 数据遍历开销：每次运算都遍历一次数据
// 3. 缓存不友好：临时对象可能不在缓存中

// 示例：大型向量运算
// a + b * c + d
// 普通方式：
//   temp1 = b * c     → 分配N个double + 遍历N个元素
//   temp2 = a + temp1 → 分配N个double + 遍历N个元素
//   result = temp2 + d → 分配N个double + 遍历N个元素
//   总计：3次内存分配 + 3次遍历

// 表达式模板方式：
//   result = a + b * c + d
//   → 0次内存分配 + 1次遍历
//   for(i) result[i] = a[i] + b[i]*c[i] + d[i]
```

### 3.2 表达式模板的内存优势

```cpp
#include <iostream>
#include <chrono>

// 性能对比
void benchmark() {
    const std::size_t N = 1000000;
    const int ITERATIONS = 100;

    // 普通向量
    {
        NaiveVector a(N, 1.0), b(N, 2.0), c(N, 3.0), d(N, 4.0);
        NaiveVector result(N);

        auto start = std::chrono::high_resolution_clock::now();
        for (int i = 0; i < ITERATIONS; ++i) {
            result = a + b * c + d;  // 3次遍历 + 2个临时对象
        }
        auto end = std::chrono::high_resolution_clock::now();
        std::cout << "普通向量: "
                  << std::chrono::duration<double>(end - start).count()
                  << "秒" << std::endl;
    }

    // 表达式模板向量
    {
        Vec a(N, 1.0), b(N, 2.0), c(N, 3.0), d(N, 4.0);
        Vec result(N);

        auto start = std::chrono::high_resolution_clock::now();
        for (int i = 0; i < ITERATIONS; ++i) {
            result = a + b * c + d;  // 1次遍历 + 0个临时对象
        }
        auto end = std::chrono::high_resolution_clock::now();
        std::cout << "表达式模板: "
                  << std::chrono::duration<double>(end - start).count()
                  << "秒" << std::endl;
    }
}
```

## 4. 数学表达式模板实现

### 4.1 完整的向量表达式模板

```cpp
#include <vector>
#include <cstddef>
#include <cmath>
#include <iostream>

// 表达式基类
template<typename Derived>
class ExprBase {
public:
    const Derived& derived() const {
        return static_cast<const Derived&>(*this);
    }
};

// 向量类
class Vec : public ExprBase<Vec> {
    std::vector<double> data_;
public:
    explicit Vec(std::size_t n = 0, double val = 0.0) : data_(n, val) {}
    Vec(std::initializer_list<double> init) : data_(init) {}

    double& operator[](std::size_t i) { return data_[i]; }
    const double& operator[](std::size_t i) const { return data_[i]; }
    std::size_t size() const { return data_.size(); }

    // 从表达式赋值
    template<typename Expr>
    Vec& operator=(const ExprBase<Expr>& expr) {
        const Expr& e = expr.derived();
        data_.resize(e.size());
        for (std::size_t i = 0; i < size(); ++i) {
            data_[i] = e[i];
        }
        return *this;
    }

    // 复合赋值运算符
    template<typename Expr>
    Vec& operator+=(const ExprBase<Expr>& expr) {
        const Expr& e = expr.derived();
        for (std::size_t i = 0; i < size(); ++i) {
            data_[i] += e[i];
        }
        return *this;
    }

    template<typename Expr>
    Vec& operator-=(const ExprBase<Expr>& expr) {
        const Expr& e = expr.derived();
        for (std::size_t i = 0; i < size(); ++i) {
            data_[i] -= e[i];
        }
        return *this;
    }
};

// 二元运算表达式
template<typename Op, typename L, typename R>
class BinaryExpr : public ExprBase<BinaryExpr<Op, L, R>> {
    const L& left_;
    const R& right_;
public:
    BinaryExpr(const L& l, const R& r) : left_(l), right_(r) {}

    double operator[](std::size_t i) const {
        return Op::apply(left_[i], right_[i]);
    }

    std::size_t size() const { return left_.size(); }
};

// 运算符仿函数
struct AddOp {
    static double apply(double a, double b) { return a + b; }
};

struct SubOp {
    static double apply(double a, double b) { return a - b; }
};

struct MulOp {
    static double apply(double a, double b) { return a * b; }
};

struct DivOp {
    static double apply(double a, double b) { return a / b; }
};

// 运算符重载
template<typename L, typename R>
BinaryExpr<AddOp, L, R> operator+(const ExprBase<L>& l, const ExprBase<R>& r) {
    return BinaryExpr<AddOp, L, R>(l.derived(), r.derived());
}

template<typename L, typename R>
BinaryExpr<SubOp, L, R> operator-(const ExprBase<L>& l, const ExprBase<R>& r) {
    return BinaryExpr<SubOp, L, R>(l.derived(), r.derived());
}

template<typename L, typename R>
BinaryExpr<MulOp, L, R> operator*(const ExprBase<L>& l, const ExprBase<R>& r) {
    return BinaryExpr<MulOp, L, R>(l.derived(), r.derived());
}

template<typename L, typename R>
BinaryExpr<DivOp, L, R> operator/(const ExprBase<L>& l, const ExprBase<R>& r) {
    return BinaryExpr<DivOp, L, R>(l.derived(), r.derived());
}
```

```cpp
// 标量表达式
class ScalarExpr : public ExprBase<ScalarExpr> {
    double value_;
public:
    explicit ScalarExpr(double v) : value_(v) {}
    double operator[](std::size_t) const { return value_; }
    // 标量没有size()，需要特殊处理
};

// 标量-向量二元运算
template<typename Op, typename VecType>
class ScalarVecExpr : public ExprBase<ScalarVecExpr<Op, VecType>> {
    double scalar_;
    const VecType& vec_;
    bool scalar_on_left_;
public:
    ScalarVecExpr(double s, const VecType& v, bool left)
        : scalar_(s), vec_(v), scalar_on_left_(left) {}

    double operator[](std::size_t i) const {
        if (scalar_on_left_) {
            return Op::apply(scalar_, vec_[i]);
        } else {
            return Op::apply(vec_[i], scalar_);
        }
    }

    std::size_t size() const { return vec_.size(); }
};

// 标量 * 向量
```

### 4.4 归约运算

```cpp
// 归约运算：将向量归约为标量
template<typename T>
double sum(const ExprBase<T>& expr) {
    const T& e = expr.derived();
    double result = 0.0;
    for (std::size_t i = 0; i < e.size(); ++i) {
        result += e[i];
    }
    return result;
}

template<typename T>
double dot(const ExprBase<T>& a, const ExprBase<T>& b) {
    return sum(a.derived() * b.derived());
}

template<typename T>
double norm(const ExprBase<T>& expr) {
    return std::sqrt(dot(expr, expr));
}

template<typename T>
double max_val(const ExprBase<T>& expr) {
    const T& e = expr.derived();
    double result = e[0];
    for (std::size_t i = 1; i < e.size(); ++i) {
        if (e[i] > result) result = e[i];
    }
    return result;
}

template<typename T>
double min_val(const ExprBase<T>& expr) {
    const T& e = expr.derived();
    double result = e[0];
    for (std::size_t i = 1; i < e.size(); ++i) {
        if (e[i] < result) result = e[i];
    }
    return result;
}

// 使用
int main() {
    Vec a{1.0, 2.0, 3.0};
    Vec b{4.0, 5.0, 6.0};

    double s = sum(a + b);        // 1+4 + 2+5 + 3+6 = 21
    double d = dot(a, b);         // 1*4 + 2*5 + 3*6 = 32
    double n = norm(a);           // sqrt(1+4+9) = sqrt(14)
    return 0;
}
```

## 5. Eigen库的表达式模板设计

### 5.1 Eigen简介

**Eigen**：C++最流行的线性代数库，广泛使用表达式模板技术。Eigen的表达式模板设计是学习该技术的最佳参考。

### 5.2 Eigen的表达式模板架构

```cpp
// Eigen的表达式模板架构（简化版）

// 1. 表达式基类
template<typename Derived>
class MatrixBase {
public:
    const Derived& derived() const {
        return static_cast<const Derived&>(*this);
    }

    // 通用接口
    std::size_t rows() const { return derived().rows(); }
    std::size_t cols() const { return derived().cols(); }
    double operator()(std::size_t i, std::size_t j) const {
        return derived()(i, j);
    }

    // 运算符
    template<typename Other>
    auto operator+(const MatrixBase<Other>& other) const {
        return CwiseBinaryOp<scalar_sum_op,
                             Derived,
                             typename Other::Derived>(
            derived(), other.derived());
    }

    template<typename Other>
    auto operator*(const MatrixBase<Other>& other) const {
        // 矩阵乘法（非逐元素）
        return Product<Derived, typename Other::Derived>(
            derived(), other.derived());
    }
};

// 2. 具体矩阵类
template<typename Scalar, int Rows, int Cols>
class Matrix : public MatrixBase<Matrix<Scalar, Rows, Cols>> {
    // 数据存储
    Scalar data_[Rows * Cols];
public:
    Scalar& operator()(std::size_t i, std::size_t j) {
        return data_[i * Cols + j];
    }
    Scalar operator()(std::size_t i, std::size_t j) const {
        return data_[i * Cols + j];
    }

    std::size_t rows() const { return Rows; }
    std::size_t cols() const { return Cols; }

    // 从表达式赋值
    template<typename Expr>
    Matrix& operator=(const MatrixBase<Expr>& expr) {
        for (std::size_t i = 0; i < Rows; ++i) {
            for (std::size_t j = 0; j < Cols; ++j) {
                data_[i * Cols + j] = expr(i, j);
            }
        }
        return *this;
    }
};
```

### 5.3 Eigen的关键设计决策

```cpp
// Eigen的设计决策：

// 1. 区分逐元素运算和矩阵运算
// 逐元素加法：a + b → CwiseBinaryOp
// 矩阵乘法：a * b → Product（不同的表达式类型）

// 2. 编译期大小信息
// 固定大小：Matrix<double, 3, 3> → 编译期已知大小，可优化
// 动态大小：Matrix<double, Dynamic, Dynamic> → 运行期确定大小

// 3. 惰性求值的边界
// 逐元素运算：惰性求值（表达式模板）
// 矩阵乘法：立即求值（因为需要临时存储中间结果）

// 4. 别名问题
// mat = mat * mat;  // 危险！结果可能覆盖输入
// Eigen通过eval()和noalias()控制求值时机

// 5. SIMD优化
// Eigen在表达式模板层面集成SIMD指令
// 在赋值时对表达式进行向量化求值
```

### 5.4 Eigen表达式模板的实际使用

```cpp
#include <Eigen/Dense>
#include <iostream>

void eigen_examples() {
    // 基本运算
    Eigen::VectorXd a(3), b(3), c(3), result(3);
    a << 1, 2, 3;
    b << 4, 5, 6;
    c << 7, 8, 9;

    // 表达式模板：一次遍历，无临时对象
    result = a + 2.0 * b + c;
    // 编译器生成等价于：
    // for(i) result[i] = a[i] + 2.0*b[i] + c[i]

    // 矩阵运算
    Eigen::Matrix2d A, B;
    A << 1, 2, 3, 4;
    B << 5, 6, 7, 8;

    // 矩阵乘法（立即求值，非惰性）
    Eigen::Matrix2d C = A * B;

    // 逐元素运算（惰性求值）
    Eigen::Matrix2d D = A.cwiseProduct(B);  // 逐元素乘法
    Eigen::Matrix2d E = (A + B).cwiseSqrt();  // 逐元素开方

    // 归约运算
    double s = a.sum();       // 求和
    double m = a.mean();      // 平均值
    double n = a.norm();      // 范数
    double d = a.dot(b);      // 点积

    // 别名问题
    Eigen::Matrix2d X;
    X << 1, 2, 3, 4;
    // X = X * X;  // 危险！Eigen会检测并创建临时对象
    X.noalias() = X * X;  // 告诉Eigen不需要临时对象（用户保证安全）
}
```

### 5.6 表达式模板常见陷阱

```cpp
// 陷阱1：悬垂引用——表达式对象引用已销毁的临时对象
template<typename L, typename R>
class VecAdd {
    const L& left_;   // 引用！
    const R& right_;  // 引用！
public:
    VecAdd(const L& l, const R& r) : left_(l), right_(r) {}
    // ...
};

// 危险场景1：存储表达式对象
auto expr = a + b;  // expr引用a和b
// 如果a或b在此之后被修改或销毁，expr变成悬垂引用
Vec result(3);
result = expr;  // 可能访问已销毁的a或b

// 危险场景2：函数返回表达式对象
auto make_expr() {
    Vec a{1, 2, 3};
    Vec b{4, 5, 6};
    return a + b;  // 返回引用a和b的表达式对象
    // a和b在函数返回后销毁！
}
// auto expr = make_expr();  // 悬垂引用！

// 解决方案1：立即求值，不存储表达式
Vec result = a + b * c;  // OK：赋值触发立即求值

// 解决方案2：使用值捕获而非引用
template<typename L, typename R>
class SafeVecAdd {
    L left_;   // 值拷贝！
    R right_;  // 值拷贝！
public:
    SafeVecAdd(const L& l, const R& r) : left_(l), right_(r) {}
    // ...
};
// 代价：额外的拷贝开销

// 解决方案3：仅对Vec类型使用引用，对中间表达式使用值
template<typename L, typename R>
class SmartVecAdd {
    L left_;   // 如果L是Vec，则为引用；如果是表达式，则为值
    R right_;
    // 需要更复杂的类型计算...
};

// 陷阱2：别名问题
// a = a + b 可能不安全（如果a同时是输入和输出）
Vec a{1, 2, 3}, b{4, 5, 6};
a = a + b;  // 可能安全（因为惰性求值逐元素计算）
// 但 a = a * a 可能不安全（如果乘法依赖a的当前值）

// Eigen的解决方案：
// mat = mat * mat;  // Eigen检测到别名，自动创建临时对象
// mat.noalias() = mat * mat;  // 告诉Eigen不需要临时对象

// 陷阱3：表达式模板与auto的交互
auto expr = a + b;  // expr是VecAdd<Vec, Vec>，不是Vec！
// expr的类型不是Vec，而是表达式类型
// 如果后续修改a或b，expr的结果会改变

// 陷阱4：表达式模板与std::vector的兼容性
// 表达式模板通常需要自定义向量类
// 不能直接用于std::vector
// std::vector<double> a, b;
// auto result = a + b;  // 错误！std::vector没有重载+

// 陷阱5：调试困难
// 表达式模板的错误信息可能非常冗长
// VecAdd<VecMul<Vec, Vec>, VecAdd<Vec, Vec>>
```

```cpp
class NaiveVector {
    std::vector<double> data_;
public:
    explicit NaiveVector(std::size_t n, double val = 0.0) : data_(n, val) {}
    NaiveVector(std::initializer_list<double> init) : data_(init) {}

        for (std::size_t i = 0; i < size(); ++i)
            result[i] = data_[i] + other[i];
        return result;
    }

        return result;
```

### 5.9 表达式模板最佳实践

```cpp
// 实践1：表达式对象应立即求值，不要存储
// 正确用法
Vec result = a + b * c + d;  // 立即求值

// 危险用法
auto expr = a + b * c;  // 存储表达式对象

// 实践2：为表达式模板提供值类型而非引用
// 当表达式可能跨语句使用时，使用值类型
template<typename L, typename R>
class SafeExpr {
    L left_;   // 值类型
    R right_;  // 值类型
public:
    SafeExpr(L l, R r) : left_(std::move(l)), right_(std::move(r)) {}

// 实践3：处理别名问题
template<typename Expr>
Vec& Vec::operator=(const ExprBase<Expr>& expr) {
    // 检测别名：如果this出现在expr中，需要临时对象
    const Expr& e = expr.derived();
    // 简单方案：总是先计算到临时对象
    auto temp = eval(e);  // 完全求值
    for (std::size_t i = 0; i < size(); ++i) {
        data_[i] = temp[i];
    }
    return *this;
}

// 实践4：提供noalias()方法
template<typename Expr>
Vec& Vec::noalias_assign(const ExprBase<Expr>& expr) {
    // 用户保证没有别名，直接赋值
    const Expr& e = expr.derived();
    for (std::size_t i = 0; i < size(); ++i) {
        data_[i] = e[i];
    }
    return *this;
}

// 实践5：使用C++20 Concepts约束表达式类型
template<typename T>
concept VectorExpression = requires(const T& t, std::size_t i) {

};

template<VectorExpression L, VectorExpression R>
VecAdd<L, R> operator+(const L& l, const R& r) {
    return VecAdd<L, R>(l, r);
```

## 小结

本章介绍了表达式模板的核心原理和实现：

| 技术要点 | 作用 | 实现方式 |
|---------|------|---------|
| 表达式编码 | 将运算编码到类型 | 嵌套模板类型 |
| 惰性求值 | 延迟计算 | 返回表达式对象 |
| 消除临时对象 | 避免内存分配 | 赋值时一次遍历 |
| 标量运算 | 支持标量-向量运算 | ScalarVecExpr |
| 数学函数 | 支持逐元素函数 | UnaryExpr |
| 归约运算 | 向量归约为标量 | sum/dot/norm |

**关键要点**：

1. **表达式模板通过类型编码实现零开销抽象**：编译器将表达式内联为一个循环
2. **惰性求值是核心**：运算符返回表达式对象而非结果
3. **赋值触发求值**：在operator=中遍历表达式树
4. **Eigen是最佳实践参考**：学习其架构设计
5. **注意别名问题**：`a = a * a`可能不安全
6. **表达式模板不仅限于数学运算**：也可用于字符串拼接等场景

表达式模板是C++零开销抽象的典范，它使得高级抽象的代码性能与手写底层代码相当，是C++在高性能计算领域保持竞争力的关键技术。
