# 编译期反射与代码生成

> C++元编程前沿：编译期反射原理、实现与未来

---

> **Reflection is the holy grail of C++ metaprogramming.**
> （反射是C++元编程的圣杯。）

> **让程序在编译期"认识自己"，自动生成代码。**
> （Let the program "know itself" at compile time, auto-generate code.）

---

> **🎯 编译期反射：让类型自己描述自己。**

> 💡 **通俗理解 - 什么是编译期反射？**

想象你在照镜子：
- **运行时反射**：你照镜子，看到自己的样子，可以描述自己（Java/C#的反射）
- **编译期反射**：你的"照片"在编译时就已经拍好了，编译器直接看照片（C++的反射方向）

**编译期反射就是让类型在编译时"自我描述"，自动生成处理代码！**

```cpp
// 没有反射：手动为每个字段写序列化代码
struct Person {
    std::string name;
    int age;
};

std::string serialize(const Person& p) {
    return "{\"name\":\"" + p.name + "\",\"age\":" + std::to_string(p.age) + "}";
}

// 有反射：自动遍历所有字段，自动生成序列化代码
std::string auto_serialize(const auto& obj) {
    // 编译期遍历obj的所有字段，自动生成序列化代码
    // 不需要手动为每个字段写代码！
}
```

> 🔬 **抽象理解 - 编译期反射的本质**：
> - **反射（Reflection）**：程序在运行时或编译期获取类型信息的能力
> - **编译期反射**：在编译期获取类型的成员列表、成员名称、成员类型等信息
> - **手动反射**：通过宏和模板手动注册类型信息
> - **自动反射**：编译器自动提取类型信息（C++26提案）
> - **代码生成**：基于反射信息自动生成序列化、比较、哈希等代码

## 1. 编译期反射的需求

### 1.1 概念与定义

**编译期反射**：在编译期获取类型的结构信息（成员列表、成员名称、成员类型、基类列表等），并基于这些信息自动生成代码。C++目前没有语言级别的编译期反射，但有多种手动实现方式。

### 1.2 为什么需要反射

```cpp
// 需求1：序列化/反序列化
// 没有反射：为每个类型手写序列化代码
struct User {
    std::string name;
    int age;
    std::string email;
};

std::string serialize(const User& u) {
    return "{name:" + u.name + ",age:" + std::to_string(u.age) + ",email:" + u.email + "}";
}

User deserialize(const std::string& json) {
    // 手动解析每个字段...
}

// 有反射：一个函数处理所有类型
template<typename T>
std::string auto_serialize(const T& obj);

// 需求2：对象比较
// 没有反射：手写operator==
bool operator==(const User& a, const User& b) {
    return a.name == b.name && a.age == b.age && a.email == b.email;
}

// 有反射：自动比较所有字段
template<typename T>
bool auto_equal(const T& a, const T& b);

// 需求3：ORM映射
// 没有反射：手动写SQL映射
std::string to_sql(const User& u) {
    return "INSERT INTO users(name, age, email) VALUES('" +
           u.name + "'," + std::to_string(u.age) + ",'" + u.email + "')";
}

// 有反射：自动生成SQL
template<typename T>
std::string auto_to_sql(const T& obj);
```

### 1.3 C++反射的现状

```cpp
// C++反射的现状：
// 1. 没有语言级别的静态反射（C++26提案中）
// 2. 有运行时RTTI（dynamic_cast, typeid），但功能有限
// 3. 手动反射：宏 + 模板

// | C#      | 运行时+编译时 | 完整支持 |
```

## 2. 手动反射实现

### 2.1 宏注册方式

```cpp
#include <string>
#include <tuple>
#include <iostream>

// 反射宏：注册结构体的字段
#define REFLECT_FIELDS(...) \
    auto fields() { return std::make_tuple(__VA_ARGS__); } \
    auto fields() const { return std::make_tuple(__VA_ARGS__); }

#define FIELD(name) name

// 使用宏注册字段
struct Person {
    std::string name;
    int age;
    double height;

    REFLECT_FIELDS(name, age, height)
};

// 基于反射的通用操作
template<typename T>
void print_fields(const T& obj) {
    auto fields = obj.fields();
    std::apply([](const auto&... args) {
        ((std::cout << args << " "), ...);
    }, fields);
    std::cout << std::endl;
}

int main() {
    Person p{"Alice", 30, 1.68};
    print_fields(p);  // 输出：Alice 30 1.68
    return 0;
}
```

### 2.2 带名称的反射宏

```cpp
#include <string>
#include <tuple>
#include <iostream>
#include <sstream>

// 字段描述
template<typename T>
struct Field {
    const char* name;
    T T::*pointer;  // 成员指针
};

// 反射宏：带名称注册
#define REFLECT(Type, ...) \
    static constexpr auto get_fields() { \
        return std::make_tuple(__VA_ARGS__); \
    }

#define FIELD(Type, name) Field<Type>{#name, &Type::name}

// 使用
struct Student {
    std::string name;
    int id;
    double score;

    REFLECT(Student,
        FIELD(Student, name),
        FIELD(Student, id),
        FIELD(Student, score)
    )
};

// 基于反射的序列化
template<typename T>
std::string to_json(const T& obj) {
    std::ostringstream oss;
    oss << "{";
    bool first = true;
    auto fields = T::get_fields();
    std::apply([&](const auto&... fs) {
        ((oss << (first ? "" : ",") << "\"" << fs.name << "\":"
              << "\"" << obj.*(fs.pointer) << "\"",
          first = false), ...);
    }, fields);
    oss << "}";
    return oss.str();
}

int main() {
    Student s{"Bob", 1001, 95.5};
    std::cout << to_json(s) << std::endl;
    // 输出：{"name":"Bob","id":"1001","score":"95.5"}
    return 0;
}
```

### 2.3 更完善的反射系统

```cpp
#include <string>
#include <tuple>
#include <type_traits>
#include <iostream>

// 字段元信息
template<typename Class, typename T>
struct FieldInfo {
    const char* name;
    T Class::*pointer;

    // 获取字段值
    const T& get(const Class& obj) const {
        return obj.*pointer;
    }

    // 设置字段值
    void set(Class& obj, const T& value) const {
        obj.*pointer = value;
    }
};

// 类型列表
template<typename... Fields>
struct Schema {
    std::tuple<Fields...> fields;

    constexpr Schema(Fields... fs) : fields(fs...) {}

    static constexpr std::size_t field_count = sizeof...(Fields);

    // 遍历所有字段
    template<typename Func>
    void for_each(Func&& func) const {
        std::apply([&](const auto&... fs) {
            (func(fs), ...);
        }, fields);
    }
};

// 反射宏
#define BEGIN_CLASS(ClassName) \
    using Self = ClassName; \
    static constexpr auto schema() {

#define FIELD_DEF(name, type) \
    FieldInfo<Self, type>{#name, &Self::name}

#define END_CLASS() \
    }

// 使用
struct Product {
    std::string name;
    double price;
    int stock;

    BEGIN_CLASS(Product)
        return Schema(
            FIELD_DEF(name, std::string),
            FIELD_DEF(price, double),
            FIELD_DEF(stock, int)
        );
    END_CLASS()
};

// 通用序列化
template<typename T>
std::string serialize_to_json(const T& obj) {
    std::ostringstream oss;
    oss << "{";
    bool first = true;
    T::schema().for_each([&](const auto& field) {
        oss << (first ? "" : ",");
        oss << "\"" << field.name << "\":";
        oss << "\"" << field.get(obj) << "\"";
        first = false;
    });
    oss << "}";
    return oss.str();
}

// 通用打印
template<typename T>
void print_object(const T& obj) {
    std::cout << typeid(T).name() << " {" << std::endl;
    T::schema().for_each([&](const auto& field) {
        std::cout << "  " << field.name << " = " << field.get(obj) << std::endl;
    });
    std::cout << "}" << std::endl;
}
```

## 3. magic_get/pfr库原理

### 3.1 概念与定义

**magic_get / Boost.PFR**：一个不需要任何宏或注册就能访问聚合类型字段的库。它利用C++17的结构化绑定和聚合初始化来"自动"获取字段信息。

### 3.2 PFR的核心原理

```cpp
// PFR的核心原理：
// 1. 利用聚合初始化检测字段数量
// 2. 利用结构化绑定访问字段
// 3. 为不同字段数量生成特化代码

// 简化版PFR实现

// 步骤1：计算字段数量
template<std::size_t N>
struct any_type {
    // 可以隐式转换为任意类型
    template<typename T>
    constexpr operator T() const noexcept;
};

template<typename T, typename = void, typename... Args>
struct is_braces_constructible : std::false_type {};

template<typename T, typename... Args>
struct is_braces_constructible<T,
    std::void_t<decltype(T{std::declval<Args>()...})>,
    Args...> : std::true_type {};

// 步骤2：使用二分搜索找到字段数量
template<typename T, std::size_t N>
constexpr bool has_at_least_n_fields() {
    // 尝试用N个any_type参数初始化T
    // 如果成功，T至少有N个字段
    return is_braces_constructible<T, void,
        any_type<0>, any_type<1>, /* ... */, any_type<N-1>>::value;
}

// 步骤3：使用结构化绑定访问字段
template<typename T>
auto tie_fields(T& obj) {
    // 根据字段数量选择不同的结构化绑定
    // 需要为每个可能的字段数量生成代码
    if constexpr (field_count<T>() == 1) {
        auto& [f1] = obj;
        return std::tie(f1);
    } else if constexpr (field_count<T>() == 2) {
        auto& [f1, f2] = obj;
        return std::tie(f1, f2);
    } else if constexpr (field_count<T>() == 3) {
        auto& [f1, f2, f3] = obj;
        return std::tie(f1, f2, f3);
    }
    // ... 继续到某个上限
}
```

### 3.3 PFR的实际使用

```cpp
#include <boost/pfr.hpp>
#include <string>
#include <iostream>

struct Person {
    std::string name;
    int age;
    double height;
};

int main() {
    Person p{"Alice", 30, 1.68};

    // 访问字段数量
    constexpr std::size_t n = boost::pfr::tuple_size_v<Person>;
    std::cout << "字段数量: " << n << std::endl;  // 3

    // 遍历所有字段
    boost::pfr::for_each_field(p, [](const auto& field) {
        std::cout << field << " ";
    });
    std::cout << std::endl;  // Alice 30 1.68

    // 按索引访问
    std::cout << boost::pfr::get<0>(p) << std::endl;  // Alice
    std::cout << boost::pfr::get<1>(p) << std::endl;  // 30

    // 比较两个对象
    Person p2{"Alice", 30, 1.68};
    std::cout << (boost::pfr::eq(p, p2) ? "相等" : "不等") << std::endl;

    // 获取字段名称（C++20，需要定义BOOST_PFR_ENABLE_GET_NAME）
    // boost::pfr::names_as_array<Person>() → {"name", "age", "height"}

    return 0;
}
```

### 3.4 PFR的局限性

```cpp
// PFR的局限性：

// 1. 只支持聚合类型（无自定义构造函数、无私有/保护成员、无虚函数等）
struct NotAggregate {
    NotAggregate(int x) : value(x) {}  // 自定义构造函数 → 不是聚合类型
    int value;
};
// boost::pfr::for_each_field(NotAggregate{42});  // 可能编译错误

// 2. 字段数量有上限
// PFR通过为每个字段数量生成特化代码实现
// 通常支持最多100个字段

// 3. 引用字段和位域不支持
struct BitFields {
    unsigned int a : 3;
    unsigned int b : 5;
};
// PFR无法处理位域

// 4. 继承的聚合类型
struct Base { int x; };
struct Derived : Base { int y; };
// C++17中Derived不是聚合类型
// C++20中Derived是聚合类型，但PFR可能不支持

// 5. 字段名称需要额外支持
// 字段名称不是C++类型系统的一部分
// PFR通过编译器扩展获取字段名称
```

## 5. 编译期序列化与反序列化

### 5.1 基于宏的序列化

```cpp
#include <string>
#include <sstream>
#include <tuple>

// 序列化框架
template<typename T>
struct Serializer;

// 基本类型序列化
template<>
struct Serializer<int> {
    static std::string serialize(int val) { return std::to_string(val); }
    static int deserialize(const std::string& s) { return std::stoi(s); }
};

template<>
struct Serializer<double> {
    static std::string serialize(double val) { return std::to_string(val); }
    static double deserialize(const std::string& s) { return std::stod(s); }
};

template<>
struct Serializer<std::string> {
    static std::string serialize(const std::string& val) {
        return "\"" + val + "\"";
    }
    static std::string deserialize(const std::string& s) {
        return s.substr(1, s.size() - 2);  // 去掉引号
    }
};

// 通用结构体序列化
#define DEFINE_SERIALIZER(Type, ...) \
    template<> \
    struct Serializer<Type> { \
        static std::string serialize(const Type& obj) { \
            std::ostringstream oss; \
            oss << "{"; \
            bool first = true; \
            __VA_ARGS__ \
            oss << "}"; \
            return oss.str(); \
        } \
    };

#define SERIALIZE_FIELD(name) \
    oss << (first ? "" : ",") << "\"" #name "\":" << Serializer<decltype(obj.name)>::serialize(obj.name); \
    first = false;

// 使用
struct Book {
    std::string title;
    std::string author;
    double price;
};

DEFINE_SERIALIZER(Book,
    SERIALIZE_FIELD(title)
    SERIALIZE_FIELD(author)
    SERIALIZE_FIELD(price)
)

int main() {
    Book b{"C++ Primer", "Lippman", 59.99};
    std::cout << Serializer<Book>::serialize(b) << std::endl;
    // 输出：{"title":"C++ Primer","author":"Lippman","price":59.99}
    return 0;
}
```

### 5.2 基于PFR的序列化

```cpp
#include <boost/pfr.hpp>
#include <string>
#include <sstream>

// 基于PFR的通用JSON序列化
template<typename T>
std::string pfr_to_json(const T& obj) {
    std::ostringstream oss;
    oss << "{";
    std::size_t index = 0;
    boost::pfr::for_each_field(obj, [&](const auto& field) {
        if (index > 0) oss << ",";
        oss << "\"" << "field" << index << "\":";

        using FieldType = std::decay_t<decltype(field)>;
        if constexpr (std::is_same_v<FieldType, std::string>) {
            oss << "\"" << field << "\"";
        } else if constexpr (std::is_arithmetic_v<FieldType>) {
            oss << field;
        } else {
            oss << pfr_to_json(field);  // 递归处理嵌套结构
        }
        ++index;
    });
    oss << "}";
    return oss.str();
}

// 使用
struct Address {
    std::string city;
    std::string street;
};

struct Employee {
    std::string name;
    int id;
    Address address;
};

int main() {
    Employee e{"Alice", 1001, {"Beijing", "Chaoyang Road"}};
    std::cout << pfr_to_json(e) << std::endl;
    return 0;
```

```cpp
#include <cstdint>
#include <cstring>
#include <vector>
#include <string>

// 编译期二进制序列化框架
class BinaryWriter {
    std::vector<uint8_t> buffer_;
public:
    void write_bytes(const void* data, std::size_t size) {
        const auto* ptr = static_cast<const uint8_t*>(data);
        buffer_.insert(buffer_.end(), ptr, ptr + size);
    }

    template<typename T>
    void write(const T& value) {
        if constexpr (std::is_trivially_copyable_v<T>) {
            write_bytes(&value, sizeof(T));
        } else if constexpr (std::is_same_v<T, std::string>) {
            uint32_t len = static_cast<uint32_t>(value.size());
            write(len);
            write_bytes(value.data(), len);
        } else {
            // 使用反射遍历字段
            value.serialize(*this);
        }
    }

    const std::vector<uint8_t>& data() const { return buffer_; }
};

class BinaryReader {
    const uint8_t* data_;
    std::size_t size_;
    std::size_t pos_ = 0;
public:
    BinaryReader(const uint8_t* data, std::size_t size)
        : data_(data), size_(size) {}

    void read_bytes(void* dest, std::size_t size) {
        std::memcpy(dest, data_ + pos_, size);
        pos_ += size;
    }

    template<typename T>
    T read() {
        if constexpr (std::is_trivially_copyable_v<T>) {
            T value;
            read_bytes(&value, sizeof(T));
            return value;
        } else if constexpr (std::is_same_v<T, std::string>) {
            uint32_t len = read<uint32_t>();
            std::string str(len, '\0');
            read_bytes(str.data(), len);
            return str;
        } else {
            T value;
            value.deserialize(*this);
            return value;
        }
    }
};

// 使用反射宏简化序列化
#define BINARY_SERIALIZABLE(...) \
    void serialize(BinaryWriter& writer) const { \
        (writer.write(__VA_ARGS__), ...); \
    } \
    void deserialize(BinaryReader& reader) { \
        ((__VA_ARGS__ = reader.read<std::decay_t<decltype(__VA_ARGS__)>>()), ...); \
    }

struct Message {
    uint32_t id;
    std::string content;
    double timestamp;

    BINARY_SERIALIZABLE(id, content, timestamp)
};
```

```cpp
struct Validator;

template<typename T>
struct RangeRule {
    T min_val, max_val;
    bool operator()(const T& val) const {
        return val >= min_val && val <= max_val;
    }
    std::string error() const {
        return "值必须在" + std::to_string(min_val) + "和" +
               std::to_string(max_val) + "之间";
    }
};

struct NotEmptyRule {
    bool operator()(const T& val) const {
        return !val.empty();
    }
    std::string error() const { return "不能为空"; }

// 校验结果
struct ValidationResult {
    bool valid;
    std::vector<std::string> errors;

    explicit operator bool() const { return valid; }
};

// 字段校验器
template<typename T, typename... Rules>
struct FieldValidator {
    const char* name;
    Rules... rules;

    void validate(const T& value, ValidationResult& result) const {
        // 对每个规则进行校验
        (check_rule(value, result, rules), ...);
    }

    template<typename Rule>
    void check_rule(const T& value, ValidationResult& result,
                    const Rule& rule) const {
        if (!rule(value)) {
            result.valid = false;
            result.errors.push_back(
                std::string(name) + ": " + rule.error());
        }
    }
};
```

### 5.6 编译期反射常见陷阱

```cpp
// 陷阱1：宏注册的侵入性
// 使用宏注册字段会修改结构体的定义
struct Person {
    std::string name;

// 陷阱3：PFR只支持聚合类型
struct NotAggregate {
    NotAggregate(int x) : value(x) {}  // 自定义构造函数
    int value;

struct Base { int x; };
```

### 5.7 编译期反射完整实战案例：通用ORM映射

```cpp
#include <string>
#include <sstream>
#include <tuple>
#include <iostream>

// 完整案例：基于宏注册的通用ORM映射框架

// 字段元信息
template<typename Class, typename T>
struct ColumnInfo {
    const char* name;
    T Class::*pointer;
    const char* sql_type;

    const T& get(const Class& obj) const { return obj.*pointer; }
    void set(Class& obj, const T& value) const { obj.*pointer = value; }
};

// ORM宏
#define ORM_COLUMN(Type, name, sql_type) \
    ColumnInfo<Type>{#name, &Self::name, sql_type}

#define ORM_TABLE(ClassName, table_name, ...) \
    using Self = ClassName; \
    static constexpr const char* table_name_str = table_name; \
    static constexpr auto columns() { \
        return std::make_tuple(__VA_ARGS__); \
    }

// SQL生成器
template<typename T>
class OrmMapper {
public:
    static std::string create_table_sql() {
        std::ostringstream sql;
        sql << "CREATE TABLE IF NOT EXISTS " << T::table_name_str << " (\n";
        bool first = true;
        auto cols = T::columns();
        std::apply([&](const auto&... cols) {
            ((sql << (first ? "  " : ",\n  ") << cols.name << " " << cols.sql_type,
              first = false), ...);
        }, cols);
        sql << "\n);";
        return sql.str();
    }

    static std::string insert_sql(const T& obj) {
        std::ostringstream sql;
        sql << "INSERT INTO " << T::table_name_str << " (";
        bool first = true;
        auto cols = T::columns();
        std::apply([&](const auto&... cols) {
            ((sql << (first ? "" : ", ") << cols.name, first = false), ...);
        }, cols);
        sql << ") VALUES (";
        first = true;
        std::apply([&](const auto&... cols) {
            ((sql << (first ? "" : ", ") << "'" << cols.get(obj) << "'",
              first = false), ...);
        }, cols);
        sql << ");";
        return sql.str();
    }

    static std::string select_sql(const std::string& where = "") {
        std::ostringstream sql;
        sql << "SELECT * FROM " << T::table_name_str;
        if (!where.empty()) {
            sql << " WHERE " << where;
        }
        sql << ";";
        return sql.str();
    }
};

// 使用ORM映射
struct User {
    int id;
    std::string name;
    std::string email;
    int age;

    ORM_TABLE(User, "users",
        ORM_COLUMN(int, id, "INTEGER PRIMARY KEY"),
        ORM_COLUMN(std::string, name, "TEXT NOT NULL"),
        ORM_COLUMN(std::string, email, "TEXT UNIQUE"),
        ORM_COLUMN(int, age, "INTEGER CHECK(age > 0)")
    )
};

int main() {
    // 生成建表SQL
    std::cout << OrmMapper<User>::create_table_sql() << std::endl;
    // CREATE TABLE IF NOT EXISTS users (
    //   id INTEGER PRIMARY KEY,
    //   name TEXT NOT NULL,
    //   email TEXT UNIQUE,
    //   age INTEGER CHECK(age > 0)
    // );

    // 生成插入SQL
    User user{1, "Alice", "alice@example.com", 30};
    std::cout << OrmMapper<User>::insert_sql(user) << std::endl;
    // INSERT INTO users (id, name, email, age) VALUES ('1', 'Alice', 'alice@example.com', '30');

    // 生成查询SQL
    std::cout << OrmMapper<User>::select_sql("age > 25") << std::endl;
    // SELECT * FROM users WHERE age > 25;

    return 0;
}
```

## 小结

本章介绍了编译期反射与代码生成的核心内容：

| 技术 | 原理 | 优势 | 劣势 |
|------|------|------|------|
| 宏注册 | 手动注册字段信息 | 完全控制 | 侵入式、冗余 |
| PFR/magic_get | 聚合初始化+结构化绑定 | 非侵入式 | 仅支持聚合类型 |
| C++26反射 | 语言级别反射 | 最优雅 | 尚未标准化 |
| 手动序列化 | 为每个类型手写代码 | 完全控制 | 代码冗余 |

**关键要点**：

1. **编译期反射是C++的长期需求**：消除大量样板代码
2. **宏注册是最常用的手动反射方式**：侵入式但可控
3. **PFR是非侵入式反射的最佳实践**：利用聚合类型特性
4. **C++26反射提案将改变游戏规则**：语言级别支持
5. **序列化是反射最常见的应用**：JSON、二进制、ORM
6. **编译期校验提高代码质量**：在编译期捕获错误

编译期反射是C++元编程的前沿领域，掌握现有技术并关注C++26的进展，将使你在C++开发中保持领先。
