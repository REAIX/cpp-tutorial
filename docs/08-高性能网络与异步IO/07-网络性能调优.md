# 网络性能调优

> 掌握网络性能优化的方法论与实践技巧

---

> **Premature optimization is the root of all evil, but premature pessimization is the root of all wasted time.**
> （过早优化是万恶之源，但过早悲观是浪费时间的根源。）

> **调优：先测量，再优化，最后验证。**

---

> 🎯 **对症下药，药到病除。**

> （性能调优必须基于数据，而非猜测。）

---

> 💡 **通俗理解 - 网络性能调优**

想象开车：
- **TCP参数调优**：调整发动机参数——让车跑得更快
- **连接池**：提前热车——不用每次冷启动
- **负载均衡**：多车道分流——不堵一条路
- **瓶颈分析**：找到堵车点——对症下药
- **压测**：模拟高峰——提前发现问题

**网络性能调优就是找到系统的"堵车点"并逐一解决！**

> 🔬 **抽象理解 - 网络性能调优**：
> - **TCP调优**：调整内核TCP参数，优化传输效率
> - **连接池**：复用连接，避免频繁建立/断开
> - **负载均衡**：将请求分散到多个后端
> - **瓶颈分析**：使用工具定位性能瓶颈
> - **压测**：量化系统性能，验证优化效果

## 1. TCP参数调优

### 1.1 关键TCP参数

```
┌──────────────────────────────────────────────────────────────┐
│                    关键TCP参数调优                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   TCP_NODELAY —— 禁用Nagle算法                               │
│   ┌──────────────────────────────────────────────┐          │
│   │  Nagle算法：将小包合并发送，减少网络中小包数量  │          │
│   │  问题：增加延迟（最多40ms）                     │          │
│   │  解决：设置TCP_NODELAY禁用Nagle算法             │          │
│   │  适用：低延迟场景（游戏、金融、RPC）            │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   SO_REUSEPORT —— 多进程监听同一端口                          │
│   ┌──────────────────────────────────────────────┐          │
│   │  允许多个socket监听同一端口                     │          │
│   │  内核自动负载均衡                               │          │
│   │  避免单进程accept瓶颈                           │          │
│   │  支持热更新（新进程启动后旧进程退出）           │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   SO_SNDBUF / SO_RCVBUF —— 发送/接收缓冲区大小               │
│   ┌──────────────────────────────────────────────┐          │
│   │  默认值通常较小（如16KB~128KB）                 │          │
│   │  高带宽高延迟网络需要更大的缓冲区               │          │
│   │  BDP = 带宽 × RTT（带宽延迟积）                │          │
│   │  缓冲区应 >= BDP                               │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   TCP_QUICKACK —— 快速确认                                    │
│   ┌──────────────────────────────────────────────┐          │
│   │  Linux默认延迟发送ACK（最多200ms）              │          │
│   │  TCP_QUICKACK立即发送ACK                       │          │
│   │  减少延迟，但可能增加小包数量                   │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 TCP参数调优代码

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <netinet/tcp.h>
#include <unistd.h>
#include <cstring>

// TCP参数调优工具类
class TcpTuner {
public:
    // 禁用Nagle算法——降低延迟
    static bool set_nodelay(int fd) {
        int val = 1;
        if (setsockopt(fd, IPPROTO_TCP, TCP_NODELAY,
                        &val, sizeof(val)) < 0) {
            perror("set TCP_NODELAY");
            return false;
        }
        return true;
    }

    // 启用SO_REUSEPORT——多进程监听
    static bool set_reuseport(int fd) {
        int val = 1;
        if (setsockopt(fd, SOL_SOCKET, SO_REUSEPORT,
                        &val, sizeof(val)) < 0) {
            perror("set SO_REUSEPORT");
            return false;
        }
        return true;
    }

    // 启用SO_REUSEADDR——地址复用
    static bool set_reuseaddr(int fd) {
        int val = 1;
        if (setsockopt(fd, SOL_SOCKET, SO_REUSEADDR,
                        &val, sizeof(val)) < 0) {
            perror("set SO_REUSEADDR");
            return false;
        }
        return true;
    }

    // 设置发送缓冲区大小
    static bool set_send_buffer(int fd, int size) {
        if (setsockopt(fd, SOL_SOCKET, SO_SNDBUF,
                        &size, sizeof(size)) < 0) {
            perror("set SO_SNDBUF");
            return false;
        }
        return true;
    }

    // 设置接收缓冲区大小
    static bool set_recv_buffer(int fd, int size) {
        if (setsockopt(fd, SOL_SOCKET, SO_RCVBUF,
                        &size, sizeof(size)) < 0) {
            perror("set SO_RCVBUF");
            return false;
        }
        return true;
    }

    // 启用TCP_QUICKACK
    static bool set_quickack(int fd) {
        int val = 1;
        if (setsockopt(fd, IPPROTO_TCP, TCP_QUICKACK,
                        &val, sizeof(val)) < 0) {
            perror("set TCP_QUICKACK");
            return false;
        }
        return true;
    }

    // 启用TCP keepalive
    static bool set_keepalive(int fd, int idle = 60,
                               int interval = 10, int count = 3) {
        int val = 1;
        if (setsockopt(fd, SOL_SOCKET, SO_KEEPALIVE,
                        &val, sizeof(val)) < 0) {
            perror("set SO_KEEPALIVE");
            return false;
        }
        setsockopt(fd, IPPROTO_TCP, TCP_KEEPIDLE,
                   &idle, sizeof(idle));
        setsockopt(fd, IPPROTO_TCP, TCP_KEEPINTVL,
                   &interval, sizeof(interval));
        setsockopt(fd, IPPROTO_TCP, TCP_KEEPCNT,
                   &count, sizeof(count));
        return true;
    }

    // 设置TCP_CORK——阻塞发送直到满包（与NODELAY相反）
    static bool set_cork(int fd, bool enable) {
        int val = enable ? 1 : 0;
        if (setsockopt(fd, IPPROTO_TCP, TCP_CORK,
                        &val, sizeof(val)) < 0) {
            perror("set TCP_CORK");
            return false;
        }
        return true;
    }

    // 获取TCP信息
    static void print_tcp_info(int fd) {
        tcp_info info{};
        socklen_t len = sizeof(info);
        if (getsockopt(fd, IPPROTO_TCP, TCP_INFO,
                        &info, &len) == 0) {
            std::cout << "TCP信息：" << std::endl;
            std::cout << "  RTT: " << info.tcpi_rtt << "ms" << std::endl;
            std::cout << "  RTT方差: " << info.tcpi_rttvar << "ms" << std::endl;
            std::cout << "  拥塞窗口: " << info.tcpi_snd_cwnd << std::endl;
            std::cout << "  发送缓冲区: " << info.tcpi_snd_mss << " MSS" << std::endl;
            std::cout << "  重传次数: " << info.tcpi_retransmits << std::endl;
        }
    }

    // 高性能服务器推荐配置
    static void apply_server_optimizations(int listenfd, int clientfd) {
        // 监听socket
        set_reuseaddr(listenfd);
        set_reuseport(listenfd);

        // 客户端socket
        set_nodelay(clientfd);       // 禁用Nagle
        set_quickack(clientfd);      // 快速ACK
        set_keepalive(clientfd);     // 启用心跳
        set_send_buffer(clientfd, 256 * 1024);  // 256KB发送缓冲
        set_recv_buffer(clientfd, 256 * 1024);  // 256KB接收缓冲
    }
};
```

## 2. 连接池设计

### 2.1 连接池原理

```
┌──────────────────────────────────────────────────────────────┐
│                    连接池设计                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   无连接池：                                                  │
│   请求1: connect() → 请求 → close()                         │
│   请求2: connect() → 请求 → close()                         │
│   请求3: connect() → 请求 → close()                         │
│   ⚠️ 每次请求都要建立/关闭连接 → 开销大                      │
│                                                              │
│   有连接池：                                                  │
│   初始化: connect() × N → [连接1, 连接2, ..., 连接N]         │
│   请求1: 从池中获取连接1 → 请求 → 归还连接1                  │
│   请求2: 从池中获取连接2 → 请求 → 归还连接2                  │
│   请求3: 从池中获取连接1 → 请求 → 归还连接1                  │
│   ✅ 连接复用，避免频繁建立/关闭                              │
│                                                              │
│   连接池关键参数：                                            │
│   ┌──────────────────────────────────────────────┐          │
│   │  min_size:     最小连接数（始终保持）          │          │
│   │  max_size:     最大连接数（限制资源）          │          │
│   │  idle_timeout: 空闲超时（回收多余连接）       │          │
│   │  max_lifetime: 最大生命周期（防止老连接）      │          │
│   │  connect_timeout: 连接超时                    │          │
│   │  retry_interval:  重试间隔                    │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 连接池实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <chrono>
#include <functional>
#include <memory>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cstring>

// TCP连接池
class TcpConnectionPool {
public:
    struct Config {
        std::string host;
        uint16_t port;
        size_t min_size = 5;
        size_t max_size = 50;
        std::chrono::seconds idle_timeout{300};     // 5分钟空闲超时
        std::chrono::seconds max_lifetime{3600};    // 1小时最大生命周期
        std::chrono::seconds connect_timeout{5};    // 5秒连接超时
    };

    TcpConnectionPool(const Config& config) : config_(config) {
        // 预创建最小连接数
        for (size_t i = 0; i < config_.min_size; ++i) {
            auto conn = create_connection();
            if (conn) {
                pool_.push(std::move(conn));
            }
        }
    }

    ~TcpConnectionPool() {
        while (!pool_.empty()) {
            auto conn = pool_.front();
            pool_.pop();
            if (conn && conn->fd >= 0) {
                close(conn->fd);
            }
        }
    }

    // 获取连接
    std::shared_ptr<Connection> acquire() {
        std::unique_lock<std::mutex> lock(mutex_);

        // 尝试从池中获取
        while (!pool_.empty()) {
            auto conn = pool_.front();
            pool_.pop();

            // 检查连接是否有效
            if (is_connection_alive(conn)) {
                conn->last_used = std::chrono::steady_clock::now();
                active_count_++;
                return conn;
            } else {
                // 连接已失效，关闭并创建新的
                if (conn->fd >= 0) close(conn->fd);
            }
        }

        // 池为空，尝试创建新连接
        if (active_count_ + pool_.size() < config_.max_size) {
            auto conn = create_connection();
            if (conn) {
                active_count_++;
                return conn;
            }
        }

        // 等待连接归还
        cv_.wait(lock, [this] { return !pool_.empty(); });

        if (!pool_.empty()) {
            auto conn = pool_.front();
            pool_.pop();
            active_count_++;
            return conn;
        }

        return nullptr;
    }

    // 归还连接
    void release(std::shared_ptr<Connection> conn) {
        std::lock_guard<std::mutex> lock(mutex_);
        active_count_--;

        if (conn && is_connection_alive(conn)) {
            conn->last_used = std::chrono::steady_clock::now();
            pool_.push(std::move(conn));
            cv_.notify_one();
        } else if (conn && conn->fd >= 0) {
            close(conn->fd);
        }
    }

    // 清理空闲连接
    void cleanup_idle() {
        std::lock_guard<std::mutex> lock(mutex_);
        auto now = std::chrono::steady_clock::now();

        std::queue<std::shared_ptr<Connection>> alive;

        while (!pool_.empty()) {
            auto conn = pool_.front();
            pool_.pop();

            auto idle = std::chrono::duration_cast<std::chrono::seconds>(
                now - conn->last_used);

            auto age = std::chrono::duration_cast<std::chrono::seconds>(
                now - conn->created);

            bool should_keep = idle < config_.idle_timeout &&
                               age < config_.max_lifetime &&
                               is_connection_alive(conn);

            if (should_keep) {
                alive.push(std::move(conn));
            } else {
                if (conn->fd >= 0) close(conn->fd);
            }
        }

        pool_ = std::move(alive);
    }

private:
    struct Connection {
        int fd;
        std::chrono::steady_clock::time_point created;
        std::chrono::steady_clock::time_point last_used;
    };

    std::shared_ptr<Connection> create_connection() {
        int fd = socket(AF_INET, SOCK_STREAM, 0);
        if (fd < 0) return nullptr;

        // 设置非阻塞
        int flags = fcntl(fd, F_GETFL, 0);
        fcntl(fd, F_SETFL, flags | O_NONBLOCK);

        sockaddr_in addr{};
        addr.sin_family = AF_INET;
        addr.sin_port = htons(config_.port);
        inet_pton(AF_INET, config_.host.c_str(), &addr.sin_addr);

        // 连接（简化，实际需要处理非阻塞connect）
        if (connect(fd, (sockaddr*)&addr, sizeof(addr)) < 0) {
            if (errno != EINPROGRESS) {
                close(fd);
                return nullptr;
            }
        }

        // 设置TCP优化
        TcpTuner::set_nodelay(fd);
        TcpTuner::set_keepalive(fd);

        auto conn = std::make_shared<Connection>();
        conn->fd = fd;
        conn->created = std::chrono::steady_clock::now();
        conn->last_used = conn->created;

        return conn;
    }

    bool is_connection_alive(const std::shared_ptr<Connection>& conn) {
        if (!conn || conn->fd < 0) return false;

        // 检查连接是否仍然有效
        int error = 0;
        socklen_t len = sizeof(error);
        if (getsockopt(conn->fd, SOL_SOCKET, SO_ERROR,
                        &error, &len) < 0 || error != 0) {
            return false;
        }

        return true;
    }

    Config config_;
    std::queue<std::shared_ptr<Connection>> pool_;
    std::mutex mutex_;
    std::condition_variable cv_;
    size_t active_count_ = 0;
};

// RAII连接包装器
class PooledConnection {
public:
    PooledConnection(TcpConnectionPool& pool,
                     std::shared_ptr<TcpConnectionPool::Connection> conn)
        : pool_(pool), conn_(std::move(conn)) {}

    ~PooledConnection() {
        if (conn_) {
            pool_.release(std::move(conn_));
        }
    }

    int fd() const { return conn_ ? conn_->fd : -1; }

    // 禁止拷贝
    PooledConnection(const PooledConnection&) = delete;
    PooledConnection& operator=(const PooledConnection&) = delete;

    // 允许移动
    PooledConnection(PooledConnection&&) = default;
    PooledConnection& operator=(PooledConnection&&) = default;

private:
    TcpConnectionPool& pool_;
    std::shared_ptr<TcpConnectionPool::Connection> conn_;
};
```

## 3. 负载均衡策略

### 3.1 常见负载均衡算法

```
┌──────────────────────────────────────────────────────────────┐
│                    负载均衡算法                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   1. 轮询（Round Robin）                                     │
│   ┌──────────────────────────────────────────────┐          │
│   │  请求1 → 后端A                                │          │
│   │  请求2 → 后端B                                │          │
│   │  请求3 → 后端C                                │          │
│   │  请求4 → 后端A                                │          │
│   │  简单公平，不考虑后端差异                      │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   2. 加权轮询（Weighted Round Robin）                        │
│   ┌──────────────────────────────────────────────┐          │
│   │  A(权重5) B(权重3) C(权重2)                   │          │
│   │  A A A A A B B B C C                          │          │
│   │  按权重分配，适合后端性能不同                   │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   3. 最少连接（Least Connections）                           │
│   ┌──────────────────────────────────────────────┐          │
│   │  选择当前连接数最少的后端                      │          │
│   │  适合长连接场景                                │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
│   4. 一致性哈希（Consistent Hashing）                        │
│   ┌──────────────────────────────────────────────┐          │
│   │  根据请求key计算哈希，映射到后端               │          │
│   │  后端增减时只影响相邻节点                      │          │
│   │  适合有状态服务（缓存、会话）                   │          │
│   └──────────────────────────────────────────────┘          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 负载均衡实现

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
#include <cstdint>
#include <functional>

// 后端服务器
struct Backend {
    std::string address;
    int port;
    int weight;
    int active_connections;
    bool healthy;
};

// 轮询负载均衡
class RoundRobinLB {
public:
    RoundRobinLB(const std::vector<Backend>& backends)
        : backends_(backends), next_(0) {}

    Backend* select() {
        // 跳过不健康的后端
        for (size_t i = 0; i < backends_.size(); ++i) {
            size_t idx = next_++ % backends_.size();
            if (backends_[idx].healthy) {
                return &backends_[idx];
            }
        }
        return nullptr;
    }

private:
    std::vector<Backend> backends_;
    std::atomic<size_t> next_;
};

// 加权轮询负载均衡（平滑加权轮询）
class SmoothWeightedRoundRobinLB {
public:
    SmoothWeightedRoundRobinLB(const std::vector<Backend>& backends)
        : backends_(backends) {
        current_weights_.resize(backends.size(), 0);
    }

    Backend* select() {
        int total_weight = 0;
        for (const auto& b : backends_) {
            if (b.healthy) total_weight += b.weight;
        }

        if (total_weight == 0) return nullptr;

        // 增加当前权重
        for (size_t i = 0; i < backends_.size(); ++i) {
            if (backends_[i].healthy) {
                current_weights_[i] += backends_[i].weight;
            }
        }

        // 选择当前权重最大的
        size_t best = 0;
        int best_weight = -1;
        for (size_t i = 0; i < backends_.size(); ++i) {
            if (backends_[i].healthy &&
                current_weights_[i] > best_weight) {
                best = i;
                best_weight = current_weights_[i];
            }
        }

        // 减去总权重
        current_weights_[best] -= total_weight;

        return &backends_[best];
    }

private:
    std::vector<Backend> backends_;
    std::vector<int> current_weights_;
};

// 最少连接负载均衡
class LeastConnectionLB {
public:
    LeastConnectionLB(const std::vector<Backend>& backends)
        : backends_(backends) {}

    Backend* select() {
        Backend* best = nullptr;
        int min_conn = INT_MAX;

        for (auto& b : backends_) {
            if (b.healthy && b.active_connections < min_conn) {
                min_conn = b.active_connections;
                best = &b;
            }
        }

        if (best) {
            best->active_connections++;
        }

        return best;
    }

    void release(Backend* backend) {
        if (backend) {
            backend->active_connections--;
        }
    }

private:
    std::vector<Backend> backends_;
};

// 一致性哈希
class ConsistentHashLB {
public:
    ConsistentHashLB(const std::vector<Backend>& backends,
                      int virtual_nodes = 150)
        : virtual_nodes_(virtual_nodes) {
        for (const auto& b : backends) {
            add_backend(b);
        }
    }

    Backend* select(const std::string& key) {
        if (ring_.empty()) return nullptr;

        uint32_t hash = murmurhash(key);
        auto it = ring_.lower_bound(hash);

        if (it == ring_.end()) {
            it = ring_.begin();
        }

        return it->second;
    }

    void add_backend(const Backend& backend) {
        for (int i = 0; i < virtual_nodes_; ++i) {
            std::string vnode = backend.address + ":" +
                                std::to_string(backend.port) +
                                "#" + std::to_string(i);
            uint32_t hash = murmurhash(vnode);
            ring_[hash] = const_cast<Backend*>(&backend);
        }
    }

private:
    // MurmurHash3（简化版）
    uint32_t murmurhash(const std::string& key) {
        uint32_t h = 0;
        for (char c : key) {
            h = h * 31 + static_cast<uint32_t>(c);
        }
        return h;
    }

    int virtual_nodes_;
    std::map<uint32_t, Backend*> ring_;
};
```

```cpp
// 性能分析工具
class PerformanceAnalyzer {
public:
    // 记录操作耗时
    class ScopedTimer {
    public:
        ScopedTimer(const std::string& name, PerformanceAnalyzer& analyzer)
            : name_(name), analyzer_(analyzer),
              start_(std::chrono::high_resolution_clock::now()) {}

        ~ScopedTimer() {
            auto end = std::chrono::high_resolution_clock::now();
            double ms = std::chrono::duration<double, std::milli>(
                end - start_).count();
            analyzer_.record(name_, ms);
        }

    private:
        std::string name_;
        PerformanceAnalyzer& analyzer_;
        std::chrono::high_resolution_clock::time_point start_;
    };

    void record(const std::string& name, double ms) {
        records_[name].push_back(ms);
    }

    // 生成分析报告
    void print_report() const {
        std::cout << "========== 性能分析报告 ==========" << std::endl;

        for (const auto& [name, times] : records_) {
            auto stats = calculate_stats(times);
            std::cout << "\n[" << name << "]" << std::endl;
            std::cout << "  调用次数: " << times.size() << std::endl;
            std::cout << "  平均: " << stats.avg << " ms" << std::endl;
            std::cout << "  P50:  " << stats.p50 << " ms" << std::endl;
            std::cout << "  P90:  " << stats.p90 << " ms" << std::endl;
            std::cout << "  P99:  " << stats.p99 << " ms" << std::endl;
            std::cout << "  最大: " << stats.max << " ms" << std::endl;
            std::cout << "  最小: " << stats.min << " ms" << std::endl;
        }
    }

private:
    struct Stats {
        double min, max, avg, p50, p90, p99;
    };

    Stats calculate_stats(const std::vector<double>& times) const {
        Stats stats{};
        if (times.empty()) return stats;

        std::vector<double> sorted = times;
        std::sort(sorted.begin(), sorted.end());

        stats.min = sorted.front();
        stats.max = sorted.back();
        stats.avg = std::accumulate(sorted.begin(), sorted.end(), 0.0) / sorted.size();
        stats.p50 = percentile(sorted, 0.50);
        stats.p90 = percentile(sorted, 0.90);
        stats.p99 = percentile(sorted, 0.99);

        return stats;
    }

    double percentile(const std::vector<double>& sorted, double p) const {
        size_t idx = static_cast<size_t>(p * (sorted.size() - 1));
        return sorted[std::min(idx, sorted.size() - 1)];
    }

    std::unordered_map<std::string, std::vector<double>> records_;
};
```

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cstring>
#include <chrono>
#include <vector>
#include <thread>
#include <atomic>
#include <algorithm>
#include <numeric>

// 简单的TCP压测客户端
class TcpBenchmarkClient {
public:
    struct Config {
        std::string host;
        uint16_t port;
        int num_threads = 4;
        int num_connections = 100;
        int duration_seconds = 10;
        size_t message_size = 64;
    };

    struct Result {
        int64_t total_requests;
        int64_t total_bytes;
        double duration_seconds;
        double qps;
        double throughput_mbps;
        double avg_latency_ms;
        double p50_latency_ms;
        double p99_latency_ms;
    };

    TcpBenchmarkClient(const Config& config) : config_(config) {}

    Result run() {
        std::atomic<int64_t> total_requests{0};
        std::atomic<int64_t> total_bytes{0};
        std::atomic<bool> running{true};
        std::vector<double> all_latencies;
        std::mutex latency_mutex;

        auto start = std::chrono::steady_clock::now();

        // 启动工作线程
        std::vector<std::thread> threads;
        for (int t = 0; t < config_.num_threads; ++t) {
            int conns_per_thread = config_.num_connections / config_.num_threads;
            threads.emplace_back([&, conns_per_thread] {
                worker(conns_per_thread, total_requests, total_bytes,
                       running, all_latencies, latency_mutex);
            });
        }

        // 运行指定时间
        std::this_thread::sleep_for(
            std::chrono::seconds(config_.duration_seconds));
        running = false;

        for (auto& t : threads) {
            t.join();
        }

        auto end = std::chrono::steady_clock::now();
        double duration = std::chrono::duration<double>(end - start).count();

        // 计算结果
        Result result{};
        result.total_requests = total_requests;
        result.total_bytes = total_bytes;
        result.duration_seconds = duration;
        result.qps = total_requests / duration;
        result.throughput_mbps = (total_bytes / 1024.0 / 1024.0) / duration;

        // 计算延迟统计
        std::lock_guard<std::mutex> lock(latency_mutex);
        if (!all_latencies.empty()) {
            std::sort(all_latencies.begin(), all_latencies.end());
            result.avg_latency_ms = std::accumulate(
                all_latencies.begin(), all_latencies.end(), 0.0) /
                all_latencies.size();
            result.p50_latency_ms = all_latencies[
                all_latencies.size() * 50 / 100];
            result.p99_latency_ms = all_latencies[
                all_latencies.size() * 99 / 100];
        }

        return result;
    }

    static void print_result(const Result& r) {
        std::cout << "========== 压测结果 ==========" << std::endl;
        std::cout << "总请求数: " << r.total_requests << std::endl;
        std::cout << "总数据量: " << r.total_bytes / 1024.0 / 1024.0
                  << " MB" << std::endl;
        std::cout << "持续时间: " << r.duration_seconds << " 秒" << std::endl;
        std::cout << "QPS: " << r.qps << std::endl;
        std::cout << "吞吐量: " << r.throughput_mbps << " MB/s" << std::endl;
        std::cout << "平均延迟: " << r.avg_latency_ms << " ms" << std::endl;
        std::cout << "P50延迟: " << r.p50_latency_ms << " ms" << std::endl;
        std::cout << "P99延迟: " << r.p99_latency_ms << " ms" << std::endl;
    }

private:
    void worker(int num_connections,
                std::atomic<int64_t>& total_requests,
                std::atomic<int64_t>& total_bytes,
                std::atomic<bool>& running,
                std::vector<double>& latencies,
                std::mutex& latency_mutex) {
        // 创建连接
        std::vector<int> conns;
        for (int i = 0; i < num_connections; ++i) {
            int fd = socket(AF_INET, SOCK_STREAM, 0);
            sockaddr_in addr{};
            addr.sin_family = AF_INET;
            addr.sin_port = htons(config_.port);
            inet_pton(AF_INET, config_.host.c_str(), &addr.sin_addr);

            if (connect(fd, (sockaddr*)&addr, sizeof(addr)) == 0) {
                conns.push_back(fd);
            } else {
                close(fd);
            }
        }

        // 准备发送数据
        std::vector<char> send_buf(config_.message_size, 'X');
        std::vector<char> recv_buf(config_.message_size);

        // 发送请求
        int conn_idx = 0;
        while (running) {
            int fd = conns[conn_idx % conns.size()];
            conn_idx++;

            auto req_start = std::chrono::high_resolution_clock::now();

            ssize_t sent = send(fd, send_buf.data(), send_buf.size(), 0);
            if (sent <= 0) continue;

            ssize_t recvd = recv(fd, recv_buf.data(), recv_buf.size(), 0);
            if (recvd <= 0) continue;

            auto req_end = std::chrono::high_resolution_clock::now();
            double latency = std::chrono::duration<double, std::milli>(
                req_end - req_start).count();

            total_requests++;
            total_bytes += sent + recvd;

            {
                std::lock_guard<std::mutex> lock(latency_mutex);
                latencies.push_back(latency);
            }
        }

        for (int fd : conns) close(fd);
    }

    Config config_;
};
```

## 7. 小结

### 核心要点回顾

| 要点 | 说明 |
|------|------|
| **TCP_NODELAY** | 禁用Nagle算法，降低延迟 |
| **SO_REUSEPORT** | 多进程监听同一端口，内核负载均衡 |
| **缓冲区大小** | 根据BDP调整，高带宽高延迟需更大缓冲区 |
| **连接池** | 复用连接，避免频繁建立/关闭 |
| **轮询/加权/最少连接** | 根据场景选择合适的负载均衡算法 |
| **一致性哈希** | 适合有状态服务，后端增减影响最小 |
| **分层瓶颈分析** | 应用→协议→系统→网络，逐层排查 |
| **perf + 火焰图** | CPU性能剖析利器 |
| **tcpdump + Wireshark** | 网络包分析利器 |
| **先测量再优化** | 性能调优必须基于数据 |

### 调优优先级

| 优先级 | 优化方向 | 预期收益 |
|--------|---------|---------|
| **1** | 架构优化（Reactor/线程模型） | 5-10倍 |
| **2** | IO优化（零拷贝/连接池） | 2-5倍 |
| **3** | 协议优化（二进制/批量） | 1.5-3倍 |
| **4** | TCP参数调优 | 1.2-2倍 |
| **5** | 内核参数调优 | 1.1-1.5倍 |
| **6** | 硬件升级 | 1.5-3倍 |
