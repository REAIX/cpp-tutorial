> 💡 **通俗理解 - 为什么需要高级内存管理？**

**默认malloc = 公共停车场**
- 谁来都能停，但找车位慢
- 车位大小固定，小轿车占大车位浪费
- 高峰期排队等车位（锁竞争）

**自定义内存池 = 私人车库**
- 你提前建好专属车位，随时可用
- 车位大小按需定制，不浪费
- 不用和别人抢（无锁分配）

> 🔬 **抽象理解 - 高级内存管理的本质**：
>
> - **核心目标**：减少分配/释放开销、降低内存碎片、提高缓存局部性
> - **关键手段**：池化、分区、预分配、NUMA感知
> - **性能影响**：内存分配可能占程序运行时间的10-30%
> - **权衡**：内存效率 vs 分配速度 vs 实现复杂度

## 1. 内存分配器原理

### 1.1 ptmalloc（glibc默认分配器）

ptmalloc是glibc的默认内存分配器，源自Doug Lea的dlmalloc，增加了多线程支持。

```
┌─────────────────────────────────────────────────────┐
│               ptmalloc 内存布局                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐            │
│  │ Arena 1 │  │ Arena 2 │  │ Arena N │  ...       │
│  │(主线程)  │  │(线程2)   │  │(线程N)  │            │
│  └────┬────┘  └────┬────┘  └────┬────┘            │
│       │            │            │                   │
│  ┌────▼────┐  ┌────▼────┐  ┌────▼────┐            │
│  │ Bins    │  │ Bins    │  │ Bins    │            │
│  │ Fast    │  │ Fast    │  │ Fast    │            │
│  │ Small   │  │ Small   │  │ Small   │            │
│  │ Large   │  │ Large   │  │ Large   │            │
│  │ Unsorted│  │ Unsorted│  │ Unsorted│            │
│  └─────────┘  └─────────┘  └─────────┘            │
│                                                     │
│  Top Chunk ──────────────────────────────────→     │
│  (剩余的连续堆空间)                                   │
└─────────────────────────────────────────────────────┘
```

**ptmalloc的关键特性：**

| 特性 | 说明 | 优缺点 |
|------|------|--------|
| **Arena** | 每个线程有自己的arena，减少锁竞争 | arena数量有限，仍可能竞争 |
| **Fast Bins** | 小块内存（≤80B）的快速缓存 | 不合并相邻块，可能碎片化 |
| **Small Bins** | 中等大小内存的精确大小类 | O(1)分配，但需要锁 |
| **Large Bins** | 大块内存的近似大小类 | 需要遍历，稍慢 |
| **Unsorted Bins** | 最近释放的块，优先复用 | 减少碎片 |

```cpp

// ============================================
// ptmalloc的碎片问题演示
// ============================================

void fragmentation_demo() {
    const int N = 1000;
    void* ptrs[N];

    // 分配1000个256字节的块
    for (int i = 0; i < N; ++i) {
        ptrs[i] = malloc(256);
    }

    // 释放偶数索引的块 → 产生碎片
    for (int i = 0; i < N; i += 2) {
        free(ptrs[i]);
    }

    // 现在尝试分配更大的块
    // 虽然总空闲空间足够，但可能无法找到连续空间
    void* big = malloc(200 * 1024);  // 200KB
    if (big) {
        std::cout << "大块分配成功（可能使用了mmap）" << std::endl;
        free(big);
    } else {
        std::cout << "大块分配失败（碎片化严重）" << std::endl;
    }

    // 释放剩余的块
    for (int i = 1; i < N; i += 2) {
        free(ptrs[i]);
    }
}
```

### 1.2 jemalloc

jemalloc由Jason Evans开发，是Firefox、Facebook等大规模系统的默认分配器。

```
┌─────────────────────────────────────────────────────┐
│               jemalloc 内存布局                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────────────────────────────────────────┐  │
│  │              Arena (per CPU核心)              │  │
│  │  ┌──────────┐ ┌──────────┐ ┌──────────┐     │  │
│  │  │  Bin 0   │ │  Bin 1   │ │  Bin N   │     │  │
│  │  │ (8B)     │ │ (16B)    │ │ (大块)    │     │  │
│  │  │ ┌──────┐ │ │ ┌──────┐ │ │          │     │  │
│  │  │ │Slab 1│ │ │ │Slab 1│ │ │          │     │  │
│  │  │ │Slab 2│ │ │ │Slab 2│ │ │          │     │  │
│  │  │ │ ...  │ │ │ │ ...  │ │ │          │     │  │
│  │  │ └──────┘ │ │ └──────┘ │ │          │     │  │
│  │  └──────────┘ └──────────┘ └──────────┘     │  │
│  │                                              │  │
│  │  tcache (线程本地缓存) ─→ 无锁快速分配        │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
│  Huge: 直接mmap，独立管理                            │
└─────────────────────────────────────────────────────┘
```

**jemalloc vs ptmalloc 对比：**

| 特性 | ptmalloc | jemalloc |
|------|----------|----------|
| **线程扩展性** | arena数量有限 | 按CPU核心数分配arena |
| **小对象分配** | fast bin + 锁 | tcache无锁分配 |
| **碎片控制** | 一般 | 更好的碎片整理 |
| **大对象** | 超阈值用mmap | 独立的huge分类 |
| **元数据开销** | 内联在chunk中 | 独立元数据页面 |

```cpp
#include <iostream>
#include <chrono>
#include <vector>
#include <thread>

// ============================================
// 多线程内存分配性能对比
// ============================================

// 模拟多线程内存分配场景
template<typename AllocFunc, typename FreeFunc>
void benchmark_alloc(const std::string& name,
                     AllocFunc alloc, FreeFunc free_func,
                     int threads, int ops_per_thread) {
    auto start = std::chrono::high_resolution_clock::now();

    std::vector<std::thread> thread_list;
    for (int t = 0; t < threads; ++t) {
        thread_list.emplace_back([&, t]() {
            std::vector<void*> ptrs;
            ptrs.reserve(ops_per_thread);

            for (int i = 0; i < ops_per_thread; ++i) {
                // 混合大小分配，模拟真实场景
                size_t size;
                if (i % 10 < 5) size = 16 + (i % 32);       // 小块
                else if (i % 10 < 8) size = 256 + (i % 256); // 中块
                else size = 4096 + (i % 4096);                // 大块

                void* p = alloc(size);
                if (p) ptrs.push_back(p);

                // 随机释放一些
                if (i % 3 == 0 && !ptrs.empty()) {
                    size_t idx = (i + t) % ptrs.size();
                    if (ptrs[idx]) {
                        free_func(ptrs[idx]);
                        ptrs[idx] = nullptr;
                    }
                }
            }

            // 释放剩余的
            for (void* p : ptrs) {
                if (p) free_func(p);
            }
        });
    }

    for (auto& th : thread_list) th.join();

    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();

    std::cout << name << ": " << ms << " ms ("
              << threads << " 线程, "
              << ops_per_thread << " ops/线程)" << std::endl;
}

void compare_allocators() {
    const int threads = 8;
    const int ops = 100000;

    // 使用默认分配器（ptmalloc）
    benchmark_alloc("ptmalloc",
        [](size_t s) -> void* { return malloc(s); },
        [](void* p) { free(p); },
        threads, ops);

    // 注意：要使用jemalloc，需要链接jemalloc库
    // 编译时: g++ -ljemalloc ...
    // 运行时: LD_PRELOAD=/usr/lib/libjemalloc.so ./program
}
```

## 2. 自定义内存池

### 2.1 固定大小内存池

固定大小内存池是最简单高效的内存管理方案，适用于分配大小固定的场景。

```cpp
#include <iostream>
#include <vector>
#include <cassert>
#include <cstdint>

// ============================================
// 固定大小内存池实现
// ============================================

class FixedSizePool {
public:
    // 构造函数：指定每个块的大小和初始容量
    FixedSizePool(size_t block_size, size_t initial_capacity = 64)
        : block_size_(block_size)
        , free_list_(nullptr)
        , allocated_count_(0)
        , free_count_(0)
    {
        // 确保块大小至少能存放一个指针（用于空闲链表）
        block_size_ = std::max(block_size, sizeof(void*));
        // 对齐到8字节
        block_size_ = (block_size_ + 7) & ~7UL;

        expand(initial_capacity);
    }

    ~FixedSizePool() {
        for (void* chunk : chunks_) {
            ::free(chunk);
        }
    }

    // 分配一个块
    void* allocate() {
        if (!free_list_) {
            // 空闲列表为空，扩展池
            expand(chunks_.size() * 2);  // 每次翻倍增长
        }

        // 从空闲列表头部取一个块
        Block* block = free_list_;
        free_list_ = free_list_->next;
        allocated_count_++;
        free_count_--;

        return block;
    }

    // 释放一个块
    void deallocate(void* ptr) {
        if (!ptr) return;

        // 将块放回空闲列表头部
        Block* block = static_cast<Block*>(ptr);
        block->next = free_list_;
        free_list_ = block;

        allocated_count_--;
        free_count_++;
    }

    // 统计信息
    size_t allocatedCount() const { return allocated_count_; }
    size_t freeCount() const { return free_count_; }
    size_t totalCapacity() const { return allocated_count_ + free_count_; }
    size_t blockSize() const { return block_size_; }

    // 禁止拷贝
    FixedSizePool(const FixedSizePool&) = delete;
    FixedSizePool& operator=(const FixedSizePool&) = delete;

private:
    // 空闲链表节点
    struct Block {
        Block* next;
    };

    // 扩展池：分配新的大块内存并切分为小块
    void expand(size_t num_blocks) {
        // 分配一大块连续内存
        void* chunk = ::malloc(num_blocks * block_size_);
        if (!chunk) {
            throw std::bad_alloc();
        }

        chunks_.push_back(chunk);

        // 将大块切分为小块，加入空闲链表
        char* ptr = static_cast<char*>(chunk);
        for (size_t i = 0; i < num_blocks; ++i) {
            Block* block = reinterpret_cast<Block*>(ptr + i * block_size_);
            block->next = free_list_;
            free_list_ = block;
            free_count_++;
        }
    }

    size_t block_size_;
    Block* free_list_;       // 空闲链表头
    std::vector<void*> chunks_;  // 已分配的大块内存
    size_t allocated_count_;
    size_t free_count_;
};

// ============================================
// 使用示例
// ============================================

struct Particle {
    float x, y, z;        // 位置
    float vx, vy, vz;     // 速度
    float mass;
    int id;
};

void fixed_pool_demo() {
    // 创建粒子对象池
    FixedSizePool pool(sizeof(Particle), 1000);

    std::cout << "块大小: " << pool.blockSize() << " 字节" << std::endl;
    std::cout << "初始容量: " << pool.totalCapacity() << std::endl;

    // 分配粒子
    std::vector<Particle*> particles;
    for (int i = 0; i < 500; ++i) {
        Particle* p = static_cast<Particle*>(pool.allocate());
        p->id = i;
        p->x = p->y = p->z = 0.0f;
        p->vx = p->vy = p->vz = 0.0f;
        p->mass = 1.0f;
        particles.push_back(p);
    }

    std::cout << "已分配: " << pool.allocatedCount() << std::endl;
    std::cout << "空闲:   " << pool.freeCount() << std::endl;

    // 释放一半
    for (int i = 0; i < 250; ++i) {
        pool.deallocate(particles[i]);
    }

    std::cout << "释放后已分配: " << pool.allocatedCount() << std::endl;
    std::cout << "释放后空闲:   " << pool.freeCount() << std::endl;

    // 释放剩余
    for (int i = 250; i < 500; ++i) {
        pool.deallocate(particles[i]);
    }
}
```

### 2.2 多大小类内存池

```cpp
#include <iostream>
#include <array>
#include <cmath>

// ============================================
// 多大小类内存池
// ============================================

class MultiSizePool {
public:
    MultiSizePool() {
        // 初始化各个大小类的内存池
        // 大小类: 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096
        for (size_t i = 0; i < NUM_CLASSES; ++i) {
            size_t size = minClassSize() << i;
            pools_[i] = new FixedSizePool(size, 64);
        }
    }

    ~MultiSizePool() {
        for (auto* pool : pools_) {
            delete pool;
        }
    }

    void* allocate(size_t size) {
        // 找到合适的大小类
        int cls = sizeToClass(size);
        if (cls >= 0) {
            return pools_[cls]->allocate();
        }
        // 超出大小类范围，直接用malloc
        return ::malloc(size);
    }

    void deallocate(void* ptr, size_t size) {
        if (!ptr) return;

        int cls = sizeToClass(size);
        if (cls >= 0) {
            pools_[cls]->deallocate(ptr);
        } else {
            ::free(ptr);
        }
    }

private:
    static constexpr size_t NUM_CLASSES = 10;
    static constexpr size_t MIN_CLASS_SIZE = 8;  // 最小8字节

    static size_t minClassSize() { return MIN_CLASS_SIZE; }

    // 根据大小找到对应的大小类索引
    int sizeToClass(size_t size) const {
        if (size < MIN_CLASS_SIZE) size = MIN_CLASS_SIZE;

        // 计算向上取整到2的幂
        size_t rounded = 1;
        int cls = 0;
        while (rounded < size && cls < static_cast<int>(NUM_CLASSES)) {
            rounded <<= 1;
            cls++;
        }

        if (cls >= static_cast<int>(NUM_CLASSES)) {
            return -1;  // 超出范围
        }
        return cls;
    }

    FixedSizePool* pools_[NUM_CLASSES];
};

// ============================================
// C++ allocator适配器
// ============================================

template<typename T>
class PoolAllocator {
public:
    using value_type = T;

    explicit PoolAllocator(MultiSizePool* pool) : pool_(pool) {}

    template<typename U>
    PoolAllocator(const PoolAllocator<U>& other) noexcept
        : pool_(other.pool_) {}

    T* allocate(size_t n) {
        size_t bytes = n * sizeof(T);
        return static_cast<T*>(pool_->allocate(bytes));
    }

    void deallocate(T* ptr, size_t n) noexcept {
        size_t bytes = n * sizeof(T);
        pool_->deallocate(ptr, bytes);
    }

    template<typename U>
    bool operator==(const PoolAllocator<U>& other) const noexcept {
        return pool_ == other.pool_;
    }

    template<typename U>
    bool operator!=(const PoolAllocator<U>& other) const noexcept {
        return pool_ != other.pool_;
    }

    // 让其他特化能访问pool_
    template<typename U>
    friend class PoolAllocator;

private:
    MultiSizePool* pool_;
};

void multi_size_pool_demo() {

    // 使用内存池分配各种大小的对象
    int* a = static_cast<int*>(pool.allocate(sizeof(int)));          // 4B → 8B类
    double* b = static_cast<double*>(pool.allocate(sizeof(double)));  // 8B → 8B类
    char* c = static_cast<char*>(pool.allocate(100));                 // 100B → 128B类
    int* d = static_cast<int*>(pool.allocate(2000));                  // 2000B → 2048B类

    *b = 3.14;
    std::cout << "a = " << *a << ", b = " << *b << std::endl;

    pool.deallocate(b, sizeof(double));
    pool.deallocate(c, 100);

    std::vector<int, PoolAllocator<int>> vec(alloc);
    vec.push_back(1);
    vec.push_back(2);
    vec.push_back(3);

    std::cout << "vector: ";
    for (int v : vec) std::cout << v << " ";
    std::cout << std::endl;
}
```

## 3. Arena分配

### 3.1 Arena分配原理

Arena分配是一种"批量分配、统一释放"的策略，特别适合请求处理型程序。

```
┌─────────────────────────────────────────────────────┐
│              Arena分配生命周期                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  请求开始                                            │
│    │                                                │
│    ▼                                                │
│  ┌──────────────┐                                   │
│  │ Arena创建     │ ← 分配一大块内存                   │
│  └──────┬───────┘                                   │
│         │                                           │
│    ┌────▼────┐                                      │
│    │ 处理请求 │ ← 从Arena中快速分配，无需free         │
│    │ 分配内存 │   (bump pointer分配，O(1))           │
│    └────┬────┘                                      │
│         │                                           │
│    ┌────▼────┐                                      │
│    │ 请求完成 │ ← 一次性释放整个Arena                 │
│    │ Arena重置│   (只需重置指针，O(1))               │
│    └─────────┘                                      │
│                                                     │
│  优势：无碎片、无逐个释放开销、缓存友好               │
└─────────────────────────────────────────────────────┘
```

### 3.2 Arena分配器实现

```cpp
#include <iostream>
#include <vector>
#include <cstddef>
#include <cstdint>
#include <cassert>

// ============================================
// Arena分配器实现
// ============================================

class Arena {
public:
    // 构造函数：指定初始块大小
    explicit Arena(size_t block_size = 64 * 1024)  // 默认64KB
        : block_size_(block_size)
        , current_block_(nullptr)
        , offset_(0)
        , remaining_(0)
    {
        allocateNewBlock();
    }

    ~Arena() {
        for (void* block : blocks_) {
            ::free(block);
        }
    }

    // 从Arena分配内存（bump pointer分配）
    void* allocate(size_t size, size_t alignment = alignof(std::max_align_t)) {
        // 对齐当前偏移
        size_t aligned_offset = (offset_ + alignment - 1) & ~(alignment - 1);
        size_t padding = aligned_offset - offset_;

        if (size + padding <= remaining_) {
            // 当前块有足够空间
            void* ptr = static_cast<char*>(current_block_) + aligned_offset;
            offset_ = aligned_offset + size;
            remaining_ -= (size + padding);
            return ptr;
        }

        // 当前块空间不足，分配新块
        size_t new_block_size = std::max(block_size_, size + alignment);
        allocateNewBlock();

        // 重新对齐并分配
        aligned_offset = (offset_ + alignment - 1) & ~(alignment - 1);
        padding = aligned_offset - offset_;

        void* ptr = static_cast<char*>(current_block_) + aligned_offset;
        offset_ = aligned_offset + size;
        remaining_ -= (size + padding);
        return ptr;
    }

    // 重置Arena（保留已分配的块，重置偏移）
    void reset() {
        if (blocks_.empty()) return;

        // 使用第一个块作为当前块
        current_block_ = blocks_[0];
        offset_ = 0;
        remaining_ = block_size_;

        // 后续的块保留但暂不使用
        // 如果需要可以释放多余的块
    }

    // 获取Arena使用的总内存
    size_t totalMemory() const {
        return blocks_.size() * block_size_;
    }

    // 获取Arena实际使用的内存
    size_t usedMemory() const {
        size_t total = 0;
        for (size_t i = 0; i < blocks_.size() - 1; ++i) {
            total += block_size_;
        }
        total += offset_;
        return total;
    }

    // 禁止拷贝
    Arena(const Arena&) = delete;
    Arena& operator=(const Arena&) = delete;

private:
    void allocateNewBlock() {
        void* block = ::malloc(block_size_);
        if (!block) throw std::bad_alloc();

        blocks_.push_back(block);
        current_block_ = block;
        offset_ = 0;
        remaining_ = block_size_;
    }

    size_t block_size_;
    void* current_block_;
    size_t offset_;
    size_t remaining_;
    std::vector<void*> blocks_;
};

// ============================================
// Arena友好的数据结构
// ============================================

// Arena分配的字符串（无需单独释放）
class ArenaString {
public:
    ArenaString(Arena& arena, const char* str, size_t len)
        : data_(static_cast<char*>(arena.allocate(len + 1)))
        , size_(len)
    {
        std::memcpy(data_, str, len);
        data_[len] = '\0';
    }

    ArenaString(Arena& arena, const std::string& str)
        : ArenaString(arena, str.c_str(), str.size()) {}

    const char* c_str() const { return data_; }
    size_t size() const { return size_; }

private:
    char* data_;
    size_t size_;
};

// Arena分配的动态数组（无需单独释放）
template<typename T>
class ArenaVector {
public:
    ArenaVector(Arena& arena, size_t initial_capacity = 16)
        : arena_(arena)
        , data_(static_cast<T*>(arena.allocate(initial_capacity * sizeof(T))))
        , size_(0)
        , capacity_(initial_capacity)
    {}

    void push_back(const T& value) {
        if (size_ >= capacity_) {
            // Arena中分配新数组（旧数组不释放，Arena重置时统一释放）
            size_t new_capacity = capacity_ * 2;
            T* new_data = static_cast<T*>(arena_.allocate(new_capacity * sizeof(T)));

            // 搬迁旧数据
            for (size_t i = 0; i < size_; ++i) {
                new (new_data + i) T(std::move(data_[i]));
                data_[i].~T();
            }

            data_ = new_data;
            capacity_ = new_capacity;
        }

        new (data_ + size_) T(value);
        size_++;
    }

    T& operator[](size_t i) { return data_[i]; }
    const T& operator[](size_t i) const { return data_[i]; }
    size_t size() const { return size_; }
    T* data() { return data_; }

private:
    Arena& arena_;
    T* data_;
    size_t size_;
    size_t capacity_;
};

// ============================================
// Arena使用示例：HTTP请求处理
// ============================================

struct HttpRequest {
    ArenaString method;
    ArenaString path;
    ArenaVector<std::pair<ArenaString, ArenaString>> headers;
    ArenaString body;

    HttpRequest(Arena& arena)
        : method(arena, "", 0)
        , path(arena, "", 0)
        , headers(arena)
        , body(arena, "", 0)
    {}
};

void handle_http_request(const char* raw_request) {
    // 每个请求创建一个Arena
    Arena arena(4 * 1024);  // 4KB初始大小

    // 在Arena上解析请求（所有分配都是O(1)）
    HttpRequest req(arena);

    // 模拟解析...
    new (&req.method) ArenaString(arena, "GET");
    new (&req.path) ArenaString(arena, "/api/users");

    // 处理请求...
    std::cout << "处理请求: " << req.method.c_str()
              << " " << req.path.c_str() << std::endl;

    // 请求处理完毕，Arena自动析构时释放所有内存
    // 或者调用arena.reset()重用Arena
}
```

## 4. mmap高级用法

### 4.1 mmap基础回顾

mmap（Memory Map）将文件或设备映射到进程的虚拟地址空间，实现零拷贝访问。

```cpp
#include <iostream>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <cstring>

// ============================================
// mmap高级用法1：匿名映射实现自定义分配器
// ============================================

class MmapAllocator {
public:
    // 分配页面对齐的内存
    static void* allocate(size_t size) {
        // 向上对齐到页面大小
        size_t page_size = sysconf(_SC_PAGESIZE);
        size = (size + page_size - 1) & ~(page_size - 1);

        // MAP_ANONYMOUS: 不映射文件，内容初始化为0
        // MAP_PRIVATE: 写时复制
        void* ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                        MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
        if (ptr == MAP_FAILED) {
            return nullptr;
        }
        return ptr;
    }

    static void deallocate(void* ptr, size_t size) {
        size_t page_size = sysconf(_SC_PAGESIZE);
        size = (size + page_size - 1) & ~(page_size - 1);
        munmap(ptr, size);
    }
};

// ============================================
// mmap高级用法2：大块内存的懒分配
// ============================================

class LazyMemoryRegion {
public:
    LazyMemoryRegion(size_t size) : size_(size), data_(nullptr) {
        // 只分配虚拟地址空间，不分配物理内存
        // 物理内存按需分配（缺页中断时）
        data_ = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                    MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
        if (data_ == MAP_FAILED) {
            data_ = nullptr;
            throw std::bad_alloc();
        }
    }

    ~LazyMemoryRegion() {
        if (data_) {
            munmap(data_, size_);
        }
    }

    void* data() { return data_; }
    size_t size() const { return size_; }

    // 建议内核释放指定范围的物理页面（保留虚拟映射）
    void adviseDontNeed(size_t offset, size_t len) {
        madvise(static_cast<char*>(data_) + offset, len, MADV_DONTNEED);
    }

    // 建议内核指定范围将顺序访问
    void adviseSequential(size_t offset, size_t len) {
        madvise(static_cast<char*>(data_) + offset, len, MADV_SEQUENTIAL);
    }

    // 建议内核指定范围将随机访问
    void adviseRandom(size_t offset, size_t len) {
        madvise(static_cast<char*>(data_) + offset, len, MADV_RANDOM);
    }

private:
    size_t size_;
    void* data_;
};

// ============================================
// mmap高级用法3：共享内存通信
// ============================================

class SharedMemory {
public:
    // 创建共享内存
    static SharedMemory create(const char* name, size_t size) {
        int fd = shm_open(name, O_CREAT | O_RDWR, 0666);
        ftruncate(fd, size);
        void* ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
        close(fd);
        return SharedMemory(ptr, size, name);
    }

    // 打开已有共享内存
    static SharedMemory open(const char* name, size_t size) {
        int fd = shm_open(name, O_RDWR, 0666);
        void* ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
        close(fd);
        return SharedMemory(ptr, size, name);
    }

    void* data() { return data_; }
    size_t size() const { return size_; }

    // 同步共享内存到磁盘（如果需要持久化）
    void sync() {
        msync(data_, size_, MS_SYNC);
    }

    ~SharedMemory() {
        if (data_) {
            munmap(data_, size_);
            if (name_[0] != '\0') {
                shm_unlink(name_);
            }
        }
    }

    SharedMemory(SharedMemory&& other) noexcept
        : data_(other.data_), size_(other.size_) {
        strncpy(name_, other.name_, 256);
        other.data_ = nullptr;
    }

private:
    SharedMemory(void* data, size_t size, const char* name)
        : data_(data), size_(size) {
        strncpy(name_, name, 256);
    }

    void* data_;
    size_t size_;
    char name_[256]{};
};

void mmap_advanced_demo() {
    // 懒分配大内存
    LazyMemoryRegion region(1ULL * 1024 * 1024 * 1024);  // 1GB虚拟空间
    std::cout << "分配1GB虚拟地址空间（物理内存按需分配）" << std::endl;

    // 实际只使用一小部分
    int* ptr = static_cast<int*>(region.data());
    ptr[0] = 42;
    std::cout << "只使用了4字节，实际物理内存占用很小" << std::endl;

    // 释放未使用的部分
    region.adviseDontNeed(4096, region.size() - 4096);
    std::cout << "已通知内核释放未使用的物理页面" << std::endl;
}
```

## 5. 大页内存(HugePages)

### 5.1 大页内存原理

标准页面大小为4KB，大页通常为2MB或1GB。使用大页可以减少TLB miss，提高大内存应用的性能。

```
┌─────────────────────────────────────────────────────┐
│            标准页 vs 大页                             │
├─────────────────────────────────────────────────────┤
│                                                     │
│  1GB内存，4KB页面:                                   │
│  ┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐                   │
│  │P1│P2│P3│P4│P5│P6│P7│P8│..│262144│              │
│  └──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘                   │
│  需要262144个页表项 → TLB压力大                       │
│                                                     │
│  1GB内存，2MB大页:                                   │
│  ┌───────┬───────┬───────┬───┬───────┐             │
│  │  HP1  │  HP2  │  HP3  │...│ HP512 │             │
│  └───────┴───────┴───────┴───┴───────┘             │
│  只需512个页表项 → TLB压力小512倍                     │
│                                                     │
│  TLB (Translation Lookaside Buffer):                │
│  - 缓存虚拟地址→物理地址的映射                        │
│  - TLB miss代价: ~100ns (需要遍历页表)               │
│  - 大页减少TLB miss次数                              │
└─────────────────────────────────────────────────────┘
```

### 5.2 大页内存使用

```cpp
#include <iostream>
#include <sys/mman.h>
#include <unistd.h>

// ============================================
// 透明大页（Transparent Huge Pages, THP）
// ============================================

void transparent_hugepage_demo() {
    size_t size = 100 * 1024 * 1024;  // 100MB

    // 使用MAP_HUGETLB标志请求大页
    void* ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                    MAP_PRIVATE | MAP_ANONYMOUS | MAP_HUGETLB, -1, 0);

    if (ptr == MAP_FAILED) {
        // 大页不可用，回退到普通页面
        std::cout << "大页不可用，使用普通页面" << std::endl;
        ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                  MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
    } else {
        std::cout << "大页分配成功" << std::endl;
    }

    // 使用内存...
    memset(ptr, 0, size);

    munmap(ptr, size);
}

// ============================================
// 显式大页分配器
// ============================================

class HugePageAllocator {
public:
    // 尝试分配大页内存
    static void* allocate(size_t size) {
        // 对齐到2MB
        const size_t huge_page_size = 2 * 1024 * 1024;
        size = (size + huge_page_size - 1) & ~(huge_page_size - 1);

        // 方法1：使用MAP_HUGETLB
        void* ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                        MAP_PRIVATE | MAP_ANONYMOUS | MAP_HUGETLB,
                        -1, 0);

        if (ptr != MAP_FAILED) {
            std::cout << "使用MAP_HUGETLB分配大页: "
                      << size / huge_page_size << " 个2MB大页" << std::endl;
            return ptr;
        }

        // 方法2：使用madvise建议使用透明大页
        ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE,
                  MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);

        if (ptr != MAP_FAILED) {
            // 建议内核使用大页
            if (madvise(ptr, size, MADV_HUGEPAGE) == 0) {
                std::cout << "使用MADV_HUGEPAGE建议透明大页" << std::endl;
            } else {
                std::cout << "透明大页不可用，使用普通页面" << std::endl;
            }
            return ptr;
        }

        return nullptr;
    }

    static void deallocate(void* ptr, size_t size) {
        const size_t huge_page_size = 2 * 1024 * 1024;
        size = (size + huge_page_size - 1) & ~(huge_page_size - 1);
        munmap(ptr, size);
    }
};

// ============================================
// 大页内存池
// ============================================

class HugePagePool {
public:
    HugePagePool(size_t total_size) {
        const size_t huge_page_size = 2 * 1024 * 1024;
        total_size = (total_size + huge_page_size - 1) & ~(huge_page_size - 1);

        base_ = HugePageAllocator::allocate(total_size);
        if (!base_) throw std::bad_alloc();

        total_size_ = total_size;
        used_ = 0;
    }

    void* allocate(size_t size) {
        // 简单的bump pointer分配
        const size_t alignment = 64;  // 缓存行对齐
        size_t aligned_used = (used_ + alignment - 1) & ~(alignment - 1);
        size_t padding = aligned_used - used_;

        if (aligned_used + size > total_size_) {
            return nullptr;  // 空间不足
        }

        void* ptr = static_cast<char*>(base_) + aligned_used;
        used_ = aligned_used + size;
        return ptr;
    }

    void reset() {
        used_ = 0;
    }

    ~HugePagePool() {
        if (base_) {
            HugePageAllocator::deallocate(base_, total_size_);
        }
    }

private:
    void* base_;
    size_t total_size_;
    size_t used_;
};

void hugepage_demo() {
    // 创建256MB的大页内存池
    HugePagePool pool(256 * 1024 * 1024);

    // 从大页池中分配
    int* data = static_cast<int*>(pool.allocate(1024 * 1024 * sizeof(int)));
    if (data) {
        // 初始化
        for (int i = 0; i < 1024 * 1024; ++i) {
            data[i] = i;
        }
        std::cout << "在大页内存中处理了100万个整数" << std::endl;
        std::cout << "TLB miss大幅减少，性能提升显著" << std::endl;
    }
}
```

## 6. NUMA感知内存分配

### 6.1 NUMA架构原理

NUMA（Non-Uniform Memory Access）系统中，CPU访问本地内存比远程内存快得多。

```
│  │  │CPU2│ │CPU3│  │    │  │CPU6│ │CPU7│  │      │
│  │  └────┘ └────┘  │    │  └────┘ └────┘  │      │
│  │                  │    │                  │      │
│  │  ┌────────────┐  │    │  ┌────────────┐  │      │
│  │  │ 本地内存0   │  │    │  │ 本地内存1   │  │      │
```

### 6.2 NUMA感知编程

```cpp
#include <iostream>
#include <vector>
#include <thread>
#include <numa.h>
#include <numaif.h>
#include <sched.h>

// ============================================
// NUMA信息查询
// ============================================

void print_numa_info() {
    if (numa_available() < 0) {
        std::cout << "系统不支持NUMA" << std::endl;

    }

    int num_nodes = numa_num_configured_nodes();
    int num_cpus = numa_num_configured_cpus();

    std::cout << "=== NUMA系统信息 ===" << std::endl;
    std::cout << "NUMA节点数: " << num_nodes << std::endl;
    std::cout << "CPU总数:    " << num_cpus << std::endl;

    // 每个节点的CPU和内存信息
    for (int node = 0; node < num_nodes; ++node) {
        struct bitmask* cpus = numa_allocate_cpumask();
        numa_node_to_cpus(node, cpus);

        long long free_mem = 0;
        long long total_mem = numa_node_size64(node, &free_mem);

        std::cout << "\n节点 " << node << ":" << std::endl;
        std::cout << "  总内存: " << total_mem / (1024 * 1024) << " MB" << std::endl;
        std::cout << "  空闲:   " << free_mem / (1024 * 1024) << " MB" << std::endl;
        std::cout << "  CPU:    ";

        for (int cpu = 0; cpu < num_cpus; ++cpu) {
            if (numa_bitmask_isbitset(cpus, cpu)) {
                std::cout << cpu << " ";
            }
        }
        std::cout << std::endl;

        numa_free_cpumask(cpus);
    }
}

// ============================================
// NUMA感知内存分配器
// ============================================

class NumaAllocator {
public:
    // 在指定NUMA节点上分配内存
    static void* allocate_on_node(size_t size, int node) {
        // 方法1：使用numa_alloc_onnode
        void* ptr = numa_alloc_onnode(size, node);
        if (ptr) {
            return ptr;
        }

        // 方法2：先分配再迁移
        ptr = numa_alloc_local(size);  // 在本地节点分配
        if (ptr) {
            // 尝试迁移到目标节点
            if (mbind(ptr, size, MPOL_BIND, get_node_mask(node), 
                     numa_max_node() + 1, 0) != 0) {
                // 迁移失败，使用本地内存
                std::cerr << "警告: 无法迁移到节点 " << node << std::endl;
            }
        }
        return ptr;
    }

    // 在当前线程所在的NUMA节点上分配
    static void* allocate_local(size_t size) {
        return numa_alloc_local(size);
    }

    // 分配交错内存（跨所有节点均匀分布）
    static void* allocate_interleaved(size_t size) {
        return numa_alloc_interleaved(size);
    }

    static void deallocate(void* ptr, size_t size) {
        numa_free(ptr, size);
    }

private:
    static struct bitmask* get_node_mask(int node) {
        struct bitmask* mask = numa_allocate_nodemask();
        numa_bitmask_setbit(mask, node);
        return mask;
    }
};

// ============================================
// NUMA感知的线程与数据绑定
// ============================================

class NumaAwareWorker {
public:
    NumaAwareWorker(int node) : node_(node) {
        // 绑定线程到指定NUMA节点
        struct bitmask* cpus = numa_allocate_cpumask();
        numa_node_to_cpus(node, cpus);

        // 设置CPU亲和性
        cpu_set_t cpu_set;
        CPU_ZERO(&cpu_set);
        for (int cpu = 0; cpu < numa_num_configured_cpus(); ++cpu) {
            if (numa_bitmask_isbitset(cpus, cpu)) {
                CPU_SET(cpu, &cpu_set);
            }
        }
        sched_setaffinity(0, sizeof(cpu_set), &cpu_set);
        numa_free_cpumask(cpus);
    }

    void* allocLocal(size_t size) {
        return NumaAllocator::allocate_on_node(size, node_);
    }

    int node() const { return node_; }

private:
    int node_;
};

// ============================================
// NUMA感知的并行处理示例
// ============================================

void numa_parallel_demo() {
    if (numa_available() < 0) {
        std::cout << "NUMA不可用，跳过演示" << std::endl;
        return;
    }

    int num_nodes = numa_num_configured_nodes();
    std::cout << "使用 " << num_nodes << " 个NUMA节点并行处理" << std::endl;

    // 每个节点分配本地数据并处理
    std::vector<std::thread> threads;
    std::vector<int*> data_ptrs;

    for (int node = 0; node < num_nodes; ++node) {
        threads.emplace_back([node]() {
            // 绑定到当前NUMA节点
            NumaAwareWorker worker(node);

            // 在本地节点分配数据（避免远程访问）
            const size_t data_size = 1024 * 1024;  // 100万个int
            int* data = static_cast<int*>(worker.allocLocal(data_size * sizeof(int)));

            // 处理数据（全部在本地节点完成）
            for (size_t i = 0; i < data_size; ++i) {
                data[i] = static_cast<int>(i * node);
            }

            long long sum = 0;
            for (size_t i = 0; i < data_size; ++i) {
                sum += data[i];
            }

            std::cout << "节点 " << node << " 处理完成, sum = " << sum << std::endl;

            NumaAllocator::deallocate(data, data_size * sizeof(int));
        });
    }

    for (auto& t : threads) {
        t.join();
    }
}
```

## 7. 小结

### 核心要点回顾

| 技术 | 核心思想 | 适用场景 |
|------|---------|---------|
| **ptmalloc** | 多arena减少锁竞争 | 通用场景 |
| **jemalloc** | tcache无锁 + 按CPU核心arena | 多线程高并发 |
| **tcmalloc** | 三层缓存 + 细粒度锁 | Google服务、Chrome |
| **固定大小池** | 空闲链表 + 预分配 | 对象大小固定的场景 |
| **Arena** | bump pointer + 批量释放 | 请求处理型程序 |
| **mmap** | 零拷贝 + 懒分配 | 大文件、共享内存 |
| **HugePages** | 减少TLB miss | 大内存数据库、缓存 |
| **NUMA感知** | 本地分配 + 线程绑定 | 多路服务器 |

### 内存管理选择决策树

```
需要高性能内存管理？
├── 对象大小固定？ → 固定大小内存池
├── 请求处理型？ → Arena分配
├── 大内存(>1GB)？ → 大页内存
├── 多路服务器？ → NUMA感知分配
├── 通用多线程？ → jemalloc/tcmalloc
└── 简单场景？ → ptmalloc (默认)
```

### 性能优化优先级

1. **减少分配次数** → 池化、预分配、对象复用
2. **减少锁竞争** → 线程本地缓存、无锁分配
3. **提高缓存局部性** → 连续分配、紧凑布局
4. **减少TLB miss** → 大页内存
5. **减少远程访问** → NUMA感知分配
