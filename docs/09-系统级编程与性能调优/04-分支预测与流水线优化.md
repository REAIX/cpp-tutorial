> 💡 **通俗理解 - 什么是分支预测？**

**分支预测 = 预测路口方向**

想象你开车到一个岔路口：
- 如果提前知道走哪条路（预测正确）→ 不减速，直接通过
- 如果猜错了（误预测）→ 必须刹车、掉头、重新走 → 浪费15-20个时钟周期

**CPU的困境：**
- 流水线有14-19级（现代x86），意味着一条指令从开始到完成需要14-19个周期
- 遇到条件分支时，CPU不知道下一条指令在哪
- 如果等条件算完再取指令，流水线空转15+周期
- 所以CPU会"猜"（预测）分支走向，提前取指令

> 🔬 **抽象理解 - 分支预测的本质**：
>
> - **分支预测**：CPU在条件判断结果出来之前，预测分支走向
> - **预测正确**：零开销，流水线继续满载运行
> - **预测失败**：清空流水线，重新取指，损失15-20个周期
> - **优化核心**：减少不可预测的分支，或消除分支

## 1. CPU流水线原理

### 1.1 指令流水线

现代CPU使用流水线（Pipeline）技术，将指令执行分为多个阶段，不同指令的不同阶段可以并行执行：

```
┌──────────────────────────────────────────────────────────┐
│              CPU指令流水线（简化5级）                      │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  时钟周期:  1    2    3    4    5    6    7    8         │
│                                                          │
│  指令1:    [IF]  [ID]  [EX]  [MEM] [WB]                 │
│  指令2:         [IF]  [ID]  [EX]  [MEM] [WB]            │
│  指令3:              [IF]  [ID]  [EX]  [MEM] [WB]       │
│  指令4:                   [IF]  [ID]  [EX]  [MEM] [WB]  │
│                                                          │
│  IF=取指  ID=译码  EX=执行  MEM=访存  WB=写回            │
│                                                          │
│  理想情况：每个周期完成一条指令（CPI=1）                   │
├──────────────────────────────────────────────────────────┤
│  分支误预测时的流水线：                                    │
│                                                          │
│  时钟周期:  1    2    3    4    5    6    7    8    9    │
│                                                          │
│  指令1:    [IF]  [ID]  [EX]  [MEM] [WB]                 │
│  分支:                [IF]  [ID]  [EX] ← 发现预测错误    │
│  误取1:                    [IF]  [ID] ← 清空!            │
│  误取2:                         [IF] ← 清空!             │
│  正确指令:                           [IF]  [ID]  [EX]... │
│                                                          │
│  浪费了3-5个周期（实际可能15-20个周期）                   │
└──────────────────────────────────────────────────────────┘
```

### 1.3 流水线冒险

```cpp
#include <iostream>

// ============================================
// 流水线冒险类型
// ============================================

// 冒险1：数据冒险（Data Hazard）
void data_hazard_example() {
    int a = 1;
    int b = a + 1;   // 依赖a的值，可能需要等待
    int c = b * 2;   // 依赖b的值，可能需要等待

    // 编译器和CPU会通过以下方式缓解：
    // 1. 指令调度：重排无关指令
    // 2. 转发（Forwarding）：ALU结果直接传递给下一条指令
    // 3. 乱序执行：CPU自行调整执行顺序
}

// 冒险2：控制冒险（Control Hazard）- 本节重点
void control_hazard_example() {
    int x = 42;
    if (x > 0) {       // 分支：CPU需要预测走向
        x = x * 2;     // 分支内的指令
    } else {
        x = -x;        // 另一个分支
    }
    // 如果预测错误，流水线需要清空
}

// 冒险3：结构冒险（Structural Hazard）
void structural_hazard_example() {
    // 两条指令同时需要同一个功能单元
    // 例如：两条除法指令同时执行，但只有一个除法器
    double a = 1.0 / 2.0;
    double b = 3.0 / 4.0;  // 可能需要等待除法器空闲
}
```

## 2. 分支预测与误预测代价

### 2.1 分支预测器类型

```
┌──────────────────────────────────────────────────────────┐
│              分支预测器类型                                │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  1. 静态预测器（编译时）                                  │
│     - 向后分支预测跳转（循环）                            │
│     - 向前分支预测不跳转（if）                            │
│     - 准确率: ~60%                                       │
│                                                          │
│  2. 局部预测器（1-bit / 2-bit饱和计数器）                 │
│     - 记录每个分支的最近历史                              │
│     - 2-bit: 强不跳转→弱不跳转→弱跳转→强跳转             │
│     - 准确率: ~85%                                       │
│                                                          │
│  3. 全局预测器（GShare）                                  │
│     - 利用全局分支历史                                    │
│     - 相关分支之间共享信息                                │
│     - 准确率: ~93%                                       │
│                                                          │
│  4. 混合预测器（Tournament）                              │
│     - 同时运行多种预测器，选择最准的                      │
│     - 现代CPU使用此方案                                  │
│     - 准确率: ~97-99%                                    │
│                                                          │
│  关键：可预测的分支几乎零开销，不可预测的分支代价极高      │
└──────────────────────────────────────────────────────────┘
```

### 2.2 分支预测性能影响实测

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <chrono>
#include <random>

// ============================================
// 经典的分支预测性能演示
// ============================================

// 场景：对数组中大于128的元素求和
// 对比：排序数组（可预测）vs 随机数组（不可预测）

int64_t sum_if_sorted(const std::vector<uint8_t>& data) {
    int64_t sum = 0;
    for (uint8_t val : data) {
        if (val >= 128) {   // 排序后：前半段全不跳，后半段全跳
            sum += val;      // 分支高度可预测
        }
    }
    return sum;
}

int64_t sum_if_random(const std::vector<uint8_t>& data) {
    int64_t sum = 0;
    for (uint8_t val : data) {
        if (val >= 128) {   // 随机数据：分支完全不可预测
            sum += val;      // 分支预测率约50%，大量误预测
        }
    }
    return sum;
}

// 无分支版本：消除分支预测问题
int64_t sum_branchless(const std::vector<uint8_t>& data) {
    int64_t sum = 0;
    for (uint8_t val : data) {
        // 用位运算替代条件分支
        int64_t mask = -(val >= 128);  // 条件为真时mask=-1(全1)，否则0
        sum += val & mask;
    }
    return sum;
}

void branch_prediction_demo() {
    const size_t N = 100000000;
    std::vector<uint8_t> data(N);

    // 生成随机数据
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dist(0, 255);
    for (auto& v : data) v = dist(gen);

    // 测试1：随机数据（分支不可预测）
    {
        auto start = std::chrono::high_resolution_clock::now();
        int64_t sum = sum_if_random(data);
        auto end = std::chrono::high_resolution_clock::now();
        auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
        std::cout << "随机数据(有分支): " << ms << " ms, sum=" << sum << std::endl;
    }

    // 测试2：排序数据（分支可预测）
    {
        std::vector<uint8_t> sorted_data = data;
        std::sort(sorted_data.begin(), sorted_data.end());

        auto start = std::chrono::high_resolution_clock::now();
        int64_t sum = sum_if_sorted(sorted_data);
        auto end = std::chrono::high_resolution_clock::now();
        auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
        std::cout << "排序数据(有分支): " << ms << " ms, sum=" << sum << std::endl;
    }

    // 测试3：无分支版本
    {
        auto start = std::chrono::high_resolution_clock::now();
        int64_t sum = sum_branchless(data);
        auto end = std::chrono::high_resolution_clock::now();
        auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
        std::cout << "随机数据(无分支): " << ms << " ms, sum=" << sum << std::endl;
    }

    // 典型结果：
    // 随机数据(有分支): ~400ms  ← 大量分支误预测
    // 排序数据(有分支): ~100ms  ← 分支高度可预测
    // 随机数据(无分支): ~120ms  ← 无分支，不受数据分布影响
}
```

### 2.3 分支预测与数据模式

```cpp
#include <iostream>
#include <vector>
#include <chrono>

// ============================================
// 不同数据模式对分支预测的影响
// ============================================

// 模式1：完全可预测（全真或全假）
void predictable_pattern() {
    const int N = 100000000;
    std::vector<int> data(N, 1);  // 全部为1

    auto start = std::chrono::high_resolution_clock::now();
    int count = 0;
    for (int val : data) {
        if (val) count++;  // 永远为真，预测准确率100%
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
    std::cout << "全真模式: " << ms << " ms" << std::endl;
}

// 模式2：交替模式（TFTFTF...）
void alternating_pattern() {
    const int N = 100000000;
    std::vector<int> data(N);
    for (int i = 0; i < N; ++i) data[i] = i % 2;

    auto start = std::chrono::high_resolution_clock::now();
    int count = 0;
    for (int val : data) {
        if (val) count++;  // 交替模式，局部预测器可以学会
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
    std::cout << "交替模式: " << ms << " ms" << std::endl;
}

// 模式3：随机模式
void random_pattern() {
    const int N = 100000000;
    std::vector<int> data(N);
    for (int i = 0; i < N; ++i) data[i] = rand() % 2;

    auto start = std::chrono::high_resolution_clock::now();
    int count = 0;
    for (int val : data) {
        if (val) count++;  // 完全随机，预测准确率约50%
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
    std::cout << "随机模式: " << ms << " ms" << std::endl;
}

// 模式4：长周期模式（TTTTFFFFTTTTFFFF...）
void periodic_pattern() {
    const int N = 100000000;
    std::vector<int> data(N);
    for (int i = 0; i < N; ++i) data[i] = (i / 4) % 2;

    auto start = std::chrono::high_resolution_clock::now();
    int count = 0;
    for (int val : data) {
        if (val) count++;  // 周期模式，预测器可以学会
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
    std::cout << "周期模式: " << ms << " ms" << std::endl;
}
```

## 3. __builtin_expect与likely/unlikely

### 3.1 分支提示机制

```cpp
#include <iostream>

// ============================================
// __builtin_expect 原理
// ============================================

// __builtin_expect(expr, value) 告诉编译器expr大概率等于value
// 编译器据此调整分支布局，将大概率执行的代码放在顺序位置

// 定义likely/unlikely宏
#if defined(__GNUC__) || defined(__clang__)
    #define LIKELY(x)   __builtin_expect(!!(x), 1)
    #define UNLIKELY(x) __builtin_expect(!!(x), 0)
#else
    #define LIKELY(x)   (x)
    #define UNLIKELY(x) (x)
#endif

// C++20标准: [[likely]] 和 [[unlikely]] 属性
// if (condition) [[likely]] { ... }
// if (condition) [[unlikely]] { ... }

// ============================================
// 使用场景1：错误检查（错误路径是罕见路径）
// ============================================

int divide(int a, int b) {
    // b为0是罕见情况，标记为unlikely
    if (UNLIKELY(b == 0)) {
        std::cerr << "除零错误" << std::endl;
        return 0;
    }
    return a / b;
}

// ============================================
// 使用场景2：快速路径优化
// ============================================

class HashMap {
public:
    int* find(int key) {
        size_t idx = hash(key) % capacity_;

        // 大部分情况都能找到，标记为likely
        if (LIKELY(slots_[idx].occupied && slots_[idx].key == key)) {
            return &slots_[idx].value;
        }

        // 碰撞处理是罕见情况
        return probe(key);
    }

private:
    struct Slot {
        int key;
        int value;
        bool occupied;
    };

    Slot* slots_;
    size_t capacity_;

    size_t hash(int key) const { return static_cast<size_t>(key); }
    int* probe(int key) { return nullptr; }
};

// ============================================
// 使用场景3：循环条件
// ============================================

template<typename T>
bool binary_search(const T* data, size_t n, T target) {
    size_t lo = 0, hi = n;

    while (LIKELY(lo < hi)) {
        size_t mid = lo + (hi - lo) / 2;

        if (data[mid] == target) return true;

        if (data[mid] < target) {
            lo = mid + 1;
        } else {
            hi = mid;
        }
    }

    return false;
}

// ============================================
// 使用场景4：C++20 [[likely]]/[[unlikely]] 属性
// ============================================

#if __cplusplus >= 202002L

int modern_branch_hint(int value) {
    if (value > 0) [[likely]] {
        return value * 2;  // 常见路径
    } else [[unlikely]] {
        return -value;     // 罕见路径
    }
}

#endif

// likely/unlikely对汇编的影响
// ============================================

    //   ; 正常路径代码在顺序位置（更好的指令缓存利用）
```

## 4. 无分支编程技巧

### 4.1 条件赋值

```cpp
#include <iostream>
#include <algorithm>
#include <cmath>

// ============================================
// 技巧1：条件赋值（cmov）
// ============================================

// 有分支版本
int min_branch(int a, int b) {
    if (a < b) return a;
    else return b;
}

// 无分支版本：三元运算符（编译器可能生成cmov）
int min_branchless(int a, int b) {
    return (a < b) ? a : b;
    // 编译器通常生成: cmp/cmovl 指令
    // cmov = conditional move，无分支预测惩罚
}

// ============================================
// 技巧2：算术条件赋值
// ============================================

// 有分支：根据条件选择值
int select_branch(bool cond, int true_val, int false_val) {
    if (cond) return true_val;
    else return false_val;
}

// 无分支：利用布尔值转整数
int select_branchless(bool cond, int true_val, int false_val) {
    // cond为true时mask=0xFFFFFFFF(-1)，false时mask=0
    int mask = -static_cast<int>(cond);
    return (true_val & mask) | (false_val & ~mask);
}

// ============================================
// 技巧3：条件加法
// ============================================

// 有分支：条件成立时加值
int add_if_branch(int base, int value, bool cond) {
    if (cond) {
        return base + value;
    }
    return base;
}

// 无分支：条件加法
int add_if_branchless(int base, int value, bool cond) {
    // cond为true时加value，false时加0
    return base + (value & (-static_cast<int>(cond)));
}

// ============================================
// 技巧4：条件计数
// ============================================

// 有分支：统计满足条件的元素个数
size_t count_if_branch(const int* data, size_t n, int threshold) {
    size_t count = 0;
    for (size_t i = 0; i < n; ++i) {
        if (data[i] > threshold) {
            count++;
        }
    }
    return count;
}

// 无分支：利用布尔值转整数
size_t count_if_branchless(const int* data, size_t n, int threshold) {
    size_t count = 0;
    for (size_t i = 0; i < n; ++i) {
        // (data[i] > threshold) 为true时结果为1，false时为0
        count += (data[i] > threshold);
    }
    return count;
}

// ============================================
// 技巧5：绝对值
// ============================================

// 有分支
int abs_branch(int x) {
    return (x >= 0) ? x : -x;
}

// 无分支：利用补码特性
int abs_branchless(int x) {
    // x为负时mask=0xFFFFFFFF，正时mask=0
    int mask = x >> 31;  // 算术右移，符号扩展
    return (x ^ mask) - mask;
    // 负数: (x ^ -1) - (-1) = ~x + 1 = -x
    // 正数: (x ^ 0) - 0 = x
}

// ============================================
// 技巧6：Clamp（值域限制）
// ============================================

// 有分支
int clamp_branch(int val, int lo, int hi) {
    if (val < lo) return lo;
    if (val > hi) return hi;
    return val;
}

// 无分支
int clamp_branchless(int val, int lo, int hi) {
    // 先取max(val, lo)，再取min(result, hi)
    // std::min/std::max通常编译为cmov
    return std::max(lo, std::min(val, hi));
}

    std::cout << "add_if(true, 100, 50) = " << add_if_branchless(100, 50, true) << std::endl;
    std::cout << "add_if(false, 100, 50) = " << add_if_branchless(100, 50, false) << std::endl;

    std::cout << "abs(-42) = " << abs_branchless(-42) << std::endl;
    std::cout << "abs(42) = " << abs_branchless(42) << std::endl;

    std::cout << "clamp(150, 0, 100) = " << clamp_branchless(150, 0, 100) << std::endl;
    std::cout << "clamp(-10, 0, 100) = " << clamp_branchless(-10, 0, 100) << std::endl;
    std::cout << "clamp(50, 0, 100) = " << clamp_branchless(50, 0, 100) << std::endl;
```

```cpp
    b = hi;

    int max_ab = std::max(a, b);

    c = max_bc;
```

## 5. 查表法

### 5.1 查表法原理

查表法（Lookup Table）用预先计算好的结果替代运行时计算，消除分支和复杂运算。

```
┌──────────────────────────────────────────────────────────┐
│              查表法 vs 计算                               │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  计算: 输入 → [复杂运算/分支] → 输出                      │
│  查表: 输入 → [数组索引] → 输出                           │
│                                                          │
│  优势:                                                   │
│  - 无分支，无分支预测惩罚                                 │
│  - O(1)时间，与计算复杂度无关                             │
│  - 适合输入范围有限、计算复杂的场景                       │
│                                                          │
│  劣势:                                                   │
│  - 占用内存（特别是输入范围大时）                         │
│  - 表可能超出缓存，导致缓存未命中                         │
│  - 初始化需要时间                                        │
└──────────────────────────────────────────────────────────┘
```

### 5.2 查表法实例

```cpp
#include <iostream>
#include <cstdint>
#include <cstring>
#include <cmath>

// ============================================
// 查表法1：位计数（population count）
// ============================================

// 预计算8位值的位计数
struct PopCountTable {
    uint8_t counts[256];

    constexpr PopCountTable() : counts{} {
        for (int i = 0; i < 256; ++i) {
            int n = i;
            int count = 0;
            while (n) {
                count += n & 1;
                n >>= 1;
            }
            counts[i] = static_cast<uint8_t>(count);
        }
    }
};

// 编译期生成查找表
static constexpr PopCountTable popcount_table;

// 使用查找表计算32位整数的位计数
int popcount_lut(uint32_t x) {
    return popcount_table.counts[x & 0xFF] +
           popcount_table.counts[(x >> 8) & 0xFF] +
           popcount_table.counts[(x >> 16) & 0xFF] +
           popcount_table.counts[(x >> 24) & 0xFF];
}

// ============================================
// 查表法2：字节反转
// ============================================

struct ByteReverseTable {
    uint8_t reversed[256];

    constexpr ByteReverseTable() : reversed{} {
        for (int i = 0; i < 256; ++i) {
            uint8_t val = static_cast<uint8_t>(i);
            uint8_t rev = 0;
            for (int bit = 0; bit < 8; ++bit) {
                rev |= ((val >> bit) & 1) << (7 - bit);
            }
            reversed[i] = rev;
        }
    }
};

static constexpr ByteReverseTable byte_reverse_table;

uint32_t reverse_bits_lut(uint32_t x) {
    return (static_cast<uint32_t>(byte_reverse_table.reversed[x & 0xFF]) << 24) |
           (static_cast<uint32_t>(byte_reverse_table.reversed[(x >> 8) & 0xFF]) << 16) |
           (static_cast<uint32_t>(byte_reverse_table.reversed[(x >> 16) & 0xFF]) << 8) |
           (static_cast<uint32_t>(byte_reverse_table.reversed[(x >> 24) & 0xFF]));
}

// ============================================
// 查表法3：CRC32计算
// ============================================

struct CRC32Table {
    uint32_t table[256];

    constexpr CRC32Table() : table{} {
        for (uint32_t i = 0; i < 256; ++i) {
            uint32_t crc = i;
            for (int j = 0; j < 8; ++j) {
                if (crc & 1) {
                    crc = (crc >> 1) ^ 0xEDB88320;
                } else {
                    crc >>= 1;
                }
            }
            table[i] = crc;
        }
    }
};

static constexpr CRC32Table crc32_table;

uint32_t crc32_lut(const void* data, size_t len) {
    const uint8_t* bytes = static_cast<const uint8_t*>(data);
    uint32_t crc = 0xFFFFFFFF;

    for (size_t i = 0; i < len; ++i) {
        uint8_t idx = static_cast<uint8_t>((crc ^ bytes[i]) & 0xFF);
        crc = (crc >> 8) ^ crc32_table.table[idx];
    }

    return crc ^ 0xFFFFFFFF;
}

// ============================================
// 查表法4：十六进制转换
// ============================================

// 有分支版本
char hex_char_branch(int value) {
    if (value < 10) return '0' + value;
    else return 'A' + (value - 10);
}

// 查表版本
static const char hex_table[] = "0123456789ABCDEF";

char hex_char_lut(int value) {
    return hex_table[value & 0xF];  // 无分支，直接索引
}

// ============================================
// 查表法5：条件映射
// ============================================

// 有分支：根据类型码获取大小
size_t type_size_branch(int type_code) {
    switch (type_code) {
        case 0: return sizeof(char);
        case 1: return sizeof(short);
        case 2: return sizeof(int);
        case 3: return sizeof(long);
        case 4: return sizeof(long long);
        case 5: return sizeof(float);
        case 6: return sizeof(double);
        default: return 0;
    }
}

// 查表版本
static const size_t type_size_table[] = {
    sizeof(char), sizeof(short), sizeof(int),
    sizeof(long), sizeof(long long),
    sizeof(float), sizeof(double)
};

size_t type_size_lut(int type_code) {
    // 边界检查后直接查表
    if (static_cast<size_t>(type_code) < sizeof(type_size_table) / sizeof(type_size_table[0])) {
        return type_size_table[type_code];
    }
    return 0;
}

void lut_demo() {
    std::cout << "=== 查表法演示 ===" << std::endl;

    // 位计数
    std::cout << "popcount(0xFF00FF00) = " << popcount_lut(0xFF00FF00) << std::endl;

    // CRC32
    const char* msg = "Hello, Lookup Table!";
    std::cout << "CRC32 = 0x" << std::hex << crc32_lut(msg, strlen(msg)) << std::dec << std::endl;

    // 十六进制
    std::cout << "hex(15) = " << hex_char_lut(15) << std::endl;
}
```

## 6. 位运算替代条件判断

### 6.1 常用位运算技巧

```cpp
#include <iostream>
#include <cstdint>

// ============================================
// 位运算技巧1：利用符号位生成掩码
// ============================================

// 判断x是否为负数，返回-1（负）或0（非负）
int32_t sign_mask(int32_t x) {
    return x >> 31;  // 算术右移，符号扩展
}

// 条件取反：flag为真时取反，否则不变
int32_t conditional_negate(int32_t x, bool flag) {
    int32_t mask = -static_cast<int32_t>(flag);  // flag为真时mask=-1
    return (x ^ mask) - mask;
    // mask=-1: (x ^ -1) - (-1) = ~x + 1 = -x
    // mask=0:  (x ^ 0) - 0 = x
}

// ============================================
// 位运算技巧2：无分支的最大/最小值
// ============================================

// 无分支min（不使用cmov）
int32_t min_bitwise(int32_t a, int32_t b) {
    int32_t diff = a - b;
    int32_t mask = diff >> 31;  // a<b时mask=-1，否则mask=0
    return b + (diff & mask);
    // a<b: b + (a-b) = a
    // a>=b: b + 0 = b
}

// 无分支max
int32_t max_bitwise(int32_t a, int32_t b) {
    int32_t diff = a - b;
    int32_t mask = diff >> 31;  // a<b时mask=-1，否则mask=0
    return a - (diff & mask);
    // a<b: a - (a-b) = b
    // a>=b: a - 0 = a
}

// 注意：上述方法在a-b溢出时不正确，实际中推荐用std::min/std::max

// ============================================
// 位运算技巧3：对齐计算
// ============================================

// 向上对齐到ALIGN的倍数（ALIGN必须是2的幂）
template<size_t ALIGN>
size_t align_up(size_t value) {
    return (value + ALIGN - 1) & ~(ALIGN - 1);
}

// 向下对齐
template<size_t ALIGN>
size_t align_down(size_t value) {
    return value & ~(ALIGN - 1);
}

// 判断是否已对齐
template<size_t ALIGN>
bool is_aligned(size_t value) {
    return (value & (ALIGN - 1)) == 0;
}

// ============================================
// 位运算技巧4：2的幂次判断
// ============================================

bool is_power_of_2(uint32_t x) {
    return x != 0 && (x & (x - 1)) == 0;
    // 2的幂的二进制只有一个1
    // x-1会将最低的1变为0，其下的0变为1
    // 例如: 8=1000, 7=0111, 8&7=0
}

// 下一个2的幂
uint32_t next_power_of_2(uint32_t x) {
    x--;
    x |= x >> 1;
    x |= x >> 2;
    x |= x >> 4;
    x |= x >> 8;
    x |= x >> 16;
    x++;
    return x;
}

// ============================================
// 位运算技巧5：位域操作
// ============================================

// 提取位域
uint32_t extract_bits(uint32_t value, int start, int length) {
    uint32_t mask = (1U << length) - 1;
    return (value >> start) & mask;
}

// 设置位域
uint32_t set_bits(uint32_t value, int start, int length, uint32_t new_bits) {
    uint32_t mask = (1U << length) - 1;
    value &= ~(mask << start);        // 清除原位域
    value |= (new_bits & mask) << start;  // 设置新值
    return value;
}

// ============================================
// 位运算技巧6：无分支的状态标志管理
// ============================================

class StatusFlags {
public:
    void setFlag(int flag, bool value) {
        if (value) {
            flags_ |= (1U << flag);    // 设置标志
        } else {
            flags_ &= ~(1U << flag);   // 清除标志
        }
    }

    // 无分支版本
    void setFlag_branchless(int flag, bool value) {
        uint32_t mask = 1U << flag;
        // value为true时设置，false时清除
        flags_ = (flags_ & ~mask) | (-static_cast<uint32_t>(value) & mask);
    }

    bool getFlag(int flag) const {
        return (flags_ >> flag) & 1;
    }

    // 无分支：检查是否设置了任一标志
    bool hasAnyFlag(uint32_t mask) const {
        return (flags_ & mask) != 0;
    }

    // 无分支：检查是否设置了所有标志
    bool hasAllFlags(uint32_t mask) const {
        return (flags_ & mask) == mask;
    }

private:
    uint32_t flags_ = 0;
};

// ============================================
```

### 6.2 综合实例：无分支的统计数据结构

```cpp
#include <iostream>
#include <vector>
#include <cstdint>
#include <chrono>

// ============================================
// 无分支的统计直方图
// ============================================

class BranchlessHistogram {
public:
    explicit BranchlessHistogram(int num_bins, int min_val, int max_val)
        : bins_(num_bins, 0)
        , min_val_(min_val)
        , bin_width_((max_val - min_val + num_bins - 1) / num_bins)
    {}

    // 有分支版本
    void add_branch(int value) {
        int bin = (value - min_val_) / bin_width_;
        if (bin < 0) bin = 0;
        if (bin >= static_cast<int>(bins_.size())) bin = bins_.size() - 1;
        bins_[bin]++;
    }

    // 无分支版本
    void add_branchless(int value) {
        int bin = (value - min_val_) / bin_width_;
        // 无分支钳制到[0, size-1]
        bin = std::max(0, std::min(bin, static_cast<int>(bins_.size()) - 1));
        bins_[bin]++;
    }

    const std::vector<int64_t>& bins() const { return bins_; }

private:
    std::vector<int64_t> bins_;
    int min_val_;
    int bin_width_;
};

// ============================================
// 无分支的环形缓冲区索引
// ============================================

template<size_t CAPACITY>  // CAPACITY必须是2的幂
class BranchlessRingBuffer {
public:
    BranchlessRingBuffer() : head_(0), tail_(0) {
        static_assert((CAPACITY & (CAPACITY - 1)) == 0, "CAPACITY必须是2的幂");
    }

    bool push(int value) {
        if (size() >= CAPACITY) return false;
        buffer_[head_ & (CAPACITY - 1)] = value;  // 位运算取模，无分支
        head_++;
        return true;
    }

    bool pop(int& value) {
        if (size() == 0) return false;
        value = buffer_[tail_ & (CAPACITY - 1)];  // 位运算取模，无分支
        tail_++;
        return true;
    }

    size_t size() const { return head_ - tail_; }
    bool empty() const { return head_ == tail_; }

private:
    int buffer_[CAPACITY];
    size_t head_;
    size_t tail_;
};

void branchless_structures_demo() {
    // 环形缓冲区
    BranchlessRingBuffer<16> ring;
    for (int i = 0; i < 10; ++i) ring.push(i);

    int val;
    while (ring.pop(val)) {
        std::cout << val << " ";
    }
    std::cout << std::endl;
}
```

## 7. 小结

### 核心要点回顾

| 技术 | 原理 | 适用场景 |
|------|------|---------|
| **likely/unlikely** | 调整代码布局，改善指令缓存 | 错误检查、快速路径 |
| **cmov** | 条件移动指令，无分支预测惩罚 | 简单条件赋值 |
| **算术掩码** | 布尔值转整数掩码 | 条件加法、条件赋值 |
| **查表法** | 预计算结果，运行时直接索引 | 输入范围有限的复杂计算 |
| **位运算** | 利用补码和位操作 | 绝对值、对齐、取模 |
| **排序网络** | 固定的比较交换序列 | 小数组排序 |

### 分支优化决策树

```
遇到条件分支？
├── 分支高度可预测？ → 保持分支（likely/unlikely提示）
├── 简单条件赋值？ → 三元运算符（cmov）
├── 条件加法/计数？ → 算术掩码
├── 输入范围有限？ → 查表法
├── 取模运算？ → 位运算（2的幂大小）
├── 小数组排序？ → 排序网络
└── 复杂逻辑？ → 考虑数据重排使分支可预测
```

### 性能优化检查清单

```
□ 是否有随机不可预测的分支？
□ 是否可以用cmov替代条件赋值？
□ 是否可以用算术掩码替代条件加法？
□ 是否可以用查表法替代复杂计算？
□ 是否使用了likely/unlikely提示？
□ 是否将数据排序使分支可预测？
□ 是否用位运算替代了取模运算？
```
