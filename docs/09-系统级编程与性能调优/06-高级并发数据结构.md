> 💡 **通俗理解 - 为什么需要高级并发数据结构？**

**传统加锁 = 红绿灯**
- 同一时刻只有一个方向通行
- 绿灯方向空了，红灯方向也得等
- 红绿灯坏了（死锁），全部堵死

**无锁数据结构 = 立交桥**
- 各方向独立通行，互不干扰
- 没有红绿灯，不需要等待
- 即使一个方向堵了，其他方向照走

**但立交桥更复杂：**
- 设计难度大（正确性难以保证）
- 建造成本高（代码复杂）
- 需要特殊维护（内存回收）

> 🔬 **抽象理解 - 高级并发数据结构的本质**：
>
> - **核心目标**：减少或消除线程间的阻塞，最大化并行度
> - **关键挑战**：正确性（ABA问题、内存回收）、性能（缓存友好性）
> - **核心技术**：CAS、Hazard Pointer、Epoch-based回收、RCU
> - **适用场景**：高并发读多写少、低延迟要求

## 1. 无锁队列(Michael-Scott)

### 1.1 Michael-Scott队列原理

Michael-Scott队列（MSQueue）是最经典的无锁FIFO队列，由Maged Michael和Michael Scott于1996年提出。

```
┌──────────────────────────────────────────────────────────┐
│           Michael-Scott队列结构                           │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  Sentinel ──→ Node1 ──→ Node2 ──→ Node3 ──→ nullptr     │
│     ↑                                          ↑         │
│   head                                        tail       │
│                                                          │
│  入队(enqueue): 在tail后添加新节点，CAS更新tail          │
│  出队(dequeue): 取head的下一个节点，CAS更新head          │
│                                                          │
│  关键设计:                                               │
│  1. 哑节点(sentinel): head始终指向哑节点，避免空队列特判  │
│  2. 两步CAS: 入队时先链接节点，再更新tail               │
│  3. 帮助机制: 其他线程可以帮助完成未完成的tail更新        │
└──────────────────────────────────────────────────────────┘
```

### 1.2 MSQueue实现

```cpp
#include <iostream>
#include <atomic>
#include <memory>
#include <optional>

// ============================================
// Michael-Scott无锁队列
// ============================================

template<typename T>
class MSQueue {
private:
    struct Node {
        std::atomic<Node*> next{nullptr};
        T data;

        Node() = default;  // 哑节点
        explicit Node(const T& val) : data(val) {}
    };

    alignas(64) std::atomic<Node*> head_;
    alignas(64) std::atomic<Node*> tail_;

public:
    MSQueue() {
        Node* sentinel = new Node();  // 哑节点
        head_.store(sentinel, std::memory_order_relaxed);
        tail_.store(sentinel, std::memory_order_relaxed);
    }

    ~MSQueue() {
        // 清空队列
        while (dequeue().has_value()) {}
        // 删除哑节点
        delete head_.load();
    }

    // 入队
    void enqueue(const T& value) {
        Node* new_node = new Node(value);

        while (true) {
            Node* t = tail_.load(std::memory_order_acquire);
            Node* next = t->next.load(std::memory_order_acquire);

            // 检查tail是否仍然指向t（可能已被其他线程修改）
            if (t == tail_.load(std::memory_order_acquire)) {
                if (next == nullptr) {
                    // tail的next为空，尝试链接新节点
                    Node* null_ptr = nullptr;
                    if (t->next.compare_exchange_weak(
                            null_ptr, new_node,
                            std::memory_order_release,
                            std::memory_order_relaxed)) {
                        // 链接成功，尝试更新tail
                        // 即使CAS失败也没关系，其他线程会帮忙更新
                        tail_.compare_exchange_strong(
                            t, new_node,
                            std::memory_order_release,
                            std::memory_order_relaxed);
                        return;
                    }
                } else {
                    // tail落后了，帮助推进tail
                    tail_.compare_exchange_strong(
                        t, next,
                        std::memory_order_release,
                        std::memory_order_relaxed);
                }
            }
        }
    }

    // 出队
    std::optional<T> dequeue() {
        while (true) {
            Node* h = head_.load(std::memory_order_acquire);
            Node* t = tail_.load(std::memory_order_acquire);
            Node* next = h->next.load(std::memory_order_acquire);

            // 检查head是否仍然指向h
            if (h == head_.load(std::memory_order_acquire)) {
                if (h == t) {
                    // 队列为空或tail落后
                    if (next == nullptr) {
                        // 队列确实为空
                        return std::nullopt;
                    }
                    // tail落后，帮助推进
                    tail_.compare_exchange_strong(
                        t, next,
                        std::memory_order_release,
                        std::memory_order_relaxed);
                } else {
                    // 队列非空，尝试取出头元素
                    T value = next->data;  // 先读取数据
                    if (head_.compare_exchange_weak(
                            h, next,
                            std::memory_order_release,
                            std::memory_order_relaxed)) {
                        // 成功取出，旧的哑节点可以安全删除
                        // 注意：在无锁环境中，不能立即delete！
                        // 需要使用Hazard Pointer或Epoch-based回收
                        // 这里简化处理，实际生产代码需要安全回收
                        return value;
                    }
                }
            }
        }
    }

    bool empty() const {
        Node* h = head_.load(std::memory_order_acquire);
        Node* t = tail_.load(std::memory_order_acquire);
        Node* next = h->next.load(std::memory_order_acquire);
        return (h == t) && (next == nullptr);
    }
};

// ============================================
// 使用示例
// ============================================

void msqueue_demo() {
    MSQueue<int> queue;

    // 单线程测试
    for (int i = 0; i < 10; ++i) {
        queue.enqueue(i);
    }

    while (auto val = queue.dequeue()) {
        std::cout << *val << " ";
    }
    std::cout << std::endl;

    // 多线程测试
    const int PRODUCERS = 4;
    const int CONSUMERS = 4;
    const int ITEMS = 100000;

    std::atomic<int> total_consumed{0};
    std::atomic<int64_t> sum{0};

    // 生产者线程
    std::vector<std::thread> producers;
    for (int p = 0; p < PRODUCERS; ++p) {
        producers.emplace_back([&queue, p]() {
            for (int i = 0; i < ITEMS; ++i) {
                queue.enqueue(p * ITEMS + i);
            }
        });
    }

    // 消费者线程
    std::vector<std::thread> consumers;
    for (int c = 0; c < CONSUMERS; ++c) {
        consumers.emplace_back([&queue, &total_consumed, &sum]() {
            int local_count = 0;
            int64_t local_sum = 0;
            while (total_consumed.load(std::memory_order_relaxed) < PRODUCERS * ITEMS) {
                auto val = queue.dequeue();
                if (val.has_value()) {
                    local_sum += *val;
                    local_count++;
                    total_consumed.fetch_add(1, std::memory_order_relaxed);
                }
            }
            sum.fetch_add(local_sum, std::memory_order_relaxed);
        });
    }

    for (auto& t : producers) t.join();
    for (auto& t : consumers) t.join();

    std::cout << "总消费: " << total_consumed.load() << std::endl;
}
```

## 2. 无锁哈希表

### 2.1 基于开放寻址的无锁哈希表

```cpp
#include <iostream>
#include <atomic>
#include <vector>
#include <optional>

// ============================================
// 无锁哈希表（基于开放寻址法）
// ============================================

template<typename Key, typename Value>
class LockFreeHashTable {
private:
    enum class SlotState : uint32_t {
        EMPTY = 0,
        OCCUPIED = 1,
        DELETED = 2
    };

    struct Slot {
        std::atomic<SlotState> state{SlotState::EMPTY};
        Key key{};
        Value value{};

        Slot() = default;
    };

    std::vector<Slot> table_;
    size_t capacity_;
    std::atomic<size_t> size_{0};

    // 哈希函数
    size_t hash(const Key& key) const {
        size_t h = std::hash<Key>{}(key);
        return h & (capacity_ - 1);
    }

public:
    explicit LockFreeHashTable(size_t capacity = 1024)
        : capacity_(1) {
        // 容量对齐到2的幂
        while (capacity_ < capacity) capacity_ <<= 1;
        table_.resize(capacity_);
    }

    // 插入
    bool insert(const Key& key, const Value& value) {
        size_t idx = hash(key);

        for (size_t probe = 0; probe < capacity_; ++probe) {
            size_t i = (idx + probe) & (capacity_ - 1);
            Slot& slot = table_[i];

            SlotState state = slot.state.load(std::memory_order_acquire);

            if (state == SlotState::EMPTY) {
                // 尝试占用空槽
                SlotState expected = SlotState::EMPTY;
                if (slot.state.compare_exchange_strong(
                        expected, SlotState::OCCUPIED,
                        std::memory_order_acq_rel,
                        std::memory_order_acquire)) {
                    slot.key = key;
                    slot.value = value;
                    size_.fetch_add(1, std::memory_order_relaxed);
                    return true;
                }
                // CAS失败，重新检查
                state = slot.state.load(std::memory_order_acquire);
            }

            if (state == SlotState::OCCUPIED && slot.key == key) {
                // 键已存在，更新值
                slot.value = value;
                return true;
            }

            // DELETED或冲突，继续探测
        }

        return false;  // 表满
    }

    // 查找
    std::optional<Value> find(const Key& key) const {
        size_t idx = hash(key);

        for (size_t probe = 0; probe < capacity_; ++probe) {
            size_t i = (idx + probe) & (capacity_ - 1);
            const Slot& slot = table_[i];

            SlotState state = slot.state.load(std::memory_order_acquire);

            if (state == SlotState::EMPTY) {
                return std::nullopt;  // 未找到
            }

            if (state == SlotState::OCCUPIED && slot.key == key) {
                return slot.value;
            }

            // DELETED或冲突，继续探测
        }

        return std::nullopt;
    }

    // 删除
    bool erase(const Key& key) {
        size_t idx = hash(key);

        for (size_t probe = 0; probe < capacity_; ++probe) {
            size_t i = (idx + probe) & (capacity_ - 1);
            Slot& slot = table_[i];

            SlotState state = slot.state.load(std::memory_order_acquire);

            if (state == SlotState::EMPTY) {
                return false;  // 未找到
            }

            if (state == SlotState::OCCUPIED && slot.key == key) {
                // 标记为已删除（逻辑删除）
                SlotState expected = SlotState::OCCUPIED;
                if (slot.state.compare_exchange_strong(
                        expected, SlotState::DELETED,
                        std::memory_order_acq_rel,
                        std::memory_order_acquire)) {
                    size_.fetch_sub(1, std::memory_order_relaxed);
                    return true;
                }
            }

            // 继续探测
        }

        return false;
    }

    size_t size() const {
        return size_.load(std::memory_order_relaxed);
    }
};

// ============================================
// 使用示例
// ============================================

void lockfree_hashtable_demo() {
    LockFreeHashTable<int, std::string> table(256);

    // 插入
    table.insert(1, "Hello");
    table.insert(2, "World");
    table.insert(42, "Answer");

    // 查找
    if (auto val = table.find(1)) {
        std::cout << "key=1: " << *val << std::endl;
    }
    if (auto val = table.find(42)) {
        std::cout << "key=42: " << *val << std::endl;
    }

    // 删除
    table.erase(2);
    if (!table.find(2).has_value()) {
        std::cout << "key=2 已删除" << std::endl;
    }

    std::cout << "大小: " << table.size() << std::endl;
}
```

## 3. Hazard Pointer

### 3.1 Hazard Pointer原理

Hazard Pointer是无锁编程中解决内存回收问题的经典方案。

```
┌──────────────────────────────────────────────────────────┐
│           Hazard Pointer工作原理                          │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  线程1的Hazard Pointer:                                  │
│  ┌─────────────┐                                        │
│  │ hp1 → NodeA │  ← 线程1声明"我正在用NodeA"            │
│  └─────────────┘                                        │
│                                                          │
│  线程2的Hazard Pointer:                                  │
│  ┌─────────────┐                                        │
│  │ hp2 → NodeC │  ← 线程2声明"我正在用NodeC"            │
│  └─────────────┘                                        │
│                                                          │
│  退休列表(retired list):                                 │
│  [NodeA, NodeB, NodeC, NodeD]                           │
│                                                          │
│  回收过程:                                               │
│  1. 扫描所有Hazard Pointer                               │
│  2. NodeA在hp1中 → 不能回收                              │
│  3. NodeB不在任何hp中 → 可以回收！                       │
│  4. NodeC在hp2中 → 不能回收                              │
│  5. NodeD不在任何hp中 → 可以回收！                       │
└──────────────────────────────────────────────────────────┘
```

### 3.2 Hazard Pointer实现

```cpp
#include <iostream>
#include <atomic>
#include <vector>
#include <array>
#include <thread>

// ============================================
// Hazard Pointer实现
// ============================================

template<typename T>
class HazardPointerManager {
private:
    static constexpr size_t MAX_HAZARD_POINTERS = 128;
    static constexpr size_t MAX_THREADS = 64;
    static constexpr size_t HP_PER_THREAD = 2;
    static constexpr size_t RETIRE_THRESHOLD = MAX_HAZARD_POINTERS * 2;

    // Hazard Pointer记录
    struct HPRecord {
        std::atomic<T*> pointer{nullptr};
        std::atomic<bool> active{false};
    };

    // 每个线程的退休列表
    struct RetiredList {
        std::vector<T*> nodes;
        std::atomic<size_t> count{0};
    };

    // 全局Hazard Pointer数组
    static inline std::array<HPRecord, MAX_HAZARD_POINTERS> hp_records_;

    // 每线程退休列表
    static inline std::array<RetiredList, MAX_THREADS> retired_lists_;

    // 线程本地存储：当前线程使用的HP索引
    static inline thread_local int tl_hp_indices_[HP_PER_THREAD] = {-1, -1};
    static inline thread_local int tl_thread_id_ = -1;
    static inline thread_local size_t tl_retired_count_ = 0;

    static std::atomic<int> next_thread_id_;

    // 获取线程ID
    static int getThreadId() {
        if (tl_thread_id_ < 0) {
            tl_thread_id_ = next_thread_id_.fetch_add(1);
        }
        return tl_thread_id_;
    }

public:
    // 获取一个Hazard Pointer
    static T** acquire(int hp_index = 0) {
        if (tl_hp_indices_[hp_index] < 0) {
            // 寻找一个空闲的HP记录
            for (size_t i = 0; i < MAX_HAZARD_POINTERS; ++i) {
                bool expected = false;
                if (hp_records_[i].active.compare_exchange_strong(
                        expected, true,
                        std::memory_order_acq_rel)) {
                    tl_hp_indices_[hp_index] = static_cast<int>(i);
                    break;
                }
            }
        }
        return &hp_records_[tl_hp_indices_[hp_index]].pointer;
    }

    // 释放Hazard Pointer
    static void release(int hp_index = 0) {
        if (tl_hp_indices_[hp_index] >= 0) {
            hp_records_[tl_hp_indices_[hp_index]].pointer.store(
                nullptr, std::memory_order_release);
        }
    }

    // 退休一个节点（延迟删除）
    static void retire(T* node) {
        int tid = getThreadId();
        retired_lists_[tid].nodes.push_back(node);
        retired_lists_[tid].count.fetch_add(1, std::memory_order_relaxed);
        tl_retired_count_++;

        // 当退休列表超过阈值时，尝试回收
        if (tl_retired_count_ >= RETIRE_THRESHOLD) {
            scanAndReclaim();
        }
    }

    // 扫描并回收安全的节点
    static void scanAndReclaim() {
        int tid = getThreadId();

        // 1. 收集所有活跃的Hazard Pointer
        std::vector<T*> hazard_pointers;
        for (size_t i = 0; i < MAX_HAZARD_POINTERS; ++i) {
            T* p = hp_records_[i].pointer.load(std::memory_order_acquire);
            if (p != nullptr) {
                hazard_pointers.push_back(p);
            }
        }

        // 2. 遍历退休列表，回收不在hazard_pointers中的节点
        std::vector<T*> remaining;
        for (T* node : retired_lists_[tid].nodes) {
            bool is_hazardous = false;
            for (T* hp : hazard_pointers) {
                if (node == hp) {
                    is_hazardous = true;
                    break;
                }
            }

            if (is_hazardous) {
                remaining.push_back(node);  // 仍在使用，保留
            } else {
                delete node;  // 安全回收
            }
        }

        // 3. 更新退休列表
        retired_lists_[tid].nodes = std::move(remaining);
        tl_retired_count_ = retired_lists_[tid].nodes.size();
    }
};

template<typename T>
std::atomic<int> HazardPointerManager<T>::next_thread_id_{0};

// ============================================
// 使用Hazard Pointer的安全无锁栈
// ============================================

template<typename T>
class LockFreeStack {
private:
    struct Node {
        T data;
        std::atomic<Node*> next{nullptr};

        explicit Node(const T& val) : data(val) {}
    };

    std::atomic<Node*> head_{nullptr};

public:
    void push(const T& value) {
        Node* new_node = new Node(value);
        new_node->next.store(head_.load(std::memory_order_relaxed),
                            std::memory_order_relaxed);

        while (!head_.compare_exchange_weak(
                new_node->next, new_node,
                std::memory_order_release,
                std::memory_order_relaxed)) {
            // CAS失败，new_node->next已自动更新
        }
    }

    std::optional<T> pop() {
        // 获取Hazard Pointer
        Node** hp = HazardPointerManager<Node>::acquire(0);

        Node* old_head;
        while (true) {
            old_head = head_.load(std::memory_order_acquire);
            *hp = old_head;  // 设置Hazard Pointer保护

            // 再次检查head是否改变
            if (old_head != head_.load(std::memory_order_acquire)) {
                continue;  // head已变，重试
            }

            if (old_head == nullptr) {
                HazardPointerManager<Node>::release(0);
                return std::nullopt;  // 栈空
            }

            if (head_.compare_exchange_weak(
                    old_head, old_head->next.load(std::memory_order_relaxed),
                    std::memory_order_acq_rel,
                    std::memory_order_relaxed)) {
                break;  // 成功弹出
            }
        }

        // 读取数据
        T value = std::move(old_head->data);

        // 释放Hazard Pointer
        HazardPointerManager<Node>::release(0);

        // 退休旧节点（延迟删除）
        HazardPointerManager<Node>::retire(old_head);

        return value;
    }
};

void hazard_pointer_demo() {
    LockFreeStack<int> stack;

    // 多线程压栈和弹栈
    std::vector<std::thread> threads;
    for (int t = 0; t < 4; ++t) {
        threads.emplace_back([&stack, t]() {
            for (int i = 0; i < 1000; ++i) {
                stack.push(t * 1000 + i);
            }
            for (int i = 0; i < 500; ++i) {
                stack.pop();
            }
        });
    }

    for (auto& th : threads) th.join();

    std::cout << "Hazard Pointer保护的栈操作完成" << std::endl;
}
```

## 4. Epoch-based回收

### 4.1 Epoch-based原理

```
┌──────────────────────────────────────────────────────────┐
│           Epoch-based回收原理                             │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  全局Epoch: 1 → 2 → 3 → 1 → 2 → 3 → ...               │
│                                                          │
│  线程1: [Epoch=2] 正在读取...                            │
│  线程2: [Epoch=2] 正在读取...                            │
│  线程3: [Epoch=1] 正在读取... (较慢)                     │
│                                                          │
│  退休列表:                                               │
│  Epoch 1: [NodeA, NodeB]  ← 不能回收(线程3还在Epoch1)   │
│  Epoch 2: [NodeC]         ← 不能回收(有线程在Epoch2)    │
│  Epoch 0: [NodeD]         ← 可以回收！(没有线程在Epoch0) │
│                                                          │
│  规则: 只有当所有线程都离开了Epoch N时，                 │
│        Epoch N-1及更早的退休节点才能安全回收              │
│                                                          │
│  优势: 批量回收，比Hazard Pointer更高效                  │
│  劣势: 延迟可能更大（需要等所有线程离开旧Epoch）         │
└──────────────────────────────────────────────────────────┘
```

### 4.2 Epoch-based实现

```cpp
#include <iostream>
#include <atomic>
#include <vector>
#include <array>
#include <thread>

// ============================================
// Epoch-based回收实现
// ============================================

class EpochReclaimer {
private:
    static constexpr size_t NUM_EPOCHS = 3;
    static constexpr size_t MAX_THREADS = 64;
    static constexpr size_t RETIRE_THRESHOLD = 100;

    // 全局Epoch
    static inline std::atomic<size_t> global_epoch_{0};

    // 每线程的Epoch记录
    struct ThreadEpoch {
        std::atomic<size_t> epoch{0};
        std::atomic<bool> active{false};
    };

    static inline std::array<ThreadEpoch, MAX_THREADS> thread_epochs_;

    // 退休节点
    struct RetiredNode {
        void* node;
        void (*deleter)(void*);
        size_t epoch;
    };

    // 每线程退休列表
    static inline std::array<std::vector<RetiredNode>, MAX_THREADS> retired_lists_;

    static inline std::atomic<int> next_thread_id_{0};
    static inline thread_local int tl_thread_id_ = -1;
    static inline thread_local size_t tl_retired_count_ = 0;

public:
    // 进入临界区
    static void enter() {
        int tid = getThreadId();
        size_t current_epoch = global_epoch_.load(std::memory_order_acquire);
        thread_epochs_[tid].epoch.store(current_epoch, std::memory_order_release);
        thread_epochs_[tid].active.store(true, std::memory_order_release);
    }

    // 离开临界区
    static void leave() {
        int tid = getThreadId();
        thread_epochs_[tid].active.store(false, std::memory_order_release);
    }

    // 退休一个节点
    template<typename T>
    static void retire(T* node) {
        int tid = getThreadId();
        size_t current_epoch = global_epoch_.load(std::memory_order_acquire);

        retired_lists_[tid].push_back({
            static_cast<void*>(node),
            [](void* p) { delete static_cast<T*>(p); },
            current_epoch
        });

        tl_retired_count_++;

        // 尝试推进全局Epoch并回收
        if (tl_retired_count_ >= RETIRE_THRESHOLD) {
            tryAdvanceEpoch();
            tryReclaim();
        }
    }

private:
    static int getThreadId() {
        if (tl_thread_id_ < 0) {
            tl_thread_id_ = next_thread_id_.fetch_add(1);
        }
        return tl_thread_id_;
    }

    // 尝试推进全局Epoch
    static void tryAdvanceEpoch() {
        size_t current = global_epoch_.load(std::memory_order_acquire);

        // 检查所有活跃线程是否都在当前Epoch
        bool all_current = true;
        for (size_t i = 0; i < MAX_THREADS; ++i) {
            if (thread_epochs_[i].active.load(std::memory_order_acquire)) {
                if (thread_epochs_[i].epoch.load(std::memory_order_acquire) != current) {
                    all_current = false;
                    break;
                }
            }
        }

        if (all_current) {
            // 所有线程都在当前Epoch，可以推进
            size_t next = (current + 1) % NUM_EPOCHS;
            global_epoch_.compare_exchange_strong(
                current, next,
                std::memory_order_acq_rel);
        }
    }

    // 尝试回收安全的节点
    static void tryReclaim() {
        int tid = getThreadId();
        size_t current = global_epoch_.load(std::memory_order_acquire);

        // 计算安全Epoch：比所有活跃线程的Epoch都旧
        size_t min_active_epoch = current;
        for (size_t i = 0; i < MAX_THREADS; ++i) {
            if (thread_epochs_[i].active.load(std::memory_order_acquire)) {
                size_t te = thread_epochs_[i].epoch.load(std::memory_order_acquire);
                if (te < min_active_epoch) {
                    min_active_epoch = te;
                }
            }
        }

        // 回收比min_active_epoch更旧的节点
        std::vector<RetiredNode> remaining;
        for (auto& rn : retired_lists_[tid]) {
            // 简化的判断：Epoch距离超过2则安全
            size_t age = (current - rn.epoch + NUM_EPOCHS) % NUM_EPOCHS;
            if (age >= 2) {
                rn.deleter(rn.node);  // 安全回收
            } else {
                remaining.push_back(rn);
            }
        }

        retired_lists_[tid] = std::move(remaining);
        tl_retired_count_ = retired_lists_[tid].size();
    }
};

// ============================================
// 使用Epoch的安全无锁链表
// ============================================

template<typename T>
class EpochLockFreeList {
private:
    struct Node {
        T data;
        std::atomic<Node*> next{nullptr};
        explicit Node(const T& val) : data(val) {}
    };

    std::atomic<Node*> head_{nullptr};

public:
    void insert(const T& value) {
        Node* new_node = new Node(value);
        new_node->next.store(head_.load(std::memory_order_relaxed));

        while (!head_.compare_exchange_weak(
                new_node->next, new_node,
                std::memory_order_release,
                std::memory_order_relaxed)) {}
    }

    bool remove(const T& value) {
        EpochReclaimer::enter();

        Node* prev = nullptr;
        Node* curr = head_.load(std::memory_order_acquire);

        while (curr) {
            if (curr->data == value) {
                // 找到目标，执行删除
                if (prev == nullptr) {
                    Node* expected = curr;
                    if (!head_.compare_exchange_strong(
                            expected, curr->next.load(),
                            std::memory_order_acq_rel)) {
                        EpochReclaimer::leave();
                        return false;
                    }
                } else {
                    prev->next.store(curr->next.load(),
                                    std::memory_order_release);
                }

                // 退休节点
                EpochReclaimer::retire(curr);
                EpochReclaimer::leave();
                return true;
            }
            prev = curr;
            curr = curr->next.load(std::memory_order_acquire);
        }

        EpochReclaimer::leave();
        return false;
    }

    bool contains(const T& value) const {
        EpochReclaimer::enter();

        Node* curr = head_.load(std::memory_order_acquire);
        while (curr) {
            if (curr->data == value) {
                EpochReclaimer::leave();
                return true;
            }
            curr = curr->next.load(std::memory_order_acquire);
        }

        EpochReclaimer::leave();
        return false;
    }
};
```

## 5. RCU(Read-Copy-Update)

### 5.1 RCU原理

```
┌──────────────────────────────────────────────────────────┐
│              RCU工作原理                                  │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  1. 读取端（极低开销）                                   │
│     ┌──────────┐                                         │
│     │ rcu_read_lock()  │  ← 几乎零开销(仅禁用抢占)      │
│     │ 读取共享数据      │  ← 直接读取，无需加锁          │
│     │ rcu_read_unlock()│  ← 几乎零开销                   │
│     └──────────┘                                         │
│                                                          │
│  2. 更新端                                               │
│     ┌──────────────────────────┐                         │
│     │ 1. 创建数据副本           │                         │
│     │ 2. 修改副本               │                         │
│     │ 3. 原子替换指针           │  ← 读者立即看到新数据   │
│     │ 4. 等待所有读者退出       │  ← synchronize_rcu()   │
│     │ 5. 释放旧数据             │                         │
│     └──────────────────────────┘                         │
│                                                          │
│  核心优势:                                               │
│  - 读取零开销（无锁、无原子操作）                        │
│  - 适用于读多写少场景                                    │
│  - Linux内核大量使用                                     │
└──────────────────────────────────────────────────────────┘
```

### 5.2 用户态RCU实现

```cpp
#include <iostream>
#include <atomic>
#include <vector>
#include <thread>
#include <chrono>

// ============================================
// 简化的用户态RCU实现
// ============================================

class UserspaceRCU {
private:
    static constexpr size_t MAX_THREADS = 64;

    // 每线程的读取端计数器
    struct ReadCounter {
        std::atomic<size_t> count{0};  // >0表示在读端临界区
        char padding[56];              // 避免false sharing
    };

    static inline std::array<ReadCounter, MAX_THREADS> counters_;
    static inline std::atomic<int> next_thread_id_{0};
    static inline thread_local int tl_thread_id_ = -1;

    static int getThreadId() {
        if (tl_thread_id_ < 0) {
            tl_thread_id_ = next_thread_id_.fetch_add(1);
        }
        return tl_thread_id_;
    }

public:
    // 读取端加锁（几乎零开销）
    static void readLock() {
        int tid = getThreadId();
        counters_[tid].count.fetch_add(1, std::memory_order_acquire);
    }

    // 读取端解锁
    static void readUnlock() {
        int tid = getThreadId();
        counters_[tid].count.fetch_sub(1, std::memory_order_release);
    }

    // 等待所有读者退出（写端调用）
    static void synchronize() {
        // 记录所有活跃读者的计数
        std::vector<size_t> snapshots(MAX_THREADS);
        for (int i = 0; i < MAX_THREADS; ++i) {
            snapshots[i] = counters_[i].count.load(std::memory_order_acquire);
        }

        // 等待所有活跃读者退出
        for (int i = 0; i < MAX_THREADS; ++i) {
            if (snapshots[i] > 0) {
                while (counters_[i].count.load(std::memory_order_acquire) > 0) {
                    std::this_thread::yield();
                }
            }
        }
    }

    // 延迟回调（在所有读者退出后执行）
    template<typename T>
    static void call(T&& func) {
        synchronize();
        func();
    }
};

// ============================================
// RCU保护的链表
// ============================================

template<typename T>
class RCUList {
private:
    struct Node {
        T data;
        Node* next;
        explicit Node(const T& val) : data(val), next(nullptr) {}
    };

    std::atomic<Node*> head_{nullptr};

public:
    // 读取（无锁，零开销）
    bool contains(const T& value) const {
        UserspaceRCU::readLock();

        Node* curr = head_.load(std::memory_order_acquire);
        bool found = false;
        while (curr) {
            if (curr->data == value) {
                found = true;
                break;
            }
            curr = curr->next;
        }

        UserspaceRCU::readUnlock();
        return found;
    }

    // 插入（Copy-Update）
    void insert(const T& value) {
        Node* new_node = new Node(value);
        new_node->next = head_.load(std::memory_order_acquire);

        // 原子替换head指针
        while (!head_.compare_exchange_weak(
                new_node->next, new_node,
                std::memory_order_release,
                std::memory_order_relaxed)) {}
    }

    // 删除（Copy-Update）
    bool remove(const T& value) {
        // 第1步：找到要删除的节点
        Node* prev = nullptr;
        Node* curr = head_.load(std::memory_order_acquire);

        while (curr && curr->data != value) {
            prev = curr;
            curr = curr->next;
        }

        if (!curr) return false;

        // 第2步：创建新链表（复制受影响的部分）
        // 对于简单实现，直接修改指针
        if (prev == nullptr) {
            Node* expected = curr;
            if (!head_.compare_exchange_strong(
                    expected, curr->next,
                    std::memory_order_acq_rel)) {
                return false;
            }
        } else {
            prev->next = curr->next;
        }

        // 第3步：等待所有读者退出，然后释放旧节点
        UserspaceRCU::call([curr]() {
            delete curr;
        });

        return true;
    }

    // 遍历（读取端）
    template<typename Func>
    void forEach(Func func) const {
        UserspaceRCU::readLock();

        Node* curr = head_.load(std::memory_order_acquire);
        while (curr) {
            func(curr->data);
            curr = curr->next;
        }

        UserspaceRCU::readUnlock();
    }
};

void rcu_demo() {
    RCUList<int> list;

    // 插入数据
    for (int i = 0; i < 10; ++i) {
        list.insert(i);
    }

    // 并发读取（零开销）
    std::vector<std::thread> readers;
    for (int r = 0; r < 4; ++r) {
        readers.emplace_back([&list]() {
            for (int i = 0; i < 1000; ++i) {
                list.contains(5);  // 无锁读取
            }
        });
    }

    // 并发写入
    std::thread writer([&list]() {
        for (int i = 10; i < 20; ++i) {
            list.insert(i);
        }
    });

    for (auto& t : readers) t.join();
    writer.join();

    std::cout << "RCU保护的链表操作完成" << std::endl;
}
```

## 6. 乐观并发控制

### 6.1 乐观锁原理

```cpp
#include <iostream>
#include <atomic>
#include <cstdint>

// ============================================
// 乐观并发控制
// ============================================

// 核心思想：假设冲突很少，先执行操作，最后检查是否有冲突

template<typename T>
class OptimisticValue {
private:
    std::atomic<uint64_t> version_{0};
    T value_;

public:
    // 读取（乐观）
    struct Snapshot {
        T value;
        uint64_t version;
    };

    Snapshot read() const {
        uint64_t v1, v2;
        T val;

        do {
            v1 = version_.load(std::memory_order_acquire);
            val = value_;  // 读取值
            v2 = version_.load(std::memory_order_acquire);
            // 如果版本号不同，说明读取期间被修改，需要重试
        } while (v1 != v2);

        return {val, v1};
    }

    // 写入（乐观）
    bool write(const T& new_value, uint64_t expected_version) {
        // 尝试更新版本号
        uint64_t expected = expected_version;
        if (!version_.compare_exchange_strong(
                expected, expected_version + 1,
                std::memory_order_acq_rel)) {
            return false;  // 版本号不匹配，有其他写入
        }

        value_ = new_value;
        version_.fetch_add(1, std::memory_order_release);
        return true;
    }

    // 乐观更新（读取-修改-写入）
    template<typename Func>
    bool update(Func modifier) {
        while (true) {
            Snapshot snap = read();
            T new_value = modifier(snap.value);

            if (write(new_value, snap.version)) {
                return true;
            }
            // 冲突，重试
        }
    }
};

// ============================================
// 乐观并发哈希表
// ============================================

template<typename Key, typename Value>
class OptimisticHashTable {
private:
    struct Entry {
        Key key;
        Value value;
        std::atomic<uint64_t> version{0};
        std::atomic<bool> occupied{false};
    };

    std::vector<Entry> table_;
    size_t mask_;

    size_t hash(const Key& key) const {
        return std::hash<Key>{}(key) & mask_;
    }

public:
    explicit OptimisticHashTable(size_t capacity = 1024) {
        size_t cap = 1;
        while (cap < capacity) cap <<= 1;
        table_.resize(cap);
        mask_ = cap - 1;
    }

    // 乐观读取
    std::optional<Value> get(const Key& key) {
        size_t idx = hash(key);

        for (size_t probe = 0; probe <= mask_; ++probe) {
            size_t i = (idx + probe) & mask_;
            Entry& entry = table_[i];

            if (!entry.occupied.load(std::memory_order_acquire)) {
                return std::nullopt;
            }

            if (entry.key == key) {
                // 乐观读取：检查版本号
                uint64_t v1 = entry.version.load(std::memory_order_acquire);
                Value val = entry.value;
                uint64_t v2 = entry.version.load(std::memory_order_acquire);

                if (v1 == v2 && (v1 % 2 == 0)) {
                    // 版本号未变且为偶数（无正在进行的写入）
                    return val;
                }
                // 版本号变化，重试
                continue;
            }
        }
        return std::nullopt;
    }

    // 乐观写入
    void put(const Key& key, const Value& value) {
        size_t idx = hash(key);

        for (size_t probe = 0; probe <= mask_; ++probe) {
            size_t i = (idx + probe) & mask_;
            Entry& entry = table_[i];

            if (!entry.occupied.load(std::memory_order_acquire) ||
                entry.key == key) {

                // 标记写入开始（版本号变奇数）
                entry.version.fetch_add(1, std::memory_order_acq_rel);

                entry.key = key;
                entry.value = value;
                entry.occupied.store(true, std::memory_order_release);

                // 标记写入完成（版本号变偶数）
                entry.version.fetch_add(1, std::memory_order_release);
                return;
            }
        }
    }
};
```

## 8. 小结

### 核心要点回顾

| 数据结构/技术 | 核心思想 | 适用场景 |
|-------------|---------|---------|
| **MSQueue** | CAS + 哑节点 + 帮助机制 | 生产者-消费者模式 |
| **无锁哈希表** | 开放寻址 + 原子状态 | 高并发键值查找 |
| **Hazard Pointer** | 声明式保护 + 延迟回收 | 保护少量被访问节点 |
| **Epoch-based** | 分代 + 批量回收 | 读多写少，批量回收 |
| **RCU** | 读取零开销 + 宽限期 | 极端读多写少 |
| **乐观并发** | 版本号 + 冲突重试 | 低冲突场景 |

### 并发数据结构选择决策树

```
需要并发数据结构？
├── 读远多于写(>99%)？ → RCU
├── 读多写少？ → Epoch-based + 无锁结构
├── 读写均衡？
│   ├── 需要FIFO？ → MSQueue
│   ├── 需要键值查找？ → 无锁哈希表
│   └── 需要栈？ → Treiber Stack + Hazard Pointer
├── 冲突率低？ → 乐观并发控制
└── 复杂度高？ → 细粒度锁（先试这个！）
```
