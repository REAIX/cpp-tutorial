# 语义分析与中间表示

> 从语法树到中间代码：编译器理解程序含义的关键阶段

---

> **Syntax is what the language looks like; semantics is what the language means.** — Anonymous
> （语法是语言的样子，语义是语言的含义。）

> **理解代码的含义，是编译器最核心的能力。**

---

> **🎯 知其然，更要知其所以然。**
>
> （语法分析知道代码的结构，语义分析理解代码的含义。）

---

> 💡 **通俗理解 - 语义分析和中间表示是什么？**

想象你在阅读一个句子：
1. **语法分析**：识别出"狗 追 猫"是"主语+谓语+宾语"结构
2. **语义分析**：理解"狗追猫"的含义——狗是追的动作发出者，猫是被追的对象
3. **中间表示**：把"狗追猫"翻译成一种通用格式，方便后续翻译成不同语言

**编译器也是这样工作的！**
- 语义分析：检查类型是否匹配、变量是否声明、操作是否合法
- 中间表示：把 AST 翻译成与语言和平台无关的中间代码

---

> 🔬 **抽象理解 - 语义分析与IR的本质**：
> - **语义分析**：基于属性文法，对 AST 进行类型标注和语义规则验证
> - **符号表**：维护标识符的语义信息（类型、作用域、存储位置）
> - **中间表示**：前端与后端的解耦层，使编译器可模块化

## 1. 符号表管理

### 1.1 符号表的作用

符号表是编译器中最重要的数据结构之一，贯穿编译的多个阶段：

```
符号表在编译器中的角色：

词法分析 ──→ 语法分析 ──→ 语义分析 ──→ 代码生成
                              │              │
                              ▼              ▼
                         ┌─────────────────────┐
                         │      符号表          │
                         │                     │
                         │  变量名 → 类型       │
                         │  函数名 → 签名       │
                         │  类型名 → 定义       │
                         │  作用域 → 层级       │
                         └─────────────────────┘
```

### 1.2 完整的符号表实现

```cpp
#include <string>
#include <vector>
#include <unordered_map>
#include <memory>
#include <optional>
#include <iostream>

// ==================== 类型系统 ====================

enum class BaseType {
    VOID, BOOL, CHAR, INT, LONG, FLOAT, DOUBLE,
    STRUCT, UNION, ENUM, FUNCTION, POINTER, ARRAY
};

// 类型描述符
class Type {
public:
    BaseType base;
    int size;           // 字节大小
    int alignment;      // 对齐要求
    bool isConst;       // 是否 const
    bool isVolatile;    // 是否 volatile
    bool isSigned;      // 是否有符号

    // 复合类型的附加信息
    std::string name;                     // 结构体/枚举名
    std::vector<Type> paramTypes;         // 函数参数类型
    Type* returnType;                     // 函数返回类型
    Type* pointeeType;                    // 指针指向的类型
    Type* elementType;                    // 数组元素类型
    int arraySize;                        // 数组大小

    Type(BaseType b = BaseType::INT)
        : base(b), size(0), alignment(0),
          isConst(false), isVolatile(false), isSigned(true),
          returnType(nullptr), pointeeType(nullptr),
          elementType(nullptr), arraySize(0) {}

    bool isInteger() const {
        return base == BaseType::CHAR || base == BaseType::INT ||
               base == BaseType::LONG;
    }

    bool isFloat() const {
        return base == BaseType::FLOAT || base == BaseType::DOUBLE;
    }

    bool isPointer() const { return base == BaseType::POINTER; }
    bool isArray() const { return base == BaseType::ARRAY; }
    bool isFunction() const { return base == BaseType::FUNCTION; }

    // 类型兼容性检查
    bool isCompatibleWith(const Type& other) const {
        if (base != other.base) return false;
        if (isPointer() && other.isPointer()) {
            return pointeeType->isCompatibleWith(*other.pointeeType);
        }
        return true;
    }

    // 隐式转换检查
    bool canImplicitConvertTo(const Type& target) const {
        // 整数提升
        if (isInteger() && target.isInteger()) return true;
        // 整数到浮点
        if (isInteger() && target.isFloat()) return true;
        // 浮点转换
        if (isFloat() && target.isFloat()) return true;
        // 指针到 bool
        if (isPointer() && target.base == BaseType::BOOL) return true;
        // 同类型指针
        if (isPointer() && target.isPointer()) {
            if (target.pointeeType && target.pointeeType->base == BaseType::VOID)
                return true;  // 任何指针可转为 void*
        }
        return false;
    }

    std::string toString() const {
        std::string result;
        if (isConst) result += "const ";
        switch (base) {
            case BaseType::VOID:   result += "void"; break;
            case BaseType::BOOL:   result += "bool"; break;
            case BaseType::CHAR:   result += "char"; break;
            case BaseType::INT:    result += "int"; break;
            case BaseType::LONG:   result += "long"; break;
            case BaseType::FLOAT:  result += "float"; break;
            case BaseType::DOUBLE: result += "double"; break;
            case BaseType::POINTER:
                result += pointeeType->toString() + "*";
                break;
            case BaseType::ARRAY:
                result += elementType->toString() + "[" +
                         std::to_string(arraySize) + "]";
                break;
            case BaseType::FUNCTION:
                result += returnType->toString() + "(";
                for (size_t i = 0; i < paramTypes.size(); i++) {
                    if (i > 0) result += ", ";
                    result += paramTypes[i].toString();
                }
                result += ")";
                break;
            default: result += name; break;
        }
        return result;
    }
};

// ==================== 符号条目 ====================

enum class SymbolKind {
    VARIABLE, FUNCTION, PARAMETER,
    STRUCT, UNION, ENUM,
    TYPEDEF, ENUM_CONSTANT,
    LABEL
};

enum class StorageClass {
    AUTO,     // 自动（栈上）
    STATIC,   // 静态
    EXTERN,   // 外部
    REGISTER  // 寄存器
};

struct Symbol {
    std::string name;         // 符号名
    SymbolKind kind;          // 符号种类
    Type type;                // 类型信息
    StorageClass storage;     // 存储类
    int scopeLevel;           // 作用域层级
    int offset;               // 栈帧偏移
    bool isDefined;           // 是否已定义
    bool isUsed;              // 是否被使用（用于未使用变量警告）
    int declarationLine;      // 声明行号
    int definitionLine;       // 定义行号（函数）

    Symbol(const std::string& n, SymbolKind k, const Type& t, int scope)
        : name(n), kind(k), type(t), storage(StorageClass::AUTO),
          scopeLevel(scope), offset(0), isDefined(false),
          isUsed(false), declarationLine(0), definitionLine(0) {}
};

// ==================== 作用域管理的符号表 ====================

class SymbolTable {
private:
    // 每个作用域一个符号映射
    std::vector<std::unordered_map<std::string, std::unique_ptr<Symbol>>> scopes;
    // 当前函数的参数信息
    std::vector<Symbol*> currentFunctionParams;

public:
    SymbolTable() { pushScope(); } // 全局作用域

    // 进入新作用域
    void pushScope() {
        scopes.emplace_back();
    }

    // 离开当前作用域
    void popScope() {
        if (scopes.size() > 1) {
            // 检查未使用的变量
            for (const auto& [name, sym] : scopes.back()) {
                if (sym->kind == SymbolKind::VARIABLE && !sym->isUsed) {
                    std::cerr << "警告: 变量 '" << name
                             << "' 已声明但未使用 (行 "
                             << sym->declarationLine << ")\n";
                }
            }
            scopes.pop_back();
        }
    }

    // 在当前作用域插入符号
    bool insert(std::unique_ptr<Symbol> symbol) {
        auto& current = scopes.back();
        if (current.find(symbol->name) != current.end()) {
            return false; // 符号已存在
        }
        std::string name = symbol->name;
        current[name] = std::move(symbol);
        return true;
    }

    // 从内到外查找符号
    Symbol* lookup(const std::string& name) {
        for (auto it = scopes.rbegin(); it != scopes.rend(); ++it) {
            auto symIt = it->find(name);
            if (symIt != it->end()) {
                symIt->second->isUsed = true;
                return symIt->second.get();
            }
        }
        return nullptr;
    }

    // 仅在当前作用域查找
    Symbol* lookupCurrent(const std::string& name) {
        auto& current = scopes.back();
        auto it = current.find(name);
        if (it != current.end()) {
            return it->second.get();
        }
        return nullptr;
    }

    int currentScopeLevel() const {
        return static_cast<int>(scopes.size()) - 1;
    }

    void setFunctionParams(const std::vector<Symbol*>& params) {
        currentFunctionParams = params;
    }

    const std::vector<Symbol*>& getFunctionParams() const {
        return currentFunctionParams;
    }
};
```

## 2. 类型检查

### 2.1 类型检查的作用

类型检查是语义分析的核心任务，确保程序在类型层面是安全的：

```
类型检查的三个层次：
1. 类型一致性：赋值和运算的操作数类型是否兼容
2. 类型安全性：操作是否可能导致类型违规（如解引用空指针）
3. 类型完整性：所有表达式是否都有明确的类型
```

### 2.2 类型检查器实现

```cpp
#include <vector>
#include <string>
#include <memory>
#include <sstream>

// 类型检查错误
struct TypeError {
    std::string message;
    int line;
    int column;
    enum Severity { ERROR, WARNING } severity;

    TypeError(const std::string& msg, int ln, int col,
              Severity sev = ERROR)
        : message(msg), line(ln), column(col), severity(sev) {}

    std::string toString() const {
        std::string prefix = (severity == ERROR) ? "错误" : "警告";
        return "[" + prefix + " " + std::to_string(line) + ":" +
               std::to_string(column) + "] " + message;
    }
};

// 类型检查器
class TypeChecker {
private:
    SymbolTable& symbolTable;
    std::vector<TypeError> errors;

    void addError(const std::string& msg, int line, int col) {
        errors.emplace_back(msg, line, col, TypeError::ERROR);
    }

    void addWarning(const std::string& msg, int line, int col) {
        errors.emplace_back(msg, line, col, TypeError::WARNING);
    }

    // 获取两个类型的公共类型（隐式转换）
    Type getCommonType(const Type& left, const Type& right) {
        // 算术转换规则（C标准）
        // 1. 整数提升：char/short → int
        // 2. 如果操作数有 long double → long double
        // 3. 如果操作数有 double → double
        // 4. 如果操作数有 float → float
        // 5. 整数转换：较小类型 → 较大类型

        if (left.base == BaseType::DOUBLE || right.base == BaseType::DOUBLE)
            return Type(BaseType::DOUBLE);
        if (left.base == BaseType::FLOAT || right.base == BaseType::FLOAT)
            return Type(BaseType::FLOAT);
        if (left.base == BaseType::LONG || right.base == BaseType::LONG)
            return Type(BaseType::LONG);
        return Type(BaseType::INT);
    }

public:
    TypeChecker(SymbolTable& st) : symbolTable(st) {}

    // 检查二元运算的类型
    Type checkBinaryOp(const std::string& op, const Type& left,
                       const Type& right, int line, int col) {
        // 算术运算符：+ - * / %
        if (op == "+" || op == "-" || op == "*" || op == "/") {
            if (left.isPointer() && right.isInteger()) {
                // 指针算术：ptr + n
                return left;
            }
            if (left.isInteger() && right.isPointer() && op == "+") {
                // 指针算术：n + ptr
                return right;
            }
            if ((left.isInteger() || left.isFloat()) &&
                (right.isInteger() || right.isFloat())) {
                return getCommonType(left, right);
            }
            addError("二元运算符 '" + op + "' 的操作数类型不合法: " +
                    left.toString() + " 和 " + right.toString(), line, col);
            return Type(BaseType::INT);
        }

        // 取余运算：仅适用于整数
        if (op == "%") {
            if (!left.isInteger() || !right.isInteger()) {
                addError("取余运算符 '%' 的操作数必须是整数类型", line, col);
            }
            return getCommonType(left, right);
        }

        // 比较运算符：== != < > <= >=
        if (op == "==" || op == "!=" || op == "<" || op == ">" ||
            op == "<=" || op == ">=") {
            if (left.isPointer() && right.isPointer()) {
                // 指针比较：类型必须兼容
                if (!left.isCompatibleWith(right)) {
                    addWarning("比较不同类型的指针", line, col);
                }
            } else if ((left.isInteger() || left.isFloat()) &&
                       (right.isInteger() || right.isFloat())) {
                // 算术比较
            } else {
                addError("比较运算符 '" + op + "' 的操作数类型不兼容", line, col);
            }
            return Type(BaseType::INT); // 比较结果为 int
        }

        // 逻辑运算符：&& ||
        if (op == "&&" || op == "||") {
            // 操作数必须是标量类型
            return Type(BaseType::INT);
        }

        // 赋值运算符
        if (op == "=") {
            if (left.isConst) {
                addError("不能对 const 变量赋值", line, col);
            }
            if (!right.canImplicitConvertTo(left)) {
                addError("不能将 " + right.toString() +
                        " 隐式转换为 " + left.toString(), line, col);
            }
            return left;
        }

        return Type(BaseType::INT);
    }

    // 检查函数调用
    Type checkFunctionCall(const std::string& funcName,
                          const std::vector<Type>& argTypes,
                          int line, int col) {
        Symbol* func = symbolTable.lookup(funcName);
        if (!func) {
            addError("未声明的函数 '" + funcName + "'", line, col);
            return Type(BaseType::INT);
        }

        if (func->kind != SymbolKind::FUNCTION) {
            addError("'" + funcName + "' 不是函数", line, col);
            return Type(BaseType::INT);
        }

        // 检查参数数量
        const auto& paramTypes = func->type.paramTypes;
        if (argTypes.size() != paramTypes.size()) {
            addError("函数 '" + funcName + "' 期望 " +
                    std::to_string(paramTypes.size()) + " 个参数，但提供了 " +
                    std::to_string(argTypes.size()) + " 个", line, col);
        }

        // 检查参数类型
        size_t checkCount = std::min(argTypes.size(), paramTypes.size());
        for (size_t i = 0; i < checkCount; i++) {
            if (!argTypes[i].canImplicitConvertTo(paramTypes[i])) {
                addError("函数 '" + funcName + "' 的第 " +
                        std::to_string(i + 1) + " 个参数类型不匹配: 期望 " +
                        paramTypes[i].toString() + "，实际 " +
                        argTypes[i].toString(), line, col);
            }
        }

        return *func->type.returnType;
    }

    // 检查数组下标
    Type checkArraySubscript(const Type& arrayType, const Type& indexType,
                            int line, int col) {
        if (arrayType.isArray() || arrayType.isPointer()) {
            if (!indexType.isInteger()) {
                addError("数组下标必须是整数类型", line, col);
            }
            if (arrayType.isArray()) return *arrayType.elementType;
            return *arrayType.pointeeType;
        }
        addError("不能对非数组/指针类型进行下标操作", line, col);
        return Type(BaseType::INT);
    }

    // 检查成员访问
    Type checkMemberAccess(const Type& objectType, const std::string& member,
                          bool isArrow, int line, int col) {
        if (isArrow) {
            // ptr->member：objectType 必须是指针
            if (!objectType.isPointer()) {
                addError("'->' 运算符需要指针类型", line, col);
                return Type(BaseType::INT);
            }
            // 查找成员
            // ...（简化处理）
        } else {
            // obj.member：objectType 必须是结构体
            if (objectType.base != BaseType::STRUCT) {
                addError("'.' 运算符需要结构体类型", line, col);
                return Type(BaseType::INT);
            }
        }
        return Type(BaseType::INT);
    }

    const std::vector<TypeError>& getErrors() const { return errors; }
    bool hasErrors() const {
        for (const auto& e : errors) {
            if (e.severity == TypeError::ERROR) return true;
        }
        return false;
    }
};
```

## 3. 语义规则

### 3.1 属性文法

属性文法在上下文无关文法的基础上添加语义规则：

```
属性文法 = 上下文无关文法 + 属性 + 语义规则

属性类型：
- 综合属性（Synthesized）：自底向上传递，子节点 → 父节点
  例：表达式的类型由操作数类型综合得出
- 继承属性（Inherited）：自顶向下传递，父节点/兄弟节点 → 子节点
  例：变量的存储位置由声明上下文继承

示例：表达式类型检查的属性文法

产生式                    语义规则
────────────────────────────────────────────────
E → E1 + E2             E.type = arithCoerce(E1.type, E2.type)
E → E1 * E2             E.type = arithCoerce(E1.type, E2.type)
E → -E1                 E.type = E1.type
E → (E1)                E.type = E1.type
E → id                  E.type = lookup(id.name).type
E → num                 E.type = int
```

    }

        // for (auto& decl : node->declarations) {
        //     visitDeclaration(decl);
        // }
    }

    // 访问变量声明
    void visitVarDecl(const std::string& name, const Type& type,
                     bool hasInitializer, int line) {
        // 检查是否在当前作用域重复声明
        if (symbolTable.lookupCurrent(name)) {
            addError("重复声明变量 '" + name + "'", line);
            return;

                      int line) {

        Symbol* existing = symbolTable.lookupCurrent(name);
        if (existing) {
            if (existing->kind != SymbolKind::FUNCTION) {
                addError("'" + name + "' 已声明为非函数类型", line);
                return;
            }
            // 检查函数签名是否一致
            // ...（简化处理）
        }

        // 创建函数类型
        Type funcType(BaseType::FUNCTION);
        funcType.returnType = new Type(returnType);
        for (const auto& [pname, ptype] : params) {
            funcType.paramTypes.push_back(ptype);
        }

        // 插入符号表
        auto sym = std::make_unique<Symbol>(name, SymbolKind::FUNCTION,
                                            funcType, symbolTable.currentScopeLevel());
        sym->declarationLine = line;
        symbolTable.insert(std::move(sym));

        // 进入函数作用域
        symbolTable.pushScope();

        // 插入参数
        for (const auto& [pname, ptype] : params) {
            auto param = std::make_unique<Symbol>(pname, SymbolKind::PARAMETER,
                                                   ptype, symbolTable.currentScopeLevel());
            param->declarationLine = line;
            symbolTable.insert(std::move(param));
        }

        // 分析函数体
        // visitBlock(funcBody);

        // 离开函数作用域
        symbolTable.popScope();
    }

    // 访问 if 语句
    void visitIfStmt(ASTNode* condition, int line) {
        // 条件表达式必须是标量类型
        Type condType = getExprType(condition);
        if (condType.base == BaseType::STRUCT) {
            addError("if 条件不能是结构体类型", line);
        }
    }

    // 访问 return 语句
    void visitReturnStmt(const Type& returnType, const Type& funcReturnType,
                        int line) {
        if (!returnType.canImplicitConvertTo(funcReturnType)) {
            addError("返回类型 " + returnType.toString() +
                    " 与函数返回类型 " + funcReturnType.toString() +
                    " 不匹配", line);
        }
    }

    // 获取表达式的类型（综合属性）
    Type getExprType(ASTNode* expr) {
        // 根据 AST 节点类型计算表达式的类型
        // 这是综合属性的典型应用
        return Type(BaseType::INT); // 简化
    }

    const std::vector<TypeError>& getErrors() const { return errors; }
};

## 4. 三地址码

### 4.1 三地址码概述

三地址码（Three-Address Code, TAC）是一种常见的中间表示形式：

```
三地址码的特点：
- 每条指令最多包含三个操作数
- 每条指令最多执行一个运算
- 类似于汇编语言，但使用无限个临时变量

x = y op z      // 二元运算
x = op y        // 一元运算
x = y           // 赋值
goto L          // 无条件跳转
if x goto L     // 条件跳转
param x         // 设置参数
call f, n       // 调用函数
x = call f, n   // 函数调用并获取返回值
return x        // 返回
x = y[i]        // 数组读取
x[i] = y        // 数组写入
x = &y          // 取地址
x = *y          // 解引用
*x = y          // 间接写入
```

### 4.2 三地址码实现

```cpp
#include <string>
#include <vector>
#include <sstream>
#include <unordered_map>
#include <memory>

// 三地址码指令类型
enum class TACOp {
    // 算术运算
    ADD, SUB, MUL, DIV, MOD,
    NEG,
    // 比较运算
    EQ, NEQ, LT, GT, LEQ, GEQ,
    // 逻辑运算
    AND, OR, NOT,
    // 位运算
    BIT_AND, BIT_OR, BIT_XOR, BIT_NOT, SHL, SHR,
    // 赋值
    ASSIGN,
    // 跳转
    GOTO, IF_TRUE, IF_FALSE,
    // 函数
    PARAM, CALL, RETURN,
    // 内存
    LOAD, STORE, ADDR_OF, DEREF, DEREF_ASSIGN,
    // 数组
    INDEX_LOAD, INDEX_STORE,
    // 标签
    LABEL,
    // 类型转换
    CAST_INT_TO_FLOAT, CAST_FLOAT_TO_INT, CAST_INT_TO_PTR, CAST_PTR_TO_INT
};

// 三地址码指令
struct TACInstruction {
    TACOp op;
    std::string result;   // 结果操作数
    std::string arg1;     // 第一操作数
    std::string arg2;     // 第二操作数
    std::string label;    // 标签（用于跳转目标）

    TACInstruction(TACOp o, const std::string& res = "",
                  const std::string& a1 = "",
                  const std::string& a2 = "")
        : op(o), result(res), arg1(a1), arg2(a2) {}

    std::string toString() const {
        switch (op) {
            case TACOp::ADD:
                return result + " = " + arg1 + " + " + arg2;
            case TACOp::SUB:
                return result + " = " + arg1 + " - " + arg2;
            case TACOp::MUL:
                return result + " = " + arg1 + " * " + arg2;
            case TACOp::DIV:
                return result + " = " + arg1 + " / " + arg2;
            case TACOp::NEG:
                return result + " = -" + arg1;
            case TACOp::ASSIGN:
                return result + " = " + arg1;
            case TACOp::GOTO:
                return "goto " + label;
            case TACOp::IF_TRUE:
                return "if " + arg1 + " goto " + label;
            case TACOp::IF_FALSE:
                return "if_false " + arg1 + " goto " + label;
            case TACOp::LABEL:
                return label + ":";
            case TACOp::PARAM:
                return "param " + arg1;
            case TACOp::CALL:
                if (!result.empty())
                    return result + " = call " + arg1 + ", " + arg2;
                return "call " + arg1 + ", " + arg2;
            case TACOp::RETURN:
                if (!arg1.empty()) return "return " + arg1;
                return "return";
            case TACOp::LOAD:
                return result + " = *" + arg1;
            case TACOp::STORE:
                return "*" + arg1 + " = " + arg2;
            case TACOp::ADDR_OF:
                return result + " = &" + arg1;
            case TACOp::EQ:
                return result + " = " + arg1 + " == " + arg2;
            case TACOp::LT:
                return result + " = " + arg1 + " < " + arg2;
            default:
                return result + " = " + arg1 + " ? " + arg2;
        }
    }
};

// 三地址码生成器
class TACGenerator {
private:
    std::vector<TACInstruction> instructions;
    int tempCounter = 0;
    int labelCounter = 0;

    // 生成临时变量名
    std::string newTemp() {
        return "t" + std::to_string(tempCounter++);
    }

    // 生成标签名
    std::string newLabel() {
        return "L" + std::to_string(labelCounter++);
    }

public:
    // 生成二元运算
    std::string genBinaryOp(TACOp op, const std::string& left,
                           const std::string& right) {
        std::string temp = newTemp();
        instructions.emplace_back(op, temp, left, right);
        return temp;
    }

    // 生成赋值
    void genAssign(const std::string& target, const std::string& value) {
        instructions.emplace_back(TACOp::ASSIGN, target, value);
    }

    // 生成 if 语句
    void genIf(const std::string& cond, const std::string& trueLabel,
              const std::string& falseLabel) {
        instructions.emplace_back(TACOp::IF_TRUE, "", cond, "");
        instructions.back().label = trueLabel;
        instructions.emplace_back(TACOp::GOTO, "", "", "");
        instructions.back().label = falseLabel;
    }

    // 生成 while 循环
    struct WhileLabels {
        std::string startLabel;
        std::string bodyLabel;
        std::string endLabel;
    };

    WhileLabels genWhileStart() {
        WhileLabels labels;
        labels.startLabel = newLabel();
        labels.bodyLabel = newLabel();
        labels.endLabel = newLabel();

        // 循环开始标签
        instructions.emplace_back(TACOp::LABEL, "", "", "");
        instructions.back().label = labels.startLabel;

        return labels;
    }

    void genWhileEnd(const WhileLabels& labels, const std::string& cond) {
        // 条件为真跳转到循环体
        instructions.emplace_back(TACOp::IF_TRUE, "", cond, "");
        instructions.back().label = labels.bodyLabel;

        // 条件为假跳转到循环结束
        instructions.emplace_back(TACOp::GOTO, "", "", "");
        instructions.back().label = labels.endLabel;

        // 循环体标签
        instructions.emplace_back(TACOp::LABEL, "", "", "");
        instructions.back().label = labels.bodyLabel;

        // 循环体结束后跳回循环开始
        instructions.emplace_back(TACOp::GOTO, "", "", "");
        instructions.back().label = labels.startLabel;

        // 循环结束标签
        instructions.emplace_back(TACOp::LABEL, "", "", "");
        instructions.back().label = labels.endLabel;
    }

    // 生成函数调用
    std::string genCall(const std::string& funcName,
                       const std::vector<std::string>& args) {
        // 设置参数
        for (const auto& arg : args) {
            instructions.emplace_back(TACOp::PARAM, "", arg);
        }
        // 调用函数
        std::string result = newTemp();
        instructions.emplace_back(TACOp::CALL, result, funcName,
                                std::to_string(args.size()));
        return result;
    }

    // 生成 return
    void genReturn(const std::string& value = "") {
        instructions.emplace_back(TACOp::RETURN, "", value);
    }

    // 打印所有指令
    void print() const {
        for (const auto& inst : instructions) {
            std::cout << "    " << inst.toString() << std::endl;
        }
    }

    const std::vector<TACInstruction>& getInstructions() const {
        return instructions;
    }
};
```

## 5. SSA（静态单赋值）

### 5.1 SSA 概述

SSA（Static Single Assignment）是现代编译器最重要的 IR 形式：

```
SSA 的核心规则：每个变量只被赋值一次

普通代码：                 SSA 形式：
x = 1                     x1 = 1
x = 2                     x2 = 2
y = x + 1                 y1 = x2 + 1

分支合并的问题：
if (cond)                 if (cond)
    x = 1;                    x1 = 1;
else                      else
    x = 2;                    x2 = 2;
y = x;                    y = φ(x1, x2);  // φ 函数

φ 函数：在控制流汇合点选择正确的变量版本
```

### 5.2 SSA 构造算法

class BasicBlock {
public:

    std::vector<BasicBlock*> predecessors;
    std::vector<BasicBlock*> successors;

    std::set<std::string> liveOut;   // 活跃变量（出口）

    BasicBlock(const std::string& n) : name(n) {}
};

    std::map<std::string, std::stack<int>> stacks;            // 变量版本栈

    void insertPhiFunctions(std::vector<std::unique_ptr<BasicBlock>>& blocks) {
        // 对每个变量，计算其支配边界
        for (auto& [var, defBlockSet] : defBlocks) {

            std::vector<BasicBlock*> worklist(defBlockSet.begin(), defBlockSet.end());

            while (!worklist.empty()) {
                BasicBlock* block = worklist.back();
                worklist.pop_back();

                // 在支配边界插入 φ 函数
                for (BasicBlock* df : getDominanceFrontier(block)) {
                    if (phiInserted.find(df) == phiInserted.end()) {

### 5.3 SSA 的优势

```
SSA 的优势：
1. 简化数据流分析
   - 每个变量只有一个定义点
   - use-def 链是隐式的

2. 便于优化
   - 常量传播更简单：只需检查唯一定义
   - 死代码消除更直接：无使用的定义可删除
   - 值编号更高效：相同定义产生相同值

3. 寄存器分配更简单
   - 变量的活跃区间更明确
   - 不存在同一变量的多个活跃区间重叠

示例：常量传播在 SSA 中的简化

普通形式：              SSA 形式：
x = 5                   x1 = 5
x = 10                  x2 = 10
y = x + 3               y1 = x2 + 3  → 直接知道 y1 = 13

在 SSA 中，x2 的唯一定义是 10，所以 y1 = 10 + 3 = 13
```

## 6. LLVM IR基础

### 6.1 LLVM IR 概述

LLVM IR 是 LLVM 编译器基础设施的核心中间表示：

```
LLVM IR 的特点：
1. SSA 形式：每个寄存器只被赋值一次
2. 类型系统：显式的类型信息（i32, float, i32*, [10 x i32]）
3. 无限虚拟寄存器：命名寄存器 %0, %1, %2, ...
4. 低级但与平台无关：比三地址码更接近机器，但不含平台细节

LLVM IR 的三种形式：
- 内存中的 IR（编译器内部使用）
- 位码 .bc（二进制格式，紧凑高效）
- 可读文本 .ll（人类可读的文本格式）
```

### 6.2 LLVM IR 语法

```llvm
; === LLVM IR 基本语法 ===

; 注释以分号开头

; 函数声明
declare i32 @printf(i8*, ...)

; 全局变量
@.str = private unnamed_addr constant [13 x i8] c"hello world\0A\00"

; 函数定义
define i32 @add(i32 %a, i32 %b) {
entry:
    %result = add i32 %a, %b
    ret i32 %result
}

; 主函数
define i32 @main() {
entry:
    ; 调用函数
    %sum = call i32 @add(i32 3, i32 4)

    ; 条件分支
    %cmp = icmp sgt i32 %sum, 5
    br i1 %cmp, label %then, label %else

then:
    call i32 (i8*, ...) @printf(i8* getelementptr ([13 x i8], [13 x i8]* @.str, i32 0, i32 0))
    br label %end

else:
    br label %end

end:
    ret i32 %sum
}
```

## 7. IR生成实战

### 7.1 从 AST 生成 LLVM IR

```cpp
#include "llvm/IR/LLVMContext.h"
#include "llvm/IR/Module.h"
#include "llvm/IR/IRBuilder.h"
#include "llvm/IR/Verifier.h"
#include <string>
#include <vector>
#include <map>

// LLVM IR 生成器
class IRGenerator {
private:
    llvm::LLVMContext context;
    std::unique_ptr<llvm::Module> module;
    std::unique_ptr<llvm::IRBuilder<>> builder;
    std::map<std::string, llvm::Value*> namedValues;

public:
    IRGenerator(const std::string& moduleName)
        : module(std::make_unique<llvm::Module>(moduleName, context)),
          builder(std::make_unique<llvm::IRBuilder<>>(context)) {}

    // 生成函数
    llvm::Function* generateFunction(const std::string& name,
                                     const std::vector<std::string>& paramNames) {
        // 函数类型：int func(int, int, ...)
        std::vector<llvm::Type*> paramTypes(
            paramNames.size(), llvm::Type::getInt32Ty(context));
        llvm::FunctionType* funcType = llvm::FunctionType::get(
            llvm::Type::getInt32Ty(context), paramTypes, false);

        // 创建函数
        llvm::Function* function = llvm::Function::Create(
            funcType, llvm::Function::ExternalLinkage, name, module.get());

        // 设置参数名
        unsigned idx = 0;
        for (auto& arg : function->args()) {
            arg.setName(paramNames[idx++]);
        }

        return function;
    }

    // 生成函数体
    void generateFunctionBody(llvm::Function* function, ASTNode* body) {
        // 创建入口基本块
        llvm::BasicBlock* entry = llvm::BasicBlock::Create(context, "entry", function);
        builder->SetInsertPoint(entry);

        // 将函数参数存入命名值表
        namedValues.clear();
        for (auto& arg : function->args()) {
            // 在栈上创建 alloca，存储参数
            llvm::AllocaInst* alloca = builder->CreateAlloca(
                arg.getType(), nullptr, arg.getName().str());
            builder->CreateStore(&arg, alloca);
            namedValues[arg.getName().str()] = alloca;
        }

        // 递归生成函数体中的语句
        // ...（遍历 AST 节点，生成对应的 LLVM IR）

        // 验证函数
        llvm::verifyFunction(*function);
    }

    // 生成二元表达式
    llvm::Value* generateBinaryExpr(BinaryOp op, llvm::Value* left,
                                    llvm::Value* right) {
        switch (op) {
            case BinaryOp::ADD:
                return builder->CreateAdd(left, right, "addtmp");
            case BinaryOp::SUB:
                return builder->CreateSub(left, right, "subtmp");
            case BinaryOp::MUL:
                return builder->CreateMul(left, right, "multmp");
            case BinaryOp::DIV:
                return builder->CreateSDiv(left, right, "divtmp");
            case BinaryOp::EQ:
                return builder->CreateICmpEQ(left, right, "eqtmp");
            case BinaryOp::NEQ:
                return builder->CreateICmpNE(left, right, "neqtmp");
            case BinaryOp::LT:
                return builder->CreateICmpSLT(left, right, "lttmp");
            case BinaryOp::GT:
                return builder->CreateICmpSGT(left, right, "gttmp");
            case BinaryOp::LEQ:
                return builder->CreateICmpSLE(left, right, "leqtmp");
            case BinaryOp::GEQ:
                return builder->CreateICmpSGE(left, right, "geqtmp");
            default:
                return nullptr;
        }
    }

    // 生成 if 语句
    void generateIfStmt(llvm::Value* condition, ASTNode* thenBranch,
                        ASTNode* elseBranch, llvm::Function* function) {
        // 将条件转换为 i1（布尔值）
        condition = builder->CreateICmpNE(
            condition, llvm::ConstantInt::get(llvm::Type::getInt32Ty(context), 0),
            "ifcond");

        llvm::BasicBlock* thenBB = llvm::BasicBlock::Create(context, "then", function);
        llvm::BasicBlock* elseBB = llvm::BasicBlock::Create(context, "else");
        llvm::BasicBlock* mergeBB = llvm::BasicBlock::Create(context, "merge");

        // 条件跳转
        builder->CreateCondBr(condition, thenBB, elseBranch ? elseBB : mergeBB);

        // then 分支
        builder->SetInsertPoint(thenBB);
        // ... 生成 then 分支代码
        builder->CreateBr(mergeBB);
        thenBB = builder->GetInsertBlock();  // 更新（代码生成可能改变当前块）

        // else 分支
        if (elseBranch) {
            function->insert(function->end(), elseBB);
            builder->SetInsertPoint(elseBB);
            // ... 生成 else 分支代码
            builder->CreateBr(mergeBB);
        }

        // 合并点
        function->insert(function->end(), mergeBB);
        builder->SetInsertPoint(mergeBB);

        // 如果 if 是表达式，需要 φ 节点
        // llvm::Value* result = builder->CreatePHI(llvm::Type::getInt32Ty(context), 2, "iftmp");
        // result->addIncoming(thenValue, thenBB);
        // result->addIncoming(elseValue, elseBB);
    }

    // 生成 while 循环
    void generateWhileStmt(ASTNode* condition, ASTNode* body,
                          llvm::Function* function) {
        llvm::BasicBlock* condBB = llvm::BasicBlock::Create(context, "while.cond", function);
        llvm::BasicBlock* bodyBB = llvm::BasicBlock::Create(context, "while.body");
        llvm::BasicBlock* endBB = llvm::BasicBlock::Create(context, "while.end");

        // 跳转到条件判断
        builder->CreateBr(condBB);

        // 条件判断块
        builder->SetInsertPoint(condBB);
        // llvm::Value* condValue = generateExpression(condition);
        // condValue = builder->CreateICmpNE(condValue, ...);
        // builder->CreateCondBr(condValue, bodyBB, endBB);

        // 循环体块
        function->insert(function->end(), bodyBB);
        builder->SetInsertPoint(bodyBB);
        // ... 生成循环体代码
        builder->CreateBr(condBB);  // 跳回条件判断

        // 循环结束块
        function->insert(function->end(), endBB);
        builder->SetInsertPoint(endBB);
    }

    // 生成变量引用
    llvm::Value* generateVariable(const std::string& name) {
        auto it = namedValues.find(name);
        if (it == namedValues.end()) {
            return nullptr;  // 未定义变量
        }
        // 从 alloca 加载值
        return builder->CreateLoad(llvm::Type::getInt32Ty(context),
                                  it->second, name.c_str());
    }

    // 生成赋值
    llvm::Value* generateAssignment(const std::string& name, llvm::Value* value) {
        auto it = namedValues.find(name);
        if (it == namedValues.end()) {
            // 创建新的 alloca
            llvm::AllocaInst* alloca = builder->CreateAlloca(
                llvm::Type::getInt32Ty(context), nullptr, name);
            namedValues[name] = alloca;
            it = namedValues.find(name);
        }
        builder->CreateStore(value, it->second);
        return value;
    }

    // 打印生成的 IR
    void printIR() {
        module->print(llvm::outs(), nullptr);
    }

    llvm::Module* getModule() { return module.get(); }
};
```

# 2. 生成 LLVM 位码（二进制格式）

# 5. 汇编和链接
clang main.s -o main

entry:
    %cmp = icmp sle i32 %n, 1
    br i1 %cmp, label %if.then, label %if.else

if.then:

## 8. 本章小结

### 核心要点回顾

| 概念 | 关键内容 |
|------|---------|
| 符号表 | 维护标识符的语义信息，支持作用域嵌套和符号查找 |
| 类型检查 | 验证操作的类型合法性，支持隐式转换和类型推导 |
| 语义规则 | 基于属性文法，通过综合属性和继承属性传播语义信息 |
| 三地址码 | 简单的 IR 形式，每条指令最多三个操作数 |
| SSA | 每个变量只赋值一次，φ 函数处理控制流汇合 |
| LLVM IR | 工业级 SSA IR，类型化、无限虚拟寄存器、丰富的指令集 |

### 关键理解

1. **符号表是语义分析的核心数据结构**：贯穿编译全过程，维护标识符的所有语义信息
2. **类型检查是程序安全的第一道防线**：在编译期发现类型错误，避免运行时崩溃
3. **SSA 是现代编译优化的基础**：几乎所有高级优化都依赖 SSA 形式
4. **LLVM IR 是工业级 IR 的典范**：设计精良，兼顾表达能力和优化友好性
