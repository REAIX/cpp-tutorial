# 实时操作系统

> 掌握RTOS原理、FreeRTOS任务调度、同步机制与内存管理

***

> **A real-time system is one in which the correctness of the computations depends not only on the logical results but also on the time at which the results are produced.** — IEEE
> （实时系统的正确性不仅取决于逻辑结果，还取决于结果产生的时间。）

> **The art of real-time programming is making the right trade-offs.** — Unknown
> （实时编程的艺术在于做出正确的权衡。）

***

> **🎯 欲速则不达。**
>
> （实时系统追求的不是最快，而是可预测——在确定的时间内完成确定的任务。）

> 💡 **通俗理解 - 什么是RTOS？**

想象一下：

- **裸机超级循环** 就像"一个人做所有家务"，扫地、做饭、洗衣服串行做，紧急电话来了也接不了
- **RTOS** 就像"一个管家调度多个佣人"，每个佣人负责一件事，管家根据紧急程度安排谁先做
- **优先级** 就像"佣人的等级"，管家优先安排高等级的佣人工作
- **信号量** 就像"房间钥匙"，只有拿到钥匙的佣人才能进房间

RTOS的核心价值：**保证高优先级任务在确定时间内得到执行**。

> 🔬 **抽象理解 - RTOS核心概念**：
>
> - **任务调度**：决定哪个任务在什么时候运行
> - **优先级反转**：低优先级任务阻塞高优先级任务的异常情况
> - **同步机制**：信号量、互斥量、消息队列——任务间通信与协调
> - **内存管理**：静态分配、内存池——避免碎片化和不确定延迟

## 1. RTOS原理

### 1.1 实时性分类

```
硬实时（Hard Real-Time）
├── 超时 = 系统失败/灾难
├── 示例：汽车刹车、飞行控制、心脏起搏器
└── 要求：100%保证截止时间

软实时（Soft Real-Time）
├── 超时 = 性能下降但可接受
├── 示例：视频流、音频播放、网络通信
└── 要求：尽量满足截止时间

确定实时（Firm Real-Time）
├── 超时 = 结果无效但系统继续
├── 示例：金融交易、预测控制
└── 要求：偶尔超时可接受
```

### 1.2 调度算法

```cpp
// 常见调度算法

// 1. 速率单调调度（Rate Monotonic Scheduling, RMS）
// - 静态优先级：周期越短，优先级越高
// - 最优的静态优先级调度算法
// - 可调度条件：Σ(Ci/Ti) ≤ n(2^(1/n) - 1)

// 2. 截止时间单调调度（Deadline Monotonic Scheduling, DMS）
// - 静态优先级：截止时间越短，优先级越高
// - 适用于截止时间不等于周期的场景

// 3. 最早截止时间优先（Earliest Deadline First, EDF）
// - 动态优先级：截止时间最近的任务优先
// - 理论上最优的调度算法
// - 可调度条件：Σ(Ci/Ti) ≤ 1

// 4. 最低松弛度优先（Least Laxity First, LLF）
// - 动态优先级：松弛度 = 截止时间 - 剩余执行时间
// - 松弛度最小的任务优先

// RMS可调度性分析示例
struct TaskInfo {
    uint32_t period;     // 周期（ms）
    uint32_t execTime;   // 最坏执行时间（ms）
    uint32_t deadline;   // 截止时间（ms）
    uint32_t priority;   // 优先级
};

bool isRmsSchedulable(const TaskInfo tasks[], size_t count) {
    // 计算总CPU利用率
    float totalUtilization = 0.0f;
    for (size_t i = 0; i < count; ++i) {
        totalUtilization += static_cast<float>(tasks[i].execTime) /
                           static_cast<float>(tasks[i].period);
    }

    // RMS可调度上限
    float rmsBound = count * (std::pow(2.0f, 1.0f / count) - 1.0f);

    // 对于n=3: 上限 ≈ 0.780 (78%)
    // 对于n=∞: 上限 → ln(2) ≈ 0.693 (69.3%)

    return totalUtilization <= rmsBound;
}

// 示例：三个任务的RMS分析
void rmsAnalysisExample() {
    TaskInfo tasks[] = {
        {10, 2, 10, 3},   // 任务1：周期10ms，执行2ms，最高优先级
        {20, 3, 20, 2},   // 任务2：周期20ms，执行3ms
        {50, 5, 50, 1},   // 任务3：周期50ms，执行5ms，最低优先级
    };

    // CPU利用率 = 2/10 + 3/20 + 5/50 = 0.2 + 0.15 + 0.1 = 0.45
    // RMS上限(3任务) = 3*(2^(1/3)-1) ≈ 0.780
    // 0.45 < 0.780 → 可调度

    bool schedulable = isRmsSchedulable(tasks, 3);
    printf("RMS可调度性: %s\n", schedulable ? "是" : "否");
}
```

```cpp
#include "FreeRTOS.h"
#include "task.h"

// 任务函数签名
// void taskFunction(void* pvParameters);

// 方式1：动态创建任务（使用FreeRTOS堆）
void createDynamicTask() {
    TaskHandle_t taskHandle;

    BaseType_t result = xTaskCreate(
        sensorTask,          // 任务函数
        "SensorTask",        // 任务名称（调试用）
        256,                 // 栈大小（单位：字，即1024字节）
        nullptr,             // 参数
        3,                   // 优先级（数字越大优先级越高）
        &taskHandle          // 任务句柄
    );

    if (result != pdPASS) {
        // 任务创建失败（通常是内存不足）
        handleError();
    }
}

// 方式2：静态创建任务（使用静态分配的栈和TCB）
static StaticTask_t sensorTaskBuffer;
static StackType_t sensorTaskStack[256];

void createStaticTask() {
    TaskHandle_t taskHandle = xTaskCreateStatic(
        sensorTask,              // 任务函数
        "SensorTask",            // 任务名称
        256,                     // 栈大小
        nullptr,                 // 参数
        3,                       // 优先级
        sensorTaskStack,         // 静态分配的栈
        &sensorTaskBuffer        // 静态分配的TCB
    );

    if (taskHandle == nullptr) {
        handleError();
    }
}

// 任务函数示例
void sensorTask(void* pvParameters) {
    // 初始化（只执行一次）
    initSensor();

    // 任务主循环
    while (1) {
        // 读取传感器
        float value = readSensor();

        // 发送数据到处理任务
        xQueueSend(dataQueue, &value, pdMS_TO_TICKS(10));

        // 延时到下一个周期
        vTaskDelay(pdMS_TO_TICKS(100));  // 100ms周期
    }
}

// 精确周期任务（使用vTaskDelayUntil）
void periodicTask(void* pvParameters) {
    TickType_t xLastWakeTime = xTaskGetTickCount();
    const TickType_t xPeriod = pdMS_TO_TICKS(10);  // 10ms周期

    while (1) {
        // 精确周期性执行
        vTaskDelayUntil(&xLastWakeTime, xPeriod);

        // 执行任务...
        processPeriodicEvent();
    }
}

// 任务删除
void cleanupTask(TaskHandle_t task) {
    if (task != nullptr) {
        vTaskDelete(task);  // 删除指定任务
    }
}

// 任务信息查询
void printTaskInfo() {
    TaskHandle_t handle = xTaskGetCurrentTaskHandle();
    printf("任务名: %s\n", pcTaskGetName(handle));
    printf("优先级: %lu\n", uxTaskPriorityGet(handle));
    printf("剩余栈: %u 字节\n", uxTaskGetStackHighWaterMark(handle) * sizeof(StackType_t));
```

### 2.2 任务状态与调度

```
FreeRTOS任务状态转换：

                 ┌──────────────┐
                 │   Running    │ ← 当前执行的任务
                 │  (运行态)     │
                 └──────┬───────┘
                    │   │
    被抢占/时间片   │   │ 阻塞等待
         用完       │   │ (延时/信号量/队列)
                    ↓   ↓
             ┌──────────────┐
             │   Ready      │ ← 可以运行但未在运行
             │  (就绪态)     │
             └──────┬───────┘
                    ↑   │
         事件满足    │   │ 等待事件
                    │   ↓
             ┌──────────────┐
             │   Blocked    │ ← 等待事件（延时/资源）
             │  (阻塞态)     │
             └──────────────┘

             ┌──────────────┐
             │   Suspended  │ ← 被挂起（不参与调度）
             │  (挂起态)     │
             └──────────────┘
```

## 3. 优先级反转与继承

### 3.1 优先级反转问题

```
优先级反转示例：

时间 →
任务H（高优先级）:    ──────[等待互斥量]──────────[获得→执行]──
任务M（中优先级）:         ────[执行]──────────────────────
任务L（低优先级）:   ──[获得互斥量→执行]──────────[释放]──

1. 任务L获得互斥量
2. 任务H就绪，抢占L
3. 任务H需要同一互斥量，被阻塞
4. 任务M就绪，抢占L（M不需要互斥量）
5. 任务L无法运行，无法释放互斥量
6. 任务H被M间接阻塞 → 优先级反转！

正常情况：H应该比M先执行
反转情况：M在H之前执行
```

### 3.2 优先级继承协议

```
优先级继承解决反转：

时间 →
任务H（高优先级）:    ──────[等待互斥量]──────────[获得→执行]──
任务M（中优先级）:         ────[等待]──────────────────[执行]──
任务L（低优先级）:   ──[获得互斥量→提升优先级→执行]──[释放→恢复]──

1. 任务L获得互斥量
2. 任务H就绪，抢占L
3. 任务H需要互斥量，被阻塞
4. 任务L的优先级被提升到H的优先级（继承）
5. 任务L以H的优先级执行，M无法抢占
6. 任务L释放互斥量，优先级恢复
7. 任务H获得互斥量并执行
```

```cpp
// FreeRTOS互斥量与优先级继承

#include "FreeRTOS.h"
#include "semphr.h"

// 创建互斥量（内置优先级继承）
SemaphoreHandle_t xMutex;

void initMutex() {
    // 创建互斥量
    xMutex = xSemaphoreCreateMutex();
    if (xMutex == nullptr) {
        handleError();
    }
}

// 高优先级任务
void highPriorityTask(void* pvParameters) {
    while (1) {
        // 等待事件
        waitForEvent();

        // 获取互斥量
        if (xSemaphoreTake(xMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
            // 访问共享资源
            accessSharedResource();

            // 释放互斥量
            xSemaphoreGive(xMutex);
        }

        vTaskDelay(pdMS_TO_TICKS(50));
    }
}

// 低优先级任务
void lowPriorityTask(void* pvParameters) {
    while (1) {
        // 获取互斥量
        if (xSemaphoreTake(xMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
            // 访问共享资源
            // 此时如果有高优先级任务等待此互斥量，
            // FreeRTOS会自动提升此任务的优先级
            accessSharedResource();

            // 释放互斥量
            // 优先级自动恢复
            xSemaphoreGive(xMutex);
        }

        vTaskDelay(pdMS_TO_TICKS(200));
    }
}
```

## 4. 信号量与互斥量

### 4.1 二值信号量

```cpp
// 二值信号量 - 用于任务同步和中断同步

#include "FreeRTOS.h"
#include "semphr.h"

SemaphoreHandle_t xBinarySemaphore;

// 初始化
void initBinarySemaphore() {
    xBinarySemaphore = xSemaphoreCreateBinary();
    // 创建后初始状态为空（不可获取）
}

// 中断中释放信号量（用于中断→任务同步）
extern "C" void EXTI0_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;

    // 在中断中释放信号量
    xSemaphoreGiveFromISR(xBinarySemaphore, &xHigherPriorityTaskWoken);

    // 如果释放了高优先级任务，请求上下文切换
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}

// 任务中等待信号量
void waitingTask(void* pvParameters) {
    while (1) {
        // 等待信号量（阻塞直到中断释放）
        if (xSemaphoreTake(xBinarySemaphore, portMAX_DELAY) == pdTRUE) {
            // 处理中断事件
            handleInterruptEvent();
        }
    }
}
```

### 4.2 计数信号量

```cpp
// 计数信号量 - 用于资源管理和事件计数

SemaphoreHandle_t xCountingSemaphore;

// 初始化（最大计数10，初始计数0）
void initCountingSemaphore() {
    xCountingSemaphore = xSemaphoreCreateCounting(10, 0);
}

// 生产者：多个中断可以累积事件
void producerIsr() {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    xSemaphoreGiveFromISR(xCountingSemaphore, &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}

// 消费者：逐个处理事件
void consumerTask(void* pvParameters) {
    while (1) {
        if (xSemaphoreTake(xCountingSemaphore, portMAX_DELAY) == pdTRUE) {
            processEvent();
        }
    }
}

// 资源池管理示例
class ResourcePool {
public:
    void init(int count) {
        semaphore_ = xSemaphoreCreateCounting(count, count);
        for (int i = 0; i < count; ++i) {
            resources_[i].id = i;
            resources_[i].inUse = false;
        }
        maxResources_ = count;
    }

    Resource* acquire(TickType_t timeout) {
        if (xSemaphoreTake(semaphore_, timeout) != pdTRUE) {
            return nullptr;  // 无可用资源
        }

        ScopedCriticalSection cs;
        for (int i = 0; i < maxResources_; ++i) {
            if (!resources_[i].inUse) {
                resources_[i].inUse = true;
                return &resources_[i];
            }
        }
        return nullptr;
    }

    void release(Resource* res) {
        {
            ScopedCriticalSection cs;
            res->inUse = false;
        }
        xSemaphoreGive(semaphore_);
    }

private:
    struct Resource {
        int id;
        bool inUse;
    };

    SemaphoreHandle_t semaphore_;
    Resource resources_[16];
    int maxResources_ = 0;
};
```

### 4.3 互斥量

```cpp
// 互斥量 - 用于保护共享资源

// 互斥量 vs 二值信号量：
// - 互斥量：有所有权概念，只有获取者才能释放；内置优先级继承
// - 二值信号量：无所有权，任何任务都可以释放；无优先级继承

// RAII互斥量守卫
class MutexGuard {
public:
    explicit MutexGuard(SemaphoreHandle_t mutex, TickType_t timeout = portMAX_DELAY)
        : mutex_(mutex), acquired_(false) {
        acquired_ = (xSemaphoreTake(mutex_, timeout) == pdTRUE);
    }

    ~MutexGuard() {
        if (acquired_) {
            xSemaphoreGive(mutex_);
        }
    }

    bool isAcquired() const { return acquired_; }

    // 禁止拷贝
    MutexGuard(const MutexGuard&) = delete;
    MutexGuard& operator=(const MutexGuard&) = delete;

private:
    SemaphoreHandle_t mutex_;
    bool acquired_;
};

// 使用示例
SemaphoreHandle_t dataMutex;
SharedData sharedData;

void protectedAccess() {
    MutexGuard guard(dataMutex, pdMS_TO_TICKS(100));

    if (guard.isAcquired()) {
        // 安全访问共享数据
        sharedData.counter++;
        sharedData.timestamp = xTaskGetTickCount();
    } else {
        // 获取互斥量超时
        handleTimeout();
    }
    // 离开作用域自动释放
}

// 递归互斥量（同一任务可以多次获取）
SemaphoreHandle_t xRecursiveMutex;

void initRecursiveMutex() {
    xRecursiveMutex = xSemaphoreCreateRecursiveMutex();
}

void recursiveFunction(int depth) {
    if (depth <= 0) return;

    // 同一任务可以多次获取递归互斥量
    if (xSemaphoreTakeRecursive(xRecursiveMutex, portMAX_DELAY) == pdTRUE) {
        // 执行需要互斥保护的操作
        doSomething();

        // 递归调用
        recursiveFunction(depth - 1);

        // 释放（必须与获取次数匹配）
        xSemaphoreGiveRecursive(xRecursiveMutex);
    }
}
```

### 6.3 内存池

```cpp
// 自定义内存池 - 避免碎片化和不确定延迟

template<size_t BlockSize, size_t BlockCount>
class MemoryPool {
public:
    MemoryPool() {
        // 初始化空闲链表
        for (size_t i = 0; i < BlockCount - 1; ++i) {
            *reinterpret_cast<void**>(&pool_[i * BlockSize]) =
                &pool_[(i + 1) * BlockSize];
        }
        *reinterpret_cast<void**>(&pool_[(BlockCount - 1) * BlockSize]) = nullptr;
        freeList_ = &pool_[0];
        freeCount_ = BlockCount;
    }

    void* allocate() {
        ScopedCriticalSection cs;
        if (freeList_ == nullptr) return nullptr;

        void* block = freeList_;
        freeList_ = *reinterpret_cast<void**>(freeList_);
        --freeCount_;
        return block;
    }

    void deallocate(void* block) {
        if (block == nullptr) return;

        ScopedCriticalSection cs;
        *reinterpret_cast<void**>(block) = freeList_;
        freeList_ = block;
        ++freeCount_;
    }

    size_t freeCount() const { return freeCount_; }
    bool isEmpty() const { return freeCount_ == 0; }

    // 重载new/delete（用于C++对象）
    static void* operator new(size_t, MemoryPool& pool) {
        return pool.allocate();
    }

    static void operator delete(void* ptr, MemoryPool& pool) {
        pool.deallocate(ptr);
    }

private:
    alignas(std::max_align_t) uint8_t pool_[BlockSize * BlockCount];
    void* freeList_ = nullptr;
    size_t freeCount_ = 0;
};

// 使用示例
struct Message {
    uint8_t type;
    uint8_t data[32];
};

// 创建消息内存池
MemoryPool<sizeof(Message), 32> messagePool;

void poolExample() {
    // 从池中分配
    void* raw = messagePool.allocate();
    if (raw) {
        Message* msg = new(raw) Message;  // placement new
        msg->type = 1;
        // 使用消息...

        msg->~Message();  // 显式析构
        messagePool.deallocate(raw);
    }
```

## 10. 本章小结

本章深入讲解了实时操作系统的核心知识，要点如下：

| 主题 | 核心要点 |
|------|---------|
| RTOS原理 | 硬/软实时、RMS/EDF调度、上下文切换 |
| FreeRTOS任务 | 动态/静态创建、任务状态、vTaskDelayUntil |
| 优先级反转 | 反转原因、优先级继承协议、互斥量内置支持 |
| 信号量与互斥量 | 二值/计数信号量、互斥量所有权、RAII守卫 |
| 消息队列 | 队列通信、队列集、ISR安全操作 |
| 内存管理 | 5种heap方案、静态分配、内存池 |
| POSIX RT | SCHED_FIFO、消息队列、信号量、定时器 |
| 常见陷阱 | ISR中阻塞、优先级分配、栈溢出、死锁、忘记portYIELD |
| 调试技巧 | 运行时统计、钩子函数、事件组监控 |
| 项目实践 | 分层任务架构、消息总线、安全认证配置 |

**关键理解**：

1. **实时 ≠ 快速**：实时意味着可预测，不是越快越好
2. **优先级继承是必要的**：互斥量必须支持优先级继承以避免反转
3. **静态分配更可靠**：嵌入式系统应尽量使用静态分配避免碎片和不确定延迟
4. **中断安全是关键**：所有RTOS API都有ISR版本，必须正确使用
5. **POSIX RT适用于Linux**：运行嵌入式Linux的系统可以使用POSIX实时扩展
6. **ISR中绝不阻塞**：使用FromISR后缀的API，并正确处理上下文切换
7. **死锁可通过顺序获取互斥量避免**：所有任务以相同顺序获取多个互斥量
