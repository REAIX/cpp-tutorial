# ISO/IEC 标准文档

本仓库收录 C 和 C++ 语言的 ISO/IEC 标准文档。

## 命名规则

`ISO_IEC_{标准号}-{年份}_{语言版本}_{来源}.pdf`

- 标准号：9899（C 语言）、14882（C++）
- 语言版本：C99、C11、C17、C23 / Cpp98、Cpp03、Cpp11、Cpp14、Cpp17、Cpp20、Cpp23
- 来源：BS（英国标准学会采用版）、ISO（ISO 官方版）

注:BS版和ISO版内容无差异，仅封面和字体略微差异
